# TakeoffCraft: browser edition

TakeoffCraft as plain files: put the folder on any web server and open it in your browser. No account, no install, nothing to build. Your files stay on your computer.

- **Get it:** `takeoffcraft-browser-edition-v0.4.0.zip` from [Releases](https://github.com/getcadcraft/takeoffcraft/releases) (checksum beside it), or the [`v0.4/`](v0.4/) folder from a clone.
- **Install, servers, updating:** [v0.4/INSTALL.md](v0.4/INSTALL.md).
- **Try it now:** https://getcadcraft.com/try/takeoffcraft

Every other platform ships this same folder inside a thin shell.

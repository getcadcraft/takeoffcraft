## अंदाजपत्रक (XLSX वर्कशीट आणि CSV)

प्रत्येक वस्तूसाठी एक ओळ, त्यानंतर तिच्या असेंब्लीतील प्रत्येक घटकासाठी एक ओळ (आत दाबलेली). मग एक रिकामी ओळ आणि कामाचा एकूण.

| स्तंभ | सामग्री | XLSX मध्ये |
|---|---|---|
| A Item | वस्तूचे नाव (ठळक) किंवा घटकाचे नाव (आत दाबलेले) | मजकूर |
| B Type | Linear, Area, Count किंवा Component | मजकूर |
| C Unit | LF, m, SF, SY, m², EA, किंवा घटकाचे एकक | मजकूर |
| D Quantity | मोजलेली एकूण, किंवा सूत्राचा निकाल | संख्या |
| E Waste % | Waste | टक्केवारी (0.10 = 10%) |
| F Qty with waste | प्रमाण × (1 + waste) | सूत्र `D*(1+E)` |
| G Material per unit | साहित्याचा दर | संख्या |
| H Labor per unit | मजुरीचा दर | संख्या |
| I Material | विस्तारित साहित्य | सूत्र `ROUND(F*G,2)` |
| J Labor | विस्तारित मजुरी | सूत्र `ROUND(F*H,2)` |
| K Total | साहित्य + मजुरी | सूत्र `I+J` |
| L Notes | वापरलेले सूत्र, सूत्र त्रुटी, स्केल नसलेल्या शीटवरील चिन्हे, भिंत क्षेत्र, परिमिती | मजकूर |

कामाच्या एकूण ओळीत वरील प्रत्येक ओळीवर स्तंभ I, J आणि K चे `SUM`, आणि काही वगळले असल्यास नोट्समध्ये "अपूर्ण: वरील नोट्स पहा".

सूत्र त्रुटी असलेल्या ओळीला प्रमाण किंवा रक्कम नसते; तिची नोट त्रुटी देते. शीर्षक ओळ गोठवलेली असते.

CSV मध्ये, त्याच स्तंभांत साधी मूल्ये असतात, Waste % ही टक्केवारीची संख्या असते (10% साठी 10), आणि पैसे डॉलरमध्ये दोन दशांश स्थानांसह असतात. स्प्रेडशीटला सूत्र वाटू शकणारा मजकूर (`=`, `+`, `-` किंवा `@` ने सुरू होणारा) मजकूर राहावा म्हणून त्यापुढे `'` जोडला जातो.

## शीटनुसार (फक्त XLSX)

| स्तंभ | सामग्री |
|---|---|
| Sheet | शीटचे नाव (उघडलेली नसल्यास PDF नावासह) |
| Item | वस्तूचे नाव |
| Quantity | त्या शीटवरील त्या वस्तूचे प्रमाण, तिच्या एककात |
| Unit | वस्तूचे एकक |
| Marks | चिन्हांची संख्या |

## चिन्हे (फक्त XLSX)

प्रत्येक चिन्हासाठी एक ओळ.

| स्तंभ | सामग्री |
|---|---|
| Sheet | शीटचे नाव |
| Item | वस्तूचे नाव |
| Type | Linear, Area किंवा Count |
| Quantity | लांबी, निव्वळ क्षेत्र, किंवा 1 |
| Unit | LF किंवा m; SF, SY किंवा m²; EA |
| Detail | Linear: विभागांच्या लांबी, वजा केलेल्या "(वजा)" म्हणून चिन्हांकित, आणि "काढलेल्या (length) पैकी (length) वजा". Area: कट-आउट असल्यास एकूण आणि कट-आउट क्षेत्रे, आणि परिमिती. स्केल नसलेल्या चिन्हांसाठी "शीटला स्केल नाही". |
| Bid area | फक्त जेव्हा टेकऑफमध्ये निविदा क्षेत्रे असतात: चिन्हाचे क्षेत्र, किंवा "निविदा क्षेत्र नाही" |

## निविदा क्षेत्रनुसार (फक्त XLSX, टेकऑफमध्ये निविदा क्षेत्रे असल्यास)

| स्तंभ | काय |
|---|---|
| Bid area | क्षेत्राचे नाव, किंवा "निविदा क्षेत्र नाही" |
| Item | वस्तू, किंवा तिच्या खाली आत दाबलेला घटक |
| Unit | वस्तूचे किंवा घटकाचे एकक |
| Quantity | त्या क्षेत्रात मोजलेले (घटक: क्षेत्राच्या एकूणांवरील सूत्र) |
| Qty with waste | प्रमाण × (1 + waste) |
| Material, Labor, Total | पैशापर्यंत विस्तारित, अंदाजपत्रकाप्रमाणे |
| Notes | सूत्र, त्रुटी आणि स्केल नसलेली चिन्हे, अंदाजपत्रकाप्रमाणे |

प्रत्येक क्षेत्र "(नाव) उपबेरीज" ओळीने संपते, जिच्या खर्च त्या ओळींवरील `SUM` सूत्रे आहेत; शेवटची ओळ, **सर्व निविदा क्षेत्रे**, उपबेरीज जोडते. मग **Marks** वर्कशीटला सातवा स्तंभ असतो, **निविदा क्षेत्र**.

## स्केल (फक्त XLSX)

स्केल किंवा चिन्हे असलेल्या प्रत्येक शीटसाठी एक ओळ.

| स्तंभ | सामग्री |
|---|---|
| Sheet | शीटचे नाव |
| Scale | प्रीसेटचे नाव, किंवा कॅलिब्रेट केलेला स्केल, किंवा "स्केल नाही" |
| How | "Preset" (प्रीसेट), किंवा "कॅलिब्रेट केले (तुम्ही टाइप केलेल्या अंतरावर)" |
| Feet per PDF unit | TakeoffCraft वापरत असलेला अचूक स्केल घटक |

## फाइल नावे

- `(name).xlsx` आणि `(name).csv`, जिथे नाव टेकऑफमध्ये उघडलेल्या पहिल्या PDF वरून येते.
- CSV UTF-8 मध्ये आहे, byte order mark आणि Windows ओळ-शेवटांसह, जे प्रत्येक प्लॅटफॉर्मवरील स्प्रेडशीट प्रोग्राम वाचतात.

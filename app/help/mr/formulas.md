असेंब्ली घटक त्यांचे प्रमाण सूत्रातून घेतात. सूत्र म्हणजे वस्तूच्या मोजलेल्या मूल्यांवरील एक छोटी अंकगणितीय अभिव्यक्ती. उदाहरणांसाठी [असेंब्ली आणि सूत्रे](topic:assemblies) पहा.

## चल

| वस्तू प्रकार | चल | अर्थ |
|---|---|---|
| Linear | `L` | एकूण लांबी |
| Linear | `H` | वस्तूची उंची |
| Linear | `A` | भिंत क्षेत्र, L × H, ज्या ओळींवर उघडे आहेत त्यांची उघडी वजा करून (BimCraft मधील टेकऑफ). जेव्हा तो टेकऑफ मापन पद्धत नाव देतो, तेव्हा `A` त्या पद्धतीने मोजले जाते: पद्धतीच्या सर्वात लहान आकारापेक्षा मोठी नसलेली उघडी आत राहतात, आणि भिंती जिथे भेटतात तिथे पद्धत जे वगळते ते वगळले जाते. वस्तूखालील नोट पद्धतीचे नाव देते |
| Linear | `N` | ओळींची संख्या |
| Area | `A` | एकूण निव्वळ क्षेत्र (बाह्यरेषा वजा कट-आउट) |
| Area | `P` | एकूण परिमिती, कट-आउटच्या कडांसह |
| Area | `H` | वस्तूची खोली किंवा जाडी |
| Area | `N` | क्षेत्रांची संख्या |
| Count | `N` | गणना |

- चल वस्तूच्या एककांत असतात: [एकके](topic:units) पहा.
- मोठी आणि लहान अक्षरे सारखीच आहेत: `l` म्हणजे `L`.
- फक्त वस्तूच्या स्वतःच्या प्रकाराचे चल चालतात. Linear वस्तूवर `P` दिल्यास `"P" येथे मोजलेले मूल्य नाही. L, H, A, N वापरा.` मिळतो.
- रिकामी उंची किंवा खोली 0 आहे.

## संक्रिया

| लिहा | अर्थ |
|---|---|
| `+` | बेरीज |
| `-` किंवा `−` | वजाबाकी, किंवा ऋण मूल्य |
| `*` किंवा `×` | गुणाकार |
| `/` किंवा `÷` | भागाकार |
| `( )` | गट |

गुणाकार आणि भागाकार बेरीज आणि वजाबाकीच्या आधी होतात: `L * 2 + 4` म्हणजे (L × 2) + 4. शंका असल्यास कंस वापरा.

संख्यांना दशांश (`1.333`, `.5`) आणि घातांक (`1e3` = 1000) असू शकतात. स्पेस दुर्लक्षित केल्या जातात.

## फंक्शन्स

| फंक्शन | परिणाम | उदाहरण |
|---|---|---|
| `ceil(x)` | वरच्या पूर्ण संख्येपर्यंत पूर्णांकीकरण | `ceil(67.5)` = 68 |
| `floor(x)` | खालच्या पूर्ण संख्येपर्यंत पूर्णांकीकरण | `floor(67.5)` = 67 |
| `round(x)` | जवळच्या पूर्ण संख्येपर्यंत पूर्णांकीकरण, अर्धे शून्यापासून दूर | `round(2.5)` = 3 |
| `round(x, d)` | d दशांश स्थानांपर्यंत पूर्णांकीकरण (0 ते 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | सर्वात लहान मूल्य | `min(N, 10)` |
| `max(a, b, …)` | सर्वात मोठे मूल्य | `max(1, ceil(N / 12))` |
| `abs(x)` | चिन्हाशिवाय मूल्य | `abs(-3)` = 3 |

`ceil` आणि `floor` संगणकाच्या लहान पूर्णांकीकरण आवाजाकडे दुर्लक्ष करतात, त्यामुळे अचूक 1 असायला हवे ते मूल्य कधीही 2 पर्यंत वर पूर्ण होत नाही.

## त्रुटी

वाचता किंवा मोजता न येणारे सूत्र फील्डखाली आपली त्रुटी दाखवते, आणि घटक एकूणांतून वगळला जातो ({{ui:प्रमाण}} शीर्षक "अपूर्ण" म्हणते).

| संदेश | उपाय |
|---|---|
| सूत्र टाइप करा, जसे L किंवा ceil(L / 1.333) + 1. | सूत्र रिकामे आहे. |
| `"X"` येथे मोजलेले मूल्य नाही. वापरा … | सूचीबद्ध चलांपैकी एक वापरा. |
| `"X"` येथे फंक्शन नाही. ceil, floor, round, min, max, abs वापरा. | त्यापैकी एक फंक्शन वापरा. |
| सूत्रात `"#"` अनुमत नाही. | ते अक्षर काढा (एकके, `%`, `$` आणि `=` अनुमत नाहीत). |
| `")"` गहाळ आहे. / `"("` शिवाय `")"` आहे. | कंस संतुलित करा. |
| `")"` च्या आधी मूल्य गहाळ आहे. | जसे `max(1, )`: मूल्य भरा. |
| सूत्र लवकर संपते. | जसे `L *`: ते पूर्ण करा. |
| अनपेक्षित `"…"`. संक्रिया गहाळ आहे का? | दोन मूल्ये शेजारी, जसे `2L`: `2 * L` लिहा. |
| `ceil()` ला 1 मूल्य लागते. | फंक्शनला योग्य संख्येची मूल्ये द्या. |
| `round(x, digits)` ला 0 ते 10 मधील पूर्ण अंक हवेत. | दशांशांची पूर्ण संख्या वापरा. |
| सूत्र शून्याने भागते. | सहसा H 0 आहे: वस्तूची उंची किंवा खोली सेट करा. |
| सूत्र संख्या देत नाही. | निकाल संख्या होण्यासाठी खूप मोठा आहे. |
| ते सूत्र खूप मोठे आहे (जास्तीत जास्त 500 अक्षरे). | ते लहान करा. |

## रचनेनुसार सुरक्षित

सूत्र वरील चल आणि फंक्शन्ससह फक्त अंकगणित करू शकते. ते कोड चालवू शकत नाही किंवा इतर काही वाचू शकत नाही, त्यामुळे कोणी पाठवलेल्या प्रकल्प फाइलमधील सूत्र हानिकारक नसते.

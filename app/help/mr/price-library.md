**किंमत लायब्ररी** तुम्ही प्रत्येक कामात वापरता ते आयटम्स ठेवते: त्यांचा प्रकार, युनिट, उंची, वेस्ट, मटेरियल आणि मजुरीचे दर, आणि त्यांची असेंब्ली. ती या ब्राउझरमध्ये, कोणत्याही टेकऑफपासून वेगळी ठेवली जाते, त्यामुळे इथे उघडलेला प्रत्येक टेकऑफ तिचा वापर करू शकतो.

ती {{ui:Items}} पॅनलच्या वरच्या भागी असलेल्या {{ui:Library}} ने उघडा.

## लायब्ररी भरा

- {{ui:Import CSV…}} स्प्रेडशीट CSV म्हणून सेव्ह केलेली वाचते (खालील स्तंभ पहा). नाव आणि प्रकार आधीच लायब्ररीत असलेले आयटम्स बदलले जातात; बाकीचे जोडले जातात. न वाचता येणाऱ्या ओळी वगळल्या जातात, आणि कोणत्या का ते सांगितले जाते.
- {{ui:Add this takeoff's items}}: या टेकऑफमधील प्रत्येक आयटम, त्याच्या दरांसह आणि असेंब्लीसह लायब्ररीत कॉपी होतो (खुणांसह नाही).
- TakeoffCraft ने निर्यात केलेला अंदाज CSV ([अंदाज निर्यात करा](topic:export-estimate)) जसा आहे तसा आयात होतो: मागील कामाच्या किमती पुढच्या कामासाठी सुरुवात बनतात.
- {{ui:Trade packs…}} कोणत्याही ट्रेडसाठी (जसे ड्रायवॉल, इलेक्ट्रिकल किंवा काँक्रीट) किमतींशिवाय मोफत असेंब्ली जोडते. [ट्रेड पॅक](topic:trade-packs) पहा.

{{ui:Export CSV}} लायब्ररी CSV म्हणून जतन करते, प्रत ठेवण्यासाठी, स्प्रेडशीटमध्ये संपादित करण्यासाठी किंवा सहकाऱ्याला देण्यासाठी. {{ui:Clear}} ती रिकामी करते (दोनदा क्लिक करा).

:::note
लायब्ररी या ब्राउझरच्या स्टोरेजमध्ये राहते. दुसरा ब्राउझर, दुसरा संगणक किंवा खाजगी विंडो स्वतःची (किंवा काहीच नाही) ठेवते. ती हलवायची असेल तर एक्सपोर्ट करा.
:::

## टेकऑफमध्ये वापरा

- आयटम्स टिक करा ({{ui:Find in the library}} मध्ये टाइप करून यादी अरुंद करा) आणि {{ui:Add to takeoff}} निवडा. ते त्यांच्या असेंब्लीसह एका स्टेपमध्ये जोडले जातात, जी {{key:Mod+Z}} परत घेते. टेकऑफमध्ये आधीच असलेल्या नावाला क्रमांक मिळतो, जसे `Carpet (2)`.
- {{ui:Update prices}} लायब्ररीचा वेस्ट आणि दर टेकऑफच्या आयटम्सना देते, प्रत्येक आयटमला ज्याचे नाव आणि प्रकार लायब्ररी आयटमशी जुळतात, आणि असेंब्ली घटकांनाही तसेच, जर नाव जुळत असेल. उंची, युनिट्स आणि सूत्रे जशी आहेत तशीच राहतात. एक {{key:Mod+Z}} सर्व जुन्या किमती परत आणते.

## CSV स्तंभ

पहिली ओळ स्तंभांची नावे देते, कोणत्याही क्रमात; इतर स्तंभ दुर्लक्षित केले जातात.

| स्तंभ | त्यात काय जाते |
|---|---|
| Item (or Name) | आयटमचे नाव. आवश्यक. |
| Type | Linear, Area किंवा Count (LF, SF आणि EA देखील चालतात). रिकामे ठेवल्यास युनिट ठरवते. |
| Unit | LF किंवा m; SF, SY किंवा m²; EA. रिकामे: प्रकाराचे नेहमीचे युनिट. |
| Waste % | `10` किंवा `10%`. |
| Material per unit, Labor per unit | `2.10` किंवा `$1,250` सारखे दर. |
| Height (or Depth) | `9'-0"`, `9`, किंवा मेट्रिक युनिट्ससाठी `2.7`. |
| Component, Formula | Component नाव असलेली ओळ (किंवा Type `Component`) वरील आयटमच्या असेंब्लीचा भाग असते. तिचे Unit, Waste आणि दर तिचे स्वतःचे असतात; तिचे Formula आयटमची अक्षरे वापरते, [असेंब्ली आणि सूत्रे](topic:assemblies) पहा. |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

स्तंभांमध्ये स्वल्पविराम, अर्धविराम किंवा टॅब, कोणतेही चालते.

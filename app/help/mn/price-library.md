**Үнийн номын сан** нь та ажил бүрт ашигладаг зүйлсээ хадгална: тэдний төрөл, нэгж, өндөр, хаягдал, материал ба хөдөлмөрийн нэгжийн үнэ, мөн угсралт. Энэ нь ажлын тоо хэмжээнээс тусдаа энэ хөтөч дээр хадгалагдаж, таны нээсэн ажил бүр үүнийг ашиглана.

Нээхийн тулд **Зүйлс** самбарын дээд талд {{ui:Library}}-г дар.

## Номын санг бөглөх

- {{ui:Import CSV…}} таблицын програмаар CSV-ээр хадгалсан файлыг уншина (доорх баганууд). Нэр ба төрөл нь номын санд аль хэдийн байгаа зүйлсийг солино; үлдсэнийг нэмнэ. Уншиж чадаагүй мөрийг алгасаж, аль нь, яагаад гэдгийг хэлнэ.
- **Энэ ажлын тоо хэмжээний зүйлсийг нэмэх** нь нээлттэй ажлын зүйл бүрийг нэгжийн үнэ, угсралттайгаа номын санд хуулна (тэмдэгийг биш).
- TakeoffCraft-ийн экспортлодог тооцоо ([Тооцоог экспорт хийх](topic:export-estimate)) өөрчлөлтгүйгээр импортлогдоно: өмнөх ажлын үнэ дараагийнхыг эхлүүлнэ.
- {{ui:Trade packs…}} худалдааны ажлын төрлүүдэд (жишээ нь гипсэн хана, цахилгаан, бетон) угсралт нэмнэ, үнийн мэдээлэлгүйгээр. [Худалдааны багцууд](topic:trade-packs)-ыг үзнэ үү.

{{ui:Export CSV}} номын санг CSV-ээр хадгална: хуулбар хадгалах, хүснэгтээр засах эсвэл хамтрагчдаа өгөхөд. {{ui:Clear}} үүнийг хоослоно (хоёр удаа дар).

:::note
Номын сан энэ хөтчийн санах ойд байна. Өөр хөтөч, өөр компьютер эсвэл нууц цонх өөрийнхийг (эсвэл огт байхгүй) байдаг. Үүнийг зөөхийн тулд экспорт хий.
:::

## Ажилд ашиглах

- Зүйлсийг тэмдэглэ ({{ui:Find in the library}}-д бичиж жагсаалтыг багасгана) ба {{ui:Add to takeoff}}-г сонго. Тэд угсралттайгаа нэг алхмаар нэмэгдэх бөгөөд {{key:Mod+Z}} үүнийг буцаана. Ажилд аль хэдийн байгаа нэр нь дугаар авна, жишээ нь `Carpet (2)`.
- {{ui:Update prices}} нь нэр ба төрөл таарсан номын сангийн зүйл бүрт ажлын зүйлд хаягдал ба нэгжийн үнийг өгнө, мөн ижил нэртэй угсралтын бүрдэл хэсгүүдэд. Өндөр, нэгж, томъёо хэвээрээ үлдэнэ. Нэг {{key:Mod+Z}} хуучин үнийг бүгдийг буцаана.

## CSV-ийн баганууд

Эхний мөр нь баганын нэрийг дурын дарааллаар өгнө; бусад багана үл тоомсорлогдоно.

| Багана | Юу бичигдэх |
|---|---|
| Item (or Name) | Зүйлийн нэр. Заавал. |
| Type | Linear, Area эсвэл Count (LF, SF, EA бас ажиллана). Хоосон бол нэгж шийднэ. |
| Unit | LF эсвэл m; SF, SY эсвэл m²; EA. Хоосон: төрлийн ердийн нэгж. |
| Waste % | `10` эсвэл `10%`. |
| Material per unit, Labor per unit | `2.10` эсвэл `$1,250` шиг нэгжийн үнэ. |
| Height (or Depth) | `9'-0"`, `9`, эсвэл метрийн нэгжид `2.7`. |
| Component, Formula | Component нэртэй (эсвэл Type нь `Component`) мөр нь дээрх зүйлийн угсралтын хэсэг. Түүний Unit, Waste ба үнэ нь өөрийнх; түүний Formula нь зүйлийн үсгүүдийг ашиглана, см. [Угсралт ба томъёо](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

Баганын хооронд таслал, цэг таслал эсвэл таб бүгд ажиллана.

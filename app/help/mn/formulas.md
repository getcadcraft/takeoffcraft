Угсралтын бүрдэл тоо хэмжээгээ томьёогоор авна. Томьёо нь зүйлийн хэмжсэн утгууд дээрх жижиг арифметик илэрхийлэл юм. Жишээг [Угсралт ба томьёо](topic:assemblies)-д үзнэ үү.

## Хувьсагчид

| Зүйлийн төрөл | Хувьсагч | Утга |
|---|---|---|
| Шугаман | `L` | Нийт урт |
| Шугаман | `H` | Зүйлийн өндөр |
| Шугаман | `A` | Ханын талбай, L × H, нээлхийн хасалтаар (BimCraft-ын ажлын тоо хэмжээ). Тэр ажлын тоо хэмжээ хэмжих аргыг нэрлэсэн бол `A`-г тэр аргаар хэмжинэ: арга хамгийн бага хэмжээнээс том биш нээлхийг хэвээр оруулна, мөн ханыг уулзварт тэр аргаар хасах зүйлийг хасна. Зүйлийн доорх тэмдэглэл аргыг нэрлэнэ |
| Шугаман | `N` | Замын тоо |
| Талбай | `A` | Нийт цэвэр талбай (контураас таслалтыг хасна) |
| Талбай | `P` | Нийт периметр, таслалтын ирмэгийг оруулаад |
| Талбай | `H` | Зүйлийн гүн эсвэл зузаан |
| Талбай | `N` | Талбайн тоо |
| Тоолол | `N` | Тоо |

- Хувьсагчид зүйлийн нэгжээр байна: [Нэгжүүд](topic:units)-ийг үзнэ үү.
- Том ба жижиг үсэг адил: `l` нь `L`.
- Зүйлийн өөрийн төрлийн хувьсагч л ажиллана. Шугаман зүйл дээрх `P` нь «"P" энд хэмжигдсэн утга биш. Ашиглана уу: L, H, A, N.» гэсэн мессеж өгнө.
- Хоосон өндөр эсвэл гүн нь 0.

## Үйлдлүүд

| Бичнэ | Утга |
|---|---|
| `+` | Нэмэх |
| `-` эсвэл `−` | Хасах, эсвэл сөрөг утга |
| `*` эсвэл `×` | Үржүүлэх |
| `/` эсвэл `÷` | Хуваах |
| `( )` | Бүлэглэх |

Үржүүлэх ба хуваах нь нэмэх ба хасахаас өмнө хийгдэнэ: `L * 2 + 4` нь (L × 2) + 4. Эргэлзвэл хаалт ашиглана уу.

Тоонууд аравтын (`1.333`, `.5`) ба экспонент (`1e3` = 1000) байж болно. Хоосон зайг үл тооно.

## Функцууд

| Функц | Үр дүн | Жишээ |
|---|---|---|
| `ceil(x)` | Дээш бүхэл тоонд дугуйлна | `ceil(67.5)` = 68 |
| `floor(x)` | Доош бүхэл тоонд дугуйлна | `floor(67.5)` = 67 |
| `round(x)` | Ойрын бүхэл тоонд, хагасыг тэгээс хол | `round(2.5)` = 3 |
| `round(x, d)` | d аравтын орон хүртэл дугуйлна (0-10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Хамгийн бага утга | `min(N, 10)` |
| `max(a, b, …)` | Хамгийн их утга | `max(1, ceil(N / 12))` |
| `abs(x)` | Тэмдэггүй утга | `abs(-3)` = 3 |

`ceil` ба `floor` компьютерийн жижиг дугуйлтын алдааг үл тооно, тиймээс яг 1 байх утга хэзээ ч 2 болж дээш дугуйлагдахгүй.

## Алдаанууд

Уншиж эсвэл тооцоолж чадахгүй томьёо нь алдаагаа талбарын доор харуулна, мөн бүрдэл нийт дүнгээс хасагдана ({{ui:Тоо хэмжээ}} толгой «Дутуу» гэж бичнэ). Мессежүүд:

| Мессеж | Засвар |
|---|---|
| Томьёо бичнэ үү, жишээ нь L эсвэл ceil(L / 1.333) + 1. | Томьёо хоосон байна. |
| «X» энд хэмжигдсэн утга биш. Ашиглана уу … | Жагсаасан хувьсагчдын нэгийг ашиглана уу. |
| «X» энд функц биш. Ашиглана уу: ceil, floor, round, min, max, abs. | Эдгээрийн нэгийг ашиглана уу. |
| «#» томьёонд зөвшөөрөгдөхгүй. | Тэр тэмдэгтийг хасна уу (нэгж, `%`, `$` ба `=` зөвшөөрөгдөхгүй). |
| «)» дутуу байна. / «)»-ийн өмнө «(» байхгүй. | Хаалтуудыг тэнцвэржүүлнэ үү. |
| «)»-ийн өмнө утга дутуу байна. | Жишээ нь `max(1, )`: утгыг бөглөнө үү. |
| Томьёо хэт богино төгсөв. | Жишээ нь `L *`: дуусгана уу. |
| Гэнэтийн «…». Үйлдэл дутуу юу? | Хоёр утга зэрэгцсэн, жишээ нь `2L`: `2 * L` гэж бичнэ үү. |
| ceil() 1 утга авна. | Функцэд зөв тооны утга өгнө үү. |
| round(x, digits) 0-10 хүртэлх бүхэл орон шаардана. | Бүхэл тооны аравтын орон ашиглана уу. |
| Томьёо тэгээр хуваана. | Ихэвчлэн H нь 0: зүйлийн өндөр эсвэл гүнийг тохируулна уу. |
| Томьёо тоо өгөхгүй байна. | Үр дүн тоо болоход хэт том байна. |
| Томьёо хэт урт (дээд тал нь 500 тэмдэгт). | Богиносгоно уу. |

## Загварын хувьд аюулгүй

Томьёо нь дээр дурдсан хувьсагч ба функцээр л арифметик хийж чадна. Код ажиллуулах эсвэл өөр зүйлийг унших боломжгүй тул хэн нэгний илгээсэн төслийн файл дахь томьёо хор хөнөөлгүй.

## Төсөв (XLSX ажлын хуудас ба CSV)

Зүйл тус бүрд нэг мөр, түүний угсралтын бүрдэл тус бүрд нэг мөр (догол). Дараа нь хоосон мөр ба ажлын нийт дүн.

| Багана | Агуулга | XLSX-д |
|---|---|---|
| A Зүйл | Зүйлийн нэр (тод) эсвэл бүрдлийн нэр (догол) | Текст |
| B Төрөл | Шугаман, Талбай, Тоолол эсвэл Бүрдэл | Текст |
| C Нэгж | LF, m, SF, SY, m², EA эсвэл бүрдлийн нэгж | Текст |
| D Тоо хэмжээ | Хэмжсэн нийт эсвэл томьёоны үр дүн | Тоо |
| E Алдагдал % | Алдагдал | Хувь (0.10 = 10%) |
| F Алдагдалтай тоо хэмжээ | Тоо хэмжээ × (1 + алдагдал) | Томьёо `D*(1+E)` |
| G Материал нэгжид | Материалын нэгжийн үнэ | Тоо |
| H Хөдөлмөр нэгжид | Хөдөлмөрийн нэгжийн үнэ | Тоо |
| I Материал | Тооцсон материалын дүн | Томьёо `ROUND(F*G,2)` |
| J Хөдөлмөр | Тооцсон хөдөлмөрийн дүн | Томьёо `ROUND(F*H,2)` |
| K Нийт | Материал + хөдөлмөр | Томьёо `I+J` |
| L Тэмдэглэл | Ашигласан томьёо, томьёоны алдаа, масштабгүй хуудсан дээрх тэмдэглэгээ, ханын талбай, периметр | Текст |

Ажлын нийт мөр: дээрх бүх мөрийн I, J, K баганад `SUM`, мөн юу нэгэнт орхигдсон бол Тэмдэглэлд «Дутуу: дээрх тэмдэглэлийг харна уу».

Томьёоны алдаатай мөрөнд тоо хэмжээ ба дүн байхгүй; тэмдэглэлд алдаа нь заагдана. Толгой мөр бэхлэгдсэн байна.

CSV-д ижил баганууд энгийн утгатай байна: Алдагдал % нь хувийн тоо (10 = 10%), мөнгө доллараар хоёр аравтын оронтойгоор. Хүснэгт томьёо гэж ойлгож болох текст (`=`, `+`, `-` эсвэл `@`-аар эхэлсэн) урд нь `'` авч, текст хэвээр үлдэнэ.

## Хуудсаар (зөвхөн XLSX)

| Багана | Агуулга |
|---|---|
| Хуудас | Хуудасны нэр (нээгдээгүй бол PDF-ийн нэр хамт) |
| Зүйл | Зүйлийн нэр |
| Тоо хэмжээ | Тухайн зүйлийн тоо хэмжээ тэр хуудсан дээр, нэгжээрээ |
| Нэгж | Зүйлийн нэгж |
| Тэмдэглэгээ | Тэмдэглэгээний тоо |

## Тэмдэглэгээ (зөвхөн XLSX)

Тэмдэглэгээ бүр нэг мөр.

| Багана | Агуулга |
|---|---|
| Хуудас | Хуудасны нэр |
| Зүйл | Зүйлийн нэр |
| Төрөл | Шугаман, Талбай эсвэл Тоолол |
| Тоо хэмжээ | Урт, цэвэр талбай эсвэл 1 |
| Нэгж | LF эсвэл m; SF, SY эсвэл m²; EA |
| Дэлгэрэнгүй | Шугаман: сегментийн урт, хасагдсан нь «(хасагдсан)» гэж тэмдэглэгдэж, мөн «зурсан (урт)-ийн (урт) хасалт». Талбай: нийт ба таслагдсан талбай, таслагдсан хэсэг байвал, мөн периметр. Масштабгүй тэмдэглэгээнд «Хуудсанд масштаб байхгүй». |
| Тендерийн талбай | Зөвхөн ажлын тоо хэмжээнд тендерийн талбай байвал: тэмдэглэгээний талбай эсвэл «Тендерийн талбай байхгүй» |

## Тендерийн талбайгаар (зөвхөн XLSX, ажлын тоо хэмжээнд тендерийн талбай байвал)

| Багана | Юу вэ |
|---|---|
| Тендерийн талбай | Талбайн нэр, эсвэл «Тендерийн талбай байхгүй» |
| Зүйл | Зүйл, эсвэл түүний доорх догол бүрдэл |
| Нэгж | Зүйлийн эсвэл бүрдлийн нэгж |
| Тоо хэмжээ | Тэр талбайд хэмжсэн (бүрдэл: талбайн нийлбэр дээрх томьёо) |
| Алдагдалтай тоо хэмжээ | Тоо хэмжээ × (1 + алдагдал) |
| Материал, Хөдөлмөр, Нийт | Төсөвтэй адил центэд хүртэл тооцсон |
| Тэмдэглэл | Томьёо, алдаа ба масштабгүй тэмдэглэгээ, Төсөвтэй адил |

Талбар бүр «(нэр) дэд нийлбэр» мөрөөр төгсөх бөгөөд түүний дүнгүүд мөрүүдийн `SUM` томьёо байна. Сүүлийн мөр **Бүх тендерийн талбай** дэд нийлбэрүүдийг нэмнэ. **Тэмдэглэгээ** ажлын хуудсанд долоо дахь багана **Тендерийн талбай** нэмэгдэнэ.

## Масштабууд (зөвхөн XLSX)

Масштаб эсвэл тэмдэглэгээтэй хуудас бүр нэг мөр.

| Багана | Агуулга |
|---|---|
| Хуудас | Хуудасны нэр |
| Масштаб | Бэлэн тохиргооны нэр, тохируулсан масштаб, эсвэл «Масштаб байхгүй» |
| Хэрхэн | «Бэлэн тохиргоо», эсвэл «Тохируулсан (таны оруулсан зай дээр)» |
| Фут PDF нэгжид | TakeoffCraft-ын ашигладаг яг масштабын коэффициент |

## Файлын нэр

- `(name).xlsx` ба `(name).csv`, энд нэр нь ажлын тоо хэмжээнд нээсэн эхний PDF-ээс авна.
- CSV нь UTF-8 байт тэмдэгтэй, Windows мөрийн төгсгөлтэй; үүнийг бүх платформын хүснэгтийн программ уншина.

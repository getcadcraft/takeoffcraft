## Юу нээдэг вэ

| Файл | Яаж | Тэмдэглэл |
|---|---|---|
| PDF (`.pdf`) | {{ui:Open plans}}, {{key:Mod+O}}, эсвэл хуудсан дээр унагах | Нэгэн зэрэг хэд хэдэн. PDF-ийн хуудас бүр тусдаа хуудас болно. |
| Ажлын төсөл (`.takeoff.json`) | {{ui:Open takeoff}}, эсвэл хуудсан дээр унагах | Таны зүйлс, масштаб, тэмдэглэгээ. Үүнийг PDF-үүдтэйгээ хамт унагаж болно. |

Хуудсан дээр унагасан бусад файлыг алгасах бөгөөд статус мөрөнд тэдгээрийн нэрийг харуулна.

- **Нууц үгтэй PDF** нээгдэхгүй: "(name) нууц үгтэй байна. Хамгаалалтгүй хуулбар нээнэ үү."
- **Нэг PDF хоёр удаа** нэг удаа нээгдэнэ: "(name) аль хэдийн нээгдсэн байна." TakeoffCraft файлуудыг нэрээр нь бус агуулгаар нь таньдаг.
- **Скан PDF** нээгдэж, бусдын адил хэмжигдэнэ; TakeoffCraft PDF дахь текст шаарддаггүй.
- **Том планын багц**: PDF бүрийг нээхэд бүтнээр нь уншина (хурууны хээг тогтоохын тулд), тиймээс маш том файл хэдэн мөч зарцуулна. Жижиг зургуудыг гүйлгэх үед нэг нэгээр зурна.

## Юу хадгалдаг вэ

Хадгалах бүр татаж авалт. PDF-үүддээ юу ч буцаан бичигдэхгүй.

| Та сонгоно | Та авна | Юу агуулах вэ |
|---|---|---|
| {{ui:Save takeoff}} | `(name).takeoff.json` | Зүйлс, угсралтууд, нэгжийн үнэ, хуудасны масштаб ба тэмдэглэгээ бүр, PDF бүртэй агуулгаараа холбогдсон. PDF хуудас байхгүй. |
| {{ui:XLSX}} | `(name).xlsx` | Дөрвөн ажлын хуудас: {{ui:Estimate}} (шууд томьёотой), {{ui:By sheet}}, Тэмдэглэгээ, Масштаб. |
| {{ui:CSV}} | `(name).csv` | Тооцоо энгийн утгаар, зүйл ба бүрэлдэхүүн хэсэг бүрт нэг мөр. |
| {{ui:Marked PDF}} | `(PDF name) (takeoff).pdf` | Тэмдэглэгээтэй нээлттэй PDF бүрийн хуулбар, хуудсан дээр ажлын тоо хэмжээ, тайлбартай. PDF бүр тусдаа файл. |

Нэрийг энэ ажлын тоо хэмжээнд нээсэн эхний PDF-ээс авна. Одоогоор нэр солих талбар алга: өөр нэр хүсвэл татсан файлаа нэрлэнэ үү.

Харна уу: [Тооцоо ба тэмдэглэсэн PDF-ийг экспортлох](topic:export-estimate) ба [Экспортын багана](topic:export-columns).

## Татсан файлууд хаана очдог вэ

Таны хөтөч бүх татаж авалтыг хадгалдаг газарт, ихэвчлэн Downloads хавтсанд хадгална. Үүнийг {{pick:mac=Finder|windows=File Explorer|linux=таны файл менежер}}-ээс олно. Хэрэв таны хөтөч файл бүрийг хаана хадгалахыг асуудаг бол тэр асууна.

:::chromium
{{ui:Marked PDF}}-г хэд хэдэн тэмдэглэсэн PDF-тэй нэгэн зэрэг татахад хэд хэдэн файл зэрэг татагдана. Chrome ба Edge энэ сайтад олон файл татахыг зөвшөөрөх эсэхийг нэг удаа асууж магадгүй. {{ui:Allow}} гэж сонгоно уу.
:::

:::safari
Safari-гийн Тохиргоо, Ерөнхий хэсэгт татах байршлыг өөрчлөөгүй бол Safari файлыг Downloads хавтсанд хадгална.
:::

## Яагаад ажлын төсөл ба PDF-үүд тусдаа байдаг вэ

`.takeoff.json` файл зөвхөн таны ажлын тоо хэмжээг агуулна. Энэ нь PDF-үүдээ агуулгаар нь (файл бүрийн хурууны хээгээр) дахин олдог, тиймээс:

- PDF-ийг нэрлэх эсвэл зөөх нь хамаагүй.
- Өөр программаар өөрчлөгдсөн эсвэл дахин хадгалагдсан PDF нэр нь ижил байсан ч өөр файл гэж тооцогдоно.
- Нээгдээгүй PDF дээрх тэмдэглэгээ нийт дүнд тооцогдсоор байна.

Харна уу: [Ажлын тоо хэмжээг хадгалах ба дахин нээх](topic:save-and-reopen).

## Онлайн ба офлайн

PDF-үүд ба ажлын тоо хэмжээ таны компьютерээс онлайн эсвэл офлайн үед хэзээ ч гарахгүй. Холболт зөвхөн TakeoffCraft өөрөө ачаалагдахад хэрэгтэй.

Холболтгүйгээр ажиллахын тулд эхлээд онлайн байхдаа аппыг хадгалана уу:

1. Дээд талын аппын мөрөнд {{ui:Save for offline}} сонгоно уу.
   Хадгалах явцад товч "Хадгалж байна 12 / 40" гэж тоолно.
2. {{ui:Offline ready}} гарахыг хүлээнэ үү.

TakeoffCraft-ийг хадгалах нь аппыг, энэ тусламжийг, PDF уншигчийг, {{ui:Marked PDF}}-д ашигладаг PDF бичигчийг, мөн auto count worker-ийг таны хөтөчид ойролцоогоор 6 MB хадгална. {{ui:Offline ready}} гарсны дараа бүх зүйл офлайнд ажиллана: PDF нээх, хэмжих, {{ui:Auto count}}, {{ui:Save takeoff}}, {{ui:XLSX}}, {{ui:CSV}} ба {{ui:Marked PDF}}.

| Товч нь | Утга |
|---|---|
| {{ui:Save for offline}} | Энэ хөтчид хараахан хадгалагдаагүй. Хадгалахын тулд сонгоно уу. |
| Хадгалж байна (n) / (m) | Одоо хадгалж байна. |
| {{ui:Offline ready}} | Хадгалагдсан. Сонгоод {{ui:Save again (get the newest version)}} эсвэл {{ui:Remove the offline copy}} хийж болно. |
| {{ui:Could not save}} | Зарим файл татагдсангүй. Холболтоо шалгаад дахин сонгоно уу. |
| {{ui:Offline not available}} | Энэ хөтчийн цонх офлайн хуулбар хадгалж чадахгүй (нууц цонх болон зарим удирдлагатай компьютер хаадаг). |

Дэлгэрэнгүй, мөн хадгалсан хуулбар хөтөч бүрт хэр удаан хүчинтэй байдгийг: [Офлайнаар ажиллах](common:offline).

:::offline
Та офлайн байна. Аппын мөрөнд {{ui:Offline ready}} харагдаж байвал бүх зүйл ажиллана. Үгүй бол энэ табад одоогоор ачаалагдаагүй хэсгүүд (PDF бичигч {{ui:Marked PDF}}-д, auto count worker) одоо ачаалагдахгүй, мөн {{ui:Marked PDF}} «Тэмдэглэсэн PDF бичигдэж чадсангүй» гэж зогсоно. Ажлын тоо хэмжээ ямар ч тохиолдолд аюулгүй: {{ui:Save takeoff}}, {{ui:XLSX}} ба {{ui:CSV}} холболт шаардахгүй. Онлайн болтол табыг дахин ачаалахгүй байна уу.
:::

:::online
Та онлайн байна. Талбайн үзлэг эсвэл нислэгийн өмнө {{ui:Save for offline}} сонгоод {{ui:Offline ready}} гарахыг хүлээнэ үү.
:::

## Хүснэгтүүд

XLSX нь шууд томьёотой хэвээр үлдэнэ, тиймээс хүснэгтийн программ файлыг нээхэд тооцоог дахин тооцоолж, та хаягдал эсвэл нэгжийн үнийг өөрчилснөө хадгална. Ажлын дэвтрийг LibreOffice Calc дээр шалгасан бөгөөд бүх нийт дүнг ижил центээр дахин тооцоолсон. Excel дээр одоохондоо нээгдээгүй.

CSV нь байт дараалсан тэмдэг (BOM) бүхий энгийн утгатай тул хүснэгтийн программууд m² зэрэг тэмдэгтийг зөв уншина.

IFC 4.3 файл нь зам, төмөр зам, гүүр, далайн барилга болон тэдгээрийн бүрдэл хэсгүүдийг агуулж чадна: хучилт, хучилтын давхарга, бордюр, төмөр зам, шороон ажил, тулгуур, шон гэх мэт. TakeoffCraft эдгээрийг уншаад үнэлж болох төрөлтэй тоо хэмжээ болгоно.

## Файлаа нээх

1. **Файл** бүлэгт {{ui:Open plans}}-ыг сонгох, эсвэл {{key:Mod+O}} дарах.
2. IFC файлыг сонго (PDF-тэй хамт сонгож болно), эсвэл TakeoffCraft дээр буулга.

Ангилал болон урьдчилсан төрөл бүрт нэг төрөлтэй тоо хэмжээ үүснэ, жишээ нь «Pavement (flexible): count», мөн файлд заасан бол «length» m, «area» m² ба «volume» m³. Зүйл бүрийн тайлбарт хэдэн элемент тоологдсон, хэд нь тоо хэмжээ заагаагүй байсныг заана. Ижил нэртэй шинэ файлыг нээвэл эдгээр тоо хэмжээг шинэчилнэ, нэмэхгүй.

## Юу хийдэггүй вэ

- Файлын агуулсан quantity set-ийг (IfcElementQuantity) уншина. Элементийн 3D хэлбэрийг хэмжихгүй тул quantity set байхгүй элемент тоологдох боловч урт, талбай, эзлэхүүн нэмэхгүй.
- Зөвхөн IFC 4.3-ийн дэд бүтцийн ангиуд уншигдана. Барилгын файл (хана, хаалга, хавтан) энд тоо хэмжээ болохгүй; IFC 4.3 биш файл үүнийг хэлж, юу ч оруулахгүй.
- Нэгжүүд нь файлынх өөрийнх, метр болгон хөрвүүлэгдэнэ.

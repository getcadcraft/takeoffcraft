Тооцоо нь таны тоолсон зүйлийг үнэлдэг. **Тендерийн хураангуй** үүнийг үнэ болгон хувиргана: борлуулалтын татвар, ерөнхий зардал, ашиг, баталгааг нэмнэ, мөн таны оруулах ба хасах зүйлсээр **саналын PDF** гаргана.

Үүнийг {{ui:Export}} › {{ui:Bid summary & proposal…}}-ээс нээнэ. Бүх зүйл тоолгын хамт хадгалагдана, өөрчлөлт бүрийг буцааж болно.

## Нэмэлтүүд

Таван зүйлийн аль нэгэнд хувь бичнэ (бусдыг 0 үлдээнэ). Тэдгээрийг энэ дарааллаар, өмнөхөөсөө тооцно:

| Мөр | Тооцоолол |
|---|---|
| Материал, хөдөлмөр | Тооцооны нийт дүн (тоололд [нэмэлт сонголт](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) байвал үндсэн тендер). |
| Хөдөлмөрийн нөхцөл | Нөхцөл % × хөдөлмөр: таны бригадын цалин дээрх цалингийн татвар, даатгал, тэтгэмж. |
| **Өртөг** | Материал + хөдөлмөр + хөдөлмөрийн нөхцөл. |
| Материалын борлуулалтын татвар | Татвар % × материал. |
| Ерөнхий зардал | Ерөнхий зардал % × (өртөг + татвар). |
| Ашиг | Ашиг % × (өртөг + татвар + ерөнхий зардал). |
| Баталгаа | Баталгаа % × дээрх бүх зүйл. |
| **Тендерийн санал** | Мөрүүдийн нийлбэр. |

Мөр бүр центэд бүхэллэнэ. Ажлын ном ижил мөрүүдийг Estimate ажлын хуудасны нийт дүнгийн доор амьд томьёотойгоор харуулна. Хураангуй таны хувь бичих тутамд шинэчлэгдэнэ: {{key:Enter}} дарвал хувийг хүлээн авна. Нэмэлт сонголт бүр өөрийн өртөгт ижил нэмэлтээр харагдана, ингэснээр эзэн нь түүнийг авах нь үнэхээр юуг өөрчлөхийг харна.

## Санал

Саналд юу бичих ёстойгоо бөглөнө:

- **Төсөл** (хэрэв хоосон бол тоолгын нэр), **Хэнд** (үйлчлүүлэгч) ба **Хаанаас** (таны компани).
- **Оруулах** ба **Хасах**: мөр бүрт нэг; эхэнд зураас эсвэл цэг байвал зүгээр.
- **Нөхцөл**: чөлөөтэй текст, жишээ нь "30 хоногийн турш хүчинтэй."
- **Зүйлс ба тоо хэмжээг жагсаах**: хамрах хүрээ, зүйл бүрээр, тоо хэмжээтэйгээр, үнэгүй. Нийт дүнгээр санал болгохдоо тэмдэглэлээ авна.

{{ui:Proposal PDF}}-г сонгоно. PDF (`<takeoff> - proposal.pdf`) нь огноо, үнийн блок бүрийн нэмэлттэй ба тендерийн дүнтэй, нэмэлт сонголтууд, хамрах хүрээ, оруулах ба хасах зүйлс, нөхцөл, гарын үсэг ба огноо зурах мөрүүдтэй. Зарим тоо хэмжигдэж чадаагүй бол (масштабгүй хуудас) үнийн доор үүнийг хэлнэ.

## Экспортод

Тендерийн хураангуй байгаа тоолол дээр CSV нь түүнээр төгсөж, ажлын ном **Bid summary** ажлын хуудас авна: мөр бүр, түүний хувь ба дүн. Харна уу [Тооцоог экспортлох](topic:export-estimate).

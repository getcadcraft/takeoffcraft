Чычкан көрсөткүчү барактын каалаган жеринде турганда жана талаага текст терип жатпаганда тамга баскычтары иштейт. Диалог ачык болсо, анын өз баскычтары колдонулат. Тамгалар {{key:Shift}} менен же ансыз иштейт.

## Тартып жатканда

| Баскыч же аракет | Эмне кылат |
|---|---|
| Чыкылдатуу | Чекит коёт (чекит, {{ui:Саноо}} менен). |
| {{key:P}} | Жол: PDF сызыгынын бүтүн туташкан жолун же чыкылдатуудан кийинки контурду тандайт ([PDF'тин сызыктарын тандоо](topic:pick-the-lines)). |
| {{key:F3}} | Чиймеден сызыктарга тутунууну күйгүзүү же өчүрүү ([Чиймедеги сызыктарга тутуноо](topic:snap-to-the-drawing)). |
| {{key:Shift}} басып турганда чыкылдатуу | Кесиндини акыркы чекитке карата 0°, 45°, 90° же 135° бурчка тутундурат. Аркалардын чекиттери же айланалар үчүн эмес. |
| Эки жолу чыкылдатуу | Сызыкты аяктайт же аянтты, тешикти жабат. |
| {{key:Enter}} | Сызыкты аяктайт же аянтты, тешикти жабат. |
| Оң чыкылдатуу (жылдырбай) | Сызыкты аяктайт же аянтты, тешикти жабат. |
| Биринчи чекитти чыкылдатуу | Аянтты же тешикти жабат (үчүнчү чекиттен баштап). |
| {{key:Backspace}} же {{key:Delete}} | Акыркы чекитти алып салат (алгач күтүлүп жаткан аркалуу чекитти). |
| {{key:Esc}} | Күтүлүп жаткан аркалуу чекитти таштайт; андан кийин аяктала элек белгини жокко чыгарат; андан кийин {{ui:Тандоо}} куралына кайтат. |

| {{key:Shift}} + белгини чыкылдатуу | Тандоого кошот же алып салат. |

| Бурч туткасын сүйрөө | Ал чекитти жылдырат ({{key:Shift}} 45°ка тутундурат). Бир белги тандалганда иштейт. |
| {{key:Delete}} же {{key:Backspace}} | Тандалган белгилерди өчүрөт (сызбай жатканда). |
| {{key:Esc}} | Эч нерсени тандабайт: тандоону жана текшерүү сызыгын тазалайт. |
| {{key:Mod+Z}} | Артка кайтаруу. |
| {{key:Mod+Y}} же {{key:Mod+Shift+Z}} | Кайра аткаруу. |

## Көчүрүү жана чаптоо

| Баскыч | Эмне кылат |
|---|---|
| {{key:Mod+C}} | Тандалган белгилерди элементтери менен көчүрөт. |
| {{key:Mod+X}} | Кесүү: тандалган белгилерди көчүрүп, андан кийин өчүрөт. |
| {{key:Mod+V}} | Чаптоо: көчүрмө көрсөткүчтү ээрчийт; жери үчүн чыкылдатыңыз. |
| {{key:Mod+Shift+V}} | Ордунда чаптоо: ачык барактагы ошол эле жерге. |
| {{key:Mod+D}} | Тандалган белгилердин дубликатын жасайт: көчүрмө көрсөткүчтү ээрчийт; жери үчүн чыкылдатыңыз. |
| {{key:Esc}} | Эч нерсе койбойт: көрсөткүчтө турган чаптоону же дубликатты жокко чыгарат. |

Тамгалар өз алдынча да курал тандайт ({{key:C}} — {{ui:Саноо}}, {{key:D}} — {{ui:Текшерүү}}, {{key:X}} — {{ui:Тешик}}, {{key:V}} — {{ui:Тандоо}}, {{key:A}} — {{ui:Аянт}}); {{key:Mod}} менен бирге гана көчүрүп жана чаптайт. Текст талаасында бул баскычтар адаттагыдай текст көчүрөт жана чаптайт. Караңыз: [Белгилерди көчүрүү, чаптоо жана дубликаттоо](topic:copy-paste).

:::warning
{{key:Backspace}} сызбай жатканда тандалган белгини өчүрөт. Ал кокустан болсо, {{key:Mod+Z}} аны кайтарат.
:::

## Платформа боюнча эскертүүлөр

:::mac
- {{key:Mod}} — Command баскычы: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}. Толук экран өзгөчө: Control+Shift+F.
- Сенсордук тактада оң чыкылдатуу — эки манжа менен басуу, System Settings'те, Trackpad астында экинчи баскыч күйгүзүлгөндө. TakeoffCraft экинчи баскычты гана окуйт; Control-чыкылдатуу жөнөкөй чыкылдатуу катары кабыл алынып, чекит кошушу мүмкүн.
- Сенсордук тактада эки манжа менен сыйпоо баракты чоңойтот (жылдырбайт). Жылдыруу үчүн басып сүйрөңүз же {{key:Space}} басып туруп сүйрөңүз.
- Page Up жана Page Down өзүнчө жок клавиатураларда fn басып, жогорку жана төмөнкү жебелер.
- Backspace — delete деп белгиленген баскыч.
:::

:::windows
- {{key:Mod}} — Ctrl: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}.
- Ноутбуктун сенсордук тактасында эки манжа менен сыйпоо баракты чоңойтот. Жылдыруу үчүн басып сүйрөңүз.
:::

:::linux
- {{key:Mod}} — Ctrl. Айрым иш үстөлдөрүндө өз Ctrl+Alt же Super жарлыктары бар; TakeoffCraft аларды колдонбойт.
- Сенсордук тактада эки манжа менен сыйпоо баракты чоңойтот. Жылдыруу үчүн басып сүйрөңүз.
:::

:::touch
TakeoffCraft сенсорду бир көрсөткүч катары окуйт:

- Тийүү чекит коёт, белгини тандайт же саноо чекитин кошот.
- Бир манжа менен сүйрөө баракты жылдырат ({{ui:Авто саноо}} ичинде издөө кутусун тартат).
- Эки манжа менен кысып чоңойтуу азырынча колдоого алынбайт. {{ui:Бетти шайкештирүү}} жана {{ui:Туурасы боюнча}} колдонуңуз же клавиатурада {{key:Plus}} жана {{key:Minus}}.
- Аянтты жабуу үчүн анын биринчи чекитине тийиңиз. Сызыкты аяктоо үчүн браузериңиз эки тийүүнү эки жолу чыкылдатууга айландырган жерде эки жолу тийиңиз же клавиатурада {{key:Enter}} басыңыз.
- Көрсөткүч жок болгондуктан, тийгенге чейин түз узундук көрсөтүлбөйт.

Азыр көлөмдөрдү эсептөө үчүн клавиатура жана чычкан же сенсордук такта жакшыраак жол.
:::

## Браузер өзүнө калтырган баскычтар

Браузерлер айрым жарлыктарды өзүнө калтырат, бет аларды колдоно албайт: өтмөктү жабуу ({{key:Mod+W}}), жаңы өтмөк же терезе ({{key:Mod+T}}, {{key:Mod+N}}) жана браузердин масштабы ({{key:Mod+Plus}}, {{key:Mod+Minus}}). Ошондуктан TakeoffCraft баракты дөңгөлөк жана жөнөкөй {{key:Plus}} жана {{key:Minus}} баскычтары менен чоңойтот. {{key:Mod+Plus}} кокустан басылса, бүт бет чоңоёт; {{key:Mod+0}} аны калыбына келтирет. Караңыз: [Баскычтар, чычкандар жана сенсордук тактар](common:keys).

## Жылдыруу кайда жашайт

Жылдыруу командасы жок: саноо чекитин тандап сүйрөңүз, же аянт же сызыкты тандап анын бурч туткаларын сүйрөңүз.

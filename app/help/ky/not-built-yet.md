TakeoffCraft иштелип жатат. Бул тизмеде учурдагы сборка эмнени жасабай турганы жана иш-милдетти ошондо да кантип бүтүрүүгө болорун көрсөтүлгөн.

## Өлчөө

| Азырынча жок | Анын ордуna, азыр |
|---|---|
| Жолдун же контурдун ортосуна чекит кошуу | Белгини өчүрүп, кайра сызыңыз. |
| Кутучалуу (терезе) тандоо | {{key:Shift}} + ар бир белгини басыңыз, же барактагы бардык белгилер үчүн {{key:Mod+A}}. Караңыз: [Белгилерди көчүрүү, чаптоо жана дубликатка алуу](topic:copy-paste). |
| Чапталган көчүрмөнү буруу, чагылдыруу же масштабын өзгөртүү | Баракка ошол эле масштабда жана ошол эле багытта чаптаңыз; калганын колуңуз менен сызыңыз. |
| Сканерленген баракта же графикалык масштаб тилкесинде масштабды окуу | Даяр тандаңыз же тилкенин узундугу боюнча калибрлеңиз. |
| Бир бетте бир нече масштаб (деталдар, чоңойтулган пландар) | Бөлүктү барактын масштабында өлчөңүз; топтомдо болсо, деталды анын өз чоңойтулган барагында эсептеңиз. |

## Элементтер жана баа коюу

| Азырынча жок | Анын ордуna, азыр |
|---|---|
| Жыйнак формулалары элементтин башка белгилеринин түрлөрүн колдонот (бөлмө элементинин эшиктери анын кабатынын формулаларында) | Формулалар негизги түрдүн жыйынтыктарын колдонот; башка түрлөрдү өз саптарында бааласаңыз болот. |
| Жыйнак формулалары ар бир жол боюнча эсептелет | Формулалар элементтин жыйынтыктарын колдонот; ар бир жол үчүн кошумча нерселер үчүн `N` колдонуңуз. |
| Башка элементтин саныктарын колдонгон формулалар | Ошол элементте өлчөөнү кайталаңыз, же электрондук таблицага экспорттодо эсептеңиз. |
| Жыйнак компоненттериндеги бригадалар же 8 сааттан башка иш күнү | Бригаданы элементке бериңиз; башка иш күнүнүн узундугу үчүн бригада-күндөрүн бригада-саат ÷ сиздин иш күнү деп окуңуз. |
| Эскертмелерден, булуттардан жана белгилөөлөрдөн (жебелер, өлчөмдөр, мөөрлөр) башка белгилөөлөр же эскертмедеги жооптор | Текстине жазыңыз; аны жыйынтыктаганда статусун өзгөртүңүз. |
| Топ тарабынан бөлүшүлгөн баа китепканасы же аккаунтуңузда сакталган китепкана | Китепкана ушул браузерде сакталат: аны CSV катары экспорттоп, башка компьютерге импорттоңуз. |
| Иштеп жаткан сметачылар тарабынан текшерилген соода топтомдору | Ар бир топтом баштапкы үлгү: баа койгонуңузга чейин анын болжолдуулууларын өз жумушуңузга жана продукцияңызга салыштырып текшериңиз. Караңыз: [Соода топтомдору](topic:trade-packs). |
| Соода топтомдорундагы бааалар | Топтомдор жыйнактарды гана камсыздайт: өз баазаларыңызды коюңуз же баа тизмеңизди CSV катары импорттоңуз. |
| Көлөмдү атын өзгөртүү | Аты биринчи PDFтен алынат; жүктөлгөн файлдардын атын өзгөртүңүз. |
| Барактарды колуңуз менен аттоо | Барактар PDFтин бет белгилеринен аталат; файлдын аты жана бет боюнча издеңиз. |

## Электрондук таблицалар

XLSX жумушчу китеби LibreOffice Calcте текшерилди; ал ар бир жыйынтыкты TakeoffCraft менен бир тыйынга чейин бирдей эсептеген. Excelде али ачылган эмес. Электрондук таблица программасы күтүлбөгөн нерсени көрсөтсө, CSV экспорту ошол эле сметаны жөнөкөй маанилер катары камтыйт.

**Баа китепканасы** ар бир ишке колдонулуучу элементтерди сактайт: алардын түрү, бирдиги, бийиктиги, калдыгы, материал жана эмгек баалары, жана алардын жыйнагы. Ал ушул браузерде сакталат, ар бир көлөмдөн бөлөк, ошондуктан бул жерде ачылган ар бир көлөм аны колдоно алат.

Аны {{ui:Items}} панелинин үстүндөгү {{ui:Library}} менен ачыңыз.

## Китепкананы толтуруу

- {{ui:Import CSV…}} CSV катары сакталган электрондук таблицаны окуйт (төмөндөгү мамычаларды караңыз). Аты жана түрү китепканада бар элементтер алмаштырылат; калгандары кошулат. Окуй албаган саптар өткөрүлүп жиберилет, жана кайсы жана эмне үчүн экени айтылат.
- {{ui:Add this takeoff's items}} ачык көлөмдүн ар бир элементин китепканага көчүрөт, баалары жана жыйнагы менен (белгилери менен эмес).
- TakeoffCraft экспорттогон смета CSVси ([Сметаны экспорттоо](topic:export-estimate)) ошол бойдон импорттолот: акыркы иштин баалары кийинкисинин башталышы болот.
- {{ui:Trade packs…}} соода үчүн акысыз жыйнактарды кошот, мисалы дубалдар, электр же бетон, баасыз. Караңыз: [Соода топтомдору](topic:trade-packs).

{{ui:Export CSV}} китепкананы CSV катары сактайт: көчүрмө сактоо, электрондук таблицада түзөтүү же кесиптешке берүү үчүн. {{ui:Clear}} аны бошотот (эки жолу басыңыз).

:::note
Китепкана бул браузердин сактагычында турат. Башка браузер, башка компьютер же жашыруун терезе өз китепканасына ээ (же такыр жок). Көчүрүү үчүн экспорттоңуз.
:::

## Көлөмдө колдонуу

- Элементтерди белгилеңиз ({{ui:Find in the library}} менен тизмени тардатыңыз) жана {{ui:Add to takeoff}} тандаңыз. Алар жыйнактары менен бир кадамда кошулат, аны {{key:Mod+Z}} артка кайтарат. Көлөмдө бар ат `Carpet (2)` сыяктуу номер алат.
- {{ui:Update prices}} көлөмдүн элементтерине китепкананын калдыгын жана баасын берет, аты жана түрү дал келген ар бир элемент үчүн, жана жыйнактын бирдей аттагы компоненттери үчүн дагы ошондой. Бийиктиктер, бирдиктер жана формулалар өзгөрүүсүз калат. Бир {{key:Mod+Z}} бардык эски баалар кайтарат.

## CSV мамычалары

Биринчи сап мамычаларды атайт, каалаган тартипте; башка мамычалар эске алынбайт.

| Мамыча | Ага эмне жазылат |
|---|---|
| Item (же Name) | Элементтин аты. Милдеттүү. |
| Type | Linear, Area же Count (LF, SF жана EA да иштейт). Бош калса, бирдик чечет. |
| Unit | LF же m; SF, SY же m²; EA. Бош: түрдүн адаттагы бирдиги. |
| Waste % | `10` же `10%`. |
| Material per unit, Labor per unit | Баалар, мисалы `2.10` же `$1,250`. |
| Height (or Depth) | `9'-0"`, `9`, же метрикалык бирдиктер үчүн `2.7`. |
| Component, Formula | Component аты бар (же Type `Component`) сап анын үстүндөгү элементтин жыйнагынын бөлүгү болот. Анын Unit, Waste жана баалары өз алдынча; анын Formula элементтин тамгаларын колдонот, караңыз: [Жыйнактар жана формулалар](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

Үтүрлөр, нүктөлүү үтүрлөр же табуляциялар мамычалардын ортосунда бардыгы иштейт.

IFC 4.3 файлы жолдорду, темир жолдорду, көпүрөлөрдү, деңиз курулмаларын жана аларды түзгөн бөлүктөрдү камтышы мүмкүн: асфальт, конструкциялык катмарлар, бордюрлар, рельстер, жер иштери, таяныч, уюлдар жана башкалар. TakeoffCraft аларды окуп, баа коё турган типтүү санактарга айлантат.

## Файлды ачуу

1. **Файл** тобундагы {{ui:Open plans}} тандаңыз же {{key:Mod+O}} басыңыз.
2. IFC файлын тандаңыз (аны PDFтер менен кошо тандаса болот), же TakeoffCraftka таштаңыз.

Ар бир класс жана алдын ала аныкталган түр үчүн бир типтүү сан түзүлөт, мисалы "Асфальт (ийкемдүү): саны", жана файл көрсөткөндө "узундук" м да, "аянт" м² да жана "көлөм" м³ дө. Ар бир элементтин эскертмесинде канча элемент саналганы жана канча элементте сан көрсөтүлбөгөнү айтылат. Ошол эле аттагы жаңы файлды ачсаңыз, ал санактарды жаңыртат, кошпойт.

## Эмне кылбайт

- Файлда бар сан топтомдорун (IfcElementQuantity) окуйт. Элементтин 3D формаларын өлчөбөйт, ошондуктан сан топтому жок элемент саналат, бирок узундук, аянт же көлөм кошпойт.
- IFC 4.3тун инфраструктуралык класстары гана окулат. Имарат файлы (дубалдар, эшиктер, плиталар) бул жерде санактарга айландырылбайт; IFC 4.3 эмес файл муну айтып, эч нерсе киргизбейт.
- Бирдиктер файлдыкы, метрге айландырылган.

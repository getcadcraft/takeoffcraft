Жыйнактын компоненттери санын формуладан алышат. Формула — бул элементтин өлчөнгөн маанилеринен турган кичинекей арифметикалык туюнтма. Мисалдар үчүн [Жыйнактар жана формулалар](topic:assemblies) караңыз.

## Өзгөрмөлөр

| Элемент түрү | Өзгөрмө | Мааниси |
|---|---|---|
| Сызыктуу | `L` | Жалпы узундук |
| Сызыктуу | `H` | Элементтин бийиктиги |
| Сызыктуу | `A` | Дубалдын аянты, L × H, ачылыштары азайтылган (аларды алып жүргөн сызыктар үчүн) (BimCraft'тан эсептөө). Эгер ал эсептөө өлчөө ыкмасын атаса, `A` ошол ыкма менен өлчөнөт: ыкманын эң кичине өлчөмүнөн чоң эмес ачылыштар ичинде калат, ал эми дубалдар туташкан жерлерде ыкма эсептебеген нерсе чыгарылат. Элементтин астындагы эскертме ыкманын атын көрсөтөт |
| Сызыктуу | `N` | Сызыктардын саны |
| Аянт | `A` | Жалпы таза аянт (контурлар минус кесилген тешиктер) |
| Аянт | `P` | Жалпы периметр, кесилген тешиктердин кырлары кошулуп |
| Аянт | `H` | Элементтин тереңдиги же калыңдыгы |
| Аянт | `N` | Аянттардын саны |
| Санак | `N` | Санак |

- Өзгөрмөлөр элементтин өз бирдиктеринде: [Бирдиктер](topic:units) караңыз.
- Баш жана кичи тамгалар бирдей: `l` — бул `L`.
- Элементтин өз түрүнүн өзгөрмөлөрү гана иштейт. Сызыктуу элементте `P` колдонсо, ал `"P" бул жерде өлчөнгөн маани эмес. Колдонуңуз: L, H, A, N.` деген ката берет.
- Бийиктик же тереңдик бош болсо, ал 0 болот.

## Операторлор

| Жазылышы | Мааниси |
|---|---|
| `+` | Кошуу |
| `-` же `−` | Кемитүү же терс маани |
| `*` же `×` | Көбөйтүү |
| `/` же `÷` | Бөлүү |
| `( )` | Топтоо |

Көбөйтүү жана бөлүү кошуу жана кемитүүдөн мурун аткарылат: `L * 2 + 4` — бул (L × 2) + 4. Шек санасаңыз, кашааларды колдонуңуз.

Сандарда ондук бөлүктөр (`1.333`, `.5`) жана даражалар (`1e3` = 1000) болушу мүмкүн. Бош орундар эске алынбайт.

## Функциялар

| Функция | Натыйжа | Мисал |
|---|---|---|
| `ceil(x)` | Бүтүн санга чейин жогору тегеректөө | `ceil(67.5)` = 68 |
| `floor(x)` | Бүтүн санга чейин төмөн тегеректөө | `floor(67.5)` = 67 |
| `round(x)` | Эң жакын бүтүн санга тегеректөө, жарымдары нөлдөн алыстатылат | `round(2.5)` = 3 |
| `round(x, d)` | d ондук белгиге тегеректөө (0дөн 10го чейин) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Эң кичине маани | `min(N, 10)` |
| `max(a, b, …)` | Эң чоң маани | `max(1, ceil(N / 12))` |
| `abs(x)` | Белгисин алып салган маани | `abs(-3)` = 3 |

`ceil` жана `floor` компьютердин майда тегеректөө ызы-чуусун эске албайт, ошондуктан так 1 болушу керек маани эч качан 2ге тегеректелбейт.

## Каталар

Окула албаган же эсептелбеген формуланын катасы талаанын астында көрсөтүлөт, ал компонент жалпы суммаларга кирбейт (баш тилкеде {{ui:Quantities}} «Толук эмес» деп жазылат).

| Билдирүү | Оңдоо |
|---|---|
| «Формуланы териңиз, мисалы L же ceil(L / 1.333) + 1.» | Формула бош. |
| `"X" бул жерде өлчөнгөн маани эмес. Колдонуңуз …` | Тизмеленген өзгөрмөлөрдүн бирин колдонуңуз. |
| `"X" бул жерде функция эмес. Колдонуңуз: ceil, floor, round, min, max, abs.` | Ушул функциялардын бирин колдонуңуз. |
| `"#" формулада уруксат берилбейт.` | Ал белгини алып салыңыз (бирдиктер, `%`, `$` жана `=` уруксат берилбейт). |
| `")" жетишпейт.` / `")" бар, бирок "(" жок.` | Кашааларды теңеңиз. |
| `")" алдында маани жетишпейт.` | Мисалы `max(1, )` сыяктуу нерсе: маанини толтуруңуз. |
| `Формула өтө эрте бүтөт.` | Мисалы `L *` сыяктуу: аягына чейин жазыңыз. |
| `Күтүлбөгөн "…". Оператор жетишпейби?` | Эки маани катар турганда, мисалы `2L`: `2 * L` деп жазыңыз. |
| `ceil() 1 маани кабыл алат.` | Функцияга туура сандагы маани бериңиз. |
| `round(x, digits) 0дөн 10го чейинки бүтүн сандарды талап кылат.` | Бүтүн ондук белгилердин санын колдонуңуз. |
| `Формула нөлгө бөлөт.` | Адатта H 0: элементтин бийиктигин же тереңдигин коюңуз. |
| `Формула сан бербейт.` | Натыйжа сан болуу үчүн өтө чоң. |
| `Бул формула өтө узун (500 белгиден көп эмес).` | Кыскартыңыз. |

## Долбоорлоодо коопсуз

Формула жогоруда көрсөтүлгөн өзгөрмөлөр жана функциялар менен гана арифметика аткара алат. Ал код иштете же башка нерсени окуй албайт, ошондуктан сиз алган долбоор файлындагы формула зыянсыз.

Смета сиз эсептеген нерсеге баа коёт. **Сунуштун кыскача маалыматы** аны бааға айлантат: сатуу салыгын, үстөк чыгымды, пайданы жана кепилдикти кошот жана кирүүчү жана кирбей турган нерселери бар **сунуш PDF** файлын жасайт.

Аны {{ui:Экспорт}} › {{ui:Сунуштун кыскача маалыматы жана сунуш…}} ачыңыз. Анын ичиндеги бардык нерсе көлөм менен бирге сакталат, ар бир өзгөртүүнү артка кайтарууга болот.

## Накрутка

Беш пайыздын ичинен кайсы бирине пайыз жазыңыз (калгандарын 0 калтырыңыз). Алар бул тартипте эсептелет, ар бири өзүнүн үстүндөгүгө карата:

| Сап | Кантип эсептелет |
|---|---|
| Материал, Эмгек | Сметанын суммалары (көлөмдө [альтернативалар](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) болсо, негизги сунуш). |
| Эмгек жүгү | Эмгек жүгү % × эмгек: жумушчу командаңыздын эмгек акысына салыктар, камсыздандыруу жана жеңилдиктер. |
| **Чыгым** | Материал + эмгек + эмгек жүгү. |
| Материалга сатуу салыгы | Салык % × материал. |
| Үстөк чыгым | Үстөк чыгым % × (чыгым + салык). |
| Пайда | Пайда % × (чыгым + салык + үстөк чыгым). |
| Кепилдик | Кепилдик % × жогоруда бардыгы. |
| **Сунуш** | Саптардын суммасы. |

Ар бир сап цент менен тегеректелет. Жумуш китебинде ушул саптар **Смета** барагынын жалпы суммасынын астында жандуу формулалар менен көрсөтүлөт. Сумма сиз терген сайын жаңыланат: {{key:Enter}} пайызды кабыл алат. Ар бир альтернатива өз чыгымында ушундай накрутка менен көрсөтүлөт, ошондо ээси аны алып салганда чындап эмне өзгөрөрүн көрөт.

## Сунуш

Сунуш эмнени айтышы керектигин толтуруңуз:

- **Долбоор** (бош болсо, көлөмдүн аты), **Кимге** (кардар) жана **Кимден** (сиздин компания).
- **Кирүүчү** жана **Кирбей турган**: ар бирин жаңы сапта; башында сызык же оңдук белгиси болсо да болот.
- **Шарттар**: эркин текст, мисалы «30 күн жарактуу».
- **Элементтерди жана көлөмдөрдү тизмелөө**: скоп, элемент-элемент, көлөмдөр менен жана бааларсыз. Сумма сунушу үчүн белгисин алып салыңыз.

{{ui:Сунуш PDF}} тандаңыз. PDF (`<takeoff> - proposal.pdf`) датаны, ар бир накрутка жана сунуш менен баа блогун, альтернативаларды, скопту, кирүүчү жана кирбей турган нерселерди, шарттарды жана кол коюу жана дата сызыктарын камтыйт. Айрым көлөмдөрдү өлчөө мүмкүн болбосо (масштабы жок барак), ал баанын астында ошону айтат.

## Экспортто

Эсептөөдө сунуштун кыскача маалыматы болгондо CSV ага менен аяктайт, ал эми жумуш китебинде **Сунуштун кыскача маалыматы** барагы пайда болот: ар бир сап, анын пайызы жана суммасы менен. Караңыз: [Сметаны экспорттоо](topic:export-estimate).

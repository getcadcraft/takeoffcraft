Элементтин **жыйнагы** — бул компоненттердин тизмеси, ар бирине өзүнүн саны формуласы, калдыгы жана баа ставкалары бар. Формула элементтин өлчөнгөн жалпы маанилерин колдонот, ошондуктан дубалдын бир өлчөөсү тирөөч устундарды, брустарды жана тактайды бир эле учурда берет жана өлчөгөнүңүздө алар жаңыланат.

## Колдонсо боло турган өзгөрмөлөр

| Элемент түрү | Өзгөрмөлөр |
|---|---|
| Сызыктуу | `L` узундук, `H` бийиктик, `A` дубалдын аянты (L × H), `N` сыздардын саны |
| Аянт | `A` аянт, `P` периметр (контур + кесилген жерлер), `H` тереңдик же калыңдык, `N` аянттардын саны |
| Саноо | `N` саны |

Маанилер элементтин өз бирдиктеринде берилет: LF жана SF элементтери үчүн футтарда жана квадраттык футтарда, m жана m² элементтери үчүн метрлерде жана квадраттык метрлерде. SY элементи үчүн `A` квадраттык ярддарда, ал эми `P` жана `H` футтарда калат.

Формулаларда `+ - * /` (же × ÷), кашаалар, сандар жана `ceil`, `floor`, `round`, `min`, `max` жана `abs` функциялары колдонулат. Толук эрежелер [Формула тили](topic:formulas) бөлүмүндө.

## Иш мисалы: ички дубал

Айталы, сиз **Ички дубал A түрү** элементин сызыктуу элемент катары өлчөдүңүз: 4 сыз, жалпы 120 LF, {{ui:Бийиктик}} `9'-0"`. Анын **Өлчөнгөн** маанилери: L = 120, N = 4, A = 1,080 (дубалдын SF, бир тарап).

1. {{ui:Элементтер}} астынан элементти тандаңыз.
2. {{ui:Жыйнак}} бөлүмүндө {{ui:Компонент кошуу}} тандаңыз.
   «Компонент» деген компонент пайда болот, формуласы `L` жана натыйжасы төмөндө.
3. {{ui:Аты}} талаасына `Studs 16 in o.c.`, ал эми {{ui:Бирдик}} талаасына `EA` деп жазыңыз.
4. {{ui:Саны формуласы}} талаасына `ceil(L * 12 / 16) + N` деп жазыңыз.
   Натыйжа терүү учурунда жаңыланат: «= 94 EA». Бул 120 футтук узундук боюнча 16 дюйм борбор аралыгында бир устун (90), плюс 4 сыздын ар бирин жаап турган дагы бир устун.
5. Брустар үчүн {{ui:Компонент кошуу}} дагы бир жолу тандаңыз: аты `Plates, top and bottom`, бирдик `LF`, формула `L * 2`. Натыйжа: 240 LF.
6. Тактайды кошуңуз: аты `Gypsum board 4x8, both sides`, бирдик `sheets`, формула `ceil(A * 2 / 32)`. Натыйжа: 68 барак (2,160 SF тактай ÷ барагына 32 SF = 67.5, жогору тегеректелген).
7. Ар бир компоненттин {{ui:Калдык %}}, {{ui:Материал $}} жана {{ui:Жумушчу күч $}} талааларын толтуруңуз.
   Ар бир компонент {{ui:Саныктар}} тизмесинде элементтин астында өз катарын алат, элемент сыяктуу баалангат, ал эми {{ui:Жумуштун жалпы суммасы}} аны камтыйт.

Дубалдын баасы толугу менен компоненттерде болсо, элементтин өз материал жана эмгек ставкаларын 0 калтырыңыз, антпесе ал эки жолу эсепке алынат.

:::tip
Калдык формуладан кийин колдонулат жана тегеректелбейт: 10% калдык менен 68 барак 74.8 барак болот. Бүтүн барактарды заказ берүү үчүн калдыкты формуланын ичине киргизиңиз, мисалы `ceil(A * 2 / 32 * 1.1)`, ал эми компоненттин калдыгын 0 калтырыңыз.
:::

## Дагы формулалар

| Эмне | Элемент | Формула |
|---|---|---|
| Тирөөч устундар, 24 дюйм борбор аралыгында | Сызыктуу | `ceil(L / 2) + N` |
| Жылуулоочу матлар, SF | Бийиктиги бар сызыктуу | `A` |
| Боёк, эки тарап, галлон 350 SF эсебинде | Бийиктиги бар сызыктуу | `ceil(A * 2 / 350)` |
| Плитка караптары, 15 SF, 10% запас менен | Аянт | `ceil(A * 1.1 / 15)` |
| Плинтус же четки тилкелер, LF | Аянт | `P` |
| Бетон, кубдук ярд | Тереңдиги бар аянт | `A * H / 27` |
| Бетон, чейрек ярдга чейин жогорулатылган | Тереңдиги бар аянт | `ceil(A * H / 27 * 4) / 4` |
| Топчулар, эшикке үч | Саноо | `N * 3` |
| Жок дегенде бир кути, 12ге бир | Саноо | `max(1, ceil(N / 12))` |

## Формула туура эмес болгондо

Формуланын астындагы сап ката билдирүүсүнө айланат, мисалы `"X" is not a measured value here. Use L, H, A, N.` же `A ")" is missing.` Андан кийин компонентте суммалар болбойт, анын {{ui:Саныктар}} тизмесиндеги катарында «Formula error: …» көрсөтүлөт, ал эми башкы бөлүгүндө «Incomplete: 1 formula error (not in the totals)» деп жазылат. Формуланы оңдоңуз, жалпы суммалар жаңыланат.

Нөлгө бөлгөн формула да ката: «The formula divides by zero.», мисалы тереңдиги жок элементте `A / H`.

## Чектөөлөр

- Формулалар элементтин **жалпы суммаларында** иштейт, ар бир сап боюнча эмес. `ceil(L * 12 / 16) + N` ар бир сызыкка бир устун кошот; сызык боюнча тегеректөө азырынча жок.
- Формула өзүнүн элементинин гана өзгөрмөлөрүн колдоно алат, башка элементтики эмес.
- Элементке 50гө чейин компонент, формулага 500 белгиге чейин.

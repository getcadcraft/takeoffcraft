## Смета (XLSX жумушчу барагы жана CSV)

Ар бир элемент үчүн бир сап, андан кийин анын жыйнагынын ар бир компоненти үчүн сап (оңго чегинтилген). Андан кийин бош сап жана жалпы сумма.

| Мамыча | Мазмуну | XLSX'те |
|---|---|---|
| A Элемент | Элементтин аты (калың) же компоненттин аты (чегинтилген) | Текст |
| B Түрү | Сызыктуу, Аянт, Санак же Компонент | Текст |
| C Бирдик | LF, m, SF, SY, m², EA же компоненттин бирдиги | Текст |
| D Саны | Өлчөнгөн жалпы же формуланын натыйжасы | Сан |
| E Калдык % | Калдык | Пайыз (0.10 = 10%) |
| F Калдык менен саны | Саны × (1 + калдык) | Формула `D*(1+E)` |
| G Материалдын бирдик баасы | Материалдын бирдик баасы | Сан |
| H Эмгектин бирдик баасы | Эмгектин бирдик баасы | Сан |
| I Материал | Кеңейтилген материал | Формула `ROUND(F*G,2)` |
| J Эмгек | Кеңейтилген эмгек | Формула `ROUND(F*H,2)` |
| K Жалпы | Материал + эмгек | Формула `I+J` |
| L Эскертмелер | Колдонулган формула, формуланын катасы, масштабы жок барактардагы белгилер, дубалдын аянты, периметр | Текст |

Жалпы сумманын сабы: бардык жогорудагы саптардын I, J жана K мамычаларынын `SUM`у; эгер бир нерсе калтырылса, Эскертмелерде «Толук эмес: жогорудагы эскертмелерди караңыз».

Формула катасы бар сапта саны же суммалар болбойт; анын эскертмесинде ката көрсөтүлөт. Баш сап бекитилген.

CSVде ошол эле мамычалар жөнөкөй маанилерди камтыйт, Калдык % пайыздын саны (10 = 10%), ал эми акча долларларда эки ондук белги менен. Электрондук таблица формула деп тааныши мүмкүн болгон текст (`=`, `+`, `-` же `@` менен башталат) текст бойдон калуу үчүн алдына `'` белгиси алат.

## Барак боюнча (XLSX гана)

| Мамыча | Мазмуну |
|---|---|
| Барак | Барактын аты (PDF аты менен, эгер ал ачык эмес болсо) |
| Элемент | Элементтин аты |
| Саны | Ошол элементтин ошол баракта саны, анын бирдигинде |
| Бирдик | Элементтин бирдиги |
| Белгилер | Белгилердин саны |

## Белгилер (XLSX гана)

Ар бир белги үчүн бир сап.

| Мамыча | Мазмуну |
|---|---|
| Барак | Барактын аты |
| Элемент | Элементтин аты |
| Түрү | Сызыктуу, Аянт же Санак |
| Саны | Узундук, таза аянт же 1 |
| Бирдик | LF же m; SF, SY же m²; EA |
| Майда маалымат | Сызыктуу: сегменттердин узундуктары, чыгарылгандар «(чыгарылат)» деп белгиленип, жана «(узундук) чийилген (узундук) чыгарылат». Аянт: кесилген тешиктер болгондо жалпы жана кесилген аянттар, жана периметр. Масштабсыз белгилер үчүн «Барактын масштаби жок». |
| Тендердик аймак | Тендердик аймактар болгондо гана: белгинин аянты же «Тендердик аймак жок» |

## Тендердик аймак боюнча (XLSX гана, эгер эсептөөдө тендердик аймактар болсо)

| Мамыча | Мазмуну |
|---|---|
| Тендердик аймак | Аймактын аты же «Тендердик аймак жок» |
| Элемент | Элемент же анын астындагы чегинтилген компонент |
| Бирдик | Элементтин же компоненттин бирдиги |
| Саны | Ошол аймакта өлчөнгөн (компоненттер: аймактын жыйынтыктары боюнча формула) |
| Калдык менен саны | Саны × (1 + калдык) |
| Материал, Эмгек, Жалпы | Цент менен кеңейтилген, Смета сыяктуу |
| Эскертмелер | Формула, каталар жана масштабсыз белгилер, Смета сыяктуу |

Ар бир аймак «(аты) жыйынтыгы» сабы менен аяктайт, анын чыгымдары ошол саптардын `SUM` формулалары; акыркы сап **Бардык тендердик аймактар** жыйынтыктарды кошот. **Белгилер** жумушчу барагында андан кийин жетинчи мамыча, **Тендердик аймак** болот.

## Масштабдар (XLSX гана)

Масштабы же белгилери бар ар бир барак үчүн бир сап.

| Мамыча | Мазмуну |
|---|---|
| Барак | Барактын аты |
| Масштаб | Пресеттин аты, же калибрленген масштаб, же «Масштаб жок» |
| Кантип | «Пресет», же «Калибрленген (сиз терген аралык боюнча)» |
| PDF бирдигине фут | TakeoffCraft колдонгон так масштаб коэффициенти |

## Файл аттары

- `(name).xlsx` жана `(name).csv`, мында аты эсептөөдө ачылган биринчи PDFтен алынат.
- CSV — UTF-8, байт тартиби белгиси жана Windows сап үзүлүштөрү менен; аны ар кандай платформадагы электрондук таблица программалары окуйт.

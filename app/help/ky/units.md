## Элемент бирдиктери

| Элемент түрү | Бирдик | Аты |
|---|---|---|
| Сызыктуу | LF | сызыктуу фут (демейки) |
| Сызыктуу | m | метр |
| Аянт | SF | чарчы фут (демейки) |
| Аянт | SY | чарчы ярд |
| Аянт | SQ | чатыр квадраттары (100 чарчы фут) |
| Аянт | ac | акр |
| Аянт | m² | чарчы метр |
| Аянт | ha | гектар |
| Саноо | EA | ар бири |

Аны элемент редакторундагы {{ui:Unit}} менен каалаган убакта өзгөртсөңүз болот, өлчөгөндөн кийин да; сан дароо айландырылат.

{{ui:Unit}} тизмеси {{ui:Settings}} › {{ui:General}} › {{ui:Units}} ичинде күйгүзүлгөн бирдиктерди көрсөтөт, ал эми ар дайым элементтин өз бирдигин. Жаңы элемент ошол жердеги жылдызчаланган узундук же аянт бирдигинде башталат, эгер ал элементтин бирдиктеринин бири болсо; антпесе LF же SF'те. Караңыз: [Бирдиктер, терилген маанилер жана бирдик тизмелери](common:unit-lists).

## Формула өзгөрмөлөрүнүн бирдиктери

| Элемент бирдиги | L, P, H | A |
|---|---|---|
| LF | фут | чарчы фут (дубалдын аянты) |
| m | метр | чарчы метр (дубалдын аянты) |
| SF | фут | чарчы фут |
| SY | фут | чарчы ярд |
| SQ | фут | квадраттар |
| ac | фут | акр |
| m² | метр | чарчы метр |
| ha | метр | гектар |

SY элементтери үчүн `A` чарчы ярдда, ал эми `P` жана `H` футта калат. SY элементинен көлөм `A * 9 * H / 27` куб ярд; плиталар үчүн SF колдонуу жөнөкөй.

## Бирдиктер кайда бекитилген

Айрым көрсөткүчтөр ар дайым футту колдонот:

- сызып жатканда абал тилкесиндеги түз көрсөткүч (фут-дюйм, SF),
- **Тандалган белги** (фут-дюйм, LF жана SF),
- текшерүүнүн натыйжасы (фут-дюйм, ондук фут жана метр менен),
- электрондук таблицанын Белгилер барагындагы кесиндилердин узундуктары жана периметрлери (фут-дюйм).

Элементтин жыйынтыктары, {{ui:Quantities}} таблицасы, формулалар жана Смета барагы элементтин өз бирдигин колдонот.

## Масштаб жана бирдиктер өз ара бөлүнгөн

Барактын масштабы чиймэнин канчалык чоң экенин айтат; элементтин бирдиги аны кантип отчет кылууну айтат. Метрикалык чийме `1:100` масштабында LF менен эсептелиши мүмкүн, ал эми империялык чийме m² менен. Калибрлөө каалаган бирдикти кабыл алат: `24'-6"`, `7.5 m`, `7500 mm`.

## Тактык

TakeoffCraft басып турган чекиттеринен так ченейт, анын ичинде ийри сызыктардын чыныгы узундуктары жана аянттары, жана саныктарды тегеректебейт. Көрсөтүү узундуктарды 1/16 дюймга, ондук сандарды эки орунга чейин тегеректейт. Акча гана жалпы суммаларда, центке чейин тегеректелет.

Складові отримують кількість з формули. Формула — це невеликий арифметичний вираз над виміряними значеннями позиції. Приклади з розрахунками див. у [Складові та формули](topic:assemblies).

## Змінні

| Тип позиції | Змінна | Значення |
|---|---|---|
| Лінійна | `L` | Загальна довжина |
| Лінійна | `H` | Висота позиції |
| Лінійна | `A` | Площа стіни, L × H, мінус отвори відрізків, які їх мають (визначення обсягів із BimCraft). Коли у визначенні названо спосіб вимірювання, `A` вимірюється ним: отвори не більші за найменший розмір цього способу залишаються, а те, що спосіб не враховує там, де стіни сходяться, виключається. Примітка під позицією називає спосіб |
| Лінійна | `N` | Кількість відрізків |
| Площа | `A` | Загальна чиста площа (контури мінус вирізи) |
| Площа | `P` | Загальний периметр, включно з краями вирізів |
| Площа | `H` | Глибина або товщина позиції |
| Площа | `N` | Кількість площ |
| Підрахунок | `N` | Підрахунок |

- Змінні вимірюються в одиницях позиції: див. [Одиниці](topic:units).
- Великі та малі літери однакові: `l` — це `L`.
- Працюють лише змінні свого типу позиції. `P` для лінійної позиції дає: «"P" тут не є виміряним значенням. Використовуйте L, H, A, N.»
- Порожня висота або глибина дорівнює 0.

## Оператори

| Записується | Значення |
|---|---|
| `+` | Додати |
| `-` або `−` | Відняти або від'ємне значення |
| `*` або `×` | Помножити |
| `/` або `÷` | Поділити |
| `( )` | Групування |

Множення і ділення виконуються раніше за додавання і віднімання: `L * 2 + 4` — це (L × 2) + 4. Використовуйте дужки, якщо сумніваєтесь.

Числа можуть мати десяткову частину (`1.333`, `.5`) і степені (`1e3` = 1000). Пробіли ігноруються.

## Функції

| Функція | Результат | Приклад |
|---|---|---|
| `ceil(x)` | Округлення вгору до цілого | `ceil(67.5)` = 68 |
| `floor(x)` | Округлення вниз до цілого | `floor(67.5)` = 67 |
| `round(x)` | Округлення до найближчого цілого, половини від нуля | `round(2.5)` = 3 |
| `round(x, d)` | Округлення до d знаків після коми (від 0 до 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Найменше значення | `min(N, 10)` |
| `max(a, b, …)` | Найбільше значення | `max(1, ceil(N / 12))` |
| `abs(x)` | Значення без знака | `abs(-3)` = 3 |

`ceil` і `floor` ігнорують дрібний комп'ютерний шум округлення, тож значення, яке має бути рівно 1, ніколи не округлюється вгору до 2.

## Помилки

Формула, яку не можна прочитати або обчислити, показує свою помилку під полем, а складова не береться до сум (заголовок {{ui:Quantities}} каже «Неповно»). Повідомлення:

| Повідомлення | Виправлення |
|---|---|
| Введіть формулу, наприклад L або ceil(L / 1.333) + 1. | Формула порожня. |
| «X» тут не є виміряним значенням. Використовуйте … | Використовуйте одну зі змінних зі списку. |
| «X» тут не є функцією. Використовуйте ceil, floor, round, min, max, abs. | Використовуйте одну з цих функцій. |
| «#» не дозволено у формулі. | Видаліть цей символ (одиниці, `%`, `$` і `=` не дозволені). |
| Бракує «)». / Є «)» без відповідного «(». | Збалансуйте дужки. |
| Перед «)» бракує значення. | Щось на кшталт `max(1, )`: введіть значення. |
| Формула закінчується раніше, ніж треба. | Щось на кшталт `L *`: завершіть її. |
| Неочікуване «…». Чи бракує оператора? | Два значення поряд, як `2L`: запишіть `2 * L`. |
| ceil() приймає 1 значення. | Передайте функції потрібну кількість значень. |
| round(x, digits) потребує цілого числа знаків від 0 до 10. | Використовуйте ціле число десяткових знаків. |
| Формула ділить на нуль. | Зазвичай H дорівнює 0: задайте висоту або глибину позиції. |
| Формула не дає числа. | Результат завеликий, щоб бути числом. |
| Ця формула занадто довга (не більше 500 символів). | Скоротіть її. |

## Безпечна за задумом

Формула може виконувати лише арифметику зі змінними та функціями, наведеними вище. Вона не може запускати код або читати щось інше, тож формула у файлі проєкту, який вам надіслала інша людина, безпечна.

## Кошторис (аркуш XLSX і CSV)

Один рядок на позицію, за ним рядок на кожну складову її складу (з відступом). Далі порожній рядок і загальна сума проєкту.

| Колонка | Вміст | У XLSX |
|---|---|---|
| A Позиція | Назва позиції (жирним) або назва складової (з відступом) | Текст |
| B Тип | Лінійна, Площа, Підрахунок або Складова | Текст |
| C Одиниця | LF, m, SF, SY, m², EA або одиниця складової | Текст |
| D Кількість | Виміряна сума або результат формули | Число |
| E Відходи % | Відходи | Відсоток (0.10 = 10%) |
| F Кількість з відходами | Кількість × (1 + відходи) | Формула `D*(1+E)` |
| G Матеріал за одиницю | Ставка матеріалу | Число |
| H Праця за одиницю | Ставка праці | Число |
| I Матеріал | Розрахунковий матеріал | Формула `ROUND(F*G,2)` |
| J Праця | Розрахункова праця | Формула `ROUND(F*H,2)` |
| K Разом | Матеріал + праця | Формула `I+J` |
| L Примітки | Використана формула, помилка формули, позначки на аркушах без масштабу, площа стін, периметр | Текст |

Рядок загальної суми: `SUM` для колонок I, J і K по всіх рядках вище, а в примітках «Неповно: див. примітки вище», якщо щось не враховано.

Рядок з помилкою формули не має кількості й сум; його примітка вказує на помилку. Рядок заголовка закріплений.

У CSV ті самі колонки містять звичайні значення: Відходи % — це число відсотків (10 для 10%), а гроші подано в доларах з двома знаками після коми. Текст, який електронна таблиця може сприйняти як формулу (починається з `=`, `+`, `-` або `@`), отримує початковий `'`, щоб залишитися текстом.

## За аркушами (лише XLSX)

| Колонка | Вміст |
|---|---|
| Аркуш | Назва аркуша (з назвою PDF, якщо той не відкрито) |
| Позиція | Назва позиції |
| Кількість | Кількість цієї позиції на цьому аркуші в її одиниці |
| Одиниця | Одиниця позиції |
| Позначки | Кількість позначок |

## Позначки (лише XLSX)

Один рядок на кожну позначку.

| Колонка | Вміст |
|---|---|
| Аркуш | Назва аркуша |
| Позиція | Назва позиції |
| Тип | Лінійна, Площа або Підрахунок |
| Кількість | Довжина, чиста площа або 1 |
| Одиниця | LF або m; SF, SY або m²; EA |
| Деталі | Лінійна: довжини відрізків, відняті відрізки позначено як «(віднімання)», і «віднімає (довжина) з (довжина) накреслених». Площа: загальна та вирізна площі, коли є вирізи, і периметр. «Аркуш без масштабу» для позначок без масштабу. |
| Зона торгів | Лише коли у визначенні обсягів є зони торгів: площа позначки або «Немає зони торгів» |

## За зонами торгів (лише XLSX, коли у визначенні обсягів є зони торгів)

| Колонка | Що це |
|---|---|
| Зона торгів | Назва зони або «Немає зони торгів» |
| Позиція | Позиція або складова з відступом під нею |
| Одиниця | Одиниця позиції або складової |
| Кількість | Виміряна в цій зоні (для складових: формула за підсумками зони) |
| Кількість з відходами | Кількість × (1 + відходи) |
| Матеріал, Праця, Разом | Розраховані до копійки, як на аркуші Кошторис |
| Примітки | Формула, помилки та позначки без масштабу, як на аркуші Кошторис |

Кожна зона завершується рядком «(назва) підсумок», де суми — це формули `SUM` по її рядках. Останній рядок, **Усі зони торгів**, додає підсумки зон. Аркуш **Позначки** тоді має сьому колонку — **Зона торгів**.

## Масштаби (лише XLSX)

Один рядок на кожен аркуш, що має масштаб або позначки.

| Колонка | Вміст |
|---|---|
| Аркуш | Назва аркуша |
| Масштаб | Назва пресету, відкалібрований масштаб або «Немає масштабу» |
| Спосіб | «Пресет» або «Відкалібровано за відстанню, яку ви ввели» |
| Футів на одиницю PDF | Точний коефіцієнт масштабу, який використовує TakeoffCraft |

## Назви файлів

- `(name).xlsx` і `(name).csv`, де назва береться з першого PDF, відкритого у визначенні обсягів.
- CSV у кодуванні UTF-8 з міткою порядку байтів (BOM) і кінцями рядків Windows, які читають електронні таблиці на всіх платформах.

Տառերի ստեղները աշխատում են, երբ ցուցիչը էջի ցանկացած տեղում է և դուք դաշտում չեք մուտքագրում։ Երբ երկխոսության պատուհանը բաց է, նրա սեփական ստեղները գործում են։ Տառերը աշխատում են {{key:Shift}}-ով և առանց դրա։

## Գծելու ընթացքում

|---|---|
| Սեղմել | Տեղադրել կետ (կետ՝ {{ui:Count}}-ով)։ |
| {{key:P}} | Ուղի՝ ընտրել PDF գծի ամբողջ կապակցված ուղին, կամ սեղմած կետի շուրջ ուրվագիծը ([Ընտրել PDF-ի գծերը](topic:pick-the-lines))։ |
| {{key:F3}} | Միացնել կամ անջատել գծագրի գծերին հավասարվելը ([Հավասարեցնել գծագրի գծերին](topic:snap-to-the-drawing))։ |
| {{key:Shift}} պահած ժամանակ սեղմելիս | Հավասարեցնել հատվածը 0°, 45°, 90° կամ 135° վերջին կետից։ Աղեղի կետերի և շրջանների համար՝ ոչ։ |
| Կրկնակի սեղմում | Ավարտել շարանը, կամ փակել մակերեսը կամ անցքը։ |
| {{key:Enter}} | Ավարտել շարանը, կամ փակել մակերեսը կամ անցքը։ |
| Աջ սեղմում (առանց շարժելու) | Ավարտել շարանը, կամ փակել մակերեսը կամ անցքը։ |
| Սեղմել առաջին կետը | Փակել մակերեսը կամ անցքը (երրորդ կետից սկսած)։ |
| {{key:Backspace}} կամ {{key:Delete}} | Հեռացնել վերջին կետը (նախ սպասվող աղեղի կետը)։ |
| {{key:Esc}} | Հեռացնել սպասվող աղեղի կետը․ ապա չավարտված նշումը․ ապա վերադառնալ {{ui:Select}}-ին։ |

## Ընտրել և խմբագրել

| Ստեղն կամ գործողություն | Ինչ է անում |
|---|---|
| Սեղմել օբյեկտը ({{ui:Select}} գործիքով) | Ընտրել այն և դարձնել իր տարրը ընթացիկ։ |
| {{key:Shift}} + սեղմել օբյեկտը | Ավելացնել ընտրությանը կամ հանել այնտեղից։ |
| {{key:Mod+A}} | Ընտրել բաց թերթի բոլոր օբյեկտները։ |
| Քաշել անկյունային բռնակը | Տեղափոխել այդ կետը ({{key:Shift}}-ը հավասարեցնում է 45°-ին)։ Աշխատում է, երբ ընտրված է մեկ օբյեկտ։ |
| {{key:Delete}} կամ {{key:Backspace}} | Ջնջել ընտրված օբյեկտները (երբ չեք գծում)։ |
| {{key:Esc}} | Ոչինչ չընտրել․ մաքրել ընտրությունը և ստուգման գիծը։ |
| {{key:Mod+Z}} | Հետարկել։ |
| {{key:Mod+Y}} կամ {{key:Mod+Shift+Z}} | Կրկնել։ |

## Պատճենել և տեղադրել

| Ստեղն | Ինչ է անում |
|---|---|
| {{key:Mod+C}} | Պատճենել ընտրված օբյեկտները՝ իրենց տարրերով։ |
| {{key:Mod+X}} | Կտրել․ պատճենել ընտրված օբյեկտները, ապա ջնջել դրանք։ |
| {{key:Mod+V}} | Տեղադրել․ պատճենը հետևում է ցուցիչին, սեղմեք, թե որտեղ տեղադրել։ |
| {{key:Mod+Shift+V}} | Տեղադրել նույն տեղում՝ բաց թերթի նույն կետում։ |
| {{key:Mod+D}} | Կրկնօրինակել ընտրված օբյեկտները․ պատճենը հետևում է ցուցիչին, սեղմեք, թե որտեղ։ |
| {{key:Esc}} | Ոչինչ չդնել․ չեղարկել ցուցիչի վրա գտնվող տեղադրումը կամ կրկնօրինակումը։ |

Տառերը առանձին դեպքում դեռ ընտրում են գործիքներ ({{key:C}}՝ {{ui:Count}}, {{key:D}}՝ {{ui:Check}}, {{key:X}}՝ {{ui:Cut-out}}, {{key:V}}՝ {{ui:Select}}, {{key:A}}՝ {{ui:Area}})․ միայն {{key:Mod}}-ով դրանք պատճենում և տեղադրում են։ Տեքստային դաշտում այս ստեղները պատճենում և տեղադրում են տեքստ, ինչպես սովորաբար։ Տե՛ս [Պատճենել, տեղադրել և կրկնօրինակել օբյեկտները](topic:copy-paste)։

:::warning
{{key:Backspace}}-ը ջնջում է ընտրված օբյեկտը, երբ չեք գծում։ Եթե դա պատահաբար եղավ, {{key:Mod+Z}}-ը այն վերադարձնում է։
:::

## Հարթակի նշումներ

:::mac
- {{key:Mod}}-ը Command ստեղնն է։ Լրիվ էկրանը բացառություն է՝ Control+Shift+F։
- Աջ սեղմումը թրեքփադում երկու մատի սեղմումն է, երբ միացված է secondary click-ը System Settings-ում, Trackpad բաժնում։ TakeoffCraft-ը կարդում է միայն երկրորդական կոճակը․ Control-սեղմումը կարող է համարվել սովորական սեղմում և ավելացնել կետ։
- Երկու մատի սահեցումը թրեքփադում մասշտաբավորում է թերթը (չի սահեցնում)։ Տեղաշարժելու համար սեղմեք և քաշեք, կամ պահեք {{key:Space}}-ը և քաշեք։
- Page Up և Page Down-ը fn-ը վերև և ներքև սլաքների հետ են այն ստեղնաշարերի վրա, որոնք դրանք չունեն։
- Backspace-ը այն ստեղնն է, որը կրում է delete պիտակը։
:::

- Լաբթոփի թրեքփադում երկու մատի սահեցումը մասշտաբավորում է թերթը։ Տեղաշարժելու համար սեղմեք և քաշեք։
:::

:::linux
- {{key:Mod}}-ը Ctrl է։ Որոշ desktop-ներ ունեն իրենց Ctrl+Alt կամ Super դյուրանցումները․ TakeoffCraft-ը դրանցից ոչ մեկը չի օգտագործում։
- Թրեքփադում երկու մատի սահեցումը մասշտաբավորում է թերթը։ Տեղաշարժելու համար սեղմեք և քաշեք։
:::

:::touch
TakeoffCraft-ը հպումը կարդում է որպես մեկ ցուցիչ․

- Հպումը տեղադրում է կետ, ընտրում է օբյեկտ կամ ավելացնում քանակի կետ։
- Մեկ մատով քաշելը տեղաշարժում է թերթը ({{ui:Auto count}}-ում այն գծում է որոնման տուփը)։
- Մատների սեղմումով մասշտաբավորումը դեռ չի աջակցվում։ Օգտագործեք {{ui:Fit page}} և {{ui:Fit width}}, կամ ստեղնաշարի {{key:Plus}} և {{key:Minus}}։
- Մակերեսը փակելու համար հպեք դրա առաջին կետին։ Շարանն ավարտելու համար կրկնակի հպեք այնտեղ, որտեղ զննարկիչը կրկնակի հպումը վերածում է կրկնակի սեղմման, կամ ստեղնաշարի վրա սեղմեք {{key:Enter}}։
- Մինչև հպելը երկարության ցուցադրում չկա, քանի որ սավառնելը չկա։

Այսօր ծավալների հաշվարկի համար ավելի հարմար են ստեղնաշարը և մկնիկը կամ թրեքփադը։
:::

## Զննարկչի պահած ստեղներ

Զննարկիչները իրենց համար են պահում որոշ դյուրանցումներ, և էջը չի կարող դրանք օգտագործել․ փակել ներդիրը ({{key:Mod+W}}), նոր ներդիր կամ պատուհան ({{key:Mod+T}}, {{key:Mod+N}}) և զննարկչի մասշտաբը ({{key:Mod+Plus}}, {{key:Mod+Minus}})։ Այդ պատճառով TakeoffCraft-ը թերթը մասշտաբավորում է անիվով և առանց Mod-ի {{key:Plus}} և {{key:Minus}} ստեղներով։ Եթե սխալմամբ սեղմեք {{key:Mod+Plus}}, ամբողջ էջը կմեծանա․ {{key:Mod+0}}-ը այն վերադարձնում է։ Տե՛ս [Ստեղներ, մկնիկներ և թրեքփադներ](common:keys)։

## Որտեղ է Տեղափոխելը

Տեղափոխել հրաման չկա․ ընտրեք քանակի կետը և քաշեք այն, կամ ընտրեք մակերես կամ գիծ և քաշեք դրա անկյունային բռնակները։

TakeoffCraft-ը մշակման փուլում է։ Այս ցանկը ներկա տարբերակի չիրականացված գործառույթներն են և ինչպես կատարել աշխատանքը, այնուամենայնիվ։

## Չափում

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Կետ տեղադրել շարքի կամ ուրվագծի մեջտեղում | Ջնջեք նշումը և նորից գծեք այն։ |
| Ուղղանկյունով (պատուհանով) ընտրություն | {{key:Shift}} + սեղմեք յուրաքանչյուր նշման վրա, կամ {{key:Mod+A}}՝ թերթի բոլոր նշումների համար։ Տես [Պատճենել, տեղադրել և կրկնօրինակել նշումները](topic:copy-paste)։ |
| Տեղադրված պատճենը պտտել, հայելապատկել կամ մասշտաբավորել | Տեղադրեք թերթի վրա նույն մասշտաբով և նույն կողմնորոշմամբ. մնացածը գծեք ձեռքով։ |
| Մասշտաբը սկանավորված թերթից կամ գրաֆիկական մասշտաբի գծից կարդալ | Ընտրեք նախադրվածը, կամ չափաբերեք գծի երկարությամբ։ |
| Մեկից ավել մասշտաբ մեկ թերթի վրա (մանրամասն տարածքներ, խոշորացված հատակագծեր) | Չափեք մասը թերթի մասշտաբով, իսկ մանրամասնը հաշվեք առանձին՝ նրա խոշորացված թերթից, եթե հավաքածուն ունի այն։ |

## Տարրեր և գնագոյացում

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Հավաքման բանաձևեր, որոնք օգտագործում են տարրի նշումների այլ տեսակներ (սենյակի տարրի դռները՝ իր հարկի բանաձևերում) | Բանաձևերը օգտագործում են հիմնական տեսակի գումարները. գնագոյացրեք մյուս տեսակները առանձին տողերում։ |
| Հավաքման բանաձևեր, որոնք հաշվվում են շարքով | Բանաձևերը օգտագործում են տարրի գումարները. օգտագործեք `N` յուրաքանչյուր շարքի լրացումների համար։ |
| Բանաձևեր, որոնք օգտագործում են այլ տարրի քանակները | Կրկնեք չափումը այդ տարրում, կամ հաշվեք այն աղյուսակային արտահանման մեջ։ |
| Աշխատախմբեր հավաքման բաղադրիչների վրա, կամ 8 ժամից այլ աշխատանքային օր | Աշխատախումբը վերագրեք տարրին. այլ օրվա տևողության համար կարդացեք աշխատախումբ-օրերը՝ որպես աշխատախումբ-ժամեր ÷ ձեր օր։ |
| Նշումներ՝ բացի գրառումներից, ամպերից և ընդգծումներից (սլաքներ, չափեր, կնիքներ), կամ պատասխաններ գրառման վրա | Գրեք այն գրառման տեքստում. փոխեք դրա կարգավիճակը, երբ լուծվի։ |
| Թիմի կողմից համօգտագործվող գնային գրադարան, կամ՝ պահվող ձեր հաշվի հետ | Գրադարանը պահվում է այս դիտարկիչում. արտահանեք այն որպես CSV և ներմուծեք մյուս համակարգչում։ |
| Առևտրային փաթեթներ, որոնք վերանայված են աշխատող նախահաշվողների կողմից | Յուրաքանչյուր փաթեթ սկզբնական տարբերակ է. ստուգեք դրա ենթադրությունները ձեր աշխատանքի և ձեր ապրանքների հետ, նախքան գնագոյացնելը։ Տես [Առևտրային փաթեթներ](topic:trade-packs)։ |
| Գներ առևտրային փաթեթներում | Փաթեթները բերում են միայն հավաքումներ. սահմանեք ձեր սեփական դրույքները, կամ ներմուծեք ձեր գնացուցակը որպես CSV։ |
| Ծավալի վերանվանում | Անվանումը գալիս է առաջին PDF-ից. վերանվանեք ներբեռնված ֆայլերը։ |
| Թերթերի ձեռքով անվանում | Թերթերը անվանվում են PDF-ի էջի պիտակներից. փնտրեք ըստ ֆայլի անվան և էջի։ |

## Գծագրեր (DWG և DXF)

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Տպագրության ոճի աղյուսակներ, գրչի նշանակումներ և CTB ֆայլեր գծագրի թերթերի վրա | Գծագիրը ցուցադրվում է սևով, կամ թղթի համար մգացված իր գույներով. գծերի հաստությունը գալիս է գծագրից։ |
| Երկուական DXF-ի կամ AutoCAD 2000-ից հին DWG-ի բացում | Պահեք այն որպես ASCII DXF կամ ավելի նոր DWG։ |
| Կապված գծագրի (xref) գտնում՝ ըստ թղթապանակի, որտեղ այն գտնվում է | Բացեք նաև կապված գծագրի ֆայլը՝ հիմնական գծագրի հետ միասին. այն գտնվում է ֆայլի անվամբ՝ բաց ֆայլերի մեջ։ |
| 3D բազմագծերի, ցանցերի, ծավալային մարմինների և տիրույթների չափում | Հաշվեք դրանք ըստ շերտի և տեսակի, կամ չափեք հատակագծի տեսքը Գծային և Մակերես գործիքներով։ |
| Տեքստ նշված PDF-ում՝ գծագրից, լատինից բացի այլ գրերով | Նիշերը, որոնց համար Helvetica-ն գլիֆ չունի, նշված PDF-ում տպվում են որպես «?». Էկրանին գծագիրը անփոփոխ է։ |
| Գծագրի հանձնումը մեկ այլ ծրագրին թերթի գոտուց | Բացեք նույն ֆայլը այդ ծրագրում։ |
| Գծագիր, որը պարունակում է ծավալը, ինչպես PDF-ների դեպքում՝ {{ui:PDF՝ ներսում ծավալների հաշվարկով}} | {{ui:Պահել ծավալները}}՝ `.takeoff.json`-ը նորից բացվում է նույն գծագրի վրա, որը գտնվում է իր բովանդակությամբ։ |
| Գծագրում տեղադրված PDF ենթաշերտերի, պատկերների և OLE օբյեկտների գծում կամ հաշվում | Պատկերները ցուցադրվում են միայն շրջանակով. բացեք ենթաշերտ PDF-ը որպես թերթ։ |

## Ավտոհաշվում

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Խորհրդանիշների գտնում թերթի վրա, որի մասշտաբը նշված չէ և որը գծված է այլ չափսով | Տվեք թերթին դրա մասշտաբը, կամ փնտրեք այն այնտեղ գծված պատուհանով։ |
| Հայելապատկված խորհրդանիշների գտնում | Հաշվեք դրանք ձեռքով, կամ նորից փնտրեք հայելապատկվածի շուրջ գծված պատուհանով։ |

## Ֆայլեր և համօգտագործում

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Մեկ PDF, որը միաժամանակ ցուցադրում է նշումները և պարունակում ծավալը | {{ui:Նշված PDF}}՝ նշումները մարդկանց ցուցադրելու համար. {{ui:PDF՝ ներսում ծավալների հաշվարկով}}՝ TakeoffCraft-ում նորից բացելու համար։ |
| Քանակների CSV ըստ թերթի կամ նշումների | Օգտագործեք {{ui:XLSX}}. դրա By sheet և Marks թերթերը ունեն դրանք։ |
| Ամպում պահում | Դեռ հասանելի չէ. պահեք նախագծի ֆայլերը ձեր համակարգչում և պահուստավորեք դրանք։ |
| TakeoffCraft-ի առանձին աշխատասեղանի ծրագիր | 0.5 տարբերակից աշխատասեղանի ծրագիրը CadCraft Studio-ն է՝ բոլոր ութ ծրագրերով մեկ տեղադրմամբ։ TakeoffCraft-ը աշխատում է նաև դիտարկիչում։ |

## Էկրան և մուտքագրում

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Աջ սեղմումով (կամ երկար սեղմումով) ընտրացանկ | Օգտագործեք գործիքագոտին, վահանակները և ստեղները։ Երկար սեղմումը ավարտում է շարքը կամ ուրվագիծը։ |
| Տեսքի պտտում | PDF-ում արդեն պտտված էջերը արդեն ուղիղ են երևում։ |

## 3D տեսք

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|
| Նշումների գծում կամ խմբագրում 3D-ում | Վերադարձեք թերթին ({{key:3}}) գծելու համար. ընտրումը և ջնջումը աշխատում են 3D-ում։ |
| Իրար վրա դրված հարկերի հավասարեցում, որոնք իրենց էջերում տարբեր տեղերում են գծված | Դրեք նույն կերպ գծված հարկերը իրար վրա. մնացածը ստուգեք մեկ թերթով։ |
| Հաշվվող օբյեկտի չափով սյուների հաշվում | Թերթի յուրաքանչյուր սյուն նույն չափն ունի. այն ցույց է տալիս, թե որտեղ է հաշվարկը, և ոչ թե ինչն է այն։ |

## Հայտեր

| Դեռ չկառուցված | Փոխարենը, այսօր |
|---|---|

## Աղյուսակային ծրագրեր

XLSX գիրքը ստուգվել է LibreOffice Calc-ում, որը հաշվարկել է յուրաքանչյուր գումար նույն սենտի ճշտությամբ, ինչ TakeoffCraft-ը։ Այն դեռ չի բացվել Excel-ում։ Եթե աղյուսակային ծրագիրը ցույց է տալիս անսպասելի բան, CSV արտահանումը պարունակում է նույն նախահաշիվը որպես պարզ արժեքներ։

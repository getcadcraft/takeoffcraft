**Գնային գրադարանը** պահում է տարրեր, որոնք օգտագործում եք աշխատանքից աշխատանք. դրանց տեսակը, չափման միավորը, բարձրությունը, թափոնը, նյութի և աշխատանքի դրույքները և դրանց հավաքումը։ Այն պահվում է այս դիտարկիչում, առանձին ցանկացած ծավալից, այնպես որ այստեղ բացած յուրաքանչյուր ծավալ կարող է օգտագործել այն։

Բացեք այն {{ui:Գրադարան}}-ով՝ {{ui:Տարրեր}} վահանակի վերևում։

## Լրացնել գրադարանը

- {{ui:Ներմուծել CSV…}}-ը կարդում է CSV-ով պահված աղյուսակ (տես ստորև սյունակները)։ Այն տարրերը, որոնց անունն ու տեսակը արդեն գրադարանում են, փոխարինվում են. մնացածը ավելացվում են։ Չկարդացվող տողերը բաց են թողնվում, և ասվում է, թե որոնք և ինչու։
- {{ui:Ավելացնել այս ծավալի տարրերը}}-ը պատճենում է բաց ծավալի յուրաքանչյուր տարր գրադարան՝ իր դրույքներով և հավաքումով (ոչ նշումներով)։
- TakeoffCraft-ի արտահանած նախահաշվի CSV-ը ([Արտահանել նախահաշիվը](topic:export-estimate)) ներմուծվում է այնպես, ինչպես կա. վերջին աշխատանքի գները սկիզբ են դնում հաջորդին։

- {{ui:Առևտրային փաթեթներ…}}-ն ավելացնում է անվճար հավաքումներ որևէ արհեստի համար, օրինակ՝ գիպսատախտակ (drywall), էլեկտրական կամ բետոն, առանց գների։ Տես [Առևտրային փաթեթներ](topic:trade-packs)։

{{ui:Արտահանել CSV}}-ն պահում է գրադարանը որպես CSV՝ պատճենը պահելու, աղյուսակում խմբագրելու կամ գործընկերոջը տալու համար. {{ui:Մաքրել}}-ը դատարկում է այն (սեղմեք երկու անգամ)։

:::note
Գրադարանը պահվում է այս դիտարկիչի պահոցում. մեկ այլ դիտարկիչ, մեկ այլ համակարգիչ կամ գաղտնի պատուհանը ունեն իրենը (կամ ոչ մի)։ Արտահանեք այն՝ տեղափոխելու համար։
:::

## Օգտագործել ծավալի մեջ

- Նշեք տարրերը ({{ui:Փնտրել գրադարանում}}-ում գրեք՝ ցանկը նեղացնելու համար) և ընտրեք {{ui:Ավելացնել ծավալին}}։ Դրանք ավելանում են իրենց հավաքումներով մեկ քայլով, որը {{key:Mod+Z}}-ը հետ է վերցնում։ Ծավալում արդեն եղած անունը ստանում է համար, օրինակ՝ `Carpet (2)`։
- {{ui:Թարմացնել գները}}-ը ծավալի տարրերին տալիս է գրադարանի թափոնն ու դրույքները՝ յուրաքանչյուր տարրի համար, որի անունն ու տեսակը համընկնում են գրադարանի տարրի հետ, և նույնը՝ նույն անվամբ հավաքման բաղադրիչների համար։ Բարձրությունները, չափման միավորները և բանաձևերը մնում են նույնը։ Մեկ {{key:Mod+Z}}-ով բոլոր հին գները վերադառնում են։

## CSV սյունակները

Առաջին տողը անվանում է սյունակները, ցանկացած հերթականությամբ. մյուս սյունակները անտեսվում են։

| Սյունակ | Ինչ է գրվում դրանում |
|---|---|
| Item (կամ Name) | Տարրի անունը։ Պարտադիր է։ |
| Type | Linear, Area կամ Count (LF, SF և EA նույնպես աշխատում են)։ Դատարկ թողնելու դեպքում որոշում է միավորը։ |
| Unit | LF կամ m; SF, SY կամ m²; EA։ Դատարկ՝ տեսակի սովորական միավորը։ |
| Waste % | `10` կամ `10%`։ |
| Material per unit, Labor per unit | Դրույքներ, օրինակ՝ `2.10` կամ `$1,250`։ |
| Height (կամ Depth) | `9'-0"`, `9`, կամ `2.7` մետրային միավորների համար։ |
| Component, Formula | Տող՝ Component անվամբ (կամ Type `Component`-ով), մաս է իրմից վերևի տարրի հավաքման։ Դրա Unit, Waste և դրույքները իրենցն են. դրա Formula-ն օգտագործում է տարրի տառերը, տես [Հավաքումներ և բանաձևեր](topic:assemblies)։ |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

Ստորակետերը, կիսակետերը կամ տաբուլյացիաները սյունակների միջև բոլորն աշխատում են։

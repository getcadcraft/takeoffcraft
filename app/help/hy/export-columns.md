## Estimate (XLSX աշխատաթերթ և CSV)

Մեկ տող յուրաքանչյուր տարրի համար, որին հաջորդում է տող յուրաքանչյուր բաղադրիչի համար՝ նրա հավաքածուից (տեղաշարժված)։ Ապա դատարկ տող և ընդհանուր գումարը։

| Սյունակ | Բովանդակություն | XLSX-ում |
|---|---|---|
| A Item | Տարրի անուն (թավ) կամ բաղադրիչի անուն (տեղաշարժված) | Տեքստ |
| B Type | Գծային, Մակերեսային, Հաշվվող կամ Բաղադրիչ | Տեքստ |
| C Unit | LF, m, SF, SY, m², EA կամ բաղադրիչի միավորը | Տեքստ |
| D Quantity | Չափված ընդհանուր կամ բանաձևի արդյունք | Թիվ |
| E Waste % | Թափոն | Տոկոս (0.10 = 10%) |
| F Qty with waste | Քանակ × (1 + թափոն) | Բանաձև `D*(1+E)` |
| G Material per unit | Նյութի գին | Թիվ |
| H Labor per unit | Աշխատանքի գին | Թիվ |
| I Material | Ընդլայնված նյութ | Բանաձև `ROUND(F*G,2)` |
| J Labor | Ընդլայնված աշխատանք | Բանաձև `ROUND(F*H,2)` |
| K Total | Նյութ + աշխատանք | Բանաձև `I+J` |
| L Notes | Օգտագործված բանաձև, բանաձևի սխալ, նշումներ առանց մասշտաբի թերթերի վրա, պատի մակերես, պարագիծ | Տեքստ |

Ընդհանուր գումարի տող՝ `SUM` I, J և K սյուների վրա վերևի բոլոր տողերի համար, և Notes-ում՝ «Թերի է․ տես վերևի նշումները», երբ ինչ-որ բան բաց է թողնված։

Բանաձևի սխալ ունեցող տողը չունի քանակ կամ գումարներ․ նրա նշումն ասում է սխալը։ Վերնագրի տողը ամրացված է։

CSV-ում նույն սյուները պարունակում են պարզ արժեքներ, Waste %-ը տոկոսի թիվ է (10՝ 10%-ի համար), իսկ գումարները՝ դոլարներով՝ երկու տասնորդական նշանով։ Տեքստը, որը աղյուսակը կարող է ընդունել որպես բանաձև (սկսվում է `=`, `+`, `-` կամ `@`), ստանում է առաջատար `'`, որպեսզի մնա տեքստ։

## Ըստ թերթի (միայն XLSX)

| Սյունակ | Բովանդակություն |
|---|---|
| Sheet | Թերթի անունը (PDF անունով, երբ այն բաց չէ) |
| Item | Տարրի անունը |
| Quantity | Տարրի քանակը այդ թերթում, իր միավորով |
| Unit | Տարրի միավորը |
| Marks | Նշանների քանակը |

## Նշաններ (միայն XLSX)

Յուրաքանչյուր նշանի համար՝ մեկ տող։

| Սյունակ | Բովանդակություն |
|---|---|
| Sheet | Թերթի անունը |
| Item | Տարրի անունը |
| Type | Գծային, Մակերեսային կամ Հաշվվող |
| Quantity | Երկարություն, զուտ մակերես կամ 1 |
| Unit | LF կամ m; SF, SY կամ m²; EA |
| Detail | Գծային՝ հատվածների երկարությունները, հանված հատվածները նշված «(deduct)»-ով, և «deducts (երկարություն) of (երկարություն) drawn»։ Մակերեսային՝ համախառն և կտրված մակերեսները, երբ կան կտրվածքներ, և պարագիծը։ «Թերթը մասշտաբ չունի»՝ մասշտաբ չունեցող նշանների համար։ |
| Bid area | Միայն այն դեպքում, երբ ծավալն ունի հայտի տարածքներ՝ նշանի մակերեսը կամ «Հայտի տարածք չկա» |

## Ըստ հայտի տարածքի (միայն XLSX, երբ ծավալն ունի հայտի տարածքներ)

| Սյունակ | Բովանդակություն |
|---|---|
| Bid area | Տարածքի անունը կամ «Հայտի տարածք չկա» |
| Item | Տարրը, կամ նրա տակ տեղաշարժված բաղադրիչը |
| Unit | Տարրի կամ բաղադրիչի միավորը |
| Quantity | Չափված այդ տարածքում (բաղադրիչներ՝ տարածքի գումարների բանաձևը) |
| Qty with waste | Քանակ × (1 + թափոն) |
| Material, Labor, Total | Հաշված մինչև սենտը, ինչպես Estimate-ում |
| Notes | Բանաձև, սխալներ և մասշտաբ չունեցող նշաններ, ինչպես Estimate-ում |

Յուրաքանչյուր տարածք ավարտվում է «(name) subtotal» տողով, որի գները `SUM` բանաձևեր են նրա տողերի վրա։ Վերջին տողը՝ **All bid areas**, գումարում է ենթագումարները։ **Marks** աշխատաթերթն այնուհետև ունի յոթերորդ սյունակ՝ **Bid area**։

## Մասշտաբներ (միայն XLSX)

Յուրաքանչյուր թերթի համար, որն ունի մասշտաբ կամ նշաններ՝ մեկ տող։

| Սյունակ | Բովանդակություն |
|---|---|
| Sheet | Թերթի անունը |
| Scale | Նախադրված մասշտաբի անունը, կալիբրացված մասշտաբը կամ «No scale» |
| How | «Preset», կամ «Calibrated on (the distance you typed)» |
| Feet per PDF unit | Ճշգրիտ մասշտաբային գործակիցը, որ օգտագործում է TakeoffCraft-ը |

## Ֆայլերի անուններ

- `(name).xlsx` և `(name).csv`, որտեղ անունը գալիս է ծավալում բացված առաջին PDF-ից։
- CSV-ն UTF-8 է՝ բայթերի կարգի նշանով (byte order mark) և Windows տողերի ավարտերով, որոնք կարդում են աղյուսակային ծրագրերը բոլոր պլատֆորմներում։

Հավաքածուի բաղադրիչները քանակ են ստանում բանաձևից։ Բանաձևը պարզ թվաբանական արտահայտություն է տարրի չափված արժեքների վրա։ Աշխատված օրինակների համար տես [Հավաքածուներ և բանաձևեր](topic:assemblies)։

## Փոփոխականներ

| Տարրի տեսակ | Փոփոխական | Իմաստ |
|---|---|---|
| Գծային | `L` | Ընդհանուր երկարություն |
| Գծային | `H` | Տարրի բարձրությունը |
| Գծային | `A` | Պատի մակերես՝ L × H, հանած այն բացվածքները, որոնք ունեն վազքերը (ծավալ BimCraft-ից)։ Երբ այդ ծավալն անվանում է չափման եղանակ, `A`-ն չափվում է դրանով․ այն բացվածքները, որոնք չեն գերազանցում եղանակի ամենափոքր չափը, մնում են ներսում, իսկ այն, ինչ եղանակը հանում է պատերի միացման վայրերում, բաց է թողնվում։ Տարրի տակ գտնվող նշումն անվանում է եղանակը։ |
| Գծային | `N` | Վազքերի քանակը |
| Մակերեսային | `A` | Ընդհանուր զուտ մակերես (ուրվագծեր՝ հանած կտրվածքները) |
| Մակերեսային | `P` | Ընդհանուր պարագիծ, ներառյալ կտրվածքների եզրերը |
| Մակերեսային | `H` | Տարրի խորությունը կամ հաստությունը |
| Մակերեսային | `N` | Մակերեսների քանակը |
| Հաշվվող | `N` | Հաշվվող քանակը |

- Փոփոխականները տարրի միավորներով են․ տես [Միավորներ](topic:units)։
- Մեծ և փոքր տառերը նույնն են․ `l`-ը նույնն է, ինչ `L`-ը։
- Աշխատում են միայն տարրի սեփական տեսակի փոփոխականները։ Գծային տարրի վրա `P`-ն տալիս է՝ «"P" այստեղ չափված արժեք չէ։ Օգտագործեք L, H, A, N։»
- Դատարկ բարձրությունը կամ խորությունը 0 է։

## Գործողություններ

| Գրել | Իմաստ |
|---|---|
| `+` | Գումարել |
| `-` կամ `−` | Հանել, կամ բացասական արժեք |
| `*` կամ `×` | Բազմապատկել |
| `/` կամ `÷` | Բաժանել |
| `( )` | Խմբավորել |

Բազմապատկումը և բաժանումը նախ են գալիս գումարումից և հանումից․ `L * 2 + 4`-ը (L × 2) + 4 է։ Կասկածի դեպքում օգտագործեք փակագծեր։

Թվերը կարող են ունենալ տասնորդական մասեր (`1.333`, `.5`) և աստիճաններ (`1e3` = 1000)։ Բացատները անտեսվում են։

## Ֆունկցիաներ

| Ֆունկցիա | Արդյունք | Օրինակ |
|---|---|---|
| `ceil(x)` | Կլորացնել դեպի վերև՝ ամբողջ թվի | `ceil(67.5)` = 68 |
| `floor(x)` | Կլորացնել դեպի ներքև՝ ամբողջ թվի | `floor(67.5)` = 67 |
| `round(x)` | Կլորացնել մոտակա ամբողջ թվին, կեսերը՝ զրոյից հեռու | `round(2.5)` = 3 |
| `round(x, d)` | Կլորացնել d տասնորդական նշանի (0-ից 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Ամենափոքր արժեքը | `min(N, 10)` |
| `max(a, b, …)` | Ամենամեծ արժեքը | `max(1, ceil(N / 12))` |
| `abs(x)` | Արժեքը՝ առանց նշանի | `abs(-3)` = 3 |

`ceil`-ը և `floor`-ը անտեսում են համակարգչի կլորացման աննշան աղմուկը, ուստի այն արժեքը, որը պետք է ճիշտ 1 լինի, երբեք չի կլորացվի դեպի 2։

## Սխալներ

Բանաձևը, որը չի կարող կարդալ կամ հաշվել, ցույց է տալիս իր սխալը դաշտի տակ, և բաղադրիչը դուրս է մնում գումարներից ({{ui:Quantities}} վերնագիրը ասում է «Incomplete»)։ Հաղորդագրությունները՝

| Հաղորդագրություն | Ուղղում |
|---|---|
| «Մուտքագրեք բանաձև, օրինակ՝ L կամ ceil(L / 1.333) + 1։» | Բանաձևը դատարկ է։ |
| «"X" այստեղ չափված արժեք չէ։ Օգտագործեք …» | Օգտագործեք թվարկված փոփոխականներից մեկը։ |
| «"X" այստեղ ֆունկցիա չէ։ Օգտագործեք ceil, floor, round, min, max, abs։» | Օգտագործեք այդ ֆունկցիաներից մեկը։ |
| «"#" բանաձևում թույլատրելի չէ։» | Հեռացրեք այդ նիշը (միավորները, `%`, `$` և `=` թույլատրելի չեն)։ |
| «Բացակայում է ")"։» / «Կա ")", առանց իր "("-ի։» | Հավասարեցրեք փակագծերը։ |
| «")"-ից առաջ արժեք բացակայում է։» | Օրինակ՝ `max(1, )`. լրացրեք արժեքը։ |
| «Բանաձևն ավարտվում է շատ շուտ։» | Օրինակ՝ `L *`. ավարտեք այն։ |
| «Անսպասելի "…"։ Գործողություն բացակայո՞ւմ է։» | Երկու արժեք կողք կողքի, օրինակ՝ `2L`. գրեք `2 * L`։ |
| «ceil()-ը վերցնում է 1 արժեք։» | Տվեք ֆունկցիային արժեքների ճիշտ քանակ։ |
| «round(x, digits)-ը պահանջում է ամբողջ նիշեր 0-ից 10։» | Օգտագործեք տասնորդական նշանների ամբողջ քանակ։ |
| «Բանաձևը բաժանում է զրոյի վրա։» | Սովորաբար H-ը 0 է. սահմանեք տարրի բարձրությունը կամ խորությունը։ |
| «Բանաձևը թիվ չի տալիս։» | Արդյունքը շատ մեծ է թիվ լինելու համար։ |
| «Այդ բանաձևը շատ երկար է (առավելագույնը 500 նիշ)։» | Կրճատեք այն։ |

## Ապահով է ըստ դիզայնի

Բանաձևը կարող է կատարել միայն թվաբանություն վերը նշված փոփոխականներով և ֆունկցիաներով։ Այն չի կարող գործարկել կոդ կամ կարդալ որևէ այլ բան, ուստի ձեզ ուղարկված նախագծային ֆայլի բանաձևը անվնաս է։

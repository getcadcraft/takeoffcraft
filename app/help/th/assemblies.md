**ชุดงานต้นทุน** ของรายการคือรายการองค์ประกอบ โดยแต่ละองค์ประกอบมีสูตรปริมาณ ความสูญเสีย และราคาต่อหน่วยของตัวเอง สูตรใช้ค่ารวมที่วัดได้ของรายการ ดังนั้นการนับผนังเพียงครั้งเดียวจะได้ทั้งสตัด แผ่นรอง และแผ่นวัสดุพร้อมกัน และค่าจะปรับตามการวัดที่เปลี่ยนไป

## ตัวแปรที่ใช้ได้

| ประเภทรายการ | ตัวแปร |
|---|---|
| เส้นตรง | `L` ความยาว, `H` ความสูง, `A` พื้นที่ผนัง (L × H), `N` จำนวนช่วงเส้น |
| พื้นที่ | `A` พื้นที่, `P` เส้นรอบรูป (เส้นขอบ + ช่องตัด), `H` ความลึกหรือความหนา, `N` จำนวนพื้นที่ |
| จำนวน | `N` จำนวน |

ค่าใช้หน่วยของรายการเอง: ฟุตและตารางฟุตสำหรับรายการ LF และ SF เมตรและตารางเมตรสำหรับรายการ m และ m² สำหรับรายการ SY ค่า `A` เป็นตารางหลา ส่วน `P` และ `H` ยังเป็นฟุต

สูตรใช้ `+ - * /` (หรือ × ÷) วงเล็บ ตัวเลข และฟังก์ชัน `ceil`, `floor`, `round`, `min`, `max` และ `abs` กฎทั้งหมดอยู่ใน [ภาษาของสูตร](topic:formulas)

## ตัวอย่าง: ผนังภายใน

สมมติว่านับ **ผนังภายในประเภท A** เป็นรายการเส้นตรง มี 4 ช่วงรวม 120 LF โดยตั้ง {{ui:ความสูง}} เป็น `9'-0"` ค่า **ที่วัดได้** คือ L = 120, N = 4, A = 1,080 (SF ของผนัง ด้านเดียว)

1. เลือกรายการภายใต้ {{ui:รายการ}}
2. ใน {{ui:ชุดงานต้นทุน}} เลือก {{ui:เพิ่มองค์ประกอบ}}
   องค์ประกอบชื่อ "Component" จะปรากฏ พร้อมสูตร `L` และผลลัพธ์ด้านล่าง
3. พิมพ์ `Studs 16 in o.c.` ใน {{ui:ชื่อ}} และ `EA` ใน {{ui:หน่วย}}
4. ใน {{ui:สูตรปริมาณ}} พิมพ์ `ceil(L * 12 / 16) + N`
   ผลลัพธ์จะอัปเดตขณะพิมพ์: "= 94 EA" คือหนึ่งสตัดทุก 16 นิ้วตามความยาว 120 ฟุต (90) บวกอีกหนึ่งตัวเพื่อปิดปลายแต่ละช่วงทั้ง 4 ช่วง
5. เลือก {{ui:เพิ่มองค์ประกอบ}} อีกครั้งสำหรับแผ่นรอง ตั้งชื่อ `Plates, top and bottom`, หน่วย `LF`, สูตร `L * 2` ผลลัพธ์: 240 LF
6. เพิ่มแผ่นวัสดุ: ชื่อ `Gypsum board 4x8, both sides`, หน่วย `sheets`, สูตร `ceil(A * 2 / 32)` ผลลัพธ์: 68 แผ่น (พื้นที่แผ่นยิปซัม 2,160 SF ÷ 32 SF ต่อแผ่น = 67.5 ปัดขึ้น)
7. กรอก {{ui:ความสูญเสีย %}}, {{ui:วัสดุ $}} และ {{ui:ค่าแรง $}} ของแต่ละองค์ประกอบ
   แต่ละองค์ประกอบจะได้แถวของตัวเองใต้รายการใน {{ui:ปริมาณ}} คิดราคาเหมือนรายการ และ {{ui:ยอดรวมงาน}} รวมด้วย

หากต้นทุนผนังอยู่ในองค์ประกอบทั้งหมด ให้ตั้งอัตราวัสดุและค่าแรงของรายการเองเป็น 0 ไม่เช่นนั้นจะนับซ้ำสองครั้ง

:::tip
ความสูญเสียใช้หลังสูตรและไม่ปัดเศษ: 68 แผ่นที่มีความสูญเสีย 10% เท่ากับ 74.8 แผ่น หากต้องการสั่งเป็นแผ่นเต็ม ให้ใส่ความสูญเสียในสูตร เช่น `ceil(A * 2 / 32 * 1.1)` และตั้งความสูญเสียขององค์ประกอบเป็น 0
:::

## สูตรเพิ่มเติม

| สิ่งที่ต้องการ | รายการ | สูตร |
|---|---|---|
| สตัดระยะ 24 นิ้วจากศูนย์กลาง | เส้นตรง | `ceil(L / 2) + N` |
| แผ่นฉนวน SF | เส้นตรงที่มีความสูง | `A` |
| สีสองด้าน เป็นแกลลอนที่ 350 SF | เส้นตรงที่มีความสูง | `ceil(A * 2 / 350)` |
| กล่องกระเบื้อง 15 SF เผื่อ 10% | พื้นที่ | `ceil(A * 1.1 / 15)` |
| บัวเชิงผนังหรือไม้ขอบ LF | พื้นที่ | `P` |
| คอนกรีต ลูกบาศก์หลา | พื้นที่ที่มีความลึก | `A * H / 27` |
| คอนกรีต ปัดขึ้นเป็นหนึ่งในสี่ลูกบาศก์หลา | พื้นที่ที่มีความลึก | `ceil(A * H / 27 * 4) / 4` |
| บานพับ 3 ตัวต่อประตู | จำนวน | `N * 3` |
| อย่างน้อยหนึ่งกล่อง หนึ่งกล่องต่อ 12 | จำนวน | `max(1, ceil(N / 12))` |

## เมื่อสูตรผิด

บรรทัดใต้สูตรจะกลายเป็นข้อความผิดพลาด เช่น `"X" is not a measured value here. Use L, H, A, N.` หรือ `A ")" is missing.` องค์ประกอบนั้นจึงไม่มีจำนวนเงิน แถวใน {{ui:ปริมาณ}} จะแสดง "ข้อผิดพลาดของสูตร: …" และส่วนหัวจะขึ้นว่า "ยังไม่สมบูรณ์: มีข้อผิดพลาดของสูตร 1 รายการ (ไม่รวมในยอดรวม)" แก้สูตรแล้วยอดรวมจะอัปเดต

สูตรที่หารด้วยศูนย์ก็เป็นข้อผิดพลาดเช่นกัน ("The formula divides by zero." › "สูตรหารด้วยศูนย์") เช่น `A / H` กับรายการที่ไม่มีความลึก

## ข้อจำกัด

- สูตรทำงานกับ**ค่ารวม**ของรายการ ไม่ใช่ทีละช่วง `ceil(L * 12 / 16) + N` เพิ่มสตัดหนึ่งตัวต่อช่วง แต่ยังไม่มีการปัดเศษต่อช่วง
- สูตรใช้ตัวแปรของรายการเดียวกันเท่านั้น ใช้ตัวแปรของรายการอื่นไม่ได้
- ไม่เกิน 50 องค์ประกอบต่อรายการ และไม่เกิน 500 อักขระต่อสูตร

TakeoffCraft อธิบายการปฏิเสธส่วนใหญ่ในแถบสถานะด้านล่างของหน้าต่าง ค้นหาข้อความด้านล่าง

## การเปิดไฟล์

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ตัวอ่าน PDF โหลดไม่ได้ โหลดหน้าใหม่เพื่อลองอีกครั้ง | ตัวอ่าน PDF ของแอปโหลดไม่ขึ้น มักเป็นเพราะคุณออฟไลน์และแอปไม่เคยถูกบันทึกเพื่อใช้ออฟไลน์ | เชื่อมต่ออินเทอร์เน็ตแล้วโหลดใหม่ จากนั้นเลือก {{ui:Save for offline}} และรอจนกว่าจะขึ้น {{ui:Offline ready}}; ดู [ทำงานแบบออฟไลน์](common:offline) |
| (name) มีรหัสผ่าน เปิดสำเนาที่ไม่มีการป้องกัน | PDF ต้องใช้รหัสผ่านในการเปิด | ขอสำเนาที่ไม่มีการป้องกัน หรือลบรหัสผ่านในโปรแกรม PDF ที่คุณเชื่อถือ |
| (name) อ่านเป็น PDF ไม่ได้ (…) | ไฟล์เสียหายหรือไม่ใช่ PDF จริง | ดาวน์โหลดใหม่ หรือบันทึกใหม่จากโปรแกรมที่สร้างไฟล์ |
| (name) เปิดอยู่แล้ว | PDF เดียวกัน (เนื้อหาเหมือนกัน) เปิดอยู่ | ไม่ต้องทำอะไร |
| TakeoffCraft เปิดได้เฉพาะ PDF และโปรเจกต์ .takeoff.json ข้ามไป: … | ไฟล์ชนิดอื่นถูกข้ามไป | แปลงแบบเป็น PDF ก่อน |
| ไม่มีอะไรเกิดขึ้นเมื่อฉันวางไฟล์ | ไฟล์ถูกวางนอกหน้าต่างเบราว์เซอร์ หรือเบราว์เซอร์เปิด PDF ในแท็บใหม่ | วางลงบนหน้า TakeoffCraft เอง กรอบ "วาง PDF หรือ .takeoff.json" จะแสดงว่าจะใช้ได้เมื่อใด |
| การเปิดชุดแบบขนาดใหญ่ใช้เวลานาน | ทุก PDF ถูกอ่านทั้งไฟล์เพื่อสร้างลายนิ้วมือ | รอจนข้อความ "กำลังเปิด (name)…" หายไป ภาพย่อจะค่อยๆ ปรากฏเมื่อคุณเลื่อน |

## การวัด

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เปิด PDF ก่อน | ยังไม่ได้เปิดแผ่น | เปิด PDF |
| แผ่นนี้ยังไม่มีมาตราส่วน จึงวัดไม่ได้ เลือกค่าที่ตั้งไว้ของมาตราส่วนหรือปรับเทียบก่อน (การนับทำได้โดยไม่ต้องมี) | เครื่องมือเส้น พื้นที่ วงกลม และช่องตัดต้องใช้มาตราส่วน | [ตั้งมาตราส่วน](topic:set-the-scale) |
| สร้างรายการเส้นก่อน (ตั้งชื่อใต้ {{ui:Items}}) แล้วคลิกบนแผ่น | ไม่มีรายการชนิดนั้น | กรอกฟอร์ม {{ui:New item}} ที่เปิดขึ้น แล้วเลือก {{ui:Add}} |
| เลือกรายการที่จะถอดปริมาณก่อน (พาเนลรายการ) | รายการปัจจุบันถูกลบ | คลิกรายการใต้ {{ui:Items}} |
| เส้นต้องมีอย่างน้อยสองจุด | คุณเสร็จหลังคลิกเพียงครั้งเดียว | คลิกอย่างน้อยสองจุด |
| พื้นที่ต้องมีอย่างน้อยสามจุด | มุมมีน้อยเกินไป | คลิกอย่างน้อยสามมุม |
| เส้นรอบรูปตัดกับตัวเอง ทำให้พื้นที่ผิด วาดใหม่โดยไม่ให้ตัดกัน | รูปเลขแปด | วาดเป็นสองพื้นที่ หรือลากรอบขอบตามลำดับ |
| จุดเหล่านั้นไม่ล้อมพื้นที่ใด | ทุกจุดอยู่บนเส้นเดียวกัน | คลิกมุมที่ล้อมพื้นที่ได้ |
| เลือกเครื่องหมายพื้นที่ก่อน (เครื่องมือเลือก) แล้วเลือก {{ui:Cut-out}} และวาดรูไว้ข้างใน | {{ui:Cut-out}} ต้องการพื้นที่ที่เลือก | กด {{key:V}} คลิกพื้นที่ แล้วกด {{key:X}} |
| ช่องตัดต้องอยู่ภายในพื้นที่ทั้งหมด | รูตัดหรือออกนอกเส้นรอบรูป | วาดรูไว้ภายในพื้นที่ |
| ช่องตัดซ้อนทับกันไม่ได้ | รูสองรูซ้อนกัน | วาดรูเดียวล้อมทั้งสองรู หรือเว้นระยะให้ห่างกัน |
| … จุดถูกย้ายกลับ | มุมที่ลากจะทำให้เส้นรอบรูปตัดกันเอง หรือดันรูออกนอกพื้นที่ | ลากไปยังตำแหน่งที่ทำให้รูปร่างถูกต้อง |
| คลิกจุดบนขอบวงกลม ห่างจากจุดศูนย์กลาง | การคลิกที่สองใกล้จุดศูนย์กลางเกินไป | คลิกให้ไกลออกไป |
| การคลิกเลื่อนแผ่นแทนการเพิ่มจุด | ตัวชี้เคลื่อนมากกว่าไม่กี่พิกเซลขณะกดปุ่ม ซึ่งนับเป็นการลาก | คลิกโดยไม่เคลื่อนที่ โดยเฉพาะบนแทร็กแพด |
| Shift ไม่สแนป | คุณกำลังวางจุดบนส่วนโค้ง หรือกำลังวาดวงกลม | สแนป 45° ใช้กับส่วนของเส้นตรงเท่านั้น |
| จุดกระโดดไปยังเส้นใกล้เคียง | เปิด [สแนปไปยังเส้นของแบบ](topic:snap-to-the-drawing) อยู่ | ซูมเข้าเพื่อคลิกระหว่างเส้น หรือกด {{key:F3}} เพื่อปิดสแนป |
| ไม่มีเครื่องหมายสแนปปรากฏ | สแนปปิดอยู่ แผ่นเป็นภาพสแกน หรือเครื่องมือไม่สแนป (นับ, นับอัตโนมัติ, การวาง) | กด {{key:F3}}; บนภาพสแกนไม่มีเส้นให้สแนป |
| ความยาวผิด | มาตราส่วนผิด (มักเป็น PDF ที่ปรับขนาดและใช้ค่าที่ตั้งไว้) | ใช้ {{ui:Check}} กับไดเมนชันที่รู้ค่า แล้วใช้ {{ui:Calibrate}} |

## มาตราส่วน

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เลือกจุดสองจุดที่ห่างกันมากขึ้น | จุดปรับเทียบเกือบซ้อนทับกัน | ปรับเทียบบนไดเมนชันที่ยาวกว่า |
| ข้อความในกล่องโต้ตอบปรับเทียบ เช่น "ไม่สามารถอ่านระยะทางนั้นได้" | ระยะอยู่ในรูปแบบที่ TakeoffCraft อ่านไม่ได้ | ดู [การป้อนความยาว อัตรา และเปอร์เซ็นต์](topic:entry-formats) |
| แผ่นนี้ยังไม่มีมาตราส่วน จึงไม่มีอะไรให้ตรวจ ปรับเทียบ หรือเลือกค่าที่ตั้งไว้ | {{ui:Check}} บนแผ่นที่ไม่มีมาตราส่วน | ตั้งมาตราส่วนก่อน |
| รายการ {{ui:Preset}} เป็นสีเทา | ยังไม่ได้เปิดแผ่น | เปิด PDF |

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ไม่สมบูรณ์: … (ไม่รวมในยอดรวม) | ข้อผิดพลาดของสูตร หรือเครื่องหมายบนแผ่นที่ไม่มีมาตราส่วน | ดู [อ่านปริมาณและประมาณราคา](topic:read-quantities#the-incomplete-warning) |
| +(n) ไม่มีมาตราส่วน ถัดจากรายการ | บางเครื่องหมายอยู่บนแผ่นที่ไม่มีมาตราส่วน | ตั้งมาตราส่วนให้แผ่นเหล่านั้น |
| ข้อผิดพลาดของสูตร: … | คำนวณสูตรไม่ได้ | ดู [ภาษาสูตร](topic:formulas#errors) |
| รายการนี้มีเครื่องหมาย จึงเปลี่ยนชนิดไม่ได้ | ชนิดจะถูกล็อกเมื่อมีเครื่องหมาย | สร้างรายการใหม่ของอีกชนิดหนึ่ง และวาดเครื่องหมายใหม่ด้วยรายการนั้น |
| รายการต้องมีชื่อ | ช่องชื่อถูกล้าง | พิมพ์ชื่อ |
| พิมพ์จำนวนเงิน เช่น 12.50 / พิมพ์เปอร์เซ็นต์ เช่น 10 หรือ 7.5 | อ่านอัตราหรือความสูญเสียไม่ได้ | ดู [การป้อนความยาว อัตรา และเปอร์เซ็นต์](topic:entry-formats) |
| ยอดรวมดูเหมือนเป็นสองเท่า | รายการมีอัตราของตัวเองและส่วนประกอบที่มีต้นทุนเดียวกัน | ตั้งอัตราของรายการเป็น 0 เมื่อส่วนประกอบมีต้นทุนอยู่แล้ว |
| เครื่องหมายของรายการนี้อยู่บน PDF ที่ยังไม่ได้เปิด | คุณคลิกรายการที่เครื่องหมายทั้งหมดอยู่บน PDF ที่ยังไม่ได้เปิด | เปิด PDF เหล่านั้น ชื่อของ PDF จะแสดงใต้ {{ui:Sheets}} |

## นับอัตโนมัติ

|---|---|---|
| กรอบนั้นเล็กเกินไป วาดรอบสัญลักษณ์ทั้งหมด | กรอบมีขนาดเล็กมาก | ซูมเข้าและวาดกรอบรอบสัญลักษณ์ทั้งหมด |
| กรอบนั้นแทบว่าง วาดรอบสัญลักษณ์ | กรอบมีแต่กระดาษ | วาดกรอบรอบสัญลักษณ์เอง |
| ไม่มีรายการที่ตรงกัน ลดแถบ {{ui:Match}} หรือวาดกรอบรอบสัญลักษณ์ให้แน่นขึ้น | ไม่มีอะไรได้คะแนนสูงพอ | วาดกรอบรอบสัญลักษณ์ให้แน่น หรือลากแถบ {{ui:Match}} ลงต่ำลง |

| การค้นหาล้มเหลว: … | การค้นหาเบื้องหลังหยุดลง | ลองอีกครั้ง; โหลดหน้าใหม่หากเกิดซ้ำ (บันทึกก่อน) เมื่อออฟไลน์ จะทำงานได้เฉพาะเมื่อแถบแอปแสดง {{ui:Offline ready}} |
| การลากวาดกรอบแทนการเลื่อนแผ่น | นั่นคือวิธีที่ {{ui:Auto count}} ทำงาน | กด {{key:Space}} แล้วลาก หรือลากด้วยปุ่มกลาง |

## ปุ่มและเมาส์

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ปุ่มตัวอักษรไม่ทำงาน | เคอร์เซอร์อยู่ในช่องกรอก (ค้นหา ตัวแก้ไขรายการ หรือตาราง) | คลิกบนแผ่น หรือกด {{key:Tab}} ออกจากช่อง |
| ล้อเมาส์ซูมแทนการเลื่อน | ล้อจะซูมแผ่นเสมอ | ลากเพื่อเลื่อนแผ่น |
| ทั้งหน้าใหญ่ขึ้นหรือเล็กลง | การซูมของเบราว์เซอร์ ({{key:Mod+Plus}} หรือ {{key:Mod+Minus}}) | กด {{key:Mod+0}} ซูมแผ่นด้วยล้อ หรือด้วย {{key:Plus}} และ {{key:Minus}} โดยไม่มีตัวปรับ |
| เครื่องหมายหายไปเมื่อกด Backspace | Backspace ลบเครื่องหมายที่เลือกเมื่อคุณไม่ได้กำลังวาด | {{key:Mod+Z}} จะนำกลับมา |
| คลิกขวาไม่จบบน Mac | Control-คลิกถูกส่งมาเป็นการคลิกปกติ | ใช้การคลิกสองนิ้วเมื่อเปิดคลิกรองไว้ หรือกด {{key:Enter}} |

## หน้าจอสัมผัส

บนหน้าจอสัมผัส:

- **แตะ** วางจุด (หรือเลือกเครื่องหมายด้วย {{ui:Select}}) นิ้วเดียวลากเพื่อเลื่อน
- **สองนิ้ว** บีบเพื่อซูมรอบจุดระหว่างนิ้ว และเลื่อนเมื่อนิ้วเคลื่อนไปด้วยกัน การวางนิ้วที่สองจะยกเลิกสิ่งที่นิ้วแรกเริ่มไว้ ดังนั้นการบีบจะไม่ทิ้งจุดไว้
- **จบ** เส้นหรือเส้นรอบรูปด้วย **กดค้าง** (เทียบเท่าคลิกขวา) **แตะสองครั้ง** หรือ {{ui:Finish}} ในแถบด้านล่างของแผ่น แถบเดียวกันมี {{ui:Back}} (ถอยจุดสุดท้าย) และ {{ui:Cancel}} พื้นที่ยังปิดได้โดยแตะจุดแรก
- นิ้วมีเป้าหมายที่ใหญ่ขึ้น: จุดจะสแนป ปิด และเลือกได้จากระยะไกลขึ้น และที่จับมุมจะใหญ่ขึ้น

การพิมพ์ความยาวต้องใช้คีย์บอร์ด คีย์บอร์ดบนหน้าจอใช้ได้เมื่อกล่อง {{ui:Type}} ถูกโฟกัส

บนแท็บเล็ต คีย์บอร์ดและเมาส์หรือแทร็กแพดทำให้การถอดปริมาณง่ายขึ้นมาก

## ทำงานแบบออฟไลน์

| ปุ่มหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| {{ui:Could not save}} | ไฟล์บางส่วนของแอปไม่ได้ดาวน์โหลดระหว่างการบันทึกเพื่อใช้ออฟไลน์ | ตรวจการเชื่อมต่อและเลือกปุ่มอีกครั้ง |
| {{ui:Offline not available}} | หน้าต่างส่วนตัวและคอมพิวเตอร์ที่จัดการบางเครื่องบล็อกสำเนาออฟไลน์ | ใช้หน้าต่างปกติ หรือเบราว์เซอร์อื่น |
| "กำลังบันทึก…" ไม่เริ่มต้น | คุณออฟไลน์ การบันทึกต้องมีการเชื่อมต่อ | บันทึกขณะออนไลน์ |
| แอปเก่าหลังอัปเดต | สำเนาออฟไลน์มาจากวันก่อนหน้า | ขณะออนไลน์ เลือก {{ui:Offline ready}} แล้วเลือก {{ui:Save again (get the newest version)}} |
| ต้องการพื้นที่คืน | สำเนาออฟไลน์มีขนาดประมาณ 6 MB | เลือก {{ui:Offline ready}} แล้วเลือก {{ui:Remove the offline copy}} |

## ยังแก้ไม่ได้

โหลดหน้าใหม่หากแอปหยุดตอบสนอง การถอดปริมาณของคุณจะหายเมื่อโหลดใหม่ เว้นแต่คุณจะได้บันทึกไว้ ดังนั้นบันทึกก่อนด้วย {{key:Mod+S}} หากทำได้ สำหรับคำถามเรื่องเบราว์เซอร์ ดู [เบราว์เซอร์และคอมพิวเตอร์](common:browsers)

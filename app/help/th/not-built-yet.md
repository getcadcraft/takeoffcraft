TakeoffCraft อยู่ระหว่างการพัฒนา รายการนี้คือสิ่งที่บิลด์ปัจจุบันยังไม่ทำ และวิธีทำงานให้เสร็จด้วยวิธีอื่น

## การวัด

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การแทรกจุดกลางเส้นหรือเส้นขอบ | ลบเครื่องหมายแล้ววาดใหม่ |
| การเลือกแบบกรอบ (หน้าต่าง) | กด {{key:Shift}} + คลิกทีละเครื่องหมาย หรือกด {{key:Mod+A}} เพื่อเลือกทุกเครื่องหมายบนแผ่น ดู [คัดลอก วาง และทำสำเนาเครื่องหมาย](topic:copy-paste) |
| การหมุน พลิก หรือปรับขนาดสำเนาที่วาง | วางบนแผ่นที่มาตราส่วนเดียวกันและทิศทางเดียวกัน แล้ววาดส่วนที่เหลือด้วยมือ |
| การอ่านมาตราส่วนจากแผ่นสแกนหรือจากแถบมาตราส่วนกราฟิก | เลือกค่าที่ตั้งไว้ หรือปรับเทียบจากความยาวของแถบ |
| มากกว่าหนึ่งมาตราส่วนต่อแผ่น (พื้นที่รายละเอียด แปลนขยาย) | วัดชิ้นส่วนที่มาตราส่วนของแผ่น และถอดปริมาณรายละเอียดบนแผ่นขยายของมันเอง หากชุดแบบมีแผ่นนั้น |

## รายการและการตั้งราคา

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| สูตรแอสเซมบลีที่ใช้เครื่องหมายประเภทอื่นของรายการ (เช่น ประตูของรายการห้องในสูตรของชั้นนั้น) | สูตรใช้ผลรวมของประเภทหลัก ตั้งราคาเครื่องหมายประเภทอื่นในแถวของมันเอง |
| สูตรแอสเซมบลีที่คำนวณทีละเส้น | สูตรใช้ผลรวมของรายการ ใช้ `N` สำหรับส่วนเพิ่มต่อเส้น |
| สูตรที่ใช้ปริมาณของรายการอื่น | วัดซ้ำในรายการนั้น หรือคำนวณในไฟล์สเปรดชีตที่ส่งออก |
| ทีมงานในส่วนประกอบของแอสเซมบลี หรือวันทำงานที่ไม่ใช่ 8 ชั่วโมง | กำหนดทีมให้รายการ และอ่านวันทีมสำหรับความยาววันอื่นเป็นชั่วโมงทีม ÷ จำนวนชั่วโมงต่อวันของคุณ |
| มาร์กอัปอื่นนอกจากหมายเหตุ เมฆ และไฮไลต์ (ลูกศร ไดเมนชัน ตราประทับ) หรือการตอบกลับในหมายเหตุ | เขียนไว้ในข้อความของหมายเหตุ และเปลี่ยนสถานะเมื่อจัดการเสร็จ |
| คลังราคาที่ทีมใช้ร่วมกัน หรือเก็บไว้กับบัญชีของคุณ | คลังเก็บไว้ในเบราว์เซอร์นี้: ส่งออกเป็น CSV แล้วนำเข้าในคอมพิวเตอร์อีกเครื่อง |
| ชุดงานอาชีพที่ผ่านการตรวจโดยผู้ประเมินราคาที่ทำงานจริง | ทุกชุดเป็นชุดเริ่มต้น ตรวจสมมติฐานกับงานและผลิตภัณฑ์ของคุณก่อนตั้งราคา ดู [ชุดงานอาชีพ](topic:trade-packs) |
| ราคาในชุดงานอาชีพ | ชุดงานให้แอสเซมบลีเท่านั้น ตั้งอัตราของคุณเอง หรือนำเข้ารายการราคาของคุณเป็น CSV |
| การเปลี่ยนชื่อ takeoff | ชื่อมาจาก PDF แรก เปลี่ยนชื่อไฟล์ที่ดาวน์โหลดแทน |
| การตั้งชื่อแผ่นด้วยมือ | แผ่นถูกตั้งชื่อจากป้ายหน้าของ PDF ค้นหาตามชื่อไฟล์และหน้า |

## แบบ (DWG และ DXF)

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| ตารางสไตล์การพล็อต การกำหนดปากกา และไฟล์ CTB บนแผ่นของแบบ | แบบจะวาดเป็นสีดำ หรือใช้สีของแบบที่เข้มขึ้นสำหรับกระดาษ เส้นหนาจะมาจากแบบ |
| การเปิด DXF แบบไบนารี หรือ DWG ที่เก่ากว่า AutoCAD 2000 | บันทึกเป็น DXF แบบ ASCII หรือ DWG ที่ใหม่กว่า |
| การหาแบบที่เชื่อมโยง (xref) จากโฟลเดอร์ที่มันอยู่ | เปิดไฟล์ของแบบที่เชื่อมโยงด้วย พร้อมแบบหลัก ระบบจะหาจากชื่อไฟล์ในบรรดาไฟล์ที่เปิดอยู่ |
| การวัดโพลีไลน์ 3 มิติ เมช โซลิด และรีเจียน | นับตามเลเยอร์และประเภท หรือวัดมุมมองผังด้วยเครื่องมือเส้นตรงและพื้นที่ |
| ข้อความในแบบที่เขียนด้วยสคริปต์ที่ไม่ใช่อักษรละติน ใน PDF ที่มีมาร์ก | อักขระที่ Helvetica ไม่มีรูปร่างจะพิมพ์เป็น "?" ใน PDF ที่มีมาร์ก แบบบนหน้าจอไม่ได้รับผล |
| การส่งต่อแบบไปยังแอปอื่นจากแถบแผ่น | เปิดไฟล์เดียวกันในแอปนั้น |
| แบบที่บรรจุ takeoff ไว้ข้างใน อย่างที่ {{ui:PDF with the takeoff inside}} ทำกับ PDF | {{ui:Save takeoff}}: ไฟล์ `.takeoff.json` จะเปิดใหม่บนแบบเดิม โดยหาจากเนื้อหา |
| การแสดงหรือการนับ PDF พื้นหลัง รูปภาพ และวัตถุ OLE ที่วางในแบบ | รูปภาพแสดงเป็นกรอบเท่านั้น เปิด PDF พื้นหลังเองเป็นแผ่น |

## นับอัตโนมัติ

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การหาสัญลักษณ์บนแผ่นที่ไม่มีมาตราส่วนซึ่งวาดในขนาดอื่น | กำหนดมาตราส่วนให้แผ่น หรือค้นหาด้วยกรอบที่วาดตรงนั้น |
| การหาสัญลักษณ์ที่สะท้อน | นับด้วยมือ หรือค้นหาใหม่โดยวาดกรอบรอบตัวที่สะท้อน |

## ไฟล์และการแชร์

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| ไฟล์ PDF เดียวที่แสดงทั้งเครื่องหมายและบรรจุ takeoff | {{ui:Marked PDF}} ให้ผู้อื่นดูเครื่องหมาย และ {{ui:PDF with the takeoff inside}} เพื่อเปิดใหม่ใน TakeoffCraft |
| ไฟล์ CSV ของปริมาณแยกตามแผ่นหรือของเครื่องหมาย | ใช้ {{ui:XLSX}}: เวิร์กชีต By sheet และ Marks มีข้อมูลนี้ |
| การบันทึกบนคลาวด์ | ยังไม่พร้อมใช้งาน บันทึกไฟล์โปรเจกต์ลงคอมพิวเตอร์และสำรองไว้ |
| แอปเดสก์ท็อป TakeoffCraft แยกต่างหาก | ตั้งแต่ 0.5 แอปเดสก์ท็อปคือ CadCraft Studio ซึ่งรวมทั้งแปดแอปในการติดตั้งเดียว TakeoffCraft ทำงานในเบราว์เซอร์ได้ด้วย |

## หน้าจอและการป้อนข้อมูล

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| เมนูคลิกขวา (หรือกดค้าง) | ใช้แถบเครื่องมือ พาเนล และปุ่มต่าง ๆ การกดค้างจะจบเส้นต่อเนื่องหรือเส้นขอบ |
| การหมุนมุมมอง | หน้าที่หมุนไว้แล้วใน PDF จะแสดงตรงอยู่แล้ว |

## มุมมอง 3 มิติ

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การวาดหรือแก้ไขเครื่องหมายใน 3 มิติ | กลับไปที่แผ่น ({{key:3}}) เพื่อวาด การเลือกและการลบใช้ได้ใน 3 มิติ |
| การเรียงชั้นที่พล็อตไว้ที่ตำแหน่งต่างกันบนหน้า | เรียงชั้นที่พล็อตเหมือนกัน และตรวจชั้นอื่นทีละแผ่น |
| การนับเสาที่มีขนาดเท่ากับวัตถุที่ถูกนับ | เสาทุกต้นบนแผ่นมีขนาดเท่ากัน เสาบอกตำแหน่งที่นับ ไม่ได้บอกว่าเป็นอะไร |

## การประมูล

| ยังไม่ได้สร้าง | ทำแทนได้ตอนนี้ |
|---|---|
| การเพิ่มเติมให้แพ็กเกจที่ส่งไปแล้ว จดหมายแจ้งผลการคัดเลือก หรือแผ่นขอบเขตที่ผู้ประมูลแต่ละรายลงนาม | ส่งแพ็กเกจใหม่ แล้วเขียนหนังสือแจ้งผลเอง [ส่งแพ็กเกจเพื่อการประมูล](topic:bid-invitations) อธิบายสิ่งที่สร้างไว้แล้ว |
| การส่งคำเชิญประมูลจากบัญชีใดก็ได้: ระหว่างการทดสอบ อีเมลถึงผู้ประมูลภายนอกปิดไว้ ยกเว้นบัญชีที่ทีม CadCraft เปิดใช้ | ดาวน์โหลด {{ui:Scope CSV}} ส่งอีเมลเอง แล้วพิมพ์ราคาประมูลเข้าไป |
| การส่งแพ็กเกจประมูลจากหน้าต่าง Studio | ส่งจาก TakeoffCraft ในเบราว์เซอร์ |
| การตั้งราคาพื้นที่ประมูลของทางเลือกใหม่ด้วยราคาประมูลที่เลือก | ทางเลือกและยอดรวมพื้นที่ประมูลใช้ราคาของคุณเอง ปรับทางเลือกด้วยมือ |
| การเตือนอัตโนมัติก่อนวันหมดอายุประกันหรือใบอนุญาตของผู้รับเหมาช่วง | ระบบทำเครื่องหมายวันที่ในหน้าผู้รับเหมาช่วงเมื่อเลยกำหนดหรือเหลือไม่เกิน 30 วัน ตรวจสอบเมื่อคุณเชิญ |

## สเปรดชีต

เวิร์กบุ๊ก XLSX ได้ตรวจใน LibreOffice Calc แล้ว ซึ่งคำนวณผลรวมทุกรายการให้ตรงถึงทศนิยมสองตำแหน่งเดียวกับ TakeoffCraft แต่ยังไม่ได้เปิดใน Excel หากโปรแกรมสเปรดชีตแสดงผลที่ไม่คาดคิด ไฟล์ CSV ที่ส่งออกมีประมาณการเดียวกันเป็นค่าธรรมดา

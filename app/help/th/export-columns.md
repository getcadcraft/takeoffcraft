## ประมาณราคา (แผ่นงาน XLSX และ CSV)

หนึ่งแถวต่อรายการ ตามด้วยหนึ่งแถวต่อส่วนประกอบของชุดงานต้นทุน (ย่อหน้า) จากนั้นเป็นแถวว่างและยอดรวมงาน

| คอลัมน์ | เนื้อหา | ใน XLSX |
|---|---|---|
| A รายการ | ชื่อรายการ (ตัวหนา) หรือชื่อส่วนประกอบ (ย่อหน้า) | ข้อความ |
| B ประเภท | Linear, Area, Count หรือ Component | ข้อความ |
| C หน่วย | LF, m, SF, SY, m², EA หรือหน่วยของส่วนประกอบ | ข้อความ |
| D ปริมาณ | ผลรวมที่วัดได้ หรือผลลัพธ์ของสูตร | ตัวเลข |
| E ความสูญเสีย % | ความสูญเสีย | เปอร์เซ็นต์ (0.10 = 10%) |
| F ปริมาณรวมความสูญเสีย | ปริมาณ × (1 + ความสูญเสีย) | สูตร `D*(1+E)` |
| G วัสดุต่อหน่วย | อัตราวัสดุ | ตัวเลข |
| H ค่าแรงต่อหน่วย | อัตราค่าแรง | ตัวเลข |
| I วัสดุ | วัสดุที่คำนวณแล้ว | สูตร `ROUND(F*G,2)` |
| J ค่าแรง | ค่าแรงที่คำนวณแล้ว | สูตร `ROUND(F*H,2)` |
| K รวม | วัสดุ + ค่าแรง | สูตร `I+J` |
| L หมายเหตุ | สูตรที่ใช้ ข้อผิดพลาดของสูตร เครื่องหมายบนแผ่นที่ไม่มีมาตราส่วน พื้นที่ผนัง เส้นรอบรูป | ข้อความ |

แถวยอดรวมงาน: `SUM` ของคอลัมน์ I, J และ K ในทุกแถวด้านบน และในหมายเหตุขึ้นว่า "ไม่สมบูรณ์: ดูหมายเหตุด้านบน" เมื่อมีบางอย่างถูกละไว้

แถวที่มีข้อผิดพลาดของสูตรจะไม่มีปริมาณหรือจำนวนเงิน หมายเหตุของแถวจะบอกข้อผิดพลาด แถวหัวตารางถูกตรึงไว้

ใน CSV คอลัมน์เดียวกันเก็บค่าธรรมดา ความสูญเสีย % เป็นตัวเลขของเปอร์เซ็นต์ (10 สำหรับ 10%) และเงินเป็นดอลลาร์ทศนิยมสองตำแหน่ง ข้อความที่สเปรดชีตอาจถือเป็นสูตร (ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@`) จะมี `'` นำหน้า เพื่อให้คงเป็นข้อความ

## ตามแผ่น (เฉพาะ XLSX)

| คอลัมน์ | เนื้อหา |
|---|---|
| แผ่น | ชื่อแผ่น (พร้อมชื่อ PDF เมื่อไม่ได้เปิดอยู่) |
| รายการ | ชื่อรายการ |
| ปริมาณ | ปริมาณของรายการนั้นบนแผ่นนั้น ในหน่วยของรายการ |
| หน่วย | หน่วยของรายการ |
| เครื่องหมาย | จำนวนเครื่องหมาย |

## เครื่องหมาย (เฉพาะ XLSX)

หนึ่งแถวต่อเครื่องหมาย

| คอลัมน์ | เนื้อหา |
|---|---|
| แผ่น | ชื่อแผ่น |
| รายการ | ชื่อรายการ |
| ประเภท | Linear, Area หรือ Count |
| ปริมาณ | ความยาว พื้นที่สุทธิ หรือ 1 |
| หน่วย | LF หรือ m; SF, SY หรือ m²; EA |
| รายละเอียด | Linear: ความยาวของแต่ละช่วง โดยช่วงที่ถูกหักมีเครื่องหมาย "(หัก)" และ "หักรวม (ความยาว) จาก (ความยาว) ที่วาดไว้" Area: พื้นที่รวมและพื้นที่ตัดออกเมื่อมีช่องตัด และเส้นรอบรูป "แผ่นไม่มีมาตราส่วน" สำหรับเครื่องหมายที่ไม่มีมาตราส่วน |
| พื้นที่ประมูล | เฉพาะเมื่อ takeoff มีพื้นที่ประมูล: พื้นที่ของเครื่องหมาย หรือ "ไม่มีพื้นที่ประมูล" |

## ตามพื้นที่ประมูล (เฉพาะ XLSX เมื่อ takeoff มีพื้นที่ประมูล)

| คอลัมน์ | เนื้อหา |
|---|---|
| พื้นที่ประมูล | ชื่อของพื้นที่ หรือ "ไม่มีพื้นที่ประมูล" |
| รายการ | รายการ หรือส่วนประกอบย่อหน้าภายใต้รายการ |
| หน่วย | หน่วยของรายการหรือส่วนประกอบ |
| ปริมาณ | วัดในพื้นที่นั้น (ส่วนประกอบ: สูตรบนยอดรวมของพื้นที่) |
| ปริมาณรวมความสูญเสีย | ปริมาณ × (1 + ความสูญเสีย) |
| วัสดุ, ค่าแรง, รวม | คำนวณถึงหน่วยเซนต์ เหมือนในประมาณราคา |
| หมายเหตุ | สูตร ข้อผิดพลาด และเครื่องหมายที่ไม่มีมาตราส่วน เหมือนในประมาณราคา |

แต่ละพื้นที่จบด้วยแถว "(ชื่อ) ยอดย่อย" ซึ่งค่าใช้จ่ายเป็นสูตร `SUM` ของแถวในพื้นที่นั้น แถวสุดท้าย **พื้นที่ประมูลทั้งหมด** รวมยอดย่อย แผ่นงาน **เครื่องหมาย** จะมีคอลัมน์ที่เจ็ด **พื้นที่ประมูล**

## มาตราส่วน (เฉพาะ XLSX)

หนึ่งแถวต่อแผ่นที่มีมาตราส่วนหรือเครื่องหมาย

| คอลัมน์ | เนื้อหา |
|---|---|
| แผ่น | ชื่อแผ่น |
| มาตราส่วน | ชื่อของค่าที่ตั้งไว้ มาตราส่วนที่ปรับเทียบ หรือ "ไม่มีมาตราส่วน" |
| วิธีการ | "ค่าที่ตั้งไว้" หรือ "ปรับเทียบบน (ระยะที่พิมพ์)" |
| ฟุตต่อหน่วย PDF | อัตราส่วนที่แน่นอนที่ TakeoffCraft ใช้ |

## ชื่อไฟล์

- `(name).xlsx` และ `(name).csv` โดยชื่อมาจาก PDF ไฟล์แรกที่เปิดใน takeoff
- CSV เป็น UTF-8 พร้อมเครื่องหมายลำดับไบต์ (BOM) และการขึ้นบรรทัดแบบ Windows ซึ่งโปรแกรมสเปรดชีตทุกแพลตฟอร์มอ่านได้

## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียนเอง) ทำงานกับ TakeoffCraft และวิธีตัดสินใจว่าผู้ช่วยแตะต้องอะไรได้บ้าง

TakeoffCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใด คุณนำผู้ช่วยมาเอง คือโปรแกรมใดก็ได้ที่ใช้ Model Context Protocol (MCP) ได้ TakeoffCraft เพียงให้เครื่องมือแก่ผู้ช่วย และคุณเป็นผู้เลือกว่าเครื่องมือใดบ้าง

## เปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนเฟืองบนแถบแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:TakeoffCraft}}
2. ใต้ {{ui:ผู้ช่วย}} ให้ทำเครื่องหมาย **ให้ผู้ช่วย AI และสคริปต์ใช้ TakeoffCraft** ตอนเริ่มต้นสวิตช์นี้ปิดอยู่จนกว่าคุณจะเปิด
3. เลือกสิ่งที่ผู้ช่วยทำได้: **อ่าน** ถูกทำเครื่องหมายไว้ตั้งแต่ต้น ทำเครื่องหมาย **แก้ไข**, **บันทึก** หรือ **ส่งออก** เฉพาะเมื่อคุณต้องการใช้

เครื่องมือที่อยู่นอกสิทธิ์ที่คุณทำเครื่องหมายจะไม่ถูกเสนอให้ผู้ช่วย และหากผู้ช่วยขอใช้ TakeoffCraft จะปฏิเสธและบันทึกไว้ในบันทึกกิจกรรม การปิดสวิตช์จะตัดการเชื่อมต่อทั้งหมดในทันที {{ui:รีเซ็ตการตั้งค่า TakeoffCraft}} ก็ปิดสวิตช์นี้ด้วย

## เชื่อมต่อผู้ช่วยของคุณ

ผู้ช่วยเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ Studio รันเซิร์ฟเวอร์ขนาดเล็กที่มีเพียงคอมพิวเตอร์เครื่องนี้เข้าถึงได้ และป้องกันด้วยโทเคนที่ Studio สร้างขึ้นทุกครั้งที่เริ่มทำงาน ใน Studio ให้เลือก {{ui:เชื่อมต่อผู้ช่วย}} แล้วคัดลอกที่อยู่และโทเคนไปใส่ในผู้ช่วยของคุณ (Studio จะแสดงการตั้งค่าที่ต้องวางให้เห็น) อย่าแชร์โทเคนกับใคร

:::note
แท็บเบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้ ในแอปบนเบราว์เซอร์ สวิตช์จะไม่มีผลจนกว่าคุณจะใช้ CadCraft Studio บนคอมพิวเตอร์ของคุณ
:::

## คุณยังควบคุมได้เสมอ

- **การเปลี่ยนแปลงทุกครั้งคือหนึ่งขั้นตอนเลิกทำ** มีป้ายกำกับเป็นชื่อที่ผู้ช่วยใช้เรียกการกระทำนั้น (เช่น "ผู้ช่วย: …") {{key:Mod+Z}} จะเลิกทำการเปลี่ยนแปลงล่าสุดของผู้ช่วยทั้งชุด
- **คุณรู้ได้เมื่อมีการเชื่อมต่อ** ปุ่มบนแถบแอปจะแสดงชื่อผู้ช่วยขณะที่เชื่อมต่ออยู่ คลิกเพื่อดูว่าผู้ช่วยทำอะไรได้ หรือเพื่อ **ยกเลิกการเชื่อมต่อ**
- **กิจกรรม** {{ui:การตั้งค่า}} › {{ui:TakeoffCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงทุกการเรียกใช้: เมื่อไร เครื่องมือใด และทำเสร็จหรือถูกปฏิเสธ {{ui:บันทึกบันทึกกิจกรรม}} เก็บสำเนาไว้

## ผู้ช่วยขอใช้อะไรได้บ้าง

| เครื่องมือ | สิทธิ์ | ทำอะไร |
|---|---|---|
| `app_info`, `sheets_list` | อ่าน | การคำนวณปริมาณที่เปิดอยู่ PDF และแผ่น มาตราส่วนและมาร์กของแต่ละแผ่น |
| `items_list` | อ่าน | รายการพร้อมหน่วย ราคาต่อหน่วย และสูตรชุดงาน |
| `takeoff_quantities` | อ่าน | ปริมาณแยกตามรายการหรือตามแผ่น มาร์กบนแผ่นที่ไม่มีมาตราส่วนจะถูกแสดงเป็นรายการ ไม่ถูกนับเป็นศูนย์ |
| `takeoff_estimate` | อ่าน | ประมาณราคาที่ TakeoffCraft คำนวณ พร้อมยอดรวม |
| `takeoff_export` | ส่งออก | การส่งออก CSV หรือ XLSX ของ TakeoffCraft เอง |
| `items_add` | แก้ไข | เพิ่มรายการพร้อมหน่วย ราคาต่อหน่วย และความสูญเสีย |
| `marks_add` | แก้ไข | วัดแนวความยาว พื้นที่ และจำนวนบนแผ่น ความยาวและพื้นที่ทำได้เฉพาะบนแผ่นที่มีมาตราส่วนเท่านั้น ไม่ทำบนแผ่นที่ไม่มีมาตราส่วน |
| `cad_sheets`, `cad_catalog`, `cad_count` | อ่าน | บน DWG หรือ DXF ที่คุณเปิด: แผ่นและมาตราส่วนของแผ่น สิ่งที่นับได้ (บล็อก เลเยอร์และประเภท ข้อความ) และจำนวนที่แน่นอน เหมือนที่ {{ui:นับจาก CAD}} ทำ ([นับจากแบบ](topic:count-from-a-drawing)) |
| `cad_count_add` | แก้ไข | นับในแบบและวางมาร์กการนับบนวัตถุแต่ละชิ้นที่พบ ในขั้นตอนเดียว การนับอีกครั้งจะเพิ่มเฉพาะสิ่งที่ใหม่ |
| `cad_measure` | แก้ไข | วัดรายการแบบความยาวหรือพื้นที่จากเส้น ส่วนโค้ง โพลีไลน์ และแฮตช์ของแบบ เหมือนที่ {{ui:วัดแบบ}} ทำ ([วัดจากแบบ](topic:measure-from-a-drawing)) ทำได้เฉพาะบนแผ่นที่มีมาตราส่วน |
| `usd_export` | ส่งออก | แนวความยาว พื้นที่ และจำนวนที่วัดของแผ่นที่มีมาตราส่วน เป็นโมเดลตรวจ 3D ในรูปแบบ USD (`.usdz`, `.usda` หรือ `.usdc`) เหมือนที่ {{ui:แพ็กเกจ USD (.usdz)}} ในมุมมองตรวจ 3D เขียนไฟล์ ([ส่งออกมุมมองตรวจ 3D เป็น USD](topic:usd)) |

เมื่อทำเครื่องหมาย **แก้ไข** ผู้ช่วยจะเพิ่มรายการและมาร์กได้ (การเรียกแต่ละครั้งคือหนึ่งขั้นตอนเลิกทำ) แต่ย้าย เปลี่ยน หรือลบมาร์กที่มีอยู่แล้วไม่ได้

ข้อมูลปริมาณและประมาณราคาชุดเดียวกันนี้ใช้ได้โดยไม่ต้องเปิด TakeoffCraft: เซิร์ฟเวอร์ MCP ของ CadCraft เปิดไฟล์ `.takeoff.json` ในโฟลเดอร์ที่คุณระบุได้ (`takeoff_open`, `takeoff_quantities`, `takeoff_estimate`, `takeoff_export`) และ `cadcraft info Job.takeoff.json` แสดงข้อมูลเหล่านั้นบนบรรทัดคำสั่ง นอกจากนี้ยังเปิด DWG หรือ DXF เป็นการคำนวณปริมาณใหม่บนแผ่นของมัน (มาตราส่วนมาจากแบบ เหมือนที่ TakeoffCraft กำหนด) นับและวัดด้วยเครื่องมือ `cad_*` ชุดเดียวกัน เพิ่มรายการ และบันทึกการคำนวณปริมาณ (`takeoff_save`) ได้ และ `cadcraft count plan.dwg --block SHELF-18X48 --sheet K-101` นับจากบรรทัดคำสั่งได้

## หากมีปัญหา

- **ผู้ช่วยไม่เห็นเครื่องมือของ TakeoffCraft:** ตรวจสอบว่าสวิตช์เปิดอยู่ในหน้าต่างนี้ และหน้าต่างเปิดอยู่ใน Studio
- **"ต้องมีสิทธิ์ส่งออก":** ทำเครื่องหมาย **ส่งออก** ใต้ {{ui:ผู้ช่วย}} แล้วขออีกครั้ง
- **ข้อผิดพลาด "401" หรือ "token":** โทเคนเปลี่ยนไปแล้ว (Studio เริ่มทำงานใหม่ หรือ {{ui:โทเคนใหม่}}) คัดลอกโทเคนใหม่ไปใส่ในการตั้งค่าของผู้ช่วย

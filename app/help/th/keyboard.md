ปุ่มตัวอักษรใช้ได้เมื่อตัวชี้อยู่ที่ใดก็ได้บนหน้า และไม่ได้กำลังพิมพ์อยู่ในช่องกรอก ขณะที่กล่องโต้ตอบเปิดอยู่ ปุ่มของกล่องโต้ตอบนั้นจะใช้งาน ตัวอักษรใช้ได้ทั้งกับและไม่กับ {{key:Shift}}

## การเลือกและการแก้ไข

| ปุ่มหรือการกระทำ | สิ่งที่ทำ |
|---|---|
| คลิกมาร์ก (เครื่องมือเลือก) | เลือกมาร์กนั้นและตั้งรายการของมันเป็นรายการปัจจุบัน |
| {{key:Shift}} + คลิกมาร์ก | เพิ่มเข้าในที่เลือก หรือนำออก |
| {{key:Mod+A}} | เลือกมาร์กทุกอันบนแผ่นที่เปิดอยู่ |
| ลากปุ่มจับมุม | ย้ายจุดนั้น ({{key:Shift}} สแนปที่ 45°) ใช้ได้เมื่อเลือกมาร์กหนึ่งอัน |
| {{key:Delete}} หรือ {{key:Backspace}} | ลบมาร์กที่เลือก (เมื่อไม่ได้กำลังวาด) |
| {{key:Esc}} | ยกเลิกการเลือกทั้งหมด: ล้างที่เลือกและเส้นตรวจ |
| {{key:Mod+Z}} | เลิกทำ |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำ |

## คัดลอกและวาง

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Mod+C}} | คัดลอกมาร์กที่เลือก พร้อมรายการของมาร์กเหล่านั้น |
| {{key:Mod+X}} | ตัด: คัดลอกมาร์กที่เลือก แล้วลบ |
| {{key:Mod+V}} | วาง: สำเนาจะตามตัวชี้ คลิกตรงที่ต้องการวาง |
| {{key:Mod+Shift+V}} | วางที่เดิม: ตำแหน่งเดิมบนแผ่นที่เปิดอยู่ |
| {{key:Mod+D}} | ทำสำเนา: สำเนาจะตามตัวชี้ คลิกตรงที่ต้องการวาง |
| {{key:Esc}} | ไม่วางอะไรลง: ยกเลิกการวางหรือทำสำเนาที่ติดอยู่กับตัวชี้ |

ตัวอักษรเพียงลำพังยังเลือกเครื่องมือได้ ({{key:C}} คือ {{ui:นับ}} {{key:D}} คือ {{ui:ตรวจ}} {{key:X}} คือ {{ui:ช่องตัด}} {{key:V}} คือ {{ui:เลือก}} {{key:A}} คือ {{ui:พื้นที่}}) มีเพียง {{key:Mod}} ร่วมกับตัวอักษรเหล่านี้เท่านั้นที่คัดลอกและวาง ในช่องข้อความ ปุ่มเหล่านี้คัดลอกและวางข้อความตามปกติ ดู [คัดลอก วาง และทำสำเนามาร์ก](topic:copy-paste)

:::warning
{{key:Backspace}} ลบมาร์กที่เลือกเมื่อไม่ได้กำลังวาด หากเกิดขึ้นโดยไม่ตั้งใจ {{key:Mod+Z}} จะนำกลับมา
:::

## หมายเหตุตามแพลตฟอร์ม

:::mac
- {{key:Mod}} คือปุ่ม Command: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}} ยกเว้นเต็มหน้าจอ ซึ่งคือ Control+Shift+F
- คลิกขวาคือการแตะด้วยสองนิ้วบนแทร็กแพด เมื่อเปิด secondary click ใน System Settings ภายใต้ Trackpad TakeoffCraft อ่านเฉพาะปุ่มรอง การคลิกด้วย Control อาจนับเป็นการคลิกธรรมดาและเพิ่มจุด
- การเลื่อนด้วยสองนิ้วบนแทร็กแพดจะซูมแผ่น (ไม่ได้เลื่อน) เพื่อแพน ให้กดแล้วลาก หรือกด {{key:Space}} ค้างแล้วลาก
- Page Up และ Page Down คือ fn ร่วมกับปุ่มลูกศรขึ้นและลงในคีย์บอร์ดที่ไม่มีปุ่มเหล่านี้
- {{key:Backspace}} คือปุ่มที่มีป้ายว่า delete
:::

:::windows
- {{key:Mod}} คือ Ctrl: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}
- บนทัชแพดของแล็ปท็อป การเลื่อนด้วยสองนิ้วจะซูมแผ่น เพื่อแพน ให้กดแล้วลาก
:::

:::linux
- {{key:Mod}} คือ Ctrl บางเดสก์ท็อปมีปุ่มลัด Ctrl+Alt หรือ Super ของตัวเอง TakeoffCraft ไม่ใช้ปุ่มลัดเหล่านั้น
- บนแทร็กแพด การเลื่อนด้วยสองนิ้วจะซูมแผ่น เพื่อแพน ให้กดแล้วลาก
:::

:::touch
TakeoffCraft อ่านการสัมผัสเป็นตัวชี้เดียว:

- แตะเพื่อวางจุด เลือกมาร์ก หรือเพิ่มจุดนับ
- ลากด้วยนิ้วเดียวเพื่อแพนแผ่น (ใน {{ui:นับอัตโนมัติ}} จะวาดกล่องค้นหา)
- ยังไม่รองรับการหนีบเพื่อซูม ให้ใช้ {{ui:พอดีหน้า}} และ {{ui:พอดีความกว้าง}} หรือ {{key:Plus}} และ {{key:Minus}} บนคีย์บอร์ด
- เพื่อปิดพื้นที่ ให้แตะจุดแรก เพื่อจบเส้นต่อเนื่อง ให้แตะสองครั้งในตำแหน่งที่เบราว์เซอร์แปลงการแตะสองครั้งเป็นดับเบิลคลิก หรือกด {{key:Enter}} บนคีย์บอร์ด
- ไม่มีการแสดงความยาวสดจนกว่าจะแตะ เพราะไม่มีการชี้ค้าง

ปัจจุบันการใช้คีย์บอร์ดและเมาส์หรือแทร็กแพดเป็นวิธีที่ดีกว่าในการทำ takeoff
:::

## ปุ่มที่เบราว์เซอร์สงวนไว้

เบราว์เซอร์สงวนปุ่มลัดบางอย่างไว้ใช้เอง และหน้าเว็บใช้ไม่ได้: การปิดแท็บ ({{key:Mod+W}}) แท็บหรือหน้าต่างใหม่ ({{key:Mod+T}}, {{key:Mod+N}}) และการซูมของเบราว์เซอร์ ({{key:Mod+Plus}}, {{key:Mod+Minus}}) นั่นเป็นเหตุผลที่ TakeoffCraft ซูมแผ่นด้วยล้อและปุ่ม {{key:Plus}} และ {{key:Minus}} เดี่ยว ๆ หากกด {{key:Mod+Plus}} โดยไม่ตั้งใจ ทั้งหน้าจะขยาย {{key:Mod+0}} จะคืนค่า ดู [ปุ่ม เมาส์ และแทร็กแพด](common:keys)

## คำสั่งย้ายอยู่ที่ไหน

ไม่มีคำสั่งย้าย: เลือกจุดนับแล้วลาก หรือเลือกพื้นที่หรือเส้นแล้วลากปุ่มจับมุม

**คลังราคา** เก็บรายการที่คุณใช้ในทุกงาน ได้แก่ ประเภท หน่วย ความสูง ความสูญเสีย อัตราวัสดุและค่าแรง และแอสเซมบลี คลังเก็บไว้ในเบราว์เซอร์นี้ แยกจาก takeoff ใด ๆ ดังนั้นทุก takeoff ที่คุณเปิดที่นี่จะใช้คลังได้

เปิดด้วย {{ui:Library}} ที่ด้านบนของพาเนล {{ui:Items}}

## เติมคลัง

- {{ui:Import CSV…}} อ่านสเปรดชีตที่บันทึกเป็น CSV (ดูคอลัมน์ด้านล่าง) รายการที่ชื่อและประเภทมีอยู่ในคลังแล้วจะถูกแทนที่ ที่เหลือจะถูกเพิ่ม แถวที่อ่านไม่ได้จะถูกข้าม และระบบจะบอกว่าแถวใดและเพราะอะไร
- {{ui:เพิ่มรายการของ takeoff นี้}} คัดลอกทุกรายการของ takeoff ที่เปิดอยู่ไปยังคลัง พร้อมอัตราและแอสเซมบลี (แต่ไม่รวมเครื่องหมาย)
- ไฟล์ประมาณราคาในรูปแบบ CSV ที่ TakeoffCraft ส่งออก ([ส่งออกประมาณราคา](topic:export-estimate)) นำเข้าได้ตามที่เป็น ราคาของงานก่อนหน้าจะเป็นจุดเริ่มต้นของงานถัดไป

- {{ui:Trade packs…}} เพิ่มแอสเซมบลีฟรีสำหรับงานอาชีพ เช่น ดรายวอลล์ ไฟฟ้า หรือคอนกรีต โดยไม่มีราคา ดู [ชุดงานอาชีพ](topic:trade-packs)

{{ui:Export CSV}} บันทึกคลังเป็น CSV เพื่อเก็บสำเนา แก้ไขในสเปรดชีต หรือส่งให้เพื่อนร่วมงาน {{ui:Clear}} ล้างคลัง (กดสองครั้ง)

:::note
คลังอยู่ในที่เก็บข้อมูลของเบราว์เซอร์นี้ เบราว์เซอร์อื่น คอมพิวเตอร์อื่น หรือหน้าต่างส่วนตัวจะมีคลังของตัวเอง (หรือไม่มีเลย) ส่งออกเพื่อย้ายคลัง
:::

## ใช้ในงาน takeoff

- เลือกรายการ (พิมพ์ใน {{ui:Find in the library}} เพื่อจำกัดรายการ) แล้วเลือก {{ui:Add to takeoff}} รายการจะถูกเพิ่มพร้อมแอสเซมบลีในขั้นตอนเดียว ซึ่ง {{key:Mod+Z}} ยกเลิกได้ ชื่อที่มีอยู่ใน takeoff แล้วจะได้หมายเลขต่อท้าย เช่น `Carpet (2)`
- {{ui:Update prices}} ให้รายการของ takeoff ใช้ความสูญเสียและอัตราจากคลัง สำหรับทุกรายการที่ชื่อและประเภทตรงกับรายการในคลัง และเช่นเดียวกันกับส่วนประกอบของแอสเซมบลีที่มีชื่อเดียวกัน ความสูง หน่วย และสูตรยังคงเดิม {{key:Mod+Z}} หนึ่งครั้งจะคืนราคาเดิมทั้งหมด

## คอลัมน์ CSV

แถวแรกระบุชื่อคอลัมน์ ตามลำดับใดก็ได้ คอลัมน์อื่นจะถูกละเว้น

| คอลัมน์ | สิ่งที่ใส่ |
|---|---|
| Item (or Name) | ชื่อรายการ จำเป็นต้องมี |
| Type | Linear, Area หรือ Count (LF, SF และ EA ใช้ได้เช่นกัน) หากเว้นว่าง หน่วยจะเป็นตัวกำหนด |
| Unit | LF หรือ m; SF, SY หรือ m²; EA ว่าง: หน่วยปกติของประเภทนั้น |
| Waste % | `10` หรือ `10%` |
| Material per unit, Labor per unit | อัตรา เช่น `2.10` หรือ `$1,250` |
| Height (or Depth) | `9'-0"`, `9` หรือ `2.7` สำหรับหน่วยเมตริก |
| Component, Formula | แถวที่มีชื่อ Component (หรือประเภท `Component`) เป็นส่วนหนึ่งของแอสเซมบลีของรายการด้านบน หน่วย ความสูญเสีย และอัตราเป็นของตัวเอง สูตรใช้ตัวอักษรของรายการ ดู [แอสเซมบลีและสูตร](topic:assemblies) |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

จุลภาค เซมิโคลอน หรือแท็บระหว่างคอลัมน์ใช้ได้ทั้งหมด

ส่วนประกอบของชุดงานต้นทุนได้ปริมาณจากสูตร สูตรคือนิพจน์เลขคณิตขนาดเล็กเหนือค่าที่วัดได้ของรายการ ดู [ชุดงานต้นทุนและสูตร](topic:assemblies) สำหรับตัวอย่าง

## ตัวแปร

| ประเภทรายการ | ตัวแปร | ความหมาย |
|---|---|---|
| Linear | `L` | ความยาวรวม |
| Linear | `H` | ความสูงของรายการ |
| Linear | `A` | พื้นที่ผนัง L × H หักช่องเปิดของช่วงที่มีช่องเปิดนั้น (takeoff จาก BimCraft) เมื่อ takeoff นั้นระบุวิธีวัด `A` จะวัดตามวิธีนั้น: ช่องเปิดที่ไม่ใหญ่กว่าขนาดเล็กที่สุดของวิธีจะคงไว้ และส่วนที่วิธีนั้นตัดออกตรงจุดที่ผนังมาบรรจบกันจะถูกตัดออก หมายเหตุใต้รายการจะระบุชื่อวิธีนั้น |
| Linear | `N` | จำนวนช่วง |
| Area | `A` | พื้นที่สุทธิรวม (เส้นขอบลบช่องตัด) |
| Area | `P` | เส้นรอบรูปรวม รวมขอบช่องตัด |
| Area | `H` | ความลึกหรือความหนาของรายการ |
| Area | `N` | จำนวนพื้นที่ |
| Count | `N` | จำนวนนับ |

- ตัวแปรใช้หน่วยของรายการ: ดู [หน่วย](topic:units)
- ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กเหมือนกัน: `l` คือ `L`
- ใช้ได้เฉพาะตัวแปรของประเภทรายการนั้นเอง `P` บนรายการ linear จะให้ `"P" ไม่ใช่ค่าที่วัดได้ที่นี่ ใช้ L, H, A, N.`
- ความสูงหรือความลึกที่ว่างเท่ากับ 0

## ตัวดำเนินการ

| เขียน | ความหมาย |
|---|---|
| `+` | บวก |
| `-` หรือ `−` | ลบ หรือค่าติดลบ |
| `*` หรือ `×` | คูณ |
| `/` หรือ `÷` | หาร |
| `( )` | จัดกลุ่ม |

การคูณและหารทำก่อนการบวกและลบ: `L * 2 + 4` คือ (L × 2) + 4 ใช้วงเล็บเมื่อไม่แน่ใจ

ตัวเลขมีทศนิยมได้ (`1.333`, `.5`) และเลขยกกำลังได้ (`1e3` = 1000) ช่องว่างถูกละเว้น

## ฟังก์ชัน

| ฟังก์ชัน | ผลลัพธ์ | ตัวอย่าง |
|---|---|---|
| `ceil(x)` | ปัดขึ้นเป็นจำนวนเต็ม | `ceil(67.5)` = 68 |
| `floor(x)` | ปัดลงเป็นจำนวนเต็ม | `floor(67.5)` = 67 |
| `round(x)` | ปัดเป็นจำนวนเต็มที่ใกล้ที่สุด ครึ่งหนึ่งออกจากศูนย์ | `round(2.5)` = 3 |
| `round(x, d)` | ปัดเป็น d ตำแหน่งทศนิยม (0 ถึง 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | ค่าที่น้อยที่สุด | `min(N, 10)` |
| `max(a, b, …)` | ค่าที่มากที่สุด | `max(1, ceil(N / 12))` |
| `abs(x)` | ค่าโดยไม่มีเครื่องหมาย | `abs(-3)` = 3 |

`ceil` และ `floor` ละเว้นสัญญาณรบกวนการปัดเศษเล็กน้อยของคอมพิวเตอร์ ค่าที่ควรเป็น 1 พอดีจึงไม่ถูกปัดขึ้นเป็น 2

## ข้อผิดพลาด

สูตรที่อ่านหรือคำนวณไม่ได้จะแสดงข้อผิดพลาดใต้ช่อง และส่วนประกอบนั้นจะถูกละจากยอดรวม (ส่วนหัว {{ui:ปริมาณ}} จะขึ้นว่า "ไม่สมบูรณ์") ข้อความและวิธีแก้:

| ข้อความ | วิธีแก้ |
|---|---|
| `พิมพ์สูตร เช่น L หรือ ceil(L / 1.333) + 1.` | สูตรว่าง |
| `"X" ไม่ใช่ค่าที่วัดได้ที่นี่ ใช้ …` | ใช้ตัวแปรหนึ่งในที่ระบุไว้ |
| `"X" ไม่ใช่ฟังก์ชันที่นี่ ใช้ ceil, floor, round, min, max, abs.` | ใช้ฟังก์ชันหนึ่งในนั้น |
| `"#" ใช้ในสูตรไม่ได้` | ลบอักขระนั้นออก (หน่วย `%`, `$` และ `=` ใช้ไม่ได้) |
| `ขาด ")"` / `มี ")" โดยไม่มี "("` | จับคู่วงเล็บให้ครบ |
| `ไม่มีค่าก่อน ")" เช่น max(1, ): ใส่ค่า` | เติมค่า |
| `สูตรจบเร็วเกินไป เช่น L *: เขียนให้จบ` | เขียนให้จบ |
| `ไม่คาดคิด "…" มีตัวดำเนินการขาดหรือไม่?` | สองค่าอยู่ติดกัน เช่น `2L`: เขียน `2 * L` |
| `ceil() รับค่าได้ 1 ค่า` | ให้จำนวนค่าที่ถูกต้องแก่ฟังก์ชัน |
| `round(x, digits) ต้องใช้จำนวนตำแหน่งทศนิยมเป็นจำนวนเต็มตั้งแต่ 0 ถึง 10` | ใช้จำนวนเต็มของตำแหน่งทศนิยม |
| `สูตรหารด้วยศูนย์` | โดยปกติ H เป็น 0: ตั้งความสูงหรือความลึกของรายการ |
| `สูตรไม่ให้ผลเป็นตัวเลข` | ผลลัพธ์ใหญ่เกินกว่าจะเป็นตัวเลข |
| `สูตรนั้นยาวเกินไป (ไม่เกิน 500 อักขระ)` | ทำให้สั้นลง |

## ปลอดภัยโดยการออกแบบ

สูตรทำได้เฉพาะการคำนวณเลขกับตัวแปรและฟังก์ชันข้างต้น สูตรไม่สามารถรันโค้ดหรืออ่านสิ่งอื่นได้ ดังนั้นสูตรในไฟล์โครงการที่ใครส่งมาให้จึงไม่เป็นอันตราย

TakeoffCraft သည် ဖွံ့ဖြိုးဆဲ ဖြစ်သည်။ ဤစာရင်းသည် လက်ရှိဗားရှင်းမလုပ်နိုင်သည့်အရာများနှင့် ယခုအချိန်တွင် အလုပ်ကို ပြီးအောင် လုပ်နိုင်သည့် နည်းလမ်းများ ဖြစ်သည်။

## တိုင်းတာခြင်း

| မတည်ဆောက်ရသေးသော အရာ | အစားထိုး၊ ယခု |
|---|---|
| run သို့မဟုတ် outline အလယ်တွင် အမှတ်ထည့်ခြင်း | အမှတ်ကို ဖျက်ပြီး ပြန်ဆွဲပါ။ |
| ဘောက်စ် (ဝင်းဒိုး) ဖြင့် ရွေးခြင်း | {{key:Shift}} + အမှတ်တစ်ခုချင်းစီကို နှိပ်ပါ၊ သို့မဟုတ် စာရွက်ပေါ်ရှိ အမှတ်အားလုံးအတွက် {{key:Mod+A}}။ ကြည့်ပါ [အမှတ်များကို ကူး၊ ကူးထည့်နှင့် ပွားခြင်း](topic:copy-paste)။ |
| ကူးထည့်ထားသော မိတ္တူကို လှည့်ခြင်း၊ ထင်ဟပ်ခြင်း သို့မဟုတ် စကေးပြန်ညှိခြင်း | တူညီသော စကေးနှင့် တူညီသော ဦးတည်ချက်ဖြင့် စာရွက်ပေါ်တွင် ကူးထည့်ပါ; ကျန်သည်များကို လက်ဖြင့် ဆွဲပါ။ |
| စကင်ဖတ်ထားသော စာရွက်မှ သို့မဟုတ် ဂရပ်ဖစ် စကေးဘားမှ စကေးဖတ်ခြင်း | preset ကို ရွေးပါ၊ သို့မဟုတ် ဘား၏ အရှည်ဖြင့် စံညှိပါ။ |
| စာရွက်တစ်ရွက်လျှင် စကေးတစ်ခုထက် ပိုများခြင်း (အသေးစိတ်ဧရိယာများ၊ ချဲ့ထားသော ပုံစံများ) | အစိတ်အပိုင်းကို စာရွက်၏ စကေးဖြင့် တိုင်းပါ၊ စာရွက်တွင် ချဲ့ထားသော စာရွက်ပါရှိလျှင် အသေးစိတ်ကို ၎င်း၏ကိုယ်ပိုင် စာရွက်ပေါ်တွင် takeoff လုပ်ပါ။ |

## ပစ္စည်းများနှင့် ဈေးနှုန်း

| မတည်ဆောက်ရသေးသော အရာ | အစားထိုး၊ ယခု |
|---|---|
| ပစ္စည်းတစ်ခု၏ အခြားအမျိုးအစား အမှတ်များကို သုံးသော assembly ဖော်မြူလာများ (အခန်းပစ္စည်း၏ တံခါးများကို ၎င်းထပ်၏ ဖော်မြူလာများတွင်) | ဖော်မြူလာများသည် အဓိကအမျိုးအစား၏ စုစုပေါင်းကို သုံးသည်; အခြားအမျိုးအစားများကို ၎င်းတို့ကိုယ်ပိုင် အတန်းများတွင် ဈေးသတ်မှတ်ပါ။ |
| run တစ်ခုချင်းစီအလိုက် တွက်ချက်သော assembly ဖော်မြူလာများ | ဖော်မြူလာများသည် ပစ္စည်း၏ စုစုပေါင်းကို သုံးသည်; run တစ်ခုချင်းစီ၏ အပိုများအတွက် `N` ကို သုံးပါ။ |
| အခြားပစ္စည်း၏ ပမာဏများကို သုံးသော ဖော်မြူလာများ | ထိုပစ္စည်းတွင် တိုင်းတာမှုကို ထပ်လုပ်ပါ၊ သို့မဟုတ် spreadsheet export တွင် တွက်ချက်ပါ။ |
| assembly အစိတ်အပိုင်းများပေါ်ရှိ အလုပ်သမားအဖွဲ့များ၊ သို့မဟုတ် ၈ နာရီမဟုတ်သော အလုပ်ရက် | အဖွဲ့ကို ပစ္စည်းသို့ ပေးပါ; အခြားရက်ရှည်အတွက် crew-days ကို crew-hours ÷ သင့်အလုပ်ရက် ဖြင့် ဖတ်ပါ။ |
| မှတ်စု၊ တိမ်ပုံနှင့် အရောင်ခြယ်မှုများမှလွဲ၍ အခြား markup များ (မြှားများ၊ အတိုင်းအတာများ၊ တံဆိပ်များ) သို့မဟုတ် မှတ်စုတစ်ခုပေါ်ရှိ ပြန်ကြားချက်များ | မှတ်စု၏ စာသားထဲတွင် ရေးပါ; ပြီးစီးသည်နှင့်အမျှ ၎င်း၏ အခြေအနေကို ပြောင်းပါ။ |
| အဖွဲ့တစ်ခုမှ မျှဝေသော ဈေးနှုန်း စာကြည့်တိုက်၊ သို့မဟုတ် သင့်အကောင့်တွင် သိမ်းထားသော စာကြည့်တိုက် | စာကြည့်တိုက်ကို ဤ browser တွင် သိမ်းထားသည်: CSV အဖြစ် ထုတ်ပို့ပြီး အခြားကွန်ပျူတာတွင် သွင်းပါ။ |
| အလုပ်လုပ်နေသော ခန့်မှန်းသူများက ပြန်လည်စစ်ဆေးထားသော trade packs | pack တိုင်းသည် အစမ်းစတင်ရန်ဖြစ်သည်: ဈေးမတင်မီ ၎င်း၏ ယူဆချက်များကို သင့်အလုပ်နှင့် သင့်ထုတ်ကုန်များဖြင့် စစ်ဆေးပါ။ ကြည့်ပါ [ကုန်သွယ်မှု ပက်ခ်များ](topic:trade-packs)။ |
| trade packs ထဲရှိ ဈေးနှုန်းများ | packs များတွင် assemblies များသာ ပါသည်: သင့်ကိုယ်ပိုင် နှုန်းများကို သတ်မှတ်ပါ၊ သို့မဟုတ် သင့်ဈေးစာရင်းကို CSV အဖြစ် သွင်းပါ။ |
| takeoff ကို အမည်ပြောင်းခြင်း | အမည်သည် ပထမ PDF မှ ရရှိသည်; ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်များကို အမည်ပြောင်းပါ။ |
| စာရွက်များကို လက်ဖြင့် အမည်ပေးခြင်း | စာရွက်များကို PDF ၏ page label များမှ အမည်ပေးသည်; ဖိုင်အမည်နှင့် စာမျက်နှာဖြင့် ရှာပါ။ |

## ပုံဆွဲများ (DWG နှင့် DXF)

| မတည်ဆောက်ရသေးသော အရာ | အစားထိုး၊ ယခု |
|---|---|
| ပုံဆွဲ၏ စာရွက်များပေါ်ရှိ plot style ဇယားများ၊ ဘောပင်သတ်မှတ်ချက်များနှင့် CTB ဖိုင်များ | ပုံဆွဲကို အမည်းရောင် သို့မဟုတ် စက္ကူအတွက် မှိန်ထားသော အရောင်များဖြင့် ဆွဲသည်; မျဉ်းအထူများသည် ပုံဆွဲမှ ရရှိသည်။ |
| binary DXF သို့မဟုတ် AutoCAD 2000 ထက်ဟောင်းသော DWG ဖွင့်ခြင်း | ASCII DXF သို့မဟုတ် အသစ်သော DWG အဖြစ် သိမ်းပါ။ |
| တည်ရှိရာ ဖိုင်တွဲဖြင့် ချိတ်ဆက်ထားသော ပုံဆွဲ (xref) ကို ရှာခြင်း | ချိတ်ဆက်ထားသော ပုံဆွဲဖိုင်ကိုလည်း host နှင့်အတူ ဖွင့်ပါ: ၎င်းကို ဖွင့်ထားသော ဖိုင်များထဲတွင် ဖိုင်အမည်ဖြင့် ရှာတွေ့သည်။ |
| 3D polylines၊ meshes၊ solids နှင့် regions များကို တိုင်းတာခြင်း | layer နှင့် အမျိုးအစားအလိုက် ရေတွက်ပါ၊ သို့မဟုတ် Linear နှင့် Area ကိရိယာများဖြင့် plan view ကို တိုင်းပါ။ |
| Latin မဟုတ်သော စာလုံးပုံစံများဖြင့် ပုံဆွဲမှ စာသား marked PDF တွင် | Helvetica တွင် glyph မရှိသော အက္ခရာများကို marked PDF တွင် "?" အဖြစ် ပရင့်ထုတ်သည်; မျက်နှာပြင်ပေါ်ရှိ ပုံဆွဲကို မထိခိုက်ပါ။ |
| စာရွက်ဘားမှ ပုံဆွဲကို အခြား app သို့ လွှဲပြောင်းခြင်း | တူညီသော ဖိုင်ကို ထို app တွင် ဖွင့်ပါ။ |
| {{ui:PDF with the takeoff inside}} က PDF များအတွက် ပြုလုပ်သကဲ့သို့ takeoff ကို အတွင်းတွင် သယ်ဆောင်သော ပုံဆွဲ | {{ui:Save takeoff}}: `.takeoff.json` ကို ပြန်ဖွင့်လျှင် တူညီသော ပုံဆွဲပေါ်တွင် ပြန်ပေါ်ပြီး ၎င်း၏ အကြောင်းအရာဖြင့် တွေ့ရသည်။ |
| ပုံဆွဲတွင် ထည့်ထားသော PDF underlay များ၊ ပုံများနှင့် OLE object များကို ဆွဲခြင်း သို့မဟုတ် ရေတွက်ခြင်း | ပုံများကို ဘောင်တစ်ခုအဖြစ်သာ ပြသည်။ underlay PDF ကိုယ်တိုင်ကို စာရွက်အဖြစ် ဖွင့်ပါ။ |

## ဈေးတင်ခြင်း

| မတည်ဆောက်ရသေးသော အရာ | အစားထိုး၊ ယခု |
|---|---|
| ပို့ပြီးသား package သို့ ဖြည့်စွက်ချက်များ၊ award စာများ၊ bidder တစ်ဦးချင်းစီ လက်မှတ်ထိုးသော scope စာရွက် | package အသစ်ပို့ပြီး award ကို သင်ကိုယ်တိုင် ရေးပါ။ [ဈေးတင်ရန် package ပို့ခြင်း](topic:bid-invitations) တွင် ယခု ပါဝင်သည်များ ရှိသည်။ |
| မည်သည့်အကောင့်မှမဆို bid ဖိတ်ကြားချက်ပို့ခြင်း: စမ်းသပ်နေစဉ် ပြင်ပ bidder များသို့ အီးမေးလ်ကို CadCraft အဖွဲ့ ဖွင့်ပေးထားသော အကောင့်များမှလွဲ၍ ပိတ်ထားသည် | {{ui:Scope CSV}} ကို ဒေါင်းလုဒ်လုပ်ပြီး ကိုယ်တိုင် အီးမေးလ်ပို့ကာ bid များကို ရိုက်ထည့်ပါ။ |
| Studio ဝင်းဒိုးမှ bid packages ပို့ခြင်း | browser ရှိ TakeoffCraft မှ ပို့ပါ။ |
| ရွေးထားသော bid ဖြင့် alternate ၏ bid ဧရိယာကို ပြန်ဈေးသတ်မှတ်ခြင်း | Alternates နှင့် bid-area subtotal များသည် သင့်ကိုယ်ပိုင်ဈေးနှုန်းများကို သုံးသည်; alternate ကို လက်ဖြင့် ညှိပါ။ |
| subcontractor ၏ အာမခံ သို့မဟုတ် လိုင်စင်ရက် မကုန်ခင် အလိုအလျောက် သတိပေးချက်များ | ရက်စွဲကို ကျော်လွန်ပြီးသည် သို့မဟုတ် ရက် ၃၀ အတွင်းဖြစ်သည်နှင့် Subcontractors စာမျက်နှာတွင် အမှတ်အသားပြုသည်; ဖိတ်ကြားချိန်တွင် စစ်ပါ။ |

## စာရင်းဇယားများ

XLSX workbook ကို LibreOffice Calc တွင် စစ်ဆေးပြီးဖြစ်ပြီး စုစုပေါင်းတိုင်းကို TakeoffCraft နှင့် ဆင့်မပါ တူညီသော ဆင့်ကဲ တွက်ချက်ခဲ့သည်။ Excel တွင် မဖွင့်ရသေးပါ။ spreadsheet program က မမျှော်လင့်သည့်အရာကို ပြပါက CSV export တွင် တူညီသော ခန့်မှန်းချက်ကို ရိုးရိုး တန်ဖိုးများအဖြစ် ရှိသည်။

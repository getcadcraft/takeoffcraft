linear ပစ္စည်းသည် အရှည်ကို တိုင်းတာပါသည်။ run တစ်ခုစီသည် အမှတ်များ၏ ကွင်းဆက်တစ်ခု ဖြစ်သည်: ဖြောင့်သော အပိုင်းများနှင့် arc mode ကို ဖွင့်ထားသည့်အခါ arc များ။ ပစ္စည်းတစ်ခုတွင် ပုံစာရွက်အမျိုးမျိုးပေါ်တွင် run အရေအတွက် မည်မျှမဆို ရှိနိုင်ပါသည်။

မစတင်မီ: ပုံစာရွက်တွင် scale လိုအပ်သည် ([scale သတ်မှတ်ခြင်း](topic:set-the-scale)) နှင့် linear ပစ္စည်းတစ်ခု လိုအပ်သည် ([takeoff ပစ္စည်းများ ဖန်တီးခြင်း](topic:create-items))။

vector PDF တွင် သင့်နှိပ်ချက်များသည် ပုံ၏ ကိုယ်ပိုင်မျဉ်းများသို့ ကပ်ပါသည်: အစွန်း၊ အလယ်နှင့် ဖြတ်ကျော်မှုများ ([ပုံ၏ မျဉ်းများသို့ snap](topic:snap-to-the-drawing); {{key:F3}} က ပိတ်ပါသည်)။

## run တစ်ခု ဆွဲခြင်း

1. {{ui:ပစ္စည်းများ}} အောက်ရှိ linear ပစ္စည်းကို နှိပ်ပါ။
2. ကိရိယာဘားတွင် {{ui:မျဉ်း}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:L}} ကို နှိပ်ပါ။
3. run ၏ အစကို နှိပ်ပါ။
4. အောက်ရှိ ထောင့်တစ်ခုစီကို နှိပ်ပါ။
   status bar က "Length" (ယခုအထိ run၊ ညွှန်ပြကိရိယာအထိ) နှင့် "segment" (ဆွဲနေသော အပိုင်း) ကို ပေ နှင့် လက်မဖြင့် ပြပါသည်။
5. run ကို ပြီးဆုံးပါ: နောက်ဆုံးအမှတ်ကို နှစ်ချက်နှိပ်ပါ၊ {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် right-click လုပ်ပါ။
   run ကို ပစ္စည်း၏ အရောင်ဖြင့် ဆွဲပြီး ရွေးထားသော အမှတ်အသား ဖြစ်လာပါသည်။ {{ui:ပစ္စည်းများ}} စာရင်းနှင့် {{ui:ပမာဏများ}} ဇယားရှိ ပစ္စည်း၏ အရှည် တိုးလာပါသည်။

ကိရိယာသည် {{ui:မျဉ်း}} ပေါ်တွင် ဆက်ရှိနေသဖြင့် နောက် run ကို ချက်ချင်း စတင်နိုင်ပါသည်။ {{ui:ရွေးရန်}} သို့ ပြန်ရန် {{key:Esc}} ကို နှိပ်ပါ။

ဆွဲနေစဉ်:

- {{key:Backspace}} (သို့မဟုတ် {{key:Delete}}) က နောက်ဆုံးအမှတ်ကို ဖယ်ပါသည်။
- {{key:Esc}} က မပြီးသေးသော run ကို ပစ်ပစ်ပါသည်။
- ဆွဲခြင်းက ပုံစာရွက်ကို ရွှေ့ပြီး wheel က zoom လုပ်ပါသည်၊ အမှတ်မထည့်ဘဲ။

:::mac
Mac trackpad တွင် right-click သည် လက်ညှိုးနှစ်ချောင်းနှိပ်ခြင်း ဖြစ်သည် (System Settings အောက်ရှိ Trackpad တွင် secondary click ကို ဖွင့်ပါ)။ TakeoffCraft က secondary ခလုတ်ကိုသာ ဖတ်ပါသည်၊ ထို့ကြောင့် Control-click ကို ရိုးရိုးနှိပ်ခြင်းအဖြစ် ယူဆပြီး အမှတ်ထည့်နိုင်ပါသည်။ နှစ်ချက်နှိပ်ခြင်း သို့မဟုတ် {{key:Enter}} က အမြဲ ပြီးဆုံးစေပါသည်။
:::

:::touch
touch screen တွင် အမှတ်ချရန် တို့ပါ၊ ပုံကို ရွှေ့ရန် လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ၊ zoom လုပ်ရန် လက်နှစ်ချောင်းဖြင့် ညှပ်ပါ။ ပြီးဆုံးရန် ကြာကြာ ထိထားခြင်း၊ နှစ်ချက်တို့ခြင်း သို့မဟုတ် ပုံအောက်ရှိ bar ရှိ {{ui:ပြီးဆုံးရန်}} ကို ရွေးပါ ({{ui:နောက်}} က နောက်ဆုံးအမှတ်ကို ပြန်ယူပါသည်)။ [ပြဿနာရှာဖွေခြင်း](topic:troubleshooting#touch-screens) ကို ကြည့်ပါ။
:::

## 45° အဆင့်များဖြင့် ဖြောင့်သောမျဉ်းများ

အမှတ်ချနေစဉ် {{key:Shift}} ကို ကိုင်ထားပါ။ နောက်ဆုံးအမှတ်မှ အပိုင်းသည် အနီးဆုံး 0°, 45°, 90° သို့မဟုတ် 135° လမ်းကြောင်းသို့ snap လုပ်ပြီး ဆွဲခဲ့သော အရှည်ကို ထိန်းထားပါသည်။ status bar က သတိပေးပါသည်: "Shift snaps to 45°"။

arc mode တွင် ၎င်းသည် arc ဆုံးသည့်နေရာတွင် အကျုံးဝင်ပါသည်: arc ၏ chord သည် စသည့်နေရာမှ 45° အဆင့်များဖြင့် သွားပါသည်။ ကွေးပေါ်တွင် သင်နှိပ်သော အမှတ်ကို snap မလုပ်ပါ။

## Arc များနှင့် ကွေးနံရံများ

1. run ဆွဲနေစဉ် ကွေး စသည့်နေရာတွင် အမှတ်ချပါ။
2. arc mode ကို ဖွင့်ပါ: ကိရိယာဘားတွင် {{ui:အဝိုင်းကွေး}} ကို ရွေးပါ သို့မဟုတ် {{key:R}} ကို နှိပ်ပါ။ ခလုတ်သည် နှိပ်ထားဆဲ ဖြစ်နေပါသည်။
3. ကွေးပေါ်ရှိ မည်သည့်အမှတ်ကိုမဆို၊ အလယ်ဝန်းကျင်တွင် နှိပ်ပါ။
   status bar တွင် "(arc: click where it ends)" ထပ်ပေါ်လာပြီး အကြို ပြသမှုသည် သင့်အမှတ်ကို ဖြတ်၍ ကွေးပါသည်။
4. ကွေးဆုံးသည့်နေရာကို နှိပ်ပါ။
   arc ကို ထည့်ပါသည်။ ၎င်း၏အရှည်သည် တိကျသော arc အရှည်ဖြစ်ပြီး တိုတောင်းသော chord များစု မဟုတ်ပါ။
5. နောက်ကွေးပေါ်ရှိ အခြားအမှတ်နှင့် ၎င်း၏အဆုံးကို နှိပ်ပြီး arc များ ဆက်ဆွဲနိုင်ပါသည်၊ သို့မဟုတ် ဖြောင့်သော အပိုင်းများသို့ ပြန်ရန် {{key:R}} ကို နောက်တစ်ကြိမ် နှိပ်ပါ။

{{key:Backspace}} သို့မဟုတ် {{key:Esc}} က ကွေးပေါ်ရှိ ဆိုင်းငံ့အမှတ်ကို အရင်ဖယ်ပါသည်; ပုံမှန်အတိုင်း အမှတ်များကို ဖယ်ရန် ထပ်နှိပ်ပါ။

## အရှည်နှင့် coordinate များ ရိုက်ခြင်း

ပထမအမှတ်ပြီးနောက် နောက်အမှတ်ကို နှိပ်မည့်အစား ရိုက်ထည့်နိုင်ပါသည်။ ဂဏန်း၊ `@` သို့မဟုတ် `#` ကို ရိုက်ပါ: status bar တွင် သင်ရိုက်သည့်အရာဖြင့် {{ui:ရိုက်ထည့်ရန်}} ဘောက်စ် ဖွင့်ပါသည်။ အမှတ်ချရန် {{key:Enter}} ကို နှိပ်ပါ; ဘောက်စ်သည် နောက်တစ်ခုအတွက် ဖွင့်ထားပါသည်။

| ရိုက်ထည့်ချက် | နောက်အမှတ် ရောက်ရှိမည့်နေရာ |
|---|---|
| `12'6"` | နောက်ဆုံးအမှတ်မှ 12'-6" ညွှန်ပြကိရိယာဘက်သို့ (ဦးတည်ချက်ကို ညွှန်ပြပြီး အလျား ရိုက်ပါ) |
| `12'6"<45` | 12'-6" ကို 45° တွင်၊ မျက်နှာပြင်၏ ညာဘက်မှ နာရီလက်ပြန်ဆန့်ဘက် ရေတွက်ပါ (`<90` က အပေါ်၊ `<-90` က အောက်) |
| `@6',-4'` | နောက်ဆုံးအမှတ်မှ 6' ညာ နှင့် 4' အောက် |
| `6',4'` (သို့မဟုတ် `#6',4'`) | ဤ run ၏ ပထမအမှတ်မှ 6' ညာ နှင့် 4' အပေါ် |

အရှည်များကို TakeoffCraft တစ်လျှောက် ရိုက်သကဲ့သို့ ရိုက်ပါ ([ထည့်သွင်းပုံစံများ](topic:entry-formats)): `12'-6 1/2"`, `12.5` (ပေ), `30"`, `3.2 m`။ "ညာ" နှင့် "အပေါ်" သည် ပုံစာရွက်ကို မြင်ရသည့်အတိုင်း ဖြစ်ပြီး PDF စာမျက်နှာကို လှည့်ထားလျှင်လည်း ဖြစ်သည်။

ဗလာဘောက်စ်တွင် {{key:Enter}} က run ကို ပြီးဆုံးစေပြီး ပုံစာရွက်ပေါ်ရှိ {{key:Enter}} နှင့် တူပါသည်; {{key:Esc}} က ဘောက်စ်ကို ပိတ်ပြီး run ကို ဆက်ထားပါသည်။ ရိုက်ထည့်ထားသော အမှတ်များသည် နှိပ်ချက်များနှင့် အတူ စည်းမျဉ်းအတိုင်း ဖြစ်ပါသည်: နုတ်ခြင်း၊ arc များနှင့် area ပိတ်ခြင်း အားလုံး အလုပ်လုပ်ပါသည်။ တူညီသော ဘောက်စ်သည် {{ui:ဧရိယာ}} နှင့် {{ui:အပေါက်ဖောက်ရန်}} တွင်လည်း အလုပ်လုပ်ပါသည်; စက်ဝိုင်း၏ ဗဟိုပြီးနောက် ၎င်းသည် radius ကို ယူပါသည်။

## run ၏ အပိုင်းတစ်ခုကို နုတ်ခြင်း

တံခါး သို့မဟုတ် storefront ကို ဖြတ်သော နံရံ run ကို တိုက်ရိုက် ဆွဲနိုင်ပြီး နံရံကိုသာ ရေတွက်ပါသည်: ဖွင့်ထားသော နေရာကို ဖြတ်သော အပိုင်းများသည် **deduct** များ ဖြစ်သည်။ ၎င်းတို့ကို မျဉ်းထိုးပါးပါးဖြင့် ဆွဲပြီး မရေတွက်ပါ။

ဆွဲနေစဉ်:

1. ဖွင့်ထားသော နေရာ၏ အစတွင် အမှတ်ချပါ။
2. ကိရိယာဘားတွင် {{ui:နုတ်ရန်}} ကို ရွေးပါ သို့မဟုတ် {{key:E}} ကို နှိပ်ပါ။ ခလုတ်သည် နှိပ်ထားဆဲ ဖြစ်ပြီး status bar က နောက်အပိုင်းများ deduct ဖြစ်သည်ဟု ပြောပါသည်။
3. ဖွင့်ထားသော နေရာ၏ အဆုံးတွင် နှိပ်ပါ။ အပိုင်းကို မျဉ်းထိုးဖြင့် ဆွဲပြီး status bar ရှိ "Length" တွင် ထည့်မတွက်ပါ။
4. {{key:E}} ကို နောက်တစ်ကြိမ် နှိပ်ပြီး နံရံအတိုင်း ဆက်ဆွဲပါ။

ဆွဲပြီးနောက်: run ကို ရွေးပါ။ **Selected mark** အောက်တွင် အပိုင်းတစ်ခုစီတွင် {{ui:နုတ်ရန်}} ဘောက်စ် ရှိပါသည်: ထိုအပိုင်းကို နုတ်လိုလျှင် အမှန်ခြစ်ပါ၊ ပြန်ရေတွက်လိုလျှင် အမှန်ဖြုတ်ပါ။ ပြောင်းလဲမှုတစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်ပါသည်။

run တွင် အမြဲ ရေတွက်သော အပိုင်းအနည်းဆုံးတစ်ခု ကျန်ရှိနေပါသည်။ panel တွင် **Deducts** (နုတ်ထားသော အရှည်) နှင့် **Drawn** (run တစ်ခုလုံး) ကို ပြပါသည်; **Length**၊ ပစ္စည်း၏ ပမာဏ၊ နံရံဧရိယာနှင့် ကုန်ကျစရိတ်များသည် deduct မပါသော အရှည်ကို သုံးပါသည်။ 3D စစ်ဆေးမှု အမြင်သည် နံရံတွင် ကွက်လပ်ထားပြီး marked PDF က deduct များကို မျဉ်းထိုးဖြင့် ဆွဲပြီး ထုတ်ယူထားသော **Marks** စာရွက်တွင် ၎င်းတို့ကို စာရင်းပြုစုပါသည်။

run ၏ ထောင့်ကို ရွှေ့ခြင်းသည် deduct များကို ထိန်းပါသည်။ အမှတ်များ ထည့်ခြင်း သို့မဟုတ် ဖယ်ခြင်း (run ကို ပြန်ဆွဲခြင်းဖြင့်) သည် deduct မပါဘဲ စတင်ပါသည်။

## run ၏ အသေးစိတ်ကို ကြည့်ခြင်း

{{ui:ရွေးရန်}} ({{key:V}}) ကို ရွေးပြီး run ကို နှိပ်ပါ။ ညာဘက်ရှိ **Selected mark** က ပြသသည်များ:

- ၎င်းပိုင်သော ပစ္စည်း (run ကို ထိုနေရာသို့ ရွှေ့ရန် စာရင်းတွင် အခြား linear ပစ္စည်းကို ရွေးပါ)၊
- စာရွက်၊
- **Length** ပေနှင့် လက်မဖြင့်၊ နှင့် LF ဖြင့်၊
- **Segments** အရေအတွက်၊ နှင့် ပစ္စည်းတွင် အမြင့် ရှိသည့်အခါ **Wall area**၊
- အပိုင်းတစ်ခုစီ၏ အရှည်၊ arc များနောက်တွင် "(arc)" နှင့်၊ ၎င်း၏ {{ui:နုတ်ရန်}} ဘောက်စ်။

ပုံစာရွက်ပေါ်တွင် ရွေးထားသော run ၏ အပိုင်းတစ်ခုစီကို ၎င်း၏ အရှည်ဖြင့် အညွှန်းတပ်ပါသည်။

## run ကို ပြင်ခြင်း

- **အမှတ်တစ်ခု ရွှေ့ခြင်း**: run ကို ရွေးပြီး စတုရန်း ထောင့် handle တစ်ခုကို ဆွဲပါ။ ရွှေ့ထားသော အပိုင်းကို 45° အဆင့်များသို့ snap လုပ်ရန် {{key:Shift}} ကို ကိုင်ထားပါ။ arc တစ်ခုသည် ၎င်း၏ ကွေးကို ထိန်းထားပါသည်။
- **arc ကို ကွေးညွှတ်ခြင်း**: ရွေးထားသော run တွင် arc တစ်ခုစီ၏ အလယ်တွင် စက်ဝိုင်းပုံ handle တစ်ခု ပြပါသည်။ ၎င်းကို ဆွဲပါ: arc သည် သင်လွှတ်လိုက်သော နေရာကို ဖြတ်သွားပြီး ပိုကွေး၊ လျော့ကွေး သို့မဟုတ် တခြားဘက်သို့ ကွေးပါသည်။ ၎င်း၏ အဆုံးများကြား ဖြောင့်သောမျဉ်းပေါ်သို့ ဆွဲချလျှင် ဖြောင့်အပိုင်း ဖြစ်လာပါသည်။ {{key:Mod+Z}} က ပြန်ဖျက်ပါသည် ("Bend arc")။
- **run ကို ဖျက်ခြင်း**: ရွေးပြီး {{key:Delete}} ကို နှိပ်ပါ၊ ကိရိယာဘား၏ {{ui:နောက်ထပ်}} မီနူးရှိ {{ui:ဖျက်ရန်}} ကို ရွေးပါ၊ သို့မဟုတ် panel ရှိ {{ui:အမှတ်အသားကို ဖျက်ရန်}} ကို ရွေးပါ။
- **ပြန်ဖျက်ခြင်း**: {{key:Mod+Z}}; ပြန်လုပ်ရန် {{key:Mod+Y}}။

run ၏ အလယ်တွင် အမှတ်ထည့်ခြင်းကို ယခုအချိန်တွင် မလုပ်နိုင်သေးပါ။ run ကို ဖျက်ပြီး ပြန်ဆွဲပါ။

## နံရံဧရိယာ

linear ပစ္စည်းကို {{ui:အမြင့်}} ပေးပါ (ဥပမာ `9'-0"`)။ ထို့နောက် **Wall area (A)** = အရှည် × အမြင့် ကို SF (သို့မဟုတ် မက်ထရစ်ပစ္စည်းအတွက် m²) ဖြင့် ပြပါသည်၊ နံရံဧရိယာသည် spreadsheet ထုတ်ယူမှု၏ မှတ်စုကော်လံသို့ ရောက်ပါသည်။ ဘုတ်၊ ဆေး သို့မဟုတ် insulation အတွက် assembly များတွင် သုံးပါ: [Assembly နှင့် ပုံသေနည်းများ](topic:assemblies) ကို ကြည့်ပါ။

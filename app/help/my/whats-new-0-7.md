TakeoffCraft 0.6 နှင့် နှိုင်းယှဉ်ပါက 0.7 တွင် ပြောင်းလဲခဲ့သည်များ ဤသည်ဖြစ်သည်။ ပုံဆွဲများကို ယခုအတိုင်း ဖွင့်နိုင်ပြီး PDF သို့ အရင်ပလော့ထုတ်ရန် မလိုတော့ပါ၊ bid ပက်ကေ့ဂျ်ကို subcontractor များထံ ပို့ပြီး ဈေးနှုန်းပါသည့်အတိုင်း ပြန်ရနိုင်သည်။

## အသစ်

### DWG နှင့် DXF ပုံဆွဲများ

- **ပုံဆွဲကို စာရွက်များအဖြစ် ဖွင့်ပါ။** {{ui:ဖိုင်}} အုပ်စုရှိ {{ui:စီမံကိန်းများ ဖွင့်ရန်}} ({{key:Mod+O}}၊ သို့မဟုတ် ဖိုင်များကို ချပါ) က DWG နှင့် DXF ပုံဆွဲများကို PDF များနှင့်အတူ လက်ခံသည်။ model space နှင့် layout အားလုံးသည် {{ui:စာရွက်များ}} စာရင်းတွင် စာရွက်များဖြစ်လာပြီး takeoff တစ်ခုသည် ပုံဆွဲနှင့် PDF များကို အတူတကွ ဖုံးလွှမ်းနိုင်သည်။ ဘာမျှ မတင်ပါ။ [DWG သို့မဟုတ် DXF ပုံဆွဲကို ဖွင့်ရန်](topic:open-a-drawing) ကို ကြည့်ပါ။
- **scale သည် ပုံဆွဲမှ လာသည်။** layout တစ်ခုသည် ၎င်း၏ အကြီးဆုံး viewport ၏ scale ဖြင့် စတင်သည်၊ preset ဖြစ်ပါက preset အမည်ဖြင့် ပေးထားသည်၊ ဥပမာ 1/2" = 1'-0"။ Model သည် ပုံဆွဲ၏ ယူနစ်ဖြင့် စတင်သည်။ ယူနစ်မရှိသော ပုံဆွဲသည် သင် စံညှိသည်အထိ scale မရှိ ဟု ပြသည်။ {{ui:စံညှိရန်}}၊ {{ui:စစ်ဆေးရန်}} နှင့် {{ui:ကြိုတင်သတ်မှတ်ချက်}} က ဆက်လက်အနိုင်ရသည်။ [scale](topic:open-a-drawing#the-scale) ကို ကြည့်ပါ။
- **Layers နှင့် linked drawings။** sheet bar ရှိ {{ui:Layer များ}} က ပုံဆွဲ၏ layers များကို ပြ သို့မဟုတ် ဝှက်ပေးသည်။ ဖိုင်က ပိတ်ထားသော သို့မဟုတ် freeze လုပ်ထားသော layers များသည် ဝှက်ထားစတင်ပြီး သင်ရွေးမှသာ ရေတွက်သည်။ host ဘေးတွင် ဖွင့်ထားသော linked drawing (xref) ကို ထည့်သွင်းထားရာနေရာတွင် ဆွဲပြီး ရေတွက်သည်; ဖွင့်မထားသေးသရွေ့ status bar က ပျောက်နေသည်ကို ပြောသည်။ [Layers](topic:open-a-drawing#layers) ကို ကြည့်ပါ။
- **marked PDF သည် ပုံဆွဲမှ အလုပ်လုပ်သည်။** {{ui:ထုတ်ယူရန်}} › {{ui:အမှတ်အသားပါသော PDF}} က ပုံဆွဲ၏ marked စာရွက်များကို PDF အဖြစ် ဦးစွာ ဆွဲပေးသည်၊ ထို့ကြောင့် မိတ္တူတွင် သင်၏ အမှတ်အသားများနှင့် legend ပါဝင်ပြီး ပလော့ထုတ်ရန် အဆင့်မလိုပါ။ ပုံဆွဲကို အမဲရောင် သို့မဟုတ် ပုံဆွဲ၏ အရောင်များဖြင့် ဆွဲသည်၊ plot style table မပါဘဲ။ [marked PDF](topic:export-estimate#a-marked-pdf) ကို ကြည့်ပါ။

### ပုံဆွဲမှ တိကျသော ရေတွက်မှုများနှင့် အလျားများ

- **ပုံဆွဲက ရှိသည်ဟု ပြောသည်အတိုင်း ရေတွက်ပါ။** sheet bar ရှိ {{ui:CAD ရေတွက်}} က block ကို အမည်ဖြင့်၊ layer တစ်ခုပေါ်ရှိ အမျိုးအစား တစ်မျိုးလုံးကို၊ သို့မဟုတ် စာသား သို့မဟုတ် attribute တန်ဖိုးကို ရေတွက်သည် (nested blocks၊ dynamic block states နှင့် block arrays အပါအဝင်)။ စာရွက်ပြသသည့်အရာ သို့မဟုတ် ပုံဆွဲတစ်ခုလုံးကို တစ်ကြိမ် ရေတွက်သည်။ အမှတ်အသားများ ထည့်ခြင်းသည် undo အဆင့်တစ်ခု ဖြစ်ပြီး ထပ်ရေတွက်ပါက အသစ်သာ ထည့်သည်။ {{ui:အလိုအလျောက်ရေတွက်}} သည် PDF များနှင့် block မဟုတ်သော သင်္ကေတများအတွက် ဆက်ရှိသည်။ [ပုံဆွဲမှ ရေတွက်ရန်](topic:count-from-a-drawing) ကို ကြည့်ပါ။
- **ပုံဆွဲ၏ မိမိ လိုင်းများမှ တိုင်းတာပါ။** {{ui:ပုံဆွဲမှ တိုင်းတာရန်}} က သင် click သို့မဟုတ် window ဖြင့် ရွေးသော လိုင်းများ၊ arc များ၊ polyline များ၊ စက်ဝိုင်းများ၊ hatch များနှင့် solid များကို linear သို့မဟုတ် area item ၏ အမှတ်အသားများအဖြစ် ယူသည်။ Arc၊ bulge နှင့် hatch ၏ အပေါက်များသည် တိကျစွာ ထွက်ပေါ်သည်; ellipse နှင့် spline များကို သေးငယ်သော လိုင်းခွဲများဖြင့် တိုင်းပြီး ဘားက ထိုသို့ ပြောသည်။ [ပုံဆွဲမှ တိုင်းတာရန်](topic:measure-from-a-drawing) ကို ကြည့်ပါ။

### Bid များ

- **subcontractor ၏ bid ကို ပက်ကေ့ဂျ်၏ ဈေးနှုန်းအဖြစ် သုံးပါ။** {{ui:ထုတ်ယူရန်}} › {{ui:ဈေးနှုန်းအထုပ်များနှင့် ညှိခြင်း…}} တွင် bid တစ်ခုပေါ်ရှိ {{ui:သုံးရန်}} ကို ရွေးပါ။ ပက်ကေ့ဂျ်၏ items များသည် ပမာဏအဖြစ် ဆက်ရှိသည်၊ **ရွေးထားသော bid** တစ်ကြောင်းက ဈေးနှုန်းကို ဆောင်သည်၊ bid က ချန်ထားသော items များသည် သင့်ကိုယ်ပိုင်ကုန်ကျစရိတ်ဖြင့် ဆက်ရှိသည်၊ နှင့် overhead၊ profit နှင့် bond တို့ကို ၎င်းတွင် အသုံးပြုသည်။ bid ပြောင်းခြင်းသည် undo အဆင့်တစ်ခု; workbook နှင့် bid အကျဉ်းချုပ်တွင်လည်း ပါဝင်သည်။ [bid ကို ပက်ကေ့ဂျ်၏ ဈေးနှုန်းအဖြစ် သုံးရန်](topic:bid-leveling#use-a-bid-as-the-packages-price) ကို ကြည့်ပါ။
- **bid ပို့ခြင်း။** ပက်ကေ့ဂျ်အောက်ရှိ {{ui:ဈေးနှုန်းအတွက် ပို့ရန်…}} က subcontractor တစ်ဦးချင်းစီကို အကောင့်မလိုသော စာမျက်နှာ link တစ်ခု အီးမေးလ်ဖြင့် ပို့သည်: scope နှင့် စာရွက်များကို PDF အဖြစ် မြင်ရသည်၊ လိုင်းတစ်ခုချင်းစီတွင် ဈေးနှုန်း ရိုက်နိုင်သည် သို့မဟုတ် မပါဝင်ဟု အမှတ်အသားတပ်နိုင်သည်၊ မှတ်ချက်များနှင့် ဖိုင် သုံးခုအထိ ထည့်နိုင်သည်၊ သို့မဟုတ် ငြင်းပယ်နိုင်သည်။ {{ui:ဈေးနှုန်းများ ရယူရန်}} က ပြန်လာသည်များကို leveling စာရွက်ထဲ ဆွဲသွင်းပြီး **web** ဟု အမှတ်အသားတပ်သည်။ ပို့ခြင်းကို CadCraft အဖွဲ့က စမ်းသပ်နေစဉ် ဖွင့်ပေးထားသော အကောင့်များအတွက်သာ ဖွင့်ထားသည် (အောက်တွင် ကြည့်ပါ)။ [bid ပို့ရန်](topic:bid-invitations) ကို ကြည့်ပါ။
- **ပိတ်ထားပြီး ဖွင့်သည့်အချိန်အထိ။** သင် သတ်မှတ်သော ဖွင့်သည့်အချိန်အထိ ဈေးနှုန်းများကို ပိတ်ထားနိုင်သည်: ထိုအချိန်အထိ သင်အပါအဝင် ဘယ်သူမျှ ဈေးနှုန်းမမြင်ရပါ။ ဖွင့်ချိန်တွင် bid အားလုံး တစ်ပြိုင်နက် ပေါ်လာပြီး ရက်ကန့်သတ်ပြီးနောက် ရောက်သော bid ကို နောက်ကျသည်ဟု အမှတ်အသားတပ်သည်။ [ပိတ်ထားသော bid များနှင့် ဖွင့်ခြင်း](topic:bid-invitations#sealed-bids-and-the-opening) ကို ကြည့်ပါ။
- **subcontractor မှတ်တမ်းများ။** getcadcraft.com ရှိ သင့်အကောင့်က ကုမ္ပဏီတစ်ခုချင်းစီ၏ ဆက်သွယ်ရန်များ၊ အလုပ်အမျိုးအစားများ၊ အရည်အချင်းဖြေဆိုချက်များ၊ အာမခံနှင့် လိုင်စင် ရက်စွဲများ (ကုန်သွားပြီး သို့မဟုတ် ရက် ၃၀ အတွင်းဖြစ်ပါက အမှတ်အသား) ကို ၎င်းတို့၏ ယခင် bid များနှင့်အတူ သိမ်းထားသည်။ CSV အဖြစ် ထည့်သွင်းနိုင်ပြီး ထုတ်ယူနိုင်သည်၊ ပက်ကေ့ဂျ် ပို့သည့်အခါ ရွေးနိုင်သည်။ [ဝက်ဘ်ဆိုက်တွင်](topic:bid-invitations#on-the-website) ကို ကြည့်ပါ။

### AI အကူအညီပေးသူများ

- **အကူအညီပေးသူများက takeoff ထဲသို့ ထည့်နိုင်သည်။** **တည်းဖြတ်ရန်** အမှန်ခြစ်ထားသောအခါ သင်၏ကိုယ်ပိုင် အကူအညီပေးသူက items (`items_add`) နှင့် စာရွက်ပေါ်ရှိ runs၊ areas နှင့် counts (`marks_add`; အလျားနှင့် ဧရိယာများကို scale ရှိသော စာရွက်တွင်သာ) ထည့်နိုင်သည်၊ ခေါ်ဆိုမှုတစ်ခုစီသည် undo အဆင့်တစ်ခု။
- **ပုံဆွဲများအတွက် အကူအညီပေးသူ ကိရိယာများ။** ဖွင့်ထားသော DWG သို့မဟုတ် DXF ပေါ်တွင် အကူအညီပေးသူသည် ၎င်း၏ စာရွက်များနှင့် ရေတွက်နိုင်သည်များကို စာရင်းပြုနိုင်သည်၊ တိကျစွာ ရေတွက်နိုင်သည်၊ ရေတွက်အမှတ်အသားများ ထည့်နိုင်သည်၊ နှင့် ပုံဆွဲ၏ ဂျီသြမေတြီမှ တိုင်းတာနိုင်သည်။ TakeoffCraft ဖွင့်မထားဘဲ CadCraft MCP server သည် ပုံဆွဲကို takeoff အသစ်အဖြစ် ဖွင့်ပြီး သိမ်းပေးနိုင်သည်၊ `cadcraft count` က command line မှ ရေတွက်သည်။ [အကူအညီပေးသူ တောင်းဆိုနိုင်သည်များ](topic:use-with-ai-assistants#what-an-assistant-can-ask-for) ကို ကြည့်ပါ။

### USD

- **3D check view ကို USD အဖြစ်။** 3D check view ရှိ {{ui:GLB}} ဘေးရှိ {{ui:USD ပက်ကေ့ဂျ် (.usdz)}} က wall၊ slab၊ plate၊ count post နှင့် run တိုင်းကို ကိုယ်ပိုင် object အဖြစ် ရေးသည်; item အမည်ဖြင့် အမည်ပေးပြီး ပမာဏကို မီတာဖြင့် ဆောင်သည်။ အကူအညီပေးသူက ၎င်းကိုလည်း ထုတ်ယူနိုင်သည် (`usd_export`)။ [3D check view ကို USD အဖြစ် ထုတ်ယူရန်](topic:usd) ကို ကြည့်ပါ။

## app အားလုံးတွင်

- **ယူနစ်များ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ယူနစ်များ}} တွင် အလျား၊ ဧရိယာ၊ ထုထည်၊ angle နှင့် slope အတွက် စာရင်းတစ်ခုစီ ရှိသည်၊ ယူနစ်အသီးသီး၏ သတ်မှတ်ချက်များက ပေးသော အရွယ်အစားအတိအကျဖြင့် (US survey foot သည် ကိုယ်ပိုင် ယူနစ်ဖြစ်သည်)။ သင်မသုံးသော ယူနစ်များကို ပိတ်လိုက်ပါက ယူနစ်စာရင်းမှ ထွက်သွားပြီး၊ တစ်ခုကို ကြယ်ပွင့်ပေးပါက အသစ်များက ၎င်းဖြင့် စတင်သည်။ ဖိုင်တစ်ခုက အမြဲ ၎င်း၏ကိုယ်ပိုင် ယူနစ်ကို ထိန်းထားသည်။ TakeoffCraft တွင် item ၏ {{ui:ယူနစ်}} စာရင်းများက ခလုတ်များကို လိုက်ပါသည်၊ item အသစ်သည် ကြယ်ပွင့်ပေးထားသော အလျား သို့မဟုတ် ဧရိယာယူနစ်ဖြင့် စတင်သည်၊ roofing squares (SQ)၊ acre နှင့် hectare တို့သည် ဧရိယာယူနစ်အသစ်များဖြစ်သည်၊ အလျားအကွက်သည် မည်သည့်ယူနစ်၏ အမှတ်အသားကိုမဆို လက်ခံသည်၊ ဥပမာ `3 yd`။ [ယူနစ်များ၊ ရိုက်ထည့်သော တန်ဖိုးများနှင့် ယူနစ်စာရင်းများ](common:unit-lists) ကို ကြည့်ပါ။
- **ပိုသိပ်သော layout နှင့် ပိတ်ထားနိုင်သည့် panel များ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:အပြင်အဆင် သိပ်သည်းမှု}} › {{ui:ကျစ်လစ်သော}} က မျက်နှာပြင်ပေါ် ပိုထည့်ပေးသည် (touch screen နှင့် ဖုန်းများသည် ၎င်းတို့၏ ကြီးသော ခလုတ်များကို ဆက်ထားသည်)။ side panel တစ်ခုစီတွင် ပါးလွှာသော title bar ရှိသည်: ၎င်းကို ဆွဲ၍ panel ကို dock သို့မဟုတ် float လုပ်နိုင်သည်၊ အခြား panel ၏ bar ပေါ် ချ၍ frame တစ်ခုတည်းကို tab များအဖြစ် မျှဝေနိုင်သည်၊ edge သို့ ပိတ်ရန် pin လုပ်နိုင်သည်၊ သို့မဟုတ် ဝှက်ပြီး edge မှ ပြန်ခေါ်နိုင်သည်။ [panel များကို စီစဉ်ရန်](common:arrange-panels#make-the-layout-denser) ကို ကြည့်ပါ။
- **Dialog များ ရွှေ့နိုင်သည်။** dialog ကို title bar ဖြင့် ဆွဲ၍ ပုံဆွဲနှင့် မတိုက်အောင် ရွှေ့နိုင်သည်; ထားခဲ့သည့်နေရာသို့ ပြန်ရောက်သည်။ title bar ကို နှစ်ချက်နှိပ်ပါက ပြန် အလယ်တွင် ထားသည်။ [dialog ရွှေ့ရန်](common:arrange-panels#move-a-dialog) ကို ကြည့်ပါ။
- **AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ။** သင်၏ကိုယ်ပိုင် အကူအညီပေးသူအတွက် ပြည့်စုံသော တောင်းဆိုချက် ဆယ်ခု (ပုံဆွဲကို သပ်ရပ်အောင်လုပ်ခြင်း၊ စာရွက်အစုကို plot လုပ်ခြင်း၊ ပုံဆွဲများ စစ်ဆေးခြင်း၊ model အကြောင်း မေးခြင်း၊ takeoff စုစုပေါင်းတွက်ခြင်း၊ အစိတ်အပိုင်း ကွဲပြားမှု စမ်းခြင်း…) တစ်ခုချင်းစီ၏ ခေါ်ဆိုသည့် ကိရိယာများနှင့် လိုအပ်သည့် ခွင့်ပြုချက်များ၊ နှင့် ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ပြန်ဖွင့်ထားသည်။ app များတွင် AI မပါပါ။ [AI အကူအညီပေးသူများအတွက် နည်းလမ်းများ](common:assistants-recipes) ကို ကြည့်ပါ။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ဘာသာစကား}} တွင် အသစ်ဖြစ်သည်။ ၎င်းနှင့် **Português (Brasil)**၊ **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် app များ၏ စကားလုံးအားလုံး ယခုရှိပြီးဖြစ်သည်၊ မူကြမ်းအဖြစ်၊ ဇာတိသုံးစွဲသူက မစစ်ဆေးရသေးပါ။ အကူအညီ အကြောင်းအရာများသည် အင်္ဂလိပ်ဘာသာဖြင့်သာ ရှိသည်။
- **CadCraft Studio** သည် update စစ်ဆေးမှု မအောင်မြင်ခဲ့ရသည့် အကြောင်းကို ပြသည် (သင့်စနစ်အတွက် ဖိုင် မရှိသေး၊ network မရှိ၊ signature မှား) "Done" ဟုသာ မပြဘဲ၊ သင်ပိတ်ထားသော အသစ်ရှိသည်များ ကတ်ကို ဗားရှင်းအသစ်မရှိမချင်း ပြန်မပြတော့ပါ။

## ဤဗားရှင်းတွင် မပါသေးသည်များ

- **0.7 ကို code-sign မလုပ်ထားပါ။** Signing နှင့် Microsoft Store package ကို certificate validation မရောက်သေးသောကြောင့် 0.8 သို့ ရွှေ့ထားသည်။ getcadcraft.com/download ရှိ ဖိုင်တစ်ခုစီ၏ ဘေးရှိ SHA-256 ကို စစ်ဆေးပါ။ Windows တွင် SmartScreen က installer ကို ရပ်ပါက {{ui:နောက်ထပ် အချက်အလက်}} ကို ရွေးပြီး {{ui:မည်သို့ပင်ဖြစ်စေ ဆက်လုပ်ရန်}} ကို ရွေးပါ။ Mac တွင် ပထမအကြိမ် CadCraft Studio ကို right-click ပြီး {{ui:ဖွင့်ရန်}} ကို ရွေးပါ။ CadCraft Studio သည် app store တွင် မရှိသေးပါ၊ iPad သို့မဟုတ် iPhone build လည်း မရှိသေးပါ။
- {{ui:ယူနစ်များ}} ရှိ angle နှင့် slope စာရင်းများကို သိမ်းထားသည်၊ သို့သော် မည်သည့်အကွက်မျှ ဖတ်ခြင်း မရှိသေးပါ။
- **Bid ဖိတ်ကြားချက်များကို အကောင့်အများစုအတွက် ပိတ်ထားသည်။** စမ်းသပ်နေစဉ်၊ အပြင်ဘက် bidder များထံ စာပို့ခြင်းကို CadCraft အဖွဲ့က ဖွင့်ပေးထားသော အကောင့်များမှသာ ထွက်သည်။ ပို့ပြီးသား ဖိတ်ကြားချက်တိုင်း၏ bidder စာမျက်နှာများ အလုပ်လုပ်ဆဲဖြစ်သည်။ အခြားသူများ: {{ui:Scope CSV}} ကို ဒေါင်းလုဒ်လုပ်ပြီး ကိုယ်တိုင် အီးမေးလ်ပို့ကာ bid များကို ရိုက်ထည့်ပါ။
- CadCraft Studio window သည် bid ဖိတ်ကြားချက်များ မပို့နိုင်သေးပါ: browser တွင် TakeoffCraft သုံးရန် ပြောပါသည်။ ပို့ထားသော တောင်းဆိုချက်များရှိ takeoff ဖွင့်ခြင်း၊ leveling နှင့် bid ရွေးခြင်းတို့ Studio တွင် အလုပ်လုပ်သည်။
- Addenda၊ award letters၊ bidder တစ်ဦးစီ လက်မှတ်ထိုးသော scope စာရွက်နှင့် အာမခံရက် မကုန်ခင် အလိုအလျောက် သတိပေးချက်များကို မတည်ဆောက်ရသေးပါ။ ရွေးထားသော bid သည် alternate ၏ bid ဧရိယာကို ဈေးနှုန်းပြန်မသတ်မှတ်ပါ။
- ပုံဆွဲများ: plot style table နှင့် CTB ဖိုင်များကို အသုံးမပြုပါ၊ binary DXF ကို ငြင်းပယ်သည် (ASCII DXF သို့မဟုတ် DWG အဖြစ် သိမ်းပါ)၊ linked drawing များကို ဖွင့်ထားသော ဖိုင်များထဲတွင် ဖိုင်အမည်ဖြင့်သာ ရှာတွေ့သည်၊ ပုံဆွဲထဲရှိ PDF underlay၊ ပုံများနှင့် OLE object များကို မဆွဲ သို့မဟုတ် မရေတွက်ပါ။ ရေတွက်မှုနှင့် scale များကို နမူနာပုံဆွဲများပေါ်တွင် စစ်ဆေးပြီးပါပြီ၊ သို့သော် ၎င်းကို ဖန်တီးခဲ့သော program ဖြင့် ဖွင့်ထားသည့် အမှန်တကယ် အလုပ်မှ ပုံဆွဲများပေါ်တွင် မစစ်ရသေးပါ။
- အကူအညီပေးသူက items နှင့် အမှတ်အသားများ ထည့်နိုင်သော်လည်း ရှိပြီးသား အမှတ်အသားများကို ရွှေ့၊ ပြောင်း သို့မဟုတ် ဖျက်၍မရပါ။

ကျန်အရာအားလုံးကို [အခုထိ မတည်ဆောက်ရသေးသည်များ](topic:not-built-yet) တွင် ကြည့်ပါ။

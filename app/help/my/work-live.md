## ဤအကြောင်းကို သင်ယူရမည်

takeoff တစ်ခုသည် လူများစွာ တစ်ပြိုင်နက် job တစ်ခုကို တိုင်းနေစဉ် ဘာဖြစ်သည်ကို။ CadCraft Studio သည် Live TeamWork session ကို စတင်ပြီး ဝင်ရောက်သည် (live မျှဝေရန်၊ ဝင်ရောက်ရန်); ဤစာမျက်နှာသည် takeoff ကိုယ်တိုင်အကြောင်း ဖြစ်သည်။

## အားလုံး တစ်ပြိုင်နက် တိုင်းခြင်း

ဝင်ရောက်သူ အားလုံးထံ host ၏ PDF များ ရောက်ရှိသည်။ items ထည့်ပါ၊ run၊ area နှင့် count များကို တိုင်းပါ၊ scale နှင့် ဈေးနှုန်းများကို ပုံမှန်အတိုင်း သတ်မှတ်ပါ။ သင့်ကိုယ်ပိုင် အမှတ်အသားများ ချက်ချင်းပေါ်သည်; အခြားသူများ၏ အမှတ်အသားများ ခဏအကြာတွင် ပေါ်လာသည်။

- **စုစုပေါင်းများ အားလုံးအတွက် တူညီသည်။** ဝင်းဒိုးတိုင်းသည် အမှတ်အသားများမှ ပမာဏများနှင့် ခန့်မှန်းချက်ကို ပြန်တွက်သည်၊ ထို့ကြောင့် တစ်စုံတစ်ဦး၏ စုစုပေါင်းများ လွဲမသွားနိုင်ပါ။
- **လူနှစ်ဦးသည် item တစ်ခု သို့မဟုတ် အမှတ်အသားတစ်ခုကို ပြောင်းသည်:** မတူသော အရာနှစ်ခုစလုံး ထိန်းထားသည်; တူသော အရာသည် နောက်ပြောင်းလဲမှုသို့ သွားသည်။
- **လူတစ်ဦး ဖျက်လိုက်သော item ပေါ်ရှိ အမှတ်အသား** ကို ပြန်ဖျက်ပြီး status bar က အကြောင်းပြောသည်။
- လူတိုင်း၏ item အသစ်များနှင့် အမှတ်အသားအသစ်များသည် ကိုယ်ပိုင် နံပါတ်ရသည်၊ ထို့ကြောင့် လူနှစ်ဦး တူတူနံပါတ် မဖြစ်ပါ။

## တစ်ဦးကိုတစ်ဦး မြင်ခြင်း

Session ရှိ လူတိုင်းတွင် ကိုယ်ပိုင် အရောင် ရှိသည်။ ကြည့်နေသော စာရွက်ပေါ်တွင် လူတစ်ဦးစီ၏ pointer ကို ၎င်းတို့ အရောင်ဖြင့် မြား အနေဖြင့် မြင်ရပြီး ၎င်းတို့ အမည် ဘေးတွင်ရှိသည်၊ ရွေးထားသော အမှတ်အသားများ ပတ်လည်တွင် ၎င်းတို့အရောင်ဖြင့် အစက်မျဉ်ဘောင် ရှိသည်။ အခြား စာရွက်ပေါ်ရှိ လူများကို view ၏ ညာဘက်ထိပ်တွင် ထိုစာရွက်၏ အမည်ဖြင့် စာရင်းပြုသည်။

Pointer၊ အမည်နှင့် ရွေးချယ်မှုများသည် session အတွက်သာ ဖြစ်သည်: ဖိုင်တွင် ဘယ်တော့မျှ မသိမ်းပါ၊ မည်သူ၏ undo တွင်မျှ မဝင်ပါ။ ၎င်းတို့သည် လူတစ်ဦးစီ ရှိသည့်နေရာသို့ ချောမွေ့စွာ ရွေ့သွားသည်၊ ထို့ကြောင့် နှေးသော connection တွင်လည်း ချောမွေ့နေသည်။

## Undo က သင့်ကိုယ်ပိုင် အလုပ်ကိုသာ ပြန်ဖျက်သည်

{{key:Mod+Z}} သည် သင့်ကိုယ်ပိုင် နောက်ဆုံးပြောင်းလဲမှုကို ပြန်ဖျက်ပြီး အခြားသူများ၏ အရာကို မထိပါ။ နောက်ပိုင်း တူညီသော အရာကို တစ်စုံတစ်ဦး ပြောင်းလဲခဲ့လျှင် တစ်ခုမျှ ပြန်မဖျက်ပါ၊ status bar က ဘယ်သူဖြစ်ကြောင်း ပြောသည်။

## browser မှ ဝင်ရောက်ခြင်း

Studio မရှိသော အဖွဲ့ဝင်တစ်ဦးသည် host ၏ code အောက်ရှိ ပုံကို network တူတူရှိ ဖုန်း၊ တက်ဘလက် သို့မဟုတ် ကွန်ပျူတာဖြင့် scan လုပ်နိုင်သည်။ TakeoffCraft သည် browser တွင် ဖွင့်ပြီး host က ခွင့်ပြုသည်နှင့် host ၏ takeoff နှင့် PDF များဖြင့် ဖြည့်သည်။ invite link သည် အခြား network မှ ဝင်ရောက်စေနိုင်သည်: host တွင် app အတွက် Team Cloud Plan seat လိုအပ်သည်၊ အခြားသူများ အခမဲ့ ဝင်ရောက်သည်၊ link သည် host ၏ session ဖွင့်နေချိန်တွင်သာ အလုပ်လုပ်သည်။

## session ပြီးဆုံးချိန်

host သာ takeoff ကို သိမ်းသည်။ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားသည်: ထိန်းထားလိုပါက သိမ်းပါ။

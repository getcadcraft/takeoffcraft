## ဤအကြောင်းကို သင်ယူရမည်

AI အကူအညီပေးသူ (သို့မဟုတ် သင်ရေးထားသော script) ကို TakeoffCraft နှင့် အလုပ်လုပ်စေပုံနှင့် ၎င်းက ထိရောက်ခွင့်ရှိသည့်အရာကို ဆုံးဖြတ်ပုံ။

TakeoffCraft တွင် ကိုယ်ပိုင် AI မရှိပါ၊ မည်သည့်နေရာသို့မျှ ဘာမျှ မပို့ပါ။ အကူအညီပေးသူကို သင်ကိုယ်တိုင် ယူလာရပါမည်- Model Context Protocol (MCP) ကို နားလည်သည့် မည်သည့် program မဆို ဖြစ်နိုင်သည်။ TakeoffCraft က ကိရိယာများကို ပေးသည်သာ၊ မည်သည့်ကိရိယာကို ပေးမည်ကို သင်ရွေးချယ်ပါသည်။

## ဖွင့်ရန်

1. {{ui:ဆက်တင်များ}} ကို ဖွင့်ပါ (app bar ရှိ ဂီယာအိုင်ကွန်၊ သို့မဟုတ် {{key:Mod+,}}) ပြီးနောက် {{ui:TakeoffCraft}} tab သို့ သွားပါ။
2. {{ui:အကူအညီပေးသူများ}} အောက်တွင် **AI အကူအညီပေးသူများနှင့် scripts များ TakeoffCraft ကို သုံးခွင့်ပြုရန်** ကို အမှန်ခြစ်ပါ။ သင်မလုပ်မချင်း ၎င်းသည် ပိတ်ထားသည်။
3. ဘာလုပ်ခွင့်ရှိမည်ကို ရွေးပါ- **ဖတ်ရန်** ကို စတင်ချိန်တွင် အမှန်ခြစ်ထားသည်; **တည်းဖြတ်ရန်**၊ **သိမ်းရန်** သို့မဟုတ် **ထုတ်ယူရန်** ကို လိုအပ်မှသာ အမှန်ခြစ်ပါ။

သင်အမှန်ခြစ်ထားသော ခွင့်ပြုချက်များအပြင်ရှိ ကိရိယာများကို အကူအညီပေးသူအား ပေးမည် မဟုတ်ပါ၊ အကူအညီပေးသူက ၎င်းကို တောင်းဆိုပါက TakeoffCraft က ငြင်းပယ်ပြီး လှုပ်ရှားမှုမှတ်တမ်းတွင် မှတ်ထားပါမည်။ ခလုတ်ကို ပိတ်လိုက်ပါက ချိတ်ဆက်မှုအားလုံး တစ်ပြိုင်နက် ရပ်ဆိုင်းသွားပါမည်; {{ui:TakeoffCraft ဆက်တင်များ ပြန်သတ်မှတ်ရန်}} ကလည်း ၎င်းကို ပိတ်ပါသည်။

## အကူအညီပေးသူကို ချိတ်ဆက်ရန်

အကူအညီပေးသူများသည် သင့်ကွန်ပျူတာပေါ်ရှိ **CadCraft Studio** မှတစ်ဆင့် ချိတ်ဆက်ပါသည်- Studio သည် ဤကွန်ပျူတာမှသာ ဝင်ရောက်နိုင်သော server ငယ်တစ်ခုကို run ပြီး စတင်တိုင်း ဖန်တီးသော token ဖြင့် ကာကွယ်ထားပါသည်။ Studio တွင် {{ui:အကူအညီပေးသူကို ချိတ်ဆက်ရန်}} ကို ရွေးပြီး address နှင့် token ကို အကူအညီပေးသူသို့ ကူးထည့်ပါ (ကူးထည့်ရမည့် ဆက်တင်အတိအကျကို Studio က ပြပါသည်)။ token ကို ဘယ်တော့မျှ မမျှဝေပါနှင့်။

:::note
browser tab သည် အကူအညီပေးသူအတွက် ချိတ်ဆက်မှု ဖွင့်၍မရပါ- browser app များတွင် သင့်ကွန်ပျူတာပေါ်ရှိ CadCraft Studio ကို မသုံးမချင်း ခလုတ်သည် အကျိုးမရှိပါ။
:::

## သင်ကိုယ်တိုင် ထိန်းချုပ်ထားသည်

- **ပြောင်းလဲမှုတိုင်းသည် undo အဆင့်တစ်ခု** ဖြစ်ပြီး အကူအညီပေးသူ၏ အမည်ဖြင့် အမှတ်အသားတပ်ထားသည် (ဥပမာ "Assistant: …")။ {{key:Mod+Z}} သည် အကူအညီပေးသူ၏ နောက်ဆုံးပြောင်းလဲမှုကို တစ်ခုလုံး ပြန်ဖျက်ပေးသည်။
- **ချိတ်ဆက်ထားသည်ကို သင်သိနိုင်သည်။** ချိတ်ဆက်ထားစဉ် app bar ရှိ ခလုတ်တစ်ခုက အကူအညီပေးသူ၏ အမည်ကို ပြသည်; နှိပ်လိုက်ပါက ၎င်း ဘာလုပ်ခွင့်ရှိသည်ကို ကြည့်နိုင်ပြီး **ချိတ်ဆက်မှုဖြတ်ရန်** ကိုလည်း လုပ်နိုင်သည်။
- **လှုပ်ရှားမှု။** {{ui:ဆက်တင်များ}} › {{ui:TakeoffCraft}} › {{ui:အကူအညီပေးသူများ}} › {{ui:လှုပ်ရှားမှု}} တွင် ခေါ်ဆိုမှုတိုင်းကို စာရင်းပြုသည်: အချိန်၊ ကိရိယာ၊ ပြီးမြောက်ခြင်း သို့မဟုတ် ငြင်းပယ်ခြင်း။ {{ui:မှတ်တမ်းကို သိမ်းရန်}} က မိတ္တူတစ်ခု သိမ်းထားပေးသည်။

## အကူအညီပေးသူ တောင်းဆိုနိုင်သည်များ

| ကိရိယာ | ခွင့်ပြုချက် | အလုပ်လုပ်ပုံ |
|---|---|---|
| `app_info`, `sheets_list` | ဖတ်ရန် | ဖွင့်ထားသော takeoff၊ ၎င်း၏ PDF များနှင့် စာရွက်များ၊ စာရွက်တစ်ခုချင်းစီ၏ scale နှင့် အမှတ်အသားများ |
| `items_list` | ဖတ်ရန် | items များ၊ ၎င်းတို့၏ ယူနစ်များ၊ နှုန်းထားများနှင့် assembly ဖော်မြူလာများ |
| `takeoff_quantities` | ဖတ်ရန် | item တစ်ခုချင်းစီ သို့မဟုတ် စာရွက်တစ်ခုချင်းစီအလိုက် ပမာဏများ; scale မရှိသော စာရွက်များပေါ်ရှိ အမှတ်အသားများကို စာရင်းပြုသည်၊ သုညအဖြစ် ဘယ်တော့မျှ မရေတွက်ပါ |
| `takeoff_estimate` | ဖတ်ရန် | TakeoffCraft က တွက်ချက်သည့်အတိုင်း ဈေးနှုန်းသတ်မှတ်ထားသော ခန့်မှန်းချက်၊ စုစုပေါင်းများနှင့်အတူ |
| `takeoff_export` | ထုတ်ယူရန် | TakeoffCraft ၏ ကိုယ်ပိုင် CSV သို့မဟုတ် XLSX ထုတ်ယူမှု |
| `items_add` | တည်းဖြတ်ရန် | ယူနစ်များ၊ နှုန်းထားများနှင့် waste ပါသော items များ ထည့်ခြင်း |
| `marks_add` | တည်းဖြတ်ရန် | စာရွက်ပေါ်တွင် runs၊ areas နှင့် counts တိုင်းတာခြင်း။ အလျားနှင့် ဧရိယာများကို scale ရှိသော စာရွက်ပေါ်တွင်သာ၊ scale မရှိသည့် စာရွက်ပေါ်တွင် ဘယ်တော့မျှ မပြုလုပ်ပါ |
| `cad_sheets`, `cad_catalog`, `cad_count` | ဖတ်ရန် | ဖွင့်ထားသော DWG သို့မဟုတ် DXF ပေါ်တွင်: ၎င်း၏ စာရွက်များနှင့် scale များ၊ ရေတွက်နိုင်သည့်အရာများ (blocks၊ layers နှင့် အမျိုးအစားများ၊ စာသားများ)၊ နှင့် {{ui:CAD ရေတွက်}} က ပေးသည့်အတိုင်း တိကျသော ရေတွက်မှုများ ([ပုံဆွဲမှ ရေတွက်ရန်](topic:count-from-a-drawing)) |
| `cad_count_add` | တည်းဖြတ်ရန် | ပုံဆွဲထဲတွင် ရေတွက်ပြီး တွေ့သော object တစ်ခုစီပေါ်တွင် count အမှတ်အသား တပ်ပေးသည်၊ တစ်ဆင့်တည်း; ထပ်ရေတွက်ပါက အသစ်ဖြစ်သည်များသာ ထည့်သည် |
| `cad_measure` | တည်းဖြတ်ရန် | ပုံဆွဲ၏ မိမိ လိုင်း၊ arc၊ polyline နှင့် hatch များမှ linear သို့မဟုတ် area item ကို တိုင်းတာသည်၊ {{ui:ပုံဆွဲမှ တိုင်းတာရန်}} ကဲ့သို့ ([ပုံဆွဲမှ တိုင်းတာရန်](topic:measure-from-a-drawing)); scale ရှိသော စာရွက်ပေါ်တွင်သာ |
| `usd_export` | ထုတ်ယူရန် | scale ရှိသော စာရွက်တစ်ခု၏ တိုင်းတာထားသော runs၊ areas နှင့် counts ကို USD (`.usdz`၊ `.usda` သို့မဟုတ် `.usdc`) 3D စစ်ဆေးမော်ဒယ်အဖြစ်၊ 3D check view ရှိ {{ui:USD ပက်ကေ့ဂျ် (.usdz)}} ကဲ့သို့ ([3D check view ကို USD အဖြစ် ထုတ်ယူရန်](topic:usd)) |

**တည်းဖြတ်ရန်** အမှန်ခြစ်ထားသောအခါ အကူအညီပေးသူသည် items နှင့် အမှတ်အသားများ ထည့်နိုင်သည် (ခေါ်ဆိုမှုတစ်ခုစီသည် undo အဆင့်တစ်ခု); ရှိပြီးသား အမှတ်အသားများကို ရွှေ့ခြင်း၊ ပြောင်းခြင်း သို့မဟုတ် ဖျက်ခြင်း မလုပ်နိုင်ပါ။

TakeoffCraft ကို မဖွင့်ဘဲလည်း ပမာဏနှင့် ခန့်မှန်းချက်များ ရနိုင်ပါသည်: CadCraft MCP server သည် သင်အမည်ပေးထားသော folder တစ်ခုထဲရှိ `.takeoff.json` ဖိုင်ကို ဖွင့်ပေးသည် (`takeoff_open`၊ `takeoff_quantities`၊ `takeoff_estimate`၊ `takeoff_export`) နှင့် `cadcraft info Job.takeoff.json` က command line တွင် ၎င်းတို့ကို ပရင့်ထုတ်ပေးသည်။ ၎င်းသည် DWG သို့မဟုတ် DXF ကိုလည်း ၎င်း၏ စာရွက်များပေါ်တွင် takeoff အသစ်တစ်ခုအဖြစ် ဖွင့်နိုင်သည် (TakeoffCraft က scale လုပ်သည့်အတိုင်း ပုံဆွဲမှ scale လုပ်ထားသည်)၊ အတူတူ `cad_*` ကိရိယာများဖြင့် ရေတွက်ပြီး တိုင်းတာနိုင်သည်၊ items ထည့်ပြီး takeoff ကို သိမ်းနိုင်သည် (`takeoff_save`); `cadcraft count plan.dwg --block SHELF-18X48 --sheet K-101` က command line မှ ရေတွက်သည်။

## အလုပ်မလုပ်ပါက

- **အကူအညီပေးသူသည် TakeoffCraft ကိရိယာများ မမြင်ပါ:** ဤဝင်းဒိုးတွင် ခလုတ် ဖွင့်ထားခြင်းနှင့် ဝင်းဒိုး Studio တွင် ဖွင့်ထားခြင်းကို စစ်ဆေးပါ။
- **"needs the export permission":** {{ui:အကူအညီပေးသူများ}} အောက်တွင် **ထုတ်ယူရန်** ကို အမှန်ခြစ်ပြီး ထပ်မေးပါ။
- **"401" သို့မဟုတ် "token" အမှားများ:** token ပြောင်းသွားပါပြီ (Studio ပြန်စတင်ခဲ့ခြင်း သို့မဟုတ် {{ui:token အသစ်}})။ အသစ်ကို အကူအညီပေးသူ၏ ဆက်တင်များထဲ ကူးထည့်ပါ။

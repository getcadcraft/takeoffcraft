TakeoffCraft သည် ပုံစံကွက်အစုများ၊ PDF များနှင့် DWG သို့မဟုတ် DXF ဒရော်ဝင်းများကို တိုင်းတာပြီး တိုင်းတာချက်များကို ဈေးနှုန်းပါသော ခန့်မှန်းချက်အဖြစ် ပြောင်းပေးသည်။ ဖိုင်များကို ဖွင့်ပါ (ဒရော်ဝင်းတစ်ခုသည် ၎င်း၏ block များမှ တိုက်ရိုက် ရေတွက်သည်- [DWG သို့မဟုတ် DXF ဒရော်ဝင်း ဖွင့်ခြင်း](topic:open-a-drawing) ကို ကြည့်ပါ)၊ စာရွက်တစ်ရွက်စီကို စကေးပေးပါ (ဒရော်ဝင်းက ကိုယ်ပိုင်စကေး ယူလာသည်)၊ **ပစ္စည်းများ** ဖန်တီးပါ (နံရံအမျိုးအစား၊ ကြမ်းပြင်အပြီးသတ်၊ ပစ္စည်းတပ်ဆင်မှု)၊ ထို့နောက် စာရွက်များပေါ်တွင် နှိပ်၍ ထုတ်ယူပါ။ ပမာဏများ၊ ကုန်ကျစရိတ်များနှင့် အလုပ်စုစုပေါင်းတို့ သင်ဆက်လုပ်သည်နှင့်အမျှ အပ်ဒိတ်ဖြစ်သည်။ ခန့်မှန်းချက်ကို spreadsheet အဖြစ်နှင့် သင့် takeoff ဆွဲထားသော PDF မိတ္တူအဖြစ် ထုတ်ယူနိုင်သည်။

အခြားပရိုဂရမ်များတွင် takeoff လုပ်ဖူးပါက နောက်တစ်ခုအနေဖြင့် [အခြား takeoff ဆော့ဖ်ဝဲမှ ပြောင်းလာခြင်း](topic:coming-from) ကို ဖတ်ပါ။ ဤနေရာတွင် အချို့အရာများ ကွဲပြားစွာ အလုပ်လုပ်သည်။

## ဘယ်မှာ အလုပ်လုပ်သလဲ

TakeoffCraft သည် သင့် web browser တွင် အလုပ်လုပ်သည်။ TakeoffCraft ကို ဖွင့်လိုက်လျှင် မျက်နှာပြင် ချက်ချင်း အဆင်သင့်ဖြစ်သည်၊ install လုပ်စရာ မလိုပါ။

- **သင့် PDF များသည် သင့်ကွန်ပျူတာပေါ်တွင်သာ ရှိနေသည်။** browser က ဖွင့်ပြီး ဘယ်တော့မှ upload မလုပ်ပါ။ သိမ်းခြင်းသည် ဒေါင်းလုဒ် ဖြစ်သည်။
- လက်ရှိ Chrome၊ Edge၊ Firefox နှင့် Safari တွင် အလုပ်လုပ်သည်။ [Browser များနှင့် ကွန်ပျူတာများ](common:browsers) ကို ကြည့်ပါ။
- app bar တွင် {{ui:Save for offline}} ကို ရွေးပြီး {{ui:Offline ready}} ဟု ပြသပြီးနောက် အင်တာနက်ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်သည်။ [အော့ဖ်လိုင်း အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။
- cloud သိမ်းခြင်း မရရှိသေးပါ။ desktop အက်ပ်အတွက် TakeoffCraft သည် အခြားအက်ပ် 7 ခုနှင့်အတူ CadCraft Studio တွင် ပါဝင်သည်။

## ပထမ takeoff ကို အဆင့် 10 ဆင့်ဖြင့်

ဤလမ်းညွှန်သည် နံရံအမျိုးအစားတစ်ခုကို တိုင်းတာပြီး ဈေးနှုန်းသတ်မှတ်သည်။ သင့်ဆီရှိ မည်သည့်ပုံစံကွက်ဖြင့်မဆို မိနစ်အနည်းငယ် ကြာသည်။

1. toolbar ရှိ {{ui:File}} အုပ်စုတွင် {{ui:Open plans}} ကို ရွေးပါ (သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ)၊ PDF တစ်ခု သို့မဟုတ် တစ်ခုထက်ပို ရွေးပြီး Open ကို ရွေးပါ။ PDF များကို စာမျက်နှာ၏ မည်သည့်နေရာသို့မဆို ချထားနိုင်သည်။
   စာရွက်များ ဘယ်ဘက်တွင် ပေါ်လာပြီး ပထမစာရွက်ကို အလယ်တွင် ဖွင့်သည်။
2. စာရွက်၏ ပုံနှိပ်ထားသော စကေးကို title block တွင် သို့မဟုတ် ဒရော်ဝင်းခေါင်းစဉ်အောက်တွင် ရှာပါ။
3. {{ui:Scale}} အုပ်စုရှိ {{ui:Preset}} စာရင်းကို ဖွင့်ပြီး ထိုစကေးကို ရွေးပါ၊ ဥပမာ `1/4" = 1'-0"`။
   စာရွက်အောက်ခြေရှိ bar တွင် "စကေး 1/4" = 1'-0"" ဟု ယခုပြသည်။
4. {{ui:Check}} ကို ရွေးပါ (သို့မဟုတ် {{key:D}} ကို နှိပ်ပါ) ပြီး ဒရော်ဝင်းပေါ်ပုံနှိပ်ထားသော အတိုင်းအတာ၏ အဆုံးနှစ်ခုကို နှိပ်ပါ။
   ဘယ်ဘက်အောက်ခြေ status bar ရှိ ဖတ်ပြချက်သည် ပုံနှိပ်ထားသော အတိုင်းအတာနှင့် ကိုက်ညီသင့်သည်။ မကိုက်ညီပါက [စကေး သတ်မှတ်ခြင်း](topic:set-the-scale) ကို ကြည့်ပါ။
5. ညာဘက်ရှိ {{ui:Items}} panel တွင် {{ui:New item}} ကို ရွေးပါ၊ `Interior wall type A` ကဲ့သို့ အမည်ရိုက်ပါ၊ အမျိုးအစားကို {{ui:Linear (length)}} အဖြစ်ထားပြီး {{ui:Add}} ကို ရွေးပါ။
6. toolbar တွင် {{ui:Linear}} ကို ရွေးပါ (သို့မဟုတ် {{key:L}} ကို နှိပ်ပါ)။
7. နံရံ၏ အစကို နှိပ်ပြီး ထိုနံရံတလျှောက် ထောင့်တိုင်းကို နှိပ်ပါ။ Double-click လုပ်ပါ၊ {{key:Enter}} ကို နှိပ်ပါ သို့မဟုတ် right-click ဖြင့် run ကို ပြီးဆုံးပါ။
   run ကို ပစ္စည်း၏ အရောင်ဖြင့် ဆွဲပြီး အလျားက ပစ္စည်းဘေးတွင် ပေါ်လာသည်။
8. {{ui:Items}} အောက်ရှိ ပစ္စည်းတည်းဖြတ်ကိရိယာတွင် {{ui:Height}} ထဲ `9'-0"`၊ {{ui:Material $/LF}} ထဲ `0.85` နှင့် {{ui:Labor $/LF}} ထဲ `1.20` ရိုက်ပါ။
   အောက်ခြေရှိ {{ui:Quantities}} ဇယားတွင် အလျား၊ တိုးချဲ့ထားသော ပစ္စည်းနှင့် လုပ်အား ကုန်ကျစရိတ်နှင့် {{ui:Job total}} ကို ပြသသည်။
9. {{ui:Save takeoff}} ကို ရွေးပါ (သို့မဟုတ် {{key:Mod+S}} ကို နှိပ်ပါ)။
   သင့် browser က `.takeoff.json` ဖိုင်ကို ဒေါင်းလုဒ်လုပ်သည်။ ၎င်းတွင် ပစ္စည်း၊ စကေးနှင့် အမှတ်အသားများ ပါပြီး တူညီသော PDF များပေါ်တွင် ပြန်ဖွင့်နိုင်သည်။
10. toolbar ရှိ {{ui:Export}} မီနူးကို ဖွင့်ပြီး {{ui:XLSX}} ကို ရွေးကာ ခန့်မှန်းချက်ကို spreadsheet အဖြစ် ဒေါင်းလုဒ်လုပ်ပါ။

:::tip
{{key:Esc}} ကို နှိပ်ပါက လုပ်နေသည်ကို ရပ်ပြီး {{ui:Select}} ကိရိယာသို့ ပြန်သွားသည်။ {{key:Mod+Z}} က ပြောင်းလဲမှုတိုင်းကို ပြန်ဖျက်သည်။
:::

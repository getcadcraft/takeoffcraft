{{ui:Edit}} အုပ်စုရှိ ကိရိယာဘားတွင် {{ui:Undo}}၊ {{ui:Redo}}၊ {{ui:Copy}} နှင့် {{ui:Paste}} ရှိသည်။ ၎င်း၏ {{ui:More}} menu တွင် ကျန်တာများ ရှိပြီး တစ်ခုချင်းစီတွင် ၎င်း၏ key ပါသည်: {{ui:Cut}}၊ {{ui:Copy}}၊ {{ui:Paste}}၊ {{ui:Paste in place}}၊ {{ui:Duplicate}}၊ {{ui:Delete}}၊ {{ui:Select all}} နှင့် {{ui:Select none}}။ ၎င်းတို့အားလုံးသည် {{key:Mod+Z}} ဖြင့် undo တစ်ဆင့်သာ ဖြစ်သည်။

## အမှတ်များကို ရွေးခြင်း

1. {{ui:Select}} ({{key:V}}) ကို ရွေးပြီး အမှတ်တစ်ခုကို နှိပ်ပါ။
2. ထပ်ထည့်ရန် {{key:Shift}} ကိုင်ထားပြီး အမှတ်များကို နှိပ်ပါ။ ရွေးထားပြီးသား အမှတ်ပေါ်တွင် {{key:Shift}} + နှိပ်ခြင်းက ပြန်ဖယ်ရှားသည်။
3. သို့မဟုတ် {{key:Mod+A}} ({{ui:Select all}}) ကို နှိပ်ပြီး ဖွင့်ထားသော စာရွက်ပေါ်ရှိ အမှတ်အားလုံးကို ယူပါ။

အမှတ်များစွာ ရွေးထားသောအခါ ညာဘက် panel တွင် **Selected marks** ကို ပြသည်- ပစ္စည်းတစ်ခုချင်းစီ၏ အရေအတွက်၊ {{ui:Copy}}၊ {{ui:Duplicate}}၊ {{ui:Cut}} နှင့် {{ui:Delete marks}} ပါသည်။ ထောင့် handles များသည် အမှတ်တစ်ခုသာ ရွေးထားသောအခါ ပေါ်သည်။ {{key:Esc}} ({{ui:Select none}}) က ရွေးချယ်မှုကို ရှင်းသည်။

## နှိပ်သည့်နေရာတွင် ကူးပြီး ကူးထည့်ခြင်း

1. အမှတ်များကို ရွေးပြီး {{key:Mod+C}} ({{ui:Copy}}) ကို နှိပ်ပါ။ အမှတ်များကို ၎င်းတို့၏ ပစ္စည်းများနှင့်အတူ ကူးသည်၊ ပစ္စည်းတစ်ခုချင်းစီ၏ assembly၊ waste နှင့် ကုန်ကျစရိတ်များအပါအဝင်။
2. ၎င်းတို့ထားလိုသော စာရွက်သို့ သွားပါ (တူညီသော စာရွက်လည်း ဖြစ်နိုင်သည်)။
3. {{key:Mod+V}} ({{ui:Paste}}) ကို နှိပ်ပါ။ ပြတ်ပြတ်မျဉ်းဖြင့် ကူးထားသော ပုံတစ်ခုသည် pointer ကို လိုက်သည်။
4. ၎င်းသွားရမည့်နေရာကို နှိပ်ပါ။ ကူးထားသော အမှတ်များ၏ အလယ်သည် pointer တွင် ရောက်သည်။

{{key:Esc}} က ပယ်ဖျက်ပြီး ဘာမှ မထည့်ပါ။ ကူးထည့်ပြီးနောက် အမှတ်များကို ရွေးထားသည်၊ ထို့ကြောင့် {{key:Delete}} သို့မဟုတ် {{key:Mod+Z}} ဖြင့် ပြန်ဖယ်ရှားနိုင်သည်။

တူညီသော takeoff တွင် ကူးထည့်သော အမှတ်များသည် **တူညီသော ပစ္စည်းများ** ပေါ်သို့ သွားပြီး ၎င်းတို့၏ ပမာဏများ ထိုပစ္စည်းများသို့ ပေါင်းထည့်သည်။ အခြား takeoff တစ်ခုတွင် (အခြား tab သို့မဟုတ် {{ui:New}} ပြီးနောက်) အမည်နှင့် အမျိုးအစား တူသော ပစ္စည်းကို အသုံးပြုသည်; မဟုတ်ပါက ပစ္စည်းကို ၎င်း၏ assembly ဖြင့် ထည့်သည်။ အမည်ကို အခြားအမျိုးအစားရှိ ပစ္စည်းက ယူထားပါက ထည့်သော ပစ္စည်းကို "(name) (copy)" ဟု ခေါ်သည်။

ကူးထည့်သော အမှတ်များသည် {{ui:Items}} panel ၏ထိပ်တွင် ရွေးထားသော bid area (သို့မဟုတ် မည်သည့်အရာမျှ မရှိ) ထဲသို့ ဝင်သည်။ See [Bid areas](topic:bid-areas)။

## နေရာတူ ကူးထည့်ခြင်း

{{key:Mod+Shift+V}} ({{ui:Paste in place}}) သည် ဖွင့်ထားသော စာရွက်ပေါ်ရှိ တိကျစွာ တူညီသော နေရာတွင် မိတ္တူကို ထားသည်၊ စာမျက်နှာပေါ်ရှိ ၎င်း၏ အနေအထားအလိုက်။ typical floor အတွက် သုံးပါ: level 2 ကို takeoff လုပ်၊ ကူး၊ level 3 ကို ဖွင့်၊ နေရာတူ ကူးထည့်ပါ။

Paste in place သည် သင်ကူးခဲ့သော စာရွက်နှင့် **အရွယ်အစား တူညီသော** စာရွက် လိုအပ်သည်။ အခြားအရွယ်အစားရှိ စာရွက်တွင် TakeoffCraft က ထိုအကြောင်း ပြောပြပြီး ဘာမျှ မကူးထည့်ပါ; အစား {{ui:Paste}} ကို သုံးပြီး နှိပ်ပါ။ ကူးခဲ့သော စာရွက်ပေါ်တွင် မိတ္တူသည် မူရင်းများ၏ အပေါ်တွင် ကျသည်။

## စကေးတူရမည်

အလျားနှင့် area များသည် စာရွက်၏ စကေးပေါ် မူတည်သည်။ 1/4" = 1'-0" တွင် 10' တိုင်းသော run သည် 1/8" = 1'-0" စာရွက်တွင် 20' ဖြစ်မည်။ ထို့ကြောင့် TakeoffCraft သည် run များနှင့် area များကို ၎င်းတို့ ဆင်းသက်လာသည့် စာရွက်နှင့် **တူညီသော စကေး** ရှိသော စာရွက်သို့သာ ကူးထည့်ပြီး မဖြစ်သည့်အခါ ရိုးရိုးရှင်းရှင်း ပြောပြသည်:

- ဖွင့်ထားသော စာရွက်တွင် စကေးမရှိသေး: ကူးထည့်ခြင်းမပြုမီ ဦးစွာ ပေးပါ ([Set the scale](topic:set-the-scale))။
- ဖွင့်ထားသော စာရွက်တွင် အခြားစကေးရှိ: မက်ဆေ့ချ်က စကေးနှစ်ခုလုံးကို အမည်ပေးသည်။ တူညီသော စကေးရှိ စာရွက်တွင် ကူးထည့်ပါ။
- အရေအတွက်များအတွက် စကေးမလို: ကူးထားသော အရေအတွက်များကို မည်သည့်နေရာတွင်မဆို ကူးထည့်နိုင်သည်။

## ပွားခြင်း

{{key:Mod+D}} ({{ui:Duplicate}}) သည် ရွေးထားသော အမှတ်များကို ကူးပြီး မိတ္တူကို pointer ပေါ်တွင် ချက်ချင်း ထားသည်; နေရာကို နှိပ်ပါ။ နှိပ်သည်အထိ ဘာမျှ မထည့်ပါ၊ {{key:Esc}} က ဘာမျှ မထားပါ။ Duplicate သည် {{ui:Paste}} ကူးထည့်သည့်အရာကို မပြောင်းလဲပါ။

## ဖြတ်ခြင်းနှင့် ဖျက်ခြင်း

- {{key:Mod+X}} ({{ui:Cut}}) သည် ရွေးထားသော အမှတ်များကို ကူးပြီး ဖျက်သည်။ ၎င်းတို့ သင့်တော်သည့်နေရာတွင် ကူးထည့်ပါ၊ သို့မဟုတ် cut ကို undo လုပ်ပါ။
- {{key:Delete}} သို့မဟုတ် {{key:Backspace}} ({{ui:Delete}}) သည် ရွေးထားသော အမှတ်များကို မကူးဘဲ ဖျက်သည်။

## ပစ္စည်းတစ်ခု ကူးခြင်း

ပစ္စည်းတည်းဖြတ်သူ (**Items** အောက်) သည် ဤအရာဖြင့် အဆုံးသတ်သည်:

- {{ui:Copy item}}: ပစ္စည်းကို assembly၊ waste နှင့် ကုန်ကျစရိတ်များဖြင့် ကူးသည်၊ အမှတ်မပါဘဲ။ {{ui:Paste}} သည် ၎င်း၏ မိတ္တူကို ဤ takeoff သို့ သို့မဟုတ် အခြားတစ်ခုသို့ ထည့်သည်။
- {{ui:Duplicate item}}: မိတ္တူကို ချက်ချင်း ထည့်သည်၊ "(name) (copy)" ဟု အမည်ပေးထားသည်။

:::tip
မိတ္တူသည် ဤကွန်ပျူတာပေါ်တွင် ရှိနေသည်: ၎င်းသည် ဤ tab နှင့် ဘရောက်ဇာ၏ သိုလှောင်မှုတွင် ရှိပြီး TakeoffCraft အခြား tab တစ်ခုက ကူးထည့်နိုင်သည်။ မည်သည့်အရာမျှ upload မလုပ်ပါ၊ system clipboard ကို မသုံးပါ၊ ထို့ကြောင့် အမှတ်များကို အခြား programs သို့ ကူးထည့်၍ မရပါ။
:::

:::note
မိတ္တူသည် စာရွက်တစ်ခုချင်းစီမှ ဖြစ်သည်။ အမှတ်များကို ရှိတိုင်း ကူးထည့်သည်: ယခုအချိန်တွင် မိတ္တူကို လှည့်ခြင်း သို့မဟုတ် ကြည့်ထောင့်ပြောင်းခြင်း မရှိပါ။
:::

count item သည် အရာများကို ရေတွက်သည်: တံခါးများ၊ မီးဖိုင်းပစ္စည်းများ၊ outlets၊ ရေပိုက်ပစ္စည်းများ။ ပုံပေါ်ရှိ နှိပ်ချက်တိုင်းက count mark တစ်ခု ထည့်သည်။ ရေတွက်ရန် စကေး မလိုအပ်ပါ။

## ရေတွက်ခြင်း

1. {{ui:Items}} အောက်တွင် count item ({{ui:Count}} အမျိုးအစား) တစ်ခု ပြုလုပ်ပါ သို့မဟုတ် နှိပ်ပါ။
2. ကိရိယာဘားတွင် {{ui:Count}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:C}} ကို နှိပ်ပါ။
3. ပုံပေါ်ရှိ တစ်ခုချင်းစီကို နှိပ်ပါ။
   နှိပ်တိုင်း ပစ္စည်း၏ အရောင်ဖြင့် အစက်တစ်ခု ထည့်ပြီး ပစ္စည်း၏ အရေအတွက် တစ်ခု တိုးသည်။
4. နောက်စာရွက်သို့ ({{key:PageDown}}) ရွှေ့ပြီး ဆက်ရေတွက်ပါ။ ကိရိယာသည် {{ui:Count}} တွင် ဆက်ရှိနေသည်။
5. ပြီးသောအခါ {{key:Esc}} ကို နှိပ်ပါ။ TakeoffCraft သည် {{ui:Select}} သို့ ပြန်သွားသည်။

ရေတွက်နေစဉ် ဆွဲရွှေ့ခြင်းက ဆက် pan လုပ်ပြီး wheel က ဆက် zoom လုပ်သည်၊ ထို့ကြောင့် အစက်မထည့်ဘဲ ပုံဝန်းကျင်တွင် ရွှေ့နိုင်သည်။

:::tip
ကုန်ဆုံးစာရင်းအတွက် count item ကို နှိပ်ပါ၊ ၎င်း၏ အစက်များကို စာရွက်အားလုံးတွင် မီးမောင်းပြသည်။ စာရွက်များစာရင်းက စာရွက်တစ်ခုချင်းစီတွင် မည်မျှရှိသည်ကို ပြသည်၊ ရေမတွက်ရသေးသော စာရွက်များကို ရှာရန် ကူညီသည်။
:::

## ရေတွက်မှု ပြင်ဆင်ခြင်း

- **အစက်ဖယ်ရှားရန်**: {{ui:Select}} ({{key:V}}) ကို ရွေးပြီး အစက်ကို နှိပ်ကာ {{key:Delete}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Delete mark}} ကို ရွေးပါ။ သို့မဟုတ် မှားနှိပ်ပြီးချက်ချင်း {{key:Mod+Z}} ကို နှိပ်ပါ။
- **အစက်ရွှေ့ရန်**: ရွေးပြီး ဆွဲပါ။
- **မှားသော item အောက်တွင် ရေတွက်ထားခြင်း**: အစက်ကို ရွေးပြီး **Selected mark** အောက်ရှိ **Item** စာရင်းမှ မှန်ကန်သော count item ကို ရွေးပါ။

## အစက်အရွယ်၊ မျက်နှာပြင်နှင့် PDF တွင်

အစက်များသည် မည်မျှ zoom လုပ်သည်ဖြစ်စေ မျက်နှာပြင်တွင် အရွယ်တူ ရှိနေသည်။ ပြောင်းရန် {{ui:Settings}} ကို ဖွင့်ပြီး TakeoffCraft tab ကို ရွေးကာ **Count marker size** ကို ရွေးပါ: Extra small၊ Small၊ Medium (မူလ) သို့မဟုတ် Large။

PDF ထုတ်ယူခြင်း ({{ui:Export}} › marked PDF) သည် စာရွက်အရွယ်အစား မည်သို့ပင်ဖြစ်စေ အစက်တစ်ခုချင်းစီကို စာရွက်ပေါ်တွင် အရွယ်တူ ဆွဲသည်; 100% ဖြင့် ပြသသော PDF viewer သည် အစက်များကို မျက်နှာပြင်ပေါ်ရှိ အရွယ်အတိုင်း ပြသည်။ စာရွက်ပေါ်ရှိ အစက်များ ထိနေမည်ဆိုလျှင် ထုတ်ယူမှုသည် ထိုစာရွက်၏ အစက်များကို ပိုသေးစေပြီး တစ်ခုချင်းစီ ဖတ်နိုင်စေသည်။

## သင်္ကေတများစွာ တူညီခြင်း

စာရွက်ပေါ်တွင် သင်္ကေတတစ်ခု အကြိမ်များစွာ ထပ်ခါတလဲလဲ ဖြစ်သည့်အခါ [Auto count](topic:auto-count) ကို စမ်းကြည့်ပါ: တစ်ခုကို ဘောက်စ်ခတ်ပါ၊ ရှာတွေ့သည်များကို စစ်ဆေးပြီး တစ်ကြိမ်တည်းဖြင့် အားလုံး ထည့်ပါ။

## ရေတွက်မှုများကို ဖော်မြူလာများတွင် အသုံးပြုခြင်း

count item ၏ ပမာဏသည် **N** ဖြစ်သည်။ Assembly အစိတ်အပိုင်းများက ၎င်းကို အသုံးပြုနိုင်သည်၊ ဥပမာ တံခါးများအတွက် hinges `N * 3`။ See [Assemblies and formulas](topic:assemblies)။

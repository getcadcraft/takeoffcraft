**ဈေးနှုန်း စာကြည့်တိုက်** တွင် အလုပ်တိုင်းတွင် သုံးသော ပစ္စည်းများ ထားသည်: ၎င်းတို့၏ အမျိုးအစား၊ ယူနစ်၊ အမြင့်၊ waste၊ ပစ္စည်းနှင့် လုပ်အား နှုန်းများ နှင့် ၎င်းတို့၏ assembly။ takeoff နှင့် သီးခြားဖြစ်ပြီး ဤ browser တွင် သိမ်းထားသည်၊ ထို့ကြောင့် ဤနေရာတွင် ဖွင့်သော takeoff တိုင်းက အသုံးပြုနိုင်သည်။

ဖွင့်ရန် {{ui:Items}} panel ၏ထိပ်ရှိ {{ui:Library}} ဖြင့်။

## စာကြည့်တိုက် ဖြည့်ခြင်း

- {{ui:Import CSV…}} က CSV အဖြစ် သိမ်းထားသော spreadsheet ကို ဖတ်သည် (အောက်ရှိ ကော်လံများကို ကြည့်ပါ)။ အမည်နှင့် အမျိုးအစား ရှိပြီးသား ပစ္စည်းများကို အစားထိုးသည်; ကျန်များကို ထည့်သည်။ ဖတ်၍ မရသော အတန်းများကို ကျော်ပြီး မည်သည်များနှင့် အဘယ်ကြောင့်ဆိုသည်ကို ပြောသည်။
- {{ui:Add this takeoff's items}} က ဖွင့်ထားသော takeoff ၏ ပစ္စည်းတိုင်းကို ၎င်း၏ နှုန်းနှင့် assembly ဖြင့် စာကြည့်တိုက်သို့ ကူးသည် (အမှတ်များကို မကူးပါ)။
- [Estimate ကို ထုတ်ပို့ခြင်း](topic:export-estimate) မှ TakeoffCraft ထုတ်ပို့သော estimate CSV သည် ပုံအတိုင်း သွင်းသည်: ယခင်အလုပ်၏ ဈေးနှုန်းများက နောက်တစ်ခုကို စတင်ပေးသည်။

- {{ui:Trade packs…}} သည် ကုန်သွယ်မှုတစ်ခုအတွက် အခမဲ့ assemblies (drywall၊ electrical၊ concrete ကဲ့သို့) ကို ဈေးနှုန်းမပါဘဲ ထည့်သည်။ ကြည့်ပါ [ကုန်သွယ်မှု ပက်ခ်များ](topic:trade-packs)။

{{ui:Export CSV}} က စာကြည့်တိုက်ကို CSV အဖြစ် သိမ်းသည်၊ မိတ္တူထားရန်၊ spreadsheet တွင် တည်းဖြတ်ရန် သို့မဟုတ် အဖော်ထံ ပေးရန်။ {{ui:Clear}} က ဗလာလုပ်သည် (နှစ်ကြိမ် နှိပ်ပါ)။

:::note
စာကြည့်တိုက်သည် ဤ browser ၏ သိုလှောင်မှုတွင် နေသည်။ အခြား browser၊ အခြားကွန်ပျူတာ သို့မဟုတ် private window တွင် ကိုယ်ပိုင်တစ်ခု (သို့မဟုတ် မရှိ) ရှိသည်။ ရွှေ့ရန် ထုတ်ပို့ပါ။
:::

## takeoff တွင် သုံးခြင်း

- ပစ္စည်းများကို အမှန်ခြစ်ပြီး ({{ui:Find in the library}} တွင် ရိုက်ပြီး စာရင်းကို ကျဉ်းစေပါ) {{ui:Add to takeoff}} ကို ရွေးပါ။ assemblies နှင့်အတူ တစ်ဆင့်တည်းဖြင့် ထည့်သည်၊ {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သည်။ takeoff တွင် ရှိပြီးသား အမည်သည် `Carpet (2)` ကဲ့သို့ နံပါတ်ရလာသည်။
- {{ui:Update prices}} က takeoff ၏ ပစ္စည်းများကို စာကြည့်တိုက်၏ waste နှင့် နှုန်းများ ပေးသည်၊ အမည်နှင့် အမျိုးအစား ကိုက်ညီသော ပစ္စည်းတိုင်းအတွက်၊ နှင့် အမည်တူ assembly အစိတ်အပိုင်းများအတွက်လည်း။ အမြင့်၊ ယူနစ်နှင့် ဖော်မြူလာများသည် ထိုအတိုင်း ကျန်သည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် ဈေးဟောင်းအားလုံးကို ပြန်ထားသည်။

## CSV ကော်လံများ

ပထမအတန်းက ကော်လံများကို ဘယ်အစီအစဉ်ဖြင့်မဆို အမည်ပေးသည်; အခြားကော်လံများကို လျစ်လျူရှုသည်။

| ကော်လံ | ထည့်ရမည့်အရာ |
|---|---|
| Item (or Name) | ပစ္စည်း၏ အမည်။ မဖြစ်မနေ။ |
| Type | Linear, Area သို့မဟုတ် Count (LF, SF နှင့် EA လည်း အလုပ်လုပ်သည်)။ ဗလာထားလျှင် ယူနစ်က ဆုံးဖြတ်သည်။ |
| Unit | LF သို့မဟုတ် m; SF, SY သို့မဟုတ် m²; EA။ ဗလာ: အမျိုးအစား၏ ပုံမှန်ယူနစ်။ |
| Waste % | `10` သို့မဟုတ် `10%`။ |
| Material per unit, Labor per unit | `2.10` သို့မဟုတ် `$1,250` ကဲ့သို့ နှုန်းများ။ |
| Height (or Depth) | `9'-0"`၊ `9`၊ သို့မဟုတ် မက်ထရစ်ယူနစ်အတွက် `2.7`။ |
| Component, Formula | Component အမည် (သို့မဟုတ် Type `Component`) ပါသော အတန်းသည် အထက်ရှိ ပစ္စည်း၏ assembly ၏ အစိတ်အပိုင်း ဖြစ်သည်။ ၎င်း၏ Unit၊ Waste နှင့် နှုန်းများသည် ကိုယ်ပိုင်ဖြစ်သည်; ၎င်း၏ Formula သည် ပစ္စည်း၏ အက္ခရာများကို သုံးသည်၊ ကြည့်ပါ [Assemblies နှင့် ဖော်မြူလာများ](topic:assemblies)။ |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

ကော်မာ၊ semicolon သို့မဟုတ် tab များ ကော်လံများကြား အားလုံး အလုပ်လုပ်သည်။

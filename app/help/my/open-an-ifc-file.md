IFC 4.3 ဖိုင်တွင် လမ်း၊ ရထားလမ်း၊ တံတား၊ ရေလမ်းအလုပ်များနှင့် ၎င်းတို့ဖွဲ့စည်းသော အစိတ်အပိုင်းများ ပါဝင်နိုင်သည်: ကတ္တရာလမ်းမျက်နှာပြင်များ၊ အလွှာများ၊ ဘောင်ကျောက်များ၊ ရေးလ်များ၊ မြေမှုန့်အလုပ်များ၊ ထောက်ခံပစ္စည်းများ၊ ကြိုးတိုင်များ နှင့် အခြား။ TakeoffCraft က ၎င်းတို့ကို ဖတ်ပြီး ဈေးနှုန်းသတ်မှတ်နိုင်သော typed quantities အဖြစ် ပြောင်းသည်။

## ဖိုင်ကို ဖွင့်ခြင်း

1. **ဖိုင်** အုပ်စုတွင် {{ui:Open plans}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ။
2. IFC ဖိုင်ကို ရွေးပါ (PDF များနှင့်အတူ ရွေးနိုင်သည်)၊ သို့မဟုတ် TakeoffCraft ပေါ်သို့ ချထားပါ။

အတန်းနှင့် predefined type တစ်ခုစီအတွက် typed quantity တစ်ခု ပြုလုပ်သည်၊ ဥပမာ "Pavement (flexible): count"၊ နှင့် ဖိုင်က ဖော်ပြသည့်အခါ "length" (m)၊ "area" (m²) နှင့် "volume" (m³) ပါဝင်သည်။ ပစ္စည်းတစ်ခုစီ၏ မှတ်စုက ရေတွက်ခဲ့သော element အရေအတွက်နှင့် ပမာဏ မဖော်ပြသော အရေအတွက်ကို ပြသည်။ အမည်တူ IFC ဖိုင်အသစ်ကို ဖွင့်လျှင် ထပ်မထည့်ဘဲ ထိုပမာဏများကို အဆင့်မြှင့်သည်။

## မလုပ်နိုင်သည်များ

- ဖိုင်က ယူဆောင်ထားသော quantity set (IfcElementQuantity) များကို ဖတ်သည်။ 3D ပုံသဏ္ဍာန်များကို တိုင်းတာခြင်း မလုပ်ပါ၊ ထို့ကြောင့် quantity set မရှိသော element ကို ရေတွက်သော်လည်း အလျား၊ ဧရိယာ သို့မဟုတ် ထုထည် မထည့်ပါ။
- IFC 4.3 ၏ အခြေခံအဆောက်အအုံ class များကိုသာ ဖတ်သည်။ အဆောက်အဦဖိုင် (နံရံ၊ တံခါး၊ slab) ကို ဤနေရာတွင် ပမာဏအဖြစ် မပြောင်းပါ; IFC 4.3 မဟုတ်သော ဖိုင်က ထိုသို့ပြောပြီး ဘာမျှ မသွင်းပါ။
- ယူနစ်များသည် ဖိုင်၏ကိုယ်ပိုင်ဖြစ်ပြီး မီတာသို့ ပြောင်းသည်။

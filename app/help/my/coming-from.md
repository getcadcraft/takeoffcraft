PlanSwift သို့မဟုတ် Bluebeam Revu ရှိ တိုင်းတာရေးကိရိယာများဖြင့် takeoff လုပ်ဖူးပါက TakeoffCraft ၏ အများစုသည် ရင်းနှီးနေမည်ဖြစ်သည်- ပုံဆွဲအစုံ၊ စာရွက်တစ်ခုချင်းစီအတွက် စကေး၊ တိုင်းတာမည့်အရာများနှင့် တန်ဖိုးသတ်မှတ်ထားသော စုစုပေါင်း။ အစိတ်အပိုင်းများ ပေါင်းစပ်ပုံမှာ နေရာအချို့တွင် ကွဲပြားသည်၊ ထိုနေရာများကို အောက်တွင် ဖော်ပြထားသည်။

PlanSwift သို့မဟုတ် On-Screen Takeoff ကို သိပါက {{ui:Settings}} › {{ui:TakeoffCraft}} › {{ui:Menus, keys and mouse}} တွင် {{ui:Takeoff desk}} menu style ကို ရွေးပါ- ဖိုင်, တည်းဖြတ်, ကြည့်ရန်, စကေး, တွက်ချက်ခြင်း, ပစ္စည်းများ, မှတ်ချက် နှင့် ထုတ်ယူရန် menu bar တစ်ခု၊ takeoff tools အတန်းတစ်ခုနှင့် sheet bar ပေါ်ရှိ scale presets များ ရှိသည်။ See [Menus, keys and mouse](topic:menus-keys-and-mouse).

## လူများ မှားတတ်သော ကွာခြားချက်များ

**takeoff သည် သင်၏ PDF အတွင်း မရှိပါ။** သင်လုပ်သမျှ၏ အရာတိုင်းသည် PDF များကို မပြောင်းလဲပါ။ `.takeoff.json` ဖိုင်ကို သိမ်းပြီး ပုံဆွဲများနှင့်အတူ ထားပါ။ marked PDF ကို ပေးပို့ခြင်းဖြင့် တည်းဖြတ်နိုင်သော takeoff ကို မပေးပို့ပါ- project ဖိုင်နှင့် မူရင်း PDF များ၊ သို့မဟုတ် [PDF with the takeoff inside](topic:save-and-reopen#keep-the-takeoff-inside-the-pdf) ကို ပေးပို့ပါ။

**PDF များကို အမည်ဖြင့် မဟုတ်ဘဲ အကြောင်းအရာဖြင့် ကိုက်ညီစေသည်။** ဟောင်းသော ဖိုင်အမည်အပေါ် သိမ်းထားသော ပြင်ဆင်ထားသည့် စာရွက်သည် TakeoffCraft အတွက် ဖိုင်အသစ်ဖြစ်ပြီး စကေးနှင့် အမှတ်အသားမရှိပါ။ သင်၏ ဟောင်းသော အမှတ်အသားများသည် ဟောင်းသော ဗားရှင်းတွင် ကျန်ရှိပြီး ရေတွက်ဆဲဖြစ်သည်။ See [Save and reopen a takeoff](topic:save-and-reopen#when-a-pdf-has-changed)။

**စကေးမသတ်မှတ်ရသေးသော အမှတ်များကို သုညအဖြစ် မရေတွက်ဘဲ ချန်ထားသည်။** စာရွက်တွင် စကေးမရှိပါက ၎င်း၏ run များနှင့် area များကို မရေတွက်ပါ၊ ဇယားတွင် "Incomplete" ဟု ပြသည်။ program အများအပြားတွင် သင်သည် 0 ကိုသာ မြင်ရမည်။ See [Set the scale](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero)။

**စာမျက်နှာအရွယ်အစား ခန့်မှန်းခြင်း မရှိပါ။** Presets များက PDF ကို အပြည့်အစားဖြင့် ပရင့်ထုတ်ထားသည်ဟု ယူဆသည်။ တစ်ဝက်အရွယ် သို့မဟုတ် "fit to page" PDF သည် {{ui:Calibrate}} လိုအပ်သည်။ အမြဲ {{ui:Check}} ကို အသုံးပြုပါ။

**ပစ္စည်းတစ်ခု၊ အဓိကအမျိုးအစားတစ်ခု၊ တောင်းဆိုလျှင် ပိုများသည်။** ပစ္စည်းတစ်ခုသည် linear၊ area သို့မဟုတ် count ဖြစ်ပြီး အမှတ်များရှိလာသည်နှင့် ၎င်း၏အမျိုးအစား လော့ခ်ချသည်။ area နှင့် ၎င်း၏ perimeter နှစ်ခုလုံးပေးသော အခြေအနေသည် area ပစ္စည်းတစ်ခုဖြစ်ပြီး ၎င်း၏ perimeter သည် `P` variable ဖြစ်သည်။ အရှည်နှင့် area နှစ်ခုလုံးရှိသော နံရံသည် အမြင့်ပါသော linear ပစ္စည်းတစ်ခုဖြစ်သည်။ floor၊ base နှင့် တံခါးများပါသော အခန်းကဲ့သို့ အခြေအနေများစွာပါသော ပစ္စည်းအတွက် **Also measure** အောက်တွင် အခြားအမျိုးအစားများကို အမှန်ခြစ်ပါ- တစ်ခုချင်းစီကို ၎င်း၏ကိုယ်ပိုင်အတန်းတွင် ဈေးနှုန်းသတ်မှတ်သည်။ See [One item, several kinds of marks](topic:create-items#one-item-several-kinds-of-marks)။

**ဖော်မြူလာများသည် စုစုပေါင်းပေါ်တွင် လုပ်ဆောင်သည်။** Assembly ဖော်မြူလာများသည် ပစ္စည်း၏ စာရွက်အားလုံးပေါ်ရှိ စုစုပေါင်းကို အသုံးပြုသည်၊ run တစ်ခုချင်းစီကို သီးခြားမဟုတ်ပါ။ `N` (run သို့မဟုတ် area အရေအတွက်) သည် run တစ်ခုချင်းစီ၏ အပိုများအတွက် ရှိသည်၊ ဥပမာ နံရံတစ်ခုလျှင် ကော်လံတစ်ခုအပို။

**Perimeter တွင် cut-outs ပါဝင်သည်။** area တစ်ခု၏ `P` တွင် ၎င်း၏ အပေါက်များ၏ အစွန်းများ ပေါင်းထည့်သည်။ See [Measure areas with cut-outs](topic:measure-areas#read-the-area)။

**ဆွဲရွှေ့ခြင်းက pan လုပ်သည်။** စာရွက်ပေါ်ရှိ ဘယ်ဘက်ခလုတ် ဆွဲရွှေ့ခြင်းသည် {{ui:Auto count}} မှလွဲ၍ tool အားလုံးတွင် pan လုပ်သည်။ pan tool သို့ ပြောင်းရန် လိုအပ်ခြင်း မရှိပါ။ wheel က zoom လုပ်သည်၊ scroll မလုပ်ပါ။

**recovery မိတ္တူ၊ cloud မဟုတ်ပါ။** TakeoffCraft သည် ဤဘရောက်ဇာတွင် သင်၏အလုပ်မိတ္တူကို သိမ်းထားပြီး crash ဖြစ်ပြီးနောက် ပြန်ပေးသည် ([If the tab or the browser stops](topic:save-and-reopen#if-the-tab-or-the-browser-stops))၊ သို့သော် takeoff ကို သိမ်းရန် သင့်တာဝန်ဖြစ်သည်: {{key:Mod+S}}။ cloud သိမ်းဆည်းခြင်း မရရှိသေးပါ။

**အားလုံး ဘရောက်ဇာတွင်ရှိသည်။** ထည့်သွင်းရန် မလိုပါ၊ ပုံများကို ဘယ်တော့မှ upload မလုပ်ပါ။ desktop app အတွက် TakeoffCraft သည် အခြား apps ခုနစ်ခုနှင့်အတူ CadCraft Studio တွင် ရရှိသည်။

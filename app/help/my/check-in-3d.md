3D view သည် စစ်ဆေးမှုတစ်ခုဖြစ်ပြီး ဒုတိယ ပုံဆွဲခြင်း မဟုတ်ပါ: ၎င်းသည် စာရွက်ပေါ်ရှိ တိုင်းတာမှုကို စာရွက်ပေါ်မှာပင် မျက်နှာပြင်ပေါ် ထောင်ပေးသည်၊ ထို့ကြောင့် နံရံ ပျောက်နေခြင်း၊ slab ပွားနေခြင်း သို့မဟုတ် လွဲနေသော count ကို တစ်ချက်ကြည့်ရုံဖြင့် မြင်နိုင်သည်။

မစတင်မီ- စာရွက်တွင် စကေး လိုအပ်သည် ([စကေးသတ်မှတ်ခြင်း](topic:set-the-scale))။ အမြင့်နှင့် အနက်သည် ပေအမှန် လိုအပ်သဖြင့် စကေးမရှိသော စာရွက်တွင် {{ui:3D}} က ထိုသို့ ပြောပြပြီး ပြားသော စာရွက်တွင်သာ ကျန်သည်။

## 3D view ဖွင့်ခြင်း

1. စစ်ဆေးလိုသော စာရွက်ကို ပြပါ။
2. စာရွက်၏ အမည်နှင့် စကေးကို ပြသော ဘားပေါ်ရှိ {{ui:3D}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:3}} ကို နှိပ်ပါ။
   ပထမဆုံးအကြိမ်တွင် 3D view ကို တင်ရန် ခဏ ကြာသည်။ စာရွက်ကို မြေပြင်ပေါ် ဆွဲထားပြီး တိုင်းတာမှုကို ပစ္စည်းတစ်ခုစီ၏ အရောင်ဖြင့် ၎င်းပေါ် ရပ်နေသည်။
3. ပြန်သွားရန် {{ui:3D}} ကို ထပ်ရွေးပါ၊ {{ui:Back to the sheet}}, သို့မဟုတ် {{key:3}} ကို နှိပ်ပါ။ ဆွဲကိရိယာ (Linear, Area, Count စသည်) တစ်ခုကို ရွေးလျှင်လည်း ပြန်သွားသည်၊ အမှတ်များကို ပြားသော စာရွက်ပေါ်တွင်သာ ဆွဲသည်။

စာရွက်ပေါ်တွင်သာ ပြသည်; စာရွက်များကို sheets စာရင်း သို့မဟုတ် {{key:PageDown}} နှင့် {{key:PageUp}} ဖြင့် ပြောင်းပါ၊ 3D view က လိုက်သည်။ ထပ်များစွာကို တစ်ပြိုင်နက် ကြည့်လိုပါက အောက်တွင် ဖော်ပြသည့်အတိုင်း ထပ်ပေါ်ထားပါ။

## ဘာတွေ့သလဲ

| အမှတ် | 3D တွင် |
|---|---|
| Linear run၊ အမြင့်ရှိသော ပစ္စည်း | ထို run တစ်လျှောက် ထိုအမြင့်ရှိ နံရံ။ ကွေးသော run များသည် ကွေးကိုလိုက်သည်။ |
| Linear run၊ အမြင့်မရှိသော ပစ္စည်း | စာရွက်ပေါ် မျဉ်းတစ်ကြောင်း။ ထောင်လိုပါက ပစ္စည်းကို **Item** အောက်တွင် အမြင့်ပေးပါ။ |
| Area၊ အနက်ရှိသော ပစ္စည်း | ထိုအနက်ရှိ slab၊ ၎င်း၏ ဖြတ်ထွက်ပေါက်များ ဖွင့်ထားသည်။ |
| Area၊ အနက်မရှိသော ပစ္စည်း | ပါးလွှာသော 2" ပလိတ်၊ ပေါ်စေရန်။ |
| Count | counted point တစ်ခုစီတွင် သေးငယ်သော တိုင်။ |

အမြင့်သည် linear ပစ္စည်း၏ {{ui:Height}} အကွက်ဖြစ်ပြီး အနက်သည် area ပစ္စည်း၏ {{ui:Depth}} အကွက် ဖြစ်သည်၊ **Item** အောက်တွင် ([တိုင်းတာမှုပစ္စည်းများ ဖန်တီးခြင်း](topic:create-items))။ ပြောင်းလိုက်လျှင် 3D view ချက်ချင်း အပ်ဒိတ်ဖြစ်သည်။ စာရွက်အမည်အောက်ရှိ မှတ်ချက်က စာရွက်တွင် ဘာပါသလဲဆိုသည်ကို ပြောသည်၊ ဥပမာ "This sheet in 3D: 2 walls, 1 slab, 3 counts"၊ နှင့် အမြင့် သို့မဟုတ် အနက် မရှိသော run သို့မဟုတ် area အရေအတွက်ကို ပြောသည်။ နှိပ်ခြင်းများသည် မှတ်ချက်ကို ဖြတ်ပြီး view သို့ ရောက်သည်။

3D တွင် နံပါတ်များ မပြောင်းပါ: နံရံ၏ ဧရိယာသည် တိကျသော အလျား ပြီး အမြင့်ဖြစ်သည်၊ slab ၏ ထုထည်သည် net ဧရိယာ (အပြင်အကျဉ်းနှုတ် ဖြတ်ထွက်ပေါက်များ၊ ကွေးများ တိကျစွာ) ပြီး အနက်ဖြစ်သည်။ ကွေးများကို မျက်နှာပြင်ပေါ်တွင်သာ တိုတိုမျဉ်းပိုင်းများဖြင့် ဆွဲသည်။

## အထူးအလွှာ၊ အခြေနှင့် ဖြတ်ထွက်ပေါက်များပါသော နံရံများ

အမြင့်ပါသော linear ပစ္စည်းသည် ပါးလွှာသော အစင်းအဖြစ် ရပ်သည်။ ၎င်းကို အမှန်နံရံအဖြစ် မြင်ရန် ပစ္စည်း၏ **In 3D** အောက်ရှိ ဆက်တင်များတွင် ပုံသဏ္ဌာန်ပေးပါ:

- **Wall thickness** (8", 0.2 m): နံရံသည် သင်ဆွဲထားသော မျဉ်းအလယ်တွင် ဗဟိုပြုပြီး mitred ထောင့်များပါသော တည်ငြိမ်သော အစိုင်အခဲ ဖြစ်လာသည်။
- **Base height**: နံရံသည် ကြမ်းပြင်မှ ထိုမျှ အမြင့်တွင် စတင်သည် (soffit၊ အပေါ်ဘက် ဗူးလိုင်း)။ ဧရိယာပစ္စည်းများတွင်လည်း ရှိသည်; 9'-0" ရှိ ခုံမြင့်။
- **Opening head**: နုတ်ထားသော အပိုင်း (တံခါး၊ [run တစ်ခု၏ အပိုင်းကို နုတ်ခြင်း](topic:measure-linear#deduct-a-part-of-a-run)) သည် နံရံကို ထိုအမြင့်အထက်တွင် ထားသဖြင့် တံခါးက တံခါးအဖြစ် ပေါ်သည်။ ၎င်းမရှိလျှင် နုတ်ထားသော အပိုင်းသည် ထိပ်အထိ ကွာလပ်ကျန်သည်။

ဤများသည် 3D view ကို သာ ပုံသဏ္ဌာန်ပေးသည်: ပမာဏများ (အလျား၊ နံရံဧရိယာ၊ ကုန်ကျစရိတ်) သည် မူလအတိုင်း ကျန်သည်။

## ထပ်များကို ပေါင်းခြင်း

1. ထပ်တိုင်း၏ PDF များကို ဖွင့်ပါ။
2. 3D view တွင် {{ui:Levels…}} ကို ရွေးပြီး ထပ်တစ်ခုစီ၏ အမြင့် ရိုက်ပါ၊ ဥပမာ မြေညီထပ်အတွက် `0`၊ နောက်ထပ်အတွက် `12'`။ ဗလာက စာရွက်ကို ချန်ထားသည်။
3. {{ui:Stack}} ကို ရွေးပါ။ အဆင့်ရှိသော စာရွက်တိုင်းသည် ၎င်း၏အမြင့်တွင် ၎င်းတို့၏ တိုင်းတာမှုကို ပြသည်; မျက်နှာပြင်ပေါ်ရှိ စာရွက်သည် ၎င်း၏ ကိုယ်ပိုင်ထပ်အောက်တွင်ရှိပြီး အခြားများကို ဘောင်ခတ်ပြသည်။ မှတ်ချက်က ထပ်ဘယ်နှစ်ထပ် ပေါင်းထားကြောင်း ပြောသည်။

စာရွက်များသည် စာမျက်နှာပေါ်ရှိ နေရာအလိုက် ညှိသည်၊ ထို့ကြောင့် တူညီစွာ ဆွဲထားသော ထပ်ပုံများ (စာရွက်အရွယ်နှင့် နေရာ တူညီ) တွင် အလုပ်လုပ်သည်။ အဆင့်ရှိပြီး စကေးမရှိသော စာရွက်ကို ချန်ထားပြီး မှတ်ချက်က ထိုသို့ ပြောသည်။ စာရွက်တစ်ရွက်ချင်းကို ကြည့်ရန် {{ui:Stack}} ကို ထပ်ရွေးပါ။ အဆင့်များကို တိုင်းတာမှုနှင့်အတူ သိမ်းသည်။

## 3D view ကို ပုံအဖြစ် သိမ်းခြင်း

3D ဘားပေါ်ရှိ {{ui:PNG}} ကို ရွေးပါက မျက်နှာပြင်ပေါ် ရှိအတိုင်း view ၏ ပုံ (`… 3D.png`) ကို ရမည်; {{key:Shift}} + {{ui:PNG}} ကို နှိပ်လျှင် နှစ်ဆ အရွယ် (`… 3D@2x.png`) ဖြစ်ပြီး ပရင့်ထုတ်ရန် ကောင်းသည်။

## 3D view ကို မော်ဒယ်အဖြစ် သိမ်းခြင်း

3D ဘားပေါ်ရှိ {{ui:GLB}} ကို ရွေးပါ။ view ပြသသည့်အရာ၏ `.glb` ဖိုင် (glTF, binary) ရရှိမည် — မျက်နှာပြင်ပေါ် ထပ်တစ်ထပ် သို့မဟုတ် ပေါင်းထားသော ထပ်အားလုံး — အခြား 3D ပရိုဂရမ်များ ဖွင့်နိုင်သော ဖိုင်၊ မှတ်တစ်ခုလျှင် အရာဝတ္ထု တစ်ခု၊ ပစ္စည်း၏အမည်ဖြင့်၊ ပစ္စည်း၏အရောင်ဖြင့်၊ မီတာဖြင့် Y အပေါ်ဘက်ဖြင့်။ စာရွက်ကိုယ်တိုင်နှင့် အပြင်အကျဉ်းများ ထဲ မပါပါ။

## 3D မှ မှတ်တစ်ခုကို ရွေးခြင်း

နံရံ၊ slab၊ ပလိတ် သို့မဟုတ် တိုင်တစ်ခုကို နှိပ်ပါ။ ၎င်း၏ မှတ်သည် ရွေးထားသော မှတ် ဖြစ်လာသည်၊ စာရွက်ပေါ်တွင် နှိပ်ခဲ့သကဲ့သို့ပင်။ **Selected mark** အောက်တွင် ပေါ်ပြီး ၎င်း၏ပစ္စည်းသည် လက်ရှိ ဖြစ်လာကာ အခြေအနေဘားက အလျားနှင့် အမြင့်၊ သို့မဟုတ် ဧရိယာ၊ အနက်နှင့် ကုဗယတ်ကို ပေးသည်။ {{key:Shift}} + နှိပ်ခြင်းက ရွေးချယ်မှုကို ထည့်သည် သို့မဟုတ် ဖယ်သည်။ {{key:Delete}} က ရွေးထားသော မှတ်များကို ဖျက်ပြီး {{key:Mod+Z}} က ပြန်ယူသည်; {{key:Esc}} က မည်သည်ကိုမျှ မရွေးပါ။ စာရွက်သို့ ပြန်သွားလျှင် တူညီသော မှတ်များ ရွေးထားဆဲ ဖြစ်သည်။

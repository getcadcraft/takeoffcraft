TakeoffCraft ၏ command များကို မည်သည့်နည်းဖြင့် ရောက်သည်ဖြစ်စေ တူညီပါသည်။ **မီနူးပုံစံ** သည် ၎င်းတို့ ဖန်သားပြင်ပေါ် ဘယ်မှာရှိမည်၊ ဘာခေါ်မည်နှင့် ဘယ်ခလုတ်များက run မည်ကိုသာ ဆုံးဖြတ်ပါသည်။ ၎င်းကို {{ui:ဆက်တင်များ}} ({{key:Mod+,}}) › {{ui:TakeoffCraft}} › {{ui:Menus, keys နှင့် mouse}} တွင် ရွေးပါ; ပြောင်းလဲမှုသည် ချက်ချင်းဖြစ်ပြီး ဤ browser က မှတ်ထားပါသည်။

ပုံစံသုံးမျိုးလုံးသည် TakeoffCraft ၏ ခလုတ်များကို ထိန်းထားသည်: {{key:V}} ရွေး၊ {{key:L}} linear၊ {{key:A}} ဧရိယာ၊ {{key:O}} စက်ဝိုင်း၊ {{key:B}} အခန်း၊ {{key:P}} path (PDF ၏ မျဉ်းများကို ရွေး)၊ {{key:X}} cut-out၊ {{key:C}} count၊ {{key:S}} auto count၊ {{key:K}} calibrate၊ {{key:D}} check၊ {{key:R}} arc mode၊ {{key:E}} deduct mode၊ {{key:F}} နှင့် {{key:W}} ညှိရန်၊ {{key:3}} 3D စစ်ဆေးမှု အမြင်၊ {{key:F3}} snap၊ နှင့် {{key:Mod+Z}}, {{key:Mod+Y}}, {{key:Mod+S}}, {{key:Mod+O}}, {{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}}, {{key:Mod+D}}, {{key:Mod+A}}။

ပုံစာရွက်ဘား၏ ကိရိယာများ (မှတ်စု၊ တိမ်၊ မီးမောင်း၊ Compare၊ 3D) သည် PDF ဖွင့်မှသာ ရရှိပါသည်; ၎င်းမတိုင်မီ ရွေးထားလျှင် status line က ထိုသို့ ပြောပါသည်။

:::tip
TakeoffCraft ၏ ကိုယ်ပိုင် layout နှင့် ဆိုင်သော ခလုတ်တစ်ခုကို သင့်ပုံစံက အခြား command ပေးထားလျှင် ဘာမျှ မလုပ်ပါ၊ နှင့် status line က ၎င်း၏ command ဘယ်ရောက်သွားသလဲဟု ပြောပါသည်။ ("In My keys, Count is Ctrl+Alt+C")။ {{key:Delete}}, {{key:Esc}}, {{key:Enter}}, {{key:Tab}}, {{key:Space}} နှင့် မြားခလုတ်များသည် အမြဲ မူလအဓိပ္ပာယ် ရှိနေပါသည်။ run သို့မဟုတ် outline ဆွဲနေစဉ်၊ auto count ကို ကူးထည့်ခြင်း သို့မဟုတ် သုံးသပ်ခြင်းအတွင်း၊ အက္ခရာများနှင့် ရိုက်ထည့်ထားသော အလျား၏ ဂဏန်းများသည် ပုံဆွဲနေရာတွင် ကျန်ပါသည်။
:::

## ကိုယ်ပိုင်ပြုလုပ်ခြင်း

1. သင်လိုချင်သည်နှင့် အနီးဆုံး ပုံစံကို ရွေးပြီး {{ui:စိတ်ကြိုက်ပြင်ရန်…}} ကို နှိပ်ပါ။
2. {{ui:Keys နှင့် menus}} တွင် command တစ်ခုကို ရှာပါ (ရှာဖွေရေးဘောက်စ်က ကူညီပါသည်)။ {{ui:key ထည့်ရန်}} ကို နှိပ်ပြီး ခလုတ်ကို နှိပ်ပါ၊ သို့မဟုတ် အက္ခရာနှစ်လုံး တစ်ဆက်တည်းဖြင့် ခလုတ်နှစ်ခုကို နှိပ်ပါ။ ခလုတ်တစ်ခုကို နှိပ်လျှင် ဖယ်ပါသည်။
3. မီနူးဘားဖြင့် {{ui:တည်နေရာ}} က command ကို အခြားမီနူးသို့ သို့မဟုတ် {{ui:Keys သာ}} သို့ ရွှေ့ပါသည်။
4. {{ui:Mouse}} တွင် ပုံစာရွက်ကို ရွှေ့ကြည့်စေသော wheel နှင့် ခလုတ်များကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။

built-in ပုံစံကို သိမ်းခြင်းသည် သင့်ကိုယ်ပိုင်မိတ္တူ ("My Takeoff desk") ဖန်တီးပါသည်; built-in တစ်ခုသည် ဘယ်တော့မှ မပြောင်းပါ။ command နှစ်ခုကို တူညီသော ခလုတ်ပေးလျှင် အနီရောင်ဖြင့် ပြပြီး သိမ်းခင် ပြင်ရပါမည်။

## Mouse

- **Mouse wheel**: {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom in}} (စတင်) သို့မဟုတ် {{ui:အပေါ်သို့ scroll လုပ်လျှင် zoom out}}၊ နှင့် ဘယ်လောက်မြန်သလဲ။ trackpad pinch က အမြဲ လက်ချောင်းများ လှုပ်ရှားသည့်အတိုင်း zoom လုပ်ပါသည်။
- **ပုံစာရွက်ကို ရွှေ့ခြင်း**: အလယ်ခလုတ်၊ ညာခလုတ် သို့မဟုတ် နှစ်ခုလုံး။ ဘာမျှမရှိသော စာရွက်ပေါ်တွင် ဘယ်ဘက် ဆွဲခြင်းနှင့် ဆွဲနေစဉ် {{key:Space}} သည် အမြဲ ရွှေ့ကြည့်ပါသည်; ဆွဲခြင်းမရှိဘဲ ညာ click သည် run သို့မဟုတ် outline ကို အမြဲ ပြီးဆုံးစေပါသည်။
- **3D အမြင်များတွင် ဆွဲခြင်း**: {{ui:view တစ်ခုစီ၏ ကိုယ်ပိုင်}} က 3D စစ်ဆေးမှု အမြင်၏ ခလုတ်များကို ထိန်းပါသည် (ဘယ်နှင့် အလယ်က လှည့်၊ ညာက ရွှေ့)။ သို့မဟုတ် အလယ်နှင့် ညာခလုတ်များကို လှည့်၊ ရွှေ့၊ zoom သို့မဟုတ် မည်သည်မျှ မပြုလုပ်ရန် သတ်မှတ်ပါ; {{key:Shift}} ကို ကိုင်ထားပြီး ခလုတ်သည် လှည့်ခြင်းနှင့် ရွှေ့ခြင်းကို လဲပါသည်။ ဘယ်ခလုတ်က အမြဲ လှည့်ပြီး ရွေးပါသည်။

## သင်နှင့်အတူ ယူသွားခြင်း

{{ui:ထုတ်ယူရန်}} သည် အသုံးပြုနေသော ပုံစံကို `.ccinput.json` ဖိုင်ငယ်တစ်ခုအဖြစ် သိမ်းပါသည်; {{ui:သွင်းရန်…}} က တစ်ခုကို ထည့်ပါသည်၊ အခြားကွန်ပျူတာ သို့မဟုတ် လုပ်ဖော်ကိုင်ဖက်ထံမှ ဖြစ်စေ။ တင်သွင်းထားသော ဖိုင်သည် TakeoffCraft ၏ ကိုယ်ပိုင် command များကိုသာ ညွှန်ပြနိုင်ပြီး အခြားအရာများ ပါလျှင် ထုတ်ပစ်ကာ status line တွင် ရေတွက်ပါသည်။ {{ui:ဤ style ကို ဖျက်ရန်}} က သင့်ကိုယ်ပိုင်တစ်ခုကို ဖယ်ပါသည်။

:::note
ဤဆက်တင်များသည် ဤ browser တွင် ကျန်ရှိပါသည်။ ပုံစံကတ်များအောက်ရှိ {{ui:ဤ style ကို အက်ပ်အားလုံးတွင် အသုံးပြုရန်}} က အက်ပ်တိုင်းကို ၎င်း၏ ကိုက်ညီသော ပုံစံ (ကိုယ်ပိုင်ကိရိယာဘား၊ မီနူးဘား သို့မဟုတ် ribbon) ဖြင့် ဖွင့်စေပြီး၊ အက်ပ်တစ်ခုစီတွင် ပြုလုပ်ထားသော ပြောင်းလဲမှုများနှင့်အတူ ဖြစ်ပါသည်။ TakeoffCraft တွင် command line ပါသော ပုံစံ မရှိပါ: အက်ပ်အားလုံးအတွက် ရွေးလျှင် TakeoffCraft က ကိုယ်ပိုင်ကိရိယာဘားကို ထားပါသည်။
:::

ပုံဆွဲအစုံသည် မကြာခဏ PDF အများအပြား ဖြစ်သည်: ဗိသုကာ၊ ဖွဲ့စည်းပုံ၊ စက်မှု။ TakeoffCraft သည် ၎င်းတို့ကို စာရွက်စာရင်းတစ်ခုတည်းအဖြစ် ဘေးဘက်တွင် ဖွင့်ပြီး takeoff တစ်ခုတည်းက အားလုံးကို လွှမ်းနိုင်သည်။

## PDF များ ဖွင့်ခြင်း

1. **ဖိုင်** အုပ်စုတွင် {{ui:Open plans}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ။ (အခြား menu ပုံစံများက ၎င်းကို {{ui:Open PDFs…}} ဟု ခေါ်သည်။)
2. ဖိုင်ဒိုင်ယာလော့ခ်တွင် ဤပုံဆွဲအစုံ၏ PDF အားလုံးကို ရွေးပါ။ အများအပြား ရွေးရန် {{pick:mac=Command|windows=Ctrl|linux=Ctrl}} ကို ကိုင်ပါ၊ သို့မဟုတ် အပိုင်းလိုက် ရွေးရန် {{key:Shift}} ကို သုံးပါ။
3. ဖွင့်ရန် ကို ရွေးပါ။
   PDF တစ်ခုချင်းစီကို ဖတ်နေစဉ် "(name) ဖွင့်နေသည်…" message ပြသည်။ ထို့နောက် စာမျက်နှာတိုင်းသည် {{ui:Sheets}} အောက်တွင် ပေါ်ပြီး ပထမ PDF အသစ်၏ ပထမစာမျက်နှာ ဖွင့်သည်။

PDF များကို {{pick:mac=Finder|windows=File Explorer|linux=သင့်ဖိုင်မန်နေဂျာ}} မှ ဆွဲယူပြီး TakeoffCraft ၏ မည်သည့်နေရာတွင်မဆို ချထားနိုင်သည်။ ဆွဲနေချိန်တွင် "Drop PDFs, DWG or DXF drawings, or a .takeoff.json" ဘောင် ပေါ်လာသည်။

နောက်ပိုင်း PDF ထပ်ထည့်ရန် အတူတူ ပြန်လုပ်ပါ။ ဖွင့်ပြီးသား PDF များကို ကျော်သွားသည်။

Start screen သည် browser များ (Chrome နှင့် Edge) တွင် စာမျက်နှာက ဖိုင်ကို ပြန်ဖွင့်ခွင့်ပြုသည့်အခါ မကြာသေးမီက ဖွင့်ခဲ့သော PDF နှင့် takeoff များကိုလည်း စာရင်းပြသည်။ တစ်ခုကို နှိပ်ပြီး ဖွင့်ပါ; browser က ခွင့်ပြုချက်ကို အရင်မေးနိုင်သည်။ ကြည့်ပါ [သင့်ဖိုင်များ](common:your-files)။

:::note
တစ်စုံတစ်ရာကို upload မလုပ်ပါ။ Browser က PDF များကို သင့်ကွန်ပျူတာပေါ်တွင် ဖတ်သည်၊ tab ကို ပိတ်သည့်အခါ သို့မဟုတ် {{ui:အသစ်}} ကို ရွေးသည့်အခါ TakeoffCraft မှ ပျောက်သွားသည်။
:::

## PDF ဘေးရှိ ပုံဆွဲများ

{{ui:Open plans}} သည် DWG နှင့် DXF ပုံဆွဲများကိုလည်း၊ တစ်ခုတည်း သို့မဟုတ် PDF များနှင့်အတူ ယူသည်: ပုံဆွဲတစ်ခုစီ၏ model space နှင့် layout များသည် တူညီသော စာရင်းထဲတွင် စာရွက်များဖြစ်လာသည်။ ကြည့်ပါ [DWG သို့မဟုတ် DXF ပုံဆွဲ ဖွင့်ခြင်း](topic:open-a-drawing)၊ ထို့နောက် [ပုံဆွဲမှ ရေတွက်ခြင်း](topic:count-from-a-drawing)။

## အခြား app မှ လွှဲပေးသော PDF

lineup ၏ အခြား app တစ်ခုက ၎င်းဖွင့်ထားသော PDF ကို လွှဲပေးနိုင်သည်: TakeoffCraft ကို tab အသစ်တွင် ဖွင့်ပြီး PDF သည် သင်ချထားသကဲ့သို့ ထိုနေရာတွင် ဖွင့်သည်။ Status bar က "(name) ကို ဖွင့်ပြီး (app) မှ လွှဲပြောင်းသည်။ မူရင်းဖိုင် မပြောင်းလဲပါ။" ဟု ပြသည်။ ဘာမျှ upload မလုပ်ပါ; ဖိုင်သည် ဤ browser ၏ ကိုယ်ပိုင်သိုလှောင်မှုကို ဖြတ်သန်းပြီး ဖွင့်ပြီးနောက် ထိုမှ ပျောက်သည်။

Status bar က PDF "မရောက်ရှိပါ" ဟု ပြပါက tab က ကြာလွန်းခဲ့သည် သို့မဟုတ် PDF ကို အခြား tab တွင် ဖွင့်ပြီးသား ဖြစ်သည်: {{ui:Open plans}} ဖြင့် ဖွင့်ပါ။

ပြောင်းပြန်ဘက်တွင်၊ MarkupCraft သည် သင်ရှိရာနေရာတွင် run လုပ်ပြီး ဖိုင်ကို လက်ခံနိုင်သည့်အခါ ပုံဆွဲအောက်ရှိ စာရွက်ဘားတွင် {{ui:MarkupCraft}} ခလုတ် ရှိသည်: ၎င်းသည် မျက်နှာပြင်ပေါ်ရှိ စာရွက်၏ PDF ကို MarkupCraft တွင် tab အသစ်ဖြင့် ဖွင့်ပြီး ပြန်လည်သုံးသပ်ခြင်း၊ အမှတ်အသားပြုခြင်း ပြုလုပ်နိုင်သည်။

## စာရွက်ရှာခြင်း

- ဘယ်ဘက်ရှိ {{ui:Sheets}} စာရင်းကို လှိမ့်ပြီး စာရွက်ကို နှိပ်ပါ။
- စာရင်း၏ အပေါ်ရှိ **Search sheets** တွင် ရိုက်ပြီး စာရွက်နံပါတ်၊ ဖိုင်အမည် သို့မဟုတ် page label ဖြင့် စစ်ပါ။ စစ်ထုတ်မှု ဖွင့်ထားချိန်တွင် {{ui:Sheets}} ဘေးရှိ ရေတွက်သည် "3 of 40" ဟု ပြသည်။
- {{key:PageDown}} ဖြင့် နောက်စာရွက်၊ {{key:PageUp}} ဖြင့် ယခင်စာရွက် ရွေးပါ။ ၎င်းတို့သည် စစ်ထုတ်ထားသော စာရင်းကို လိုက်သည်။

:::mac
Page Up နှင့် Page Down ကီးမရှိသော Mac keyboard တွင် fn ကို up သို့မဟုတ် down arrow နှင့်အတူ နှိပ်ပါ။
:::

## စာရွက်များကို အမည်ပေးပုံ

- PDF က label ပေးထားသော စာမျက်နှာ (ဥပမာ `A-101`) ကို ထို label ဖြင့် အမည်ပေးသည်။
- label မရှိသော စာမျက်နှာ (သို့မဟုတ် စာမျက်နှာနံပါတ်သာ ဖြစ်သော label) ကို "(file name), page (n)" ဟု အမည်ပေးသည်။
- PDF အများအပြား ဖွင့်ထားသောအခါ label ရှိသော စာရွက်များတွင် ဖိုင်အမည်လည်း ပါသည်: "A-101 — Architectural"။

စာရွက်အမည်များကို လက်ဖြင့် ရိုက်ထည့်၍ မရသေးပါ။

## စာရွက်ပတ်ဝန်းကျင် ကြည့်ခြင်း

- မောက်စ်ဘီးကို လှည့်ပြီး ညွှန်ပြရာနေရာတွင် zoom လုပ်ပါ။
- ဘယ် သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲ၍ pan လုပ်ပါ။ {{ui:Auto count}} ဖြင့် သို့မဟုတ် အမှတ်၏ ထောင့်ကို စတင်သည့်အခါ {{key:Space}} ကို ဖိထားပြီး ဆွဲပါ၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲပါ။
- {{key:F}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Fit page}} ကို ရွေးပါ၊ စာရွက်တစ်ခုလုံး မြင်ရရန်; {{key:W}} သို့မဟုတ် {{ui:Fit width}} က အကျယ်ကို ညှိသည်။
- {{key:Plus}} သို့မဟုတ် {{key:=}} ဖြင့် zoom in၊ {{key:Minus}} ဖြင့် zoom out ကို ကြည့်ရှုမှု အလယ်ဗဟိုဝန်းကျင်တွင် လုပ်ပါ။

စာရွက်တစ်ခုစီသည် ဖွင့်ထားသမျှ ၎င်း၏ zoom နှင့် နေရာကို မှတ်ထားသည်။

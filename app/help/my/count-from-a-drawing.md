sheet bar ပေါ်ရှိ {{ui:CAD count}} (အခြား menu styles တွင် **Count from the drawing** command) သည် DWG သို့မဟုတ် DXF က ရှိသည်ဟု ပြောသောအရာများကို ရေတွက်သည်။ {{ui:Auto count}} သည် သင်္ကေတ၏ ပုံကို ရှာပြီး တစ်ခုကို လွတ်နိုင်သည် သို့မဟုတ် မှားသည်ကို တွေ့နိုင်သော်လည်း ဤနေရာသည် objects များကို ရေတွက်သည်: `DOOR-36` အမည်ရှိ block ၏ insert တိုင်းသည် တံခါးတစ်ခု ဖြစ်သည်။ ပထမဆုံး ပုံဆွဲကို ဖွင့်ပါ: [Open a DWG or DXF drawing](topic:open-a-drawing)။

## block တစ်ခု ရေတွက်ခြင်း

1. ပုံဆွဲ၏ စာရွက်တစ်ခုကို ဖွင့်ပါ။ {{ui:CAD count}} သည် sheet bar တွင် ရှိသည်။
2. ၎င်းကို ရွေးပါ။ ဝင်းဒိုးသည် block များကို မည်မျှရှိသည်ဖြင့် ဖော်ပြသည်။ အမည်ဖြင့် ရှာပြီး တစ်ခုကို ရွေးပါ။
3. စာရင်းအောက်ရှိ လိုင်းကို စစ်ပါ: "22 found, 22 to add."
4. {{ui:Add to}} အောက်တွင် count item တစ်ခုကို ရွေးပါ၊ သို့မဟုတ် {{ui:A new count item}} ကို ထားပြီး အမည်ပေးပါ။
5. အရေအတွက်ကို ပြသော ထည့်ခလုတ်ကို ရွေးပါ: {{ui:Add 22 marks}}။ mark များသည် block ၏ insertion နေရာများတွင် ပေါ်လာပြီး item ၏ ပမာဏသည် အရေအတွက် ဖြစ်သည်။

ဤသည်မှာ undo တစ်ဆင့်ဖြစ်သည်: {{key:Mod+Z}} က mark များ (နှင့် item အသစ်) ကို အတူ ဖယ်ရှားသည်။ ခန့်မှန်းချက်၊ spreadsheet နှင့် marked PDF သည် item ကို အခြား count item ကဲ့သို့ ဆက်ဆံသည်။

### ဘာတွေ ရေတွက်သလဲ

- **block အမည်၏ insert တိုင်း**၊ စကေးနှင့် ထောင့်မည်သို့ပင်ဖြစ်စေ၊ model space သို့မဟုတ် paper space တွင်။ Block အမည်များသည် အက္ခရာ အကြီးအသေးကို မဂရုစိုက်ပါ။
- **Block arrays** (MINSERT): array ရှိ မိတ္တူတစ်ခုချင်းစီသည် တစ်ခုဖြစ်သည်။
- **အသိုက် block များ။** block တစ်ခုကို အခြား block တစ်ခုအတွင်း ထားပါက အနက်အတိမ်အနက် တိုင်းတွင် ရေတွက်သည်။ စာရင်းက "6 inside other blocks" ဟု ပြောသည်; ပုံဆွဲတွင် တိုက်ရိုက် ထားသော inserts များကိုသာ ရေတွက်ရန် {{ui:Count blocks inside other blocks too}} ကို အမှန်ခြစ်ဖြုတ်ပါ။
- **Dynamic blocks။** dynamic block သည် ဖိုင်က သိမ်းထားသော အမည်မဲ့ မိတ္တူများ (`*U12`) အောက်တွင် မဟုတ်ဘဲ ၎င်း၏ကိုယ်ပိုင်အမည်အောက်တွင် ရေတွက်သည်။ ၎င်း၏ state များကို သီးခြား ဖော်ပြသည် ("Single 12, Double 4"): state တစ်ခုကို ရွေးပါက ထို state များကိုသာ ရေတွက်သည်၊ သို့မဟုတ် {{ui:Every variant}}။ ဖိုင်က မိတ္တူတစ်ခု မည်သည့် state ကို ပြသနေသည်ကို မပြောပါက ထိုမိတ္တူများကို "(state not known)" ဟု ဖော်ပြသည်။
- **Layer filter။** layer အများအပြားပေါ်ရှိ block: **On layer** အောက်တွင် တစ်ခုကို ရွေးပါ။

### ဘာမရေတွက်သလဲ

- **ဝှက်ထားသော layers။** ဖိုင်တွင် ပိတ်ထား သို့မဟုတ် ခဲထားသော layer (သို့မဟုတ် {{ui:Layers}} တွင် သင်ဖျောက်ထားသော) ပေါ်ရှိ object ကို ချန်ထားပြီး လိုင်းက မည်မျှဖြစ်သည်ကို ပြောသည်: "3 on hidden layers left out"။ ထည့်ရန် {{ui:Count them too}} ကို အမှန်ခြစ်ပါ။
- **မဖွင့်ရသေးသော ချိတ်ဆက်ထားသော ပုံဆွဲများ** ကို မရေတွက်ပါ; ဝင်းဒိုးက ထိုသို့ ပြောသည်။
- **အခြား object တစ်ခုအပေါ် တိတိကျကျ ထပ်ထားသော အမျိုးအစားတူ object များ** ကို နှစ်ခုအဖြစ် ရေတွက်သည် (၎င်းတို့ သည် object နှစ်ခု ဖြစ်သည်) နှင့် ဝင်းဒိုးက ထိုသို့ ပြောသည်: ၎င်းသည် များသောအားဖြင့် ရေးဆွဲမှု အမှားဖြစ်ပြီး ကြည့်ရန် တန်ဖိုးရှိသည်။

## ဤစာရွက်ပြသသည် သို့မဟုတ် ပုံဆွဲတစ်ခုလုံး

- **ဤစာရွက်ပြသသည်** သည် စာရွက်ပြသသော objects များကို ရေတွက်သည်: layout ပေါ်တွင် ၎င်း၏ viewports အတွင်းရှိ model objects (viewport တွင် ခဲထားသော layer ကို ထိုနေရာတွင် မရေတွက်) နှင့် layout ၏ ကိုယ်ပိုင်အရာများ။
- **ပုံဆွဲတစ်ခုလုံး၊ object တစ်ခုစီ တစ်ကြိမ်** သည် model space ကို တစ်ကြိမ် ရေတွက်ပြီး Model စာရွက်ပေါ်ရှိ mark များနှင့်အတူ ဖြစ်ပြီး layouts အများအပြားက ထပ်ပြသော အရာများကို မရေတွက်ပါ။

layout က ပြသသည်ကို ရေတွက်ခြင်းနှင့် Model က ပြသသည်ကို ရေတွက်ခြင်းသည် object တူညီများအတွက် တူညီသော ဂဏန်းကို ပေးသည်; တစ်ခုတည်းသော item သို့ နှစ်ခုလုံး မထည့်ပါနှင့်။

## ထပ်ရေတွက်ခြင်း

တူညီသော item ဖြင့် တူညီသော block ကို ထပ်ရေတွက်ပါက အသစ်ဖြစ်သည်များကိုသာ ထည့်သည်: "22 already counted."။ mark တစ်ခုစီသည် object တစ်ခုကို ကိုယ်စားပြုသည်။

## အလွှာနှင့် အမျိုးအစားအလိုက်

**By layer and type** တွင် layer တစ်ခုနှင့် object အမျိုးအစား (စက်ဝိုင်းများ၊ polylines၊ hatches…) ကို ရွေးပါ: "all circles on E-LITE"။ block definitions အတွင်းရှိ objects များကိုလည်း ထည့်ရန် **Also count objects inside blocks** ကို အမှန်ခြစ်ပါ၊ block ကို insert လုပ်ထားသော နေရာတိုင်းတွင်။

## စာသားအလိုက်

**By text** တွင် `A3` ကဲ့သို့ စာသားကို ရိုက်ထည့်ပြီး ၎င်းက ထိုအတိုင်းအတိအကျ၊ ပါဝင်သည်၊ သို့မဟုတ် စကားလုံးတစ်လုံးအဖြစ် ဖြစ်သည်ကို ပြောပါ။ စာသား objects များ၊ multileader စာသားနှင့် block **attribute တန်ဖိုးများ** အားလုံး ရေတွက်သည် (tag attribute `ITEM = A3` ကို တွေ့သည်); attribute တစ်ခုတည်းကိုသာ ရေတွက်ရန် **In attribute** ကို ရွေးပါ။ အသုံးအများဆုံး စာသားများကို နှိပ်ရန် စာရင်းပြုစုထားသည်။

## Auto count ကို အစား သုံးသည့်အချိန်

PDF များနှင့် block မဟုတ်သော ပုံဆွဲရှိ သင်္ကေတများ (လွတ်ဆွဲထားသော သို့မဟုတ် explode လုပ်ထားသော) အတွက် {{ui:Auto count}} ကို သုံးပါ။ block များအဖြစ် ဆွဲထားလျှင် ဤနေရာတွင် ရေတွက်ပါ။

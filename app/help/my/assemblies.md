ပစ္စည်းတစ်ခု၏ **စုစည်းမှု** ဆိုသည်မှာ အစိတ်အပိုင်းများ စာရင်း ဖြစ်ပြီး အစိတ်အပိုင်းတစ်ခုစီတွင် ၎င်းတို့၏ ပမာဏဖော်မြူလာ၊ စွန့်ပစ်မှုနှုန်းနှင့် နှုန်းထားများ ရှိသည်။ ဖော်မြူလာသည် ပစ္စည်း၏ တိုင်းတာထားသော စုစုပေါင်းတန်ဖိုးများကို အသုံးပြုသဖြင့် နံရံတစ်ခု၏ တိုင်းတမှုတစ်ကြိမ်ဖြင့် ဘောင်များ၊ ပြားများနှင့် ဘုတ်များကို တစ်ပြိုင်နက် ရရှိပြီး သင်တိုင်းတာသည်နှင့်အမျှ ၎င်းတို့ အလိုအလျောက် အပ်ဒိတ်ဖြစ်သွားသည်။

## အသုံးပြုနိုင်သော variable များ

| ပစ္စည်းအမျိုးအစား | Variable များ |
|---|---|
| Linear | `L` အလျား, `H` အမြင့်, `A` နံရံဧရိယာ (L × H), `N` အပိုင်းအရေအတွက် |
| Area | `A` ဧရိယာ, `P` ပတ်လည် (အပြင်အကျဉ်း + ဖြတ်ထွက်ပေါက်များ), `H` အနက် သို့မဟုတ် ထူ, `N` ဧရိယာအရေအတွက် |
| Count | `N` အရေအတွက် |

တန်ဖိုးများသည် ပစ္စည်း၏ ကိုယ်ပိုင်ယူနစ်များဖြင့် ဖြစ်သည်- LF နှင့် SF ပစ္စည်းများအတွက် ပေ နှင့် စတုရန်းပေ၊ m နှင့် m² ပစ္စည်းများအတွက် မီတာ နှင့် စတုရန်းမီတာ။ SY ပစ္စည်းတွင် `A` သည် စတုရန်းကိုက်ဖြစ်ပြီး `P` နှင့် `H` မှာ ပေ အတိုင်းရှိနေသည်။

ဖော်မြူလာများတွင် `+ - * /` (သို့မဟုတ် × ÷), ကွင်းများ၊ ဂဏန်းများနှင့် `ceil`, `floor`, `round`, `min`, `max`, `abs` function များကို သုံးနိုင်သည်။ စည်းမျဉ်းအပြည့်အစုံကို [ဖော်မြူလာဘာသာစကား](topic:formulas) တွင် ကြည့်ပါ။

## အလုပ်ဖြစ်စဉ် ဥပမာ- အတွင်းနံရံ

**အတွင်းနံရံ အမျိုးအစား A** ကို linear ပစ္စည်းအဖြစ် တိုင်းထားသည်ဆိုပါစို့- အပိုင်း ၄ ခု စုစုပေါင်း 120 LF၊ {{ui:Height}} ကို `9'-0"` ထားသည်။ ၎င်း၏ **Measured** တန်ဖိုးများမှာ L = 120, N = 4, A = 1,080 (နံရံ SF, မျက်နှာတစ်ဖက်) ဖြစ်သည်။

1. {{ui:Items}} အောက်တွင် ပစ္စည်းကို ရွေးပါ။
2. {{ui:Assembly}} တွင် {{ui:Add component}} ကို ရွေးပါ။
   "Component" ဟု အမည်ရှိသော အစိတ်အပိုင်းတစ်ခု ပေါ်လာပြီး ဖော်မြူလာ `L` နှင့် ၎င်း၏ရလဒ်ကို အောက်တွင် မြင်ရမည်။
3. {{ui:Name}} တွင် `Studs 16 in o.c.` ကို ရိုက်ပြီး {{ui:Unit}} တွင် `EA` ကို ရိုက်ပါ။
4. {{ui:Quantity formula}} တွင် `ceil(L * 12 / 16) + N` ကို ရိုက်ပါ။
   ရိုက်သည်နှင့် ရလဒ် အလိုအလျောက် ပြောင်းသွားသည်- "= 94 EA"။ ၎င်းမှာ 120 ပေ အတွင်း 16 လက်မတိုင်း ဘောင်တစ်ခု (90) နှင့် အပိုင်း 4 ခုစီကို ပိတ်ရန် အပို တစ်ခုစီ ပေါင်းထားခြင်း ဖြစ်သည်။
5. ပလိတ်များအတွက် {{ui:Add component}} ကို ထပ်ရွေးပါ- အမည် `Plates, top and bottom`၊ ယူနစ် `LF`၊ ဖော်မြူလာ `L * 2`။ ရလဒ်- 240 LF။
6. ဘုတ်ကို ထည့်ပါ- အမည် `Gypsum board 4x8, both sides`၊ ယူနစ် `sheets`၊ ဖော်မြူလာ `ceil(A * 2 / 32)`။ ရလဒ်- 68 sheets (ဘုတ် 2,160 SF ÷ စာရွက်တစ်ခုလျှင် 32 SF = 67.5၊ အပေါ်သို့ ပြည့်အောင် ဖော်ထားသည်)။
7. အစိတ်အပိုင်းတစ်ခုစီ၏ {{ui:Waste %}}, {{ui:Material $}} နှင့် {{ui:Labor $}} ကို ဖြည့်ပါ။
   အစိတ်အပိုင်းတိုင်း {{ui:Quantities}} ထဲရှိ ပစ္စည်းအောက်တွင် သီးခြားအတန်းတစ်ခု ရရှိပြီး ပစ္စည်းကဲ့သို့ ဈေးနှုန်းသတ်မှတ်ကာ {{ui:Job total}} တွင် ပါဝင်သည်။

နံရံ၏ ကုန်ကျစရိတ် အားလုံးသည် အစိတ်အပိုင်းများတွင်သာ ရှိပါက ပစ္စည်း၏ ကိုယ်ပိုင် ပစ္စည်းနှင့် အလုပ်သမား နှုန်းထားများကို 0 ထားပါ၊ မဟုတ်ပါက ကုန်ကျစရိတ် နှစ်ဆ ရေတွက်မိမည်။

:::tip
စွန့်ပစ်မှုကို ဖော်မြူလာအပြီးတွင် အသုံးပြုပြီး ပြည့်အောင် မဖော်ပါ- စာရွက် 68 ခုကို 10% စွန့်ပစ်မှုဖြင့် စာရွက် 74.8 ခု ဖြစ်သည်။ စာရွက်အပြည့်သာ မှာယူလိုပါက စွန့်ပစ်မှုကို `ceil(A * 2 / 32 * 1.1)` ကဲ့သို့ ဖော်မြူလာအတွင်း ထည့်ပြီး အစိတ်အပိုင်း၏ စွန့်ပစ်မှုကို 0 ထားပါ။
:::

## ဖော်မြူလာ နောက်ထပ်များ

| ရည်ရွယ်ချက် | ပစ္စည်း | ဖော်မြူလာ |
|---|---|---|
| ဘောင်များ 24 လက်မ center | Linear | `ceil(L / 2) + N` |
| Insulation batts, SF | အမြင့်ပါ Linear | `A` |
| ဆေး၊ မျက်နှာနှစ်ဖက်၊ ဂယ်လံ 350 SF | အမြင့်ပါ Linear | `ceil(A * 2 / 350)` |
| Tile ကတ်တွန်၊ 15 SF၊ 10% အပို | Area | `ceil(A * 1.1 / 15)` |
| Base သို့မဟုတ် edge trim, LF | Area | `P` |
| ကွန်ကရစ်၊ ကုဗယတ် | အနက်ပါ Area | `A * H / 27` |
| ကွန်ကရစ်၊ ကွာတာယတ်အထိ ပေါင်းထား | အနက်ပါ Area | `ceil(A * H / 27 * 4) / 4` |
| Hinge၊ တံခါးတစ်ခုလျှင် သုံးခု | Count | `N * 3` |
| အနည်းဆုံး သေတ္တာတစ်ခု၊ ၁၂ ခုလျှင် တစ်ခု | Count | `max(1, ceil(N / 12))` |

## ဖော်မြူလာ မှားသောအခါ

ဖော်မြူလာအောက်ရှိ မျဉ်းသည် အမှားစာသားအဖြစ် ပြောင်းသွားသည်၊ ဥပမာ `"X" is not a measured value here. Use L, H, A, N.` သို့မဟုတ် `A ")" is missing.`။ ထို့နောက် အစိတ်အပိုင်းတွင် ပမာဏ မရှိတော့ပြီး {{ui:Quantities}} ထဲရှိ အတန်းတွင် "Formula error: …" ပြသကာ header တွင် "Incomplete: 1 formula error (not in the totals)" ဟု ပြသသည်။ ဖော်မြူလာကို ပြင်လိုက်လျှင် စုစုပေါင်းများ အပ်ဒိတ်ဖြစ်သွားသည်။

သုညဖြင့် စားသောဖော်မြူလာလည်း အမှားဖြစ်သည် ("The formula divides by zero.")၊ ဥပမာ အနက်မရှိသော ပစ္စည်းတွင် `A / H`။

## ကန့်သတ်ချက်များ

- ဖော်မြူလာများသည် အပိုင်းတစ်ခုချင်းစီအလိုက် မဟုတ်ဘဲ ပစ္စည်း၏ **စုစုပေါင်း** ပေါ်တွင် လည်ပတ်သည်။ `ceil(L * 12 / 16) + N` သည် အပိုင်းတစ်ခုလျှင် ဘောင်တစ်ခု ပေါင်းသော်လည်း အပိုင်းတစ်ခုချင်းစီအလိုက် ပေါင်းခြင်း ဆိုင်ရာ ပြည့်စုံမှု မရှိသေးပါ။
- ဖော်မြူလာသည် ၎င်းနှင့် ပတ်သက်သော ပစ္စည်း၏ variable များကိုသာ အသုံးပြုနိုင်ပြီး အခြားပစ္စည်း၏ variable များကို မသုံးနိုင်ပါ။
- ပစ္စည်းတစ်ခုလျှင် အစိတ်အပိုင်း 50 အထိ၊ ဖော်မြူလာတစ်ခုလျှင် စာလုံး 500 အထိ။

## အစိတ်အပိုင်းတစ်ခု ဖယ်ရှားခြင်း

အောက်ရှိ {{ui:Remove component}} ကို ရွေးပါ။ {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သည်။

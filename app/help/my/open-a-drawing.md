TakeoffCraft သည် DWG သို့မဟုတ် DXF ပုံဆွဲကို PDF ကဲ့သို့ ဖွင့်သည်: PDF သို့ အရင် plot လုပ်စရာမလို။ ပုံဆွဲကိုယ်တိုင်မှ ရေတွက်ခြင်းသည် တိကျသည်၊ ပုံဆွဲက အရာတစ်ခုစီက ဘာလဲဆိုတာ သိသည်ကြောင့်ဖြစ်သည်။ ကြည့်ပါ [ပုံဆွဲမှ ရေတွက်ခြင်း](topic:count-from-a-drawing)။

## ပုံဆွဲကို ဖွင့်ခြင်း

1. **ဖိုင်** အုပ်စုတွင် {{ui:Open plans}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပါ။
2. DWG သို့မဟုတ် DXF ဖိုင်ကို ရွေးပါ။ အများအပြား ရွေးနိုင်သည်၊ PDF များနှင့်လည်း ရွေးနိုင်သည်။
3. ဖွင့်ရန် ကို ရွေးပါ။

ပုံဆွဲဖိုင်များကို PDF ကဲ့သို့ TakeoffCraft ပေါ်သို့ ချထားနိုင်သည်။ ဘာမျှ upload မလုပ်ပါ: browser က သင့်ကွန်ပျူတာပေါ်ရှိ ဖိုင်ကို ဖတ်သည်။

TakeoffCraft သည် AutoCAD 2000 မှ 2018 အထိ DWG ကို၊ R12 မှ 2018 အထိ ASCII DXF ကို ဖတ်သည်။ binary DXF (ASCII သို့မဟုတ် DWG အဖြစ် သိမ်းပါ) နှင့် ဘာမဟုတ်သော ဖိုင်ကို ငြင်းပြီး အကြောင်းပြသည်။ ပျက်စီးနေသော ဖိုင်ကို ဖတ်နိုင်သမျှဖြင့် ဖွင့်ပြီး ထိုအကြောင်း message ဖြင့် ပြောသည်; ၎င်း၏ ရေတွက်မှုများ မပြည့်စုံနိုင်ပါ။

## စာရွက်များ

- **Model** သည် ပုံဆွဲ၏ model space ဖြစ်သည်။
- **Layout တစ်ခုစီ** (paper space tab) သည် စာရွက်တစ်ရွက်ဖြစ်ပြီး tab အမည်ဖြင့်၊ tab အစီအစဉ်အတိုင်း အမည်ပေးသည်။ Layout တစ်ခုသည် ၎င်း၏ viewport များမှတစ်ဆင့် model ကို plot လုပ်သည့်အတိုင်း ပြသည်။

Zoom၊ pan၊ ပုံဆွဲ၏ မျဉ်းများသို့ snapping၊ အမှတ်များ၊ မှတ်စုများ၊ {{ui:Calibrate}} နှင့် အခြားအရာများသည် PDF ပေါ်ကဲ့သို့ အလုပ်လုပ်သည်။ ပုံဆွဲ၏ စာရွက်များကို takeoff တွင် ဖိုင်အမည်နှင့် အကြောင်းအရာ၏ fingerprint ဖြင့် သိမ်းသည်၊ PDF ကဲ့သို့ပင်: ဖိုင်တူကို ပြန်ဖွင့်လျှင် အမှတ်များသည် ၎င်း၏ စာရွက်များပေါ်တွင် ရှိနေသည်။

## စကေး

စာရွက်တစ်ရွက်သည် ပုံဆွဲက ပေးသော စကေးဖြင့် စတင်သည်:

- **Layout** သည် ၎င်း၏ အကြီးဆုံး viewport ၏ စကေးကို ယူသည်။ 1/2" = 1'-0" ကဲ့သို့ စကေးကို ၎င်း၏ preset အမည်ဖြင့် ခေါ်သည်; အခြားမည်သည့်စကေးကိုမဆို "From the drawing's viewport: 1" = 2.5'" ဟု ပြသည်။ layout တစ်ခုတွင် အခြားစကေး viewport များရှိလျှင် အကြီးဆုံးက စာရွက်၏ စကေးကို သတ်မှတ်သည်: အခြားများကို {{ui:Check}} ဖြင့် စစ်ပါ။
- **Model** သည် ပုံဆွဲ၏ ယူနစ်များ (လက်မ၊ မီလီမီတာ၊ ပေ…) ကို စကေးအဖြစ် ယူသည်၊ "Drawing units (inches)" ဟု ပြသည်။
- **ယူနစ်မရှိသော ပုံဆွဲ** (ယူနစ်တစ်ခုသည် လက်မ သို့မဟုတ် မီလီမီတာ ဖြစ်သည်ကို ပုံဆွဲက ဘယ်တော့မှ မပြောခဲ့) တွင် စကေးမရှိပါ: စာရွက်က "No scale" ဟု ပြပြီး PDF တွင် စကေးမရှိသကဲ့သို့ ထိုစာရွက်ပေါ်တွင် တိုင်းတာခြင်းကို ငြင်းသည်။ ရေတွက်ခြင်းသည် စကေးမလိုပါ။ {{ui:Calibrate}} ဖြင့် တစ်ခုပေးပါ။

{{ui:Calibrate}}၊ {{ui:Check}} နှင့် {{ui:Preset}} စာရင်းသည် စကေးကို အချိန်တိုင်း ပြောင်းနိုင်ပြီး ပုံဆွဲ၏ စကေးထက် ဦးစားပေးသည်။ Preset စာရင်းကို Model တွင် ပိတ်ထားသည်၊ ၎င်းတွင် စာရွက်အရွယ်အစား မရှိသောကြောင့်။

## Layer များ

စာရွက်ဘားပေါ်ရှိ {{ui:Layers}} သည် ပုံဆွဲ၏ layer များကို ဤစာရွက်ပေါ်တွင် အရာဝတ္ထု မည်မျှရှိသည်ကို ပြသည်။ ဖိုင်က ပိတ်ထားသော သို့မဟုတ် freeze လုပ်ထားသော layer များသည် ဖျောက်ထားသည်အဖြစ် စတင်သည်။ layer ကို ဖျောက်ရန် အမှန်ခြစ်ဖြုတ်ပါ၊ ဖျောက်ထားသည်ကို ပြရန် အမှန်ခြစ်ပါ: စာရွက်ကို ပြန်ဆွဲပြီး ဖျောက်ထားသည်များကို ရေတွက်ခြင်းနှင့် {{ui:Measure drawing}} သို့ ပေးသော အရာဝတ္ထုများထဲမှ ချန်ထားသည်၊ ဖျောက်ထားသော layer များကိုလည်း ရေတွက်ရန် တောင်းဆိုမထားလျှင်။ {{ui:Show all}} က layer အားလုံးကို ပြသည်; {{ui:Back to the file's layers}} က သင့်ပြောင်းလဲမှုများကို ပြန်ဖျက်သည်။ Layer ရွေးချယ်မှုများသည် ဤ session နှင့်သာ သက်ဆိုင်ပြီး takeoff ဖိုင်နှင့် မဆိုင်ပါ။

## ချိတ်ဆက်ထားသော ပုံဆွဲများ (xref)

ပုံဆွဲတစ်ခုက အခြားပုံဆွဲများကို ထည့်ထားသည့်နေရာတွင် ပြသည်။ TakeoffCraft သည် ချိတ်ဆက်ထားသော ပုံဆွဲကို **ဖွင့်ထားသော ဖိုင်များ** ထဲတွင် ဖိုင်အမည်ဖြင့် ရှာသည်: host ပုံဆွဲနှင့် ချိတ်ဆက်ထားသော ပုံဆွဲကို အတူ (သို့မဟုတ် တစ်ခုပြီးတစ်ခု) ဖွင့်ပါ။ ထိုအချိန်အထိ status bar က ချိတ်ဆက်ထားသော ပုံဆွဲ မည်မျှ မတွေ့ရသည်ကို ပြပြီး ၎င်းတို့ ဆွဲသည့်အရာ ပျောက်နေကြောင်း၊ ရေတွက်မှုများက ထိုအကြောင်းကို ပြောသည်။

## ကန့်သတ်ချက်များ

- TakeoffCraft ဖတ်ခြင်း သို့မဟုတ် နေရာချနိုင်ခြင်းမရှိသော အရာဝတ္ထုများ (proxy object များ၊ အမျိုးအစားမသိသော class များ) ကို ရေတွက်ဝင်းဒိုးတွင် အမျိုးအစားအလိုက် ဖော်ပြသည်; ၎င်းတို့ကို စကားမပြောဘဲ ဘယ်တော့မှ ချန်မထားပါ။
- အလွန်ကြီးမားသော ပုံဆွဲများကို အပိုင်းလိုက် ဆွဲပြီး ရေတွက်မှုများသည် ကန့်သတ်ချက်တွင် ရပ်သည်၊ ထိုအကြောင်း ပြောသည်။ ထိုသို့သော ပုံဆွဲအတွက် PDF plot ကို အစားဖွင့်ပါ။
- ပုံဆွဲကို အဖြူရောင် စက္ကူအတွက် မှိန်ထားသော အမည်းနှင့် ၎င်း၏ကိုယ်ပိုင်အရောင်များဖြင့် ဆွဲသည်။ Plot style ဇယားများနှင့် ဘောပင်သတ်မှတ်ချက်များကို အသုံးမပြုပါ။

TakeoffCraft 0.8.1 နှင့် နှိုင်းယှဉ်ပါက 0.9 တွင် ပြောင်းလဲမှုများ ဤသည်ဖြစ်သည်။ ဤသည် ဤ app အတွက် သေးငယ်သော ထုတ်ဝေမှုဖြစ်သည်: အလျားများကို မီတာ၊ စင်တီမီတာ သို့မဟုတ် မီလီမီတာဖြင့် ဖတ်နိုင်ပြီး၊ ဧရိယာများနှင့် scale များ မက်ထရစ်အလုပ်ကို ကောင်းစွာ လိုက်ပါသည်၊ Arc တွင် ပုံဆွဲနည်း ဆယ်မျိုး ရှိသည်။ Live session များသည်လည်း ဘယ်သူ ဘယ်မှာရှိသည်ကို ပြသည်။

## အသစ်

### အလျားများကို မီတာ၊ စင်တီမီတာ သို့မဟုတ် မီလီမီတာဖြင့် ဖတ်ပါ

- **အလျားများကို ဤအတိုင်း ပြပါ။** {{ui:ဆက်တင်များ}} › {{ui:TakeoffCraft}} တွင် {{ui:အလျားများကို ပြသပုံ}} ရှိသည် ({{ui:Global အတိုင်း}}၊ {{ui:ပေ-လက်မ}}၊ m၊ cm နှင့် mm)။ {{ui:Global အတိုင်း}} က {{ui:ဆက်တင်များ}} › {{ui:Global}} › {{ui:ယူနစ်များ}} တွင် ကြယ်ပွင့်ပေးထားသော မက်ထရစ် အလျားယူနစ်ကို သုံးသည်၊ မရှိပါက ပေ-လက်မကို သုံးသည်။ စာရွက်ပေါ်၊ status bar နှင့် panel များတွင် အလျားများ ဖတ်ပုံကို ပြောင်းသည်၊ အမြင့်၊ အနက်၊ အထူ နှင့် အဆင့်များအပါအဝင်။ အမြင့်အကွက်တွင် ဂဏန်းတိုတစ်ခုတည်း ရိုက်ပါက ပြထားသော ယူနစ်ဖြင့် ဖတ်သည်။
- **ပြသရုံသာ။** ပမာဏများ၊ ကုန်ကျစရိတ်များနှင့် export များကို တိကျသော အလျားများမှ တွက်သည်။ 1/16၊ 1/8 နှင့် 1/4 လက်မ ရွေးချယ်မှုသည် feet-inches အတွက်သာ ပေါ်သည်။ [မီတာဖြင့် အလျားများ ပြရန်](topic:show-lengths-in-meters) ကို ကြည့်ပါ။
- **အလေးချိန်ယူနစ်များ။** {{ui:ရိုက်ထည့်ထားသော ပမာဏ (ပုံဆွဲမလို)}} item ကို lb၊ TON၊ kg သို့မဟုတ် t ဖြင့် ထားနိုင်ပြီး ယူနစ်အလိုက် ဈေးနှုန်းသတ်မှတ်နိုင်သည်။
- **အပူချိန်။** item တိုင်းတွင် item editor ထဲ ရွေးချယ်နိုင်သော {{ui:Temperature}} အကွက် ရှိပြီး °C သို့မဟုတ် °F ဖြင့် ရိုက်ထည့်သည်။ {{ui:ဆက်တင်များ}} › {{ui:TakeoffCraft}} ရှိ {{ui:အပူချိန်ကို ဤအတိုင်း ပြရန်}} က {{ui:Global အတိုင်း}}၊ °C သို့မဟုတ် °F ကို ပေးသည်။

### မက်ထရစ်အလုပ်အတွက် ဧရိယာများနှင့် scale များ

- **ပုံဆွဲပေါ်ရှိ ဧရိယာများ m2 ဖြင့်။** မက်ထရစ် item ဖြင့် တိုင်းသော ဧရိယာသည် ပုံဆွဲ tag နှင့် mark panel တွင် SF အစား m2 ဟု ပြောပြီး table တွင်လည်း ထိုအတိုင်း ဖြစ်သည်။ စည်းမျဉ်းမှာ item ကို မက်ထရစ်ဖြင့် ဈေးနှုန်းသတ်မှတ်ထားခြင်း သို့မဟုတ် အလျားကို m၊ cm သို့မဟုတ် mm ဖြင့် ပြသထားခြင်းဖြစ်ပါက m2၊ မဟုတ်ပါက SF ဖြစ်သည်။
- **နံရံဧရိယာ။** အမြင့်ပါသော linear item သည် Items စာရင်းတွင်နှင့် by-item ပမာဏ table အောက်ရှိ မှတ်ချက်အတန်းအဖြစ် နံရံဧရိယာ (အလျား × အမြင့်) ကိုလည်း ပြသည်။
- **Scale preset 1:75 နှင့် 1:150။** scale ၃၂ ခု ရှိသော {{ui:စကေး}} အုပ်စု၏ {{ui:ကြိုတင်သတ်မှတ်ချက်}} စာရင်းတွင် ရှိသည်။ [Scale presets](topic:scale-presets) ကို ကြည့်ပါ။

### Arc နည်းလမ်း ဆယ်မျိုး

- {{ui:အဝိုင်းကွေး}} ဖွင့်ထားစဉ် (toolbar ခလုတ် သို့မဟုတ် {{key:R}}) sheet bar တွင် {{ui:Arc method}} အကွက် ပေါ်လာသည်: 3-Point, Start, Center, End, Start, Center, Angle, Start, Center, Length, Start, End, Angle, Start, End, Direction, Start, End, Radius, Center, Start, End, Center, Start, Angle နှင့် Center, Start, Length။ Angle၊ length၊ radius နှင့် direction ကို click လုပ်နိုင် သို့မဟုတ် ရိုက်နိုင်သည်။ linear run များ၊ area များနှင့် cut-out များတွင် အလုပ်လုပ်သည်။ 0.9 မတိုင်မီ သိမ်းထားသော ဖိုင်များသည် အတူတူ ဖွင့်သည်။ [Arc ကို နည်းလမ်းဆယ်မျိုးဖြင့် ဆွဲရန်](topic:draw-arcs-ten-methods) ကို ကြည့်ပါ။

### အတူ လုပ်ဆောင်ခြင်း

- **တစ်ယောက်နှင့်တစ်ယောက် cursor များ မြင်ရသည်။** Live session တွင် လူတစ်ဦးစီ၏ pointer သည် ၎င်းတို့၏ အမည်နှင့် အရောင်ဖြင့် စာရွက်ပေါ်တွင် ပြသည်၊ ၎င်းတို့ ရွေးထားသော အမှတ်အသားများ ပတ်လည်တွင် အစက်မျဉ်ဘောင် ပါသည်။ အခြား စာရွက်ပေါ်ရှိ သူများကို ထိုစာရွက်၏ အမည်ဖြင့် စာရင်းပြုသည်။ [အခြားသူများနှင့် တစ်ပြိုင်နက် အလုပ်လုပ်ခြင်း](topic:work-live) ကို ကြည့်ပါ။
- **တစ်ဦးကို လိုက်ခြင်းနှင့် လူစာရင်း။** Live session ရှိ {{ui:လူများ}} ခလုတ်က လူတစ်ဦးစီ၏ ၎င်းတို့ လည်ပတ်သော ကိရိယာ၊ ရောက်နေသော စာရွက်နှင့် နောက်ဆုံး တည်းဖြတ်ခဲ့သည့်အချိန်ကို ပြသည်။ {{ui:လိုက်ရန်}} က သင့် view ကို သူတို့နှင့်အတူ ရွှေ့ပေးသည်၊ host က {{ui:အားလုံးကို ကျွန်ုပ်ကို လိုက်ရန် တောင်းဆိုရန်}} ကို သုံးနိုင်သည်။ [Live session တွင် တစ်ဦးကို လိုက်ရန်](topic:follow-a-teammate) ကို ကြည့်ပါ။

## app အားလုံးတွင်

- **Tooltips နှင့် စတင်အကြံပြုချက်။** ကာဆာတင်ထားသော စာသားသည် Bootstrap tooltip ဖြစ်ပြီး စတင်အကြံပြုချက်ကို ပိတ်နိုင်သည်။
- **ရွှေ့နိုင်သော tab အစင်းများ။** panel ၏ tab အစင်းသည် မကိုက်ညီပါက ဖြတ်မခံဘဲ scroll လုပ်သည်။
- **Tab ခေါင်းစဉ်များ။** browser tab သည် `<document> - TakeoffCraft | CadCraft` ဟု ဖတ်သည်။
- **Layout။** {{ui:ဆက်တင်များ}} ရှိ layout စာရင်းသည် ရွေးထားသော layout ကို ပြသော drop-down ဖြစ်သည်။
- **ဘာသာစကား။** သင်ရွေးသော ဘာသာစကားသည် ယခု စာမျက်နှာကိုယ်တိုင် ပရင့်ထုတ်သော စာသားများ၊ ဥပမာ အသစ်၊ ဖွင့်ရန်နှင့် သိမ်းရန် သို့ ရောက်သည်။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် ဇာတိသုံးစွဲသူက မဖတ်မချင်း စက်ဖြင့် ဘာသာပြန်ထားသော မူကြမ်းများ ဖြစ်သည်။

## ရိုးရိုးသားသား ကန့်သတ်ချက်များ

- အလျား ပြသမှု၊ weight နှင့် အပူချိန်ယူနစ်များနှင့် preset အသစ်များကို စမ်းသပ်ချက်များနှင့် စာမျက်နှာတွင် စစ်ဆေးထားသည်။ ယူနစ်တိုင်းတွင် panel တိုင်းကို လက်ဖြင့် မစစ်ဆေးရသေးပါ။
- လူစာရင်းကို ဆရာနှင့် ကျောင်းသားအစစ်အမှန် အတန်းဖြင့် လက်ဖြင့် မစစ်ရသေးပါ။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် စက်ဖြင့် ဘာသာပြန်ထားသော မူကြမ်းများ ဖြစ်သည်။
- Windows installer များကို code-sign မလုပ်ထားပါ (နောက်ထပ် အချက်အလက်၊ ထို့နောက် မည်သို့ပင်ဖြစ်စေ ဆက်လုပ်ရန်)။ macOS disk image ကို notarize မလုပ်ထားပါ (right-click၊ ထို့နောက် ဖွင့်ရန်)။

## အစောပိုင်း: 0.8 နှင့် 0.8.1

TakeoffCraft 0.8 (2026-11-01 တွင် ထုတ်ဝေ) နှင့် 0.8.1 (2026-11-02) ၏ ပြောင်းလဲမှုများ ဤသည်ဖြစ်ပြီး 0.7 နှင့် နှိုင်းယှဉ်ထားသည်။ သင်္ကေတ legend ကို set တစ်ခုလုံးတွင် တစ်ကြိမ်တည်း ရေတွက်နိုင်ပြီ၊ takeoff အသစ်ကို သင့်ယခင် job များ၏ ဈေးနှုန်းများမှ စတင်နိုင်ပြီ၊ takeoff ကို supplier ၏ stock နှင့် စစ်ဆေးနိုင်ပြီ။ 0.8.1 သည် fix ထုတ်ဝေမှု ဖြစ်သည်။

### အသစ်

**Set တစ်ခုလုံးရှိ အရာအားလုံး ရေတွက်ပါ**

- **Legend ကို တစ်ကြိမ် ဘောင်ခတ်ပါ။** toolbar ရှိ {{ui:အားလုံး ရေတွက်ရန်}} က သင်္ကေတ legend ကို ဖတ်သည်: သင်္ကေတများနှင့် ၎င်းတို့ဘေးရှိ ပရင့်ထားသော အမည်များကို ဘောင်ခတ်ပါ။ သင်္ကေတတစ်ခုစီကို ပုံနှင့် အမည်ဖြင့် စာရင်းပြုသည်၊ အမည်သည် item ၏ အမည် ဖြစ်လာသည်။ မလိုချင်သည်များကို ဖယ်ထုတ်ပြီး {{ui:စာရွက် N ရွက်တွင် ရေတွက်ရန်}} ကို ရွေးပါ။ ဘားက ရှာနေသော စာရွက်ကို ပြသည်၊ {{ui:ပယ်ဖျက်ရန်}} က run ကို ရပ်ပြီး စာမျက်နှာ အသုံးပြုနိုင်ဆဲဖြစ်သည်။
- **Set အားလုံးတွင် run တစ်ခု။** သင်္ကေတတစ်ခုစီကို ဖွင့်ထားသော စာရွက်တိုင်းတွင် ရေတွက်သည်။ အခြား scale ဖြင့် ဆွဲထားသော စာရွက်ကို ထို scale ဖြင့် ရှာသည်၊ သင်္ကေတများကို ထောင့်မှန် မည်သည့်ထောင့်တွင် လှည့်ထားသည်ဖြစ်စေ တွေ့သည်။ legend ၏ ကိုယ်ပိုင် သင်္ကေတများကို ထိုစာရွက်တွင် မရေတွက်ပါ။
- **ထည့်မီ သုံးသပ်ပါ။** စုစုပေါင်းတိုင်းတွင် စာရွက်အလိုက် link တစ်ခုရှိသည် ("E-103: 4") ထို စာရွက်သို့ သွားသည်။ တွေ့ချက်ပေါ်ရှိ ဘောင်ကို နှိပ်ပြီး ထားခဲ့ပါ၊ ထပ်နှိပ်ပါက ပြန်ထည့်သည်။ ကိုက်ညီမှုအဆင့် (50% မှ 100%) က တွေ့ထားသည်များကို စစ်ထုတ်ရုံသာ; ဘာမျှ ပြန်မရှာပါ။
- **undo အဆင့်တစ်ခု။** {{ui:အမှတ် N ခု ထည့်ရန်}} က တွေ့သော သင်္ကေတတစ်ခုစီအတွက် count item တစ်ခု ပြုလုပ်ပြီး တွေ့တိုင်း အမှတ်အသားတစ်ခု ပေးသည်။ သင့်ရှိပြီးသား count item အမည် ပြန်သုံးသည်။ {{key:Ctrl+Z}} က item နှင့် အမှတ်အသားအားလုံးကို ပြန်ဖျက်သည်။ သင်လက်ခံသည်များက {{ui:သင်ယူပြီး}} ကိုလည်း ကျွေးသည်။
- **မည်သည့်ထောင့်ရှိ သင်္ကေတမဆို။** ရေတွက်ခြင်းမပြုမီ {{ui:မည်သည့်ထောင့်ရှိ သင်္ကေတများ}} ကို ရွေးပါ၊ right angle မဟုတ်သော ထောင့်ဖြင့် လှည့်ထားသော သင်္ကေတများကိုလည်း ရှာရန်။ ထို့နောက် ရှာဖွေမှုသည် သင်္ကေတတစ်ခုစီကို ၁၅ ဒီဂရီတိုင်း လှည့်ပြီး၊ ဝိုင်းမနေသော သင်္ကေတသည် ၆ ဆအထိ ပိုကြာနိုင်သည်။
- **ဘာလဲ။** သင့်စာရွက်များပေါ်ရှိ ရိုးရှင်းသော သင်္ကေတ တူညီမှု၊ လေ့ကျင်ထားသော model မပါ၊ သင့်ကွန်ပျူတာမှ ဘာမျှ မထွက်ပါ။ 200 စာရွက် အတုအယောင် set တစ်ခုတွင် desktop ပေါ် Chrome ဖြင့် အစမှအဆုံး 9.4 စက္ကန့် ကြာခဲ့သည်; အမှန်တကယ် ပုံဆွဲ set များသည် ပိုနှေးမည်။ [Set တွင် အရာအားလုံး ရေတွက်ရန်](topic:count-everything) ကို ကြည့်ပါ။

**သင့်ကိုယ်ပိုင် job များမှ ဈေးနှုန်းမှတ်ဉာဏ်**

- **TakeoffCraft သည် သင့်နှုန်းထားများကို မှတ်သည်။** takeoff ကို သိမ်းသောအခါ အသုံးပြုထားသော ဈေးနှုန်းပါသည့် item တိုင်းကို အမည်နှင့် အမျိုးအစားဖြင့် မှတ်ထားသည်: ပစ္စည်းနှုန်း၊ လုပ်သားနှုန်း၊ waste နှင့် ယူနစ်။ အမည်တစ်ခုအတွက် နောက်ဆုံး job ၁၂ ခု ထားသည်။ ၎င်းကို ဤကွန်ပျူတာပေါ်တွင် ဈေးနှုန်း Library ဘေးတွင် သိမ်းသည်၊ takeoff ဖိုင်အတွင်း ဘယ်တော့မျှ မထည့်ပါ၊ နှင့် ဘယ်နေရာသို့မျှ မပို့ပါ။
- **ထိုမှ takeoff အသစ်တစ်ခု စတင်ပါ။** toolbar ရှိ {{ui:ဈေးနှုန်းများ}} က item တစ်ခုစီအတွက် နောက်ဆုံး job ၏ နှုန်းများ၊ ပုံမှန်နှုန်းများနှင့် အပိုင်းအခြားကို ပြသည်။ {{ui:နောက်ဆုံးကို သုံးရန်}} သို့မဟုတ် {{ui:ပုံမှန်ကို သုံးရန်}} က item တစ်ခုကို ဈေးသတ်မှတ်ပြီး {{ui:မှတ်ထားသော အရာများဖြင့် ဈေးမသတ်မှတ်ရသေးသော N item ကို ဈေးသတ်မှတ်ရန်}} က ဈေးမရှိသေးသော item အားလုံးကို ဖြည့်သည်။ သုံးတိုင်း undo အဆင့်တစ်ခု။
- **ယခင် takeoff မှ သင်ယူရန်။** {{ui:ယခင်ပမာဏတွက်ချက်မှုမှ သင်ယူရန်…}} က သိမ်းထားသော takeoff (.json) ၏ ဈေးသတ်မှတ်ထားသော item များကို မှတ်သည်။
- **ကြည့်ရန်၊ ပြောင်းရန်၊ မေ့ရန်။** {{ui:မှတ်ထားသည်အားလုံး}} က အမည်အားလုံးကို စာရင်းပြုသည်; အမှိုက်ပုံး ခလုတ်က တစ်ခုကို မေ့စေပြီး {{ui:ဈေးနှုန်းအားလုံး ရှင်းရန်}} က အားလုံးကို မေ့စေသည်။ ရပ်ရန် {{ui:ပမာဏတွက်ချက်မှုကို သိမ်းသည့်အခါ ကျွန်ုပ်၏ဈေးနှုန်းများကို မှတ်ထားရန်}} ကို ပိတ်ပါ။ each ဈေးနှုန်းကို foot ယူနစ် item ပေါ်တွင် ဘယ်တော့မျှ မထားပါ။ [ယခင် job များမှ ဈေးနှုန်းမှတ်ဉာဏ်](topic:price-memory) ကို ကြည့်ပါ။

**Supplier stock နှင့် lead time များ**

- **supplier ၏ စာရင်းနှင့် စစ်ဆေးပါ။** toolbar ရှိ {{ui:ပေးသွင်းမှု}} က supplier ၏ stock စာရင်း ({{ui:ပေးသွင်းသူ ဖိုင်ထည့်ရန်…}}) ကို ယူပြီး takeoff လိုအပ်သည်များကို waste ပါ၍ ၎င်းနှင့် စစ်ဆေးသည်။ ဖိုင် ငါးခုအထိ သိမ်းသည်။ တစ်စုံတစ်ခုမျှ မပို့ပါ၊ supplier ကို ဘာမျှ မမေးပါ: သင်က ဖိုင်ကို ယူလာရမည်။
- **ပြောသည်များ။** တိုသော items များ ဦးစွာ ပေါ်လာသည်: "120 EA လို", "ရက် 21 စောင့်ရန်", "backorder တွင်", "ယူနစ် မတူ", "stock ကိန်း မရှိ" သို့မဟုတ် "stock ရှိ"။ {{ui:စောင့်ရန် အများဆုံးကြာချိန် (ရက်)}} က 14 မှ စသည်။
- **မှာယူစာရင်း။** {{ui:မှာယူစာရင်း (CSV)}} က တိုသော items များကို လိုနေသော ပမာဏ၊ supplier နှင့် lead time ဖြင့် ဒေါင်းလုဒ်လုပ်သည်။
- **ဈေးများကို Library သို့။** ဖိုင်တွင် ဈေးများရှိပါက {{ui:ဈေးများကို Library သို့}} က နာမည်နှင့် ယူနစ် တူသော Library entry တိုင်း၏ ပစ္စည်းဈေးကို သတ်မှတ်သည်။ takeoff သို့ ယူရန် Library မှ ပြန်ဈေးသတ်မှတ်ပါ။
- **ပြဿနာများ panel တွင်။** လိုနေမှုသည် သတိပေးချက်ဖြစ်ပြီး ကြာသော စောင့်ချိန်သည် မှတ်ချက်ဖြစ်သည်၊ "Supplier stock" အောက်တွင်။ အကြောင်းပြချက်ဖြင့် တစ်ခုကို လက်ခံနိုင်ပြီး အကြောင်းပြချက်ကို takeoff တွင် သိမ်းသည်။ [Supplier stock နှင့် lead time များကို စစ်ဆေးရန်](topic:supplier-stock) ကို ကြည့်ပါ။

**AI အကူအညီပေးသူများ**

- **သုံးခုလုံးအတွက် ကိရိယာများ။** {{ui:ဆက်တင်များ}} တွင် အကူအညီပေးသူများ ခွင့်ပြုထားပါက အကူအညီပေးသူသည် legend ကို ဖတ်နိုင်သည် (`legend_open`)၊ ရေတွက်မှုကို run နိုင်သည် (`legend_count_start`၊ ထို့နောက် `legend_count_status` နှင့် `legend_count_result`) နှင့် ထည့်နိုင်သည် (`legend_count_add`၊ ဦးစွာ ကြိုကြည့်နိုင်သည်)။ ၎င်းသည် မှတ်ထားသော ဈေးနှုန်းများကို ဖတ်နိုင်သည် (`prices_list`) နှင့် ၎င်းတို့မှ item များကို ဈေးသတ်မှတ်နိုင်သည် (`prices_apply`၊ ဦးစွာ ကြိုကြည့်နိုင်သည်)၊ နှင့် supplier စစ်ဆေးမှုကို ဖတ်နိုင်သည် (`supply_check`)။ supplier ဖိုင်ထည့်ခြင်းသည် သင်ကိုယ်တိုင် လုပ်ရမည်ဖြစ်သည်။ [TakeoffCraft ကို AI အကူအညီပေးသူများဖြင့် သုံးရန်](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

**app အားလုံးတွင်**

- **ဘာသာစကားများ။** စုစုပေါင်း ၅၄ ခု; ၁၀ ခု အသစ် (Lithuanian၊ Latvian၊ Bosnian၊ Marathi၊ Telugu၊ Albanian၊ Afrikaans၊ Filipino၊ Swahili နှင့် Uzbek)။ အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် ဇာတိသုံးစွဲသူက မဖတ်မချင်း စက်ဖြင့် ဘာသာပြန်ထားသော မူကြမ်းများ ဖြစ်သည်။
- **Input devices။** {{ui:ဆက်တင်များ}} › {{ui:Global}} › {{ui:Input devices}} က trackpad၊ mouse ၏ ဘေးခလုတ်များ၊ pen၊ 3D mouse၊ game controller သို့မဟုတ် MIDI controller ၏ လုပ်ဆောင်ချက်ကို app တိုင်း သို့မဟုတ် တစ်ခုအတွက် သတ်မှတ်သည်။ [trackpad၊ 3D mouse သို့မဟုတ် controller သုံးရန်](common:input-devices) ကို ကြည့်ပါ။
- **Toolbar rows။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ကိရိယာဘား အတန်းများ}} က {{ui:ပတ်ပြီးပြသရန်}} (အစ)၊ {{ui:အတန်း ၂ တန်း}} နှင့် {{ui:အတန်း ၁ တန်း}} ကို ပေးသည်; မကိုက်ညီသော အုပ်စုများသည် ဘေးသို့ scroll လုပ်သည်။ [panel များကို စီစဉ်ရန်](common:arrange-panels) ကို ကြည့်ပါ။
- **ပြဿနာများ panel။** သတိပေးချက်နှင့် မှတ်ချက်များ၏ မျှဝေ panel တွင် အထက်ပါ supplier stock စစ်ဆေးမှုကို အခြား စစ်ဆေးချက်များဘေးတွင် ယခု ပါဝင်သည်။
- **Add-ons။** Add-ons များသည် သင့်အကောင့်စာရင်းကို လိုက်သည်။ [Add-ons နှင့် သင့်အကောင့်စာရင်း](common:addons-basics) ကို ကြည့်ပါ။

### ဤဗားရှင်းတွင် မပါသေးသည်များ

- **Code-sign မလုပ်ထားပါ။** Windows က သတိပေးနိုင်သည်၊ Mac တွင် ပထမအကြိမ် right-click ပြီး {{ui:ဖွင့်ရန်}} ကို ရွေးပါ။ store build များ (Microsoft Store၊ Google Play၊ App Store) ကို ရပ်ထားသည်၊ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **Studio update များ။** Windows installer နှင့် Linux package များသည် နေ့စဉ်တစ်ကြိမ် စစ်ဆေးပြီး ဦးစွာ မေးသည်။ portable zip သည် ပြောပြသည်သာ၊ macOS နှင့် APK များသည် ကိုယ်ဘာသာ မပြင်ပါ။ 0.8 macOS .dmg သည် ထုတ်ဝေမှုကို လိုက်သည်။
- **AI ကို ချိတ်ဆက်ပါ။** Studio အတွင်း တစ်ချက်နှိပ် ချိတ်ဆက်မှု၊ browser အတွက် hosted connector၊ Studio အတွင်း သင့်ကိုယ်ပိုင် API key နှင့် ထုတ်ဝေထားသော MCP package တို့ကို ဤဗားရှင်းတွင် ကတိမပေးပါ။
- **အရာအားလုံး ရေတွက်ခြင်း။** legend တွင် ရေးထားသည့်နည်းအတိုင်း ဆွဲထားသော သင်္ကေတများ လိုအပ်ပြီး၊ နံရံ သို့မဟုတ် ရှည်သော လိုင်း ဖြတ်သွားသော သင်္ကေတကို လွတ်နိုင်သည်။ မှန်ပြောင်းထားသော သင်္ကေတများကို မတွေ့ပါ၊ scale မရှိ စာရွက်ကို အခြား အရွယ်အစားဖြင့် ဆွဲထားလျှင် legend ၏ အရွယ်အစားဖြင့် ရှာသည်။ ကျန်တာကို မယုံမီ ပထမစာရွက်ပေါ်ရှိ တွေ့ချက်များကို စစ်ဆေးပါ။

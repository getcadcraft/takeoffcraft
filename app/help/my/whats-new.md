ဤသည်မှာ TakeoffCraft 0.7 နှင့် နှိုင်းယှဉ်လျှင် TakeoffCraft 0.8 (2026-11-01 ထုတ်ဝေ) နှင့် 0.8.1 (2026-11-02) တွင် ပြောင်းလဲချက်များ ဖြစ်သည်။ symbol legend ကို စာရွက်အစုတစ်ခုလုံးတွင် တစ်ကြိမ်တည်း ရေတွက်နိုင်ပြီ၊ takeoff အသစ်ကို သင့်ယခင်အလုပ်များ၏ ဈေးနှုန်းမှ စတင်နိုင်ပြီ၊ takeoff ကို supplier ၏ stock ဖြင့် စစ်ဆေးနိုင်သည်။ 0.8.1 သည် ပြင်ဆင်မှုထုတ်ဝေချက် ဖြစ်သည်။

## အသစ်

### စာရွက်အစုတွင် အားလုံး ရေတွက်ရန်

- **legend ကို တစ်ကြိမ်ဘောင်ခတ်ပါ။** toolbar ရှိ {{ui:Count everything}} သည် symbol legend ကို ဖတ်သည်- သင်္ကေတများနှင့် ဘေးတွင်ပုံနှိပ်ထားသော အမည်များပတ်လည် ဘောင်ဆွဲပါ။ သင်္ကေတတစ်ခုစီကို ပုံနှင့် အမည်ဖြင့် စာရင်းပြုစုသည်၊ အမည်က ပစ္စည်း၏ အမည် ဖြစ်လာသည်။ မလိုချင်သည်များကို ဖယ်ထုတ်ပြီး {{ui:Count on N sheets}} ကို ရွေးပါ။ ဘား တစ်ခုက ရှာနေသော စာရွက်ကို ပြသသည်၊ {{ui:Cancel}} က run ကို ရပ်ပြီး စာမျက်နှာကို ဆက်သုံးနိုင်သည်။
- **စာရွက်အားလုံးကို run တစ်ခုတည်းဖြင့်။** သင်္ကေတတစ်ခုစီကို ဖွင့်ထားသော စာရွက်တိုင်းတွင် ရေတွက်သည်။ အခြားစကေးဖြင့် ဆွဲထားသော စာရွက်ကို ထိုစကေးဖြင့် ရှာသည်၊ သင်္ကေတများကို ထောင့်မှန်ရှိ မည်သည့်ထောင့်ဖြင့်မဆို လှည့်ထားသည်ကိုပါ တွေ့သည်။ legend ၏ကိုယ်ပိုင်သင်္ကေတများကို ၎င်း၏စာရွက်တွင် မရေတွက်ပါ။
- **ထည့်မီ သုံးသပ်ပါ။** စုစုပေါင်းတစ်ခုစီတွင် စာရွက်အလိုက် လင့်ခ်တစ်ခု ("E-103: 4") ရှိပြီး ထိုစာရွက်သို့ သွားသည်။ တွေ့ထားသည့်အရာပေါ် ဘောက်စ်ကို နှိပ်လျှင် ဖယ်ထုတ်ပြီး ထပ်နှိပ်လျှင် ပြန်ထည့်သည်။ ကိုက်ညီမှုအဆင့် (50% မှ 100%) က တွေ့ထားသည်များကိုသာ စစ်ထုတ်ပြီး ထပ်မရှာပါ။
- **undo အဆင့်တစ်ခု။** {{ui:Add N marks}} သည် သင်္ကေတတစ်ခုစီအတွက် ရေတွက်ပစ္စည်းတစ်ခု ဖန်တီးပြီး တွေ့သည့်နေရာတိုင်းတွင် အမှတ်အသားတစ်ခု ထည့်သည်။ သင်၏ ရေတွက်ပစ္စည်း ဖြစ်ပြီးသား အမည်ကို ပြန်သုံးသည်။ {{key:Ctrl+Z}} က ပစ္စည်းနှင့် အမှတ်အသားအားလုံးကို ပြန်ဖျက်သည်။ သင်လက်ခံသည့်အရာသည် {{ui:Learned}} ကိုလည်း ကျွေးသည်။
- **မည်သည့်ထောင့်ရှိ သင်္ကေတများ။** ရေတွက်မီ {{ui:Symbols at any angle}} ကို အမှန်ခြစ်ပါ၊ ထောင့်မှန်မဟုတ်သော ထောင့်ဖြင့် လှည့်ထားသော သင်္ကေတများကိုလည်း ရှာတွေ့စေသည်။ ထို့နောက် ရှာဖွေမှုက သင်္ကေတတစ်ခုစီကို 15 ဒီဂရီတိုင်း လှည့်ပြီး ပတ်လည်မဟုတ်သော သင်္ကေတသည် 6 ဆအထိ ပိုကြာနိုင်သည်။
- **၎င်းဘာလဲ။** သင့်စာရွက်များပေါ်ရှိ ရိုးရိုး သင်္ကေတကိုက်ညီမှုဖြစ်ပြီး trained model မပါ၊ ဘာမှ ကွန်ပျူတာမှ မထွက်ပါ။ စာရွက် 200 ရှိသော လိပ်ပြန်စာတစ်ခုတွင် Chrome ပေါ်မြန်သော desktop တွင် အစမှ အဆုံး 9.4 စက္ကန့် ကြာခဲ့သည်၊ အမှန်တကယ် ပုံစံကွက်အစုများက ပိုနှေးမည်။ [စာရွက်အစုတွင် အားလုံး ရေတွက်ခြင်း](topic:count-everything) ကို ကြည့်ပါ။

### သင့်ကိုယ်ပိုင်အလုပ်များမှ ဈေးနှုန်းမှတ်ဉာဏ်

- **TakeoffCraft က သင့်နှုန်းများကို မှတ်ထားသည်။** takeoff ကို သိမ်းသည့်အခါ အသုံးပြုသော ဈေးနှုန်းသတ်မှတ်ထားသည့် ပစ္စည်းတိုင်းကို အမည်နှင့် အမျိုးအစားဖြင့် မှတ်ထားသည်- ပစ္စည်းနှုန်း၊ လုပ်အားနှုန်း၊ waste နှင့် ယူနစ်။ အမည်တစ်ခုစီအတွက် နောက်ဆုံး အလုပ် 12 ခုကို သိမ်းထားသည်။ ၎င်းကို ဤကွန်ပျူတာပေါ်တွင် ဈေး Library ၏ဘေးတွင် သိမ်းသည်၊ takeoff ဖိုင်အတွင်း ဘယ်တော့မှ မထည့်ပါ၊ ဘယ်နေရာသို့မှ မပို့ပါ။
- **နောက်ဆုံး takeoff အသစ်ကို ထိုကနေ စတင်ပါ။** toolbar ရှိ {{ui:Prices}} က ပစ္စည်းတစ်ခုစီအတွက် နောက်ဆုံးအလုပ်၏ နှုန်းများ၊ ပုံမှန်နှုန်းများနှင့် အပိုင်းအခြားကို ပြသည်။ {{ui:Use last}} သို့မဟုတ် {{ui:Use typical}} က ပစ္စည်းတစ်ခုကို ဈေးသတ်မှတ်သည်၊ {{ui:Price N unpriced items from memory}} က ဈေးမရှိသေးသော ပစ္စည်းအားလုံးကို ဖြည့်သည်။ အသုံးပြုမှုတိုင်းသည် undo အဆင့်တစ်ခု ဖြစ်သည်။
- **ယခင်အလုပ်များ။** {{ui:Learn from a past takeoff…}} သည် သိမ်းထားသော takeoff (.json) ၏ ဈေးသတ်မှတ်ထားသော ပစ္စည်းများကို မှတ်ထားသည်။
- **ကြည့်ရန်၊ ပြောင်းရန်၊ မေ့ရန်။** {{ui:Everything remembered}} သည် အမည်အားလုံးကို စာရင်းပြုစုသည်; အမှိုက်ပုံခလုတ်က အမည်တစ်ခုကို မေ့စေပြီး {{ui:Clear all prices}} က အားလုံးကို မေ့စေသည်။ ရပ်ရန် {{ui:Remember my prices when I save a takeoff}} ကို ပိတ်ပါ။ တစ်ခုချင်းအတွက် ဈေးကို ပစ္စည်းတစ်ခုပေါ် မီတာတစ်ခုချင်းအတွက် မပြောင်းနိုင်ပါ။ [ကိုယ်ပိုင်အလုပ်များမှ ဈေးနှုန်းမှတ်ဉာဏ်](topic:price-memory) ကို ကြည့်ပါ။

### Supplier stock နှင့် lead time

- **supplier ၏ စာရင်းနှင့် စစ်ဆေးပါ။** toolbar ရှိ {{ui:Supply}} က supplier ၏ stock စာရင်း ({{ui:Add a supplier file…}}), CSV သို့မဟုတ် spreadsheet ကို ယူပြီး takeoff လိုအပ်သည့်အရာကို waste ပါ၍ ၎င်းနှင့် စစ်ဆေးသည်။ ဖိုင် 5 ခုအထိ သိမ်းထားသည်။ ဘာမှ မပို့ပါ၊ supplier ကို ဘာမှ မေးမြန်းပါ၊ ဖိုင်ကို သင်ယူလာရမည်။
- **ပြောသည်များ။** တိုရှင်းသော ပစ္စည်းများ ဦးစွာ ပေါ်သည်- "Short by 120 EA", "Lead time 21 days", "On backorder", "Unit differs", "No stock figure" သို့မဟုတ် "In stock"။ {{ui:Longest wait wanted (days)}} သည် 14 မှ စသည်။
- **မှာယူစာရင်း။** {{ui:Order list (CSV)}} က လိုနေသော ပစ္စည်းများကို လိုနေသော အရေအတွက်၊ supplier နှင့် lead time ဖြင့် ဒေါင်းလုဒ်လုပ်သည်။
- **Library သို့ ဈေးများ။** ဖိုင်တွင် ဈေးပါလျှင် {{ui:Prices into the Library}} က အမည်နှင့် ယူနစ်တူသော Library ထည့်သွင်းချက်တိုင်း၏ ပစ္စည်းဈေးကို သတ်မှတ်သည်။ takeoff ထဲ ယူရန် Library မှ ပြန်ဈေးသတ်မှတ်ပါ။
- **Problems panel တွင်။** လိုနေမှုသည် သတိပေးချက်ဖြစ်ပြီး ကြာသော စောင့်ချိန်သည် မှတ်စုဖြစ်သည်၊ "Supplier stock" အောက်တွင် ပေါ်သည်။ အကြောင်းပြချက်ဖြင့် တစ်ခုကို လက်ခံနိုင်ပြီး အကြောင်းပြချက်ကို takeoff တွင် သိမ်းသည်။ [Supplier stock နှင့် lead time စစ်ဆေးခြင်း](topic:supplier-stock) ကို ကြည့်ပါ။

### AI assistant များ

- **သုံးခုလုံးအတွက် ကိရိယာများ။** {{ui:Settings}} တွင် assistant များကို ခွင့်ပြုထားလျှင် assistant က legend ကို ဖတ်နိုင် (`legend_open`), ရေတွက်ခြင်းကို run နိုင် (`legend_count_start` ပြီး `legend_count_status` နှင့် `legend_count_result`) နှင့် ထည့်နိုင် (`legend_count_add`၊ ကြိုကြည့်နိုင်သည်)။ မှတ်ထားသော ဈေးနှုန်းများကို ဖတ်နိုင် (`prices_list`) နှင့် ၎င်းမှ ပစ္စည်းများကို ဈေးသတ်မှတ်နိုင် (`prices_apply`၊ ကြိုကြည့်နိုင်သည်) နှင့် supplier စစ်ဆေးချက်ကို ဖတ်နိုင်သည် (`supply_check`)။ supplier ဖိုင်ထည့်ခြင်းကို သင်ကိုယ်တိုင် လုပ်ရမည်။ [TakeoffCraft ကို AI assistant များနှင့် သုံးခြင်း](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

### အက်ပ်အားလုံးတွင်

- **ဘာသာစကားများ။** ဘာသာစကား 54 မျိုး စုစုပေါင်းရှိသည်၊ 10 မျိုးသည် အသစ်ဖြစ်သည် (Lithuanian, Latvian, Bosnian, Marathi, Telugu, Albanian, Afrikaans, Filipino, Swahili နှင့် Uzbek)။ အင်္ဂလိပ်မှတစ်ပါး ဘာသာစကားများသည် မူကြမ်းစက်ဖြင့် ပြုလုပ်ထားပြီး ဘာသာစကားပိုင်ရှင်က မဖတ်ရသေးပါ။
- **Input devices။** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} က trackpad၊ မောက်စ်၏ ဘေးခလုတ်များ၊ ဘောပင်၊ 3D မောက်စ်၊ game controller သို့မဟုတ် MIDI controller တို့ ဘာလုပ်မည်ကို အက်ပ်အားလုံး သို့မဟုတ် တစ်ခုအတွက် သတ်မှတ်သည်။ [trackpad၊ 3D မောက်စ် သို့မဟုတ် controller သုံးခြင်း](common:input-devices) ကို ကြည့်ပါ။

## 0.8.1 တွင် ပြင်ဆင်ထားသည်

- **DWG classes အပိုင်း။** DWG ဖိုင်၏ classes အပိုင်းကို မှားသော အမျိုးအစားအဖြစ် ဖတ်ခဲ့သည်။ TakeoffCraft နှင့် အခြားအက်ပ် 4 ခုတွင် ပြင်ဆင်ပြီးပြီ။
- **Studio သည် run နေစဉ် ဘာသာစကား ပြောင်းနိုင်သည်။** ယခင်က Studio နှင့် ၎င်း၏ packed ဗားရှင်းများသည် အင်္ဂလိပ်တစ်ခုတည်း ဖြစ်သည်။ ၎င်းကို desktop build ၏ platform တိုင်းတွင် မစမ်းသပ်ရသေးပါ; ဘာသာစကား မပြောင်းလျှင် ပြောပါ။

## ဤဗားရှင်းတွင် မရှိသေးသည်များ

- **ကုဒ်လက်မှတ်ထိုးထားခြင်း မရှိပါ။** Windows က သတိပေးနိုင်ပြီး Mac တွင် ပထမဆုံးအကြိမ် right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ store build များ (Microsoft Store၊ Google Play၊ App Store) ကို ရပ်ထားသည်၊ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **Studio အပ်ဒိတ်များ။** Windows installer နှင့် Linux package များသည် တစ်ရက်တစ်ကြိမ် စစ်ဆေးပြီး ဦးစွာမေးသည်။ portable zip က အကြောင်းကြားသာသည်၊ macOS နှင့် APK က ကိုယ်တိုင် အပ်ဒိတ်မလုပ်ပါ။ 0.8 macOS .dmg သည် ထုတ်ဝေချက်ကို လိုက်သည်။
- **သင့် AI ကို ချိတ်ဆက်ပါ။** Studio အတွင်း တစ်ချက်နှိပ် ချိတ်ဆက်ခြင်း၊ browser ရှိ AI အတွက် hosted connector၊ Studio အတွင်း သင့်ကိုယ်ပိုင် API key နှင့် ထုတ်ဝေထားသော MCP package တို့ကို ဤဗားရှင်းတွင် ကတိမပေးထားပါ။
- **Count everything။** legend တွင် ရေးထားသည့်ပုံစံအတိုင်း ဆွဲထားသော သင်္ကေတများ လိုအပ်ပြီး ကြိုးတစ်ခု သို့မဟုတ် ရှည်သောမျဉ်းဖြတ်သွားသော သင်္ကေတကို လွတ်နိုင်သည်။ မှန်ပြောင်းထားသော သင်္ကေတများကို မတွေ့ပါ၊ စကေးမရှိပြီး အခြားအရွယ်အစားဖြင့် ဆွဲထားသော စာရွက်ကို legend ၏အရွယ်အစားဖြင့် ရှာသည်။ ကျန်တာကို မယုံမီ ပထမစာရွက်ပေါ်ရှိ တွေ့ချက်များကို စစ်ပါ။
- **Supplier stock။** stock ကိန်းဂဏန်းများသည် သင်ထည့်သော ဖိုင်အတိုင်းသာ လတ်ဆတ်ပါသည်။ စစ်ဆေးချက်သည် supplier ကို ဘယ်တော့မှ မေးမြန်းခြင်း မရှိပါ။
- **ဘာသာစကားများ။** Tamil ၏ app bar သည် လွန်ကျူးနေသည်။

စာရွက်တိုင်းတွင် ၎င်း၏ကိုယ်ပိုင် စကေး ရှိသည်။ သင် သတ်မှတ်သည်၊ သို့မဟုတ် TakeoffCraft က စာရွက်များ၏ စာသား (အောက်တွင်) မှ ဖတ်စေသည်၊ ထို့နောက် စစ်ဆေးသည်။ စာရွက်တစ်ခုတွင် စကေးမရှိသေးလျှင် {{ui:Linear}}၊ {{ui:Area}}၊ {{ui:Circle}} နှင့် {{ui:Cut-out}} တို့သည် ထိုစာရွက်ပေါ်တွင် တိုင်းတာရန် ငြင်းသည်။ {{ui:Count}} နှင့် {{ui:Auto count}} တို့ကို စကေးမလိုဘဲ အလုပ်လုပ်သည်။

sheets list တွင် စာရွက်တစ်ခုစီ၏ စကေး သို့မဟုတ် **No scale** ကို ပြသည်။ ဖွင့်ထားသော စာရွက်အောက်ရှိ bar က အတူတူ ပြောသည်။

## Preset ကို သုံးရန် (PDF ကို အပြည့်အစား ပုံနှိပ်ထားသည့်အခါ)

1. စာရွက်ကို ဖွင့်ပါ။
2. {{ui:Scale}} အုပ်စုရှိ {{ui:Preset}} list ကို ဖွင့်ပါ။
3. ပုံဆွဲပေါ်တွင် ပုံနှိပ်ထားသော စကေးကို ရွေးပါ၊ ဥပမာ Architectural အောက်မှ `1/8" = 1'-0"`။
   status bar က "Scale for this sheet: 1/8" = 1'-0"." ဟု ပြသည်။
4. အောက်ပါအတိုင်း စစ်ဆေးပါ။

preset သည် PDF သည် ပုံဆွဲကို ရည်ရွယ်ခဲ့သော စက္ကူ အမှန်အရွယ်အစား ဖြစ်သည်ဟု ယူဆသည်။ PDF ကို "fit to page" ဖြင့် ပြုလုပ်ထားလျှင် သို့မဟုတ် တစ်ဝက်အရွယ် အစုံဖြစ်လျှင် preset မှားသည်။ ထိုအခါ စံညှိပါ။

preset အပြည့်စုံစာရင်းကို [စကေး preset များ](topic:scale-presets) တွင် ရှိသည်။

## စာရွက်များ၏ စာသားမှ စကေးများကို ဖတ်ရန်

ပုံဆွဲအများစုက ၎င်းတို့၏ စကေးကို ပြောသည်။ title block တွင် `SCALE: 1/4" = 1'-0"` နှင့် view အောက်တွင် `1:100`။ TakeoffCraft က ၎င်းကို ဖတ်ပြီး စာရွက်တိုင်းကို တစ်ကြိမ်တည်း သတ်မှတ်နိုင်သည်။

1. {{ui:Preset}} list ကို ဖွင့်ပြီး (ထိပ်တွင်) {{ui:From the sheets' text…}} ကို ရွေးပါ။
2. list တွင် စာရွက်အားလုံး ပြသည်- ယခုစကေး နှင့် ၎င်း၏စာသား ပြောသည့်အရာ — **Says 1/4" = 1'-0"**၊ **No scale in its text** သို့မဟုတ် **Says not to scale** (NTS)။
3. စကေးမရှိသော်လည်း စကေးပြောသည့် စာရွက်များကို အမှန်ခြစ်ထားသည်။ ၎င်းတို့ကို ခြစ်သို့မဟုတ် ဖျက်ပြီး {{ui:Set the ticked scales}} ကို ရွေးပါ။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် အားလုံး ပြန်ယူသည်။
4. {{ui:Check}} (အောက်တွင်) ဖြင့် စာရွက်တစ်ခုစီပေါ် အတိုင်းအတာတစ်ခု စစ်ဆေးပါ။ preset သည် PDF ကို အပြည့်အစား ပုံနှိပ်ထားမှသာ မှန်သည်။

ဖတ်နိုင်သည်မှာ architectural (`3/16" = 1'-0"`၊ `1 1/2" = 1'-0"`)၊ engineering (`1" = 20'`) နှင့် metric (`1:50`) အမှတ်အသားများ ဖြစ်ပြီး [preset](topic:scale-presets) နှင့် ကိုက်ညီသည်။ စာရွက်တစ်ခုက စကေး တစ်ခုထက်ပို ပြောလျှင် (အသေးစိတ် တိုးချဲ့ထားသော အစီအစဉ်) အမြဲ ပြောသော စကေးကို ယူသည်၊ SCALE စကားလုံးနောက်တွင် ရေးထားသည်ကို နှစ်ဆ ရေတွက်သည်။ အခြားများကို အနီရောင်ဖြင့် ပြသည်ဖြင့် စစ်ဆေးနိုင်သည်။ စကန်ဖတ်ထားသော စာရွက်တွင် စာသား မရှိပါ၊ ၎င်း၏ စကေးကို လက်ဖြင့် သတ်မှတ်ပါ။

## သိရှိထားသော အတိုင်းအတာဖြင့် စံညှိရန်

ယုံကြည်ရသော ပုံနှိပ်စကေး မရှိသောအခါ၊ ပုံဆွဲကို ပြန်အရွယ်ပြောင်းထားသောအခါ၊ သို့မဟုတ် စာရွက်က "not to scale" ဟု ပြော သို့သော် အတိုင်းအတာများ ရှိသောအခါ ဤနည်းကို သုံးပါ။

1. စာရွက်ကို ဖွင့်ပြီး သိထားသော ရှည်သော အတိုင်းအတာ (ဥပမာ grid line အကွာအဝေး သို့မဟုတ် အဆောက်အအုံ စုစုပေါင်း အတိုင်းအတာ) ပေါ်တွင် zoom in လုပ်ပါ။ ရှည်လေ တိကျလေ။
2. {{ui:Scale}} အုပ်စုရှိ {{ui:Calibrate}} ကို ရွေးပါ သို့မဟုတ် {{key:K}} ကို နှိပ်ပါ။
3. အတိုင်းအတာ၏ အဆုံးတစ်ဖက်ကို နှိပ်ပါ။ တိကျမှုအတွက် အဆုံးတစ်ခုစီတွင် zoom in လုပ်ပါ၊ နှိပ်ခြင်းကြားတွင် zoom နှင့် pan လုပ်နိုင်သည်။
4. တစ်ဖက်ကို နှိပ်ပါ။ မျဉ်းကို 0°၊ 45° သို့မဟုတ် 90° တွင် ထားရန် {{key:Shift}} ကို ဖိထားပါ။
   **Calibrate this sheet** dialog ဖွင့်သည်။
5. **Real distance** တွင် အမှန်အကွာအဝေးကို ရိုက်ပါ၊ ဥပမာ `24'-6 1/2"`၊ `24.5` (ဒဿမ ပေ)၊ `30"` သို့မဟုတ် `7.5 m`။ [အရှည်၊ နှုန်းထားနှင့် ရာခိုင်နှုန်း ရိုက်ထည့်ခြင်း](topic:entry-formats) ကို ကြည့်ပါ။
6. {{ui:Set the scale}} ကို ရွေးပါ။
   status bar က စကေးကို "1" = (n)'" ဟု ပြပြီး preset ၏ 0.5% အတွင်း ဖြစ်လျှင် မည်သည့် preset နှင့်ကိုက်ညီသည်ကို ပြောသည်၊ ဥပမာ "which matches 1/4" = 1'-0" (pick that preset for an exact scale)"။
   TakeoffCraft က {{ui:Select}} ကိရိယာသို့ ပြန်သွားသည်။

စံညှိမှုသည် preset တစ်ခုနှင့် ကိုက်ညီသောအခါ ထို preset ကို ရွေးလျှင် နှိပ်ခဲ့သော နေရာပေါ် မမူတည်သော တိကျသည့် စကေးကို ရသည်။

## စကေးကို စစ်ဆေးရန်

စကေးအသစ်တိုင်း အတိုင်းအတာ နောက်တစ်ခုဖြင့် အမြဲစစ်ဆေးပါ။

1. {{ui:Scale}} အုပ်စုရှိ {{ui:Check}} ကို ရွေးပါ သို့မဟုတ် {{key:D}} ကို နှိပ်ပါ။
2. ပုံဆွဲပေါ် ပုံနှိပ်ထားသော အတိုင်းအတာ၏ အဆုံးနှစ်ခုစလုံးကို နှိပ်ပါ။
   status bar က "Check: 12'-6"" ဟု ပြပြီး တူညီသော အရှည်ကို ဒဿမ ပေနှင့် မီတာဖြင့် ပြသည်။ စစ်ဆေးမှု မျဉ်းသည် ၎င်း၏ အရှည်နှင့်အတူ စာရွက်ပေါ် ကျန်နေသည်။
3. ပုံနှိပ်ထားသော အတိုင်းအတာနှင့် နှိုင်းယှဉ်ပါ။ မတူလျှင် ပိုရှည်သော အတိုင်းအတာပေါ် ပြန်စံညှိပါ။

စစ်ဆေးမှု မျဉ်းကို ရှင်းရန် {{key:Esc}} ကို နှိပ်ပါ။

## စကေးကို ပြောင်းရန်

preset အခြားတစ်ခုကို ရွေးပါ သို့မဟုတ် ထပ်စံညှိပါ။ စာရွက်တွင် တိုင်းတာမှုများ ရှိပြီးသားဆိုလျှင် TakeoffCraft က **Change this sheet's scale?** ဟု မေးပြီး အမှန်ပြန်တိုင်းရမည့် တိုင်းတာမှု အရေအတွက်ကို ပြောသည်။ {{ui:Change the scale}} ကို ရွေးပါ။ စာရွက်ပေါ်ရှိ run နှင့် ဧရိယာတိုင်းကို စကေးအသစ်ဖြင့် ပြန်တိုင်းသည်။ {{key:Mod+Z}} ဖြင့် ပြန်ရုပ်သိမ်းနိုင်သည်။

## စကေးမရှိသော စာရွက်များကို သုည အဖြစ် မရေတွက်ရသည့်အကြောင်း

စကေးမရှိသော စာရွက်ပေါ်ရှိ အမှတ်အသားတွင် အမှန်အရှည် သို့မဟုတ် ဧရိယာ မရှိပါ။ TakeoffCraft က ၎င်းကို သုည အဖြစ် ဘယ်တော့မှ မရေတွက်ပါ၊ ထိုသို့ဆိုလျှင် ခန့်မှန်းချက်သည် တိတ်တဆိတ် နိမ့်သွားမည်။ အစား ၎င်းက-

- ထိုအမှတ်အသားများကို စုစုပေါင်းမှ ချန်ထားသည်၊
- {{ui:Quantities}} တွင် ပစ္စည်းဘေးတွင် "+(n) unscaled" ကို ပြသည်၊
- ဇယား header တွင် "Incomplete: (n) marks on sheets with no scale (not in the totals)" ကို ပြသည်၊
- အရေအတွက်ကို spreadsheet export ၏ မှတ်ချက် ကော်လံတွင် ရေးသည်။

ဤသည်မှာ စကေးများ ဘယ်တော့မှ သတ်မှတ်မထားသော ပရောဂျက်ကို ဖွင့်သောအခါ ဖြစ်နိုင်သည်။ စာရွက်အား စကေးပေးလိုက်ရုံဖြင့် အမှတ်အသားများကို ချက်ချင်း ရေတွက်သည်။ Count အမှတ်အသားများကို အမြဲ ရေတွက်သည်၊ ၎င်းတို့သည် စကေး မလိုအပ်ပါ။

## အကြံပြုချက်များ

- တိုင်းတာမည့် စာရွက်တိုင်းကို မစခင် စကေးသတ်မှတ်ပါ။ ကျန်နေသေးသော စာရွက်များကို ရှာရန် sheets list တွင် **No scale** ကို ရှာပါ (search box သည် စာရွက်အမည်များကိုသာ ကြည့်သည်၊ စကေးမဟုတ်)။
- စာရွက်တစ်ခုတည်းပေါ်ရှိ အသေးစိတ်များနှင့် တိုးချဲ့ထားသော ပုံဆွဲများသည် မတူညီသော စကေးကို မကြာခဏ သုံးသည်။ TakeoffCraft သည် စာရွက်တစ်ခုလျှင် စကေး တစ်ခုသာ ရှိသည်၊ [အဖြစ်မသိမ်းသေးသည်](topic:not-built-yet) ကို ကြည့်ပါ။
- metric ပုံဆွဲများ: `1:100` ကဲ့သို့ metric preset ကို ရွေးပါ၊ သို့မဟုတ် `6000 mm` ကဲ့သို့ metric အကွာအဝေးဖြင့် စံညှိပါ။

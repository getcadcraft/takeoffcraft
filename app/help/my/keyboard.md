အက္ခရာခလုတ်များသည် ညွှန်ပြကိရိယာ စာမျက်နှာပေါ်ဘယ်နေရာမဆို ရှိနေပြီး အကွက်တစ်ခုတွင် မရိုက်နေချိန်တွင် အလုပ်လုပ်ပါသည်။ ဒိုင်ယာလော့ဂ် ဖွင့်ထားချိန်တွင် ၎င်း၏ကိုယ်ပိုင်ခလုတ်များ သက်ရောက်ပါသည်။ အက္ခရာများသည် {{key:Shift}} နှင့်အတူ သို့မဟုတ် မပါဘဲ အလုပ်လုပ်ပါသည်။

## ဆွဲနေစဉ်

| ခလုတ် သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်သလဲ |
|---|---|
| နှိပ်ခြင်း | အမှတ်တစ်ခု ချထားပါ (Count ဖြင့် အစက်တစ်ခု)။ |
| {{key:P}} | Path: PDF မျဉ်း၏ ဆက်စပ်နေသော path တစ်ခုလုံး၊ သို့မဟုတ် နှိပ်ထားသော နေရာ၏ အပြင်ဘောင်ကို ရွေးပါ ([PDF ၏ မျဉ်းများ ရွေးခြင်း](topic:pick-the-lines))။ |
| {{key:F3}} | ပုံ၏ မျဉ်းများသို့ snap ဖွင့် သို့မဟုတ် ပိတ် ([ပုံ၏ မျဉ်းများသို့ snap](topic:snap-to-the-drawing))။ |
| နှိပ်နေစဉ် {{key:Shift}} ကိုင်ထား | နောက်ဆုံးအမှတ်မှ အပိုင်းကို 0°, 45°, 90° သို့မဟုတ် 135° သို့ snap လုပ်ပါ။ arc အမှတ်များ သို့မဟုတ် စက်ဝိုင်းများအတွက် မဟုတ်ပါ။ |
| နှစ်ချက်နှိပ်ခြင်း | run ကို ပြီးဆုံးပါ၊ သို့မဟုတ် area သို့မဟုတ် cut-out ကို ပိတ်ပါ။ |
| {{key:Enter}} | run ကို ပြီးဆုံးပါ၊ သို့မဟုတ် area သို့မဟုတ် cut-out ကို ပိတ်ပါ။ |
| right-click (မရွှေ့ဘဲ) | run ကို ပြီးဆုံးပါ၊ သို့မဟုတ် area သို့မဟုတ် cut-out ကို ပိတ်ပါ။ |
| ပထမအမှတ်ကို နှိပ် | area သို့မဟုတ် cut-out ကို ပိတ်ပါ (တတိယအမှတ်မှ စ၍)။ |
| {{key:Backspace}} သို့မဟုတ် {{key:Delete}} | နောက်ဆုံးအမှတ်ကို ဖယ်ပါ (ဆိုင်းငံ့ထားသော arc အမှတ်ကို အရင်)။ |
| {{key:Esc}} | ဆိုင်းငံ့ထားသော arc အမှတ်ကို ဖယ်ပါ၊ ထို့နောက် မပြီးသေးသော အမှတ်အသားကို ပယ်ဖျက်ပါ၊ ထို့နောက် {{ui:ရွေးရန်}} သို့ ပြန်သွားပါ။ |

## ရွေးခြင်းနှင့် တည်းဖြတ်ခြင်း

| ခလုတ် သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်သလဲ |
|---|---|
| အမှတ်အသားကို နှိပ် (ရွေးရန် ကိရိယာ) | ၎င်းကို ရွေးပြီး ၎င်း၏ ပစ္စည်းကို လက်ရှိအဖြစ် ထားပါ။ |
| {{key:Shift}} + အမှတ်အသားကို နှိပ် | ရွေးချယ်မှုထဲ ထည့် သို့မဟုတ် ထုတ်ပါ။ |
| {{key:Mod+A}} | ဖွင့်ထားသော ပုံစာရွက်ပေါ်ရှိ အမှတ်အသား အားလုံးကို ရွေးပါ။ |
| ထောင့် handle ကို ဆွဲ | ထိုအမှတ်ကို ရွှေ့ပါ ({{key:Shift}} က 45° သို့ snap လုပ်သည်)။ အမှတ်အသားတစ်ခုကို ရွေးထားသည့်အခါ အလုပ်လုပ်ပါသည်။ |
| {{key:Delete}} သို့မဟုတ် {{key:Backspace}} | ရွေးထားသော အမှတ်အသားများကို ဖျက်ပါ (ဆွဲမနေချိန်တွင်သာ)။ |
| {{key:Esc}} | မည်သည်ကိုမျှ မရွေးပါနှင့်: ရွေးချယ်မှုနှင့် စစ်ဆေးမျဉ်းကို ရှင်းပါ။ |
| {{key:Mod+Z}} | ပြန်ဖျက်ရန်။ |
| {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} | ပြန်လုပ်ရန်။ |

## ကူးခြင်းနှင့် ကူးထည့်ခြင်း

| ခလုတ် | ဘာလုပ်သလဲ |
|---|---|
| {{key:Mod+C}} | ရွေးထားသော အမှတ်အသားများကို ၎င်းတို့၏ ပစ္စည်းများနှင့်အတူ ကူးပါ။ |
| {{key:Mod+X}} | ဖြတ်ရန်: ရွေးထားသော အမှတ်အသားများကို ကူးပြီး ထို့နောက် ဖျက်ပါ။ |
| {{key:Mod+V}} | ကူးထည့်ရန်: မိတ္တူသည် ညွှန်ပြကိရိယာကို လိုက်ပါမည်; သွားရမည့်နေရာတွင် နှိပ်ပါ။ |
| {{key:Mod+Shift+V}} | နေရာတိုင်းတွင် ကူးထည့်ရန်: ဖွင့်ထားသော ပုံစာရွက်ပေါ်ရှိ နေရာတူတွင်။ |
| {{key:Mod+D}} | ရွေးထားသော အမှတ်အသားများကို ပွားပါ: မိတ္တူသည် ညွှန်ပြကိရိယာကို လိုက်ပါမည်; သွားရမည့်နေရာတွင် နှိပ်ပါ။ |
| {{key:Esc}} | ဘာမျှ မချပါနှင့်: ညွှန်ပြကိရိယာပေါ်ရှိ ကူးထည့်ခြင်း သို့မဟုတ် ပွားခြင်းကို ပယ်ဖျက်ပါ။ |

အက္ခရာများတည်းဖြင့် ကိရိယာများ ရွေးနိုင်ပါသည် ({{key:C}} သည် {{ui:ရေတွက်ရန်}}၊ {{key:D}} သည် {{ui:စစ်ဆေးရန်}}၊ {{key:X}} သည် {{ui:အပေါက်ဖောက်ရန်}}၊ {{key:V}} သည် {{ui:ရွေးရန်}}၊ {{key:A}} သည် {{ui:ဧရိယာ}}); {{key:Mod}} နှင့်တွဲမှသာ ကူးခြင်းနှင့် ကူးထည့်ခြင်း ဖြစ်ပါသည်။ စာသားအကွက်တွင် ဤခလုတ်များသည် ပုံမှန်အတိုင်း စာသားကို ကူး/ကူးထည့်ပါသည်။ [အမှတ်အသား ကူးခြင်း၊ ကူးထည့်ခြင်းနှင့် ပွားခြင်း](topic:copy-paste) ကို ကြည့်ပါ။

:::warning
{{key:Backspace}} သည် သင် ဆွဲမနေချိန်တွင် ရွေးထားသော အမှတ်အသားကို ဖျက်ပါသည်။ မတော်တဆ ဖြစ်ခဲ့လျှင် {{key:Mod+Z}} က ပြန်ယူပေးပါသည်။
:::

## 3D အမြင်

| ခလုတ် သို့မဟုတ် လုပ်ဆောင်ချက် | ဘာလုပ်သလဲ |
|---|---|
| ဆွဲခြင်း၊ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲခြင်း | လှည့်ကြည့်ရန်။ |

| {{key:Esc}} | လည်ပတ်နေသော ရှာဖွေမှုကို ပယ်ဖျက်ပါ သို့မဟုတ် သုံးသပ်ချက်ကို ဖယ်ပါ။ |

## အကူအညီ

| ခလုတ် | ဘာလုပ်သလဲ |
|---|---|
| {{key:F1}} | အကူအညီပန်နယ်ကို ဖွင့် သို့မဟုတ် ပိတ်ပါ (app bar ရှိ {{ui:အကူအညီ}} ခလုတ်လည်း ဖြစ်သည်)။ ကိရိယာအားလုံးတွင် အလုပ်လုပ်ပြီး အကွက်တစ်ခုတွင် ရိုက်နေချိန်တွင်ပင် ရသည်။ |
| {{key:Esc}} | အကူအညီပန်နယ်ကို ပိတ်ပါ။ ရှာဖွေရေးဘောက်စ်တွင် ပထမ Esc က ရှာဖွေမှုကို ရှင်းပါသည်။ ပန်နယ်ဖွင့်ထားစဉ် ပုံစာရွက်ကို နှိပ်ပြီးနောက် Esc က ပန်နယ်ကို အရင်ပိတ်ပါသည်; TakeoffCraft တွင် ပယ်ဖျက်ရန် တစ်ကြိမ်ထပ်နှိပ်ပါ။ |

:::mac
Mac ကီးဘုတ်အများစုတွင် အပေါ်ဆုံးတန်းသည် အလင်းနှင့် အသံကို ထိန်းပါသည်။ fn ကို F1 နှင့်အတူ နှိပ်ပါ၊ သို့မဟုတ် System Settings အောက်ရှိ Keyboard တွင် "Use F1, F2, etc. keys as standard function keys" ကို ဖွင့်ပါ။
:::

## Platform မှတ်စုများ

:::mac
- {{key:Mod}} သည် Command ခလုတ်ဖြစ်သည်: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}။ ဖန်သားပြင်အပြည့်က ခြွင်းချက်ဖြစ်သည်: Control+Shift+F။
- trackpad ပေါ်တွင် right-click သည် လက်ညှိုးနှစ်ချောင်းနှိပ်ခြင်း ဖြစ်ပြီး System Settings အောက်ရှိ Trackpad တွင် secondary click ကို ဖွင့်ထားရပါမည်။ TakeoffCraft က secondary ခလုတ်ကိုသာ ဖတ်ပါသည်; Control-click က ရိုးရိုးနှိပ်ခြင်းအဖြစ် ယူဆပြီး အမှတ်တစ်ခု ထည့်နိုင်ပါသည်။
- trackpad ပေါ်တွင် လက်နှစ်ချောင်း ဆွဲခြင်းသည် ပုံစာရွက်ကို zoom လုပ်ပါသည် (ရွှေ့မပါ)။ ရွှေ့ကြည့်ရန် နှိပ်ဆွဲပါ၊ သို့မဟုတ် Space ကိုင်ထားပြီး ဆွဲပါ။
- ကီးဘုတ်တွင် မပါသော အခါ Page Up နှင့် Page Down သည် fn နှင့် အပေါ်/အောက် မြားခလုတ်များ ဖြစ်ပါသည်။
- Backspace သည် delete ဟု အမည်ပေးထားသော ခလုတ်ဖြစ်သည်။
:::

:::windows
- {{key:Mod}} သည် Ctrl ဖြစ်သည်: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}။
- laptop touchpad ပေါ်တွင် လက်နှစ်ချောင်း ဆွဲခြင်းသည် ပုံစာရွက်ကို zoom လုပ်ပါသည်။ ရွှေ့ကြည့်ရန် နှိပ်ဆွဲပါ။
:::

:::linux
- {{key:Mod}} သည် Ctrl ဖြစ်သည်။ desktop အချို့တွင် ၎င်းတို့ကိုယ်ပိုင် Ctrl+Alt သို့မဟုတ် Super shortcut များ ရှိနိုင်ပါသည်; TakeoffCraft က ၎င်းတို့ကို မသုံးပါ။
- touchpad ပေါ်တွင် လက်နှစ်ချောင်း ဆွဲခြင်းသည် ပုံစာရွက်ကို zoom လုပ်ပါသည်။ ရွှေ့ကြည့်ရန် နှိပ်ဆွဲပါ။
:::

:::touch
TakeoffCraft သည် touch ကို ညွှန်ပြကိရိယာတစ်ခုတည်းအဖြစ် ဖတ်ပါသည်:

- တို့ခြင်းသည် အမှတ်တစ်ခု ချထား၊ အမှတ်အသားကို ရွေး သို့မဟုတ် count အစက်တစ်ခု ထည့်ပါသည်။
- လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲခြင်းသည် ပုံစာရွက်ကို ရွှေ့ပါသည် ({{ui:အလိုအလျောက်ရေတွက်}} တွင် ရှာဖွေရေးဘောင်ကို ဆွဲပါသည်)။
- Pinch-to-zoom ကို ယခုအချိန်တွင် မထောက်ပံ့ပါ။ {{ui:စာမျက်နှာအတိုင်း ညှိရန်}} နှင့် {{ui:အကျယ်အတိုင်း ညှိရန်}} ကို သုံးပါ၊ သို့မဟုတ် ကီးဘုတ်ပေါ်ရှိ {{key:Plus}} နှင့် {{key:Minus}} ကို သုံးပါ။
- area ကို ပိတ်ရန် ပထမအမှတ်ကို တို့ပါ။ run ကို ပြီးဆုံးရန် browser က နှစ်ချက်တို့ကို နှစ်ချက်နှိပ်ခြင်းအဖြစ် ပြောင်းသည့်နေရာတွင် နှစ်ချက်တို့ပါ၊ သို့မဟုတ် ကီးဘုတ်ပေါ်တွင် {{key:Enter}} ကို နှိပ်ပါ။
- hover မရှိသောကြောင့် တို့မချင်း တိုင်းတာချက် မပြပါ။

ယခုအချိန်တွင် ကီးဘုတ်နှင့် mouse သို့မဟုတ် trackpad သည် takeoff လုပ်ရန် ပိုကောင်းသော နည်းလမ်းဖြစ်သည်။
:::

## Browser က ထားသော ခလုတ်များ

Browser က ခလုတ်အချို့ကို သူ့အတွက်ပဲ ထားရှိပြီး စာမျက်နှာက အသုံးပြုနိုင်ခြင်း မရှိပါ: tab ပိတ်ခြင်း ({{key:Mod+W}}), tab သို့မဟုတ် window အသစ် ({{key:Mod+T}}, {{key:Mod+N}}) နှင့် browser zoom ({{key:Mod+Plus}}, {{key:Mod+Minus}})။ ထို့ကြောင့် TakeoffCraft သည် wheel နှင့် ရိုးရိုး {{key:Plus}} နှင့် {{key:Minus}} ခလုတ်များဖြင့် ပုံစာရွက်ကို zoom လုပ်ပါသည်။ {{key:Mod+Plus}} ကို မတော်တဆ နှိပ်မိလျှင် စာမျက်နှာတစ်ခုလုံး ကြီးလာပါမည်; {{key:Mod+0}} က ပြန်ထားပေးပါမည်။ [ကီးများ၊ mouse နှင့် trackpad](common:keys) ကို ကြည့်ပါ။

## Move ရှိရာနေရာ

Move command မရှိပါ: count အစက်ကို ရွေးပြီး ဆွဲပါ၊ သို့မဟုတ် area သို့မဟုတ် မျဉ်းကို ရွေးပြီး ၎င်း၏ ထောင့် handle များကို ဆွဲပါ။

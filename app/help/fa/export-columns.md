## برآورد (برگه‌ی XLSX و CSV)

یک ردیف برای هر مورد، سپس یک ردیف برای هر جزء مجموعه‌اش (تورفته). بعد یک ردیف خالی و جمع کل پروژه.

| ستون | محتوا | در XLSX |
|---|---|---|
| A ردیف | نام مورد (پررنگ) یا نام جزء (تورفته) | متن |
| B نوع | خطی، مساحت، شمارش یا جزء | متن |
| C واحد | LF، m، SF، SY، m²، EA، یا واحد جزء | متن |
| D مقدار | مجموع اندازه‌گیری‌شده، یا نتیجه‌ی فرمول | عدد |
| E درصد ضایعات | ضایعات | درصد (0.10 = 10%) |
| F مقدار با ضایعات | مقدار × (1 + ضایعات) | فرمول `D*(1+E)` |
| G مصالح به ازای واحد | نرخ مصالح | عدد |
| H دستمزد به ازای واحد | نرخ دستمزد | عدد |
| I مصالح | مصالح محاسبه‌شده | فرمول `ROUND(F*G,2)` |
| J دستمزد | دستمزد محاسبه‌شده | فرمول `ROUND(F*H,2)` |
| K جمع | مصالح + دستمزد | فرمول `I+J` |
| L یادداشت‌ها | فرمول استفاده‌شده، خطای فرمول، نشانه‌ها روی برگه‌های بدون مقیاس، مساحت دیوار، محیط | متن |

ردیف جمع کل پروژه: `SUM` ستون‌های I، J و K روی همه‌ی ردیف‌های بالا، و "ناقص: به یادداشت‌های بالا نگاه کنید" در یادداشت‌ها وقتی چیزی کنار گذاشته شده باشد.

ردیفی که خطای فرمول دارد مقدار یا مبلغ ندارد؛ یادداشتش خطا را می‌گوید. سطر سرتیتر ثابت است.

در CSV، همین ستون‌ها مقادیر ساده دارند؛ درصد ضایعات عددی بر حسب درصد است (10 برای 10%)، و پول به دلار با دو رقم اعشار. متنی که یک صفحه‌گسترده ممکن است آن را فرمول بگیرد (با `=`، `+`، `-` یا `@` شروع شود) یک `'` در ابتدا می‌گیرد تا متن بماند.

## به تفکیک برگه (فقط XLSX)

| ستون | محتوا |
|---|---|
| برگه | نام برگه (با نام PDF وقتی باز نیست) |
| ردیف | نام مورد |
| مقدار | مقدار آن مورد روی آن برگه، بر حسب واحدش |
| واحد | واحد مورد |
| نشانه‌ها | تعداد نشانه‌ها |

## نشانه‌ها (فقط XLSX)

یک ردیف برای هر نشانه.

| ستون | محتوا |
|---|---|
| برگه | نام برگه |
| ردیف | نام مورد |
| نوع | خطی، مساحت یا شمارش |
| مقدار | طول، مساحت خالص، یا 1 |
| واحد | LF یا m؛ SF، SY یا m²؛ EA |
| جزئیات | خطی: طول بخش‌ها، بخش‌های کسرشده با "(deduct)" علامت می‌خورند، و "deducts (length) of (length) drawn". مساحت: مساحت ناخالص و بریده‌شده وقتی بریدگی هست، و محیط. "Sheet has no scale" برای نشانه‌های بدون مقیاس. |
| ناحیه‌ی پیشنهاد قیمت | فقط وقتی متره ناحیه‌های پیشنهاد قیمت دارد: مساحت نشانه، یا "No bid area" |

## به تفکیک ناحیه‌ی پیشنهاد قیمت (فقط XLSX، وقتی متره ناحیه دارد)

| ستون | محتوا |
|---|---|
| ناحیه‌ی پیشنهاد قیمت | نام ناحیه، یا "No bid area" |
| ردیف | مورد، یا جزئی تورفته زیر آن |
| واحد | واحد مورد یا جزء |
| مقدار | اندازه‌گیری‌شده در آن ناحیه (جزء: فرمول روی جمع‌های ناحیه) |
| مقدار با ضایعات | مقدار × (1 + ضایعات) |
| مصالح، دستمزد، جمع | تا سانت محاسبه‌شده، مانند برآورد |
| یادداشت‌ها | فرمول، خطاها و نشانه‌های بدون مقیاس، مانند برآورد |

هر ناحیه با ردیف "(نام) جمع جزئی" تمام می‌شود که هزینه‌هایش فرمول‌های `SUM` روی ردیف‌های آن است؛ آخرین ردیف، **All bid areas**، جمع‌های جزئی را جمع می‌کند. برگه‌ی **نشانه‌ها** بعد از آن یک ستون هفتم به نام **ناحیه‌ی پیشنهاد قیمت** دارد.

## مقیاس‌ها (فقط XLSX)

یک ردیف برای هر برگه‌ای که مقیاس یا نشانه دارد.

| ستون | محتوا |
|---|---|
| برگه | نام برگه |
| مقیاس | نام پیش‌تنظیم، یا مقیاس کالیبره‌شده، یا "No scale" |
| روش | "Preset"، یا "Calibrated on (the distance you typed)" |
| فوت به ازای واحد PDF | ضریب دقیق مقیاسی که TakeoffCraft استفاده می‌کند |

## نام فایل‌ها

- `(نام).xlsx` و `(نام).csv`، که نام آن از اولین PDF باز شده در متره گرفته می‌شود.
- CSV با UTF-8 همراه با نشانه‌ی ترتیب بایت (BOM) و پایان سطر ویندوزی است که برنامه‌های صفحه‌گسترده روی همه‌ی سکوها می‌خوانند.

اجزای مجموعه مقدارشان را از یک فرمول می‌گیرند. فرمول یک عبارت ریاضی کوچک روی مقادیر اندازه‌گیری‌شده‌ی مورد است. برای مثال‌های کار شده، نگاه کنید به [مجموعه‌ها و فرمول‌ها](topic:assemblies).

## متغیرها

| نوع مورد | متغیر | معنی |
|---|---|---|
| خطی | `L` | طول کل |
| خطی | `H` | ارتفاع مورد |
| خطی | `A` | مساحت دیوار، L × H، منهای بازشوهای اجراهایی که آن‌ها را دارند (برداشت از BimCraft). وقتی آن برداشت یک روش اندازه‌گیری نام می‌برد، `A` با همان روش اندازه گرفته می‌شود: بازشوهایی که از کوچک‌ترین اندازه‌ی آن روش بزرگ‌تر نیستند داخل می‌مانند، و آنچه روش در محل تلاقی دیوارها برمی‌دارد کنار گذاشته می‌شود. یادداشت زیر مورد، نام روش را می‌گوید |
| خطی | `N` | تعداد اجراها |
| مساحت | `A` | مساحت خالص کل (محیط‌ها منهای بریدگی‌ها) |
| مساحت | `P` | محیط کل، شامل لبه‌های بریدگی |
| مساحت | `H` | عمق یا ضخامت مورد |
| مساحت | `N` | تعداد مساحت‌ها |
| شمارش | `N` | شمارش |

- متغیرها به واحدهای مورد هستند: نگاه کنید به [واحدها](topic:units).
- حروف بزرگ و کوچک یکی‌اند: `l` همان `L` است.
- فقط متغیرهای نوع خود مورد کار می‌کنند. `P` روی یک مورد خطی نتیجه می‌دهد: `"P" در اینجا مقدار اندازه‌گیری‌شده نیست. از L، H، A، N استفاده کنید.`
- ارتفاع یا عمق خالی برابر 0 است.

## عملگرها

| می‌نویسید | معنی |
|---|---|
| `+` | جمع |
| `-` یا `−` | تفریق، یا یک مقدار منفی |
| `*` یا `×` | ضرب |
| `/` یا `÷` | تقسیم |
| `( )` | گروه‌بندی |

ضرب و تقسیم قبل از جمع و تفریق انجام می‌شوند: `L * 2 + 4` یعنی (L × 2) + 4. وقتی شک دارید از پرانتز استفاده کنید.

عددها می‌توانند اعشار (`1.333`، `.5`) و توان (`1e3` = 1000) داشته باشند. فاصله‌ها نادیده گرفته می‌شوند.

## توابع

| تابع | نتیجه | مثال |
|---|---|---|
| `ceil(x)` | به بالا گرد می‌شود به عدد صحیح | `ceil(67.5)` = 68 |
| `floor(x)` | به پایین گرد می‌شود به عدد صحیح | `floor(67.5)` = 67 |
| `round(x)` | به نزدیک‌ترین عدد صحیح گرد می‌شود، نیم‌ها دور از صفر | `round(2.5)` = 3 |
| `round(x, d)` | به d رقم اعشار گرد می‌شود (0 تا 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | کوچک‌ترین مقدار | `min(N, 10)` |
| `max(a, b, …)` | بزرگ‌ترین مقدار | `max(1, ceil(N / 12))` |
| `abs(x)` | مقدار بدون علامت | `abs(-3)` = 3 |

`ceil` و `floor` خطای ناچیز محاسباتی رایانه را نادیده می‌گیرند، پس مقداری که باید دقیقاً 1 باشد هرگز به 2 گرد نمی‌شود.

## خطاها

اگر فرمولی خوانده یا محاسبه نشود، خطایش زیر فیلد نشان داده می‌شود و آن جزء از جمع‌ها کنار گذاشته می‌شود (سرتیتر {{ui:مقادیر}} می‌گوید "ناقص"). پیام‌ها:

| پیام | رفع مشکل |
|---|---|
| فرمولی وارد کنید، مثلاً L یا ceil(L / 1.333) + 1. | فرمول خالی است. |
| "X" در اینجا مقدار اندازه‌گیری‌شده نیست. از … استفاده کنید. | از یکی از متغیرهای فهرست‌شده استفاده کنید. |
| "X" در اینجا تابع نیست. از ceil، floor، round، min، max، abs استفاده کنید. | از یکی از آن توابع استفاده کنید. |
| "#" در فرمول مجاز نیست. | آن نویسه را حذف کنید (واحدها، `%`، `$` و `=` مجاز نیستند). |
| یک ")" کم است. / یک ")" بدون "(" وجود دارد. | پرانتزها را متعادل کنید. |
| قبل از ")" یک مقدار کم است. | مثلاً `max(1, )`: مقدار را وارد کنید. |
| فرمول زودتر از موعد تمام شده است. | مثلاً `L *`: آن را کامل کنید. |
| "…" غیرمنتظره است. آیا یک عملگر کم است؟ | دو مقدار کنار هم، مانند `2L`: `2 * L` بنویسید. |
| ceil() یک مقدار می‌گیرد. | به تابع تعداد درست مقدار بدهید. |
| round(x, digits) به تعداد اعشار صحیح از 0 تا 10 نیاز دارد. | از یک عدد صحیح برای تعداد اعشار استفاده کنید. |
| فرمول بر صفر تقسیم می‌کند. | معمولاً H صفر است: ارتفاع یا عمق مورد را تنظیم کنید. |
| فرمول عدد نمی‌دهد. | نتیجه خیلی بزرگ است که عدد باشد. |
| این فرمول خیلی طولانی است (حداکثر 500 نویسه). | آن را کوتاه کنید. |

## طراحی امن

یک فرمول فقط می‌تواند با متغیرها و توابع بالا محاسبه انجام دهد. نمی‌تواند کد اجرا کند یا چیز دیگری بخواند، پس فرمولی که در یک فایل پروژه برایتان فرستاده شود بی‌خطر است.

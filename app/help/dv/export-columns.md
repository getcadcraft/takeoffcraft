## Estimate (XLSX ވޯކްޝީޓް އަދި CSV)

ކޮންމެ އައިޓަމަށް ރޯ އެއް، އަދި އައިޓަމުގެ އެސެމްބްލީގެ ކޮންމެ ކޮމްޕޯނަންޓަށް ރޯ އެއް (ފަހަތުން އިންޑެންޓް ކޮށް). ފަހުން ހުސް ރޯއެއް އަދި ޖުމްލަ ޖުމްލަ ޖުމްލަ ޖުމްލަ. 

ފުރިހަމަ ޖުމްލަ ބަލާ: ކޮންމެ ރޯއެއްގެ ރޯ ކޮލަމް.

| ކޮލަމް | ތަރުތީބު | XLSX ގައި |
|---|---|---|
| A Item | އައިޓަމްގެ ނަން (ބޯލްޑް) ނުވަތަ ކޮމްޕޯނަންޓްގެ ނަން (އިންޑެންޓް) | ޓެކްސްޓް |
| B Type | Linear، Area، Count ނުވަތަ Component | ޓެކްސްޓް |
| C Unit | LF، m، SF، SY، m²، EA، ނުވަތަ ކޮމްޕޯނަންޓްގެ ޔުނިޓް | ޓެކްސްޓް |
| D Quantity | ހިނގާ ޖުމްލަ އަދަދު، ނުވަތަ ފޯމިއުލާގެ ނަތީޖާ | ނަންބަރު |
| E Waste % | ވޭސްޓް | ޕަސެންޓް (0.10 = 10%) |
| F Qty with waste | އަދަދު × (1 + ވޭސްޓް) | ފޯމިއުލާ `D*(1+E)` |
| G Material per unit | މަޓީރިއަލް ރޭޓް | ނަންބަރު |
| H Labor per unit | މަސައްކަތުގެ ރޭޓް | ނަންބަރު |
| I Material | ފުރިހަމަ މަޓީރިއަލް | ފޯމިއުލާ `ROUND(F*G,2)` |
| J Labor | ފުރިހަމަ މަސައްކަތް | ފޯމިއުލާ `ROUND(F*H,2)` |
| K Total | މަޓީރިއަލް + މަސައްކަތް | ފޯމިއުލާ `I+J` |
| L Notes | ބޭނުންކުރެވުނު ފޯމިއުލާ، ފޯމިއުލާ އެރަރ، ސްކޭލް ނެތް ޝީޓުގެ މާކުތައް، ވޯލް ޢަރުދު، ޕެރިމީޓަރ | ޓެކްސްޓް |

ޖުމްލަ ރޯ: މައްޗަށް ހުރި ހުރިހާ ރޯތަކުގެ I، J އަދި K ކޮލަމްތަކުގެ `SUM`، އަދި ކޮންމެ އެއްޗެއް ނުކުރެވުނަސް Notes ގައި "Incomplete: see the notes above".

ފޯމިއުލާ އެރަރ ހުރި ރޯއަކަށް އަދަދެއް ނުވަތަ ފައިސާ ނެތް؛ އޭގެ ނޯޓުން އެރަރ ދައްކާ. ހެޑަރ ރޯ ހުއްޓިފައި ވެއެވެ.

CSV ގައި ހަމަ ކޮލަމްތަކުގައި ސާދާ އަގުތައް ހުންނަ، Waste % އަކީ ޕަސެންޓުގެ ނަންބަރެއް (10 ގެ ބަދަލުގައި 10%)، އަދި ފައިސާ ޑޮލަރުން ދެ ދަށް ހަމަ. ސްޕްރެޑްޝީޓް ފޯމިއުލާއެއްގެ ގޮތުން ހަދާނެ ޓެކްސްޓް (`=`، `+`، `-` ނުވަތަ `@` އިން ފަށާ) އަށް ލޭޑިންގ `'` ލިބެއެވެ، ޓެކްސްޓް ގޮތުގައި ހުރުމަށް.

## ޝީޓް އާބޭހުން (XLSX ގައި ބަލާ)

| ކޮލަމް | ތަފްސީލް |
|---|---|
| Sheet | ޝީޓުގެ ނަން (PDF ނަމާއެކު ޝީޓް ހުޅުވިފައި ނެތްނަމަ) |
| Item | އައިޓަމުގެ ނަން |
| Quantity | އެ ޝީޓުގައި އެ އައިޓަމުގެ އަދަދު، އެގެ ޔުނިޓުގައި |
| Unit | އައިޓަމުގެ ޔުނިޓް |
| Marks | މާކުތަކުގެ އަދަދު |

## މާކުތައް (XLSX ގައި ބަލާ)

ކޮންމެ މާކަކަށް ރޯ އެއް.

| ކޮލަމް | ތަފްސީލް |
|---|---|
| Sheet | ޝީޓުގެ ނަން |
| Item | އައިޓަމުގެ ނަން |
| Type | Linear، Area ނުވަތަ Count |
| Quantity | ދިގުމިން، ނެޓް ބޮޑުމިން، ނުވަތަ 1 |
| Unit | LF ނުވަތަ m؛ SF، SY ނުވަތަ m²؛ EA |
| Detail | Linear: ބައި ދިގުމިންތައް، ނައްތާލެވުނު ބައިތައް "(deduct)" ލިޔާ، އަދި "deducts (length) of (length) drawn". Area: ކަނޑުން ހުންނަނަމަ ކުލަވާ އަދި ކަނޑުން ނެތް ބޮޑުމިން، އަދި ޕެރިމީޓަރ. ސްކޭލް ނެތް މާކުތަކަށް "Sheet has no scale". |
| Bid area | ބިޑް ސަރަހައްދު ހުންނަ ސޮއިގައި ބަލާ: މާކުގެ ބޮޑުމިން، ނުވަތަ "No bid area" |

## ބިޑް ސަރަހައްދު (XLSX ގައި ބަލާ، ބިޑް ސަރަހައްދު ހުންނަ ޓޭކޮފުން)

| ކޮލަމް | ކޮންމެހެން |
|---|---|
| Bid area | ސަރަހައްދުގެ ނަން، ނުވަތަ "No bid area" |
| Item | އައިޓަމް، ނުވަތަ ދަށުން އިންޑެންޓް ކުރެވުނު ކޮމްޕޯނަންޓް |
| Unit | އައިޓަމް ނުވަތަ ކޮމްޕޯނަންޓްގެ ޔުނިޓް |
| Quantity | އެ ސަރަހައްދުގައި ކުރެވުނު ދިގުމިން (ކޮމްޕޯނަންޓްތަކަށް: ސަރަހައްދުގެ ޖުމްލަތަކަށް ފޯމިއުލާ) |
| Qty with waste | އަދަދު × (1 + ވޭސްޓް) |
| Material، Labor، Total | Estimate ގައިފަދައިން ސަންޓަށް ހިސާބު ކުރެވުނު |
| Notes | Estimate ގައިފަދައިން ފޯމިއުލާ، އެރަރ އަދި ސްކޭލް ނެތް މާކުތައް |

ކޮންމެ ސަރަހައްދަކީ "(name) subtotal" ރޯއެއް އަދި އޭގެ ޚަރަދު ރޯތަކުގެ `SUM` ފޯމިއުލާ. ފަހު ރޯ **All bid areas** ސަބްޓޮޓަލްތައް ޖަމާ ކުރެއެވެ. **Marks** ވޯކްޝީޓުގައި ހަތްވަނަ ކޮލަމަކަށް **Bid area** ވެއެވެ.

## ސްކޭލްތައް (XLSX ގައި ބަލާ)

ސްކޭލް ނުވަތަ މާކުތައް ހުންނަ ކޮންމެ ޝީޓަކަށް ރޯ އެއް.

| ކޮލަމް | ތަފްސީލް |
|---|---|
| Sheet | ޝީޓުގެ ނަން |
| Scale | ޕްރީސެޓުގެ ނަން، ނުވަތަ ކަލިބްރޭޓްކުރެވުނު ސްކޭލް، ނުވަތަ "No scale" |
| How | "Preset"، ނުވަތަ "Calibrated on (the distance you typed)" |
| Feet per PDF unit | TakeoffCraft ބޭނުންކުރާ ރަނގަޅު ސްކޭލް ފެކްޓަރ |

## ފައިލް ނަންތައް

- `(name).xlsx` އަދި `(name).csv`، މިކޮށް ނަމަކީ ކޮންޓިޓީގައި ފުރަތަމަ ހުޅުވާ PDF ގެ ނަމެވެ.
- CSV އަކީ UTF-8 ފޮރމެޓުގައި، byte order mark އާއި Windows ލައިން އެންޑިންގްސް ހުންނަ ފައިލެކެވެ، ކޮންމެ ޕްލެޓްފޯމެއްގެ ސްޕްރެޑްޝީޓް ޕްރޮގްރާމްތަކުން ކިޔެވޭ.

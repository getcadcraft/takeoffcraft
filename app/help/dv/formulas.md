އެސެމްބްލީ ކޮމްޕޯނަންޓްތަކުގެ އަދަދު ލިބެނީ ފޯމިއުލާއެއްން. ފޯމިއުލާއަކީ އައިޓަމުގެ މިންގަނޑުވާ އަގުތަކުގެ މައްޗަށް ކުޑަ އަރިތްމެޓިކް އެކްސްޕްރެޝަނެވެ. މިސާލު ފަހަނައަޅާ [އެސެމްބްލީ އަދި ފޯމިއުލާ](topic:assemblies) ބަލާ.

## ވެރިއެބަލްތައް

| އައިޓަމް ޓައިޕް | ވެރިއެބަލް | މާނަ |
|---|---|---|
| Linear (ރޮނގު) | `L` | ޖުމްލަ ދިގުމިން |
| Linear (ރޮނގު) | `H` | އައިޓަމުގެ އުސްމިން |
| Linear (ރޮނގު) | `A` | ފާރުގެ ބޮޑުމިން، L × H، އެ ރަންތަކުގެ ހުސްތަކެއް ކުރާ ހުސްކުރުން ނައްތާލައި (BimCraft ގެ ކޮންޓިޓީ). ކޮންޓިޓީން މިނަށް ކަންމައިން ކަނޑައަޅާނަމަ، `A` އަކީ އެ މެތަޑުންނެވެ: މެތަޑުގެ ކުޑަ ސައިޒަށްވުރެ ކުޑަ ހުސްތައް ތިބެއެވެ، އަދި ފާރުތައް ދެމެދު އެ މެތަޑުން ނެގޭ ބައިތައް ނައްތާލެވެ. އައިޓަމުގެ ދަށުން ނޯޓް މެތަޑު ދައްކާ |
| Linear (ރޮނގު) | `N` | ރަންތަކުގެ އަދަދު |
| Area (ބޮޑުމިން) | `A` | ޖުމްލަ ނެޓް ބޮޑުމިން (ރޫޓުތަކުން ކަނޑުން ނައްތާލައި) |
| Area (ބޮޑުމިން) | `P` | ޖުމްލަ ޕެރިމީޓަރ، ކަނޑުން ހުރި ކަނޑުން ފުރާ ކިނާރުތަކާއެކު |
| Area (ބޮޑުމިން) | `H` | އައިޓަމުގެ ގަނޑުމިން ނުވަތަ ތުރުން |
| Area (ބޮޑުމިން) | `N` | ބޮޑުމިންތަކުގެ އަދަދު |
| Count (ގުނުން) | `N` | ގުނުމުގެ އަދަދު |

- ވެރިއެބަލްތައް އައިޓަމުގެ ޔުނިޓުތަކުގައި: [ޔުނިޓް](topic:units) ބަލާ.
- ބޮޑު އަކުރާ އަދި ކުޑަ އަކުރާ އެއްގޮތެވެ: `l` އަކީ `L` އެވެ.
- އައިޓަމުގެ އެއް ޓައިޕަށް ވާ ވެރިއެބަލްތަކެއް ކަމުގައިވާ: ރޮނގަށް `P` ދިމާ ވާނަމަ `"P" is not a measured value here. Use L, H, A, N.`
- ހުސް ހުންނަ އުސްމިން ނުވަތަ ގަނޑުމިން 0 އެވެ.

## އޮޕަރޭޓަރުތައް

| ލިޔުން | މާނަ |
|---|---|
| `+` | އިތުރު ކުރުން |
| `-` ނުވަތަ `−` | ނައްތާލުން، ނުވަތަ މައިނަސް އަގެއް |
| `*` ނުވަތަ `×` | ގުނުން |
| `/` ނުވަތަ `÷` | ބަހާލުން |
| `( )` | ގްރޫޕްކުރުން |

ގުނުމާއި ބަހާލުން ކުރީން ކުރެވޭ ކޮށް ބަހާލުމާއި ނައްތާލުން ފަހުން: `L * 2 + 4` އަކީ (L × 2) + 4. ބަލާނުދާނަމަ ބްރެކެޓް ބޭނުންކުރޭ.

ނަންބަރުތަކަށް ދިމާތައް (`1.333`، `.5`) އަދި އެކްސްޕޯނެންޓްސް (`1e3` = 1000) ވެސް ހުރެއެވެ. ސްޕޭސް ނޭނގެއެވެ.

## ފަންކްޝަންތައް

| ފަންކްޝަން | ނަތީޖާ | މިސާލު |
|---|---|---|
| `ceil(x)` | މަތިން ފުރިހަމަ ނަންބަރަށް ރައުންޑް | `ceil(67.5)` = 68 |
| `floor(x)` | ތަރަފަށް ފުރިހަމަ ނަންބަރަށް ރައުންޑް | `floor(67.5)` = 67 |
| `round(x)` | ކައިރިހިނދުގެ ފުރިހަމަ ނަންބަރަށް ރައުންޑް، ފަސް ރަނގުން ދުރަށް | `round(2.5)` = 3 |
| `round(x, d)` | d ދަށް ހަމައަށް ރައުންޑް (0 އިން 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | ކުޑަ އަގު | `min(N, 10)` |
| `max(a, b, …)` | ބޮޑު އަގު | `max(1, ceil(N / 12))` |
| `abs(x)` | ނިޝާން ނެތް އަގު | `abs(-3)` = 3 |

`ceil` އަދި `floor` ކޮމްޕިއުޓަރގެ ސާދަ ރައުންޑިންގ ނޯއިޒް ނައްތާލެއެވެ، ފަހަރަކަށް 1 ވާންޖެހޭ އަގެއް 2 ކަމުގައި ނުވާނެއެވެ.

## އެރަރތައް

ކިހާ ގޮތެއްވެސް ކިޔަވާ ނުލެވޭ ނުވަތަ ހިސާބު ނުކުރެވޭ ފޯމިއުލާއަކަށް، އެރަރ ފީލްޑުގެ ދަށުން ދައްކާ، އަދި ކޮމްޕޯނަންޓް ޖުމްލަތަކުން ނައްތާލެވެ ({{ui:Quantities}} ހެޑަރު "Incomplete" ދައްކާ). މެސެޖްތައް:

| މެސެޖް | ރަނގަޅުކުރުން |
|---|---|
| Type a formula, like L or ceil(L / 1.333) + 1. | ފޯމިއުލާ ހުސް. |
| "X" is not a measured value here. Use … | ލިސްޓުގައިވާ ވެރިއެބަލަކު ބޭނުންކުރޭ. |
| "X" is not a function here. Use ceil, floor, round, min, max, abs. | އެ ފަންކްޝަންތަކުން އެއް ބޭނުންކުރޭ. |
| "#" is not allowed in a formula. | އެ އަކުރު ނައްތާލޭ (ޔުނިޓް، `%`، `$` އަދި `=` ނުކުރެވޭ). |
| A ")" is missing. / There is a ")" without its "(". | ބްރެކެޓް ބެލެންސް ކުރޭ. |
| A value is missing before ")". | މިސާލަކަށް `max(1, )`: އަގެއް ފުރާ. |
| The formula ends too soon. | މިސާލަކަށް `L *`: ފުރިހަމަ ކުރޭ. |
| Unexpected "…". Is an operator missing? | ދެ އަގު ކައިރި ކައިރި، މިސާލަކަށް `2L`: `2 * L` ލިޔޭ. |
| ceil() takes 1 value. | ފަންކްޝަނަށް ތަކުރާ އަދަދު ދީ ރަނގަޅުކުރޭ. |
| round(x, digits) needs whole digits from 0 to 10. | ފުރިހަމަ ދަށް ގަނޑު (0 އިން 10) ބޭނުންކުރޭ. |
| The formula divides by zero. | އާންމުކޮށް H ސުންފުޅެވެ: އައިޓަމުގެ އުސްމިން ނުވަތަ ގަނޑުމިން ސެޓް ކުރޭ. |
| The formula does not give a number. | ނަތީޖާ އެތެރެ ބޮޑު ނަންބަރަކަށް ނުވެއެވެ. |
| That formula is too long (500 characters at most). | ކުޑަކުރޭ. |

## ރަނގަޅު ޑިޒައިން

ފޯމިއުލާއަކަށް މައްޗަށް ހުރި ވެރިއެބަލްތަކާއި ފަންކްޝަންތަކުން ހިސާބު ކުރެވޭނެއެވެ. އެއަށް ކޯޑް ރަން ނުކުރެވޭ ނުވަތަ އެހެން އެއްވެސް ކަމެއް ކިޔަވައި ނުލެވޭ، އެހެންކަމުން އެއްޗެއްގައި ފޯމިއުލާ ކުރުއްވާފައިވާ ފައިލަކުން އެއް ނުނޭތްގެވެ.

TakeoffCraft އަދިވެސް ތަރައްޤީކުރެވެމުންދޭ. މިއީ މި ބިލްޑުން ނުކުރާ ކަންތައް، އަދި އެ މަސައްކަތް މިހާރު ހަދާ ގޮތެވެ.

## މިންގަނޑުކުރުން

| އަދި ހަދާފައި ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ރޮނގެއް ނުވަތަ އުޓްލައިނެއްގެ ނެތުރުގައި ނުކުތާ އިތުރުކުރުން | މާކު ފޮހެލައި އަލުން ޑްރޯ ކުރޭ. |
| ބޮކްސް (ކޮޅު) ޚިޔާރުކުރުން | {{key:Shift}} + ކްލިކް ކޮންމެ މާކަކަށް، ނުވަތަ ޝީޓުގެ ހުރިހާ މާކަށް {{key:Mod+A}}. [މާކު ކޮޕީކުރުން، ޕޭސްޓްކުރުން އަދި ޑުޕްލިކޭޓްކުރުން](topic:copy-paste) ބަލާ. |
| ޕޭސްޓްކުރެވުނު ކޮޕީ ފަރުދާ ކުރުން، އުފުރުން ނުވަތަ ސްކޭލް ބަދަލުކުރުން | ޝީޓުގައި އެއް ސްކޭލަކުން އަދި އެއް ރުޅިއަކުން ޕޭސްޓް ކުރޭ؛ ބާކީ ހަޅުން ޑްރޯ ކުރޭ. |
| ސްކޭން ކުރެވުނު ޝީޓުން، ނުވަތަ ގްރާފިކް ސްކޭލް ބާރުން ސްކޭލް ކިޔުން | ޕްރީސެޓް ޚިޔާރު ކުރޭ، ނުވަތަ ބާރުގެ ދިގުމިން މަތިން {{ui:Calibrate}} ކުރޭ. |
| ޝީޓަކަށް ގިނަ ސްކޭލް (ޑިޓޭލް ޒޯން، ބޮޑުކުރެވުނު ޕްލޭން) | ޝީޓުގެ ސްކޭލުން އެ ބައި މިންގަނޑުކުރޭ، އަދި ސެޓުގައި ވަކި ބޮޑުކުރެވުނު ޝީޓެއް ހުރި ނަމަ ޑިޓޭލް އެ ޝީޓުގައި ހިސާބު ކުރޭ. |

## އައިޓަމްތަކާއި އަގު ކިޔުން

| އަދި ހަދާފައި ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| އެސެމްބްލީ ފޯމިއުލާ އެއް އައިޓަމަކުގެ އެހެން ބާވަތުގެ މާކުތައް ބޭނުން ކުރުން (ކޮޓަރި އައިޓަމުގެ ދޮރުތައް އެ ފަރުޝުގެ ފޯމިއުލާތަކުގައި) | ފޯމިއުލާތައް ބޭނުން ކުރަނީ މައި ބާވަތުގެ ޖުމްލަތައް؛ އެހެން ބާވަތްތައް އެމީހުންގެ އަމިއްލަ ސަފުތަކުގައި އަގު ދޭ. |
| ރޮނގު ރޮނގަށް ހިސާބުކުރާ އެސެމްބްލީ ފޯމިއުލާތައް | ފޯމިއުލާތައް ބޭނުން ކުރަނީ އައިޓަމުގެ ޖުމްލަތައް؛ ކޮންމެ ރޮނގަކަށް އިތުރު ގުނުމަށް `N` ބޭނުން ކުރޭ. |
| އެހެން އައިޓަމެއްގެ އަދަދުތައް ބޭނުން ކުރާ ފޯމިއުލާތައް | އެ އައިޓަމުގައި މިންގަނޑުކުރުން އަލުން ކުރޭ، ނުވަތަ ސްޕްރެޑްޝީޓް އެކްސްޕޯޓުގައި ހިސާބު ކުރޭ. |
| އެސެމްބްލީ ކޮމްޕޯނަންޓްތަކުގެ ކްރޫ، ނުވަތަ 8 ގަޑިއިރުން ތަފާތު ދުވަހުގެ މުއްދަތު | ކްރޫ އައިޓަމަށް ދީ، ތިޔަ ދުވަހުގެ ދިގުމިން ތަފާތު ދުވަހަކަށް ކްރޫ-ގަޑިއިރު ÷ ތިޔަ ދުވަހު ކިޔޭ. |
| ނޯޓް، ކްލައުޑް އަދި ހައިލައިޓް ނޫން މާކަޕް (ތީރު، ޑައިމެންޝަން، ސްޓޭމްޕް)، ނުވަތަ ނޯޓަކަށް ޖަވާބު | ނޯޓުގެ ލިޔުމުގައި ލިޔޭ؛ ހައްލުވުމާ އެކު ޙާލަތު ބަދަލުކުރޭ. |
| ޓީމަކުން ޝެއަރކުރާ އަގު ލައިބްރަރީ، ނުވަތަ ތިޔަ އެކައުންޓާ އެކު ހިފަހައްޓާ ލައިބްރަރީ | ލައިބްރަރީ މި ބްރައުޒަރުގައި ހިފެހެއްޓޭ: CSV ގެ ގޮތުގައި އެކްސްޕޯޓްކޮށް އަނެއް ކޮމްޕިއުޓަރުގައި އިމްޕޯޓްކުރޭ. |
| ޓްރޭޑް ޕެކްތައް ކަންތައް ކުރާ އެސްޓިމޭޓަރުންގެ ރިވިއު | ކޮންމެ ޕެކެއް ފެށުމުގެ ގޮތެކެވެ. އަގު ދިނުމުގެ ކުރިން އެގެ ފަރުޟުތައް ތިޔަ ޖޮބާއި ތިޔަ ޕްރޮޑަކްޓުތަކާ ޗެކް ކުރޭ. ބަލާ [ޓްރޭޑް ޕެކްތައް](topic:trade-packs). |
| ޓްރޭޑް ޕެކްތަކުގައި އަގުތައް | ޕެކްތައް ލިބޭނީ އެސެމްބްލީ މަތިން ބަހައްޓާފައި: ތިޔަ އަމިއްލަ ރޭޓު ޖައްސާ، ނުވަތަ ތިޔަ އަގު ލިސްޓް CSV ގެ ގޮތުގައި އިމްޕޯޓްކުރޭ. |
| ކޮންޓިޓީ ހިސާބުގެ ނަން ބަދަލުކުރުން | ނަން ލިބެނީ ފުރަތަމަ PDF ން؛ ޑައުންލޯޑުވި ފައިލްތައްގެ ނަން ބަދަލުކުރޭ. |
| ޝީޓްތައް އަތުން ނަމަކުރުން | ޝީޓްތައް ނަމަކުރެވެނީ PDF ގެ ޕޭޖް ލޭބަލްތަކުންނެވެ؛ ފައިލް ނަމާއި ޕޭޖުން ހޯދާ. |

## ޑްރޯއިންގްސް (DWG އަދި DXF)

| އަދި ހަދާފައި ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ޑްރޯއިންގުގެ ޝީޓްތަކުގައި ޕްލޮޓް ސްޓައިލް ޓޭބަލްތައް، ޕެން އެސައިންމަންޓްތައް އަދި CTB ފައިލްތައް | ޑްރޯއިންގ ކާޅުން ފެންނަވާ؛ ރަނގަޅު ޕޭޕަރަށް ރަނގުތައް ޑާކްކޮށް ދައްކާ. ރޮނގުގެ ފުޅާކަން ޑްރޯއިންގުންނެވެ. |
| binary DXF ހުޅުވުން، ނުވަތަ AutoCAD 2000 ގެ ކުރީގެ DWG | ASCII DXF ނުވަތަ އާ DWG ގެ ގޮތުގައި ސޭވް ކުރޭ. |
| ފޮލްޑަރު ހިމެނޭ ފަދައިން ލިންކްކުރެވުނު ޑްރޯއިންގ (xref) ހޯދުން | ލިންކްކުރެވުނު ޑްރޯއިންގ ފައިލް ހޯސްޓާ އެކު ހުޅުވާ: ހުޅުވިފައިވާ ފައިލްތަކުގެ ތެރެއިން ފައިލް ނަމުން ހޯދެވޭ. |
| 3D ޕޮލިލައިން، މެޝް، ސޮލިޑް އަދި ރީޖަން މިންގަނޑުކުރުން | ލޭޔަރާއި ބާވަތުން ގުނޭ، ނުވަތަ Linear އަދި Area ޓޫލްތައް ބޭނުން ކޮށް ޕްލޭން ވިއު މިންގަނޑުކުރޭ. |
| ލެޓިން ނޫން ސްކްރިޕްޓްތަކުގެ ޓެކްސްޓް ޑްރޯއިންގ މާކު ކުރެވުނު PDF ގައި | ހެލްވެޓިކާއަށް ގްލިފް ނެތް އަކުރުތައް PDF ގައި "?" ގެ ގޮތުން ފެންނަވާ؛ ސްކްރީނުގެ ޑްރޯއިންގ ބަދަލު ނުވޭ. |
| ޝީޓް ބާރުން ޑްރޯއިންގ އެހެން އެޕަކަށް ހަވާލުކުރުން | އެ ފައިލް އެ އެޕުގައި ހުޅުވާ. |
| ޑްރޯއިންގ ތެރެއަށް ކޮންޓިޓީ ހިމެނުމެއް، {{ui:PDF ތެރޭގައި ކޮންޓިޓީ ހިސާބު}} PDF ތަކަށް ފަދައިން | {{ui:ކޮންޓިޓީ ރައްކާކުރޭ}}: `.takeoff.json` ނުވަތަ އޭގެ ތެރޭގައިވާ ނަމުން އެ ހަމަ ޑްރޯއިންގުގައި އަލުން ހުޅުވޭ. |
| ޑްރޯއިންގ ތެރޭގައި ހުންނަ PDF އަންޑަލޭ، ފޮޓޯ އަދި OLE އޮބްޖެކްޓްތައް | ފޮޓޯ ފްރޭމެއް ގޮތުން ދައްކާ. އަންޑަލޭ PDF އަމިއްލައަށް ޝީޓެއް ގޮތުން ހުޅުވާ. |

## އޮޓޯ ގުނާ

| އަދި ހަދާފައި ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ސްކޭލް ޑްރޯ ނުވާ ޝީޓުގައި އެކި ސައިޒުގެ ސިމްބަލްތައް ހޯދުން | ޝީޓަށް ސްކޭލް ދީ، ނުވަތަ އޭގައި ޑްރޯ ކުރެވުނު ބޯކުސަކުން ހޯދާ. |
| މިރަރ ކުރެވުނު ސިމްބަލްތައް ހޯދުން | އެ ސިމްބަލްތައް އަތުން ގުނޭ، ނުވަތަ މިރަރ ކުރެވުނު އެއް ވަށައިގެން ބޯކުސަކުން އަލުން ހޯދާ. |

## ފައިލްތަކާއި ޝޭރިންގ

## 3D ވިއު

| 3D ގައި މާކު ޑްރޯ ކުރުން ނުވަތަ އެޑިޓް ކުރުން | ޑްރޯ ކުރުމަށް ޝީޓަށް އަނބުރާ ({{key:3}}); ސިލެކްޓް އަދި ޑިލީޓް 3D ގައި މަސައްކަތް ކުރެވޭ. |

## ބިޑިންގ

| އަދި ހަދާފައި ނެތް | ބަދަލަށް، މިއަދު |

| ކުރިން ފޮނުވި ޕެކޭޖަކަށް އެޑެންޑާ، އެވޯޑް ލެޓަރު، ކޮންމެ ބިޑަރެއް ސައިން ކުރާ ސްކޯޕް ޝީޓް | އައު ޕެކޭޖެއް ފޮނުވާ، އަދި އެވޯޑް ލިޔުން އަމިއްލައަށް ލިޔޭ. ހަދާފައިވާ ކަންތައް ބަލާ [ބިޑަށް ޕެކޭޖް ފޮނުވުން](topic:bid-invitations). |

## ސްޕްރެޑްޝީޓްތައް

XLSX ވޯކްބުކް LibreOffice Calc ގައި ޗެކް ކުރެވިފައިވޭ، އެ ކޮންމެ ޖުމްލައެއް TakeoffCraft ގެ ޖުމްލައާ ހަމަވޭ. އެ އެކްސެލްގައި އަދި ހުޅުވެފައި ނެތް. ސްޕްރެޑްޝީޓް ޕްރޮގްރާމް އެއްވެސް ނޭގޭ ކަމެއް ދައްކާނަމަ، CSV އެކްސްޕޯޓް އެ އެސްޓިމޭޓް ސާދާ ވެލިއުތަކުން ހިމެނޭ.

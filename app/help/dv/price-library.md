**އަގު ލައިބްރަރީ** ގައި ތިޔަ ކޮންމެ ޖޮބަކަށް ބޭނުންވާ އައިޓަމްތައް ހިފަހައްޓަނީ: އެ އައިޓަމުގެ ބާވަތް، ޔުނިޓް، އުސްމިން، ވޭސްޓް، މެޓީރިއަލް އަދި ލޭބަރު ރޭޓު، އަދި އޭގެ އެސެމްބްލީ. އެ ބްރައުޒަރުގައި ހިފެހެއްޓޭ، ކޮންޓިޓީތަކާ ވަކި، އެހެންކަމުން ތިޔަ ހުޅުވާ ކޮންޓިޓީއެއްގެ ލައިބްރަރީ ބޭނުން ކުރެވޭ.

{{ui:ލައިބްރަރީ}} އައިޓަމްތައް ޕެނަލުގެ މަތީގައި ހުޅުވާ.

## ލައިބްރަރީ ފުރުން

- {{ui:CSV އިމްޕޯޓްކުރޭ…}} ސްޕްރެޑްޝީޓް CSV ގެ ގޮތުގައި ސޭވްކުރެވުނު ފައިލް ކިޔޭ (ކޮލަމްތައް ތިރީގައި). ނަން އަދި ބާވަތް ދެއްކޮޅު ހުރި އައިޓަމްތައް އަލުން ލިޔެ، އެހެނިހެން އާ އެޑް ކުރޭ. ކިޔެވޭ ނޫން ސަފުތައް ޖަހާ، ކޮބައި ކިޔައިދޭ.
- {{ui:މި ކޮންޓިޓީ ހިސާބުގެ އައިޓަމްތައް އެޑްކުރޭ}} ހުޅުވާ ކޮންޓިޓީގެ ހުރިހާ އައިޓަމް ލައިބްރަރީއަށް ކޮޕީ ކުރޭ، ރޭޓުތަކާއި އެސެމްބްލީ އެކު (މާކުތަކެއް ނޫން).
- [އެސްޓިމޭޓް އެކްސްޕޯޓް ކުރޭ](topic:export-estimate) ކުރާ TakeoffCraft ގެ އަގު CSV އެ ފަދައިން އިމްޕޯޓް ވޭ: ފަހު ޖޮބުގެ އަގުތައް އައު ޖޮބަށް ފެށޭ.
- {{ui:ޓްރޭޑް ޕެކްތައް…}} ކުރާ ޓްރޭޑަކަށް ފްރީ އެސެމްބްލީތައް އެޑް ކުރޭ، މިސާލަކަށް ޑްރައިވޯލް، އިލެކްޓްރިކަލް ނުވަތަ ކޮންކްރީޓް، އަގުތަކެއް ނެތި. ބަލާ [ޓްރޭޑް ޕެކްތައް](topic:trade-packs).

{{ui:CSV އެކްސްޕޯޓްކުރޭ}} ލައިބްރަރީ CSV ގެ ގޮތުން ސޭވް ކުރޭ، ކޮޕީ ހިފެހެއްޓުމަށް، ސްޕްރެޑްޝީޓުގައި އެޑިޓް ކުރުމަށް ނުވަތަ ލިބުނު ކޮލީގަށް ދިނުމަށް. {{ui:ސާފުކުރޭ}} އޭގެ ހުރިހާ ކަމެއް ހުސް ކުރޭ (ދެފަހަރު ކްލިކް).

:::note
ލައިބްރަރީ ހުރީ ބްރައުޒަރުގެ ސްޓޯރޭޖުގައި. އެހެން ބްރައުޒަރ، އެހެން ކޮމްޕިއުޓަރ ނުވަތަ ޕްރައިވެޓް ވިންޑޯ އަމިއްލަ ލައިބްރަރީ ހިފަނީ (ނުވަތަ ނުހިފާ). ހިލާ ގެންދިއުމަށް އެކްސްޕޯޓް ކުރޭ.
:::

## ކޮންޓިޓީގައި ބޭނުން ކުރުން

- އައިޓަމްތައް ޓިކް ކުރޭ ({{ui:ލައިބްރަރީގައި ހޯދާ}} ގައި ލިޔުން ލިޔޭ ލިސްޓް ކުޑަކުރުމަށް) އަދި {{ui:ކޮންޓިޓީއަށް އެޑްކުރޭ}} ޚިޔާރު ކުރޭ. އެސެމްބްލީތަކާ އެކު ޢަމަލެއްގައި އެޑްވެ، {{key:Mod+Z}} އިން އަނބުރާ ނެގެވޭ. ކޮންޓިޓީގައި ނަމެއް ކުރިން ހުރި ނަމަ `Carpet (2)` ފަދައިން ނަންބަރެއް ލިބޭ.
- {{ui:އަގުތައް އަޕްޑޭޓްކުރޭ}} ކޮންޓިޓީގެ އައިޓަމްތަކަށް ލައިބްރަރީގެ ވޭސްޓާއި ރޭޓު ދެއެވެ، ނަމާއި ބާވަތް ދެމެހޭ ކޮންމެ އައިޓަމަށް، އަދި އެސެމްބްލީ ކޮމްޕޯނަންޓްތަކަށް ހަމަ ނަމުގެ. އުސްމިން، ޔުނިޓް އަދި ފޯމިއުލާ ހުރިފަދައިން. ހަމަ ފަހަރު {{key:Mod+Z}} ހުރިހާ ފުރަނދު އަގު އަނބުރާ ދެއެވެ.

## CSV ކޮލަމްތައް

ފުރަތަމަ ސަފުގައި ކޮލަމްތަކުގެ ނަންތައް ކޮންމެ ތަރުތީބުގައި؛ އެހެން ކޮލަމްތައް ނޭގިގެން ދޫކުރެވެއެވެ.

| ކޮލަމް | ކޮބައި ލިޔޭ |
|---|---|
| Item (ނުވަތަ Name) | އައިޓަމުގެ ނަން. ލާޒިމެވެ. |
| Type | Linear، Area ނުވަތަ Count (LF، SF އަދި EA ވެސް ކަމުގައި). ހުސް ނަމަ، ޔުނިޓް ކަނޑައަޅާ. |
| Unit | LF ނުވަތަ m؛ SF، SY ނުވަތަ m²؛ EA. ހުސް: ބާވަތުގެ ޢާދަތީ ޔުނިޓް. |
| Waste % | `10` ނުވަތަ `10%`. |
| Material per unit، Labor per unit | ރޭޓު `2.10` ނުވަތަ `$1,250` ފަދައިން. |
| Height (ނުވަތަ Depth) | `9'-0"`، `9`، ނުވަތަ މެޓްރިކް ޔުނިޓަށް `2.7`. |
| Component، Formula | Component ނަމެއް (ނުވަތަ Type `Component`) ހުރި ސަފެއް، ކުރީގެ އައިޓަމުގެ އެސެމްބްލީގެ ބައެކެވެ. އޭގެ ޔުނިޓް، ވޭސްޓް އަދި ރޭޓު އެކަމުގެ އަމިއްލަ؛ ފޯމިއުލާ އައިޓަމުގެ އަކުރުތައް ބޭނުން ކުރޭ، ބަލާ [އެސެމްބްލީ އަދި ފޯމިއުލާތައް](topic:assemblies). |

```

Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

ކޮލަމްތަކާ ދެމެދު ކޮމާ، ސެމީކޯލަން ނުވަތަ ޓެބް، ހުރިހާ ކަމެއް ކަނޑު.

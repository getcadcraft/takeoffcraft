އައިޓަމެއްގެ **އެސެމްބްލީ** އަކީ ކޮމްޕޯނަންޓްތަކުގެ ލިސްޓެއް، އެކެއްގެ އަދަދުގެ ފޯމިއުލާއާއި އޭގެ ވޭސްޓާއި ރޭޓުތައް އެކުގައި. ފޯމިއުލާ ބޭނުންކުރަނީ އައިޓަމުގެ މިނިވަން ކުޅަދާނަ ޖުމްލަތަކެވެ. ފާރެއް އެއްފަހަރު މިނިވަން ކުރުމުން ސްޓަޑް، ޕްލޭޓާއި ބޯޑު އެކްސްގޮތުން ލިބެއެވެ، އަދި މިނިވަން ކުރުމާއެކު އެ އަގުތައް އަޕްޑޭޓް ވެއެވެ.

## ބޭނުންކުރެވޭ ވޭރިއަބަލްތައް

| އައިޓަމުގެ ޓައިޕް | ވޭރިއަބަލްތައް |
|---|---|
| ލީނިއާ | `L` ދިގު، `H` އުސް، `A` ފާރުގެ ބޮޑުމިން (L × H)، `N` ރަންތަކުގެ އަދަދު |
| ހަރުދަނާ | `A` ބޮޑުމިން، `P` ހަމަތެރޭގެ ދިގު (ދާރު + ކަނޑާފައިވާ ބައިތައް)، `H` ގަނޑުމިން ނުވަތަ ތިކަން، `N` ސަރަހައްދުތަކުގެ އަދަދު |
| ގުނާ | `N` އަދަދު |

އަގުތައް ވާނީ އައިޓަމުގެ ޔަގީން ޔުނިޓްތަކުގައެވެ: LF އާއި SF އައިޓަމްތަކަށް ފޫޓާއި ސްކެއާ ފޫޓު، m އާއި m² އައިޓަމްތަކަށް މީޓަރާއި ސްކެއާ މީޓަރު. SY އައިޓަމަކަށް `A` ވާނީ ސްކެއާ ޔާޑުގައި، އަދި `P` އާއި `H` ފޫޓުގައެވެ.

ފޯމިއުލާތަކުގައި `+ - * /` (ނުވަތަ × ÷)، ބްރެކެޓްތައް، އަދަދުތައް، އަދި ފަންކްޝަންތައް `ceil`، `floor`، `round`، `min`، `max` އަދި `abs` ބޭނުންކުރެވޭނެއެވެ. ފުރިހަމަ މާއްދާތައް [ފޯމިއުލާ ބަސް](topic:formulas) ގައި ވެއެވެ.

## މިސާލު: ތެރޭ ފާރެއް

ލީނިއާ އައިޓަމެއް ގޮތުގައި **ތެރޭ ފާރު ޓައިޕް A** މިނިވަން ކުރެއްވީ ކަލްपנާ: 120 LF ޖުމްލަ ދިގުގެ 4 ރަން، އަދި {{ui:Height}} `9'-0"` ގައި. އޭގެ **Measured** އަގުތައް L = 120، N = 4، A = 1,080 (ފާރުގެ SF، އެއް މޫނު).

1. {{ui:Items}} ދަށުން އައިޓަމް ޚިޔާރުކުރޭ.
2. {{ui:Assembly}} ގައި {{ui:Add component}} ޚިޔާރުކުރޭ.
   "ކޮމްޕޯނަންޓް" ނަމުގެ ކޮމްޕޯނަންޓެއް ފެނިގެން، ފޯމިއުލާ `L` އާއި އޭގެ ނަތީޖާ ދަށުގައި ފެނޭ.
3. {{ui:Name}} ގައި `Studs 16 in o.c.` ލިޔޭ، އަދި {{ui:Unit}} ގައި `EA` ލިޔޭ.
4. {{ui:Quantity formula}} ގައި `ceil(L * 12 / 16) + N` ލިޔޭ.
   ލިޔޭއިރުން ނަތީޖާ އަޕްޑޭޓް ވެއެވެ: "= 94 EA". މިއީ 120 ފޫޓުގެ ދިގު ސްޓަޑް އިންޗް 16 ފާސްލާ (90)، އަދި 4 ރަންގެ ކޮނޑުތައް ބަންދުކުރުމަށް ކޮންމެ ރަންއަކަށް އިތުރު އެއް (4).
5. ޕްލޭޓުތަކަށް {{ui:Add component}} އަލުން ޚިޔާރުކުރޭ: ނަން `Plates, top and bottom`، ޔުނިޓް `LF`، ފޯމިއުލާ `L * 2`. ނަތީޖާ: 240 LF.
6. ބޯޑު އިތުރުކުރޭ: ނަން `Gypsum board 4x8, both sides`، ޔުނިޓް `sheets`، ފޯމިއުލާ `ceil(A * 2 / 32)`. ނަތީޖާ: 68 ޝީޓް (2,160 SF ބޯޑު ÷ ކޮންމެ ޝީޓަށް 32 SF = 67.5، މަތީ ފުރާފައި).
7. ކޮމްޕޯނަންޓް ކޮންމެއަކަށް {{ui:Waste %}}، {{ui:Material $}} އާއި {{ui:Labor $}} ފުރޭ.
   ކޮންމެ ކޮމްޕޯނަންޓަކަށް {{ui:Quantities}} ގައި އެގެ ޕްރަވެސް ރޯއެއް ލިބޭ، އައިޓަމެއް ފަދައިން އަގު ލިބޭ، އަދި {{ui:Job total}} ގައި އެ އަގު ހިމެނެއެވެ.

ފާރުގެ ޚަރަދު ހުރިހާ ކޮމްޕޯނަންޓްތަކުގައި ވާނަމަ، އައިޓަމުގެ އެހެނިހެން މާޓެރިއަލް އަދި މަސައްކަތުގެ ރޭޓް 0 ގައި ތިބޭށެވެ، އެހެނަސް ދެފަހަރު ގުނާ ވާނެއެވެ.

:::tip
ވޭސްޓް ފޯމިއުލާ ފަހުން ކުރިޔަށް ގެންދެވެއެވެ، އަދި އޭގެ ފުރާ ގުނާ ނުކުރެވޭ: 68 ޝީޓް 10% ވޭސްޓާއެކު 74.8 ޝީޓް ވެއެވެ. ފުރި ޝީޓް ލިބުމަށް، ވޭސްޓް ފޯމިއުލާގެ ތެރޭގައި ލިޔޭ، މިސާލަކަށް `ceil(A * 2 / 32 * 1.1)`، އަދި ކޮމްޕޯނަންޓްގެ ވޭސްޓް 0 ގައި ތިބޭށެވެ.
:::

## އިތުރު ފޯމިއުލާ

| ކުރާ ކަންތައް | އައިޓަމް | ފޯމިއުލާ |
|---|---|---|
| ސެންޓަރުން އިންޗް 24 ގެ ސްޓަޑް | ލީނިއާ | `ceil(L / 2) + N` |
| އިންސުލޭޝަން ބެޓްސް، SF | އުސްމިނާއެކު ލީނިއާ | `A` |
| ފެންތާ، ދެފަރާތް، SF 350 ގެ ގެލަން | އުސްމިނާއެކު ލީނިއާ | `ceil(A * 2 / 350)` |
| ޓައިލް ކާޓަން، SF 15، 10% އިތުރު | ހަރުދަނާ | `ceil(A * 1.1 / 15)` |
| ބޭސް ނުވަތަ ކަނާރަ ޓްރިމް، LF | ހަރުދަނާ | `P` |
| ކޮންކްރީޓް، ކިއުބިކް ޔާޑް | ގަނޑުމިނާއެކު ހަރުދަނާ | `A * H / 27` |
| ކޮންކްރީޓް ކާލެއް ޔާޑަށް މަތީ ފުރާފައި | ގަނޑުމިނާއެކު ހަރުދަނާ | `ceil(A * H / 27 * 4) / 4` |
| ދޮރަކަށް ތިން ހިންޖް | ގުނާ | `N * 3` |
| ކަނޑައެއް ކުறަށް ކުރިން، 12 ގައި އެއް | ގުނާ | `max(1, ceil(N / 12))` |

## ފޯމިއުލާ ގޮތް ނުރައްކާތެރި ވުމުން

ފޯމިއުލާގެ ދަށުގެ ލައިން އެރަރް މެސެޖަކަށް ވެއެވެ، މިސާލަކަށް `"X" is not a measured value here. Use L, H, A, N.` ނުވަތަ `A ")" is missing.`. ފަހުން ކޮމްޕޯނަންޓަށް އަދަދެއް ނުލިބޭ، އަދި {{ui:Quantities}} ގައި އޭގެ ރޯ "Formula error: …" ފެނޭ، އަދި ހެޑަރުގައި "Incomplete: 1 formula error (not in the totals)" ފެނޭ. ފޯމިއުލާ ރަނގަޅު ކުރުމުން ޖުމްލަ އަގުތައް އަޕްޑޭޓް ވެއެވެ.

ޒީރޯން ބަހާ ފޯމިއުލާ ވެސް އެރަރެކެވެ ("The formula divides by zero."), މިސާލަކަށް ގަނޑުމިނެއް ނެތް އައިޓަމެއް ގައި `A / H`.

## ސީމާތައް

- ފޯމިއުލާ ހިސާބުކުރެވެނީ އައިޓަމުގެ **ޖުމްލަތަކަށް**، ރަން ރަނަށް ނޫން. `ceil(L * 12 / 16) + N` ކޮންމެ ރަނަކަށް ސްޓަޑް އެއް އިތުރުކުރޭ؛ ރަނަށް ރަން ފުރާ ގުނާ ކުރުމެއް މިހާރު ނެތް.
- ފޯމިއުލާއަކަށް އެ އައިޓަމުގެ ވޭރިއަބަލްތައް ބޭނުންކުރެވޭނެ، އެހެން އައިޓަމެއްގެ ނޫން.
- އައިޓަމަކަށް 50 ކޮމްޕޯނަންޓް އަދި ފޯމިއުލާއަކަށް 500 އަކުރު.

## ކޮމްޕޯނަންޓެއް ފޮހެލާ

އޭގެ ދަށުގައި {{ui:Remove component}} ޚިޔާރުކުރޭ. {{key:Mod+Z}} އިން އެކަން އަނބުރާ ކުރެވޭނެއެވެ.

އެސްޓިމޭޓް ގުނާ ކުރާ އެއްޗެއް އަގަކަށް ހަދައެވެ. **ބީލަމުގެ ޚުލާޞާ** އޭގައި ސޭލްސް ޓެކްސް، އޯވަރ ހެޑް، ނަފާ އަދި ބޮންޑު އިތުރު ކުރައި، ތިބާގެ ޝާމިލުތަކާއި ނުކުރާ ކަންތައްތަކާއެކު **ޕްރޮޕޯސަލް PDF** ހަދައެވެ.

{{ui:Export}} › {{ui:Bid summary & proposal…}} ޚިޔާރުކުރުމުން ހުޅުވޭ. އެ ހުރިހާ ކަމެއް ގުނާ ފައިލާއެކު ރައްކާ ވެއެވެ، އަދި ކޮންމެ ބަދަލެއް އަނބުރާ ކުރެވޭ.

## މާކަޕްތައް

ފަސް ޖާއިއިން ވެސް އެއް ޕަރސެންޓެއް ޓައިޕް ކުރޭ (އެހެން ކޮންމެ ފަހަރުން 0 ގައި ހުއްޓަވާ). އެ އަގުތައް ހިސާބުކުރެވެނީ މި ތަރުތީބުން، ކޮންމެ ލައިނެއް އެކެއްގެ މަތީގައި:

| ލައިން | ހިސާބު ކުރެވޭ ގޮތް |
|---|---|
| މެޓީރިއަލް، ލޭބަރ | އެސްޓިމޭޓުގެ ޖުމްލަ (ބީލަމުގެ ބޭސް، ގުނާ ފަހުން [އަލްޓަނޭޓްތައް](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) ހުރި ނަމަ). |
| ލޭބަރ ބާރު | ބާރު % × ލޭބަރ: ކްރޫގެ ހިއްސާ ފަހަރެއްގެ ޕޭރޯލް ޓެކްސް، އިންޝުއަރެންސް އަދި ފައިދާ. |
| **ކޮސްޓް** | މެޓީރިއަލް + ލޭބަރ + ލޭބަރ ބާރު. |
| މެޓީރިއަލްގެ ސޭލްސް ޓެކްސް | ޓެކްސް % × މެޓީރިއަލް. |
| އޯވަރ ހެޑް | އޯވަރ ހެޑް % × (ކޮސްޓް + ޓެކްސް). |
| ނަފާ | ނަފާ % × (ކޮސްޓް + ޓެކްސް + އޯވަރ ހެޑް). |
| ބޮންޑު | ބޮންޑު % × މަތީގެ ހުރިހާ އެއްޗެއް. |
| **ބީލަން** | ލައިންތަކުގެ ޖުމްލަ. |

ކޮންމެ ލައިނެއް ސެންޓަށް ރައުންޑް ކުރެވެއެވެ. ވޯކްބުކުގައި އެ ލައިންތައް އެސްޓިމޭޓް ޝީޓުގެ ޖުމްލައަށް ދެމެދު، ލައިވް ފޯމިއުލާތަކާއެކު ފެނޭ. ޖުމްލަ ތިބާ ޓައިޕް ކުރާ ހިނދު އަޕްޑޭޓް ވެއެވެ: {{key:Enter}} ޕަރސެންޓް ނެގެއެވެ. ކޮންމެ އަލްޓަނޭޓަކަށް އެއްވަރު މާކަޕްތައް އެހެން އެންމެހާ އޭގެ ކޮސްޓަށް ހިމެނިވެ، ތިބާ ކުއްޔަށް ދެނެގަނެވޭ މި އަލްޓަނޭޓް ހެދުމަކީ ކިހިނެއް ބަދަލެއްކަން.

## ޕްރޮޕޯސަލް

ޕްރޮޕޯސަލް ކީއްވެގެން ބުނަންޖެހޭނީ ހެއްޔެވެ ފުރާ ޖާ:

- **ޕްރޮޖެކްޓް** (ކުއްޔަށް ނެތީ ގުނާގެ ނަން), **ޓޫ** (ކްލައިޓް) އަދި **ފްރޮމް** (ތިބާގެ ކުނި).
- **ޝާމިލު** އަދި **ނުކުރާ**: ކޮންމެ ލައިނަކަށް އެއް ގޮތް; ޑޭޝް ނުވަތަ ބުލެޓް ހިމެނިޔަސް ރަނގަޅުވެއެވެ.
- **ޝަރުތު**: އެތެރެ ޓެކްސްޓް، މިސާލަކަށް "Valid for 30 days."
- **އައިޓަމްތަކާއި އަދަދުތައް ލިސްޓް ކުރޭ**: ސްކޯޕް، އައިޓަމް ފަހަށް، އަދަދުތަކާއެކު އަދި އަގުތަކެއް ނެތި. ލަމްޕް-ސަމް ޕްރޮޕޯސަލަކަށް ނުލާށެވެ.

{{ui:Proposal PDF}} ޚިޔާރުކުރޭ. PDF (`<takeoff> - proposal.pdf`) ގައި ތާރީޚު، އަގުގެ ބްލޮކް ކޮންމެ މާކަޕާއެކު އަދި ބީލަން، އަލްޓަނޭޓްތައް، ސްކޯޕް، ޝާމިލުތަކާއި ނުކުރާ ކަންތައް، ޝަރުތުތައް، އަދި ސޮއި ކޮށް ތާރީޚު ކުރެވޭ ލައިންތައް ހުށެއެވެ. ކަމެއް ނެތް ކުއާންޓިޓީ ކަނޑައަޅާ ނުކުރެވުނު ނަމަ (ސްކޭލް ނެތް ޝީޓެއް)، އަގުގެ ދަށުން ވާ ގޮތް ބުނެއެވެ.

## އެކްސްޕޯޓުގައި

ބީލަމުގެ ޚުލާޞާ ހުރި ނަމަ، CSV އޭގެ އަޚިރުގައި ވާނެ، އަދި ވޯކްބުކުގައި **Bid summary** ޝީޓެއް ލިބެނީ، ކޮންމެ ލައިންއަކާއި އޭގެ ޕަރސެންޓާއި އަދަދާއެކު. [އެސްޓިމޭޓް އެކްސްޕޯޓް](topic:export-estimate) ބަލާށެވެ.

Складнікі зборкі атрымліваюць колькасць з формулы. Формула — гэта невялікі арыфметычны выраз па вымераных значэннях элемента. Гл. [Зборкі і формулы](topic:assemblies) для прыкладаў.

## Зменныя

| Тып элемента | Зменная | Значэнне |
|---|---|---|
| Лінейны | `L` | Агульная даўжыня |
| Лінейны | `H` | Вышыня элемента |
| Лінейны | `A` | Плошча сцяны, L × H, мінус праёмы тых адрэзкаў, якія іх маюць (падлік з BimCraft). Калі ў гэтым падліку названы спосаб вымярэння, `A` вымяраецца ім: праёмы не большыя за найменшы памер гэтага спосабу застаюцца, а тое, што спосаб не ўлічвае ў месцах сустрэчы сцен, выключаецца. Нататка пад элементам называе спосаб |
| Лінейны | `N` | Колькасць адрэзкаў |
| Плошча | `A` | Агульная чыстая плошча (контуры мінус вырэзы) |
| Плошча | `P` | Агульны перыметр, уключаючы краі вырэзаў |
| Плошча | `H` | Глыбіня або таўшчыня элемента |
| Плошча | `N` | Колькасць плошчаў |
| Лік | `N` | Лік |

- Зменныя ў адзінках элемента: гл. [Адзінкі](topic:units).
- Вялікія і малыя літары аднолькавыя: `l` — гэта `L`.
- Працуюць толькі зменныя свайго тыпу элемента. `P` для лінейнага элемента дае «"P" тут не вымераная велічыня. Выкарыстоўвайце L, H, A, N.»
- Пустая вышыня або глыбіня лічыцца як 0.

## Аператары

| Запіс | Значэнне |
|---|---|
| `+` | Складанне |
| `-` або `−` | Адняцце або адмоўнае значэнне |
| `*` або `×` | Множанне |
| `/` або `÷` | Дзяленне |
| `( )` | Групоўка |

Множанне і дзяленне выконваюцца раней за складанне і адняцце: `L * 2 + 4` — гэта (L × 2) + 4. Калі не пэўныя, ужывайце дужкі.

Лікі могуць мець дзесятковыя часткі (`1.333`, `.5`) і ступені (`1e3` = 1000). Прабелы ігнаруюцца.

## Функцыі

| Функцыя | Вынік | Прыклад |
|---|---|---|
| `ceil(x)` | Акругленне ўверх да цэлага | `ceil(67.5)` = 68 |
| `floor(x)` | Акругленне ўніз да цэлага | `floor(67.5)` = 67 |
| `round(x)` | Акругленне да бліжэйшага цэлага, паловы ад нуля | `round(2.5)` = 3 |
| `round(x, d)` | Акругленне да d знакаў пасля коскі (ад 0 да 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Найменшае значэнне | `min(N, 10)` |
| `max(a, b, …)` | Найбольшае значэнне | `max(1, ceil(N / 12))` |
| `abs(x)` | Значэнне без знака | `abs(-3)` = 3 |

`ceil` і `floor` ігнаруюць дробныя камп’ютарныя хібы акруглення, таму значэнне, якое павінна быць роўна 1, ніколі не акругляецца да 2.

## Памылкі

Формула, якую нельга прачытаць або вылічыць, паказвае сваю памылку пад полем, а складнік не ўлічваецца ў вынікі (загаловак {{ui:Колькасці}} кажа «Няпоўна»). Паведамленні:

| Паведамленне | Што рабіць |
|---|---|
| «Укажыце формулу, напрыклад L або ceil(L / 1.333) + 1.» | Формула пустая. |
| «"X" тут не вымераная велічыня. Выкарыстоўвайце …» | Выкарыстоўвайце адну з пералічаных зменных. |
| «"X" тут не функцыя. Выкарыстоўвайце ceil, floor, round, min, max, abs.» | Выкарыстоўвайце адну з гэтых функцый. |
| «"#" нельга выкарыстоўваць у формуле.» | Выдаліце гэты знак (адзінкі, `%`, `$` і `=` не дапускаюцца). |
| «Не хапае ")».» / «Ёсць ")" без свайго "(".» | Выраўняйце дужкі. |
| «Перад ")" не хапае значэння.» Напрыклад `max(1, )`. | Запоўніце значэнне. |
| «Формула заканчваецца занадта рана.» Напрыклад `L *`. | Завяршыце формулу. |
| «Нечаканае "…". Ці няма аператара?» | Два значэнні побач, напрыклад `2L`: напішыце `2 * L`. |
| «ceil() прымае 1 значэнне.» | Дайце функцыі патрэбную колькасць значэнняў. |
| «round(x, digits) патрабуе цэлыя знакі ад 0 да 10.» | Выкарыстоўвайце цэлую колькасць знакаў пасля коскі. |
| «Формула дзеліць на нуль.» | Звычайна H роўна 0: задайце вышыню або глыбіню элемента. |
| «Формула не дае ліку.» | Вынік занадта вялікі, каб быць лікам. |
| «Гэтая формула занадта доўгая (не больш за 500 знакаў).» | Скараціце яе. |

## Бяспечна па задуме

Формула можа выконваць толькі арыфметыку са зменнымі і функцыямі, пералічанымі вышэй. Яна не можа запускаць код або чытаць што-небудзь іншае, таму формула ў файле праекта, які вам прыслалі, бяспечная.

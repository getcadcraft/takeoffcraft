## Каштарыс (аркуш XLSX і CSV)

Адзін радок на элемент, затым радок на кожны складнік яго зборкі (з водступам). Потым пусты радок і агульны вынік.

| Слупок | Змест | У XLSX |
|---|---|---|
| A Элемент | Назва элемента (тлустым) або назва складніка (з водступам) | Тэкст |
| B Тып | Лінейны, Плошча, Лік або Складнік | Тэкст |
| C Адзінка | LF, m, SF, SY, m², EA або адзінка складніка | Тэкст |
| D Колькасць | Вымераны агульны вынік або вынік формулы | Лік |
| E Адходы % | Адходы | Працэнт (0.10 = 10%) |
| F Колькасць з адходамі | Колькасць × (1 + адходы) | Формула `D*(1+E)` |
| G Матэрыял за адзінку | Стаўка матэрыялу | Лік |
| H Праца за адзінку | Стаўка працы | Лік |
| I Матэрыял | Развернуты матэрыял | Формула `ROUND(F*G,2)` |
| J Праца | Развернутая праца | Формула `ROUND(F*H,2)` |
| K Разам | Матэрыял + праца | Формула `I+J` |
| L Нататкі | Выкарыстаная формула, памылка формулы, меткі на аркушах без маштабу, плошча сцяны, перыметр | Тэкст |

Радок агульнага выніку: `SUM` слупкоў I, J і K па ўсіх радках вышэй; у нататках — «Няпоўна: гл. нататкі вышэй», калі нешта прапушчана.

Радок з памылкай формулы не мае колькасці або сум; у яго нататцы ўказана памылка. Радок загалоўка замацаваны.

У CSV тыя ж слупкі маюць простыя значэнні: Адходы % — гэта лік працэнтаў (10 для 10%), а грошы — у долярах з двума знакамі пасля коскі. Тэкст, які табліца можа прыняць за формулу (пачынаецца з `=`, `+`, `-` або `@`), атрымлівае `'` спераду, каб заставацца тэкстам.

## Па аркушах (толькі XLSX)

| Слупок | Змест |
|---|---|
| Аркуш | Назва аркуша (з назвай PDF, калі ён не адкрыты) |
| Элемент | Назва элемента |
| Колькасць | Колькасць гэтага элемента на гэтым аркушы ў яго адзінцы |
| Адзінка | Адзінка элемента |
| Меткі | Колькасць метак |

## Меткі (толькі XLSX)

Адзін радок на метку.

| Слупок | Змест |
|---|---|
| Аркуш | Назва аркуша |
| Элемент | Назва элемента |
| Тып | Лінейны, Плошча або Лік |
| Колькасць | Даўжыня, чыстая плошча або 1 |
| Адзінка | LF або m; SF, SY або m²; EA |
| Падрабязнасці | Лінейныя: даўжыні адрэзкаў, адлічаныя адмечаны «(адлік)», і «адлічвае (даўжыня) з (даўжыня) намаляваных». Плошча: поўныя і вырэзаныя плошчы, калі ёсць вырэзы, і перыметр. «Аркуш без маштабу» для меток без маштабу. |
| Тэндарная плошча | Толькі калі ў падліку ёсць тэндарныя плошчы: плошча меткі або «Няма тэндарнай плошчы» |

## Па тэндарных плошчах (толькі XLSX, калі ў падліку ёсць тэндарныя плошчы)

| Слупок | Змест |
|---|---|
| Тэндарная плошча | Назва плошчы або «Няма тэндарнай плошчы» |
| Элемент | Элемент або складнік пад ім з водступам |
| Адзінка | Адзінка элемента або складніка |
| Колькасць | Вымерана ў гэтай плошчы (складнікі: формула па вынікам плошчы) |
| Колькасць з адходамі | Колькасць × (1 + адходы) |
| Матэрыял, Праца, Разам | Развернута да цэнту, як на аркушы Каштарыс |
| Нататкі | Формула, памылкі і немаштабаваныя меткі, як на аркушы Каштарыс |

Кожная плошча заканчваецца радком «(назва) падсума», чые кошты — формулы `SUM` па яго радках. Апошні радок, **Усе тэндарныя плошчы**, складае падсумы. Аркуш **Меткі** тады мае сёмы слупок — **Тэндарная плошча**.

## Маштабы (толькі XLSX)

Адзін радок на аркуш, які мае маштаб або меткі.

| Слупок | Змест |
|---|---|
| Аркуш | Назва аркуша |
| Маштаб | Назва пераднастройкі, калібраваны маштаб або «Няма маштабу» |
| Як | «Пераднастройка» або «Калібравана па (адлегласць, якую вы ўвялі)» |
| Футы на адзінку PDF | Дакладны каэфіцыент маштабу, які выкарыстоўвае TakeoffCraft |

## Назвы файлаў

- `(назва).xlsx` і `(назва).csv`, дзе назва бярэцца з першага PDF, адкрытага ў падліку.
- CSV у кадаванні UTF-8 з маркерам парадку байтаў і радковымі канцамі Windows, якія чытаюць табліцы на ўсіх платформах.

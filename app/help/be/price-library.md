**Бібліятэка цэн** захоўвае пазіцыі, якія вы выкарыстоўваеце ад аб’екта да аб’екта: іх тып, адзінку, вышыню, адход, стаўкі матэрыялу і працы і іх зборку. Яна захоўваецца ў гэтым браўзеры, асобна ад любога падліку, таму кожны падлік, які вы адкрываеце тут, можа яе выкарыстоўваць.

Адкрыйце яе з {{ui:Бібліятэка}} уверсе панэлі {{ui:Пазіцыі}}.

## Запаўненне бібліятэкі

- {{ui:Імпартаваць CSV…}} чытае электронную табліцу, захаваную як CSV (гл. слупкі ніжэй). Пазіцыі, чые назва і тып ужо ёсць у бібліятэцы, замяняюцца; астатнія дадаюцца. Радкі, якія яна не можа прачытаць, прапускаюцца, і яна кажа, якія і чаму.
- {{ui:Дадаць пазіцыі гэтага падліку}} капіруе ў бібліятэку ўсе пазіцыі адкрытага падліку з іх стаўкамі і зборкай (але не адзнакамі).
- CSV-каштарыс, які экспартуе TakeoffCraft ([Экспарт каштарыса](topic:export-estimate)), імпартуецца без змяненняў: цэны мінулага аб’екта становяцца зыходнымі для наступнага.

- {{ui:Пакеты работ…}} дадае бясплатныя зборкі для галіны, напрыклад для гіпсакартону, электрыкі або бетону, без цэн. Гл. [Пакеты работ](topic:trade-packs).

{{ui:Экспартаваць CSV}} захоўвае бібліятэку як CSV: каб захаваць копію, адрэдагаваць у табліцы або перадаць калегу. {{ui:Ачысціць}} ачышчае яе (націсніце двойчы).

:::note
Бібліятэка знаходзіцца ў сховішчы гэтага браўзера. Іншы браўзер, іншы кампутар або прыватнае акно маюць сваю (або не маюць). Экспартуйце яе, каб перанесці.
:::

## Выкарыстанне ў падліку

- Адзначце пазіцыі (увядзіце ў {{ui:Пошук у бібліятэцы}}, каб звузіць спіс) і выберыце {{ui:Дадаць у падлік}}. Яны дадаюцца з сваімі зборкамі адным крокам, які {{key:Mod+Z}} адмяняе. Назва, якая ўжо ёсць у падліку, атрымлівае нумар, напрыклад `Дыван (2)`.
- {{ui:Абнавіць цэны}} дае пазіцыям падліку адход і стаўкі бібліятэкі для кожнай пазіцыі, чыя назва і тып супадаюць з пунктам бібліятэкі, і тое ж для кампанентаў зборкі з той жа назвай. Вышыні, адзінкі і формулы застаюцца такімі, як ёсць. Адно {{key:Mod+Z}} вяртае ўсе старыя цэны.

## Слупкі CSV

Першы радок называе слупкі ў любым парадку; іншыя слупкі ігнаруюцца.

| Слупок | Што ўносіцца |
|---|---|
| Item (або Name) | Назва пазіцыі. Абавязкова. |
| Type | Linear, Area або Count (LF, SF і EA таксама працуюць). Калі пуста, тып вызначае адзінка. |
| Unit | LF або m; SF, SY або m²; EA. Пуста: звычайная адзінка тыпу. |
| Waste % | `10` або `10%`. |
| Material per unit, Labor per unit | Стаўкі, напрыклад `2.10` або `$1,250`. |
| Height (or Depth) | `9'-0"`, `9` або `2.7` для метрычных адзінак. |
| Component, Formula | Радок з назвай у Component (або з тыпам `Component`) з'яўляецца часткай зборкі пазіцыі вышэй. Яго Unit, Waste і стаўкі — уласныя; яго Formula выкарыстоўвае літары пазіцыі, гл. [Зборкі і формулы](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

Коскі, кропкі з коскай або табуляцыі паміж слупкамі — працуюць усе.

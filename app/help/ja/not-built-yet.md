TakeoffCraft は開発中です。このリストは、現在のビルドでできないことと、その代わりに作業を進める方法を示します。

## 計測

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 連続線または輪郭の途中に点を挿入すること | マークを削除して、描き直してください。 |
| 窓選択 | {{key:Shift}}キーを押しながら各マークをクリックするか、{{key:Mod+A}} でシート上のすべてのマークを選択します。[マークのコピー、貼り付け、複製](topic:copy-paste) を参照してください。 |
| 貼り付けたコピーの回転、鏡像、尺度変更 | 同じ縮尺と同じ向きでシートに貼り付け、残りは手で描いてください。 |
| スキャンしたシートや図形の尺度バーからの縮尺の読み取り | プリセットを選ぶか、バーの長さで{{ui:校正}}してください。 |
| 1 枚のシートに複数の縮尺（詳細部、拡大平面図） | 部分の計測はシートの縮尺で行ってください。セットに拡大シートがある場合は、詳細部をその拡大シートで拾い出してください。 |

## 項目と単価

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 複合単価の計算式で、項目の別の種類のマークを使うこと（階の計算式で部屋の項目の建具を使うなど） | 計算式は主な種類の合計を使います。他の種類は独立した行で単価を設定してください。 |
| 連続線ごとに算出する複合単価の計算式 | 計算式は項目の合計を使います。連続線ごとの追加には `N` を使ってください。 |
| 別の項目の数量を使う計算式 | その項目で計測をやり直すか、表計算の書き出しで計算してください。 |
| 複合単価の内訳に班を設定すること、または 8 時間以外の 1 日の労働時間 | 班は項目に設定してください。別の 1 日の長さで班日数を読むには、班時間 ÷ 1 日の時間で求めてください。 |
| 注記、雲マーク、ハイライト以外のマークアップ（矢印、寸法、スタンプ）、または注記への返信 | 注記のテキストに書き、解決したらステータスを変更してください。 |
| チームで共有する単価ライブラリ、またはアカウントに保存する単価ライブラリ | ライブラリはこのブラウザーに保存されます。CSV として書き出し、もう一方のコンピューターでインポートしてください。 |
| 実務の積算担当者が確認した工種パック | すべてのパックは出発点です。単価を決める前に、前提条件を案件と製品に合わせて確認してください。[工種パック](topic:trade-packs) を参照してください。 |
| 工種パックの単価 | パックには複合単価だけが含まれます。単価は自分で設定するか、単価表を CSV としてインポートしてください。 |
| 拾い出しの名前の変更 | 名前は最初の PDF から付けられます。ダウンロードしたファイルの名前を変更してください。 |
| シートの手動での名前付け | シートの名前は PDF のページラベルから付けられます。ファイル名とページで検索してください。 |

## 図面（DWG と DXF）

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 図面のシートにある、プロットスタイルテーブル、ペンの割り当て、CTB ファイル | 図面は黒で描かれ、用紙向けに色が暗くなります。線の太さは図面の設定に従います。 |
| バイナリ DXF、または AutoCAD 2000 より古い DWG を開くこと | ASCII DXF または新しい DWG として保存してください。 |
| フォルダーの場所による外部参照（xref）の図面の検索 | リンクされた図面のファイルも、親の図面と一緒に開いてください。開いているファイルの中からファイル名で見つけられます。 |
| 3D ポリライン、メッシュ、ソリッド、領域の計測 | レイヤーと種類ごとに数えるか、平面図を長さツールと面積ツールで計測してください。 |
| ラテン文字以外の文字を含む図面の、印付き PDF のテキスト | Helvetica に字形がない文字は、印付き PDF では「?」と印刷されます。画面上の図面には影響しません。 |
| シートバーからの、別のアプリへの図面の引き渡し | 同じファイルをそのアプリで開いてください。 |
| {{ui:PDF with the takeoff inside}} のように、PDF と同様に拾い出しを内部に含む図面 | {{ui:Save takeoff}}: `.takeoff.json` は同じ図面で再び開け、内容によって図面が見つけられます。 |
| 図面に配置された PDF の下敷き、画像、OLE オブジェクトの計測または数量拾い出し | 画像は枠だけで表示されます。下敷きの PDF をシートとして直接開いてください。 |

## 自動カウント

## ファイルと共有

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| マークを表示し、拾い出しも含む 1 つの PDF | マークを確認してもらうには {{ui:Marked PDF}}、TakeoffCraft で再び開くには {{ui:PDF with the takeoff inside}} を使ってください。 |

| TakeoffCraft の専用デスクトップアプリ | バージョン 0.5 からのデスクトップアプリは CadCraft Studio で、8 つのアプリすべてを 1 回のインストールで使えます。TakeoffCraft はブラウザーでも動作します。 |

## 3D 表示

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 3D でのマークの作成と編集 | シートに戻って（{{key:3}}）描いてください。3D でも選択と削除は使えます。 |
| ページ上の異なる位置に描かれた階の位置合わせ | 同じ位置に描かれた階を積み上げてください。ほかは 1 枚ずつ確認してください。 |
| 数える対象と同じ大きさの支柱のカウント | シート上のすべての支柱は同じ大きさです。支柱は数える位置を示すもので、対象そのものではありません。 |

## 入札

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 送付済みのパッケージへの追加書類、落札通知、各入札者が承認する工事範囲シート | 新しいパッケージを送付し、落札は自分で通知してください。[入札用パッケージを送る](topic:bid-invitations) に、対応している内容を記載しています。 |
| どのアカウントからも入札の招待を送ること。テスト中は、CadCraft チームが有効にしたアカウントを除き、外部の入札者へのメールは無効です。 | {{ui:Scope CSV}} をダウンロードし、自分でメールで送って、入札額を入力してください。 |
| Studio のウィンドウからの入札用パッケージの送付 | ブラウザー版の TakeoffCraft から送ってください。 |
| 選んだ入札での代替案の入札範囲の再単価設定 | 代替案と入札範囲の小計は、自分の単価を使います。代替案は手で調整してください。 |
| 下請業者の保険またはライセンスの期限が切れる前の自動通知 | 期限が過ぎたか、30 日以内の場合は、下請業者のページに日付が表示されます。招待するときに確認してください。 |

## 表計算

XLSX ワークブックは LibreOffice Calc で確認され、すべての合計が TakeoffCraft と 1セント単位まで一致しました。Excel ではまだ開いて確認していません。表計算アプリで予期しない表示があれば、CSV の書き出しには同じ見積が単純な値として含まれています。

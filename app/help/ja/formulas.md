複合単価の内訳は、数式から数量を得ます。数式は、項目の計測値に対する小さな算術式です。作業例は[複合単価と数式](topic:assemblies)を参照してください。

## 変数

| 項目の種類 | 変数 | 意味 |
|---|---|---|
| 長さ | `L` | 合計の長さ |
| 長さ | `H` | 項目の高さ |
| 長さ | `A` | 壁面積（L × H）から、開口を持つ区間の開口を差し引いたもの（BimCraftの拾い出し）。拾い出しに計測方法が指定されている場合、`A` はその方法で計測されます。方法の最小サイズ以下の開口は含まれ、壁が交わる部分で拾い出し方法が除外する分は除かれます。項目の下の注記に方法名が示されます。 |
| 長さ | `N` | 区間の数 |
| 面積 | `A` | 正味面積の合計（輪郭から切り抜きを差し引いたもの） |
| 面積 | `P` | 切り抜きの辺を含む周長の合計 |
| 面積 | `H` | 項目の厚さ |
| 面積 | `N` | 面積の数 |
| 個数 | `N` | 個数 |

- 変数は項目の単位で表されます。[単位](topic:units)を参照してください。
- 大文字と小文字は区別されません: `l` は `L` と同じです。
- 項目自身の種類の変数だけが使えます。長さの項目で `P` を使うと、「"P" はここでは計測値ではありません。L、H、A、N を使用してください。」というエラーになります。
- 高さまたは厚さが空の場合は0です。

## 演算子

| 書き方 | 意味 |
|---|---|
| `+` | 加算 |
| `-` または `−` | 減算、または負の値 |
| `*` または `×` | 乗算 |
| `/` または `÷` | 除算 |
| `( )` | グループ化 |

乗算と除算は、加算と減算より先に計算されます: `L * 2 + 4` は (L × 2) + 4 です。迷ったら括弧を使ってください。

数値には小数（`1.333`、`.5`）と指数（`1e3` = 1000）を使えます。空白は無視されます。

## 関数

| 関数 | 結果 | 例 |
|---|---|---|
| `ceil(x)` | 整数へ切り上げ | `ceil(67.5)` = 68 |
| `floor(x)` | 整数へ切り捨て | `floor(67.5)` = 67 |
| `round(x)` | 最も近い整数へ丸め（0から遠ざかる方向に半分を丸める） | `round(2.5)` = 3 |
| `round(x, d)` | 小数点以下 d 桁へ丸め（0から10） | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | 最も小さい値 | `min(N, 10)` |
| `max(a, b, …)` | 最も大きい値 | `max(1, ceil(N / 12))` |
| `abs(x)` | 符号を除いた値 | `abs(-3)` = 3 |

`ceil` と `floor` はコンピューターの微小な丸め誤差を無視するため、ちょうど1になるべき値が2に切り上げられることはありません。

## エラー

読み取れない、または計算できない数式は、欄の下にそのエラーを表示し、その内訳は合計から除外されます（{{ui:数量}}の見出しに「未完了」と表示されます）。メッセージ:

| メッセージ | 対処 |
|---|---|
| 数式を入力してください。例: L または ceil(L / 1.333) + 1。 | 数式が空です。 |
| "X" はここでは計測値ではありません。…を使用してください。 | 一覧にある変数のいずれかを使ってください。 |
| "X" はここでは関数ではありません。ceil、floor、round、min、max、abs を使用してください。 | これらの関数のいずれかを使ってください。 |
| "#" は数式で使用できません。 | その文字を削除してください（単位、`%`、`$`、`=` は使用できません）。 |
| ")" が不足しています。 / "(" のない ")" があります。 | 括弧の数を揃えてください。 |
| ")" の前に値がありません。 | `max(1, )` のような場合です。値を入力してください。 |
| 数式が早く終わりすぎています。 | `L *` のような場合です。数式を完成させてください。 |
| 予期しない "…" です。演算子が抜けていませんか？ | `2L` のように2つの値が並ぶ場合です。`2 * L` と書いてください。 |
| ceil() は値を1つ取ります。 | 関数に正しい数の値を渡してください。 |
| round(x, digits) には、0から10までの整数の桁数が必要です。 | 小数点以下の桁数を整数で指定してください。 |
| 数式が0で除算しています。 | 通常、H が0です。項目の高さまたは厚さを設定してください。 |
| 数式は数値になりません。 | 結果が大きすぎて数値として扱えません。 |
| この数式は長すぎます（最大500文字）。 | 短くしてください。 |

## 設計上の安全性

数式は、上記の変数と関数を使った算術計算しかできません。コードを実行したり、他の何かを読み取ったりすることはできないため、誰かから送られてきた案件ファイルの数式も無害です。

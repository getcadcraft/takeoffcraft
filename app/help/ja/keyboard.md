ポインターがページ上のどこにあっても、欄に入力していなければ文字キーが機能します。ダイアログが開いている間は、そのダイアログ自身のキーが使われます。文字キーは{{key:Shift}}を押しても押さなくても機能します。

| キー | ツール |
|---|---|
| {{key:V}} | {{ui:選択}} |
| {{key:L}} | {{ui:長さ}} |
| {{key:A}} | {{ui:面積}} |
| {{key:O}} | {{ui:円}} |
| {{key:B}} | {{ui:部屋}} (1 クリックで部屋を塗りつぶします) |
| {{key:R}} | {{ui:円弧}} のオン/オフ ({{ui:長さ}}、{{ui:面積}}、{{ui:開口}} で) |
| {{key:E}} | {{ui:控除}} のオン/オフ: 連続線の次の区間は描画されますが、数えられません |
| 描画中に数字、`@`、`#` | {{ui:入力}} ボックスを開きます。長さまたは座標を入力し、{{key:Enter}} で点を配置します ([長さの連続線を計測](topic:measure-linear#type-lengths-and-coordinates)) |
| {{key:X}} | {{ui:開口}} (先に面積を選択します) |

## 描画中

| キーまたは操作 | 動作 |
|---|---|
| クリック | 点を配置します (個数の場合は点になります)。 |
| {{key:P}} | パス: PDF の線の連続した経路全体、またはクリック位置の周囲の輪郭を選択します ([PDF の線を選択](topic:pick-the-lines))。 |
| {{key:F3}} | 図面の線へのスナップのオン/オフ ([図面の線にスナップ](topic:snap-to-the-drawing))。 |
| クリック中に {{key:Shift}} を押す | 直前の点から見て、区間を 0°、45°、90°、135° にスナップします。円弧の点や円には使えません。 |
| ダブルクリック | 連続線を完了するか、面積または開口を閉じます。 |
| {{key:Enter}} | 連続線を完了するか、面積または開口を閉じます。 |
| 右クリック (動かさずに) | 連続線を完了するか、面積または開口を閉じます。 |
| 最初の点をクリック | 面積または開口を閉じます (3 点目以降)。 |
| {{key:Backspace}} または {{key:Delete}} | 最後の点を削除します (未確定の円弧の点が先に削除されます)。 |
| {{key:Esc}} | 未確定の円弧の点を取り消し、次に未完成のマークを取り消し、最後に {{ui:選択}} に戻ります。 |

## 選択と編集

| キーまたは操作 | 動作 |
|---|---|
| マークをクリック ({{ui:選択}} ツール) | マークを選択し、その項目を現在の項目にします。 |
| {{key:Shift}} + マークをクリック | 選択に追加するか、選択から外します。 |
| {{key:Mod+A}} | 開いているシート上のすべてのマークを選択します。 |
| 角のハンドルをドラッグ | その点を移動します ({{key:Shift}} で 45° にスナップ)。マークを 1 つ選択しているときに使えます。 |
| {{key:Delete}} または {{key:Backspace}} | 選択したマークを削除します (描画中でないとき)。 |
| {{key:Esc}} | 選択解除: 選択と確認線を消去します。 |
| {{key:Mod+Z}} | 元に戻す。 |
| {{key:Mod+Y}} または {{key:Mod+Shift+Z}} | やり直し。 |

## コピーと貼り付け

| キー | 動作 |
|---|---|
| {{key:Mod+C}} | 選択したマークを、その項目とともにコピーします。 |
| {{key:Mod+X}} | 切り取り: 選択したマークをコピーしてから削除します。 |
| {{key:Mod+V}} | 貼り付け: コピーはポインターに追従します。配置場所をクリックします。 |
| {{key:Mod+Shift+V}} | 同じ位置に貼り付け: 開いているシートの同じ位置に貼り付けます。 |
| {{key:Mod+D}} | 複製: 選択したマークを複製します。コピーはポインターに追従します。配置場所をクリックします。 |
| {{key:Esc}} | 何も置かない: ポインターに付いている貼り付けまたは複製を取り消します。 |

{{key:C}}は{{ui:個数}}、{{key:D}}は{{ui:確認}}、{{key:X}}は{{ui:開口}}、{{key:V}}は{{ui:選択}}、{{key:A}}は{{ui:面積}}のように、文字キーだけでもツールを選べます。{{key:Mod}}と組み合わせた場合のみ、コピーと貼り付けになります。テキスト欄では、これらのキーは通常どおりテキストをコピーおよび貼り付けします。[マークのコピー、貼り付け、複製](topic:copy-paste) を参照してください。

:::warning
描画中でないときは、{{key:Backspace}} で選択したマークが削除されます。誤って削除した場合は、{{key:Mod+Z}} で元に戻せます。
:::

| キーまたは操作 | 動作 |
|---|---|

| ドラッグ (左、中、右ボタン) | パンします。{{ui:自動カウント}} では、左ドラッグで代わりに検索ボックスを描きます。 |
| {{key:Space}} を押したままドラッグ | どのツールでもパンします。 |
| {{key:F}} | {{ui:ページに合わせる}} |
| {{key:W}} | {{ui:幅に合わせる}} |
| {{key:Plus}} または {{key:=}} | 表示の中央でズームインします。 |
| {{key:Minus}} | 表示の中央でズームアウトします。 |
| {{key:PageDown}} / {{key:PageUp}} | シート一覧の次または前のシートに移動します。 |
| {{key:Ctrl+Shift+F}} | 全画面表示モードを切り替えます (すべてのプラットフォームで Control。Mac でも同じです)。 |
| {{key:F1}} | このヘルプ (横のパネル) を開くか閉じます。 |
| {{key:3}} | シートの 3D 確認ビューのオン/オフ。 |

## 3D ビュー

| キーまたは操作 | 動作 |
|---|---|
| ドラッグ、または中ボタンでドラッグ | 軌道回転します。 |
| {{key:Shift}} + ドラッグ、または右ボタンでドラッグ | パンします。 |
| マウスホイール | ポインターの位置でズームします。トラックパッドでは、2 本指スワイプで軌道回転し、ピンチでズームします。 |
| クリック | ポインターの下のマークを選択します ({{key:Shift}} + クリックで追加または解除)。 |
| {{key:F}} または {{key:W}} | 範囲ズーム。 |
| {{key:3}} | 平面のシートに戻ります。 |

## 自動カウント

| キーまたは操作 | 動作 |
|---|---|
| ボックスをドラッグ | 検索するシンボルを囲みます (検索を開始します)。 |
| 一致ボックスをクリック | 除外するか、元に戻します。 |
| {{key:Esc}} | 実行中の検索をキャンセルするか、確認結果を破棄します。 |

## ヘルプ

| キー | 動作 |
|---|---|
| {{key:F1}} | ヘルプパネルを開くか閉じます (アプリバーの {{ui:ヘルプ}} ボタンでも同じです)。どのツールでも、欄に入力中でも機能します。 |
| {{key:Esc}} | ヘルプパネルを閉じます。その検索ボックスでは、最初の {{key:Esc}} で検索語を消去します。パネルを開いている間にシートをクリックしてから {{key:Esc}} を押すと、先にパネルが閉じます。もう一度押すと、TakeoffCraft でのキャンセルになります。 |

:::mac
多くの Mac キーボードでは、上段のキーで輝度と音量を調整します。fn を押しながら {{key:F1}} を押すか、「システム設定」の「キーボード」で「F1、F2 などのキーを標準のファンクションキーとして使用」をオンにしてください。
:::

## プラットフォームごとの注意

:::mac
- {{key:Mod}} は Command キーです: {{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。全画面表示は例外で、Control+Shift+F です。
- トラックパッドでの右クリックは 2 本指でのクリックです。ただし「システム設定」の「トラックパッド」で副ボタンのクリックをオンにしておく必要があります。TakeoffCraft は副ボタンのみを読み取ります。Control キーを押しながらのクリックは通常のクリックとして扱われ、点が追加されることがあります。
- トラックパッドで 2 本指スクロールすると、シートがズームします (スクロールはしません)。パンするには、ドラッグするか、{{key:Space}} を押したままドラッグします。
- Page Up と Page Down は、これらのキーがないキーボードでは、fn と上下の矢印キーの組み合わせです。
- {{key:Backspace}} は「delete」と表示されたキーです。
:::

:::windows
- {{key:Mod}} は Ctrl です: {{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。
- ノートパソコンのタッチパッドでは、2 本指スクロールでシートがズームします。パンするには、ドラッグします。
:::

:::linux
- {{key:Mod}} は Ctrl です。一部のデスクトップ環境では独自の Ctrl+Alt や Super のショートカットを使いますが、TakeoffCraft はそれらを一切使いません。
- タッチパッドでは、2 本指スクロールでシートがズームします。パンするには、ドラッグします。
:::

:::touch
TakeoffCraft はタッチを 1 つのポインターとして扱います:

- タップで点を配置、マークを選択、または個数の点を追加します。
- 1 本指でドラッグするとシートをパンします ({{ui:自動カウント}} では検索ボックスを描きます)。
- ピンチズームはまだ対応していません。{{ui:ページに合わせる}} と {{ui:幅に合わせる}} を使うか、キーボードで {{key:Plus}} と {{key:Minus}} を使ってください。
- 面積を閉じるには、最初の点をタップします。連続線を完了するには、ブラウザーがダブルタップをダブルクリックとして扱う場合はダブルタップするか、キーボードで {{key:Enter}} を押します。
- ホバーがないため、タップするまでリアルタイムの長さ表示はありません。

現時点では、拾い出しにはキーボードとマウスまたはトラックパッドを使う方法のほうが適しています。
:::

## ブラウザーが使うキー

ブラウザーの一部のショートカットは、ブラウザー自身が使うため、ページからは使えません。タブを閉じる ({{key:Mod+W}})、新しいタブまたはウィンドウ ({{key:Mod+T}}、{{key:Mod+N}})、ブラウザーのズーム ({{key:Mod+Plus}}、{{key:Mod+Minus}}) がこれにあたります。そのため、TakeoffCraft ではホイールと、単独の {{key:Plus}} および {{key:Minus}} キーでシートをズームします。誤って {{key:Mod+Plus}} を押すと、ページ全体が拡大されます。{{key:Mod+0}} で元に戻せます。詳しくは [キー、マウス、トラックパッド](common:keys) を参照してください。

## 移動コマンドの場所

移動コマンドはありません。個数の点を選択してドラッグするか、面積または線を選択して角のハンドルをドラッグしてください。

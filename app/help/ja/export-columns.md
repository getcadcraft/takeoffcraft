## 見積（XLSXワークシートとCSV）

項目ごとに1行、続いて項目の複合単価の内訳ごとに1行（字下げ）。次に空行と工事合計です。

| 列 | 内容 | XLSXでの形式 |
|---|---|---|
| A 項目 | 項目名（太字）または内訳名（字下げ） | テキスト |
| B 種類 | 長さ、面積、個数、または内訳 | テキスト |
| C 単位 | LF、m、SF、SY、m²、EA、または内訳の単位 | テキスト |
| D 数量 | 計測の合計、または数式の結果 | 数値 |
| E ロス率 | ロス | 割合（0.10 = 10%） |
| F ロス込み数量 | 数量 ×（1 + ロス） | 数式 `D*(1+E)` |
| G 材料単価 | 材料単価 | 数値 |
| H 労務単価 | 労務単価 | 数値 |
| I 材料費 | 材料の明細金額 | 数式 `ROUND(F*G,2)` |
| J 労務費 | 労務の明細金額 | 数式 `ROUND(F*H,2)` |
| K 合計 | 材料費 + 労務費 | 数式 `I+J` |
| L 備考 | 使用した数式、数式エラー、縮尺のないシート上のマーク、壁面積、周長 | テキスト |

工事合計の行は、上のすべての行の I、J、K 列の `SUM` です。何かが除外された場合は、備考に「未完了: 上の備考を参照」と書かれます。

数式エラーのある行には数量も金額もなく、その備考にエラーが示されます。見出し行は固定されています。

CSVでは、同じ列に単純な値が入ります。ロス率は割合の数値（10%なら10）で、金額はドル単位で小数点以下2桁です。スプレッドシートが数式と解釈しそうな文字列（`=`、`+`、`-`、`@` で始まるもの）には、先頭に `'` が付けられ、文字列のまま残ります。

## シート別（XLSXのみ）

| 列 | 内容 |
|---|---|
| シート | シート名（開いていない場合はPDF名を併記） |
| 項目 | 項目名 |
| 数量 | そのシートでの項目の数量（単位は項目の単位） |
| 単位 | 項目の単位 |
| マーク | マークの数 |

## マーク（XLSXのみ）

マークごとに1行。

| 列 | 内容 |
|---|---|
| シート | シート名 |
| 項目 | 項目名 |
| 種類 | 長さ、面積、または個数 |
| 数量 | 長さ、正味面積、または1 |
| 単位 | LFまたはm; SF、SYまたはm²; EA |
| 詳細 | 長さ: 各区間の長さ。控除されたものは「(控除)」と表示され、「描かれた(長さ)のうち(長さ)を控除」。面積: 開口がある場合は総面積と開口面積、および周長。縮尺のないマークは「シートに縮尺がありません」。 |
| 入札範囲 | 拾い出しに入札範囲がある場合のみ: マークの面積、または「入札範囲なし」 |

## 入札範囲別（XLSXのみ。拾い出しに入札範囲がある場合）

| 列 | 内容 |
|---|---|
| 入札範囲 | 範囲の名前、または「入札範囲なし」 |
| 項目 | 項目、またはその下に字下げされた内訳 |
| 単位 | 項目または内訳の単位 |
| 数量 | その範囲での計測値（内訳: 範囲の合計に対する数式） |
| ロス込み数量 | 数量 ×（1 + ロス） |
| 材料費、労務費、合計 | 見積と同様に、セント単位まで計算 |
| 備考 | 見積と同様の数式、エラー、縮尺のないマーク |

各範囲は「（名前）小計」行で終わり、その費用は行にわたる `SUM` 数式です。最後の行の**すべての入札範囲**が小計を合計します。その後、**マーク**ワークシートには7列目の**入札範囲**が加わります。

## 縮尺（XLSXのみ）

縮尺またはマークのあるシートごとに1行。

| 列 | 内容 |
|---|---|
| シート | シート名 |
| 縮尺 | プリセット名、校正された縮尺、または「縮尺なし」 |
| 方法 | 「プリセット」、または「入力した距離で校正」 |
| PDF単位あたりのフィート | TakeoffCraftが使用する正確な縮尺係数 |

## ファイル名

- `(name).xlsx` と `(name).csv`。名前は、拾い出しで最初に開いたPDFから取られます。
- CSVはUTF-8（バイトオーダーマーク付き）でWindows形式の改行コードです。どのプラットフォームのスプレッドシートプログラムでも読めます。

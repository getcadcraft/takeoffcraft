## 長さ

{{ui:校正}}の**実距離**、および項目エディターの{{ui:高さ}}と{{ui:厚さ}}で使われます。

| 入力内容 | 意味 |
|---|---|
| `24'-0"` | 24フィート |
| `24'-6 1/2"` | 24フィート6½インチ |
| `12' 6 1/2"` | 12フィート6½インチ（ダッシュの代わりにスペース） |
| `12'-6-1/2"` | 12フィート6½インチ（各部分の間にダッシュ） |
| `24'` | 24フィート |
| `30"` | 30インチ |
| `6 1/2"` | 6½インチ |
| `3/4"` | ¾インチ |
| `24 ft 6 in` | 24フィート6インチ（`foot`、`feet`、`inch`、`inches` も使用可） |
| `24.5` | 24.5（下記の既定の単位） |
| `24.5'` | 24.5フィート |
| `7.5 m` | 7.5メートル |
| `750 cm` | 750センチメートル |
| `7500 mm` | 7,500ミリメートル |

- 単なる数値は、校正とLF、SF、SYの項目では**フィート**、m、m²の項目では**メートル**として扱われます。
- ワープロの曲線引用符や prime 記号（′ ″ ’ ”）は、`'` と `"` と同じように扱われます。二つのアポストロフィ `''` は `"` として扱われます。
- カンマは無視されます: `1,200 mm` は1200 mmです。
- 分数は両側に整数が必要です: `6 1/2"` は使えますが、`6.5 1/2"` は使えません。
- ゼロと負の距離は受け付けられません。

メッセージ:

- 「距離を入力してください。例: 24'-0" または 7.5 m」（欄が空のとき）
- 「0より大きい距離を入力してください。」
- 「フィートとインチ (24'-6 1/2")、小数のフィート、m、cm、mm のいずれかを使用してください。」（単位が不明なとき）
- 「この距離は読み取れませんでした。24'-6 1/2" または 24.5 を試してください。」

項目の高さや厚さを消去するには、欄を空にします。

### 計算

長さの欄のすべてと、作図中の入力ボックスでも、`+`、`-`、`*`、`/` と括弧を使った計算ができます:
`4+7/16`（既定の単位で4.4375）、`12'6" + 3/4"`、`(24'-0")/3`（8フィート）、`2*450mm`。

- 長さに書かれたダッシュは、長さの一部として扱われます: `24'-6"` は24フィート6インチで、`6-1/2` は6½です。引き算には、ダッシュの前後にスペースを入れてください: `24' - 6"` は23'-6"です。
- 単なる数値は、長さに対して数値として掛けたり割ったりします。長さに足す場合は、既定の単位として扱われます。
- `abs`、`round`、`ceil`、`floor` も使えます。読み取れない計算は、どこで誤りがあったかを示して拒否されます。

## 長さの表示方法

長さは、フィート、インチ、16分の1インチで表示されます: `12'-6 1/2"`、`0'-0 3/4"`。表示のために値は最も近い1/16インチに丸められますが、数量自体は丸められません。小数の値は小数点以下2桁で、桁区切り付きで表示されます（例: `1,234.50 LF`）。

## 単価（材料と労務の単位あたり）

| 入力内容 | 意味 |
|---|---|
| `12.5` | $12.50 |
| `$12.50` | $12.50 |
| `1,250` | $1,250.00 |
| `0.385` | $0.385（小数点以下4桁まで。それ以上は丸められます） |
| （空） | $0 |

メッセージ: 「12.50 のような金額を入力してください。」または「この金額は大きすぎます。」マイナスの単価は受け付けられません。

明細の金額（材料、労務、合計）は、セント単位まで計算されます。ロス込みの数量 × 単価を、0から遠ざかる方向に四捨五入します。これはスプレッドシートの `ROUND(x, 2)` とまったく同じです。

## ロス率

| 入力内容 | 意味 |
|---|---|
| `10` | 10% |
| `7.5%` | 7.5% |
| （空） | 0% |

小数点以下2桁まで、0%から1000%まで入力できます。メッセージ: 「10 や 7.5 のような割合を入力してください。」または「1000%を超えるロスは使用できません。」

## 名前と単位

- 項目と内訳の名前: 200文字まで。
- 内訳の{{ui:単位}}: 20文字までの任意の文字列（例: `EA`、`sheets`、`CY`、`gal`）。ラベルだけで、TakeoffCraftは換算しません。

## 数式

複合単価の数式には独自の規則があります。[数式の言語](topic:formulas)を参照してください。

図面一式は、建築、構造、機械などの複数の PDF で構成されることが多くあります。TakeoffCraft はそれらを並べて 1 つのシート一覧として開き、1 つの拾い出しですべてを対象にできます。

## PDF を開く

1. {{ui:File}}グループの{{ui:Open plans}}を選ぶか、{{key:Mod+O}} を押します。（ほかのメニュースタイルでは {{ui:Open PDFs…}} と呼ばれます。）
2. ファイルダイアログで、図面一式のすべての PDF を選択します。複数選択するには{{pick:mac=Command|windows=Ctrl|linux=Ctrl}}を押したまま選び、範囲を選ぶには{{key:Shift}}を押したまま選びます。
3. 「開く」を選びます。
   各ファイルの読み込み中は「(name) を開いています…」というメッセージが表示されます。その後、すべてのページが{{ui:Sheets}}の下に表示され、新しく追加された最初の PDF の最初のページが開きます。

PDF は、{{pick:mac=Finder|windows=エクスプローラー|linux=ファイルマネージャー}}からドラッグして、TakeoffCraft のどこにでもドロップできます。ドラッグ中には「PDF、DWG、DXF の図面、または .takeoff.json をドロップ」という枠が表示されます。

後から PDF を追加するには、同じ操作を繰り返します。すでに開いている PDF はスキップされます。

開始画面には、最近開いた PDF と拾い出しも表示されます。ただし、ページがファイルを再び開けるブラウザー（Chrome と Edge）の場合に限ります。項目をクリックして開きます。ブラウザーが先に許可を求めることがあります。[お使いのファイル](common:your-files) を参照してください。

:::note
ファイルはアップロードされません。ブラウザーがお使いのコンピューター上の PDF を読み込みます。タブを閉じるか、{{ui:New}} を選ぶと、PDF は TakeoffCraft から削除されます。
:::

## PDF と並べて開く図面

{{ui:Open plans}} は、DWG と DXF の図面も、単独でも PDF と一緒にでも開けます。各図面のモデル空間とレイアウトが、同じ一覧のシートになります。[DWG または DXF の図面を開く](topic:open-a-drawing) を参照し、続いて [図面から拾い出す](topic:count-from-a-drawing) を参照してください。

## 別のアプリから引き渡された PDF

製品群の別のアプリは、開いている PDF を引き渡すことができます。その場合、TakeoffCraft が新しいタブで開き、ドロップしたかのように PDF が開きます。ステータスバーには「(name) を開きました。引き渡し元: (app)。元のファイルは変更されていません。」と表示されます。アップロードはされません。ファイルはこのブラウザーの保存領域を経由し、開いた後は削除されます。

ステータスバーに PDF が「届きませんでした」と表示された場合は、タブが長く待ちすぎたか、その PDF が別のタブですでに開かれています。{{ui:Open plans}} で開いてください。

逆方向として、MarkupCraft が同じ場所で動作しファイルを受け取れる場合、図面の下のシートバーに {{ui:MarkupCraft}} ボタンがあります。画面上のシートの PDF を、新しいタブの MarkupCraft で開き、確認やマークアップができます。

## シートを探す

- 左側の {{ui:Sheets}} 一覧をスクロールし、シートをクリックします。
- 一覧の上部にある **シートを検索** に入力すると、シート番号、ファイル名、ページラベルで絞り込めます。{{ui:Sheets}} の横の数字には、フィルターが有効な間「3 of 40」のように表示されます。
- 次のシートへは {{key:PageDown}}、前のシートへは {{key:PageUp}} を押します。これらは絞り込まれた一覧に従って移動します。

:::mac
Page Up と Page Down のキーがない Mac のキーボードでは、fn を押しながら上または下の矢印キーを押します。
:::

## シートの名前の付け方

- PDF がラベル（例: `A-101`）を付けたページは、そのラベルで名前が付けられます。
- ラベルのないページ（またはページ番号だけのラベル）は、「(ファイル名), page (n)」と名付けられます。
- 複数の PDF を開いている場合、ラベル付きのシートにはファイル名も付きます:「A-101 — Architectural」。

シート名は、まだ手入力できません。

## シートの見方

- マウスホイールを回すと、ポインターの位置を中心にズームします。
- 左ボタンまたは中ボタンでドラッグするとパンします。{{ui:Auto count}} を使っているとき、またはマークの角から始めたときは、{{key:Space}} を押しながらドラッグするか、中ボタンでドラッグします。
- {{key:F}} を押すか {{ui:Fit page}} を選ぶと、シート全体が表示されます。{{key:W}} または {{ui:Fit width}} で幅に合わせます。
- {{key:Plus}} または {{key:=}} で拡大、{{key:Minus}} で縮小します。表示の中央を基準にします。

各シートは、開いている間、自分のズームと位置を記憶します。

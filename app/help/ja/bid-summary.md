見積は拾い出した内容に価格を付けたものです。**入札概要**はそれを入札価格に変えます。売上税、一般管理費、利益、保証料を加え、含む事項と除外事項を記した**提案書 PDF** を作成します。

{{ui:Export}} › {{ui:Bid summary & proposal…}} から開きます。すべての内容は拾い出しと一緒に保存され、各変更は取り消せます。

## マークアップ

5つのうちいずれかに割合（%）を入力します（他は 0 のままにします）。次の順序で計算され、それぞれ上の行の値に対して計算されます:

| 行 | 計算方法 |
|---|---|
| 材料、労務 | 見積の合計（拾い出しに [代替案](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) がある場合は基本入札）。 |
| 労務諸経費 | 諸経費 % × 労務: 作業員の賃金にかかる社会保険料、保険、福利厚生。 |
| **原価** | 材料 + 労務 + 労務諸経費。 |
| 材料の売上税 | 税 % × 材料。 |
| 一般管理費 | 一般管理費 % ×（原価 + 税）。 |
| 利益 | 利益 % ×（原価 + 税 + 一般管理費）。 |
| 保証料 | 保証料 % × 上記のすべて。 |
| **入札額** | 各行の合計。 |

各行は1セント単位に丸められます。作業ブックでは、見積シートの合計の下に同じ行がライブの数式で表示されます。概要は入力に合わせて更新されます: {{key:Enter}} で割合を確定します。各代替案は、その原価に対して同じマークアップで表示されるため、発注者は、採用または除外したときに実際に何が変わるかを確認できます。

## 提案書

提案書に記載する内容を入力します:

- **プロジェクト**（空の場合は拾い出しの名前）、**宛先**（発注者）、**差出人**（自社）。
- **含む事項**と**除外事項**: 1行に1項目。先頭のダッシュや箇条書き記号も使えます。
- **条件**: 自由記述です。例:「見積の有効期限は30日間。」
- **項目と数量を一覧にする**: 工事範囲を項目ごとに、数量を付け、価格は付けずに記載します。一式見積にする場合はチェックを外してください。

{{ui:Proposal PDF}} を選びます。PDF（ファイル名 `<takeoff> - proposal.pdf`）には、日付、各マークアップと入札額を含む価格ブロック、代替案、工事範囲、含む事項と除外事項、条件、署名と日付の欄が含まれます。測定できなかった数量がある場合（縮尺のないシートなど）は、価格の下にその旨が記載されます。

## 書き出し時

拾い出しに入札概要がある場合、CSV の末尾に入札概要が追加され、作業ブックには **入札概要** シートが追加されます。各行、その割合、金額が表示されます。[見積の書き出し](topic:export-estimate) を参照してください。

ウィンドウ下部の{{ui:数量}}表は、リアルタイムの見積です。マークを描いたり、削除したり、縮尺を変えたり、単価を編集したりすると、すぐに更新されます。数量は保存されません。毎回マークから計測し直されるため、古くなることはありません。

## 項目別

{{ui:項目別}}を選びます (既定)。項目ごとに1行あり、そのアセンブリの各構成要素はその下に1行ずつ表示されます。

| 列 | 意味 |
|---|---|
| 項目 | 名前 (項目の色付き)。「+(n) 縮尺なし」は、縮尺のないシートにあるマークがあることを示します。 |
| 数量 | 項目の単位での計測の合計 (構成要素: 数式の結果) |
| 単位 | LF, m, SF, SY, m², EA, または構成要素の単位 |
| ロス % | ここに入力するか、項目エディターで入力します。 |
| ロス込み | 数量 × (1 + ロス) |
| 材料/単位, 労務/単位 | 単価。ここに直接入力できます。 |
| 材料, 労務 | ロス込み × 単価。セント単位で四捨五入します。 |
| 合計 | 材料 + 労務 |

最後の行の**総合計**は、材料、労務、合計の各列を加算します。同じ合計が表のヘッダーの右側にも表示されます。

ロスまたは単価のセルに入力し、{{key:Enter}}を押すか、ほかの場所をクリックして適用します。TakeoffCraftが読み取れない値は赤い枠で囲まれ、ステータスバーに理由が表示されます (例: "12.50のような金額を入力してください。")。

項目の行をクリックすると、すべてのシート上でその項目のマークがハイライトされ、マークがあるシートへ移動します ({{ui:項目}}の下でクリックした場合と同じです)。

## シート別

{{ui:シート別}}を選ぶと、各項目のシートごとの数量とマーク数が表示されます。行をクリックすると、その項目がハイライトされた状態でシートが開きます。すべてのシートを拾い出したかの確認や、階または作業範囲ごとに数量を分けるときに使います。

## 入札範囲別

拾い出しに入札範囲がある場合、{{ui:入札範囲別}}には各範囲の項目と小計が表示されます。[入札範囲](topic:bid-areas)を参照してください。

## 不完全の警告

合計から除外されているものがあると、ヘッダーに警告が表示されます。例:

"不完全: 数式エラー 1件、縮尺のないシート上のマーク 6件 (合計に含まれません)"

- **数式エラー**: アセンブリの構成要素の数式を計算できません。その行には "数式エラー: …" と表示されます。[アセンブリと数式](topic:assemblies#when-a-formula-is-wrong)を参照してください。
- **縮尺のないシート上のマーク**: それらのシートに縮尺を設定してください。[縮尺を設定](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero)を参照してください。

同じ注記は書き出したスプレッドシートにも含まれるため、不完全な見積が完成しているように見えることはありません。

## 項目をハイライトする

{{ui:項目}}の下、または表の項目をクリックします。その項目のマークはすべてのシートで濃い色のまま残り、ほかは薄くなります。シート一覧には、マークがあるシートごとに "(n) ハイライト中" と表示されます。もう一度項目をクリックすると、ハイライトが解除されます。

## サイドパネルの項目合計

{{ui:項目}}一覧の各項目にも数量が表示されます。項目エディターの**計測値**欄には、その数式が使う値が表示されます。長さ、区間数、壁面積、面積、周長、エリア数、個数のいずれかです。

## 開いていないPDFのマーク

拾い出しには、今回開いていないPDFのマークを含めることができます。それらのマークも、すべての合計に含まれます。シート一覧にはそのPDFの名前が表示されます。[拾い出しの保存と再度開く](topic:save-and-reopen)を参照してください。

## 表示領域を広げる

{{ui:数量}}ヘッダーの右端にある矢印ボタンを押すと、表が隠れてシートの表示領域が広がります。もう一度押すと、表が戻ります。

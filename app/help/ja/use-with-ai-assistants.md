## 学習内容

AIアシスタント（または自作のスクリプト）にTakeoffCraftを扱わせる方法と、アシスタントが変更できる範囲を決める方法を説明します。

TakeoffCraftには**独自のAIはなく**、どこにも何も送信しません。アシスタントは別途用意します。Model Context Protocol（MCP）に対応したプログラムであれば何でも使えます。TakeoffCraftが提供するのはツールだけで、どのツールを渡すかはご自身で選びます。

## 有効にする

1. {{ui:設定}}（アプリバーの歯車、または{{key:Mod+,}}）を開き、{{ui:TakeoffCraft}}タブに移動します。
2. {{ui:アシスタント}}で**AIアシスタントとスクリプトによるTakeoffCraftの使用を許可**にチェックを付けます。チェックを付けるまでは無効のままです。
3. アシスタントに許可する操作を選びます。**読み取り**は最初からチェックが付いています。**編集**、**保存**、**書き出し**は必要なときだけチェックを付けます。

チェックを付けていない権限のツールは、アシスタントに提示されません。それでもアシスタントが要求した場合、TakeoffCraftはその要求を拒否し、アクティビティログに記録します。スイッチをオフにすると、すべての接続が直ちに終了します。{{ui:TakeoffCraftの設定をリセット}}を使うと、スイッチもオフになります。

## アシスタントを接続する

アシスタントは、お使いのコンピューター上の**CadCraft Studio**を通じて接続します。Studioは、このコンピューターからのみ到達できる小さなサーバーを起動します。このサーバーは、Studioの起動ごとに作成されるトークンで保護されます。Studioで{{ui:アシスタントを接続}}を選び、アドレスとトークンをアシスタントにコピーします（貼り付けに必要な正確な設定はStudioに表示されます）。トークンは決して共有しないでください。

:::note
ブラウザーのタブからアシスタントの接続を開くことはできません。ブラウザー版のアプリでは、お使いのコンピューターでCadCraft Studioを使うまで、スイッチは効果がありません。
:::

## 主導権はいつも手元にあります

- **変更はすべて元に戻す操作1回分になり**、アシスタントの名前付きで表示されます（例: 「アシスタント: …」）。{{key:Mod+Z}}を押すと、アシスタントによる直前の変更がまとめて取り消されます。
- **接続中かどうかがわかります。** 接続されている間、アプリバーのボタンにアシスタントの名前が表示されます。そのボタンをクリックすると、アシスタントに許可されている操作を確認したり、**切断**したりできます。
- **アクティビティ。** {{ui:設定}} › {{ui:TakeoffCraft}} › {{ui:アシスタント}} › {{ui:アクティビティ}}には、すべての呼び出しが、いつ、どのツールか、実行されたか拒否されたかとともに一覧表示されます。{{ui:ログを保存}}で、ログのコピーを保存できます。

## アシスタントが要求できる内容

| ツール | 権限 | 内容 |
|---|---|---|
| `app_info`, `sheets_list` | 読み取り | 開いている拾い出し、そのPDFとシート、各シートの縮尺とマーク |
| `items_list` | 読み取り | 単位、単価、複合単価の計算式を含む項目 |
| `takeoff_quantities` | 読み取り | 項目ごとまたはシートごとの数量。縮尺のないシート上のマークは一覧に表示され、ゼロとして集計されることはありません |
| `takeoff_estimate` | 読み取り | TakeoffCraftが計算した単価付きの見積と合計 |
| `takeoff_export` | 書き出し | TakeoffCraft独自のCSVまたはXLSXの書き出し |
| `items_add` | 編集 | 単位、単価、ロス（割増）を指定して項目を追加します |
| `marks_add` | 編集 | シート上で連続線、面積、個数を計測します。長さと面積は縮尺のあるシートでのみ計測し、縮尺のないシートでは計測しません |
| `cad_sheets`, `cad_catalog`, `cad_count` | 読み取り | 開いているDWGまたはDXFについて、そのシートと縮尺、数えられるもの（ブロック、レイヤーと種類、文字）、および{{ui:CAD数量}}で得られる正確な数量（[図面から数える](topic:count-from-a-drawing)） |
| `cad_count_add` | 編集 | 図面内で数え、見つかったオブジェクトごとに個数マークを一度に付けます。再度数えると、新しく見つかったものだけが追加されます |
| `cad_measure` | 編集 | {{ui:図面計測}}と同様に、図面自体の線、円弧、ポリライン、ハッチングから長さまたは面積の項目を計測します（[図面から計測する](topic:measure-from-a-drawing)）。縮尺のあるシートでのみ実行されます |
| `usd_export` | 書き出し | 縮尺のあるシートの計測した連続線、面積、個数を、USD（`.usdz`、`.usda`、`.usdc`）の3D確認モデルとして書き出します。3D確認ビューの{{ui:USD パッケージ（.usdz）}}と同じ形式です（[3D確認ビューをUSDとして書き出す](topic:usd)） |

**編集**にチェックを付けると、アシスタントは項目とマークを追加できます（呼び出しごとに元に戻す操作1回分になります）。既にあるマークを移動、変更、削除することはできません。

TakeoffCraftを開かなくても、同じ数量と見積を利用できます。CadCraft MCPサーバーは、指定したフォルダー内の`.takeoff.json`ファイルを開きます（`takeoff_open`、`takeoff_quantities`、`takeoff_estimate`、`takeoff_export`）。`cadcraft info Job.takeoff.json`を実行すると、コマンドラインに表示されます。また、DWGまたはDXFを新しい拾い出しとしてそのシート上で開き（TakeoffCraftと同じ方法で図面から縮尺を設定）、同じ`cad_*`ツールで数えて計測し、項目を追加して拾い出しを保存（`takeoff_save`）できます。`cadcraft count plan.dwg --block SHELF-18X48 --sheet K-101`を実行すると、コマンドラインから数えられます。

## うまくいかないとき

- **アシスタントにTakeoffCraftのツールが表示されない:** このウィンドウでスイッチがオンになっていること、およびこのウィンドウがStudioで開かれていることを確認してください。
- **「書き出しの権限が必要です」:** {{ui:アシスタント}}で**書き出し**にチェックを付けてから、もう一度依頼してください。
- **「401」または「token」のエラー:** トークンが変わっています（Studioを再起動したか、{{ui:新しいトークン}}を使った場合）。新しいトークンをアシスタントの設定にコピーしてください。

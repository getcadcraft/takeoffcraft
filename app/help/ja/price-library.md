**単価ライブラリ**には、案件ごとに繰り返し使う項目を保存します。項目の種類、単位、高さ、割増、材料費と労務費の単価、複合単価が含まれます。拾い出しとは別にこのブラウザーに保存されるため、ここで開くすべての拾い出しで使えます。

{{ui:Items}} パネルの上部にある {{ui:Library}} で開きます。

## ライブラリに項目を入れる

- {{ui:CSVをインポート…}} は、CSV として保存された表計算ファイルを読み込みます（下の列を参照）。名前と種類がライブラリにすでにある項目は置き換えられ、それ以外は追加されます。読み取れない行はスキップされ、どの行がなぜスキップされたかを表示します。
- {{ui:この拾い出しの項目を追加}} は、開いている拾い出しのすべての項目を、単価と複合単価とともにライブラリにコピーします（マークはコピーしません）。
- TakeoffCraft が書き出す見積の CSV（[見積を書き出す](topic:export-estimate)）は、そのままインポートできます。前回の案件の単価が、次の案件の出発点になります。

- {{ui:工種パック…}} は、ドライウォール、電気、コンクリートなど工種ごとに、単価を含まないひな形の複合単価を追加します。[工種パック](topic:trade-packs) を参照してください。

{{ui:CSVを書き出し}} はライブラリを CSV として保存します。コピーを残す、表計算で編集する、同僚に渡す、などに使います。{{ui:クリア}} はライブラリを空にします（2 回クリックします）。

:::note
ライブラリはこのブラウザーの保存領域にあります。別のブラウザー、別のコンピューター、またはプライベートウィンドウでは、独自のライブラリを持つか（ライブラリがない）ことになります。移動するには書き出してください。
:::

## 拾い出しで使う

- 項目にチェックを入れ（{{ui:ライブラリを検索}} に入力すると一覧を絞り込めます）、{{ui:拾い出しに追加}} を選びます。項目は複合単価とともに 1 回の操作で追加され、{{key:Mod+Z}} で取り消せます。拾い出しにすでにある名前には、`Carpet (2)` のように番号が付きます。
- {{ui:単価を更新}} は、名前と種類がライブラリの項目と一致する拾い出しの各項目に、ライブラリの割増と単価を設定します。複合単価の構成要素も同じ名前であれば同様です。高さ、単位、計算式はそのままです。{{key:Mod+Z}} を 1 回押すと、古い単価がすべて元に戻ります。

## CSV の列

1 行目には列名を任意の順番で書きます。ほかの列は無視されます。

| 列 | 入力する内容 |
|---|---|
| Item (or Name) | 項目の名前。必須。 |
| Type | Linear、Area、Count（LF、SF、EA も使えます）。空欄の場合は単位で決まります。 |
| Unit | LF または m、SF、SY または m²、EA。空欄の場合は、その種類の通常の単位です。 |
| Waste % | `10` または `10%`。 |
| Material per unit, Labor per unit | `2.10` や `$1,250` のような単価。 |
| Height (or Depth) | `9'-0"`、`9`、またはメートル単位の `2.7`。 |
| Component, Formula | Component 名（または種類 `Component`）のある行は、その上の項目の複合単価の一部になります。その行の単位、割増、単価はその行独自のものです。計算式では項目の文字を使います。[複合単価と計算式](topic:assemblies) を参照してください。 |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

カンマ、セミコロン、またはタブで区切られた列はいずれも使えます。

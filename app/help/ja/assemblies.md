項目の**複合単価**は、それぞれ独自の数量の数式、ロス、単価を持つ**内訳**の一覧です。数式は項目で実測した合計値を使うため、壁を1回拾い出すだけで、間柱、上枠・下枠、ボードを同時に算出でき、実測を変更すると数量も更新されます。

## 使用できる変数

| 項目の種類 | 変数 |
|---|---|
| 長さ | `L` 長さ, `H` 高さ, `A` 壁面積 (L × H), `N` 連続線の数 |
| 面積 | `A` 面積, `P` 周長 (外形線 + 開口), `H` 厚さまたは深さ, `N` 面積の数 |
| 個数 | `N` 個数 |

値は項目自身の単位で入ります。LF と SF の項目はフィートと平方フィート、m と m² の項目はメートルと平方メートルです。SY の項目では `A` は平方ヤード、`P` と `H` はフィートのままです。

数式では `+ - * /`（または × ÷）、括弧、数値、関数 `ceil`、`floor`、`round`、`min`、`max`、`abs` が使えます。詳しい規則は [数式の言語](topic:formulas) にあります。

## 例: 室内の壁

**室内壁タイプA** を長さの項目として拾い出したとします。連続線4本、合計120 LF、{{ui:Height}} は `9'-0"` に設定されています。このとき**実測値**は L = 120、N = 4、A = 1,080（壁面、片面の SF）です。

1. {{ui:Items}} で項目を選択します。
2. {{ui:Assembly}} で {{ui:Add component}} を選択します。
   「内訳」という名前の内訳が、数式 `L` とその結果とともに表示されます。
3. {{ui:Name}} に `間柱 16 in o.c.`、{{ui:Unit}} に `EA` と入力します。
4. {{ui:Quantity formula}} に `ceil(L * 12 / 16) + N` と入力します。
   入力中に結果が更新されます:「= 94 EA」。120フィートを16インチ間隔で割った90本に、4本の連続線それぞれを閉じるための1本ずつを加えています。
5. 上枠・下枠の内訳を追加するには、{{ui:Add component}} をもう一度選択し、名前 `上枠・下枠`、単位 `LF`、数式 `L * 2` と入力します。結果: 240 LF。
6. ボードを追加します: 名前 `せっこうボード 4x8、両面`、単位 `枚`、数式 `ceil(A * 2 / 32)`。結果: 68枚（ボードの合計 2,160 SF ÷ 1枚あたり 32 SF = 67.5、切り上げ）。
7. 各内訳の {{ui:Waste %}}、{{ui:Material $}}、{{ui:Labor $}} を入力します。
   各内訳は {{ui:Quantities}} の項目の下に独自の行として表示され、項目と同様に価格が付き、{{ui:Job total}} に含まれます。

壁の費用がすべて内訳に入っている場合は、項目自身の材料と労務の単価を 0 のままにしてください。そうしないと二重に計上されます。

:::tip
ロスは数式の後に適用され、切り上げは行われません: 68枚に10%のロスを付けると 74.8枚です。発注を枚単位にするには、ロスを数式の中に入れます（例: `ceil(A * 2 / 32 * 1.1)`）。その場合は内訳のロスを 0 のままにします。
:::

## その他の数式

| 内容 | 項目 | 数式 |
|---|---|---|
| 間柱、24インチ間隔 | 長さ | `ceil(L / 2) + N` |
| 断熱材（ばら）、SF | 高さのある長さ | `A` |
| 塗料、両面、350 SF につき1ガロン | 高さのある長さ | `ceil(A * 2 / 350)` |
| タイル箱、15 SF、10%増し | 面積 | `ceil(A * 1.1 / 15)` |
| 幅木または端部の見切り材、LF | 面積 | `P` |
| コンクリート、立方ヤード | 深さのある面積 | `A * H / 27` |
| コンクリート、1/4ヤード単位に切り上げ | 深さのある面積 | `ceil(A * H / 27 * 4) / 4` |
| 扉ごとの蝶番、3個 | 個数 | `N * 3` |
| 最低1箱、12個につき1箱 | 個数 | `max(1, ceil(N / 12))` |

## 数式が誤っている場合

数式の下の行がエラーメッセージに変わります。例:「"X" はここでは実測値ではありません。L、H、A、N を使用してください。」や「A ")" がありません。」。その内訳には金額が出ず、{{ui:Quantities}} の行に「数式エラー: …」と表示され、見出しには「未完了: 数式エラー 1 件（合計には含まれません）」と表示されます。数式を直すと合計も更新されます。

0 で割る数式もエラーです（「数式が0で割っています。」）。例: 深さのない項目での `A / H`。

## 制限

- 数式は連続線ごとではなく項目の**合計**に対して実行されます。`ceil(L * 12 / 16) + N` は連続線ごとに1本を加えますが、連続線ごとの切り上げはまだ行われません。
- 数式で使えるのは同じ項目の変数だけです。他の項目の変数は使えません。
- 1項目につき内訳は最大50件、数式は500文字までです。

## 内訳を削除する

内訳の下の {{ui:Remove component}} を選択します。{{key:Mod+Z}} で取り消せます。

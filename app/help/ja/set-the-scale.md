すべてのシートには、それぞれ独自の縮尺があります。縮尺は、自分で設定するか、シートのテキスト (下記) から TakeoffCraft に読み取らせてから、確認します。縮尺が設定されるまで、{{ui:長さ}}、{{ui:面積}}、{{ui:円}}、{{ui:開口}}は、そのシート上での計測を拒否します。{{ui:個数}}と{{ui:自動カウント}}は、縮尺なしで動作します。

シート一覧には、各シートの縮尺または**縮尺なし**が表示されます。開いているシートの下のバーにも、同じ内容が表示されます。

## プリセットを使う (PDFが実寸で印刷されている場合)

1. シートを開きます。
2. {{ui:縮尺}}グループの{{ui:プリセット}}一覧を開きます。
3. 図面に印刷されている縮尺を選びます。例: 建築の `1/8" = 1'-0"`。
   ステータスバーに "このシートの縮尺: 1/8" = 1'-0"" と表示されます。
4. 確認します (下記)。

プリセットは、PDFが図面を作成した実際の用紙サイズであることを前提とします。PDFが「ページに合わせる」で作成された場合、または半分のサイズのセットの場合、プリセットは誤りです。代わりに校正してください。

一覧の全体は[縮尺プリセット](topic:scale-presets)にあります。

## シートのテキストから縮尺を読み取る

ほとんどの図面には縮尺が記載されています: 表題欄の `SCALE: 1/4" = 1'-0"`、ビューの下の `1:100` など。TakeoffCraftはそれを読み取り、すべてのシートを一度に設定できます。

1. {{ui:プリセット}}一覧を開き、(一番上の) {{ui:シートのテキストから…}} を選びます。
2. 一覧には、すべてのシートが表示されます: 現在の縮尺と、そのテキストが示す内容です。**1/4" = 1'-0" と記載**、**テキストに縮尺の記載なし**、または**縮尺なしと記載 (NTS)** のいずれかです。
3. 縮尺のないシートで縮尺が記載されているものには、チェックが付きます。任意のシートのチェックを付けたり外したりした後、{{ui:チェックした縮尺を設定}}を選びます。{{key:Mod+Z}}を1回押すと、すべて元に戻ります。
4. {{ui:確認}} (下記) で、各シートの寸法を1つ確認します。プリセットは、PDFが実寸で印刷されている場合にのみ正しいからです。

読み取れるのは、[プリセット](topic:scale-presets)に一致する建築 (`3/16" = 1'-0"`、`1 1/2" = 1'-0"`)、土木 (`1" = 20'`)、メートル法 (`1:50`) の表記です。シートに複数の縮尺が記載されている場合 (拡大詳細図を含む平面図など)、最も多く記載されているものを採用します。単語 SCALE の後に書かれたものは2回と数えます。ほかの縮尺は赤で表示されるため、確認できます。スキャンされたシートにはテキストがないため、縮尺は手動で設定してください。

## 既知の寸法で校正する

信頼できる印刷された縮尺がない場合、セットがリサイズされた場合、またはシートに「縮尺なし」と書かれているが寸法がある場合に使います。

1. シートを開き、既知の長い寸法 (通り芯の間隔や建物全体の寸法など) にズームします。長いほど正確です。
2. {{ui:縮尺}}グループの{{ui:校正}}を選ぶか、{{key:K}}を押します。
3. 寸法の一端をクリックします。精度を上げるため、各端にズームしてください。クリックの間にズームやパンもできます。
4. もう一端をクリックします。{{key:Shift}}を押したままにすると、線を0°、45°、90°に保てます。
   **このシートを校正**ダイアログが開きます。
5. **実際の距離**に実寸を入力します。例: `24'-6 1/2"`、`24.5` (10進フィート)、`30"`、`7.5 m`。[長さ、単価、割合の入力](topic:entry-formats)を参照してください。
6. {{ui:縮尺を設定}}を選びます。
   ステータスバーには縮尺が "1" = (n)'" と表示されます。プリセットの0.5%以内の場合は、どれに一致するかも表示されます。例: "(1/4" = 1'-0" に一致。正確な縮尺にはそのプリセットを選んでください)"。
   TakeoffCraftは{{ui:選択}}ツールに戻ります。

校正がプリセットに一致する場合、そのプリセットを選ぶと、クリックした位置に依存する縮尺ではなく、正確な縮尺が得られます。

## 縮尺を確認する

新しい縮尺は、必ず別の寸法で確認してください。

1. {{ui:縮尺}}グループの{{ui:確認}}を選ぶか、{{key:D}}を押します。
2. 図面に印刷された寸法の両端をクリックします。
   ステータスバーに "確認: 12'-6"" と表示され、同じ長さが10進フィートとメートルで示されます。確認線は、長さとともにシート上に残ります。
3. 印刷された寸法と比較します。ずれている場合は、より長い寸法で校正し直してください。

{{key:Esc}}を押すと、確認線が消えます。

## 縮尺を変更する

別のプリセットを選ぶか、もう一度校正します。シートにすでに計測値がある場合、TakeoffCraftは**このシートの縮尺を変更しますか？**と確認し、再計測される計測値の数を示します。{{ui:縮尺を変更}}を選んでください。シート上のすべての区間と面積は、新しい縮尺で再計測されます。{{key:Mod+Z}}で元に戻せます。

## 縮尺のないシートを0として数えない理由

縮尺のないシート上のマークには、実際の長さや面積がありません。TakeoffCraftはそれを0として数えることはありません。0として数えると、見積が気付かれずに少なくなってしまうからです。代わりに、次のように処理します:

- そのマークを合計から除外します。
- {{ui:数量}}で、項目の横に "+(n) 縮尺なし" と表示します。
- 表のヘッダーに "不完全: 縮尺のないシート上のマーク (n)件 (合計に含まれません)" と表示します。
- 件数を、スプレッドシート書き出しの備考列に書き込みます。

縮尺が設定されていない状態でプロジェクトを開いた場合に発生することがあります。シートに縮尺を設定すると、マークはすぐに計上されます。個数マークは常に計上されます。縮尺は不要です。

## ヒント

- 計測を始める前に、計測するすべてのシートに縮尺を設定してください。シート一覧で**縮尺なし**を探すと、未設定のシートが見つかります (検索ボックスはシート名を検索し、縮尺は検索しません)。
- 同じシート上の詳細図や拡大平面図は、別の縮尺を使うことがよくあります。TakeoffCraftは1シートにつき1つの縮尺のみを持ちます。[未作成の機能](topic:not-built-yet)を参照してください。
- メートル法の図面: `1:100` などのメートル法プリセットを選ぶか、`6000 mm` のようなメートル法の距離で校正してください。

TakeoffCraftは、CadCraftのアプリバーの下で、ブラウザーのウィンドウいっぱいに表示されます。上から下、左から右の順に説明します。

| 部分 | 位置 | 用途 |
|---|---|---|
| アプリバー | 最上部 | アプリ名、バージョン、{{ui:TakeoffCraftについて}}、{{ui:ヘルプ}} ({{key:F1}})、{{ui:オフライン用に保存}}、{{ui:設定}} ({{key:Mod+,}})、{{ui:全画面表示}}ボタン、{{ui:ペーパー}} / {{ui:モデル}}のテーマ切り替え。 |
| ツールバー | アプリバーの下 | すべてのコマンドを、{{ui:ファイル}}、{{ui:書き出し}}、{{ui:縮尺}}、{{ui:拾い出し}}、{{ui:編集}}、{{ui:表示}}のグループにまとめたもの。 |
| シート | 左 | 開いているすべてのPDFのすべてのページ。サムネイル、縮尺、マーク数付き。 |
| シート (本体) | 中央 | 開いているページ。ここで計測します。 |
| 項目 | 右 | 拾い出しの項目、選択した項目の設定、選択したマーク。 |
| 数量 | 下 | 項目別またはシート別の数量と費用、見積の合計。 |
| ステータスバー | 最下部 | リアルタイムの計測値、メッセージ、45°のヒント、ズーム。 |

## ツールバー

ボタンにポインターを合わせると、機能とキーが表示されます。

| グループ | ボタン |
|---|---|
| {{ui:ファイル}} | {{ui:新規}} (空の拾い出し)、{{ui:図面を開く}} ({{key:Mod+O}})、{{ui:拾い出しを開く}} (`.takeoff.json`のプロジェクト)、{{ui:拾い出しを保存}} ({{key:Mod+S}}) |
| {{ui:書き出し}} | 1つのメニュー: {{ui:XLSX}}、{{ui:CSV}}、{{ui:印付きPDF}} |
| {{ui:縮尺}} | {{ui:校正}} ({{key:K}})、{{ui:確認}} ({{key:D}})、{{ui:プリセット}}の一覧 |
| {{ui:拾い出し}} | {{ui:選択}} ({{key:V}})、{{ui:長さ}} ({{key:L}})、{{ui:面積}} ({{key:A}})、{{ui:円}} ({{key:O}})、{{ui:円弧}} ({{key:R}}、オン/オフのスイッチ)、{{ui:控除}} ({{key:E}}、オン/オフのスイッチ)、{{ui:開口}} ({{key:X}})、{{ui:個数}} ({{key:C}})、{{ui:自動カウント}} ({{key:S}}) |
| {{ui:編集}} | {{ui:元に戻す}} ({{key:Mod+Z}})、{{ui:やり直し}} ({{key:Mod+Y}})、{{ui:コピー}} ({{key:Mod+C}})、{{ui:貼り付け}} ({{key:Mod+V}})、{{ui:その他}}: {{ui:切り取り}}、{{ui:コピー}}、{{ui:貼り付け}}、{{ui:同じ位置に貼り付け}}、{{ui:複製}}、{{ui:削除}}、{{ui:すべて選択}}、{{ui:選択解除}} |
| {{ui:表示}} | {{ui:ページに合わせる}} ({{key:F}})、{{ui:幅に合わせる}} ({{key:W}}) |

使用中のツールは押された状態で表示されます。{{ui:円弧}}と{{ui:控除}}のボタンは、オンの間、押されたままになります。

## シート (左)

- **シートを検索**は、シート名、ファイル名、ページラベルで一覧を絞り込みます。
- 各シートには、サムネイル (スクロールに合わせて描画)、名前、そして縮尺または**縮尺なし**が表示されます。
- 各行の右側には、そのシートのマーク数が表示されます。項目をハイライトしている間は、代わりにその項目のマークがシートに何個あるかが表示されます。
- シートをクリックすると開きます。{{key:PageDown}}と{{key:PageUp}}で、一覧の次と前のシートに移動します。
- 拾い出しに、開いていないPDFが含まれる場合は、一覧の下の注記にその名前が表示されます。[拾い出しを保存して再び開く](topic:save-and-reopen)を参照してください。

シート名はPDFから取られます。`A-101`のようなページラベルが、そのままシート名になります。ラベルのないページは、ファイル名とページ番号 (「Plans、3ページ」など) が名前になります。複数のPDFを開いている場合、ラベル付きのシートにもファイル名が表示されます。

## シート (中央)

- シートの下のバーには、シート名とその縮尺、または「まだ縮尺がありません: プリセットを選ぶか校正してください」と表示されます。ボタンは次のとおりです。{{ui:MarkupCraft}} (そのアプリがPDFを受け取れる場合。[拾い出しを始めて図面セットを開く](topic:open-plan-set)を参照)、{{ui:比較}} (シートの古い版をこのシートに重ねる。[改訂されたシートを比較する](topic:compare-revisions))、「(n)件を確認」 (フラグの付いたマークがある場合)、{{ui:3D}} ([3Dチェックビュー](topic:check-in-3d))。
- PDFを何も開いていないときは、中央に短い5ステップのガイドが表示されます。
- ホイールでポインター位置にズームします。ドラッグでパンします。[キーボードとマウス](topic:keyboard)を参照してください。
- {{ui:自動カウント}}を使っている間は、そのコントロールのあるバーがシートの上部に表示されます。

## 項目 (右)

上部の{{ui:入札範囲}}の一覧は、新しいマークを入れる建物、階、フェーズです ([入札範囲](topic:bid-areas))。

- {{ui:新しい項目}}は、小さなフォームを開きます。名前、種類 ({{ui:長さ（延長）}}、{{ui:面積}}、{{ui:個数}})、{{ui:追加}}です。
- 一覧には、各項目の色、種類のアイコン、名前、数量が表示されます。項目をクリックすると、その項目で作図でき、すべてのシートでそのマークがハイライトされます。もう一度クリックすると、ハイライトが止まります。
- 一覧の下の**項目: (名前)**が項目エディターです。名前、種類、色、単位、高さまたは深さ、ロス、材料と労務の単価、計測値、{{ui:複合単価}}があります。[拾い出しの項目を作る](topic:create-items)を参照してください。
- **選択したマーク**は、マークを選択すると現れます。そのマークが属する項目、シート、計測値と、{{ui:開口を追加}}や{{ui:マークを削除}}などのボタンです。複数のマークを選択すると**選択したマーク**になり、項目ごとの数と、{{ui:コピー}}、{{ui:複製}}、{{ui:切り取り}}、{{ui:マークを削除}}が表示されます。
- 項目エディターの末尾には、{{ui:項目をコピー}}と{{ui:項目を複製}}があります。複合単価と費用を含み、マークを含まない項目です。[マークのコピー、貼り付け、複製](topic:copy-paste)を参照してください。

## 数量 (下)

- {{ui:項目別}}は、すべての項目とその複合単価の構成要素を、数量、ロス、単価、金額とともに一覧します。ロスと単価は、表に直接入力できます。
- {{ui:シート別}}は、各項目の数量を、シートごとに一覧します。
- 合計から漏れているものがあるときは、**不完全:**で始まる警告が表示されます。
- {{ui:見積の合計}}は、見出しの右にあります。
- 右端の矢印ボタンは、表を隠したり表示したりして、シートに広い場所を与えます。

[数量と見積を読む](topic:read-quantities)を参照してください。

## ステータスバー (下)

左から右へ。作図中のリアルタイムの計測値 (長さ、面積、半径、確認の結果)、長さを入力している間の{{ui:入力}}ボックス、TakeoffCraftからのメッセージ、「Shiftで45°にスナップ」のリマインダー ([設定](topic:settings)でオンにしている場合は「45°にスナップします。Shiftを押すと角度を自由に指定できます」)、{{ui:スナップ}}ボタン (図面の線へのスナップ。ハイライトされているとオン、{{key:F3}})、ズームのパーセンテージです。

:::tip
何も起きないときは、ステータスバーを読んでください。クリックが拒否された理由、たとえば「このシートにはまだ縮尺がありません。」が、そこに説明されます。
:::

## ほかのレイアウト

ここまで説明したのは、最初の状態の{{ui:CadCraft クラシック}}レイアウトです。{{ui:設定}} ({{key:Mod+,}}) › {{ui:グローバル}} › {{ui:レイアウト}}には、ほかに2つのレイアウトがあります。3つとも同じツールとキーが使え、{{ui:CadCraft クラシック}}を選び直すと、すべてのコントロールが元の位置に戻ります。

| レイアウト | TakeoffCraftでは |
|---|---|
| {{ui:リボンとプロジェクトブラウザー}} | 上部に{{ui:拾い出しリボン}} ([メニュー、キー、マウス](topic:menus-keys-and-mouse))、実行中のツール用のバー、開いたシートごとのタブ (図面のモデルとレイアウトもシートです)、シートの下に縮尺のプリセットと{{ui:ページに合わせる}}。左のパネルには、{{ui:プロパティ}} (選択した項目、注記、マーク) の下に{{ui:拾い出しブラウザー}}が置かれます。{{ui:シート}} (クリックするとタブで開く)、{{ui:条件}} (クリックするとそれで作図)、{{ui:見積}} (各項目の合計と見積の合計) です。サムネイルは2つ目のタブです。 |
| {{ui:ツールボックスと情報ボックス}} | シートの上のツールバー、{{ui:入札範囲}}・実行中のツールまたは選択・シートバーを持つ情報ボックス、左に拾い出しツールの列、すべてのシートのタブ、シートの下の{{ui:スナップ}}とズーム。 |

[3Dチェックビュー](topic:check-in-3d)を開いている間は、シートのタブとシートの下のバーは脇に退きます。もう一度計測するには、3Dビューを閉じてください。スマートフォンでは、常にスマートフォン用のレイアウトで動作します。

## 全画面表示とテーマ

アプリバーの{{ui:全画面表示}}ボタン、または{{key:Ctrl+Shift+F}} (Macを含むすべてのプラットフォームでControlキー) で、通常、全画面表示、バーを隠した全画面表示を順に切り替えます。バーを隠しているときは、ポインターを上端に動かすと、再びバーが表示されます。

{{ui:ペーパー}}は明るいテーマ、{{ui:モデル}}は暗いテーマです。{{ui:モデル}}では、図面が画面上でのみ反転して (暗い背景に明るい線) 表示され、書き出しが変更されることはありません。

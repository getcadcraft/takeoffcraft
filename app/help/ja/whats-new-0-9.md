0.9 で変わった点です。0.8.1 と比べた変更点です。TakeoffCraft は今回は小規模なリリースです。長さをメートル、センチメートル、ミリメートルで表示でき、面積と縮尺がメートル法の作業に正しく対応し、円弧は10通りの方法で描けます。Liveセッションでは、参加者がどこにいるかも表示されます。

## 新機能

### 長さをm、cm、mmで表示する

- **長さの表示形式。** {{ui:設定}} › {{ui:TakeoffCraft}} に {{ui:長さの表示形式}} があり、{{ui:全般の設定に従う}}、{{ui:フィート・インチ}}、m、cm、mm から選べます。{{ui:全般の設定に従う}} は、{{ui:設定}} › {{ui:グローバル}} › {{ui:単位}} で選んだメートル法の長さの単位を使い、選んでいない場合はフィート・インチを使います。図面上、ステータスバー、パネルに表示される長さ（高さ、奥行き、厚さ、レベルを含む）が変わります。高さの欄に単位なしで入力した数値は、表示されている単位として扱われます。
- **表示のみ。** 数量、費用、書き出しは正確な長さから計算されます。1/16、1/8、1/4インチの選択肢は、フィート・インチの場合にのみ表示されます。詳しくは [長さをmで表示する](topic:show-lengths-in-meters) を参照してください。
- **重さの単位。** {{ui:入力数量（図面なし）}} の項目を lb、TON、kg、t の単位で指定でき、単位ごとに単価を設定できるようになりました。
- **温度。** すべての項目に、項目エディターの任意入力欄 {{ui:温度}} があり、摂氏（°C）または華氏（°F）で入力できます。{{ui:設定}} › {{ui:TakeoffCraft}} の {{ui:温度の表示形式}} では、{{ui:全般の設定に従う}}、°C、°F を選べます。

### メートル法の作業のための面積と縮尺

- **図面上の面積をm2で表示。** メートル法の項目で計測した面積は、表と同様に、図面のタグとマークパネルにも m2 と表示されるようになりました（以前は SF）。項目がメートル法で単価設定されているか、長さが m、cm、mm で表示されている場合は m2、それ以外は SF になります。
- **壁面積。** 高さを持つ線形項目は、項目一覧に壁面積（長さ×高さ）も表示され、項目別の数量表の下に注記行としても表示されます。
- **縮尺プリセット1:75と1:150。** {{ui:縮尺}} グループの {{ui:プリセット}} 一覧に追加されました。このグループの縮尺は32種類になりました。詳しくは [縮尺プリセット](topic:scale-presets) を参照してください。

### 10の方法で描く円弧

- {{ui:円弧}} がオンの間（ツールバーのボタンまたは {{key:R}}）、シートバーに {{ui:円弧の方法}} ボックスが表示されます。選べる方法は次のとおりです: 3点／始点、中心、終点／始点、中心、角度／始点、中心、長さ／始点、終点、角度／始点、終点、方向／始点、終点、半径／中心、始点、終点／中心、始点、角度／中心、始点、長さ。角度、長さ、半径、方向は、クリックでも入力でも指定できます。線形項目、面積、切り抜きで使えます。0.9より前に保存されたファイルも同じように開けます。詳しくは [10の方法で円弧を描く](topic:draw-arcs-ten-methods) を参照してください。

### 共同作業

- **互いのカーソルを表示。** Liveセッションでは、各参加者のポインターが、その人の名前と色とともにシート上に表示されます。選択したマークは破線の枠で囲まれます。別のシートにいる参加者は、そのシート名とともに一覧に表示されます。詳しくは [共同作業をする](topic:work-live) を参照してください。
- **参加者への追従と参加者一覧。** Liveセッションの {{ui:参加者}} ボタンでは、各参加者が使用中のツール、いるシート、最後に編集した日時を一覧表示します。{{ui:追従}} を選ぶと、表示が相手の表示に合わせて動き、ホストは {{ui:全員に自分への追従を求める}} を使えます。詳しくは [Liveセッションで参加者に追従する](topic:follow-a-teammate) を参照してください。

## すべてのアプリ共通

- **ツールチップと開始時のヒント。** カーソルを合わせると表示される文字は Bootstrap のツールチップになり、開始時のヒントは閉じられるようになりました。
- **スクロールするタブ帯。** パネルのタブ帯が収まらない場合、切れずにスクロールします。
- **タブのタイトル。** ブラウザーのタブには `<document> - TakeoffCraft | CadCraft` と表示されます。
- **レイアウト。** {{ui:設定}} のレイアウト一覧はドロップダウンになり、選んだレイアウトが表示されます。
- **言語。** 選んだ言語が、ページ自身が表示する「新規」「開く」「保存」などの語にも反映されるようになりました。英語以外の言語は、ネイティブの話者が確認するまで機械翻訳の下書きです。

## 制限事項

- 表示単位、重さと温度の単位、新しいプリセットは、テストとページ上で確認しました。すべてのパネルを、すべての単位で手作業で確認したわけではありません。
- 参加者一覧は、実際の教師と生徒のクラスによる手作業での確認はまだ行っていません。
- 英語以外の言語は機械翻訳の下書きです。
- Windowsのインストーラーにはコード署名がありません（詳細情報、そのまま実行）。macOSのディスクイメージは公証を受けていません（右クリックして開く）。

## 以前の版: 0.8 と 0.8.1

TakeoffCraft 0.8（2026-11-01 リリース）と 0.8.1（2026-11-02）で、0.7 から変わった点です。記号の凡例をセット全体で一度に数えられるようになり、新しい拾い出しを過去の案件の単価から始められるようになり、拾い出しをサプライヤーの在庫と照合できるようになりました。0.8.1 は修正版です。

### 新機能

**セット内のすべてを数える**

- **凡例をひとつ囲む。** ツールバーの {{ui:一括カウント}} は、記号の凡例を読み取ります。記号と、その横に印刷された名前の周りをドラッグして囲みます。各記号は画像と名前とともに一覧に表示され、その名前が項目名になります。不要なものはチェックを外し、{{ui:N枚のシートでカウント}} を選びます。進行中のシートを示すバーが表示され、{{ui:キャンセル}} で実行を止められます。その間もページは操作できます。
- **1回の実行で全シート。** 各記号は、開いているすべてのシートで数えられます。別の縮尺で描かれたシートは、その縮尺で検索されます。記号は直角の任意の向きで見つかります。凡例自身のシート上の記号は数えられません。
- **追加の前に確認。** 各合計には、シートごとのリンク（「E-103: 4」）があり、そのシートに移動します。検出結果の枠をクリックすると除外され、もう一度クリックすると戻ります。一致度（50%から100%）は、見つかったものを絞り込むだけです。再検索はされません。
- **元に戻す操作は1回。** {{ui:Nマークを追加}} は、記号ごとに数量項目を作り、見つかった箇所すべてにマークを付けます。すでにあなたの数量項目である名前は再利用されます。{{key:Ctrl+Z}} で、すべての項目とマークが元に戻ります。承認したものは {{ui:学習済み}} にも反映されます。
- **任意の角度の記号。** 数える前に {{ui:任意の角度の記号}} にチェックを入れると、直角以外の角度で回転した記号も見つかります。その場合、検索は各記号を15度ごとに回転させ、丸くない記号は最大6倍の時間がかかることがあります。
- **仕組み。** 自分のシート上で、学習済みのモデルを使わず、単純な記号の照合を行います。データはコンピューターの外に出ません。架空の200シートのセットでは、高速なデスクトップのChromeで、始めから終わりまで9.4秒かかりました。実際の図面セットでは、もっと時間がかかります。詳しくは [セット内のすべてを数える](topic:count-everything) を参照してください。

**自分の案件からの単価の記憶**

- **TakeoffCraftが単価を覚えます。** 拾い出しを保存すると、使われた単価設定の各項目が、名前と種類ごとに記憶されます。材料単価、労務単価、ロス、単位です。名前ごとに直近12件の案件を保持します。記憶はこのコンピューターの単価ライブラリの隣に保存され、拾い出しファイルの中には入らず、どこにも送信されません。
- **記憶から新しい拾い出しを始める。** ツールバーの {{ui:単価}} には、各項目について、直近の案件の単価、標準の単価、範囲が表示されます。{{ui:前回を使用}} または {{ui:標準を使用}} で1項目に単価を設定でき、{{ui:記憶から未設定のN項目に単価を設定}} で、まだ単価のない項目すべてに設定できます。それぞれの操作は元に戻す操作1回分です。
- **以前の案件。** {{ui:過去の拾い出しから学習…}} は、保存された拾い出し（.json）の単価設定済みの項目を記憶します。
- **確認、変更、忘れる。** {{ui:記憶されているものすべて}} には、すべての名前が一覧表示されます。ゴミ箱ボタンで1件を忘れ、{{ui:すべての単価をクリア}} ですべて忘れます。停止するには {{ui:拾い出しの保存時に単価を記憶する}} のチェックを外します。1個あたりの単価が、フィートあたりの項目に設定されることはありません。詳しくは [過去の案件からの単価の記憶](topic:price-memory) を参照してください。

**サプライヤーの在庫と納期**

- **サプライヤーの一覧と照合。** ツールバーの {{ui:供給}} は、サプライヤーの在庫一覧（{{ui:サプライヤーのファイルを追加…}}）を受け取ります。CSVまたは表計算ファイルです。拾い出しに必要なものを、ロスを含めて照合します。ファイルは5件まで保持されます。データは送信されず、サプライヤーに問い合わせることもありません。ファイルはあなたが用意します。
- **結果の表示。** 不足している項目が先に表示されます。「Short by 120 EA」「Lead time 21 days」「On backorder」「Unit differs」「No stock figure」「In stock」などです。{{ui:許容する最長納期(日)}} の初期値は14です。
- **発注リスト。** {{ui:発注リスト(CSV)}} は、不足している項目を、不足数、サプライヤー、納期とともにダウンロードします。
- **単価をライブラリへ。** ファイルに単価が含まれている場合、{{ui:単価をライブラリへ}} は、同じ名前と単位のライブラリ項目の材料単価を設定します。拾い出しに反映するには、ライブラリから単単価を再設定してください。
- **問題パネルで。** 在庫不足は警告、長い納期は注記として、「Supplier stock（サプライヤーの在庫）」の下に表示されます。理由を付けて承認でき、その理由は拾い出しに保存されます。詳しくは [サプライヤーの在庫と納期を確認する](topic:supplier-stock) を参照してください。

**AIアシスタント**

- **3つすべてのツール。** {{ui:設定}} でアシスタントを許可すると、アシスタントは凡例を読み取り（`legend_open`）、数える処理を実行し（`legend_count_start`、その後 `legend_count_status` と `legend_count_result`）、追加できます（`legend_count_add`、先にプレビューも可能）。記憶された単価を読み取り（`prices_list`）、それを使って項目に単価を設定し（`prices_apply`、先にプレビューも可能）、サプライヤーの確認結果を読み取れます（`supply_check`）。サプライヤーのファイルの追加は、あなたが行います。詳しくは [AIアシスタントでTakeoffCraftを使う](topic:use-with-ai-assistants) を参照してください。

**すべてのアプリ共通**

- **言語。** 合計54言語です。新たに10言語（リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語）を追加しました。英語以外の言語は、ネイティブの話者が確認するまで機械翻訳の下書きです。
- **入力デバイス。** {{ui:設定}} › {{ui:グローバル}} › {{ui:入力デバイス}} で、トラックパッド、マウスの横ボタン、ペン、3Dマウス、ゲームコントローラー、MIDIコントローラーの動作を、すべてのアプリまたは特定のアプリについて設定できます。詳しくは [トラックパッド、3Dマウス、コントローラーを使う](common:input-devices) を参照してください。
- **ツールバーの行数。** {{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} では、{{ui:折り返し}}（開始時の設定）、{{ui:2行}}、{{ui:1行}} を選べます。収まらないグループは横にスクロールします。詳しくは [パネルを配置する](common:arrange-panels) を参照してください。
- **問題パネル。** 警告と注記を表示する共通パネルに、上記のサプライヤーの在庫確認が、他の確認と並んで表示されるようになりました。
- **アドオン。** アドオンはアカウントの一覧に従います。詳しくは [アドオンとアカウントの一覧](common:addons-basics) を参照してください。
- **AIを接続。** CadCraft Studio がハブです。アシスタントを一度接続すると、8つのアプリすべてで使えます。Studio 自体にはAIはありません。

### 0.8.1 で修正された点

- **DWGのクラスセクション。** DWGファイルのクラスセクションが誤った種類として読み取られていました。これは TakeoffCraft と他の4つのアプリで修正されました。
- **Studio は実行中に言語を変更できます。** 以前は、Studio とそのパッケージ版は英語のみでした。デスクトップ版はすべてのプラットフォームでは検証していません。言語が変わらない場合はお知らせください。

### この版ではまだ対応していない機能

- **コード署名なし。** Windows で警告が出ることがあります。Mac では、初回に右クリックして {{ui:未対応}} を選びます。ストア版（Microsoft Store、Google Play、App Store）は保留中で、iPad と iPhone 版は 0.8.1 向けに再ビルドされていません。
- **Studio の更新。** Windows インストーラーと Linux パッケージは1日1回確認し、実行前に確認を求めます。ポータブル版の zip は、更新があることを知らせるだけです。macOS と APK は自動更新しません。0.8 の macOS .dmg はリリースに合わせて更新されます。
- **AIの接続。** Studio 内のワンクリック接続、ブラウザー内のAI向けホスト型コネクター、Studio 内での独自のAPIキー、公開された MCP パッケージは、この版では提供を約束していません。
- **セット内のすべてを数える。** 凡例と同じように描かれた記号が必要です。壁や長い線が通っている記号は見逃されることがあります。鏡像の記号は見つかりません。縮尺のないシートが別の大きさで描かれている場合は、凡例のサイズで検索されます。残りを信頼する前に、最初のシートの検出結果を確認してください。
- **サプライヤーの在庫。** 在庫数は、追加したファイルと同じくらいの鮮度しかありません。確認がサプライヤーに問い合わせることはありません。
- **言語。** タミル語のアプリバーがはみ出します。

その他の内容は [まだ作成されていません](topic:not-built-yet) を参照してください。ひとつ前のリリースについては [0.7の新機能](topic:whats-new-0-7) を参照してください。

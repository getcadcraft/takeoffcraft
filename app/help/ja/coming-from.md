PlanSwift や Bluebeam Revu の計測ツールで拾い出しをしたことがあれば、TakeoffCraft の大部分は見慣れたものに感じられるでしょう。図面一式、シートごとの縮尺、計測する対象、そして金額付きの合計があります。要素の組み合わせ方は一部異なるため、その違いを以下で説明します。

PlanSwift や On-Screen Takeoff に慣れている場合は、{{ui:Settings}} › {{ui:TakeoffCraft}} › {{ui:Menus, keys and mouse}} で {{ui:Takeoff desk}} メニュースタイルを選んでください。ファイル、編集、表示、縮尺、拾い出し、項目、マークアップ、書き出しのメニューバーと、拾い出しツールの行が表示され、シートバーに縮尺プリセットが並びます。詳しくは [メニュー、キー、マウス](topic:menus-keys-and-mouse) を参照してください。

## 慣れている操作の対応

| 慣れている操作 | TakeoffCraft での操作 |
|---|---|
| 図面を保存するジョブやプロジェクトを開く (PlanSwift) | PDF と `.takeoff.json` プロジェクトを並べて開きます。プロジェクトに保存されるのは拾い出しのみで、PDF は元のファイルのままです。 |
| 注記、雲マーク、ハイライトのあるマークアップ一覧 (Bluebeam) | シートバーの {{ui:Markup}}: 状態 (未対応、回答済み、完了) 付きの注記、雲マーク、ハイライトを作成でき、**マークアップ** の下に一覧表示され、印付きPDFに描画されます。詳しくは [注記、雲マーク、ハイライト](topic:markups) を参照してください。 |
| PDF 内にマークアップとして保存された計測 (Bluebeam) | 拾い出しは `.takeoff.json` ファイルに保存されます。{{ui:Marked PDF}} は、共有用に拾い出しを描画したコピーを書き出します。{{ui:PDF with the takeoff inside}} は、TakeoffCraft で再度開くための拾い出し入りのコピーを書き出します。 |
| 拾い出し項目 (PlanSwift)、ツールチェストに保存したカスタム計測ツール (Bluebeam) | {{ui:Items}} の下の **項目**: 名前、種類、色、単位、高さまたは厚さ、ロス、単価。 |
| 数式付きの部品と複合単価 (PlanSwift) | 項目の {{ui:Assembly}}: `L H A N P` を使った数式付きの構成要素。 |
| ページの縮尺の設定、または校正 (両方) | シートごとに {{ui:Scale}} グループの {{ui:Preset}} 一覧、または {{ui:Calibrate}}。{{ui:Check}} で既知の寸法を計測します。 |
| ページ範囲に一つの縮尺を適用 | まだ対応していません: シートごとに設定してください。 |
| 1 つのシート内で縮尺の異なるビューポート (Bluebeam) | まだ対応していません: シートごとに縮尺は 1 つです。 |
| ポリラインの長さと面積のツール (Bluebeam)、長さと面積の拾い出し (PlanSwift) | {{ui:Linear}} ({{key:L}}) と {{ui:Area}} ({{key:A}})。 |
| 直線のために Shift を押す | {{key:Shift}} で 45° 刻みにスナップします。同じ考え方です。 |
| 図面の線へのスナップ | 既定でオンです: 端点、中点、交点、線上の最近接点にスナップします。CAD プログラムと同様に、{{key:F3}} で切り替えられます。 |
| 個数ツール (両方) | {{ui:Count}} ({{key:C}})。 |
| 記号の目視検索 (Bluebeam) | {{ui:Auto count}} ({{key:S}}): 一つの記号を囲み、確認して追加します。 |
| 面積内の開口または控除 | 選択した面積の {{ui:Cut-out}} ({{key:X}})、および円形の開口。 |
| 長さの経路からの控除 | 経路を直線で通して描き、開口部には {{key:E}} ({{ui:Deduct}}) を押します。詳しくは [長さを計測](topic:measure-linear) を参照してください。 |
| ポリラインの円弧区間 | {{ui:Arc}} ({{key:R}}): 曲線上の点をクリックし、次に終点をクリックします。 |
| 数量列付きのマークアップ一覧 (Bluebeam) | {{ui:Quantities}} の表、{{ui:By item}} または {{ui:By sheet}}。 |
| 単価付きの見積グリッド (PlanSwift) | 同じ表: 単位ごとのロス、材料費、労務費、金額の合計、{{ui:Job total}}。 |
| Excel への書き出し | 数式を含む {{ui:XLSX}}、または {{ui:CSV}}。 |
| Esc でツールを停止 | {{key:Esc}} でキャンセルし、{{ui:Select}} に戻ります。 |
| 右クリックで完了 | ここでも右クリックで経路を完了するか、面積を閉じます。右クリックメニューはありません。 |

## 戸惑いやすい違い

**拾い出しは PDF の中に入っていません。** どの操作も PDF を変更しません。`.takeoff.json` ファイルを保存し、図面と一緒に保管してください。印付きPDFを送っても、編集可能な拾い出しは相手に届きません。プロジェクトファイルと元の PDF、または [拾い出し入りのPDF](topic:save-and-reopen#keep-the-takeoff-inside-the-pdf) を送ってください。

**PDF は名前ではなく内容で照合されます。** 改訂したシートを古いファイル名で上書き保存すると、TakeoffCraft にとっては縮尺もマークもない新しいファイルになります。古いマークは古いバージョンに残り、引き続き数量に含まれます。詳しくは [拾い出しを保存して再度開く](topic:save-and-reopen#when-a-pdf-has-changed) を参照してください。

**縮尺のないマークは 0 ではなく除外されます。** シートに縮尺がない場合、その経路と面積は集計されず、表には「不完全」と表示されます。多くのプログラムでは単に 0 と表示されるでしょう。詳しくは [縮尺を設定](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero) を参照してください。

**用紙サイズの推測は行いません。** プリセットは PDF が実寸で印刷されていることを前提とします。半分のサイズや「ページに合わせる」で出力された PDF には {{ui:Calibrate}} が必要です。必ず {{ui:Check}} を使ってください。

**項目には主な種類が一つあり、必要に応じて他の種類を追加できます。** 項目は長さ、面積、個数のいずれかで、マークが付くと種類は固定されます。面積と周長の両方を与える条件は面積の項目になり、周長は `P` 変数です。長さと面積の両方を持つ壁は、高さを持つ長さの項目です。床、巾木、ドアを持つ部屋のような複数条件の項目では、**ほかにも計測** の下で他の種類にチェックを入れてください。それぞれ独立した行で単価が付きます。詳しくは [一つの項目に複数の種類のマーク](topic:create-items#one-item-several-kinds-of-marks) を参照してください。

**数式は合計に対して計算されます。** 複合単価の数式は、経路ごとではなく、すべてのシートにわたる項目の合計を使います。`N` (経路または面積の数) は、壁ごとに 1 本の余分な間柱のような経路ごとの追加分のためにあります。

**周長には開口が含まれます。** 面積の `P` には、その穴の辺が加算されます。詳しくは [開口のある面積を計測](topic:measure-areas#read-the-area) を参照してください。

**ドラッグでパンします。** {{ui:Auto count}} を除くすべてのツールで、シート上を左ボタンでドラッグするとパンします。パンツールに切り替える必要はありません。ホイールはズームします。スクロールはしません。

**クラウドではなく、復元用のコピーです。** TakeoffCraft は作業のコピーをこのブラウザーに保持し、異常終了後に復元を提案します ([タブやブラウザーが停止した場合](topic:save-and-reopen#if-the-tab-or-the-browser-stops))。ただし、拾い出しを保存するのはご自身です: {{key:Mod+S}}。クラウド保存はまだ利用できません。

**すべてブラウザー内で動作します。** インストールするものはなく、図面はアップロードされません。デスクトップアプリとしての TakeoffCraft は、他の7つのアプリと共に CadCraft Studio に含まれています。

## まだ利用できない機能

シートごとの縮尺領域はまだ作成されていません。すべての一覧と代わりの方法は、[まだ作成されていない機能](topic:not-built-yet) を参照してください。

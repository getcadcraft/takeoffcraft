次の図面一式を待つ必要はありません。建築家から建物モデルが届いたら、ここで開いて、そのまま数量を拾い出せます。モデルはお使いのコンピューターで読み込まれ、どこにも送信されません。

## 手順

1. {{ui:モデル}} をツールバーで選び、モデルの `.ifc` ファイルを選ぶか、他のファイルと同じように {{ui:図面を開く}} で開きます。
2. {{ui:モデルからの拾い出し}} が開き、分類と種類ごとに1行ずつ表示されます。壁は壁の種類ごと、床は床の種類ごと、ドアはドアの種類ごとに、などです。各行には個数と、その分類の計測項目が表示されます。
3. {{ui:グループ化}} を {{ui:カテゴリ}} にすると手早く合計が分かります。{{ui:カテゴリ、タイプ、レベル}} にすると、すべての種類を階ごとに分けられます。
4. 不要な行のチェックを外します。{{ui:検索}} で一覧を絞り込めます。行のチェックを外すと、3D画像内の対応する部品も非表示になります。
5. 作業全体で使う {{ui:モデル名}} を付けます（例: プロジェクト名）。
6. {{ui:拾い出しに追加}} を選びます。各数量は項目一覧の型付き数量になります。他の項目と同じく、名前を付け、単価を設定し、複合単価を関連付けられます。

## 3Dでモデルを確認する

{{ui:上の表の上に3Dでモデルを表示}} を選ぶと、表の上にモデルが描画されます。行ごとに1色で表示されます（行の名前の横の色のチップ）。ドラッグで回転し、{{key:Shift}} を押しながらドラッグで移動し、ホイールでズームします。{{ui:全体表示}} または {{ui:リセット}} で元に戻ります。

- **部品をクリック。** 画像内の部品をクリックすると、その行が表で選択され、その行のすべての部品が明るく表示され、他は薄くなります。同じ部品をもう一度クリックすると、その部品が複数の行に含まれている場合（壁がそのレイヤーの中にある場合など）、次の行が選択されます。
- **行をクリック。** 表の行をクリックすると、その行の部品が明るく表示されます。もう一度クリックするか、画像の何もない所をクリックすると解除されます。
- 部屋は描画されません。部屋の体積が建物を隠してしまうためです。
- 非常に大きいモデルでは、メモリに収めるため一部の部品は箱だけで表されます。パネルにその数が表示されます。数値は変わりません。

このコンピューターで3Dを描画できない場合も、表は従来どおり動きます。

## 材料、レイヤー、サイズでグループ化

{{ui:グループ化}} には、さらに3つの選択肢があります:

- {{ui:カテゴリと材料}}: レイヤーで構成された壁、床、屋根では、各レイヤーの材料がそれぞれ独自の行になります。そのため、石膏ボード、間柱、断熱材を別々に単価設定できます。材料が1つだけの建物の部位はその材料の行に入り、材料がない部位は「材料名なし」という行にまとめられます。
- {{ui:カテゴリとレイヤー}}: 同様ですが、レイヤーの厚さが行に入ります（例: 「断熱材、100 mm」）。
- {{ui:カテゴリ、タイプ、ドアまたは窓のサイズ}}: ドアと窓は幅と高さで分けられます（例: 3'-0" × 6'-8" または 914 × 2,032 mm）。

レイヤーの場合、面積は壁自体の面（床や屋根の場合は平面または表面の面積）で、体積はその面積にレイヤーの厚さを掛けた値です。行の注記には、いくつの数値がレイヤーから得られたかが書かれます。1つの壁のレイヤーを合計すると、モデルがその壁について示す体積と一致します。

## 行または建具表をCSVで保存

{{ui:行をCSVで保存}} は、チェックした行を、各見出しに単位を付けて、表計算ソフト用に保存します。{{ui:建具表をCSVで保存}}（モデルにドアか窓がある場合のみ表示）は、すべてのドアと窓を種類、階、サイズ別に、個数とともに保存します。

## 計測される項目

| 分類 | 数量 |
|---|---|
| 壁 | 個数、長さ、壁面積（片面、開口を除く）、体積 |
| 床、スラブ、天井などの仕上げ | 個数、平面の面積、体積 |
| 屋根 | 個数、平面の面積、屋根の表面積、体積 |
| フーチング | 個数、平面の面積、体積 |
| 柱、梁、部材 | 個数、部材に沿った長さ、体積 |
| 手すり、配管、ダクト、ケーブル経路 | 個数、長さ |
| 階段 | 個数、体積 |
| 部屋 | 個数、床面積、体積 |
| ドア、窓、その他すべて | 個数 |

モデルの作成者がファイル内で数量を示している場合は、その数値を使います。そうでない場合は、要素の形状から計測します。各数量には、どちらで求めたか、また何個の要素から数値が得られたかを示す注記が付きます。

:::note
形状から計測した壁の長さは端から端まで通るため、角で重なる2つの壁はどちらも角を含みます。体積には閉じた形状が必要です。閉じていない形状の要素は数えられますが、体積は出ません。曲線または角のある壁要素は、垂直面すべての半分として計測され、その注記にその旨が書かれます。
:::

## 新しいモデルが届いたとき

新しいファイルを開き、同じ {{ui:モデル名}} を入力します。何かを追加する前に、パネルには、新しく追加された数量の数、変更された数量の数と変更前後の値、そして以前のコピーにあった数量のうち、モデルにもはや含まれていないものが表示されます。{{ui:拾い出しに追加}} を選ぶと、変更された数量は新しい数値になり、あなたの名前、単価、ロス、複合単価はそのまま残ります。モデルから消えた数量は古い数値のまま残ります。設計で削除されている場合は、自分で削除してください。

数量は、種類とレベルの名前で識別されます。建築家が壁の種類の名前を変更すると、新しい数量として届き、古い数量は消えた数量として一覧に表示されます。

## 読み込めるファイル

IFCファイル（IFC2x3、IFC4、IFC4.3）。道路、鉄道、橋梁を含むIFCファイルは、従来どおりインフラの数量も直接取り込みます。

TakeoffCraft は、このリリースでは `.rvt` ファイルを読み込めません。建築家が Revit で作業している場合は、モデルのIFCエクスポート（ファイル、エクスポート、IFC）を依頼して、そのファイルを開いてください。

1つのモデルから一度に取り込めるのは最大500件の数量です。それ以上ある場合は、行のチェックを外すか、カテゴリでグループ化してください。

3D ビューは確認のためのものであり、2つ目の図面ではありません。開いているシートの拾い出しを、シート上に立ち上げて画面に表示するため、壁の欠落、スラブの重複、不要な数量マークがひと目で分かります。

始める前に、シートに縮尺が必要です（[縮尺の設定](topic:set-the-scale) を参照）。高さと厚さは実寸のフィートで必要なため、縮尺のないシートでは {{ui:3D}} はその旨を表示し、平面のシートのままになります。

## 3D ビューを開く

1. 確認したいシートを表示します。
2. シートの名前と縮尺を示すバーで {{ui:3D}} を選ぶか、{{key:3}} を押します。
   初回は、3D ビューの読み込みに少し時間がかかります。シートが地面に描かれ、拾い出しが各項目の色でその上に立ち上がります。
3. 元に戻るには、{{ui:3D}} をもう一度選ぶか、{{ui:Back to the sheet}} を選ぶか、{{key:3}} を押します。描画ツール（長さ、面積、数量など）を選んでも平面のシートに戻ります。マークは平面のシートに描かれるためです。

3D ビューは表示中のシートを画面に出します。シートはシート一覧、または {{key:PageDown}} と {{key:PageUp}} で切り替えると、3D ビューも追従します。複数の階を同時に見るには、下記の手順で積み上げてください。

## 表示内容

| マーク | 3D での表示 |
|---|---|
| 長さの連続線、高さのある項目 | 連続線に沿った、その高さの壁。曲線は曲線に沿います。 |
| 長さの連続線、高さのない項目 | シート上の線。項目の **項目** で高さを設定すると立ち上がります。 |
| 面積、厚さのある項目 | その厚さのスラブ。開口は開いたまま表示されます。 |
| 面積、厚さのない項目 | 薄い 2" のプレート（表示されるように）。 |
| 個数 | 数量を数えた各点の小さな柱。 |

高さは線分項目の {{ui:Height}} 欄、厚さは面積項目の {{ui:Depth}} 欄で、**項目** の下にあります（[拾い出し項目の作成](topic:create-items) を参照）。変更すると、3D ビューはすぐに更新されます。シート名の下の注記には、そのシートの内容が表示されます。例:「このシートの 3D: 壁 2、スラブ 1、数量 3」。また、高さや厚さのない連続線や面積の数も表示されます。注記の上でのクリックは、ビューに送られます。

数値は 3D では変わりません。壁の面積は正確な長さ × 高さ、スラブの体積は正味面積（外形から開口を引いたもの、曲線は正確）× 厚さです。曲線は、画面上でのみ短い直線で描かれます。

## 周囲を見る

| 操作 | 内容 |
|---|---|
| ドラッグ、または中ボタンでドラッグ | 拾い出しの周りを回転します。 |
| {{key:Shift}} + ドラッグ、または右ボタンでドラッグ | パン。 |
| マウスホイール | ポインターの位置でズームイン・ズームアウト。 |
| トラックパッドの2本指スワイプ | 回転（{{key:Shift}} でパン）。ピンチでズーム。 |
| {{ui:Iso}}、{{ui:Top}}、{{ui:Front}}、{{ui:Back}}、{{ui:Left}}、{{ui:Right}}、{{ui:Bottom}} | 標準の視点。拾い出しに合わせて表示されます。3D ビューは {{ui:Iso}} で開きます。 |
| {{ui:Perspective}} | 透視投影のオン・オフ（オフの場合は平行投影）。 |
| {{ui:Zoom extents}} または {{key:F}} | シート全体。 |
| {{ui:Sheet}} | 地面の図面の表示・非表示。 |
| 右上のビューキューブ | 面、辺、角をクリックすると、その方向から見ます。ドラッグで回転し、コンパスリングをドラッグで向きを変えます。家のボタンで {{ui:Iso}} に戻ります。 |

角には、ビューキューブ、小さな X・Y・Z 軸アイコン、または何も表示しないかを、{{ui:Settings}} の TakeoffCraft タブの **コーナーインジケーター** で選べます（[TakeoffCraft の設定](topic:settings) を参照）。平面のシートには角のインジケーターはありません。

:::touch
1本指で回転、2本指のピンチでズーム、2本指の移動でパン。タップで選択します。
:::

## 厚さ、基準高さ、開口のある壁

高さのある線分項目は薄い帯として立ち上がります。実際の壁として見せるには、その項目の設定の **3D での形状** で形状を与えます:

- **壁の厚さ**（8"、0.2 m）: 壁は、描いた線を中心にした立体になり、角は留め角になります。
- **基準高さ**: 壁が床からその高さから始まります（天井の下がり、吊り戸棚の列）。面積項目にもあります。例: 9'-0" の天井。
- **開口上端**: 控除された区間（ドア、[連続線の一部を控除](topic:measure-linear#deduct-a-part-of-a-run)）は、その高さより上の壁が残るため、ドアはドアとして表示されます。開口上端がない場合、控除区間は上端まで隙間になります。

これらは3D ビューの形だけを変えます。数量（長さ、壁面積、コスト）は変わりません。

## 階を積み上げる

1. すべての階の PDF を開きます。
2. 3D ビューで {{ui:Levels…}} を選び、各階の標高を入力します。例: 1階は `0`、次の階は `12'`。空欄のシートは除外されます。
3. {{ui:Stack}} を選びます。レベルのあるすべてのシートが、その高さで拾い出しを表示します。画面上のシートはその階の下に置かれ、他のシートは輪郭線で表示されます。注記には積み上げた階の数が表示されます。

シートは、ページ上の位置によって揃えられるため、同じように出力された平面図（同じシートサイズと位置）で動作します。レベルがあるが縮尺のないシートは除外され、注記にその旨が表示されます。1枚のシートだけ表示するには、{{ui:Stack}} をもう一度選びます。レベルは拾い出しと一緒に保存されます。

## 3D ビューを画像として保存する

3D バーで {{ui:PNG}} を選ぶと、画面上のビューの画像が保存されます（`… 3D.png`）。{{key:Shift}} + {{ui:PNG}} のクリックで2倍のサイズになります（`… 3D@2x.png`）。印刷用です。

## 3D ビューをモデルとして保存する

3D バーで {{ui:GLB}} を選びます。表示内容（画面上の階、または積み上げたすべての階）の `.glb` ファイル（glTF、バイナリ）が保存され、他の 3D プログラムで開けます。マークごとに1つのオブジェクトで、項目名が付き、項目の色で、メートル単位、Y 軸が上になります。シート自体と輪郭線は含まれません。

## 3D からマークを選択する

壁、スラブ、プレート、柱をクリックします。そのマークが選択されたマークになります。シート上でクリックした場合と同じです。**選択したマーク**の下に表示され、その項目が現在の項目になり、ステータスバーに長さと高さ、または面積、厚さ、立方ヤードが表示されます。{{key:Shift}} + クリックでマークを選択に追加、または選択から外します。{{key:Delete}} で選択したマークを削除し、{{key:Mod+Z}} で戻します。{{key:Esc}} で選択をすべて解除します。シートに戻ると、同じマークが選択されたままです。

:::tip
図面はテーマに従います。「モデル」テーマでは、地面のシートが平面ビューと同様に暗くなります。
:::

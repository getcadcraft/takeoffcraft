TakeoffCraftは、ほとんどの拒否理由をウィンドウ下部のステータスバーに表示します。下の一覧からメッセージを探してください。

## ファイルを開く

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| PDFリーダーを読み込めませんでした。ページを再読み込みして再度お試しください。 | アプリのPDFリーダーが読み込まれませんでした。通常は、オフラインで、かつこのアプリがオフライン用に保存されていないことが原因です。 | 再接続してから再読み込みします。次に{{ui:オフライン用に保存}}を選択し、{{ui:オフライン対応済み}}が表示されるまで待ちます。[オフラインでの作業](common:offline)を参照してください。 |
| (name)はパスワードで保護されています。保護されていないコピーを開いてください。 | PDFを開くにはパスワードが必要です。 | 保護されていないコピーを依頼するか、信頼できるPDFプログラムでパスワードを削除します。 |
| (name)はPDFとして読み取れませんでした(…) | ファイルが破損しているか、実際にはPDFではありません。 | 再度ダウンロードするか、作成したプログラムから保存し直してください。 |
| (name)は既に開いています。 | 同じ内容のPDFが既に開いています。 | 対処は不要です。 |
| TakeoffCraftはPDFと.takeoff.jsonプロジェクトを開きます。スキップ: … | ほかの種類のファイルは取り込まれませんでした。 | 先に図面をPDFに変換してください。 |
| ファイルをドロップしても何も起こらない | ファイルがブラウザーウィンドウの外にドロップされたか、ブラウザーがPDFを新しいタブで開きました。 | TakeoffCraftのページ自体にドロップしてください。「PDFまたは.takeoff.jsonをドロップ」の枠が表示されていれば機能します。 |
| 大きな図面一式を開くのに時間がかかる | 各PDFは識別のため全体が読み取られます。 | 「(name)を開いています…」のメッセージが消えるまで待ちます。サムネイルはスクロールに合わせて表示されます。 |

## 計測

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 先にPDFを開いてください。 | シートが開かれていません。 | PDFを開きます。 |
| このシートにはまだ縮尺がないため、計測できません。プリセット縮尺を選ぶか、先に校正してください(個数は縮尺なしでも機能します)。 | 長さ、面積、円、開口のツールには縮尺が必要です。 | [縮尺を設定](topic:set-the-scale)します。 |
| 先に長さの項目を作成し(項目の下で名前を付けます)、シート上をクリックします。 | その種類の項目がありません。 | 開いた{{ui:新しい項目}}フォームに入力し、{{ui:追加}}を選択します。 |
| 先に拾い出す項目を選択してください(項目パネル)。 | 現在の項目が削除されました。 | {{ui:項目}}の下の項目をクリックします。 |
| 連続線には少なくとも2点が必要です。 | 1回のクリックで完了しました。 | 少なくとも2点をクリックします。 |
| 面積には少なくとも3点が必要です。 | 角が少なすぎます。 | 少なくとも3つの角をクリックします。 |
| 輪郭が交差しているため、面積が正しくなくなります。交差しないように描き直してください。 | 8の字の形状。 | 2つの面積として描くか、順番に辺をたどって描きます。 |
| それらの点は面積を囲んでいません。 | すべての点が1本の線上にあります。 | 空間を囲む角をクリックします。 |
| 先に面積マークを選択し(選択ツール)、次に開口を選び、その内側に穴を描いてください。 | {{ui:開口}}には選択された面積が必要です。 | {{key:V}}を押し、面積をクリックしてから{{key:X}}を押します。 |
| 開口は面積の内側に完全に収まっている必要があります。 | 穴が輪郭と交差しているか、輪郭からはみ出しています。 | 穴を面積の内側に描きます。 |
| 開口同士は重ねられません。 | 2つの穴が重なっています。 | 両方を囲む1つの穴として描くか、互いに離して配置します。 |
| … 点は元の位置に戻されました。 | ドラッグした角により、輪郭が交差するか、穴が外側に押し出されてしまいます。 | 形状が有効なままになる位置にドラッグします。 |
| 円の縁上で、中心から離れた点をクリックしてください。 | 2回目のクリックが中心に近すぎました。 | さらに外側をクリックします。 |
| クリックしても点が追加されず、シートがパンする | ボタンを押している間にポインターが数ピクセル以上動いたため、ドラッグとみなされます。 | 動かさずにクリックします。特にトラックパッドでは注意してください。 |
| Shiftでスナップしない | 円弧上に点を配置しているか、円を描いています。 | 45°スナップは直線の区間にのみ適用されます。 |
| 近くの線に点が吸着する | 図面の線へのスナップがオンになっています。 | 拡大して線の間をクリックするか、{{key:F3}}を押してスナップをオフにします。 |
| スナップマーカーが表示されない | スナップがオフになっているか、シートがスキャンであるか、ツールがスナップしません(個数、自動カウント、貼り付け)。 | {{key:F3}}を押します。スキャンの場合は、スナップする線がありません。 |
| 長さが正しくない | 縮尺が正しくありません(多くの場合、プリセットを使用したサイズ変更済みのPDFです)。 | 既知の寸法で{{ui:確認}}を使用し、次に{{ui:校正}}を使用します。 |

## 縮尺

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 2点をより離して選択してください。 | 校正点がほぼ重なっています。 | より長い寸法で校正します。 |
| 校正ダイアログのメッセージ(例:「その距離を読み取れませんでした」) | 距離がTakeoffCraftで読み取れない形式で入力されています。 | [長さ、単価、割合の入力](topic:entry-formats)を参照してください。 |
| このシートにはまだ縮尺がないため、確認する対象がありません。校正するか、プリセットを選択してください。 | 縮尺のないシートで{{ui:確認}}を使用しています。 | 先に縮尺を設定します。 |
| {{ui:プリセット}}一覧がグレーアウトしている | シートが開かれていません。 | PDFを開きます。 |

## 数量と数式

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 未完了: … (合計に含まれません) | 数式エラー、または縮尺のないシート上のマーク。 | [数量と見積の読み方](topic:read-quantities#the-incomplete-warning)を参照してください。 |
| 項目の横に+(n)縮尺なし | 一部のマークが縮尺のないシート上にあります。 | それらのシートに縮尺を設定します。 |
| 数式エラー: … | 数式を計算できません。 | [数式言語](topic:formulas#errors)を参照してください。 |
| この項目にはマークがあるため、種類を変更できません。 | マークがあると、種類はロックされます。 | 別の種類の新しい項目を作成し、それでマークを描き直します。 |
| 項目には名前が必要です。 | 名前欄が空になりました。 | 名前を入力します。 |
| 12.50のような金額を入力してください。/ 10や7.5のような割合を入力してください。 | 単価またはロスを読み取れませんでした。 | [長さ、単価、割合の入力](topic:entry-formats)を参照してください。 |
| 合計が2倍になっているように見える | 項目自体の単価と内訳に、同じ費用が含まれています。 | 内訳が費用を持っている場合は、項目自体の単価を0に設定します。 |
| この項目のマークは、開かれていないPDF上にあります。 | すべてのマークが未開のPDF上にある項目をクリックしました。 | それらのPDFを開きます。名前は{{ui:シート}}の下に表示されています。 |

## 自動カウント

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| その枠は小さすぎます。記号全体を囲むように描いてください。 | 枠が非常に小さいです。 | 拡大して記号全体を枠で囲みます。 |
| その枠はほぼ空です。記号を囲むように描いてください。 | 枠には紙の部分しか含まれていません。 | 記号そのものを枠で囲みます。 |
| 一致なし。一致度スライダーを下げるか、記号をより狭く囲んでください。 | 十分な一致度のものがありませんでした。 | 記号をきつく枠で囲むか、{{ui:一致度}}スライダーを下にドラッグします。 |
| 誤った記号を含む一致が多すぎます | 似た記号が本物に近い一致度になります。 | {{ui:一致度}}スライダーを上げ、誤った枠をクリックして除外します。 |
| 他のシートで一致が欠けている | それらのシートでは、記号が別のサイズで、または90°刻みではない角度で描かれています。 | そのシートで枠を描いて検索するか、手作業で数えます。 |
| (n)枚のシートは、この記号サイズで検索するには大きすぎました。 | 作業サイズではシートが大きすぎます。 | より大きな記号を枠で囲むか、そのシートを手作業で数えます。 |
| 検索に失敗しました: … | バックグラウンドの検索が停止しました。 | 再度お試しください。繰り返す場合はページを再読み込みします(先に保存してください)。オフラインでは、アプリバーに{{ui:オフライン対応済み}}が表示された後にのみ機能します。 |
| ドラッグするとパンではなく枠が描かれる | これは{{ui:自動カウント}}の仕様です。 | {{key:Space}}を押したままドラッグするか、中ボタンでドラッグします。 |

## 保存と書き出し

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| まだ書き出すものがありません: 項目を作成し、拾い出しを行ってください。 | 項目がありません。 | 先に項目を作成します。 |
| 開いているPDFにはまだマークがありません。 | {{ui:印付きPDF}}は、開いているPDFに描画するものがありません。 | マークがあるPDFを開きます。 |
| このPDFはパスワードで保護または暗号化されているため、印付きのコピーを書き出せません。… | PDFが暗号化されています。 | 代わりに{{ui:XLSX}}を書き出すか、PDFの暗号化されていないコピーを使用します(別のファイルになるため、独自の拾い出しが必要です)。 |
| 印付きPDFを書き出せませんでした: … | 多くの場合、オフラインで、かつアプリがオフライン用に保存されていないため、PDFライターがありません。 | オンラインに戻り、{{ui:印付きPDF}}を再度選択します。回避するには、{{ui:オフライン用に保存}}を選択し、{{ui:オフライン対応済み}}が表示されるまで待ちます。 |
| 印付きPDFが1つしかダウンロードされない | ブラウザーが複数のダウンロードを同時にブロックしました。 | このサイトで複数のダウンロードを許可してから、再度書き出します。 |
| (file)はTakeoffCraftのプロジェクトではありません(有効なJSONではありません)。/ これはTakeoffCraftのプロジェクトファイルではありません。 | 間違ったファイル、または破損したファイルです。 | `.takeoff.json`ファイルを選択します。 |
| このプロジェクトは新しいバージョンのTakeoffCraftで保存されました。そちらで開いてください。 | ファイルは新しいビルドから作成されています。 | 新しいビルドで開きます。 |
| (n)件のマークが破損しており、除外されました。 | ファイルの一部が破損しているか、手作業で編集されています。 | 残りは開かれています。欠落したマークを描き直すか、古いコピーを開きます。 |
| 再度開いた後にマークが消えている | PDFが開かれていないか、そのうちの1つが変更されています。 | [拾い出しの保存と再度開く](topic:save-and-reopen#when-a-pdf-has-changed)を参照してください。 |
| ブラウザーが「このサイトを離れますか?」と尋ねる | 保存されていない変更があります。 | そのままページにとどまり、{{key:Mod+S}}で保存します。 |

## キーとマウス

| 症状 | 原因 | 対処 |
|---|---|---|
| 文字キーが機能しない | カーソルが入力欄(検索、項目エディター、表)にあります。 | シート上をクリックするか、{{key:Tab}}を押して入力欄から出ます。 |
| ホイールでスクロールではなくズームされる | ホイールは常にシートをズームします。 | ドラッグしてパンします。 |
| ページ全体が大きくなったり小さくなったりした | ブラウザーのズーム({{key:Mod+Plus}}または{{key:Mod+Minus}})。 | {{key:Mod+0}}を押します。シートのズームはホイール、または修飾キーなしの{{key:Plus}}と{{key:Minus}}で行います。 |
| Backspaceを押したらマークが消えた | 描画中でない場合、Backspaceは選択中のマークを削除します。 | {{key:Mod+Z}}で元に戻ります。 |
| Macで右クリックしても完了しない | Control+クリックは通常のクリックとして扱われます。 | 副クリック(右クリック)を有効にして2本指でクリックするか、{{key:Enter}}を押します。 |

## タッチスクリーン

タッチスクリーンでは次のとおりです:

- **タップ**すると点が配置されます(または{{ui:選択}}でマークを選択します)。1本指でドラッグするとパンします。
- **2本指**でピンチすると、その間の点を中心にズームし、一緒に動かすとパンします。2本目の指を置くと、1本目の操作が取り消されるため、ピンチによって点が残ることはありません。
- 連続線または輪郭は、**長押し**(右クリックに相当)、**ダブルタップ**、またはシート下部のバーにある{{ui:完了}}で完了します。同じバーには{{ui:後}}(最後の点を取り消す)と{{ui:キャンセル}}があります。面積は最初の点をタップしても閉じられます。
- 指の操作では対象が大きくなります。点はより遠くからスナップ、閉じる、選択でき、角のハンドルも大きくなります。

長さを入力するにはキーボードが必要です。画面上のキーボードは、{{ui:入力}}欄にフォーカスがあるときに使用できます。

タブレットでは、キーボードとマウスまたはトラックパッドがあると拾い出しがはるかに簡単になります。

## オフラインでの作業

| ボタンまたは症状 | 原因 | 対処 |
|---|---|---|
| {{ui:保存できませんでした}} | オフライン用に保存中に、アプリのファイルの一部がダウンロードされませんでした。 | 接続を確認し、ボタンを再度選択します。 |
| {{ui:オフライン利用不可}} | プライベートウィンドウと一部の管理されたコンピューターでは、オフラインコピーがブロックされます。 | 通常のウィンドウ、または別のブラウザーを使用します。 |
| 「保存中…」が開始しない | オフラインです。保存には接続が必要です。 | オンラインのときに保存します。 |
| 更新後もアプリが古いまま | オフラインコピーが以前の日のものです。 | オンラインで{{ui:オフライン対応済み}}を選択し、次に{{ui:もう一度保存(最新バージョンを取得)}}を選択します。 |
| 空き容量を取り戻したい | オフラインコピーは約6 MBです。 | {{ui:オフライン対応済み}}を選択し、次に{{ui:オフライン用コピーを削除}}を選択します。 |

[オフラインでの作業](common:offline)を参照してください。

## それでも解決しない場合

アプリが応答しなくなった場合は、ページを再読み込みしてください。保存していない拾い出しは、再読み込みすると失われます。可能であれば、先に{{key:Mod+S}}で保存してください。ブラウザーに関する質問は[ブラウザーとコンピューター](common:browsers)を参照してください。

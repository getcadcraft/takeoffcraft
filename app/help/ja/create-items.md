**項目**とは、測定して金額を付けるものの1つです。壁の種類、床仕上げ、天井、ドア、照明器具などが該当します。描いたマークはすべて項目に属します。他のプログラムでは、これを条件と呼ぶこともあります。

各項目には種類があり、他の種類のマークも持てます（[1つの項目に複数の種類のマーク](topic:create-items#one-item-several-kinds-of-marks)を参照）。次の表のとおりです。

| 種類 | 描くもの | 報告する値 | 単位 |
|---|---|---|---|
| 長さ | 連続した点の並び | 長さ、並びの数、高さがある場合は壁面積 | LF または m |
| 面積 | 切り抜きのある閉じた輪郭 | 面積、周長、面の数 | SF、SY、SQ、ac、ha または m² |
| 個数 | 1つにつき1クリック | 数 | EA |
| 入力数量 | なし。数量を入力します | 入力した数（またはCivilCraftから取り込んだ数） | LS、EA、CY、m³、lb、TON、kg、t、LF、m、SF、SY、SQ、ac、ha、m² |

## 入力数量（図面なし）

見積の中には、図面に描かれないものがあります。動員費、許可、予備費、一式の下請け、CivilCraftで算出した切土と盛土などです。これらは**入力数量**にします。

1. {{ui:新しい項目}}を選択し、名前を入力して、{{ui:入力数量（図面なし）}}を選び、{{ui:追加}}を選択します。
2. 項目編集画面で{{ui:単位}}を選びます（一式なら LS）。次に{{ui:数量}}を入力します: `1`、`2.5`、`1,250`。
3. ロスとレートは他の項目と同じように設定します。複合単価の計算式では、数量を表す `Q` を使います。例えば `ceil(Q / 12)` はトラックの積載回数になります。

入力数量はマークを持たず、見積が未完成になることもありません。拾い出しに入札範囲がある場合、項目編集画面には{{ui:入札範囲}}も表示されます。その場合、数量はそのマークと同じように、その範囲の代替案と合計に含まれます。他のアプリから取り込んだ数量には、その出所が書かれています。[土工と標高点](topic:earthwork#cut-and-fill-from-civilcraft)を参照してください。

## 項目を作成する

1. 右側の{{ui:項目}}パネルで、{{ui:新しい項目}}を選択します。
2. 名前を入力します。例: `Interior wall type A`、`Carpet tile`。
3. 種類を選びます: {{ui:長さ（延長）}}、{{ui:面積}}、{{ui:個数}}。
4. {{ui:追加}}を選択します（または{{key:Enter}}キーを押します）。
   項目が色付きで一覧に表示され、描画に使う項目になり、その項目の編集画面が一覧の下に開きます。ステータスバーに次に選ぶべきツールが表示されます。

フォーム内で{{key:Esc}}を押すと、項目を追加せずに閉じます。

:::tip
測定ツールを先に選んだ場合、TakeoffCraftは同じ種類の最後の項目を使うか、その種類を選んだ状態で{{ui:新しい項目}}フォームを開きます。
:::

## 描く項目を選ぶ

一覧の項目をクリックします。その項目が新しいマークの追加先になり、そのマークはすべてのシートで強調表示され、他の項目は薄くなります。開いているシートにその項目のマークがない場合、TakeoffCraftはマークがあるシートへ移動します。もう一度クリックすると強調表示は止まりますが、描く項目のままです。

{{ui:選択}}ツールでマークをクリックすると、そのマークの項目も現在の項目になります。

## 項目を設定する

項目編集画面（**項目: (名前)**）には次の欄があります。各欄は、欄から離れるか{{key:Enter}}を押したときに保存され、それぞれの変更は元に戻せます。

| 欄 | 内容 |
|---|---|
| {{ui:名前}} | 一覧、表、書き出しに表示されます。 |
| {{ui:入力}} | 長さ、面積、個数のいずれか。マークがある項目では変更できません（「マークのある項目は種類を保持します」）。 |
| {{ui:色}} | 画面およびマーク付きPDFでのマークの色。 |
| {{ui:単位}} | 数量の報告単位。長さは LF または m、面積は SF、SY、SQ、ac、ha または m²、個数は EA。 |
| {{ui:ほかにも計測}} | この項目が持てる他の種類のマーク。それぞれに単位があります。下記を参照。 |
| {{ui:高さ}}（長さ） | 壁の高さ。項目は壁面積（長さ×高さ）も報告します。BimCraftのモデルから来た並びには、ドアと窓が含まれます。それらは一度だけ差し引かれ、項目には総面積、開口部、正味面積が表示されます。BimCraftの拾い出しで測定方法を選んでいる場合、ここでも同じ方法で測定されます（注記に方法とその出所が記載され、数量積算士による未確認であることも書かれます）。方法はTakeoffCraftでは変更できません。壁種別から来たレンガまたはブロックとモルタルは、2つの構成要素になります: 発注する個数と、モルタルの体積です。 |
| {{ui:厚さ}}（面積） | 厚さまたは深さ。複合単価の計算式（例: コンクリート体積）で使われます。 |
| {{ui:ロス率%}} | 単価計算の前に数量に加算されます。10は数量×1.10を意味します。 |
| {{ui:材料 $/LF}} | 単位あたりの材料費。ラベルは単位に従います（$/SF、$/EA など）。 |
| {{ui:労務 $/LF}} | 単位あたりの労務費。 |
| {{ui:CSI番号}} | CSI MasterFormat番号（例: `09 21 16`、または部門だけの `09`）。ブックの「部門別」シートはこれで費用をまとめます。[トレードパック](topic:trade-packs)の項目には、すでに番号があります。 |

高さと厚さは、ヤードポンド法の単位ではフィートとインチ（`9'-0"`、`8' 6"`）または小数のフィート（`9`）を、メートル法の単位ではメートル（`2.7`、`2700 mm`）を入力します。レートは `12.50` や `$1,250` のように、小数点以下4桁まで入力できます。[長さ、レート、割合の入力](topic:entry-formats)を参照してください。

欄の下の**測定値**には、項目の計算式で使える合計が文字（記号）とともに表示されます。長さの項目では長さ（L）、並びの数（N）、壁面積（A）です。面積の項目では面積（A）、周長（P）、面の数（N）です。個数の項目では個数（N）です。

## 1つの項目に複数の種類のマーク

同じものでも複数の方法で測定することがあります。部屋には床（面積）、壁沿いの幅木（長さ）、ドア（個数）があります。3つの項目を作る代わりに、1つ作ります。

1. 主となる種類で項目を作ります。例: 面積の項目 `Room 101`。
2. その編集画面の{{ui:ほかにも計測}}で、{{ui:長さ}}、{{ui:個数}}のどちらか、または両方にチェックを付けます。それぞれの横に単位が付きます。
3. `Room 101` が現在の項目のとき、{{ui:面積}}で床を、{{ui:長さ}}で幅木を、{{ui:個数}}でドアを描けます。TakeoffCraftは別の項目を選ぶように求めません。

項目一覧にはすべての数量が表示されます（`50.00 SF + 2 EA`）。数量表では、項目の行に主な数量が表示され、その下に他の種類ごとの行が追加されます。例えば**Room 101 (count)**のように、それぞれ独自のロス率、材料費、労務費を持ちます。書き出し、シートごとの表、マーク付きPDFの凡例も同じように一覧表示されます。

主な種類の欄（高さや厚さ、勾配、控除面積、3D形状）は、その種類のマークだけに適用されます。面積の項目に対して描いた幅木は、平面に沿って単純に測定され、3Dでは平らに表示されます。複合単価の計算式では、主な種類の合計が使われます。

種類は、その種類のマークがない場合にだけチェックを外せます。マークを削除するか、**選択したマーク**で別の項目へ移動してから外してください。マークは、その種類を持つ任意の項目へ移動できます。

さらに下には{{ui:複合単価}}があります。スタッドや板材などの構成要素で、それぞれ独自の計算式とレートを持ちます。[複合単価と計算式](topic:assemblies)を参照してください。

一番下の{{ui:上へ移動}}と{{ui:下へ移動}}は、一覧と書き出しでの項目の位置を変えます。{{ui:項目を削除}}は、すべてのマークとともに項目を削除します（確認が表示され、元に戻せます）。

面積の項目には**勾配**（屋根面を斜面で測定: [屋根と勾配](topic:roofs-and-slopes)）と**控除面積**（マークが他の項目の面積から差し引かれます: [面積の計測](topic:measure-areas#back-outs-columns-shafts-and-openings-taken-out-of-several-items)）もあります。長さの項目には**傾斜**（水平、けらば、隅棟・谷）と、けらばと隅棟の場合は**勾配**があります。

## 表でのレート

{{ui:ロス率%}}、材料費、労務費のレートは、下部の{{ui:数量}}表（{{ui:項目別}}）に直接入力することもできます。編集画面と同じ設定です。

## 単価の計算方法

各項目と各複合単価の構成要素について次のとおりです。

1. **ロス込み** = 数量 × (1 + ロス率%)。
2. **材料費** = ロス込み × 材料単価（セント未満を四捨五入）。
3. **労務費** = ロス込み × 労務単価（セント未満を四捨五入）。
4. **合計** = 材料費 + 労務費。

{{ui:見積の合計}}は、すべての項目とすべての構成要素を加算します。項目は独自のレートと複合単価を同時に持てます。両方とも加算されるため、構成要素に費用がある場合は項目のレートを0のままにしてください。

## 班ごとの労務費

単位あたりの労務費レートではなく、班から労務費を算出することもできます。班が1時間あたりどれだけ仕上げるか、何人か、一人あたりの賃金はいくらか、を設定します。項目編集画面の{{ui:班ごとの労務費}}で、{{ui:班から労務費を算出}}にチェックを付け、次を入力します。

| 欄 | 例 |
|---|---|
| {{ui:生産性}} | `20` LF/時（項目の単位で、班全体の数値） |
| {{ui:班の人数}} | `2` 人 |
| {{ui:賃金 $/時（1人あたり）}} | `45` |

TakeoffCraftは、ロス込みの数量から次を算出します。

- **班時間** = 数量 ÷ 生産性（110 LF ÷ 20 = 5.5）、
- **人時** = 班時間 × 班の人数（11）、
- **班日数** = 班時間 ÷ 8（0.69）、
- **労務費** = 人時 × 賃金（$495.00）。

編集画面には結果と、その結果から得られるレート（$4.50/LF）が表示されます。項目の労務費レートは、編集画面と表のどちらでも読み取り専用になります。{{ui:数量}}表のヘッダーには、ジョブ全体の人時と班日数が追加されます。書き出しでは各班の時間が記載され、ブックでは労務費のセルが班に基づく計算式になります（`ROUND(F2/20*2*45,2)`）。単位あたりのレートに戻すには、チェックを外します。

## メートル法の項目

単位として m（長さ）または m²（面積）を選びます。数量、高さ、計算式の値はメートルで表されます。シートの縮尺は任意のプリセットまたは校正が使え、単位と縮尺は互いに独立しています。

## ការប៉ាន់ស្មាន (សន្លឹកការងារ XLSX និង CSV)

មួយជួរក្នុងមួយធាតុ បន្ទាប់ដោយមួយជួរសម្រាប់សមាសធាតុនីមួយៗនៃការផ្គុំរបស់វា (ចូលជួរ)។ បន្ទាប់មកជួរទទេមួយ និងផលសរុបការងារ។

| ជួរឈរ | មាតិកា | នៅក្នុង XLSX |
|---|---|---|
| A ធាតុ | ឈ្មោះធាតុ (ដិត) ឬឈ្មោះសមាសធាតុ (ចូលជួរ) | អត្ថបទ |
| B ប្រភេទ | Linear, Area, Count ឬ Component | អត្ថបទ |
| C ឯកតា | LF, m, SF, SY, m², EA ឬឯកតារបស់សមាសធាតុ | អត្ថបទ |
| D បរិមាណ | ផលសរុបដែលបានវាស់ ឬលទ្ធផលរូបមន្ត | លេខ |
| E % ខាតបង់ | ការខាតបង់ | ភាគរយ (0.10 = 10%) |
| F បរិមាណជាមួយការខាតបង់ | បរិមាណ × (1 + ការខាតបង់) | រូបមន្ត `D*(1+E)` |
| G សម្ភារៈក្នុងមួយឯកតា | អត្រាសម្ភារៈ | លេខ |
| H ពលកម្មក្នុងមួយឯកតា | អត្រាពលកម្ម | លេខ |
| I សម្ភារៈ | សម្ភារៈពង្រីក | រូបមន្ត `ROUND(F*G,2)` |
| J ពលកម្ម | ពលកម្មពង្រីក | រូបមន្ត `ROUND(F*H,2)` |
| K សរុប | សម្ភារៈ + ពលកម្ម | រូបមន្ត `I+J` |
| L កំណត់សម្គាល់ | រូបមន្តដែលបានប្រើ កំហុសរូបមន្ត សញ្ញានៅលើសន្លឹកគ្មានមាត្រដ្ឋាន ផ្ទៃជញ្ជាំង បរិមាត្រ | អត្ថបទ |

ជួរផលសរុបការងារ៖ `SUM` នៃជួរ I, J និង K លើគ្រប់ជួរខាងលើ ហើយ "Incomplete: see the notes above" នៅក្នុងកំណត់សម្គាល់ នៅពេលមានអ្វីមួយត្រូវបានទុកចោល។

ជួរដែលមានកំហុសរូបមន្តគ្មានបរិមាណ ឬចំនួនទឹកប្រាក់ទេ; កំណត់សម្គាល់របស់វាផ្ដល់កំហុស។ ជួរក្បាលត្រូវបានចាក់សោ។

នៅក្នុង CSV ជួរឈរដូចគ្នាមានតម្លៃធម្មតា % ខាតបង់ជាលេខភាគរយ (10 សម្រាប់ 10%) ហើយប្រាក់ជាដុល្លារដល់ទសភាគពីរខ្ទង់។ អត្ថបទដែលសៀវភៅគណនាអាចយកជារូបមន្ត (ចាប់ផ្ដើមដោយ `=`, `+`, `-` ឬ `@`) ទទួលបាន `'` នៅខាងមុខ ដើម្បីឱ្យវានៅជាអត្ថបទ។

| ធាតុ | ឈ្មោះធាតុ |
| បរិមាណ | បរិមាណរបស់ធាតុនោះនៅលើសន្លឹកនោះ ជាឯកតារបស់វា |
| ឯកតា | ឯកតារបស់ធាតុ |

## សញ្ញា (XLSX តែប៉ុណ្ណោះ)

មួយជួរក្នុងមួយសញ្ញា។

| ជួរឈរ | មាតិកា |
|---|---|
| សន្លឹក | ឈ្មោះសន្លឹក |
| ធាតុ | ឈ្មោះធាតុ |
| ប្រភេទ | Linear, Area ឬ Count |
| បរិមាណ | ប្រវែង ផ្ទៃសុទ្ធ ឬ 1 |
| ឯកតា | LF ឬ m; SF, SY ឬ m²; EA |
| ព័ត៌មានលម្អិត | Linear៖ ប្រវែងផ្នែក ផ្នែកដែលកាត់ចេញមានសញ្ញា "(deduct)" និង "deducts (length) of (length) drawn"។ Area៖ ផ្ទៃសរុប និងផ្ទៃកាត់ចេញនៅពេលមានការកាត់ចេញ និងបរិមាត្រ។ "Sheet has no scale" សម្រាប់សញ្ញាដែលគ្មានមាត្រដ្ឋាន។ |
| តំបន់ដេញថ្លៃ | មានតែនៅពេលការគណនាមានតំបន់ដេញថ្លៃ៖ ផ្ទៃរបស់សញ្ញា ឬ "No bid area" |

## តាមតំបន់ដេញថ្លៃ (XLSX តែប៉ុណ្ណោះ នៅពេលការគណនាមានតំបន់ដេញថ្លៃ)

| ជួរឈរ | អ្វី |
|---|---|
| តំបន់ដេញថ្លៃ | ឈ្មោះតំបន់ ឬ "No bid area" |
| ធាតុ | ធាតុ ឬសមាសធាតុចូលជួរនៅក្រោមវា |
| ឯកតា | ឯកតារបស់ធាតុ ឬសមាសធាតុ |
| បរិមាណ | វាស់នៅតំបន់នោះ (សមាសធាតុ៖ រូបមន្តលើផលសរុបរបស់តំបន់) |
| បរិមាណជាមួយការខាតបង់ | បរិមាណ × (1 + ការខាតបង់) |
| សម្ភារៈ, ពលកម្ម, សរុប | ពង្រីកដល់សេន ដូចនៅការប៉ាន់ស្មាន |
| កំណត់សម្គាល់ | រូបមន្ត កំហុស និងសញ្ញាគ្មានមាត្រដ្ឋាន ដូចនៅការប៉ាន់ស្មាន |

តំបន់នីមួយៗបញ្ចប់ដោយជួរ "(ឈ្មោះ) subtotal" ដែលចំណាយរបស់វាជារូបមន្ត `SUM` លើជួររបស់វា; ជួរចុងក្រោយ **All bid areas** បូកផលសរុបរងទាំងនោះ។ សន្លឹក **Marks** បន្ទាប់មានជួរឈរទីប្រាំពីរ **Bid area**។

| ជួរឈរ | មាតិកា |
|---|---|
| សន្លឹក | ឈ្មោះសន្លឹក |
| មាត្រដ្ឋាន | ឈ្មោះការកំណត់ជាមុន ឬមាត្រដ្ឋានដែលបានក្រិត ឬ "No scale" |

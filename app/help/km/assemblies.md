ការផ្គុំ**ធាតុ** របស់ធាតុមួយគឺជាបញ្ជីនៃ**គ្រឿង** ដែលនីមួយៗមានរូបមន្តបរិមាណ និងកាកសំណល់ និងអត្រារៀងៗខ្លួន។ រូបមន្តប្រើផលបូកដែលបានវាស់របស់ធាតុ ដូច្នេះការវាស់ជញ្ជាំងតែមួយ ផ្ដល់ឱ្យអ្នកនូវស្តង់ ផ្ទាំង និងក្ដារក្នុងពេលតែមួយ ហើយពួកវាកែប្រែនៅពេលអ្នកវាស់។

## អថេរដែលអ្នកអាចប្រើ

| ប្រភេទធាតុ | អថេរ |
|---|---|
| លីនេអ៊ែរ | `L` ប្រវែង, `H` កម្ពស់, `A` ផ្ទៃជញ្ជាំង (L × H), `N` ចំនួនខ្សែ |
| ផ្ទៃ | `A` ផ្ទៃ, `P` បរិវេណ (ខ្សែក្រៅ + ចន្លោះកាត់), `H` ជម្រៅ ឬកម្រាស់, `N` ចំនួនផ្ទៃ |
| ការរាប់ | `N` ចំនួន |

តម្លៃស្ថិតក្នុងឯកតារបស់ធាតុនោះផ្ទាល់៖ ហ្វីត និងហ្វីតការ៉េសម្រាប់ធាតុ LF និង SF, ម៉ែត្រ និងម៉ែត្រការ៉េសម្រាប់ធាតុ m និង m²។ សម្រាប់ធាតុ SY `A` គឺជាយ៉ាតការ៉េ ខណៈ `P` និង `H` នៅតែជាហ្វីត។

រូបមន្តប្រើ `+ - * /` (ឬ × ÷), វង់ក្រចក, លេខ, និងអនុគមន៍ `ceil`, `floor`, `round`, `min`, `max` និង `abs`។ ច្បាប់ពេញលេញនៅក្នុង [ភាសារូបមន្ត](topic:formulas)។

## ឧទាហរណ៍ធ្វើជាក់ស្ដែង៖ ជញ្ជាំងខាងក្នុង

សន្មតថាអ្នកបានវាស់ **ជញ្ជាំងខាងក្នុង ប្រភេទ A** ជាធាតុលីនេអ៊ែរ៖ 4 ខ្សែសរុប 120 LF ជាមួយ {{ui:Height}} កំណត់ `9'-0"`។ តម្លៃ **បានវាស់** បង្ហាញ L = 120, N = 4, A = 1,080 (SF នៃជញ្ជាំង, មុខមួយ)។

1. ជ្រើសរើសធាតុនៅក្រោម {{ui:Items}}។
2. នៅ {{ui:Assembly}} ជ្រើសរើស {{ui:Add component}}។
   គ្រឿងមួយឈ្មោះ "គ្រឿង" បង្ហាញឡើង ជាមួយរូបមន្ត `L` និងលទ្ធផលនៅខាងក្រោម។
3. វាយ `Studs 16 in o.c.` ក្នុង {{ui:Name}} និង `EA` ក្នុង {{ui:Unit}}។
4. ក្នុង {{ui:Quantity formula}} វាយ `ceil(L * 12 / 16) + N`។
   លទ្ធផលកែប្រែតាមការវាយ៖ "= 94 EA"។ នោះគឺស្តង់មួយរៀងរាល់ 16 អ៊ីញតាមបណ្ដោយ 120 ហ្វីត (90) បូកមួយបន្ថែមដើម្បីបិទខ្សែនីមួយៗក្នុង 4 ខ្សែ។
5. ចុច {{ui:Add component}} ម្ដងទៀតសម្រាប់ផ្ទាំង៖ ឈ្មោះ `Plates, top and bottom`, ឯកតា `LF`, រូបមន្ត `L * 2`។ លទ្ធផល៖ 240 LF។
6. បន្ថែមក្ដារ៖ ឈ្មោះ `Gypsum board 4x8, both sides`, ឯកតា `sheets`, រូបមន្ត `ceil(A * 2 / 32)`។ លទ្ធផល៖ 68 sheets (ក្ដារ 2,160 SF ÷ 32 SF ក្នុងមួយសន្លឹក = 67.5 បង្គត់ឡើង)។
7. បំពេញ {{ui:Waste %}}, {{ui:Material $}} និង {{ui:Labor $}} របស់គ្រឿងនីមួយៗ។
   គ្រឿងនីមួយៗមានជួរដេករៀងខ្លួនក្រោមធាតុក្នុង {{ui:Quantities}} គិតតម្លៃដូចធាតុ ហើយ {{ui:Job total}} រួមបញ្ចូលវា។

ប្រសិនបើថ្លៃជញ្ជាំងទាំងអស់នៅក្នុងគ្រឿង ទុកអត្រាសម្ភារៈ និងពលកម្មរបស់ធាតុឱ្យនៅ 0 បើមិនដូច្នេះវានឹងត្រូវបានគិតពីរដង។

:::tip
កាកសំណល់ត្រូវបានអនុវត្តបន្ទាប់ពីរូបមន្ត ហើយមិនត្រូវបានបង្គត់ទេ៖ ក្ដារ 68 សន្លឹកជាមួយកាកសំណល់ 10% គឺ 74.8 សន្លឹក។ ដើម្បីបញ្ជាទិញសន្លឹកពេញ ដាក់កាកសំណល់ក្នុងរូបមន្ត ដូចជា `ceil(A * 2 / 32 * 1.1)` ហើយទុកកាកសំណល់របស់គ្រឿងឱ្យនៅ 0។
:::

## រូបមន្តបន្ថែម

| អ្វី | ធាតុ | រូបមន្ត |
|---|---|---|
| ស្តង់ចម្ងាយ 24 in ពីផ្ចិត | លីនេអ៊ែរ | `ceil(L / 2) + N` |
| ក្រណាត់ការពារកម្ដៅ, SF | លីនេអ៊ែរមានកម្ពស់ | `A` |
| ថ្នាំលាប ទាំងពីរមុខ ជាកាឡុង ក្នុង 350 SF | លីនេអ៊ែរមានកម្ពស់ | `ceil(A * 2 / 350)` |
| ប្រអប់ក្បឿង 15 SF បន្ថែម 10% | ផ្ទៃ | `ceil(A * 1.1 / 15)` |
| ក្របខ័ណ្ឌមូលដ្ឋាន ឬគែម, LF | ផ្ទៃ | `P` |
| បេតុង, យ៉ាតគូប | ផ្ទៃមានជម្រៅ | `A * H / 27` |
| បេតុងបង្គត់ឡើងដល់មួយភាគបួនយ៉ាត | ផ្ទៃមានជម្រៅ | `ceil(A * H / 27 * 4) / 4` |
| ប៊ីស្ពានទ្វារ បីក្នុងមួយទ្វារ | ការរាប់ | `N * 3` |
| យ៉ាងតិចមួយប្រអប់ មួយក្នុងចំណោម 12 | ការរាប់ | `max(1, ceil(N / 12))` |

## នៅពេលរូបមន្តខុស

បន្ទាត់នៅក្រោមរូបមន្តប្រែទៅជាសារកំហុស ឧទាហរណ៍ `"X" is not a measured value here. Use L, H, A, N.` ឬ `A ")" is missing.` បន្ទាប់មកគ្រឿងនោះមិនមានចំនួនទេ ហើយជួររបស់វានៅ {{ui:Quantities}} បង្ហាញ "Formula error: …" ហើយក្បាលនិយាយថា "Incomplete: 1 formula error (not in the totals)"។ កែរូបមន្ត ហើយផលបូកនឹងកែប្រែ។

រូបមន្តដែលចែកនឹងសូន្យក៏ជាកំហុសដែរ ("The formula divides by zero.") ឧទាហរណ៍ `A / H` លើធាតុដែលគ្មានជម្រៅ។

## ដែនកំណត់

- រូបមន្តដំណើរការលើ**ផលបូក**របស់ធាតុ មិនមែនតាមខ្សែនីមួយៗទេ។ `ceil(L * 12 / 16) + N` បន្ថែមស្តង់មួយក្នុងមួយខ្សែ; នៅមិនទាន់មានការបង្គត់តាមខ្សែទេ។
- រូបមន្តអាចប្រើតែអថេររបស់ធាតុខ្លួនឯង មិនមែនរបស់ធាតុផ្សេងទេ។
- អតិបរមា 50 គ្រឿងក្នុងមួយធាតុ, 500 តួអក្សរក្នុងមួយរូបមន្ត។

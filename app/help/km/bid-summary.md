ការប៉ាន់ស្មានតម្លៃអ្វីដែលអ្នកបានវាស់។ **សេចក្ដីសង្ខេបការដេញថ្លៃ** បំលែងវាទៅជាតម្លៃ៖ វាបន្ថែមពន្ធលក់ ថ្លៃចំណាយលើស ប្រាក់ចំណេញ និងធានា ហើយបង្កើត**PDF សំណើ**ជាមួយការរួមបញ្ចូល និងការលើកចេញរបស់អ្នក។

បើកវាពី {{ui:Export}} › {{ui:Bid summary & proposal…}}។ អ្វីៗក្នុងវាត្រូវបានរក្សាទុកជាមួយការវាស់ ហើយការផ្លាស់ប្ដូរនីមួយៗអាចត្រឡប់វិញបាន។

## ការបន្ថែម

វាយភាគរយក្នុងមួយក្នុងចំណោមប្រាំ (ទុកផ្សេងទៀតនៅ 0)។ ពួកវាត្រូវបានគណនាតាមលំដាប់នេះ ដែលនីមួយៗលើអ្វីដែលនៅខាងលើវា៖

| បន្ទាត់ | គណនាជា |
|---|---|
| សម្ភារៈ, ពលកម្ម | សរុបការប៉ាន់ស្មាន (ការដេញថ្លៃមូលដ្ឋាននៅពេលការវាស់មាន[ជម្រើស](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts))។ |
| បន្ទុកពលកម្ម | % បន្ទុក × ពលកម្ម៖ ពន្ធបើក ធានារ៉ាប់រង និងអត្ថប្រយោជន៍លើប្រាក់ឈ្នួលរបស់ក្រុមការងាររបស់អ្នក។ |
| **ការចំណាយ** | សម្ភារៈ + ពលកម្ម + បន្ទុកពលកម្ម។ |
| ពន្ធលក់លើសម្ភារៈ | % ពន្ធ × សម្ភារៈ។ |
| ថ្លៃចំណាយលើស | % ថ្លៃចំណាយលើស × (ការចំណាយ + ពន្ធ)។ |
| ប្រាក់ចំណេញ | % ប្រាក់ចំណេញ × (ការចំណាយ + ពន្ធ + ថ្លៃចំណាយលើស)។ |
| ធានា | % ធានា × អ្វីៗទាំងអស់ខាងលើ។ |
| **ការដេញថ្លៃ** | ផលបូកនៃបន្ទាត់។ |

បន្ទាត់នីមួយៗត្រូវបានបង្គត់ទៅសេន។ សៀវភៅការងារបង្ហាញបន្ទាត់ដដែលនៅក្រោមសរុបនៃសន្លឹក Estimate ជាមួយរូបមន្តផ្ទាល់។ សេចក្ដីសង្ខេបកែប្រែតាមការវាយ៖ {{key:Enter}} យកភាគរយ។ ជម្រើសនីមួយៗបង្ហាញជាមួយការបន្ថែមដូចគ្នាលើការចំណាយរបស់វា ដូច្នេះម្ចាស់ឃើញថាការយកវាចេញពិតជាផ្លាស់ប្ដូរអ្វី។

## សំណើ

បំពេញអ្វីដែលសំណើគួរនិយាយ៖

- **គម្រោង** (ឈ្មោះការវាស់ នៅពេលទទេ), **ទៅ** (អតិថិជន) និង **ពី** (ក្រុមហ៊ុនរបស់អ្នក)។
- **រួមបញ្ចូល** និង **ការលើកចេញ**៖ មួយក្នុងមួយជួរ; សញ្ញាដាច់ ឬ bullet នៅខាងមុខគឺល្អ។
- **លក្ខខណ្ឌ**៖ អត្ថបទសេរី ដូចជា "មានសុពលភាព 30 ថ្ងៃ។"
- **បញ្ជីធាតុ និងបរិមាណ**៖ វិសាលភាព ធាតុម្ដងមួយ ជាមួយបរិមាណ និងគ្មានតម្លៃ។ ដកធីកសម្រាប់សំណើតម្លៃដុំមួយ។

ជ្រើសរើស {{ui:Proposal PDF}}។ PDF (`<takeoff> - proposal.pdf`) មានកាលបរិច្ឆេទ ប្លុកតម្លៃជាមួយការបន្ថែមនីមួយៗ និងការដេញថ្លៃ ជម្រើស វិសាលភាព រួមបញ្ចូល និងការលើកចេញ លក្ខខណ្ឌ និងបន្ទាត់សម្រាប់ចុះហត្ថលេខា និងកាលបរិច្ឆេទ។ ប្រសិនបើបរិមាណមួយចំនួនមិនអាចវាស់បាន (សន្លឹកគ្មានមាត្រដ្ឋាន) វានឹងនិយាយដូច្នេះនៅក្រោមតម្លៃ។

## នៅក្នុងការនាំចេញ

នៅពេលការវាស់មានសេចក្ដីសង្ខេបការដេញថ្លៃ CSV បញ្ចប់ដោយវា ហើយសៀវភៅការងារទទួលបានសន្លឹក **Bid summary** ជាមួយបន្ទាត់នីមួយៗ ភាគរយ និងចំនួនរបស់វា។ សូមមើល [នាំចេញការប៉ាន់ស្មាន](topic:export-estimate)។

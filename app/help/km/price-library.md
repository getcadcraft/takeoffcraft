**បណ្ណាល័យតម្លៃ** មានធាតុដែលអ្នកប្រើក្នុងការងារនីមួយៗ៖ ប្រភេទ ឯកតា កម្ពស់ ការខាតបង់ អត្រាសម្ភារៈ និងការងារ និងការផ្គុំរបស់វា។ វាត្រូវបានរក្សាទុកក្នុងកម្មវិធីរុករកនេះ ដាច់ពីការគណនាបរិមាណណាមួយ ដូច្នេះការគណនាបរិមាណទាំងអស់ដែលអ្នកបើកនៅទីនេះអាចប្រើវាបាន។

បើកវាជាមួយ {{ui:បណ្ណាល័យ}} នៅផ្នែកខាងលើនៃផ្ទាំង {{ui:ធាតុ}}។

## បំពេញបណ្ណាល័យ

- {{ui:នាំចូល CSV…}} អានសៀវភៅគណនាដែលបានរក្សាទុកជា CSV (សូមមើលជួរឈរខាងក្រោម)។ ធាតុដែលឈ្មោះ និងប្រភេទរបស់វាមានរួចក្នុងបណ្ណាល័យ ត្រូវបានជំនួស; ផ្សេងទៀតត្រូវបានបន្ថែម។ ជួរដែលមិនអាចអានត្រូវបានរំលង ហើយវាបញ្ជាក់ថាជួរណា និងមូលហេតុ។
- {{ui:បញ្ចូលធាតុនៃការគណនាបរិមាណនេះ}} ចម្លងធាតុទាំងអស់នៃការគណនាបរិមាណដែលបើកទៅក្នុងបណ្ណាល័យ ជាមួយអត្រា និងការផ្គុំរបស់វា (មិនមែនសញ្ញាសម្គាល់របស់វាទេ)។
- ការប៉ាន់ស្មានតម្លៃជា CSV ដែល TakeoffCraft នាំចេញ ([នាំចេញការប៉ាន់ស្មានតម្លៃ](topic:export-estimate)) នាំចូលដូចដែលវាស្ថិតនៅ៖ តម្លៃការងារចុងក្រោយ ផ្ដល់ដំណើរការសម្រាប់ការងារបន្ទាប់។

- {{ui:កញ្ចប់ជំនាញ…}} បន្ថែមការផ្គុំឥតគិតថ្លៃសម្រាប់ជំនាញ ដូចជាជញ្ជាំងថ្មមាត់ ថ្នាំងអគ្គិសនី ឬបេតុង ដោយគ្មានតម្លៃ។ សូមមើល [កញ្ចប់ជំនាញ](topic:trade-packs)។

{{ui:នាំចេញ CSV}} រក្សាទុកបណ្ណាល័យជា CSV ដើម្បីរក្សាច្បាប់ចម្លង ដើម្បីកែក្នុងសៀវភៅគណនា ឬដើម្បីផ្ដល់ឱ្យមិត្តរួមការងារ។ {{ui:សម្អាត}} លុបវាទាំងអស់ (ចុចពីរដង)។

:::note
បណ្ណាល័យរស់នៅក្នុងទំហំផ្ទុករបស់កម្មវិធីរុករកនេះ។ កម្មវិធីរុករកផ្សេង កុំព្យូទ័រផ្សេង ឬផ្ទាំងឯកជនមានបណ្ណាល័យរបស់ខ្លួន (ឬគ្មានសោះ)។ នាំចេញវាដើម្បីផ្លាស់ទី។
:::

## ប្រើវានៅក្នុងការគណនាបរិមាណ

- ធីកធាតុ (វាយក្នុង {{ui:ស្វែងរកក្នុងបណ្ណាល័យ}} ដើម្បីកាត់បញ្ជីឱ្យតូច) ហើយជ្រើសរើស {{ui:បញ្ចូលទៅការគណនាបរិមាណ}}។ ពួកវាត្រូវបានបន្ថែមជាមួយការផ្គុំរបស់វាក្នុងជំហានតែមួយ ដែល {{key:Mod+Z}} ត្រឡប់វិញបាន។ ឈ្មោះដែលមានរួចក្នុងការគណនាបរិមាណទទួលបានលេខ ដូចជា `Carpet (2)`។
- {{ui:ធ្វើបច្ចុប្បន្នភាពតម្លៃ}} ផ្ដល់ឱ្យធាតុនៃការគណនាបរិមាណនូវការខាតបង់ និងអត្រារបស់បណ្ណាល័យ សម្រាប់ធាតុនីមួយៗដែលឈ្មោះ និងប្រភេទត្រូវគ្នានឹងធាតុបណ្ណាល័យ ហើយដូចគ្នាសម្រាប់សមាសធាតុនៃការផ្គុំដែលមានឈ្មោះដូចគ្នា។ កម្ពស់ ឯកតា និងរូបមន្តនៅដដែល។ {{key:Mod+Z}} មួយដងដាក់តម្លៃចាស់ទាំងអស់មកវិញ។

## ជួរឈរ CSV

ជួរទីមួយដាក់ឈ្មោះជួរឈរ តាមលំដាប់ណាក៏បាន; ជួរឈរផ្សេងទៀតត្រូវបានមិនអើពើ។

| ជួរឈរ | អ្វីដែលដាក់ក្នុងនោះ |
|---|---|
| Item (ឬ Name) | ឈ្មោះធាតុ។ តម្រូវ។ |
| Type | Linear, Area ឬ Count (LF, SF និង EA ក៏ដំណើរការដែរ)។ ទុកទទេ ឯកតាកំណត់។ |
| Unit | LF ឬ m; SF, SY ឬ m²; EA។ ទទេ៖ ឯកតាធម្មតារបស់ប្រភេទនោះ។ |
| Waste % | `10` ឬ `10%`។ |
| Material per unit, Labor per unit | អត្រាដូចជា `2.10` ឬ `$1,250`។ |
| Height (ឬ Depth) | `9'-0"`, `9`, ឬ `2.7` សម្រាប់ឯកតាម៉ែទ្រ។ |
| Component, Formula | ជួរដែលមានឈ្មោះ Component (ឬប្រភេទ `Component`) ជាផ្នែកនៃការផ្គុំនៃធាតុដែលនៅខាងលើវា។ ឯកតា ការខាតបង់ និងអត្រារបស់វាជារបស់វាផ្ទាល់; រូបមន្តរបស់វាប្រើអក្សររបស់ធាតុ សូមមើល [ការផ្គុំ និងរូបមន្ត](topic:assemblies)។ |

សន្លឹកនីមួយៗមានមាត្រដ្ឋានផ្ទាល់របស់វា។ អ្នកកំណត់វា ឬអនុញ្ញាតឱ្យ TakeoffCraft អានវាពីអត្ថបទសន្លឹក (ខាងក្រោម) ហើយពិនិត្យវា។ រហូតដល់សន្លឹកមួយមានមាត្រដ្ឋាន {{ui:បន្ទាត់}}, {{ui:ផ្ទៃ}}, {{ui:រង្វង់}} និង {{ui:កាត់ចេញ}} មិនព្រមវាស់លើវាទេ។ {{ui:រាប់}} និង {{ui:រាប់ស្វ័យប្រវត្តិ}} ដំណើរការដោយគ្មានមាត្រដ្ឋាន។

បញ្ជីសន្លឹកបង្ហាញមាត្រដ្ឋាននីមួយៗ ឬ **គ្មានមាត្រដ្ឋាន**។ របារនៅក្រោមសន្លឹកដែលបើកនិយាយដូចគ្នា។

## ប្រើការកំណត់ជាមុន (នៅពេល PDF ត្រូវបានបោះពុម្ពទំហំពេញ)

1. បើកសន្លឹក។
2. បើកបញ្ជី {{ui:ការកំណត់ជាមុន}} នៅក្នុងក្រុម {{ui:មាត្រដ្ឋាន}}។
3. ជ្រើសរើសមាត្រដ្ឋានដែលបោះពុម្ពនៅលើគំនូរប្លង់ ឧទាហរណ៍ `1/8" = 1'-0"` នៅក្រោមស្ថាបត្យកម្ម។
   របារស្ថានភាពនិយាយថា "មាត្រដ្ឋានសម្រាប់សន្លឹកនេះ៖ 1/8" = 1'-0"។"
4. ពិនិត្យវា (ខាងក្រោម)។

ការកំណត់ជាមុនសន្មតថា PDF គឺជាទំហំក្រដាសពិតដែលគំនូរប្លង់ត្រូវបានធ្វើឡើងសម្រាប់។ បើនរណាម្នាក់បានធ្វើ PDF ជាមួយ "fit to page" ឬវាជាសំណុំទំហំកន្លះ ការកំណត់ជាមុននោះខុស។ ផ្ទុយទៅវិញសូមក្រិត។

បញ្ជីពេញលេញនៅក្នុង [ការកំណត់មាត្រដ្ឋានជាមុន](topic:scale-presets)។

## អានមាត្រដ្ឋានពីអត្ថបទសន្លឹក

គំនូរប្លង់ភាគច្រើនបញ្ជាក់មាត្រដ្ឋានរបស់ពួកវា៖ `SCALE: 1/4" = 1'-0"` នៅក្នុងប្លុកចំណងជើង `1:100` នៅក្រោមទិដ្ឋភាព។ TakeoffCraft អាចអានវា ហើយកំណត់សន្លឹកទាំងអស់ក្នុងពេលតែមួយ។

1. បើកបញ្ជី {{ui:ការកំណត់ជាមុន}} ហើយជ្រើសរើស {{ui:ពីអត្ថបទសន្លឹក…}} (នៅខាងលើ)។
2. បញ្ជីបង្ហាញសន្លឹកទាំងអស់៖ មាត្រដ្ឋានរបស់វាឥឡូវ និងអ្វីដែលអត្ថបទរបស់វានិយាយ — **និយាយថា 1/4" = 1'-0"**, **គ្មានមាត្រដ្ឋានក្នុងអត្ថបទរបស់វា** ឬ **និយាយថាមិនត្រូវធ្វើមាត្រដ្ឋាន** (NTS)។
3. សន្លឹកដែលគ្មានមាត្រដ្ឋាន ហើយនិយាយមួយត្រូវបានធីក។ ធីក ឬដកធីកណាមួយ ហើយបន្ទាប់មកជ្រើសរើស {{ui:កំណត់មាត្រដ្ឋានដែលបានធីក}}។ {{key:Mod+Z}} តែមួយមិនធ្វើវិញពួកវាទាំងអស់។
4. ពិនិត្យវិមាត្រមួយនៅលើសន្លឹកនីមួយៗជាមួយ {{ui:ពិនិត្យ}} (ខាងក្រោម)៖ ការកំណត់ជាមុនត្រឹមត្រូវតែនៅពេល PDF ត្រូវបានបោះពុម្ពទំហំពេញប៉ុណ្ណោះ។

វាអានសញ្ញាស្ថាបត្យកម្ម (`3/16" = 1'-0"`, `1 1/2" = 1'-0"`), វិស្វកម្ម (`1" = 20'`) និងម៉ែទ្រិក (`1:50`) ដែលត្រូវនឹង [ការកំណត់ជាមុន](topic:scale-presets)។ នៅពេលសន្លឹកនិយាយមាត្រដ្ឋានច្រើនជាងមួយ (គំនូរប្លង់ដែលមានព័ត៌មានលម្អិតពង្រីក) វាយកមួយដែលវានិយាយញឹកញាប់បំផុត ហើយមួយដែលសរសេរបន្ទាប់ពីពាក្យ SCALE រាប់ពីរដង; មាត្រដ្ឋានផ្សេងទៀតត្រូវបានបង្ហាញជាពណ៌ក្រហមដើម្បីឱ្យអ្នកពិនិត្យ។ សន្លឹកដែលស្កែនគ្មានអត្ថបទ; កំណត់មាត្រដ្ឋានរបស់វាដោយដៃ។

## ក្រិតលើវិមាត្រដែលស្គាល់

ប្រើនេះនៅពេលគ្មានមាត្រដ្ឋានដែលបោះពុម្ពដែលអ្នកជឿទុកចិត្ត សំណុំត្រូវបានប្ដូរទំហំ ឬសន្លឹកនិយាយថា "មិនត្រូវធ្វើមាត្រដ្ឋាន" ប៉ុន្តែមានវិមាត្រ។

1. បើកសន្លឹក ហើយពង្រីកលើវិមាត្រវែងមួយដែលអ្នកស្គាល់ ដូចជាចន្លោះបន្ទាត់ក្រឡាចត្រង្គ ឬវិមាត្រសរុបនៃអគារ។ កាន់តែវែង កាន់តែត្រឹមត្រូវ។
2. ជ្រើសរើស {{ui:ក្រិត}} នៅក្នុងក្រុម {{ui:មាត្រដ្ឋាន}} ឬចុច {{key:K}}។
3. ចុចចុងម្ខាងនៃវិមាត្រ។ ពង្រីកលើចុងនីមួយៗសម្រាប់ភាពជាក់លាក់; អ្នកអាចពង្រីក និងអូសទិដ្ឋភាពរវាងការចុច។
4. ចុចចុងម្ខាងទៀត។ សង្កត់ {{key:Shift}} ដើម្បីរក្សាបន្ទាត់នៅ 0°, 45° ឬ 90°។
   ប្រអប់ **ក្រិតសន្លឹកនេះ** បើក។
5. វាយចម្ងាយពិតនៅក្នុង **ចម្ងាយពិត** ឧទាហរណ៍ `24'-6 1/2"`, `24.5` (ហ្វីតទសភាគ), `30"` ឬ `7.5 m`។ សូមមើល [ការបញ្ចូលប្រវែង អត្រា និងភាគរយ](topic:entry-formats)។
6. ជ្រើសរើស {{ui:កំណត់មាត្រដ្ឋាន}}។
   របារស្ថានភាពបង្ហាញមាត្រដ្ឋានជា "1" = (n)'" ហើយនៅពេលវាស្ថិតក្នុង 0.5% នៃការកំណត់ជាមុន វាប្រាប់ថាមួយណា ឧទាហរណ៍ "ដែលត្រូវនឹង 1/4" = 1'-0" (ជ្រើសរើសការកំណត់ជាមុននោះសម្រាប់មាត្រដ្ឋានជាក់លាក់)"។
   TakeoffCraft ត្រឡប់ទៅឧបករណ៍ {{ui:ជ្រើសរើស}}។

នៅពេលការក្រិតត្រូវនឹងការកំណត់ជាមុន ការជ្រើសរើសការកំណត់ជាមុននោះផ្ដល់មាត្រដ្ឋានជាក់លាក់ ជំនួសឱ្យមាត្រដ្ឋានដែលអាស្រ័យលើកន្លែងដែលអ្នកបានចុច។

## ពិនិត្យមាត្រដ្ឋាន

ត្រូវពិនិត្យមាត្រដ្ឋានថ្មីលើវិមាត្រទីពីរជានិច្ច។

1. ជ្រើសរើស {{ui:ពិនិត្យ}} នៅក្នុងក្រុម {{ui:មាត្រដ្ឋាន}} ឬចុច {{key:D}}។
2. ចុចចុងទាំងពីរនៃវិមាត្រដែលបោះពុម្ពនៅលើគំនូរប្លង់។
   របារស្ថានភាពបង្ហាញ "ពិនិត្យ៖ 12'-6"" ជាមួយប្រវែងដូចគ្នាជាហ្វីតទសភាគ និងម៉ែត្រ ហើយបន្ទាត់ពិនិត្យនៅតែលើសន្លឹកជាមួយប្រវែងរបស់វា។
3. ប្រៀបធៀបវាជាមួយវិមាត្រដែលបោះពុម្ព។ បើវាខុស សូមក្រិតលើវិមាត្រដែលវែងជាង។

ចុច {{key:Esc}} ដើម្បីលុបបន្ទាត់ពិនិត្យ។

## ផ្លាស់ប្ដូរមាត្រដ្ឋាន

ជ្រើសរើសការកំណត់ជាមុនមួយទៀត ឬក្រិតម្ដងទៀត។ បើសន្លឹកមានការវាស់រួចហើយ TakeoffCraft នឹងសួរ **ផ្លាស់ប្ដូរមាត្រដ្ឋានសន្លឹកនេះឬ?** ហើយនិយាយថាតើការវាស់ប៉ុន្មានត្រូវវាស់ឡើងវិញ។ ជ្រើសរើស {{ui:ផ្លាស់ប្ដូរមាត្រដ្ឋាន}}។ បន្ទាត់ និងផ្ទៃនីមួយៗនៅលើសន្លឹកត្រូវបានវាស់ឡើងវិញតាមមាត្រដ្ឋានថ្មី។ អ្នកអាចមិនធ្វើវិញដោយ {{key:Mod+Z}}។

## ហេតុអ្វីសន្លឹកគ្មានមាត្រដ្ឋានមិនត្រូវបានរាប់ជាសូន្យ

សញ្ញាសម្គាល់នៅលើសន្លឹកគ្មានមាត្រដ្ឋានមិនមានប្រវែង ឬផ្ទៃពិតទេ។ TakeoffCraft មិនដែលរាប់វាជាសូន្យឡើយ ព្រោះវានឹងធ្វើឱ្យការប៉ាន់ស្មានរបស់អ្នកទាបពេកដោយស្ងៀមៗ។ ផ្ទុយទៅវិញ វា៖

- បង្ហាញ "+(n) គ្មានមាត្រដ្ឋាន" នៅក្បែរធាតុក្នុង {{ui:បរិមាណ}}
- បង្ហាញ "មិនពេញលេញ៖ (n) សញ្ញាសម្គាល់នៅលើសន្លឹកគ្មានមាត្រដ្ឋាន (មិនរាប់ក្នុងផលសរុប)" នៅក្បាលតារាង
- សរសេរចំនួននៅក្នុងជួរកំណត់សម្គាល់នៃការនាំចេញសៀវភៅបញ្ជី។

នេះអាចកើតឡើងនៅពេលអ្នកបើកគម្រោងដែលមាត្រដ្ឋានមិនដែលត្រូវបានកំណត់។ ផ្ដល់មាត្រដ្ឋានដល់សន្លឹក ហើយសញ្ញាសម្គាល់ត្រូវបានរាប់ភ្លាមៗ។ សញ្ញាសម្គាល់ការរាប់ត្រូវបានរាប់ជានិច្ច; ពួកវាមិនត្រូវការមាត្រដ្ឋានទេ។

## គន្លឹះ

- កំណត់មាត្រដ្ឋាននៅលើសន្លឹកទាំងអស់ដែលអ្នកនឹងវាស់មុនពេលចាប់ផ្ដើម។ ស្កេនបញ្ជីសន្លឹកសម្រាប់ **គ្មានមាត្រដ្ឋាន** ដើម្បីស្វែងរកសន្លឹកដែលនៅសល់ (ប្រអប់ស្វែងរកមើលឈ្មោះសន្លឹក មិនមែនមាត្រដ្ឋានទេ)។
- ព័ត៌មានលម្អិត និងប្លង់ពង្រីកនៅលើសន្លឹកដូចគ្នាច្រើនតែប្រើមាត្រដ្ឋានផ្សេង។ TakeoffCraft មានមាត្រដ្ឋានមួយក្នុងមួយសន្លឹក; សូមមើល [អ្វីដែលមិនទាន់បានសាងសង់](topic:not-built-yet)។
- គំនូរប្លង់ម៉ែទ្រិក៖ ជ្រើសរើសការកំណត់ជាមុនម៉ែទ្រិកដូចជា `1:100` ឬក្រិតជាមួយចម្ងាយម៉ែទ្រិកដូចជា `6000 mm`។

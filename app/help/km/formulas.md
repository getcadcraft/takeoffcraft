សមាសធាតុការផ្គុំទទួលបានបរិមាណពីរូបមន្ត។ រូបមន្តគឺជាកន្សោមនព្វន្ធតូចមួយលើតម្លៃដែលបានវាស់របស់ធាតុ។ សូមមើល [ការផ្គុំនិងរូបមន្ត](topic:assemblies) សម្រាប់ឧទាហរណ៍ដែលបានធ្វើរួច។

## អថេរ

| ប្រភេទធាតុ | អថេរ | មានន័យថា |
|---|---|---|
| Linear | `L` | ប្រវែងសរុប |
| Linear | `H` | កម្ពស់របស់ធាតុ |
| Linear | `A` | ផ្ទៃជញ្ជាំង L × H ដកចេញនូវបើកចំហនៃផ្នែកដែលមានវា (ការគណនាពី BimCraft)។ នៅពេលការគណនានោះដាក់ឈ្មោះវិធីសាស្ត្រវាស់ `A` ត្រូវបានវាស់ដោយវា៖ បើកចំហដែលមិនធំជាងទំហំតូចបំផុតនៃវិធីសាស្ត្រនៅតែស្ថិត ហើយអ្វីដែលវិធីសាស្ត្រកាត់ចេញត្រង់ចំណុចដែលជញ្ជាំងជួបគ្នា ត្រូវបានទុកចោល។ កំណត់សម្គាល់នៅក្រោមធាតុដាក់ឈ្មោះវិធីសាស្ត្រ |
| Linear | `N` | ចំនួនផ្នែក |
| Area | `A` | ផ្ទៃសុទ្ធសរុប (គែមដកផ្ទៃកាត់ចេញ) |
| Area | `P` | បរិមាត្រសរុប រួមទាំងគែមកាត់ចេញ |
| Area | `H` | ជម្រៅ ឬកម្រាស់របស់ធាតុ |
| Area | `N` | ចំនួនផ្ទៃ |
| Count | `N` | ចំនួន |

- អថេរជាឯកតារបស់ធាតុ៖ សូមមើល [ឯកតា](topic:units)។
- អក្សរធំនិងតូចដូចគ្នា៖ `l` គឺ `L`។
- មានតែអថេរនៃប្រភេទធាតុរបស់ខ្លួនប៉ុណ្ណោះដែលដំណើរការ។ `P` នៅលើធាតុ Linear ផ្ដល់ `"P" មិនមែនជាតម្លៃដែលបានវាស់នៅទីនេះទេ។ ប្រើ L, H, A, N.`
- កម្ពស់ ឬជម្រៅទទេគឺ 0។

## ប្រតិបត្តិករ

| សរសេរ | មានន័យថា |
|---|---|
| `+` | បូក |
| `-` ឬ `−` | ដក ឬតម្លៃអវិជ្ជមាន |
| `*` ឬ `×` | គុណ |
| `/` ឬ `÷` | ចែក |
| `( )` | ក្រុម |

គុណនិងចែកធ្វើមុនបូកនិងដក៖ `L * 2 + 4` គឺ (L × 2) + 4។ ប្រើវង់ក្រចកនៅពេលមិនច្បាស់។

លេខអាចមានទសភាគ (`1.333`, `.5`) និងនិទស្សន្ត (`1e3` = 1000)។ ដកឃ្លាត្រូវបានមិនអើពើ។

## អនុគមន៍

| អនុគមន៍ | លទ្ធផល | ឧទាហរណ៍ |
|---|---|---|
| `ceil(x)` | បង្គត់ឡើងទៅលេខគត់ | `ceil(67.5)` = 68 |
| `floor(x)` | បង្គត់ចុះទៅលេខគត់ | `floor(67.5)` = 67 |
| `round(x)` | បង្គត់ទៅលេខគត់ដែលជិតបំផុត ពាក់កណ្ដាលចេញពីសូន្យ | `round(2.5)` = 3 |
| `round(x, d)` | បង្គត់ទៅ d ខ្ទង់ទសភាគ (0 ដល់ 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | តម្លៃតូចបំផុត | `min(N, 10)` |
| `max(a, b, …)` | តម្លៃធំបំផុត | `max(1, ceil(N / 12))` |
| `abs(x)` | តម្លៃដោយគ្មានសញ្ញា | `abs(-3)` = 3 |

`ceil` និង `floor` មិនយកចិត្តទុកដាក់លើសំឡេងបង្គត់តូចៗរបស់កុំព្យូទ័រទេ ដូច្នេះតម្លៃដែលគួរតែពិតជា 1 មិនដែលត្រូវបានបង្គត់ឡើងទៅ 2 ឡើយ។

## កំហុស

រូបមន្តដែលមិនអាចអាន ឬគណនាបានបង្ហាញកំហុសរបស់វានៅក្រោមវាលនោះ ហើយសមាសធាតុនោះត្រូវបានលុបចេញពីផលសរុប (ក្បាល {{ui:Quantities}} និយាយថា "Incomplete")។ សារ៖

| សារ | ការកែ |
|---|---|
| វាយរូបមន្តដូចជា L ឬ ceil(L / 1.333) + 1។ | រូបមន្តទទេ។ ប្រើរូបមន្តមួយ។ |
| "X" មិនមែនជាតម្លៃដែលបានវាស់នៅទីនេះទេ។ ប្រើ … | ប្រើអថេរមួយក្នុងចំណោមអថេរដែលបានរាយ។ |
| "X" មិនមែនជាអនុគមន៍នៅទីនេះទេ។ ប្រើ ceil, floor, round, min, max, abs។ | ប្រើអនុគមន៍មួយក្នុងចំណោមអនុគមន៍ទាំងនោះ។ |
| "#" មិនត្រូវបានអនុញ្ញាតក្នុងរូបមន្តទេ។ | លុបតួអក្សរនោះ (ឯកតា `%` `$` និង `=` មិនត្រូវបានអនុញ្ញាត)។ |
| ខ្វះ ")" / មាន ")" ដោយគ្មាន "(" របស់វា។ | ធ្វើឱ្យវង់ក្រចកមានតុល្យភាព។ |
| ខ្វះតម្លៃមុន ")"។ | ដូចជា `max(1, )`៖ បំពេញតម្លៃ។ |
| រូបមន្តបញ្ចប់ឆាប់ពេក។ | ដូចជា `L *`៖ បញ្ចប់វា។ |
| "…" មិនរំពឹងទុក។ ខ្វះប្រតិបត្តិករឬ? | តម្លៃពីរនៅជាប់គ្នា ដូចជា `2L`៖ សរសេរ `2 * L`។ |
| ceil() យក 1 តម្លៃ។ | ផ្ដល់ចំនួនតម្លៃត្រឹមត្រូវដល់អនុគមន៍។ |
| round(x, digits) ត្រូវការខ្ទង់គត់ពី 0 ដល់ 10។ | ប្រើចំនួនគត់នៃខ្ទង់ទសភាគ។ |
| រូបមន្តចែកនឹងសូន្យ។ | ជាធម្មតា H គឺ 0៖ កំណត់កម្ពស់ ឬជម្រៅរបស់ធាតុ។ |
| រូបមន្តមិនផ្ដល់លេខ។ | លទ្ធផលធំពេកមិនអាចជាលេខបាន។ |
| រូបមន្តនោះវែងពេក (500 តួអក្សរអតិបរមា)។ | ធ្វើឱ្យវាខ្លី។ |

## ការការពារតាមការរចនា

រូបមន្តអាចធ្វើតែនព្វន្ធជាមួយអថេរ និងអនុគមន៍ខាងលើប៉ុណ្ណោះ។ វាមិនអាចដំណើរការកូដ ឬអានអ្វីផ្សេងទៀតបានទេ ដូច្នេះរូបមន្តក្នុងឯកសារគម្រោងដែលនរណាម្នាក់ផ្ញើមកអ្នកគឺមិនមានគ្រោះថ្នាក់។

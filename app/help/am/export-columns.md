## ግምት (XLSX ሉህ እና CSV)

ለእያንዳንዱ ዕቃ አንድ ረድፍ፣ ከዚያም ለእያንዳንዱ የስብስቡ ክፍል አንድ ረድፍ (ገብ ያለ)። ከዚያ ባዶ ረድፍ እና የሥራው ድምር።

| ዓምድ | ይዘቱ | በXLSX |
|---|---|---|
| A ዕቃ | የዕቃ ስም (ደፍቶ) ወይም የክፍል ስም (ገብ ያለ) | ጽሑፍ |
| B ዓይነት | መስመራዊ፣ ስፋት፣ ቆጠራ ወይም ክፍል | ጽሑፍ |
| C አሃድ | LF, m, SF, SY, m², EA ወይም የክፍሉ አሃድ | ጽሑፍ |
| D ብዛት | የተለካ ድምር ወይም የቀመር ውጤት | ቁጥር |
| E ብክነት % | ብክነት | መቶኛ (0.10 = 10%) |
| F ብዛት ከብክነት ጋር | ብዛት × (1 + ብክነት) | ቀመር `D*(1+E)` |
| G ቁሳቁስ በአንድ አሃድ | የቁሳቁስ ዋጋ | ቁጥር |
| H ጉልበት በአንድ አሃድ | የጉልበት ዋጋ | ቁጥር |
| I ቁሳቁስ | የተዘረጋ ቁሳቁስ | ቀመር `ROUND(F*G,2)` |
| J ጉልበት | የተዘረጋ ጉልበት | ቀመር `ROUND(F*H,2)` |
| K ድምር | ቁሳቁስ + ጉልበት | ቀመር `I+J` |
| L ማስታወሻዎች | ጥቅም ላይ የዋለ ቀመር፣ የቀመር ስህተት፣ ስኬል በሌላቸው ሉሆች ላይ ምልክቶች፣ የግድግዳ ስፋት፣ ዙሪያ | ጽሑፍ |

የሥራ ድምር ረድፍ፦ ከላይ ባሉት ረድፎች ሁሉ ላይ የI፣ J እና K ዓምዶች `SUM`፤ ማንኛውም ነገር ቢቀር በማስታወሻዎች ውስጥ "ያልተሟላ፡ ከላይ ያሉትን ማስታወሻዎች ይመልከቱ" ይላል።

የቀመር ስህተት ያለበት ረድፍ ብዛትም መጠንም የለውም፤ ማስታወሻው ስህተቱን ይሰጣል። የርዕስ ረድፉ ተቆልፏል።

በCSV ውስጥ ተመሳሳዩ ዓምዶች ተራ እሴቶችን ይይዛሉ፣ ብክነት % የመቶኛ ቁጥር ነው (10 ለ 10%)፣ ገንዘብም በዶላር ከሁለት አስርዮሾች ጋር ነው። ተመን ሉህ እንደ ቀመር ሊወስደው የሚችል ጽሑፍ (በ`=`፣ `+`፣ `-` ወይም `@` የሚጀምር) ጽሑፍ ሆኖ እንዲቀር ከፊቱ `'` ይጨመርበታል።

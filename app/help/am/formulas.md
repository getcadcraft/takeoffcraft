የስብስብ ክፍሎች ብዛታቸውን ከቀመር ያገኛሉ። ቀመር በዕቃው የተለኩ እሴቶች ላይ ያለ አጭር የሒሳብ አገላለጽ ነው። ለተሠሩ ምሳሌዎች [ስብስቦች እና ቀመሮች](topic:assemblies)ን ተመልከት።

## ተለዋዋጮች

| የዕቃ ዓይነት | ተለዋዋጭ | ትርጉም |
|---|---|---|
| መስመራዊ | `L` | አጠቃላይ ርዝመት |
| መስመራዊ | `H` | የዕቃው ቁመት |
| መስመራዊ | `A` | የግድግዳ ስፋት፣ L × H፣ ከሚይዙት ክፍሎች ክፍተቶች ሲቀነሱ (ከBimCraft የብዛት ልኬት)። የብዛት ልኬቱ የመለኪያ ዘዴ ሲሰይም፣ `A` በእሱ ይለካል፦ ከዘዴው ትንሹ መጠን የማይበልጡ ክፍተቶች ይቆያሉ፣ እና ዘዴው ግድግዳዎች በሚገናኙበት ቦታ የሚወስደው ይቀራል። ከዕቃው በታች ያለው ማስታወሻ ዘዴውን ይሰይማል |
| መስመራዊ | `N` | የክፍሎች ብዛት |
| ስፋት | `A` | አጠቃላይ የተጣራ ስፋት (ዝርዝሮች ሲቀነሱ የተቆረጡት) |
| ስፋት | `P` | አጠቃላይ ዙሪያ፣ የተቆረጡ ጠርዞችን ጨምሮ |
| ስፋት | `H` | የዕቃው ጥልቀት ወይም ውፍረት |
| ስፋት | `N` | የስፋቶች ብዛት |
| ቆጠራ | `N` | ቆጠራው |

- ተለዋዋጮች በዕቃው አሃዶች ናቸው፦ [አሃዶች](topic:units)ን ተመልከት።
- ትልቅ እና ትንሽ ፊደላት ተመሳሳይ ናቸው፦ `l` ማለት `L` ነው።
- የዕቃው የራሱ ዓይነት ተለዋዋጮች ብቻ ይሠራሉ። በመስመራዊ ዕቃ ላይ `P` ይሰጣል፦ `"P" እዚህ የተለካ እሴት አይደለም። L, H, A, N ተጠቀም።`
- ባዶ ቁመት ወይም ጥልቀት 0 ነው።

## ኦፕሬተሮች

| ጻፍ | ትርጉም |
|---|---|
| `+` | ደምር |
| `-` ወይም `−` | ቀንስ፣ ወይም አሉታዊ እሴት |
| `*` ወይም `×` | አባዛ |
| `/` ወይም `÷` | ክፈል |
| `( )` | አንድ ላይ አሰባስብ |

ማባዛት እና ማካፈል ከመደመር እና ከመቀነስ ይቀድማሉ፦ `L * 2 + 4` (L × 2) + 4 ነው። ጥርጣሬ ሲኖር ቅንፎችን ተጠቀም።

ቁጥሮች አስርዮሾች (`1.333`፣ `.5`) እና ኤክስፖነንት (`1e3` = 1000) ሊኖራቸው ይችላል። ክፍተቶች ችላ ይባላሉ።

## ተግባራት

| ተግባር | ውጤት | ምሳሌ |
|---|---|---|
| `ceil(x)` | ወደ ሙሉ ቁጥር ወደ ላይ ዙር | `ceil(67.5)` = 68 |
| `floor(x)` | ወደ ሙሉ ቁጥር ወደ ታች ዙር | `floor(67.5)` = 67 |
| `round(x)` | ወደ ቅርብ ሙሉ ቁጥር ዙር፣ ግማሾች ከዜሮ ራቅ ብለው | `round(2.5)` = 3 |
| `round(x, d)` | ወደ d አስርዮሾች ዙር (ከ0 እስከ 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | ትንሹ እሴት | `min(N, 10)` |
| `max(a, b, …)` | ትልቁ እሴት | `max(1, ceil(N / 12))` |
| `abs(x)` | እሴቱ ያለ ምልክቱ | `abs(-3)` = 3 |

`ceil` እና `floor` ጥቃቅን የኮምፒውተር ማዞሪያ ድምጽን ችላ ይላሉ፣ ስለዚህ በትክክል 1 መሆን ያለበት እሴት ወደ 2 በፍጹም አይዞርም።

## ስህተቶች

ሊነበብ ወይም ሊሰላ የማይችል ቀመር ስህተቱን ከመስኩ በታች ያሳያል፣ እና ክፍሉ ከድምሮቹ ይቀራል (የ{{ui:Quantities}} ርዕስ "ያልተሟላ" ይላል)። መልዕክቶች፦

| መልዕክት | ማስተካከያ |
|---|---|
| ቀመር ይተይቡ፣ ለምሳሌ L ወይም ceil(L / 1.333) + 1። | ቀመሩ ባዶ ነው። |
| `"X" እዚህ የተለካ እሴት አይደለም። … ተጠቀም።` | ከተዘረዘሩት ተለዋዋጮች አንዱን ተጠቀም። |
| `"X" እዚህ ተግባር አይደለም። ceil, floor, round, min, max, abs ተጠቀም።` | ከእነዚያ ተግባራት አንዱን ተጠቀም። |
| ቀመር ውስጥ `"#"` አይፈቀድም። | ያንን ቁምፊ አስወግድ (አሃዶች፣ `%`፣ `$` እና `=` አይፈቀዱም)። |
| `")"` ይጎድላል። / `"("` ያልያዘ `")"` አለ። | ቅንፎቹን አመጣጥን። |
| `")"` ከመምጣቱ በፊት እሴት ይጎድላል። | እንደ `max(1, )` ያለ፦ እሴቱን ሙላ። |
| ቀመሩ ገና ሳያልቅ ያበቃል። | እንደ `L *` ያለ፦ አጠናቅቀው። |
| ያልተጠበቀ `"…"`። ኦፕሬተር ይጎድላል? | ጎን ለጎን ሁለት እሴቶች፣ እንደ `2L`፦ `2 * L` ጻፍ። |
| `ceil()` 1 እሴት ይወስዳል። | ለተግባሩ ትክክለኛውን የእሴቶች ብዛት ስጠው። |
| `round(x, digits)` ከ0 እስከ 10 ሙሉ አሃዞች ያስፈልገዋል። | ሙሉ የአስርዮሽ ብዛት ተጠቀም። |
| ቀመሩ በዜሮ ይካፈላል። | ብዙ ጊዜ H 0 ነው፦ የዕቃውን ቁመት ወይም ጥልቀት አዘጋጅ። |
| ቀመሩ ቁጥር አይሰጥም። | ውጤቱ ለቁጥር በጣም ትልቅ ነው። |
| ያ ቀመር በጣም ረጅም ነው (ከፍተኛው 500 ቁምፊ)። | አሳጥረው። |

## በንድፉ ደህንነቱ የተጠበቀ

ቀመር ከላይ ባሉት ተለዋዋጮች እና ተግባራት ብቻ ሒሳብ ማድረግ ይችላል። ኮድ ማስኬድ ወይም ሌላ ማንበብ አይችልም፣ ስለዚህ አንድ ሰው የሚልክልህ የፕሮጀክት ፋይል ውስጥ ያለ ቀመር ጎጂ አይደለም።

ከ{{ui:Export}} › {{ui:Bid summary & proposal…}} ይክፈቱት። በውስጡ ያለው ሁሉ ከመለካቱ ጋር ይቀመጣል፣ እያንዳንዱ ለውጥ ሊቀለበስ ይችላል።

## ጭማሪዎች

ከአምስቱ በማንኛውም ውስጥ በመቶ ይጻፉ (ሌሎቹን በ0 ይተዉ)። የሚሰሉት በዚህ ቅደም ተከተል ነው፣ እያንዳንዱ ከበላዩ ባለው ላይ፦

| መስመር | እንዴት ይሰላል |
|---|---|
| ቁሳቁስ፣ ጉልበት | የግምቱ ድምሮች (መለካቱ [አማራጮች](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) ካሉት መሠረታዊ ጨረታ)። |
| የጉልበት ሸክም | የሸክም % × ጉልበት፦ በሠራተኞቻችሁ ደመወዝ ላይ ያሉ የግብር፣ የኢንሹራንስና የጥቅማጥቅም ክፍያዎች። |
| **ወጪ** | ቁሳቁስ + ጉልበት + የጉልበት ሸክም። |
| በቁሳቁስ ላይ የሽያጭ ግብር | የግብር % × ቁሳቁስ። |
| ኦቨርሄድ | ኦቨርሄድ % × (ወጪ + ግብር)። |
| ትርፍ | ትርፍ % × (ወጪ + ግብር + ኦቨርሄድ)። |
| ቦንድ | ቦንድ % × ከላይ ያለው ሁሉ። |
| **ጨረታ** | የመስመሮቹ ድምር። |

እያንዳንዱ መስመር ወደ ሳንቲም ይጠጋጋል። የስራ መጽሐፉ ተመሳሳይ መስመሮችን ከEstimate ሉህ ድምር በታች በቀጥታ ቀመሮች ያሳያል። ማጠቃለያው እየጻፉ ይዘምናል፤ {{key:Enter}} መቶኛውን ይወስዳል። እያንዳንዱ አማራጭ በራሱ ወጪ ላይ ተመሳሳይ ጭማሪዎች ይታያሉ፣ ባለቤቱ መውሰዱ በትክክል ምን እንደሚቀይር እንዲያይ።

## ሐሳቡ

ሐሳቡ ምን ማለት እንዳለበት ይሙሉ፦

- **ፕሮጀክት** (ባዶ ከሆነ የመለካቱ ስም)፣ **ለ** (ደንበኛው) እና **ከ** (ኩባንያዎ)።
- **የተካተቱ** እና **ያልተካተቱ**፦ በአንድ መስመር አንድ፤ መሪ ሰረዝ ወይም ነጥብ ምንም አይጎዳም።
- **ውሎች**፦ ነጻ ጽሑፍ፣ ለምሳሌ "ለ30 ቀናት የሚያገለግል።"
- **ንጥሎቹንና ብዛቶቹን ዘርዝር**፦ ወሰኑ፣ ንጥል በንጥል ከብዛቶቹ ጋር፣ ዋጋ የለሽ። ለጠቅላላ ዋጋ ሐሳብ ምልክቱን ያንሱ።

{{ui:Proposal PDF}} ይምረጡ። PDF (`<takeoff> - proposal.pdf`) ቀኑን፣ እያንዳንዱ ጭማሪ ያለበትን የዋጋ ብሎክና ጨረታውን፣ አማራጮቹን፣ ወሰኑን፣ ያካተተውንና ያላካተተውን፣ ውሎቹን፣ እና የሚፈረሙበትና ቀን የሚጻፉባቸውን መስመሮች ይይዛል። አንዳንድ ብዛቶች ሊለኩ ካልቻሉ (ልኬት የሌለው ሉህ)፣ ከዋጋው በታች ይናገራል።

## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນຮູ້

ວິທີໃຫ້ຜູ້ຊ່ວຍ AI (ຫຼື ສະຄຣິບທີ່ທ່ານຂຽນເອງ) ເຮັດວຽກກັບ TakeoffCraft ແລະ ວິທີຕັດສິນໃຈວ່າມັນສາມາດແຕະຕ້ອງຫຍັງໄດ້ແດ່.

TakeoffCraft **ບໍ່ມີ AI ຂອງຕົນເອງ** ແລະ ບໍ່ສົ່ງຫຍັງໄປບ່ອນໃດເລີຍ. ທ່ານນຳຜູ້ຊ່ວຍມາເອງ: ໂປຣແກຣມໃດກໍໄດ້ທີ່ໃຊ້ Model Context Protocol (MCP) ໄດ້. TakeoffCraft ພຽງແຕ່ໃຫ້ເຄື່ອງມືແກ່ມັນ ແລະ ທ່ານເປັນຜູ້ເລືອກວ່າຈະໃຫ້ເຄື່ອງມືໃດແດ່.

## ເປີດໃຊ້

1. ເປີດ {{ui:Settings}} (ໄອຄອນເຟືອງໃນແຖບແອັບ, ຫຼື {{key:Mod+,}}) ແລ້ວໄປທີ່ແຖບ {{ui:TakeoffCraft}}.
2. ພາຍໃຕ້ {{ui:Assistants}}, ໃຫ້ໝາຍ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະ ສະຄຣິບໃຊ້ TakeoffCraft**. ມັນປິດຢູ່ຈົນກວ່າທ່ານຈະເປີດ.
3. ເລືອກສິ່ງທີ່ມັນສາມາດເຮັດໄດ້: **ອ່ານ** ຖືກໝາຍໄວ້ຕັ້ງແຕ່ເລີ່ມຕົ້ນ; ໝາຍ **ແກ້ໄຂ**, **ບັນທຶກ** ຫຼື **ສົ່ງອອກ** ພຽງແຕ່ເມື່ອທ່ານຕ້ອງການ.

ເຄື່ອງມືທີ່ຢູ່ນອກສິດອະນຸຍາດທີ່ທ່ານໝາຍໄວ້ຈະບໍ່ຖືກສະເໜີໃຫ້ຜູ້ຊ່ວຍ, ແລະ ຖ້າມັນຂໍໃຊ້ເຄື່ອງມືນັ້ນຢ່າງໃດກໍຕາມ, TakeoffCraft ຈະປະຕິເສດ ແລະ ບັນທຶກໄວ້ໃນບັນທຶກກິດຈະກຳ. ການປິດສະວິດຈະຕັດທຸກການເຊື່ອມຕໍ່ໃນທັນທີ; {{ui:Reset TakeoffCraft settings}} ກໍປິດມັນເຊັ່ນກັນ.

## ເຊື່ອມຕໍ່ຜູ້ຊ່ວຍຂອງທ່ານ

ຜູ້ຊ່ວຍເຊື່ອມຕໍ່ຜ່ານ **CadCraft Studio** ໃນຄອມພິວເຕີຂອງທ່ານ: Studio ເປີດເຊີບເວີນ້ອຍໆ ທີ່ມີແຕ່ຄອມພິວເຕີນີ້ເຂົ້າເຖິງໄດ້, ປ້ອງກັນດ້ວຍໂທເຄັນທີ່ມັນສ້າງຂຶ້ນທຸກຄັ້ງທີ່ເລີ່ມ. ໃນ Studio ໃຫ້ເລືອກ {{ui:Connect an assistant}} ແລ້ວຄັດລອກທີ່ຢູ່ ແລະ ໂທເຄັນໄປໃສ່ຜູ້ຊ່ວຍຂອງທ່ານ (Studio ຈະສະແດງການຕັ້ງຄ່າທີ່ແນ່ນອນໃຫ້ວາງ). ຢ່າແບ່ງປັນໂທເຄັນໃຫ້ໃຜເດັດຂາດ.

:::note
ໜ້າເບຣາວເຊີບໍ່ສາມາດເປີດການເຊື່ອມຕໍ່ໃຫ້ຜູ້ຊ່ວຍໄດ້: ໃນແອັບເບຣາວເຊີ ສະວິດຈະບໍ່ມີຜົນເລີຍຈົນກວ່າທ່ານຈະໃຊ້ CadCraft Studio ໃນຄອມພິວເຕີຂອງທ່ານ.
:::

## ທ່ານຍັງຄວບຄຸມຢູ່

- **ທຸກການປ່ຽນແປງເປັນໜຶ່ງຂັ້ນຕອນຍ້ອນກັບ**, ມີປ້າຍຊື່ດ້ວຍຊື່ທີ່ຜູ້ຊ່ວຍນັ້ນໃຊ້ເອີ້ນມັນ (ຕົວຢ່າງ "ຜູ້ຊ່ວຍ: …"). {{key:Mod+Z}} ຍ້ອນກັບການປ່ຽນແປງຄັ້ງສຸດທ້າຍຂອງຜູ້ຊ່ວຍທັງໝົດ.
- **ທ່ານຮູ້ເມື່ອມີການເຊື່ອມຕໍ່.** ປຸ່ມໃນແຖບແອັບຈະສະແດງຊື່ຜູ້ຊ່ວຍໃນຂະນະທີ່ເຊື່ອມຕໍ່ຢູ່; ໃຫ້ຄລິກເພື່ອເບິ່ງວ່າມັນເຮັດຫຍັງໄດ້ແດ່, ຫຼື ເພື່ອ **ຕັດການເຊື່ອມຕໍ່**.
- **ກິດຈະກຳ.** {{ui:Settings}} › {{ui:TakeoffCraft}} › {{ui:Assistants}} › {{ui:Activity}} ລາຍການທຸກການເອີ້ນ: ເມື່ອໃດ, ເຄື່ອງມືໃດ, ສຳເລັດ ຫຼື ຖືກປະຕິເສດ. {{ui:Save the log}} ເກັບສຳເນົາໄວ້.

## ຜູ້ຊ່ວຍສາມາດຂໍຫຍັງໄດ້ແດ່

| ເຄື່ອງມື | ສິດອະນຸຍາດ | ມັນເຮັດຫຍັງ |
|---|---|---|
| `app_info`, `sheets_list` | ອ່ານ | ການຖອດປະລິມານທີ່ເປີດ, PDF ແລະ ແຜ່ນຂອງມັນ, ມາດຕາສ່ວນ ແລະ ເຄື່ອງໝາຍຂອງແຕ່ລະແຜ່ນ |
| `items_list` | ອ່ານ | ລາຍການພ້ອມຫົວໜ່ວຍ, ອັດຕາ ແລະ ສູດການປະກອບ |
| `takeoff_quantities` | ອ່ານ | ປະລິມານຕໍ່ລາຍການ ຫຼື ຕໍ່ແຜ່ນ; ເຄື່ອງໝາຍໃນແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນຈະຖືກລະບຸໄວ້, ບໍ່ເຄີຍນັບເປັນສູນ |
| `takeoff_estimate` | ອ່ານ | ການປະເມີນລາຄາທີ່ TakeoffCraft ຄຳນວນ, ພ້ອມຍອດລວມ |
| `takeoff_export` | ສົ່ງອອກ | ການສົ່ງອອກ CSV ຫຼື XLSX ຂອງ TakeoffCraft ເອງ |
| `items_add` | ແກ້ໄຂ | ເພີ່ມລາຍການພ້ອມຫົວໜ່ວຍ, ອັດຕາ ແລະ ຂອງເສຍ |
| `marks_add` | ແກ້ໄຂ | ວັດຄວາມຍາວ, ເນື້ອທີ່ ແລະ ນັບຈຳນວນໃນແຜ່ນ. ວັດຄວາມຍາວ ແລະ ເນື້ອທີ່ໄດ້ພຽງແຕ່ໃນແຜ່ນທີ່ມີມາດຕາສ່ວນ, ບໍ່ເຄີຍໃນແຜ່ນທີ່ບໍ່ມີ |
| `cad_sheets`, `cad_catalog`, `cad_count` | ອ່ານ | ໃນ DWG ຫຼື DXF ທີ່ທ່ານເປີດ: ແຜ່ນ ແລະ ມາດຕາສ່ວນຂອງມັນ, ສິ່ງທີ່ສາມາດນັບໄດ້ (ບລັອກ, ເລເຢີ ແລະ ປະເພດ, ຂໍ້ຄວາມ), ແລະ ການນັບທີ່ແນ່ນອນ, ຄືກັບທີ່ {{ui:CAD count}} ເຮັດ ([ນັບຈາກແບບແຕ້ມ](topic:count-from-a-drawing)) |
| `cad_count_add` | ແກ້ໄຂ | ນັບໃນແບບແຕ້ມ ແລະ ໃສ່ເຄື່ອງໝາຍການນັບໃສ່ແຕ່ລະວັດຖຸທີ່ພົບ, ໃນຂັ້ນຕອນດຽວ; ນັບອີກຄັ້ງຈະເພີ່ມສະເພາະສິ່ງທີ່ໃໝ່ເທົ່ານັ້ນ |
| `cad_measure` | ແກ້ໄຂ | ວັດລາຍການແບບເສັ້ນ ຫຼື ເນື້ອທີ່ຈາກເສັ້ນ, ເສັ້ນໂຄ້ງ, ໂພລີລາຍ ແລະ ແຮັດຂອງແບບແຕ້ມເອງ, ຄືກັບ {{ui:Measure drawing}} ເຮັດ ([ວັດຈາກແບບແຕ້ມ](topic:measure-from-a-drawing)); ໃຊ້ໄດ້ພຽງແຕ່ໃນແຜ່ນທີ່ມີມາດຕາສ່ວນ |
| `usd_export` | ສົ່ງອອກ | ເສັ້ນ, ເນື້ອທີ່ ແລະ ການນັບຂອງແຜ່ນທີ່ມີມາດຕາສ່ວນທີ່ວັດແລ້ວ ເປັນໂມເດລກວດ 3D ໃນ USD (`.usdz`, `.usda` ຫຼື `.usdc`), ຄືກັບ {{ui:USD package (.usdz)}} ໃນມຸມມອງກວດ 3D ຂຽນ ([ສົ່ງອອກມຸມມອງກວດ 3D ເປັນ USD](topic:usd)) |

ເມື່ອໝາຍ **ແກ້ໄຂ** ແລ້ວ, ຜູ້ຊ່ວຍຈະເພີ່ມລາຍການ ແລະ ເຄື່ອງໝາຍ (ແຕ່ລະການເອີ້ນເປັນໜຶ່ງຂັ້ນຕອນຍ້ອນກັບ); ມັນບໍ່ສາມາດຍ້າຍ, ປ່ຽນ ຫຼື ລຶບເຄື່ອງໝາຍທີ່ມີຢູ່ແລ້ວໄດ້.

ປະລິມານ ແລະ ການປະເມີນລາຄາແບບດຽວກັນນີ້ກໍມີໃຫ້ໂດຍບໍ່ຕ້ອງເປີດ TakeoffCraft ເຊັ່ນກັນ: ເຊີບເວີ CadCraft MCP ເປີດໄຟລ໌ `.takeoff.json` ໃນໂຟນເດີທີ່ທ່ານລະບຸ (`takeoff_open`, `takeoff_quantities`, `takeoff_estimate`, `takeoff_export`), ແລະ `cadcraft info Job.takeoff.json` ພິມອອກໃນບັນທັດຄຳສັ່ງ. ມັນຍັງເປີດ DWG ຫຼື DXF ເປັນການຖອດປະລິມານໃໝ່ໃນແຜ່ນຂອງມັນ (ປັບມາດຕາສ່ວນຈາກແບບແຕ້ມ ຄືກັບທີ່ TakeoffCraft ປັບ), ນັບ ແລະ ວັດໃນນັ້ນດ້ວຍເຄື່ອງມື `cad_*` ດຽວກັນ, ເພີ່ມລາຍການ ແລະ ບັນທຶກການຖອດປະລິມານ (`takeoff_save`); ຄຳສັ່ງ `cadcraft count plan.dwg --block SHELF-18X48 --sheet K-101` ນັບຈາກບັນທັດຄຳສັ່ງ.

## ຖ້າບາງຢ່າງບໍ່ເຮັດວຽກ

- **ຜູ້ຊ່ວຍບໍ່ເຫັນເຄື່ອງມືຂອງ TakeoffCraft:** ກວດວ່າສະວິດເປີດຢູ່ໃນໜ້າຕ່າງນີ້, ແລະ ໜ້າຕ່າງນີ້ເປີດຢູ່ໃນ Studio.
- **"needs the export permission":** ໝາຍ **ສົ່ງອອກ** ພາຍໃຕ້ {{ui:Assistants}}, ແລ້ວໃຫ້ຜູ້ຊ່ວຍຖາມອີກຄັ້ງ.

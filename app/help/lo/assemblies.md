ການປະກອບຂອງລາຍການ ແມ່ນລາຍຊື່ຂອງອົງປະກອບ, ແຕ່ລະອັນມີສູດປະລິມານ ແລະ ອັດຕາ **ເສຍເປົ່າ** ກັບອັດຕາລາຄາຂອງຕົນເອງ. ສູດໃຊ້ຜົນລວມທີ່ວັດໄດ້ຂອງລາຍການ, ສະນັ້ນການວັດຝາໜຶ່ງຄັ້ງໃຫ້ທ່ານທັງເສົາໂຄງ, ແຜ່ນຮອງ ແລະ ແຜ່ນບອດພ້ອມກັນ, ແລະ ຄ່າຈະອັບເດດເມື່ອທ່ານວັດເພີ່ມ.

## ຕົວແປທີ່ທ່ານໃຊ້ໄດ້

| ປະເພດລາຍການ | ຕົວແປ |
|---|---|
| ເສັ້ນ | `L` ຄວາມຍາວ, `H` ຄວາມສູງ, `A` ເນື້ອທີ່ຝາ (L × H), `N` ຈຳນວນເສັ້ນ |
| ເນື້ອທີ່ | `A` ເນື້ອທີ່, `P` ປະລິມາດຮອບ (ເສັ້ນຂອບ + ຊ່ອງຕັດ), `H` ຄວາມເລິກ ຫຼື ຄວາມໜາ, `N` ຈຳນວນເນື້ອທີ່ |
| ການນັບ | `N` ຈຳນວນ |

ຄ່າຕ່າງໆຢູ່ໃນຫົວໜ່ວຍຂອງລາຍການເອງ: feet ແລະ square feet ສຳລັບລາຍການ LF ແລະ SF, meters ແລະ square meters ສຳລັບລາຍການ m ແລະ m². ສຳລັບລາຍການ SY, `A` ເປັນ square yards ໃນຂະນະທີ່ `P` ແລະ `H` ຍັງເປັນ feet.

ສູດໃຊ້ `+ - * /` (ຫຼື × ÷), ວົງເລັບ, ຕົວເລກ, ແລະ ຟັງຊັນ `ceil`, `floor`, `round`, `min`, `max` ແລະ `abs`. ກົດລະບຽບເຕັມຢູ່ໃນ [ພາສາສູດ](topic:formulas).

## ຕົວຢ່າງ: ຝາພາຍໃນ

ສົມມຸດວ່າທ່ານໄດ້ຖອດປະລິມານ **ຝາພາຍໃນ ປະເພດ A** ເປັນລາຍການເສັ້ນ: 4 ເສັ້ນລວມ 120 LF, ໂດຍ {{ui:ຄວາມສູງ}} ຕັ້ງເປັນ `9'-0"`. ຄ່າທີ່ວັດໄດ້ອ່ານໄດ້ L = 120, N = 4, A = 1,080 (SF ຂອງຝາ, ດ້ານດຽວ).

1. ເລືອກລາຍການພາຍໃຕ້ {{ui:ລາຍການ}}.
2. ໃນ {{ui:ການປະກອບ}}, ເລືອກ {{ui:ເພີ່ມອົງປະກອບ}}.
   ອົງປະກອບຊື່ "Component" ປາກົດ, ພ້ອມສູດ `L` ແລະ ຜົນລັບຢູ່ລຸ່ມ.
3. ພິມ `Studs 16 in o.c.` ໃນ {{ui:ຊື່}} ແລະ `EA` ໃນ {{ui:ຫົວໜ່ວຍ}}.
4. ໃນ {{ui:ສູດປະລິມານ}}, ພິມ `ceil(L * 12 / 16) + N`.
   ຜົນລັບອັບເດດຕອນທ່ານພິມ: "= 94 EA". ນັ້ນແມ່ນໜຶ່ງເສົາໂຄງທຸກ 16 ນິ້ວຕາມ 120 ຟຸດ (90), ບວກອີກໜຶ່ງເພື່ອປິດແຕ່ລະເສັ້ນທັງ 4.
5. ເລືອກ {{ui:ເພີ່ມອົງປະກອບ}} ອີກຄັ້ງສຳລັບແຜ່ນຮອງ: ຕັ້ງຊື່ `Plates, top and bottom`, ຫົວໜ່ວຍ `LF`, ສູດ `L * 2`. ຜົນລັບ: 240 LF.
6. ເພີ່ມແຜ່ນບອດ: ຊື່ `Gypsum board 4x8, both sides`, ຫົວໜ່ວຍ `sheets`, ສູດ `ceil(A * 2 / 32)`. ຜົນລັບ: 68 sheets (2,160 SF ຂອງແຜ່ນບອດ ÷ 32 SF ຕໍ່ແຜ່ນ = 67.5, ປັດຂຶ້ນ).
7. ຕື່ມ {{ui:Waste %}}, {{ui:Material $}} ແລະ {{ui:Labor $}} ຂອງແຕ່ລະອົງປະກອບ.
   ແຕ່ລະອົງປະກອບໄດ້ແຖວຂອງຕົນເອງໃຕ້ລາຍການໃນ {{ui:ປະລິມານ}}, ຕີລາຄາເໝືອນລາຍການ, ແລະ {{ui:Job total}} ລວມມັນ.

ຖ້າຄ່າຝາທັງໝົດຢູ່ໃນອົງປະກອບ, ໃຫ້ປ່ອຍອັດຕາວັດສະດຸ ແລະ ແຮງງານຂອງລາຍການເອງເປັນ 0, ບໍ່ດັ່ງນັ້ນມັນຈະຖືກນັບສອງເທື່ອ.

:::tip
ການເສຍເປົ່າຖືກໃຊ້ຫຼັງສູດ ແລະ ບໍ່ຖືກປັດ: 68 sheets ທີ່ເສຍເປົ່າ 10% ແມ່ນ 74.8 sheets. ເພື່ອສັ່ງເປັນແຜ່ນເຕັມ, ໃຫ້ໃສ່ການເສຍເປົ່າໄວ້ໃນສູດ ເຊັ່ນ `ceil(A * 2 / 32 * 1.1)`, ແລະ ປ່ອຍການເສຍເປົ່າຂອງອົງປະກອບເປັນ 0.
:::

## ສູດເພີ່ມເຕີມ

| ສິ່ງທີ່ | ລາຍການ | ສູດ |
|---|---|---|
| ເສົາໂຄງທີ່ 24 ນິ້ວຈາກສູນກາງ | ເສັ້ນ | `ceil(L / 2) + N` |
| ແຜ່ນໃຍຫຸ້ມສນວນ, SF | ເສັ້ນທີ່ມີຄວາມສູງ | `A` |
| ສີ, ສອງດ້ານ, ແກລລອນທີ່ 350 SF | ເສັ້ນທີ່ມີຄວາມສູງ | `ceil(A * 2 / 350)` |
| ກ່ອງກະເບື້ອງທີ່ 15 SF, ເພີ່ມ 10% | ເນື້ອທີ່ | `ceil(A * 1.1 / 15)` |
| ຂອບຖານ ຫຼື ຂອບຂ້າງ, LF | ເນື້ອທີ່ | `P` |
| ຄອນກຣີດ, cubic yards | ເນື້ອທີ່ທີ່ມີຄວາມເລິກ | `A * H / 27` |
| ຄອນກຣີດປັດຂຶ້ນເປັນ ໜຶ່ງສ່ວນສີ່ຂອງ yard | ເນື້ອທີ່ທີ່ມີຄວາມເລິກ | `ceil(A * H / 27 * 4) / 4` |
| ບານພັບ, ສາມອັນຕໍ່ປະຕູ | ການນັບ | `N * 3` |
| ຢ່າງໜ້ອຍໜຶ່ງກ່ອງ, ໜຶ່ງກ່ອງຕໍ່ 12 | ການນັບ | `max(1, ceil(N / 12))` |

## ເມື່ອສູດຜິດ

ແຖວລຸ່ມສູດຈະກາຍເປັນຂໍ້ຄວາມຜິດພາດ, ຕົວຢ່າງ `"X" is not a measured value here. Use L, H, A, N.` ຫຼື `A ")" is missing.` ອົງປະກອບນັ້ນຈະບໍ່ມີຈຳນວນ, ແຖວຂອງມັນໃນ {{ui:ປະລິມານ}} ສະແດງ "Formula error: …", ແລະ ສ່ວນຫົວເວົ້າວ່າ "Incomplete: 1 formula error (not in the totals)". ແກ້ສູດ ແລະ ຍອດລວມຈະອັບເດດ.

ສູດທີ່ຫານດ້ວຍສູນກໍເປັນຂໍ້ຜິດພາດເຊັ່ນກັນ ("The formula divides by zero."), ຕົວຢ່າງ `A / H` ໃນລາຍການທີ່ບໍ່ມີຄວາມເລິກ.

## ຂໍ້ຈຳກັດ

- ສູດເຮັດວຽກກັບ**ຍອດລວມ**ຂອງລາຍການ, ບໍ່ແມ່ນເຮັດເສັ້ນຕໍ່ເສັ້ນ. `ceil(L * 12 / 16) + N` ເພີ່ມໜຶ່ງເສົາໂຄງຕໍ່ເສັ້ນ; ຍັງບໍ່ມີການປັດຕໍ່ເສັ້ນ.
- ສູດໃຊ້ໄດ້ສະເພາະຕົວແປຂອງລາຍການຂອງຕົນເອງ, ບໍ່ໃຊ້ຕົວແປຂອງລາຍການອື່ນໄດ້.
- ສູງສຸດ 50 ອົງປະກອບຕໍ່ລາຍການ, 500 ຕົວອັກສອນຕໍ່ສູດ.

## ລຶບອົງປະກອບ

ເລືອກ {{ui:ລຶບອົງປະກອບ}} ໃຕ້ມັນ. ທ່ານສາມາດຍ້ອນກັບດ້ວຍ {{key:Mod+Z}}.

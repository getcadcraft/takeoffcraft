ຊິ້ນສ່ວນຂອງແອດເຊມບລີໄດ້ປະລິມານຂອງມັນຈາກສູດ. ສູດເປັນການສະແດງອອກທາງເລກທີ່ສັ້ນໆ ເທິງຄ່າທີ່ວັດໄດ້ຂອງລາຍການ. ເບິ່ງ [ແອດເຊມບລີ ແລະ ສູດ](topic:assemblies) ສຳລັບຕົວຢ່າງທີ່ຄົບຖ້ວນ.

## ຕົວແປ

| ປະເພດລາຍການ | ຕົວແປ | ຄວາມໝາຍ |
|---|---|---|
| Linear | `L` | ຄວາມຍາວລວມ |
| Linear | `H` | ຄວາມສູງຂອງລາຍການ |
| Linear | `A` | ພື້ນທີ່ຝາ, L × H, ລົບຊ່ອງເປີດຂອງການວິ່ງທີ່ມີມັນ (ການຖອດປະລິມານຈາກ BimCraft). ເມື່ອການຖອດປະລິມານນັ້ນລະບຸວິທີການວັດ, `A` ຖືກວັດດ້ວຍວິທີນັ້ນ: ຊ່ອງເປີດທີ່ບໍ່ໃຫຍ່ກວ່າຂະໜາດນ້ອຍສຸດຂອງວິທີນັ້ນຈະຢູ່, ແລະ ສິ່ງທີ່ວິທີນັ້ນບໍ່ນັບຢູ່ບ່ອນທີ່ຝາມາພົບກັນຈະຖືກຕັດອອກ. ໝາຍເຫດໃຕ້ລາຍການບອກວິທີນັ້ນ |
| Linear | `N` | ຈຳນວນການວິ່ງ |
| Area | `A` | ພື້ນທີ່ສຸດທິລວມ (ຮູບຮ່າງນອກລົບພື້ນທີ່ຕັດອອກ) |
| Area | `P` | ເສັ້ນຮອບລວມ, ລວມທັງຂອບຂອງພື້ນທີ່ຕັດອອກ |
| Area | `H` | ຄວາມເລິກ ຫຼື ຄວາມໜາຂອງລາຍການ |
| Area | `N` | ຈຳນວນພື້ນທີ່ |
| Count | `N` | ຈຳນວນ |

- ຕົວແປຢູ່ໃນໜ່ວຍຂອງລາຍການ: ເບິ່ງ [ໜ່ວຍ](topic:units).
- ຕົວພິມໃຫຍ່ ແລະ ພິມນ້ອຍເໝືອນກັນ: `l` ແມ່ນ `L`.
- ມີພຽງຕົວແປຂອງປະເພດລາຍການຂອງມັນເອງທີ່ໃຊ້ໄດ້. `P` ໃນລາຍການ linear ໃຫ້ຂໍ້ຄວາມ `"P" is not a measured value here. Use L, H, A, N.`
- ຄວາມສູງ ຫຼື ຄວາມເລິກທີ່ວ່າງເປັນ 0.

## ຕົວດຳເນີນການ

| ຂຽນ | ຄວາມໝາຍ |
|---|---|
| `+` | ບວກ |
| `-` ຫຼື `−` | ລົບ, ຫຼື ຄ່າລົບ |
| `*` ຫຼື `×` | ຄູນ |
| `/` ຫຼື `÷` | ຫານ |
| `( )` | ຈັດກຸ່ມ |

ການຄູນ ແລະ ການຫານຄຳນວນກ່ອນການບວກ ແລະ ການລົບ: `L * 2 + 4` ແມ່ນ (L × 2) + 4. ໃຊ້ວົງເລັບເມື່ອບໍ່ແນ່ໃຈ.

ຕົວເລກອາດມີທົດສະນິຍົມ (`1.333`, `.5`) ແລະ ເລກຊີ້ກຳລັງ (`1e3` = 1000). ຊ່ອງວ່າງຖືກບໍ່ສົນໃຈ.

## ຟັງຊັນ

| ຟັງຊັນ | ຜົນລັບ | ຕົວຢ່າງ |
|---|---|---|
| `ceil(x)` | ປັດຂຶ້ນເປັນຈຳນວນເຕັມ | `ceil(67.5)` = 68 |
| `floor(x)` | ປັດລົງເປັນຈຳນວນເຕັມ | `floor(67.5)` = 67 |
| `round(x)` | ປັດເປັນຈຳນວນເຕັມທີ່ໃກ້ທີ່ສຸດ, ເຄິ່ງໜຶ່ງອອກຫ່າງຈາກສູນ | `round(2.5)` = 3 |
| `round(x, d)` | ປັດເປັນ d ຕຳແໜ່ງທົດສະນິຍົມ (0 ຫາ 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | ຄ່າທີ່ນ້ອຍທີ່ສຸດ | `min(N, 10)` |
| `max(a, b, …)` | ຄ່າທີ່ໃຫຍ່ທີ່ສຸດ | `max(1, ceil(N / 12))` |
| `abs(x)` | ຄ່າໂດຍບໍ່ມີເຄື່ອງໝາຍ | `abs(-3)` = 3 |

`ceil` ແລະ `floor` ບໍ່ສົນໃຈສຽງລົບກວນການປັດເລັກໆນ້ອຍໆຂອງຄອມພິວເຕີ, ສະນັ້ນຄ່າທີ່ຄວນເປັນ 1 ພໍດີຈະບໍ່ຖືກປັດຂຶ້ນເປັນ 2.

## ຂໍ້ຜິດພາດ

ສູດທີ່ອ່ານບໍ່ໄດ້ ຫຼື ຄຳນວນບໍ່ໄດ້ຈະສະແດງຂໍ້ຜິດພາດຢູ່ໃຕ້ຊ່ອງ, ແລະ ອົງປະກອບນັ້ນຖືກຕັດອອກຈາກຜົນລວມ (ສ່ວນຫົວ {{ui:Quantities}} ຂຽນວ່າ "Incomplete"). ຂໍ້ຄວາມ:

| ຂໍ້ຄວາມ | ແກ້ໄຂ |
|---|---|
| ພິມສູດ, ເຊັ່ນ L ຫຼື ceil(L / 1.333) + 1. | ສູດວ່າງ. |
| "X" ບໍ່ແມ່ນຄ່າທີ່ວັດໄດ້ທີ່ນີ້. ໃຊ້ … | ໃຊ້ໜຶ່ງໃນຕົວແປທີ່ລະບຸ. |
| "X" ບໍ່ແມ່ນຟັງຊັນທີ່ນີ້. ໃຊ້ ceil, floor, round, min, max, abs. | ໃຊ້ໜຶ່ງໃນຟັງຊັນເຫຼົ່ານັ້ນ. |
| "#" ບໍ່ອະນຸຍາດໃນສູດ. | ລຶບຕົວອັກສອນນັ້ນອອກ (ໜ່ວຍ, `%`, `$` ແລະ `=` ບໍ່ອະນຸຍາດ). |
| ຂາດ ")". / ມີ ")" ທີ່ບໍ່ມີ "(". | ເຮັດວົງເລັບໃຫ້ສົມດຸນ. |
| ຂາດຄ່າກ່ອນ ")". | ເຊັ່ນ `max(1, )`: ໃສ່ຄ່າ. |
| ສູດຈົບໄວເກີນໄປ. | ເຊັ່ນ `L *`: ຂຽນໃຫ້ຈົບ. |
| ບໍ່ຄາດຄິດ "…". ຂາດຕົວດຳເນີນການບໍ? | ສອງຄ່າຕິດກັນ, ເຊັ່ນ `2L`: ຂຽນ `2 * L`. |
| ceil() ຮັບ 1 ຄ່າ. | ໃຫ້ຟັງຊັນຈຳນວນຄ່າທີ່ຖືກຕ້ອງ. |
| round(x, digits) ຕ້ອງການຕົວເລກເຕັມ 0 ຫາ 10. | ໃຊ້ຈຳນວນຕຳແໜ່ງທົດສະນິຍົມເປັນຕົວເລກເຕັມ. |
| ສູດຫານດ້ວຍສູນ. | ປົກກະຕິ H ເປັນ 0: ຕັ້ງຄວາມສູງ ຫຼື ຄວາມເລິກຂອງລາຍການ. |
| ສູດບໍ່ໃຫ້ຜົນເປັນຕົວເລກ. | ຜົນໃຫຍ່ເກີນໄປທີ່ຈະເປັນຕົວເລກ. |
| ສູດນັ້ນຍາວເກີນໄປ (500 ຕົວອັກສອນສູງສຸດ). | ຫຍໍ້ມັນລົງ. |

## ປອດໄພໂດຍການອອກແບບ

ສູດສາມາດຄຳນວນເລກເທົ່ານັ້ນ ດ້ວຍຕົວແປ ແລະ ຟັງຊັນຂ້າງເທິງ. ມັນບໍ່ສາມາດລັນໂອ້ດ ຫຼື ອ່ານຫຍັງອື່ນ, ສະນັ້ນສູດໃນໄຟລ໌ໂຄງການທີ່ຜູ້ໃດຜູ້ໜຶ່ງສົ່ງໃຫ້ທ່ານກໍບໍ່ເປັນອັນຕະລາຍ.

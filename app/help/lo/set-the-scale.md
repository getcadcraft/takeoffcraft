ແຕ່ລະແຜ່ນມີມາດຕາສ່ວນຂອງຕົນເອງ. ທ່ານຕັ້ງມັນ, ຫຼື ໃຫ້ TakeoffCraft ອ່ານມັນຈາກຂໍ້ຄວາມຂອງແຜ່ນ (ຂ້າງລຸ່ມ), ແລ້ວກວດມັນ. ຈົນກວ່າແຜ່ນຈະມີມາດຕາສ່ວນ, {{ui:ເສັ້ນຕໍ່ເນື່ອງ}}, {{ui:ພື້ນທີ່}}, {{ui:ວົງມົນ}} ແລະ {{ui:ຕັດຮູ}} ຈະປະຕິເສດການວັດຢູ່ແຜ່ນນັ້ນ. {{ui:ນັບ}} ແລະ {{ui:ນັບອັດຕະໂນມັດ}} ເຮັດວຽກໄດ້ໂດຍບໍ່ມີມາດຕາສ່ວນ.

ລາຍຊື່ແຜ່ນສະແດງມາດຕາສ່ວນຂອງແຕ່ລະແຜ່ນ, ຫຼື **ບໍ່ມີມາດຕາສ່ວນ**. ແຖບໃຕ້ແຜ່ນທີ່ເປີດຢູ່ກໍບອກເຊັ່ນດຽວກັນ.

## ໃຊ້ຄ່າກຳນົດ (ເມື່ອ PDF ພິມໃນຂະໜາດເຕັມ)

1. ເປີດແຜ່ນ.
2. ເປີດລາຍການ {{ui:ຄ່າກຳນົດ}} ໃນກຸ່ມ {{ui:ມາດຕາສ່ວນ}}.
3. ເລືອກມາດຕາສ່ວນທີ່ພິມໄວ້ໃນແບບແຕ້ມ, ຕົວຢ່າງ `1/8" = 1'-0"` ພາຍໃຕ້ ສະຖາປັດຕະຍະກຳ.
   ແຖບສະຖານະຂຽນວ່າ "ມາດຕາສ່ວນສຳລັບແຜ່ນນີ້: 1/8" = 1'-0"."
4. ກວດມັນ (ຂ້າງລຸ່ມ).

ຄ່າກຳນົດສົມມຸດວ່າ PDF ແມ່ນຂະໜາດເຈ້ຍຈິງທີ່ແບບແຕ້ມຖືກເຮັດໄວ້. ຖ້າມີຄົນສ້າງ PDF ດ້ວຍ "ພໍດີໜ້າ", ຫຼື ມັນເປັນຊຸດເຄິ່ງໜຶ່ງ, ຄ່າກຳນົດຈະຜິດ. ໃຫ້ປັບແທນ.

ລາຍການເຕັມຢູ່ໃນ [ຄ່າກຳນົດມາດຕາສ່ວນ](topic:scale-presets).

## ອ່ານມາດຕາສ່ວນຈາກຂໍ້ຄວາມຂອງແຜ່ນ

ແບບແຕ້ມສ່ວນໃຫຍ່ບອກມາດຕາສ່ວນຂອງມັນ: `SCALE: 1/4" = 1'-0"` ໃນບລັອກຊື່ເລື່ອງ, `1:100` ໃຕ້ມຸມມອງ. TakeoffCraft ສາມາດອ່ານມັນ ແລະ ຕັ້ງທຸກແຜ່ນໃນເທື່ອດຽວ.

1. ເປີດລາຍການ {{ui:ຄ່າກຳນົດ}} ແລ້ວເລືອກ {{ui:ຈາກຂໍ້ຄວາມຂອງແຜ່ນ…}} (ຢູ່ເທິງສຸດ).
2. ລາຍການສະແດງທຸກແຜ່ນ: ມາດຕາສ່ວນຕອນນີ້, ແລະ ຂໍ້ຄວາມຂອງມັນບອກຫຍັງ — **ບອກ 1/4" = 1'-0"**, **ບໍ່ມີມາດຕາສ່ວນໃນຂໍ້ຄວາມ**, ຫຼື **ບອກວ່າຢ່າໃຊ້ມາດຕາສ່ວນ** (NTS).
3. ແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນແຕ່ມີຂໍ້ຄວາມບອກໄວ້ຈະຖືກໝາຍ. ໝາຍ ຫຼື ຍົກເລີກການໝາຍແຜ່ນໃດກໍໄດ້, ແລ້ວເລືອກ {{ui:ຕັ້ງມາດຕາສ່ວນທີ່ໝາຍແລ້ວ}}. {{key:Mod+Z}} ໜຶ່ງຄັ້ງຈະຍ້ອນກັບທັງໝົດ.
4. ກວດໜຶ່ງມິຕິໃນແຕ່ລະແຜ່ນດ້ວຍ {{ui:ກວດ}} (ຂ້າງລຸ່ມ): ຄ່າກຳນົດຈະຖືກຕ້ອງກໍຕໍ່ເມື່ອ PDF ພິມໃນຂະໜາດເຕັມເທົ່ານັ້ນ.

ມັນອ່ານໝາຍສະຖາປັດຕະຍະກຳ (`3/16" = 1'-0"`, `1 1/2" = 1'-0"`), ວິສະວະກຳ (`1" = 20'`) ແລະ ເມຕຣິກ (`1:50`) ທີ່ກົງກັບ [ຄ່າກຳນົດ](topic:scale-presets). ເມື່ອແຜ່ນບອກຫຼາຍກວ່າໜຶ່ງມາດຕາສ່ວນ (ແບບແຕ້ມທີ່ມີລາຍລະອຽດຂະຫຍາຍ), ມັນຈະເອົາອັນທີ່ບອກເລື້ອຍທີ່ສຸດ, ແລະ ອັນທີ່ຂຽນຫຼັງຄຳວ່າ SCALE ນັບເປັນສອງເທົ່າ; ອັນອື່ນຈະສະແດງເປັນສີແດງເພື່ອໃຫ້ທ່ານກວດ. ແຜ່ນສະແກນບໍ່ມີຂໍ້ຄວາມ: ໃຫ້ຕັ້ງມາດຕາສ່ວນດ້ວຍມື.

## ປັບໃສ່ມິຕິທີ່ຮູ້ແລ້ວ

ໃຊ້ເມື່ອບໍ່ມີມາດຕາສ່ວນທີ່ພິມໄວ້ທີ່ທ່ານເຊື່ອໄດ້, ຊຸດແບບແຕ້ມຖືກປັບຂະໜາດ, ຫຼື ແຜ່ນບອກວ່າ "ຢ່າໃຊ້ມາດຕາສ່ວນ" ແຕ່ມີມິຕິ.

1. ເປີດແຜ່ນ ແລະ ຊູມເຂົ້າໃສ່ມິຕິຍາວທີ່ທ່ານຮູ້, ເຊັ່ນ ໄລຍະເສັ້ນຕາຕະລາງ ຫຼື ມິຕິລວມຂອງອາຄານ. ຍິ່ງຍາວ ຍິ່ງແມ່ນຍຳ.
2. ເລືອກ {{ui:ປັບມາດຕາ}} ໃນກຸ່ມ {{ui:ມາດຕາສ່ວນ}}, ຫຼື ກົດ {{key:K}}.
3. ຄລິກປາຍດ້ານໜຶ່ງຂອງມິຕິ. ຊູມເຂົ້າໃສ່ແຕ່ລະປາຍເພື່ອຄວາມແມ່ນຍຳ; ທ່ານສາມາດຊູມ ແລະ ເລື່ອນມຸມມອງລະຫວ່າງການຄລິກ.
4. ຄລິກປາຍອີກດ້ານ. ກົດ {{key:Shift}} ເພື່ອໃຫ້ເສັ້ນຢູ່ທີ່ 0°, 45° ຫຼື 90°.
   ກ່ອງໂຕ້ຕອບ **ປັບແຜ່ນນີ້** ຈະເປີດຂຶ້ນ.
5. ພິມໄລຍະຈິງໃນ **ໄລຍະຈິງ**, ຕົວຢ່າງ `24'-6 1/2"`, `24.5` (ຟຸດທົດສະນິຍົມ), `30"` ຫຼື `7.5 m`. ເບິ່ງ [ການປ້ອນຄວາມຍາວ, ອັດຕາ ແລະ ເປີເຊັນ](topic:entry-formats).
6. ເລືອກ {{ui:ກຳນົດມາດຕາສ່ວນ}}.
   ແຖບສະຖານະສະແດງມາດຕາສ່ວນເປັນ "1" = (n)'", ແລະ ເມື່ອມັນຢູ່ພາຍໃນ 0.5% ຂອງຄ່າກຳນົດ, ມັນບອກວ່າກົງກັບອັນໃດ, ຕົວຢ່າງ "ເຊິ່ງກົງກັບ 1/4" = 1'-0" (ເລືອກຄ່າກຳນົດນັ້ນເພື່ອມາດຕາສ່ວນທີ່ແນ່ນອນ)".
   TakeoffCraft ກັບໄປເຄື່ອງມື {{ui:ເລືອກ}}.

ເມື່ອການປັບກົງກັບຄ່າກຳນົດ, ການເລືອກຄ່າກຳນົດນັ້ນຈະໃຫ້ມາດຕາສ່ວນທີ່ແນ່ນອນ ແທນທີ່ຈະເປັນອັນທີ່ຂຶ້ນກັບບ່ອນທີ່ທ່ານຄລິກ.

## ກວດມາດຕາສ່ວນ

ກວດມາດຕາສ່ວນໃໝ່ສະເໝີດ້ວຍມິຕິທີ່ສອງ.

1. ເລືອກ {{ui:ກວດ}} ໃນກຸ່ມ {{ui:ມາດຕາສ່ວນ}}, ຫຼື ກົດ {{key:D}}.
2. ຄລິກທັງສອງປາຍຂອງມິຕິທີ່ພິມໄວ້ໃນແບບແຕ້ມ.
   ແຖບສະຖານະສະແດງ "ກວດ: 12'-6"" ດ້ວຍຄວາມຍາວດຽວກັນເປັນຟຸດທົດສະນິຍົມ ແລະ ເມຕຣ, ແລະ ເສັ້ນກວດຍັງຢູ່ໃນແຜ່ນພ້ອມຄວາມຍາວຂອງມັນ.
3. ປຽບທຽບກັບມິຕິທີ່ພິມໄວ້. ຖ້າມັນບໍ່ກົງ, ໃຫ້ປັບໃສ່ມິຕິທີ່ຍາວກວ່າ.

ກົດ {{key:Esc}} ເພື່ອລຶບເສັ້ນກວດ.

## ປ່ຽນມາດຕາສ່ວນ

ເລືອກຄ່າກຳນົດອື່ນ ຫຼື ປັບອີກຄັ້ງ. ຖ້າແຜ່ນມີການວັດແລ້ວ, TakeoffCraft ຈະຖາມ **ປ່ຽນມາດຕາສ່ວນຂອງແຜ່ນນີ້ບໍ?** ແລະ ບອກວ່າຈະວັດໃໝ່ຈັກຄັ້ງ. ເລືອກ {{ui:ປ່ຽນມາດຕາສ່ວນ}}. ທຸກເສັ້ນ ແລະ ພື້ນທີ່ໃນແຜ່ນຈະຖືກວັດໃໝ່ດ້ວຍມາດຕາສ່ວນໃໝ່. ທ່ານສາມາດຍ້ອນກັບດ້ວຍ {{key:Mod+Z}}.

## ເປັນຫຍັງແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນຈຶ່ງບໍ່ນັບເປັນສູນ

ເຄື່ອງໝາຍໃນແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນບໍ່ມີຄວາມຍາວ ຫຼື ພື້ນທີ່ຈິງ. TakeoffCraft ບໍ່ເຄີຍນັບມັນເປັນສູນ, ເພາະມັນຈະເຮັດໃຫ້ການປະເມີນຂອງທ່ານຕ່ຳເກີນໄປໂດຍບໍ່ຮູ້ຕົວ. ແທນນັ້ນ ມັນຈະ:

- ເອົາເຄື່ອງໝາຍເຫຼົ່ານັ້ນອອກຈາກຍອດລວມ,
- ສະແດງ "+(n) unscaled" ຖັດຈາກລາຍການໃນ {{ui:ປະລິມານ}},
- ສະແດງ "ບໍ່ສົມບູນ: (n) ເຄື່ອງໝາຍໃນແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນ (ບໍ່ຢູ່ໃນຍອດລວມ)" ໃນຫົວຕາຕະລາງ,
- ຂຽນຈຳນວນລົງໃນຖັນໝາຍເຫດຂອງໄຟລ໌ສະເປຣດຊີດທີ່ສົ່ງອອກ.

ອັນນີ້ອາດເກີດຂຶ້ນເມື່ອທ່ານເປີດໂຄງການທີ່ບໍ່ເຄີຍຕັ້ງມາດຕາສ່ວນ. ໃຫ້ແຜ່ນມີມາດຕາສ່ວນ ແລະ ເຄື່ອງໝາຍຈະຖືກນັບທັນທີ. ເຄື່ອງໝາຍການນັບຈະຖືກນັບສະເໝີ; ມັນບໍ່ຕ້ອງການມາດຕາສ່ວນ.

## ເຄັດລັບ

- ຕັ້ງມາດຕາສ່ວນໃຫ້ທຸກແຜ່ນທີ່ທ່ານຈະວັດກ່ອນເລີ່ມ. ສະແກນລາຍຊື່ແຜ່ນຫາ **ບໍ່ມີມາດຕາສ່ວນ** ເພື່ອຊອກແຜ່ນທີ່ເຫຼືອ (ຊ່ອງຄົ້ນຫາເບິ່ງຊື່ແຜ່ນ, ບໍ່ແມ່ນມາດຕາສ່ວນ).
- ລາຍລະອຽດ ແລະ ແຜນຂະຫຍາຍໃນແຜ່ນດຽວກັນມັກໃຊ້ມາດຕາສ່ວນອື່ນ. TakeoffCraft ມີໜຶ່ງມາດຕາສ່ວນຕໍ່ແຜ່ນ; ເບິ່ງ [ສິ່ງທີ່ຍັງບໍ່ໄດ້ສ້າງ](topic:not-built-yet).
- ແບບແຕ້ມເມຕຣິກ: ເລືອກຄ່າກຳນົດເມຕຣິກເຊັ່ນ `1:100`, ຫຼື ປັບດ້ວຍມິຕິເມຕຣິກເຊັ່ນ `6000 mm`.

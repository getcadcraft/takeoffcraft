## ໜ່ວຍຂອງລາຍການ

| ປະເພດລາຍການ | ໜ່ວຍ | ຊື່ |
|---|---|---|
| ເສັ້ນຕໍ່ເນື່ອງ | LF | ຟຸດເສັ້ນຊື່ (ຄ່າເລີ່ມຕົ້ນ) |
| ເສັ້ນຕໍ່ເນື່ອງ | m | ແມັດ |
| ພື້ນທີ່ | SF | ຕາລາງຟຸດ (ຄ່າເລີ່ມຕົ້ນ) |
| ພື້ນທີ່ | SY | ຕາລາງຢາດ |
| ພື້ນທີ່ | SQ | ໜ່ວຍຫຼັງຄາ (100 ຕາລາງຟຸດ) |
| ພື້ນທີ່ | ac | ເອເຄີ |
| ພື້ນທີ່ | m² | ຕາລາງແມັດ |
| ພື້ນທີ່ | ha | ເຮັກຕາ |
| ນັບ | EA | ອັນ |

ປ່ຽນມັນດ້ວຍ {{ui:ຫົວໜ່ວຍ}} ໃນຕົວແກ້ໄຂລາຍການໄດ້ທຸກເວລາ, ເຖິງແມ່ນຫຼັງວັດແທກແລ້ວ; ປະລິມານຈະຖືກແປງທັນທີ. ລາຍການ {{ui:ຫົວໜ່ວຍ}} ສະແດງໜ່ວຍທີ່ເປີດໃນ {{ui:ການຕັ້ງຄ່າ}} › {{ui:ທົ່ວໄປ}} › {{ui:ໜ່ວຍ}}, ແລະ ສະເໝີໜ່ວຍຂອງລາຍການເອງ. ລາຍການໃໝ່ເລີ່ມໃນໜ່ວຍຄວາມຍາວ ຫຼື ພື້ນທີ່ທີ່ໝາຍດາວໄວ້ບ່ອນນັ້ນ, ເມື່ອມັນເປັນໜຶ່ງໃນໜ່ວຍຂອງລາຍການ; ຖ້າບໍ່ດັ່ງນັ້ນເລີ່ມໃນ LF ຫຼື SF. ເບິ່ງ [ໜ່ວຍ, ຄ່າທີ່ພິມ ແລະ ລາຍການໜ່ວຍ](common:unit-lists).

## ໜ່ວຍຂອງຕົວແປສູດ

| ໜ່ວຍລາຍການ | L, P, H | A |
|---|---|---|
| LF | ຟຸດ | ຕາລາງຟຸດ (ເນື້ອທີ່ຝາ) |
| m | ແມັດ | ຕາລາງແມັດ (ເນື້ອທີ່ຝາ) |
| SF | ຟຸດ | ຕາລາງຟຸດ |
| SY | ຟຸດ | ຕາລາງຢາດ |
| SQ | ຟຸດ | ໜ່ວຍຫຼັງຄາ |
| ac | ຟຸດ | ເອເຄີ |
| m² | ແມັດ | ຕາລາງແມັດ |
| ha | ແມັດ | ເຮັກຕາ |

ສຳລັບລາຍການ SY, `A` ເປັນຕາລາງຢາດ ໃນຂະນະທີ່ `P` ແລະ `H` ຍັງຄົງເປັນຟຸດ. ປະລິມານຈາກລາຍການ SY ແມ່ນ `A * 9 * H / 27` ລູກບາດຢາດ; ການໃຊ້ SF ສຳລັບແຜ່ນພື້ນງ່າຍກວ່າ.

## ບ່ອນທີ່ໜ່ວຍຖືກກຳນົດຕາຍຕົວ

ບາງການອ່ານຄ່າໃຊ້ຟຸດສະເໝີ:

- ຄ່າສົດໃນແຖບສະຖານະຂະນະແຕ້ມ (ຟຸດ-ນິ້ວ, SF),
- **ເຄື່ອງໝາຍທີ່ເລືອກ** (ຟຸດ-ນິ້ວ, LF ແລະ SF),
- ຜົນການກວດ (ຟຸດ-ນິ້ວ, ພ້ອມຟຸດທົດສະນິຍົມ ແລະ ແມັດ),
- ຄວາມຍາວຂອງສ່ວນ ແລະ ເສັ້ນຮອບ ໃນແຜ່ນ Marks ຂອງສະເປຣດຊີດ (ຟຸດ-ນິ້ວ).

ຜົນລວມລາຍການ, ຕາຕະລາງ {{ui:ປະລິມານ}}, ສູດ ແລະ ແຜ່ນ Estimate ໃຊ້ໜ່ວຍຂອງລາຍການເອງ.

## ມາດຕາສ່ວນ ແລະ ໜ່ວຍແຍກກັນ

ມາດຕາສ່ວນຂອງແຜ່ນບອກວ່າແບບແຕ້ມໃຫຍ່ປານໃດ; ໜ່ວຍຂອງລາຍການບອກວິທີລາຍງານມັນ. ແບບແຕ້ມແມັດ `1:100` ສາມາດຖອດປະລິມານເປັນ LF, ແລະ ແບບແຕ້ມອິມພີເຣຍລສາມາດເປັນ m². ການປັບມາດຕາຍອມຮັບທຸກໜ່ວຍ: `24'-6"`, `7.5 m`, `7500 mm`.

## ຄວາມແມ່ນຍຳ

TakeoffCraft ວັດແທກຢ່າງແນ່ນອນຈາກຈຸດທີ່ທ່ານກົດ, ລວມທັງຄວາມຍາວ ແລະ ເນື້ອທີ່ຂອງເສັ້ນໂຄ້ງຕົວຈິງ, ແລະ ບໍ່ປັດປະລິມານ. ການສະແດງປັດຄວາມຍາວເປັນ 1/16 ນິ້ວ ແລະ ທົດສະນິຍົມເປັນສອງຕຳແໜ່ງ. ເງິນຖືກປັດພຽງຕອນຈຳນວນເຕັມ, ເປັນສາຕາງ.

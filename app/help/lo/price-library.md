**ຄັງລາຄາ** ເກັບລາຍການທີ່ທ່ານໃຊ້ໃນທຸກວຽກ: ປະເພດ, ຫົວໜ່ວຍ, ຄວາມສູງ, ເສດເຫຼືອ, ອັດຕາວັດຖຸ ແລະ ແຮງງານ, ແລະ ການປະກອບຂອງມັນ. ມັນຖືກເກັບໄວ້ໃນບຣາວເຊີນີ້, ແຍກຈາກການຖອດປະລິມານໃດໆ, ດັ່ງນັ້ນທຸກການຖອດປະລິມານທີ່ທ່ານເປີດທີ່ນີ້ສາມາດໃຊ້ມັນໄດ້.

ເປີດມັນດ້ວຍ {{ui:Library}} ທີ່ດ້ານເທິງຂອງແຜງ {{ui:Items}}.

## ເຕີມຄັງ

- {{ui:Import CSV…}} ອ່ານສະເປຣດຊີດທີ່ບັນທຶກເປັນ CSV (ເບິ່ງຖັນຂ້າງລຸ່ມ). ລາຍການທີ່ມີຊື່ ແລະ ປະເພດຢູ່ໃນຄັງແລ້ວຈະຖືກແທນທີ່; ອັນອື່ນຖືກເພີ່ມ. ແຖວທີ່ອ່ານບໍ່ໄດ້ຈະຖືກຂ້າມ, ແລະ ມັນບອກວ່າແຖວໃດ ແລະ ເປັນຫຍັງ.
- {{ui:Add this takeoff's items}} ຄັດລອກທຸກລາຍການຂອງການຖອດປະລິມານທີ່ເປີດຢູ່ເຂົ້າຄັງ, ພ້ອມອັດຕາ ແລະ ການປະກອບຂອງມັນ (ບໍ່ລວມເຄື່ອງໝາຍ).
- ໄຟລ໌ປະເມີນລາຄາ CSV ທີ່ TakeoffCraft ສົ່ງອອກ ([ສົ່ງອອກການປະເມີນລາຄາ](topic:export-estimate)) ນຳເຂົ້າຕາມທີ່ມັນເປັນ: ລາຄາຂອງວຽກຄັ້ງສຸດທ້າຍກາຍເປັນຈຸດເລີ່ມຕົ້ນຂອງວຽກຕໍ່ໄປ.

- {{ui:Trade packs…}} ເພີ່ມການປະກອບຟຣີສຳລັບອາຊີບ, ເຊັ່ນ drywall, ໄຟຟ້າ ຫຼື ຄອນກຣີດ, ໂດຍບໍ່ມີລາຄາ. ເບິ່ງ [ແພັກເກດອາຊີບ](topic:trade-packs).

{{ui:Export CSV}} ບັນທຶກຄັງເປັນ CSV, ເພື່ອເກັບສຳເນົາ, ແກ້ໄຂໃນສະເປຣດຊີດ ຫຼື ໃຫ້ເພື່ອນຮ່ວມງານ. {{ui:Clear}} ລ້າງຄັງທັງໝົດ (ກົດສອງຄັ້ງ).

:::note
ຄັງຢູ່ໃນບ່ອນເກັບຂອງບຣາວເຊີນີ້. ບຣາວເຊີອື່ນ, ຄອມພິວເຕີອື່ນ ຫຼື ໜ້າຕ່າງສ່ວນຕົວ ມີຄັງຂອງຕົນເອງ (ຫຼື ບໍ່ມີເລີຍ). ສົ່ງອອກມັນເພື່ອຍ້າຍ.
:::

## ນຳໃຊ້ໃນການຖອດປະລິມານ

- ເລືອກລາຍການ (ພິມໃນ {{ui:Find in the library}} ເພື່ອຈຳກັດລາຍການ) ແລ້ວເລືອກ {{ui:Add to takeoff}}. ພວກມັນຖືກເພີ່ມພ້ອມການປະກອບໃນຂັ້ນຕອນດຽວທີ່ {{key:Mod+Z}} ສາມາດຍ້ອນກັບໄດ້. ຊື່ທີ່ມີຢູ່ໃນການຖອດປະລິມານແລ້ວຈະໄດ້ເລກ, ເຊັ່ນ `Carpet (2)`.
- {{ui:Update prices}} ໃຫ້ລາຍການຂອງການຖອດປະລິມານໄດ້ເສດເຫຼືອ ແລະ ອັດຕາຂອງຄັງ, ສຳລັບທຸກລາຍການທີ່ຊື່ ແລະ ປະເພດກົງກັບລາຍການໃນຄັງ, ແລະ ເຊັ່ນດຽວກັນກັບສ່ວນປະກອບການປະກອບທີ່ມີຊື່ຄືກັນ. ຄວາມສູງ, ຫົວໜ່ວຍ ແລະ ສູດຄົງເດີມ. ໜຶ່ງ {{key:Mod+Z}} ຈະເອົາລາຄາເກົ່າທັງໝົດກັບມາ.

## ຖັນ CSV

ແຖວທຳອິດຕັ້ງຊື່ຖັນ, ໃນລຳດັບໃດກໍໄດ້; ຖັນອື່ນຖືກລະເລີຍ.

| ຖັນ | ສິ່ງທີ່ໃສ່ໃນນັ້ນ |
|---|---|
| Item (or Name) | ຊື່ລາຍການ. ຈຳເປັນ. |
| Type | Linear, Area ຫຼື Count (LF, SF ແລະ EA ໃຊ້ໄດ້ເຊັ່ນກັນ). ຖ້າປ່ອຍວ່າງ, ຫົວໜ່ວຍເປັນຕົວຕັດສິນ. |
| Unit | LF ຫຼື m; SF, SY ຫຼື m²; EA. ວ່າງ: ຫົວໜ່ວຍປົກກະຕິຂອງປະເພດ. |
| Waste % | `10` ຫຼື `10%`. |
| Material per unit, Labor per unit | ອັດຕາເຊັ່ນ `2.10` ຫຼື `$1,250`. |
| Height (or Depth) | `9'-0"`, `9`, ຫຼື `2.7` ສຳລັບຫົວໜ່ວຍແບບເມຕຣິກ. |
| Component, Formula | ແຖວທີ່ມີຊື່ Component (ຫຼື Type `Component`) ເປັນສ່ວນໜຶ່ງຂອງການປະກອບຂອງລາຍການທີ່ຢູ່ເໜືອມັນ. Unit, Waste ແລະ ອັດຕາຂອງມັນເປັນຂອງມັນເອງ; Formula ຂອງມັນໃຊ້ຕົວອັກສອນຂອງລາຍການ, ເບິ່ງ [ການປະກອບ ແລະ ສູດ](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

ເຄື່ອງໝາຍຈຸລະພາກ (,), ເຄື່ອງໝາຍ (;) ຫຼື tab ລະຫວ່າງຖັນໃຊ້ໄດ້ທັງໝົດ.

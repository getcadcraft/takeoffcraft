ຊຸດແຜນຜັງມັກເປັນ PDF ຫຼາຍໄຟລ໌: ສະຖາປັດ, ໂຄງສ້າງ, ເຄື່ອງກົນ. TakeoffCraft ເປີດພວກມັນຄຽງກັນເປັນລາຍການແຜ່ນດຽວ, ແລະ ການຖອດປະລິມານໜຶ່ງສາມາດຄອບຄຸມທັງໝົດ.

## ເປີດ PDF

1. ເລືອກ {{ui:Open plans}} ໃນກຸ່ມ {{ui:File}}, ຫຼື ກົດ {{key:Mod+O}}. (ຮູບແບບເມນູອື່ນເອີ້ນມັນວ່າ {{ui:Open PDFs…}}.)
2. ໃນໜ້າຕ່າງເລືອກໄຟລ໌, ເລືອກທຸກ PDF ຂອງຊຸດ. ກົດຄ້າງ {{pick:mac=Command|windows=Ctrl|linux=Ctrl}} ເພື່ອເລືອກຫຼາຍອັນ, ຫຼື {{key:Shift}} ເພື່ອເລືອກຊ່ວງ.
3. ເລືອກ ເປີດ.
   ຂໍ້ຄວາມ "ກຳລັງເປີດ (name)…" ສະແດງໃນຂະນະອ່ານແຕ່ລະໄຟລ໌. ຈາກນັ້ນທຸກໜ້າປາກົດໃຕ້ {{ui:Sheets}} ແລະ ໜ້າທຳອິດຂອງ PDF ໃໝ່ທຳອິດຈະເປີດ.

ທ່ານຍັງສາມາດລາກ PDF ຈາກ {{pick:mac=Finder|windows=File Explorer|linux=ໂປຣແກຣມຈັດການໄຟລ໌ຂອງທ່ານ}} ແລ້ວວາງໄວ້ບ່ອນໃດກໍໄດ້ໃນ TakeoffCraft. ກອບ "ວາງ PDF, ແບບແຕ້ມ DWG ຫຼື DXF, ຫຼື .takeoff.json" ປາກົດຂະນະລາກ.

ເພື່ອເພີ່ມ PDF ພາຍຫຼັງ, ເຮັດແບບດຽວກັນອີກ. PDF ທີ່ເປີດແລ້ວຈະຖືກຂ້າມ.

ໜ້າເລີ່ມຕົ້ນຍັງລາຍການ PDF ແລະ ການຖອດປະລິມານທີ່ທ່ານເປີດຫຼ້າສຸດ, ໃນບຣາວເຊີທີ່ໃຫ້ໜ້າເວັບເປີດໄຟລ໌ອີກຄັ້ງໄດ້ (Chrome ແລະ Edge). ຄລິກອັນໃດອັນໜຶ່ງເພື່ອເປີດ; ບຣາວເຊີອາດຖາມສິດກ່ອນ. ເບິ່ງ [ໄຟລ໌ຂອງທ່ານ](common:your-files).

:::note
ບໍ່ມີການອັບໂຫຼດ. ບຣາວເຊີອ່ານ PDF ໃນຄອມພິວເຕີຂອງທ່ານ, ແລະ ພວກມັນຈະຫາຍໄປຈາກ TakeoffCraft ເມື່ອທ່ານປິດແທັບ ຫຼື ເລືອກ {{ui:New}}.
:::

## ແບບແຕ້ມຄຽງຄູ່ກັບ PDF

{{ui:Open plans}} ຍັງຮັບແບບແຕ້ມ DWG ແລະ DXF, ທັງດ່ຽວ ຫຼື ພ້ອມ PDF: ໂມເດວ ແລະ layout ຂອງແຕ່ລະແບບແຕ້ມກາຍເປັນແຜ່ນໃນລາຍການດຽວກັນ. ເບິ່ງ [ເປີດແບບແຕ້ມ DWG ຫຼື DXF](topic:open-a-drawing), ແລ້ວ [ນັບຈາກແບບແຕ້ມ](topic:count-from-a-drawing).

## PDF ທີ່ສົ່ງຕໍ່ຈາກແອັບອື່ນ

ແອັບອື່ນໃນຊຸດນີ້ສາມາດສົ່ງ PDF ທີ່ມັນເປີດຢູ່ໃຫ້ທ່ານ: ມັນເປີດ TakeoffCraft ໃນແທັບໃໝ່ ແລະ PDF ເປີດຢູ່ທີ່ນັ້ນຄືກັບທີ່ທ່ານລາກວາງ. ແຖບສະຖານະຂຽນວ່າ "ເປີດ (name) ແລ້ວ, ສົ່ງຕໍ່ຈາກ (app). ໄຟລ໌ຕົ້ນສະບັບບໍ່ປ່ຽນແປງ." ບໍ່ມີການອັບໂຫຼດ; ໄຟລ໌ຜ່ານບ່ອນເກັບຂອງບຣາວເຊີນີ້ ແລະ ຫາຍໄປຈາກມັນເມື່ອເປີດແລ້ວ.

ຖ້າແຖບສະຖານະຂຽນວ່າ PDF "ບໍ່ໄດ້ຮັບ", ແທັບລໍຖ້ານານເກີນໄປ ຫຼື PDF ຖືກເປີດໃນແທັບອື່ນແລ້ວ: ໃຫ້ເປີດດ້ວຍ {{ui:Open plans}}.

ໃນທາງກັບກັນ, ເມື່ອ {{ui:MarkupCraft}} ເຮັດວຽກຢູ່ໃນບ່ອນທີ່ທ່ານໃຊ້ງານ ແລະ ສາມາດຮັບໄຟລ໌ໄດ້, ແຖບແຜ່ນທີ່ຢູ່ໃຕ້ແບບແຕ້ມມີປຸ່ມ {{ui:MarkupCraft}}: ມັນເປີດ PDF ຂອງແຜ່ນທີ່ສະແດງຢູ່ໃນ MarkupCraft, ໃນແທັບໃໝ່, ເພື່ອກວດ ແລະ ໝາຍເພີ່ມ.

## ຊອກແຜ່ນ

- ເລື່ອນລາຍການ {{ui:Sheets}} ທາງຊ້າຍ ແລະ ຄລິກແຜ່ນ.
- ພິມໃນ **ຄົ້ນຫາແຜ່ນ** ເທິງສຸດຂອງລາຍການເພື່ອກັ່ນຕອງຕາມເລກແຜ່ນ, ຊື່ໄຟລ໌ ຫຼື ປ້າຍໜ້າ. ຕົວນັບຂ້າງ {{ui:Sheets}} ສະແດງ "3 of 40" ໃນຂະນະທີ່ມີການກັ່ນຕອງ.
- ກົດ {{key:PageDown}} ສຳລັບແຜ່ນຕໍ່ໄປ ແລະ {{key:PageUp}} ສຳລັບແຜ່ນກ່ອນ. ມັນຕາມລາຍການທີ່ກັ່ນຕອງແລ້ວ.

:::mac
ໃນແປ້ນພິມ Mac ທີ່ບໍ່ມີປຸ່ມ Page Up ແລະ Page Down, ກົດ fn ພ້ອມລູກສອນຂຶ້ນ ຫຼື ລົງ.
:::

## ການຕັ້ງຊື່ແຜ່ນ

- ໜ້າທີ່ PDF ໃຫ້ປ້າຍ, ເຊັ່ນ `A-101`, ຖືກຕັ້ງຊື່ຕາມປ້າຍນັ້ນ.
- ໜ້າທີ່ບໍ່ມີປ້າຍ (ຫຼື ປ້າຍທີ່ເປັນແຕ່ເລກໜ້າ) ຖືກຕັ້ງຊື່ເປັນ "(ຊື່ໄຟລ໌), ໜ້າ (n)".
- ເມື່ອເປີດ PDF ຫຼາຍໄຟລ໌, ແຜ່ນທີ່ມີປ້າຍກໍມີຊື່ໄຟລ໌ນຳ: "A-101 — Architectural".

ຍັງບໍ່ສາມາດພິມຊື່ແຜ່ນດ້ວຍມື.

## ເບິ່ງອ້ອມແຜ່ນ

- ໝຸນລໍ້ເມົ້າເພື່ອຊູມຢູ່ຕຳແໜ່ງຕົວຊີ້.
- ລາກດ້ວຍປຸ່ມຊ້າຍ ຫຼື ປຸ່ມກາງເພື່ອເລື່ອນມຸມມອງ. ດ້ວຍ {{ui:Auto count}}, ຫຼື ເມື່ອເລີ່ມທີ່ມຸມຂອງເຄື່ອງໝາຍ, ກົດຄ້າງ {{key:Space}} ຂະນະລາກ, ຫຼື ລາກດ້ວຍປຸ່ມກາງ.
- ກົດ {{key:F}} ຫຼື ເລືອກ {{ui:Fit page}} ເພື່ອເບິ່ງທັງແຜ່ນ; {{key:W}} ຫຼື {{ui:Fit width}} ພໍດີຄວາມກວ້າງຂອງມັນ.
- ກົດ {{key:Plus}} ຫຼື {{key:=}} ເພື່ອຊູມເຂົ້າ ແລະ {{key:Minus}} ເພື່ອຊູມອອກ, ຢູ່ກາງມຸມມອງ.

ແຕ່ລະແຜ່ນຈື່ການຊູມ ແລະ ຕຳແໜ່ງຂອງມັນເອງ ຕາບໃດທີ່ມັນຍັງເປີດຢູ່.

## Estimate (ຊີດ XLSX ແລະ CSV)

ໜຶ່ງແຖວຕໍ່ລາຍການ, ຕາມດ້ວຍໜຶ່ງແຖວຕໍ່ອົງປະກອບຂອງແອດເຊມບລີ (ຍໍ້າເຂົ້າໄປ). ຫຼັງຈາກນັ້ນເປັນແຖວຫວ່າງ ແລະ ຜົນລວມຂອງໂຄງການ.

| ຖັນ | ເນື້ອໃນ | ໃນ XLSX |
|---|---|---|
| A Item | ຊື່ລາຍການ (ໜາ) ຫຼື ຊື່ອົງປະກອບ (ຍໍ້າເຂົ້າ) | ຂໍ້ຄວາມ |
| B Type | Linear, Area, Count ຫຼື Component | ຂໍ້ຄວາມ |
| C Unit | LF, m, SF, SY, m², EA, ຫຼື ໜ່ວຍຂອງອົງປະກອບ | ຂໍ້ຄວາມ |
| D Quantity | ຜົນລວມທີ່ວັດໄດ້, ຫຼື ຜົນຂອງສູດ | ຕົວເລກ |
| E Waste % | ການສູນເສຍ | ເປີເຊັນ (0.10 = 10%) |
| F Qty with waste | ປະລິມານ × (1 + ການສູນເສຍ) | ສູດ `D*(1+E)` |
| G Material per unit | ອັດຕາວັດສະດຸ | ຕົວເລກ |
| H Labor per unit | ອັດຕາແຮງງານ | ຕົວເລກ |
| I Material | ວັດສະດຸທີ່ຄິດເປັນເງິນ | ສູດ `ROUND(F*G,2)` |
| J Labor | ແຮງງານທີ່ຄິດເປັນເງິນ | ສູດ `ROUND(F*H,2)` |
| K Total | ວັດສະດຸ + ແຮງງານ | ສູດ `I+J` |
| L Notes | ສູດທີ່ໃຊ້, ຂໍ້ຜິດພາດຂອງສູດ, ເຄື່ອງໝາຍໃນແຜ່ນທີ່ບໍ່ມີມາດຕາສ່ວນ, ພື້ນທີ່ຝາ, ເສັ້ນຮອບ | ຂໍ້ຄວາມ |

ແຖວຜົນລວມໂຄງການ: `SUM` ຂອງຖັນ I, J ແລະ K ໃນທຸກແຖວຂ້າງເທິງ, ແລະ "Incomplete: see the notes above" ໃນ Notes ເມື່ອມີບາງຢ່າງຖືກຂ້າມ.

ແຖວທີ່ມີຂໍ້ຜິດພາດຂອງສູດບໍ່ມີປະລິມານ ຫຼື ຈຳນວນເງິນ; ໝາຍເຫດຂອງມັນບອກຂໍ້ຜິດພາດ. ແຖວຫົວຖືກຕິດໄວ້ຢູ່ເທິງສຸດ.

ໃນ CSV, ຖັນດຽວກັນເກັບຄ່າທຳມະດາ, Waste % ເປັນຕົວເລກເປີເຊັນ (10 ສຳລັບ 10%), ແລະ ເງິນເປັນໂດລາ ມີສອງຕຳແໜ່ງທົດສະນິຍົມ. ຂໍ້ຄວາມທີ່ spreadsheet ອາດເຂົ້າໃຈວ່າເປັນສູດ (ເລີ່ມດ້ວຍ `=`, `+`, `-` ຫຼື `@`) ຈະມີ `'` ນຳໜ້າ ເພື່ອໃຫ້ມັນຍັງເປັນຂໍ້ຄວາມ.

## By sheet (ສະເພາະ XLSX)

| ຖັນ | ເນື້ອໃນ |
|---|---|
| Sheet | ຊື່ແຜ່ນ (ພ້ອມຊື່ PDF ເມື່ອມັນບໍ່ໄດ້ເປີດ) |
| Item | ຊື່ລາຍການ |
| Quantity | ປະລິມານຂອງລາຍການນັ້ນໃນແຜ່ນນັ້ນ, ໃນໜ່ວຍຂອງມັນ |
| Unit | ໜ່ວຍຂອງລາຍການ |
| Marks | ຈຳນວນເຄື່ອງໝາຍ |

## Marks (ສະເພາະ XLSX)

ໜຶ່ງແຖວຕໍ່ເຄື່ອງໝາຍ.

| ຖັນ | ເນື້ອໃນ |
|---|---|
| Sheet | ຊື່ແຜ່ນ |
| Item | ຊື່ລາຍການ |
| Type | Linear, Area ຫຼື Count |
| Quantity | ຄວາມຍາວ, ພື້ນທີ່ສຸດທິ, ຫຼື 1 |
| Unit | LF ຫຼື m; SF, SY ຫຼື m²; EA |
| Detail | Linear: ຄວາມຍາວຂອງແຕ່ລະສ່ວນ, ສ່ວນທີ່ຖືກຫັກໝາຍວ່າ "(deduct)", ແລະ "deducts (length) of (length) drawn". Area: ພື້ນທີ່ລວມ ແລະ ພື້ນທີ່ຕັດອອກເມື່ອມີການຕັດອອກ, ແລະ ເສັ້ນຮອບ. "Sheet has no scale" ສຳລັບເຄື່ອງໝາຍທີ່ບໍ່ມີມາດຕາສ່ວນ. |
| Bid area | ມີພຽງເມື່ອການຖອດປະລິມານມີພື້ນທີ່ປະມູນ: ພື້ນທີ່ຂອງເຄື່ອງໝາຍ, ຫຼື "No bid area" |

## By bid area (ສະເພາະ XLSX, ເມື່ອການຖອດປະລິມານມີພື້ນທີ່ປະມູນ)

| ຖັນ | ເນື້ອໃນ |
|---|---|
| Bid area | ຊື່ຂອງພື້ນທີ່, ຫຼື "No bid area" |
| Item | ລາຍການ, ຫຼື ອົງປະກອບຍໍ້າເຂົ້າໄປຢູ່ໃຕ້ມັນ |
| Unit | ໜ່ວຍຂອງລາຍການ ຫຼື ອົງປະກອບ |
| Quantity | ວັດໃນພື້ນທີ່ນັ້ນ (ອົງປະກອບ: ສູດເທິງຜົນລວມຂອງພື້ນທີ່) |
| Qty with waste | ປະລິມານ × (1 + ການສູນເສຍ) |
| Material, Labor, Total | ຄິດເປັນເງິນເຖິງສຕາງ, ຄືກັບ Estimate |
| Notes | ສູດ, ຂໍ້ຜິດພາດ ແລະ ເຄື່ອງໝາຍທີ່ບໍ່ມີມາດຕາສ່ວນ, ຄືກັບ Estimate |

ແຕ່ລະພື້ນທີ່ຈົບດ້ວຍແຖວ "(name) subtotal" ທີ່ມີຄ່າໃຊ້ຈ່າຍເປັນສູດ `SUM` ເທິງແຖວຂອງມັນ; ແຖວສຸດທ້າຍ, **All bid areas**, ລວມຜົນລວມຍ່ອຍ. ຊີດ **Marks** ຈະມີຖັນທີເຈັດ, **Bid area**.

## Scales (ສະເພາະ XLSX)

ໜຶ່ງແຖວຕໍ່ແຜ່ນທີ່ມີມາດຕາສ່ວນ ຫຼື ເຄື່ອງໝາຍ.

| ຖັນ | ເນື້ອໃນ |
|---|---|
| Sheet | ຊື່ແຜ່ນ |
| Scale | ຊື່ຂອງ preset, ຫຼື ມາດຕາສ່ວນທີ່ປັບແລ້ວ, ຫຼື "No scale" |
| How | "Preset", ຫຼື "Calibrated on (the distance you typed)" |
| Feet per PDF unit | ຕົວຄູນມາດຕາສ່ວນທີ່ແນ່ນອນທີ່ TakeoffCraft ໃຊ້ |

## ຊື່ໄຟລ໌

- `(name).xlsx` ແລະ `(name).csv`, ໂດຍຊື່ມາຈາກ PDF ທຳອິດທີ່ເປີດໃນການຖອດປະລິມານ.
- CSV ເປັນ UTF-8 ມີ byte order mark ແລະ ແຖວແບບ Windows, ເຊິ່ງໂປຣແກຣມສະເປຣດຊີດທຸກແພລດຟອມອ່ານໄດ້.

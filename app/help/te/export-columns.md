## అంచనా (XLSX వర్క్‌షీట్ మరియు CSV)

ప్రతి ఐటెమ్‌కు ఒక వరుస, దాని అసెంబ్లీలోని ప్రతి భాగానికి ఒక వరుస (ఇండెంట్ చేయబడింది). తర్వాత ఖాళీ వరుస మరియు జాబ్ మొత్తం.

| కాలమ్ | విషయాలు | XLSX లో |
|---|---|---|
| A ఐటెమ్ | ఐటెమ్ పేరు (బోల్డ్) లేదా భాగం పేరు (ఇండెంట్) | టెక్స్ట్ |
| B రకం | రేఖీయ, వైశాల్యం, లెక్కింపు లేదా భాగం | టెక్స్ట్ |
| C యూనిట్ | LF, m, SF, SY, m², EA, లేదా భాగం యూనిట్ | టెక్స్ట్ |
| D క్వాంటిటీ | కొలిచిన మొత్తం, లేదా ఫార్ములా ఫలితం | సంఖ్య |
| E వ్యర్థ % | వ్యర్థం | శాతం (0.10 = 10%) |
| F వ్యర్థంతో క్వాంటిటీ | క్వాంటిటీ × (1 + వ్యర్థం) | ఫార్ములా `D*(1+E)` |
| G యూనిట్‌కు మెటీరియల్ | మెటీరియల్ రేటు | సంఖ్య |
| H యూనిట్‌కు లేబర్ | లేబర్ రేటు | సంఖ్య |
| I మెటీరియల్ | విస్తరించిన మెటీరియల్ | ఫార్ములా `ROUND(F*G,2)` |
| J లేబర్ | విస్తరించిన లేబర్ | ఫార్ములా `ROUND(F*H,2)` |
| K మొత్తం | మెటీరియల్ + లేబర్ | ఫార్ములా `I+J` |
| L నోట్స్ | ఉపయోగించిన ఫార్ములా, ఫార్ములా లోపం, స్కేల్ లేని షీట్‌లపై మార్క్‌లు, గోడ వైశాల్యం, చుట్టుకొలత | టెక్స్ట్ |

జాబ్ మొత్తం వరుస: పైన ఉన్న ప్రతి వరుసపై కాలమ్‌లు I, J మరియు K యొక్క `SUM`, మరియు ఏదైనా వదిలివేయబడినప్పుడు నోట్స్‌లో "అసంపూర్ణం: పై నోట్స్ చూడండి".

ఫార్ములా లోపం ఉన్న వరుసకు క్వాంటిటీ లేదా మొత్తాలు ఉండవు; దాని నోట్ లోపాన్ని ఇస్తుంది. హెడర్ వరుస స్తంభింపజేయబడింది.

CSV లో, అదే కాలమ్‌లు సాదా విలువలను కలిగి ఉంటాయి; వ్యర్థ % అనేది శాతం సంఖ్య (10% కి 10), మరియు డబ్బు డాలర్లలో రెండు దశాంశాలతో ఉంటుంది. స్ప్రెడ్‌షీట్ ఫార్ములాగా తీసుకోగల టెక్స్ట్ (`=`, `+`, `-` లేదా `@` తో మొదలయ్యేది) టెక్స్ట్‌గానే ఉండేందుకు ముందు `'` పొందుతుంది.

## షీట్ వారీగా (XLSX మాత్రమే)

| కాలమ్ | విషయాలు |
|---|---|
| షీట్ | షీట్ పేరు (తెరవనప్పుడు PDF పేరుతో) |
| ఐటెమ్ | ఐటెమ్ పేరు |
| క్వాంటిటీ | ఆ షీట్‌పై ఆ ఐటెమ్ క్వాంటిటీ, దాని యూనిట్‌లో |
| యూనిట్ | ఐటెమ్ యూనిట్ |
| మార్క్‌లు | మార్క్‌ల సంఖ్య |

## మార్క్‌లు (XLSX మాత్రమే)

ప్రతి మార్క్‌కు ఒక వరుస.

| కాలమ్ | విషయాలు |
|---|---|
| షీట్ | షీట్ పేరు |
| ఐటెమ్ | ఐటెమ్ పేరు |
| రకం | రేఖీయ, వైశాల్యం లేదా లెక్కింపు |
| క్వాంటిటీ | పొడవు, నికర వైశాల్యం, లేదా 1 |
| యూనిట్ | LF లేదా m; SF, SY లేదా m²; EA |
| వివరాలు | రేఖీయ: సెగ్మెంట్ పొడవులు, తగ్గించినవి "(తగ్గించు)" గా గుర్తించబడినవి, మరియు "గీసిన (పొడవు)లో (పొడవు) తగ్గింపులు". వైశాల్యం: కట్-అవుట్‌లు ఉన్నప్పుడు స్థూల మరియు కట్-అవుట్ వైశాల్యాలు, మరియు చుట్టుకొలత. స్కేల్ లేని మార్క్‌లకు "షీట్‌కు స్కేల్ లేదు". |
| బిడ్ ఏరియా | టేకాఫ్‌లో బిడ్ ఏరియాలు ఉన్నప్పుడు మాత్రమే: మార్క్ యొక్క ఏరియా, లేదా "బిడ్ ఏరియా లేదు" |

## బిడ్ ఏరియా వారీగా (XLSX మాత్రమే, టేకాఫ్‌లో బిడ్ ఏరియాలు ఉన్నప్పుడు)

| కాలమ్ | ఏమిటి |
|---|---|
| బిడ్ ఏరియా | ఏరియా పేరు, లేదా "బిడ్ ఏరియా లేదు" |
| ఐటెమ్ | ఐటెమ్, లేదా దాని కింద ఇండెంట్ చేయబడిన భాగం |
| యూనిట్ | ఐటెమ్ లేదా భాగం యూనిట్ |
| క్వాంటిటీ | ఆ ఏరియాలో కొలిచినది (భాగాలు: ఏరియా మొత్తాలపై ఫార్ములా) |
| వ్యర్థంతో క్వాంటిటీ | క్వాంటిటీ × (1 + వ్యర్థం) |
| మెటీరియల్, లేబర్, మొత్తం | అంచనాలో ఉన్నట్లు, సెంట్ వరకు విస్తరించబడినవి |
| నోట్స్ | ఫార్ములా, లోపాలు మరియు స్కేల్ లేని మార్క్‌లు, అంచనాలో ఉన్నట్లే |

ప్రతి ఏరియా "(పేరు) ఉపమొత్తం" వరుసతో ముగుస్తుంది, దీని ఖర్చులు దాని వరుసలపై `SUM` ఫార్ములాలు; చివరి వరుస, **అన్ని బిడ్ ఏరియాలు**, ఉపమొత్తాలను కలుపుతుంది. **మార్క్‌లు** వర్క్‌షీట్‌కు ఏడవ కాలమ్, **బిడ్ ఏరియా**, ఉంటుంది.

## స్కేల్‌లు (XLSX మాత్రమే)

స్కేల్ లేదా మార్క్‌లు ఉన్న ప్రతి షీట్‌కు ఒక వరుస.

| కాలమ్ | విషయాలు |
|---|---|
| షీట్ | షీట్ పేరు |
| స్కేల్ | ప్రీసెట్ పేరు, లేదా కాలిబ్రేట్ చేసిన స్కేల్, లేదా "స్కేల్ లేదు" |
| ఎలా | "ప్రీసెట్", లేదా "(మీరు టైప్ చేసిన దూరంపై) కాలిబ్రేట్ చేయబడింది" |
| PDF యూనిట్‌కు అడుగులు | TakeoffCraft ఉపయోగించే ఖచ్చితమైన స్కేల్ కారకం |

## ఫైల్ పేర్లు

- `(name).xlsx` మరియు `(name).csv`, ఇక్కడ పేరు టేకాఫ్‌లో తెరిచిన మొదటి PDF నుండి వస్తుంది.
- CSV UTF-8 బైట్ ఆర్డర్ మార్క్ మరియు Windows లైన్ ముగింపులతో ఉంటుంది; ప్రతి ప్లాట్‌ఫామ్‌లోని స్ప్రెడ్‌షీట్ ప్రోగ్రామ్‌లు దాన్ని చదువుతాయి.

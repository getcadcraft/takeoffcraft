అసెంబ్లీ భాగాలు తమ క్వాంటిటీని ఫార్ములా నుండి పొందుతాయి. ఫార్ములా అనేది ఐటెమ్ యొక్క కొలిచిన విలువలపై ఒక చిన్న అంకగణిత వ్యక్తీకరణ. ఉదాహరణల కోసం [అసెంబ్లీలు మరియు ఫార్ములాలు](topic:assemblies) చూడండి.

## వేరియబుల్స్

| ఐటెమ్ రకం | వేరియబుల్ | అర్థం |
|---|---|---|
| రేఖీయ | `L` | మొత్తం పొడవు |
| రేఖీయ | `H` | ఐటెమ్ ఎత్తు |
| రేఖీయ | `A` | గోడ వైశాల్యం, L × H, ఓపెనింగ్‌లు తీసివేయబడినవి, వాటిని కలిగి ఉన్న రన్‌ల కోసం (BimCraft నుండి టేకాఫ్). ఆ టేకాఫ్ ఒక కొలత పద్ధతిని పేర్కొన్నప్పుడు, `A` దాని ద్వారా కొలవబడుతుంది: పద్ధతి యొక్క అతి చిన్న పరిమాణం కంటే పెద్దవి కాని ఓపెనింగ్‌లు లోపల ఉంటాయి, మరియు గోడలు కలిసే చోట పద్ధతి తీసుకునేది వదిలివేయబడుతుంది. ఐటెమ్ కింద ఉన్న నోట్ ఆ పద్ధతిని పేర్కొంటుంది |
| రేఖీయ | `N` | రన్‌ల సంఖ్య |
| వైశాల్యం | `A` | మొత్తం నికర వైశాల్యం (అవుట్‌లైన్‌లు తీసివేత కట్-అవుట్‌లు) |
| వైశాల్యం | `P` | మొత్తం చుట్టుకొలత, కట్-అవుట్ అంచులతో సహా |
| వైశాల్యం | `H` | ఐటెమ్ లోతు లేదా మందం |
| వైశాల్యం | `N` | ప్రాంతాల సంఖ్య |
| లెక్కింపు | `N` | లెక్కింపు |

- వేరియబుల్స్ ఐటెమ్ యూనిట్‌లలో ఉంటాయి: [యూనిట్‌లు](topic:units) చూడండి.
- పెద్ద మరియు చిన్న అక్షరాలు ఒకటే: `l` అంటే `L`.
- ఐటెమ్ యొక్క సొంత రకం వేరియబుల్స్ మాత్రమే పనిచేస్తాయి. రేఖీయ ఐటెమ్‌పై `P` ఇస్తుంది `"P" ఇక్కడ కొలిచిన విలువ కాదు. L, H, A, N ఉపయోగించండి.`
- ఖాళీ ఎత్తు లేదా లోతు 0.

## ఆపరేటర్లు

| రాయండి | అర్థం |
|---|---|
| `+` | కూడిక |
| `-` లేదా `−` | తీసివేత, లేదా ఋణ విలువ |
| `*` లేదా `×` | గుణకారం |
| `/` లేదా `÷` | భాగహారం |
| `( )` | సమూహం |

గుణకారం మరియు భాగహారం కూడిక మరియు తీసివేత కంటే ముందు వస్తాయి: `L * 2 + 4` అంటే (L × 2) + 4. సందేహంగా ఉన్నప్పుడు కుండలీకరణాలు ఉపయోగించండి.

సంఖ్యలకు దశాంశాలు (`1.333`, `.5`) మరియు ఘాతాంకాలు (`1e3` = 1000) ఉండవచ్చు. స్పేస్‌లు విస్మరించబడతాయి.

## ఫంక్షన్లు

| ఫంక్షన్ | ఫలితం | ఉదాహరణ |
|---|---|---|
| `ceil(x)` | పైకి పూర్ణ సంఖ్యకు రౌండ్ | `ceil(67.5)` = 68 |
| `floor(x)` | క్రిందకు పూర్ణ సంఖ్యకు రౌండ్ | `floor(67.5)` = 67 |
| `round(x)` | సమీప పూర్ణ సంఖ్యకు రౌండ్, సగం సున్నా నుండి దూరంగా | `round(2.5)` = 3 |
| `round(x, d)` | d దశాంశాలకు రౌండ్ (0 నుండి 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | అతి చిన్న విలువ | `min(N, 10)` |
| `max(a, b, …)` | అతి పెద్ద విలువ | `max(1, ceil(N / 12))` |
| `abs(x)` | దాని గుర్తు లేని విలువ | `abs(-3)` = 3 |

`ceil` మరియు `floor` చిన్న కంప్యూటర్ రౌండింగ్ శబ్దాన్ని విస్మరిస్తాయి, కాబట్టి ఖచ్చితంగా 1 ఉండాల్సిన విలువ ఎప్పుడూ 2 కి పైకి రౌండ్ కాదు.

## ఎర్రర్‌లు

చదవలేని లేదా లెక్కించలేని ఫార్ములా ఫీల్డ్ కింద దాని ఎర్రర్‌ను చూపుతుంది, మరియు భాగం మొత్తాల నుండి వదిలివేయబడుతుంది ({{ui:Quantities}} హెడర్ "అసంపూర్ణం" అని చెబుతుంది). సందేశాలు:

| సందేశం | పరిష్కారం |
|---|---|
| ఫార్ములా టైప్ చేయండి, ఉదాహరణకు L లేదా ceil(L / 1.333) + 1. | ఫార్ములా ఖాళీగా ఉంది. |
| "X" ఇక్కడ కొలిచిన విలువ కాదు. ఉపయోగించండి … | listed వేరియబుల్స్‌లో ఒకటి ఉపయోగించండి. |
| "X" ఇక్కడ ఫంక్షన్ కాదు. ceil, floor, round, min, max, abs ఉపయోగించండి. | ఆ ఫంక్షన్లలో ఒకటి ఉపయోగించండి. |
| ఫార్ములాలో "#" అనుమతించబడదు. | ఆ అక్షరాన్ని తీసివేయండి (యూనిట్‌లు, `%`, `$` మరియు `=` అనుమతించబడవు). |
| ")" లేదు. / "(" లేని ")" ఉంది. | కుండలీకరణాలను సమతుల్యం చేయండి. |
| ")" ముందు ఒక విలువ లేదు. | `max(1, )` లాంటిది: విలువ నింపండి. |
| ఫార్ములా చాలా త్వరగా ముగుస్తుంది. | `L *` లాంటిది: పూర్తి చేయండి. |
| అనుకోని "…". ఆపరేటర్ లేదా? | రెండు విలువలు పక్కపక్కన, `2L` లాంటివి: `2 * L` రాయండి. |
| ceil() ఒక విలువ తీసుకుంటుంది. | ఫంక్షన్‌కు సరైన సంఖ్యలో విలువలు ఇవ్వండి. |
| round(x, digits) కు 0 నుండి 10 మధ్య పూర్ణ దశాంశాలు కావాలి. | పూర్ణ సంఖ్యలో దశాంశాలు ఉపయోగించండి. |
| ఫార్ములా సున్నాతో భాగిస్తుంది. | సాధారణంగా H సున్నా: ఐటెమ్ ఎత్తు లేదా లోతు సెట్ చేయండి. |
| ఫార్ములా సంఖ్య ఇవ్వదు. | ఫలితం సంఖ్య కావడానికి చాలా పెద్దది. |
| ఆ ఫార్ములా చాలా పొడవుగా ఉంది (గరిష్టంగా 500 అక్షరాలు). | దాన్ని చిన్నదిగా చేయండి. |

## డిజైన్ ద్వారా సురక్షితం

ఫార్ములా పైన ఉన్న వేరియబుల్స్ మరియు ఫంక్షన్లతో మాత్రమే అంకగణితం చేయగలదు. అది కోడ్ నడపలేదు లేదా మరేదీ చదవలేదు, కాబట్టి ఎవరైనా మీకు పంపిన ప్రాజెక్ట్ ఫైల్‌లోని ఫార్ములా హానికరం కాదు.

যখন পয়েন্টার পৃষ্ঠার যেকোনো জায়গায় থাকে এবং আপনি কোনো ঘরে টাইপ করছেন না, তখন অক্ষর কী কাজ করে। কোনো ডায়ালগ খোলা থাকলে তার নিজের কী প্রযোজ্য হয়। {{key:Shift}} সহ বা ছাড়া অক্ষর কাজ করে।

## আঁকার সময়

| কী বা কাজ | কী করে |
|---|---|
| ক্লিক | একটি বিন্দু বসায় ({{ui:গণনা}}-তে একটি ডট)। |
| {{key:P}} | Path: একটি PDF লাইনের পুরো সংযুক্ত পথ, অথবা একটি ক্লিকের চারপাশের আউটলাইন বেছে নিন ([PDF-এর লাইন বেছে নিন](topic:pick-the-lines))। |
| {{key:F3}} | ড্রয়িংয়ের লাইনে স্ন্যাপ চালু বা বন্ধ ([ড্রয়িংয়ের লাইনে স্ন্যাপ করুন](topic:snap-to-the-drawing))। |
| ক্লিক করার সময় {{key:Shift}} ধরে রাখুন | শেষ বিন্দু থেকে সেগমেন্টটি 0°, 45°, 90° বা 135°-এ স্ন্যাপ করে। আর্ক বিন্দু বা বৃত্তের জন্য নয়। |
| ডাবল-ক্লিক | একটি রান শেষ করে, অথবা একটি এলাকা বা কাট-আউট বন্ধ করে। |
| {{key:Enter}} | একটি রান শেষ করে, অথবা একটি এলাকা বা কাট-আউট বন্ধ করে। |
| ডান-ক্লিক (না সরিয়ে) | একটি রান শেষ করে, অথবা একটি এলাকা বা কাট-আউট বন্ধ করে। |
| প্রথম বিন্দুতে ক্লিক | একটি এলাকা বা কাট-আউট বন্ধ করে (তৃতীয় বিন্দু থেকে)। |
| {{key:Backspace}} বা {{key:Delete}} | শেষ বিন্দু সরায় (আগে অপেক্ষমাণ আর্ক বিন্দু)। |
| {{key:Esc}} | অপেক্ষমাণ আর্ক বিন্দু বাদ দেয়; তারপর অসম্পূর্ণ মার্ক বাতিল করে; তারপর {{ui:নির্বাচন}}-এ ফিরে যায়। |

## নির্বাচন ও সম্পাদনা

| কী বা কাজ | কী করে |
|---|---|
| একটি মার্কে ক্লিক ({{ui:নির্বাচন}} টুল) | এটি নির্বাচন করে এবং তার আইটেমটি বর্তমান করে। |
| {{key:Shift}} + একটি মার্কে ক্লিক | নির্বাচনে যোগ করে, অথবা বাদ দেয়। |
| {{key:Mod+A}} | খোলা শিটের প্রতিটি মার্ক নির্বাচন করে। |
| একটি কোণের হ্যান্ডেল টেনে আনুন | সেই বিন্দু সরায় ({{key:Shift}} 45°-এ স্ন্যাপ করে)। একটি মার্ক নির্বাচিত থাকলে কাজ করে। |
| {{key:Delete}} বা {{key:Backspace}} | নির্বাচিত মার্কগুলো মুছে ফেলে (আঁকার সময় নয়)। |
| {{key:Esc}} | কিছুই নির্বাচন না করে: নির্বাচন ও যাচাই লাইন সাফ করে। |
| {{key:Mod+Z}} | পূর্বাবস্থায় ফিরুন। |
| {{key:Mod+Y}} বা {{key:Mod+Shift+Z}} | আবার করুন। |

## কপি ও পেস্ট

| কী | কী করে |
|---|---|
| {{key:Mod+C}} | নির্বাচিত মার্কগুলো তাদের আইটেমসহ কপি করে। |
| {{key:Mod+X}} | কাট: নির্বাচিত মার্কগুলো কপি করে, তারপর মুছে দেয়। |
| {{key:Mod+V}} | পেস্ট: কপিটি পয়েন্টারের সঙ্গে চলে; যেখানে যাবে সেখানে ক্লিক করুন। |
| {{key:Mod+Shift+V}} | জায়গামতো পেস্ট: খোলা শিটের একই জায়গায়। |
| {{key:Mod+D}} | ডুপ্লিকেট: নির্বাচিত মার্কগুলোর একটি কপি করে; কপিটি পয়েন্টারের সঙ্গে চলে; যেখানে যাবে সেখানে ক্লিক করুন। |
| {{key:Esc}} | কিছু না বসিয়ে: পয়েন্টারে থাকা পেস্ট বা ডুপ্লিকেট বাতিল করে। |

অক্ষরগুলো একা থাকলে এখনও টুল বেছে নেয় ({{key:C}} হল {{ui:গণনা}}, {{key:D}} হল {{ui:যাচাই}}, {{key:X}} হল {{ui:কাট-আউট}}, {{key:V}} হল {{ui:নির্বাচন}}, {{key:A}} হল {{ui:এলাকা}}); শুধু {{key:Mod}} এর সঙ্গে থাকলে কপি ও পেস্ট করে। কোনো টেক্সট ঘরে এই কীগুলো স্বাভাবিকভাবে টেক্সট কপি ও পেস্ট করে। দেখুন [মার্ক কপি, পেস্ট ও ডুপ্লিকেট করুন](topic:copy-paste)।

:::warning
আঁকছেন না এমন সময় {{key:Backspace}} নির্বাচিত মার্ক মুছে দেয়। ভুলবশত ঘটলে {{key:Mod+Z}} সেটি ফিরিয়ে আনে।
:::

এই দুটি কাজ করে, এমনকি আপনি কোনো ঘরে টাইপ করার সময়ও।

## ভিউ ও শিট

| কী বা কাজ | কী করে |
|---|---|
| মাউস হুইল | পয়েন্টারের জায়গায় জুম ইন ও আউট করে। |
| টেনে আনুন (বাঁ, মধ্য বা ডান বোতাম) | প্যান। {{ui:অটো কাউন্ট}}-এ বাঁ দিকে টানলে তার বদলে সার্চ বাক্স আঁকা হয়। |
| {{key:Space}} ধরে + টেনে আনুন | যেকোনো টুলে প্যান। |
| {{key:F}} | {{ui:পৃষ্ঠা মানানো}} |
| {{key:W}} | {{ui:প্রস্থ মানানো}} |
| {{key:Plus}} বা {{key:=}} | ভিউয়ের মাঝখানে জুম ইন। |
| {{key:Minus}} | ভিউয়ের মাঝখানে জুম আউট। |
| {{key:PageDown}} / {{key:PageUp}} | শিট তালিকায় পরের বা আগের শিট। |
| {{key:Ctrl+Shift+F}} | পূর্ণ পর্দা মোড ঘোরায় (সব প্ল্যাটফর্মে Control, Mac-এও)। |
| {{key:F1}} | এই সাহায্য খোলে বা বন্ধ করে, পাশের একটি প্যানেল। |
| {{key:3}} | শিটের 3D যাচাই ভিউ চালু বা বন্ধ। |

## 3D ভিউ

| কী বা কাজ | কী করে |
|---|---|
| টেনে আনুন, অথবা মধ্য বোতাম দিয়ে টেনে আনুন | ঘোরান। |
| {{key:Shift}} + টেনে আনুন, অথবা ডান বোতাম দিয়ে টেনে আনুন | প্যান। |
| মাউস হুইল | পয়েন্টারের জায়গায় জুম। ট্র্যাকপ্যাডে দুই আঙুলের সোয়াইপ ঘোরায় এবং পিঞ্চ জুম করে। |
| ক্লিক | পয়েন্টারের নিচের মার্ক নির্বাচন করে ({{key:Shift}} + ক্লিক যোগ বা বাদ দেয়)। |
| {{key:F}} বা {{key:W}} | পুরো বিস্তার জুম। |
| {{key:3}} | সমতল শিটে ফিরে যায়। |

দেখুন [টেকঅফ 3D-তে যাচাই করুন](topic:check-in-3d)।

## অটো কাউন্ট

| কী বা কাজ | কী করে |
|---|---|
| একটি বাক্স টেনে আনুন | যে প্রতীক খুঁজতে হবে তার চারপাশে বাক্স আঁকে (খোঁজা শুরু হয়)। |
| একটি মিল-বাক্সে ক্লিক | এটি বাতিল করে, অথবা ফিরিয়ে আনে। |
| {{key:Esc}} | চলমান খোঁজা বাতিল করে, অথবা পর্যালোচনা বাদ দেয়। |

## সাহায্য

| কী | কী করে |
|---|---|
| {{key:F1}} | সাহায্য প্যানেল খোলে বা বন্ধ করে (অ্যাপ বারের {{ui:সাহায্য}} বোতামও)। প্রতিটি টুলে কাজ করে, এমনকি ঘরে টাইপ করার সময়ও। |
| {{key:Esc}} | সাহায্য প্যানেল বন্ধ করে। এর সার্চ বাক্সে প্রথম Esc সার্চ সাফ করে। প্যানেল খোলা থাকলে, শিটে ক্লিক করার পর Esc চাপলে আগে প্যানেল বন্ধ হয়; TakeoffCraft-এ বাতিল করতে আবার চাপুন। |

:::mac
অনেক Mac কী-বোর্ডে উপরের সারি উজ্জ্বলতা ও শব্দ নিয়ন্ত্রণ করে। F1-এর সঙ্গে fn চাপুন, অথবা System Settings-এ, Keyboard-এর অধীনে "Use F1, F2, etc. keys as standard function keys" চালু করুন।
:::

## প্ল্যাটফর্ম নোট

:::mac
- {{key:Mod}} হল Command কী: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}। পূর্ণ পর্দা ব্যতিক্রম: Control+Shift+F।
- ট্র্যাকপ্যাডে দুই আঙুলের ক্লিক হল ডান-ক্লিক, যখন System Settings-এ Trackpad-এর অধীনে secondary click চালু থাকে। TakeoffCraft শুধু সেকেন্ডারি বোতাম পড়ে; Control-ক্লিক সাধারণ ক্লিক গণ্য হয়ে একটি বিন্দু যোগ করতে পারে।
- ট্র্যাকপ্যাডে দুই আঙুলে স্ক্রল করলে শিট জুম হয় (স্ক্রল হয় না)। প্যান করতে চেপে টেনে আনুন, অথবা Space ধরে টেনে আনুন।
- Page Up ও Page Down হল fn সহ উপর ও নিচের তীর কী, যেসব কী-বোর্ডে এই কী নেই।
- Backspace হল Delete লেখা কী।
:::

:::windows
- {{key:Mod}} হল Ctrl: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}।
- ল্যাপটপের টাচপ্যাডে দুই আঙুলে স্ক্রল শিট জুম করে। প্যান করতে চেপে টেনে আনুন।
:::

:::linux
- {{key:Mod}} হল Ctrl। কিছু ডেস্কটপের নিজস্ব Ctrl+Alt বা Super শর্টকাট থাকে; TakeoffCraft এর কোনোটিই ব্যবহার করে না।
- টাচপ্যাডে দুই আঙুলে স্ক্রল শিট জুম করে। প্যান করতে চেপে টেনে আনুন।
:::

:::touch
TakeoffCraft টাচকে একটি একক পয়েন্টার হিসেবে পড়ে:

- ট্যাপ একটি বিন্দু বসায়, একটি মার্ক নির্বাচন করে বা একটি গণনা-ডট যোগ করে।
- এক আঙুলে টেনে আনলে শিট প্যান হয় ({{ui:অটো কাউন্ট}}-এ এটি সার্চ বাক্স আঁকে)।
- পিঞ্চ-টু-জুম এখনও সমর্থিত নয়। {{ui:পৃষ্ঠা মানানো}} ও {{ui:প্রস্থ মানানো}} ব্যবহার করুন, অথবা কী-বোর্ডে {{key:Plus}} ও {{key:Minus}}।
- একটি এলাকা বন্ধ করতে এর প্রথম বিন্দুতে ট্যাপ করুন। একটি রান শেষ করতে, যেখানে আপনার ব্রাউজার ডাবল-ট্যাপকে ডাবল-ক্লিকে রূপান্তর করে সেখানে ডাবল-ট্যাপ করুন, অথবা কী-বোর্ডে {{key:Enter}} চাপুন।
- ট্যাপ না করা পর্যন্ত কোনো লাইভ দৈর্ঘ্য দেখানো হয় না, কারণ হভার নেই।

এখন টেকঅফের জন্য কী-বোর্ড ও মাউস বা ট্র্যাকপ্যাড ভালো উপায়।

## ব্রাউজারের নিজের কী

ব্রাউজার কিছু শর্টকাট নিজের জন্য রাখে, পেজ সেগুলো ব্যবহার করতে পারে না: ট্যাব বন্ধ করা ({{key:Mod+W}}), নতুন ট্যাব বা উইন্ডো ({{key:Mod+T}}, {{key:Mod+N}}), এবং ব্রাউজার জুম ({{key:Mod+Plus}}, {{key:Mod+Minus}})। এ কারণেই TakeoffCraft হুইল এবং শুধু {{key:Plus}} ও {{key:Minus}} কী দিয়ে শিট জুম করে। ভুলে {{key:Mod+Plus}} চাপলে পুরো পেজ বড় হয়; {{key:Mod+0}} দিয়ে আগের অবস্থায় ফেরান। দেখুন [কী, মাউস ও ট্র্যাকপ্যাড](common:keys)।

## সরানো কোথায়

সরানোর কোনো কমান্ড নেই: একটি গণনা-ডট নির্বাচন করে টেনে আনুন, অথবা একটি এলাকা বা লাইন নির্বাচন করে এর কোণের হ্যান্ডেল টেনে আনুন।

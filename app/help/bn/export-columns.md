## Estimate (XLSX ওয়ার্কশিট ও CSV)

প্রতি আইটেমের জন্য একটি সারি, তার পর অ্যাসেমব্লির প্রতিটি উপাদানের জন্য একটি সারি (ইনডেন্টসহ)। তারপর একটি ফাঁকা সারি এবং প্রকল্পের মোট।

| কলাম | বিষয়বস্তু | XLSX-এ |
|---|---|---|
| A Item | আইটেমের নাম (গাঢ়) বা উপাদানের নাম (ইনডেন্টসহ) | লেখা |
| B Type | Linear, Area, Count বা Component | লেখা |
| C Unit | LF, m, SF, SY, m², EA, অথবা উপাদানের একক | লেখা |
| D Quantity | পরিমাপকৃত মোট, অথবা সূত্রের ফল | সংখ্যা |
| E Waste % | অপচয় | শতাংশ (0.10 = 10%) |
| F Qty with waste | পরিমাণ × (1 + অপচয়) | সূত্র `D*(1+E)` |
| G Material per unit | উপকরণের রেট | সংখ্যা |
| H Labor per unit | শ্রমের রেট | সংখ্যা |
| I Material | বর্ধিত উপকরণ | সূত্র `ROUND(F*G,2)` |
| J Labor | বর্ধিত শ্রম | সূত্র `ROUND(F*H,2)` |
| K Total | উপকরণ + শ্রম | সূত্র `I+J` |
| L Notes | ব্যবহৃত সূত্র, সূত্রের ত্রুটি, স্কেলবিহীন শিটে চিহ্ন, দেয়ালের ক্ষেত্রফল, পরিধি | লেখা |

প্রকল্পের মোট সারি: উপরের সব সারির I, J ও K কলামের `SUM`; এবং কিছু বাদ পড়লে Notes-এ "অসম্পূর্ণ: উপরের নোট দেখুন" লেখা থাকে।

সূত্রের ত্রুটি আছে এমন সারিতে কোনো পরিমাণ বা অঙ্ক থাকে না; তার নোটে ত্রুটি লেখা থাকে। হেডার সারি স্থির করা থাকে।

CSV-তে একই কলামে সাধারণ মান থাকে। Waste % হয় শতাংশের সংখ্যা (10 মানে 10%), এবং টাকা ডলারে দুই দশমিক ঘরসহ। স্প্রেডশিট যাকে সূত্র ভাবতে পারে (যা `=`, `+`, `-` বা `@` দিয়ে শুরু হয়), সেই লেখার আগে একটি `'` যোগ করা হয়, যাতে তা লেখা হিসেবেই থাকে।

## By sheet (শুধু XLSX)

| কলাম | বিষয়বস্তু |
|---|---|
| Sheet | শিটের নাম (যখন PDF খোলা থাকে না তখন PDF-এর নামসহ) |
| Item | আইটেমের নাম |
| Quantity | ওই শিটে ওই আইটেমের পরিমাণ, তার এককে |
| Unit | আইটেমের একক |
| Marks | চিহ্নের সংখ্যা |

## Marks (শুধু XLSX)

প্রতি চিহ্নের জন্য একটি সারি।

| কলাম | বিষয়বস্তু |
|---|---|
| Sheet | শিটের নাম |
| Item | আইটেমের নাম |
| Type | Linear, Area বা Count |
| Quantity | দৈর্ঘ্য, নিট ক্ষেত্রফল, অথবা 1 |
| Unit | LF বা m; SF, SY বা m²; EA |
| Detail | Linear: সেগমেন্টের দৈর্ঘ্য, বাদ দেওয়াগুলো "(বাদ)" চিহ্নিত, এবং "আঁকা (length)-এর মধ্যে (length) বাদ"। Area: কাটআউট থাকলে মোট ও কাটআউটের ক্ষেত্রফল, এবং পরিধি। স্কেলবিহীন চিহ্নের জন্য "শিটের কোনো স্কেল নেই"। |
| Bid area | শুধু টেকঅফে bid area থাকলে: চিহ্নের ক্ষেত্রফল, অথবা "কোনো বিড এলাকা নেই" |

## By bid area (শুধু XLSX, টেকঅফে bid area থাকলে)

| কলাম | বিষয়বস্তু |
|---|---|
| Bid area | এলাকার নাম, অথবা "কোনো বিড এলাকা নেই" |
| Item | আইটেম, অথবা তার নিচে ইনডেন্ট করা উপাদান |
| Unit | আইটেম বা উপাদানের একক |
| Quantity | ওই এলাকায় পরিমাপ (উপাদান: এলাকার মোটের সূত্র) |
| Qty with waste | পরিমাণ × (1 + অপচয়) |
| Material, Labor, Total | Estimate-এর মতো সেন্ট পর্যন্ত বর্ধিত |
| Notes | Estimate-এর মতো সূত্র, ত্রুটি ও স্কেলবিহীন চিহ্ন |

প্রতিটি এলাকা একটি "(name) উপমোট" সারি দিয়ে শেষ হয়, যার খরচ সেই সারিগুলোর `SUM` সূত্র; শেষ সারি, **সব বিড এলাকা**, উপমোটগুলো যোগ করে। তখন **Marks** ওয়ার্কশিটে সপ্তম একটি কলাম থাকে, **Bid area**।

## Scales (শুধু XLSX)

স্কেল বা চিহ্ন আছে এমন প্রতিটি শিটের জন্য একটি সারি।

| কলাম | বিষয়বস্তু |
|---|---|
| Sheet | শিটের নাম |
| Scale | প্রিসেটের নাম, অথবা ক্যালিব্রেট করা স্কেল, অথবা "কোনো স্কেল নেই" |
| How | "প্রিসেট", অথবা "ক্যালিব্রেট করা হয়েছে (আপনার টাইপ করা দূরত্বে)" |
| Feet per PDF unit | TakeoffCraft যে সঠিক স্কেল গুণক ব্যবহার করে |

## ফাইলের নাম

- `(name).xlsx` ও `(name).csv`, যেখানে নামটি টেকঅফে প্রথম খোলা PDF থেকে আসে।
- CSV হলো UTF-8, বাইট অর্ডার মার্ক ও Windows লাইন-শেষসহ, যা সব প্ল্যাটফর্মের স্প্রেডশিট প্রোগ্রাম পড়তে পারে।

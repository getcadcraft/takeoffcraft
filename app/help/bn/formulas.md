অ্যাসেমব্লির উপাদানগুলো তাদের পরিমাণ একটি সূত্র থেকে পায়। সূত্র হলো আইটেমের পরিমাপকৃত মানের ওপর একটি ছোট গাণিতিক অভিব্যক্তি। কাজের উদাহরণের জন্য দেখুন [অ্যাসেমব্লি ও সূত্র](topic:assemblies)।

## ভেরিয়েবল

| আইটেমের ধরন | ভেরিয়েবল | অর্থ |
|---|---|---|
| Linear | `L` | মোট দৈর্ঘ্য |
| Linear | `H` | আইটেমের উচ্চতা |
| Linear | `A` | দেয়ালের ক্ষেত্রফল, L × H, যেসব রানে ফাঁক আছে সেগুলোর ফাঁক বাদে (BimCraft থেকে একটি টেকঅফ)। যখন সেই টেকঅফ একটি পরিমাপ পদ্ধতির নাম দেয়, `A` সেই পদ্ধতিতে মাপা হয়: পদ্ধতির ক্ষুদ্রতম আকারের চেয়ে ছোট ফাঁক থাকে, এবং দেয়াল যেখানে মেলে সেখানে পদ্ধতি যা বাদ দেয় তা বাদ যায়। আইটেমের নিচের নোটে পদ্ধতির নাম লেখা থাকে |
| Linear | `N` | রানের সংখ্যা |
| Area | `A` | মোট নিট ক্ষেত্রফল (বাইরের রেখা বিয়োগ কাটআউট) |
| Area | `P` | মোট পরিধি, কাটআউটের প্রান্তসহ |
| Area | `H` | আইটেমের গভীরতা বা পুরুত্ব |
| Area | `N` | ক্ষেত্রের সংখ্যা |
| Count | `N` | গণনা |

- ভেরিয়েবলগুলো আইটেমের এককে থাকে: দেখুন [একক](topic:units)।
- বড় ও ছোট হাতের অক্ষর একই: `l` হলো `L`।
- শুধু আইটেমের নিজস্ব ধরনের ভেরিয়েবল কাজ করে। Linear আইটেমে `P` দিলে দেখায়: `"P" এখানে পরিমাপকৃত মান নয়। L, H, A, N ব্যবহার করুন।`
- খালি উচ্চতা বা গভীরতা হলো 0।

## অপারেটর

| লেখা | অর্থ |
|---|---|
| `+` | যোগ |
| `-` বা `−` | বিয়োগ, অথবা ঋণাত্মক মান |
| `*` বা `×` | গুণ |
| `/` বা `÷` | ভাগ |
| `( )` | গোষ্ঠীবদ্ধ করা |

গুণ ও ভাগ যোগ ও বিয়োগের আগে হয়: `L * 2 + 4` হলো (L × 2) + 4। সন্দেহ হলে বন্ধনী ব্যবহার করুন।

সংখ্যায় দশমিক (`1.333`, `.5`) ও এক্সপোনেন্ট (`1e3` = 1000) থাকতে পারে। ফাঁকা স্থান উপেক্ষা করা হয়।

## ফাংশন

| ফাংশন | ফল | উদাহরণ |
|---|---|---|
| `ceil(x)` | পূর্ণ সংখ্যায় উপরের দিকে গোল | `ceil(67.5)` = 68 |
| `floor(x)` | পূর্ণ সংখ্যায় নিচের দিকে গোল | `floor(67.5)` = 67 |
| `round(x)` | নিকটতম পূর্ণ সংখ্যায় গোল, অর্ধেক শূন্য থেকে দূরে | `round(2.5)` = 3 |
| `round(x, d)` | d দশমিক ঘরে গোল (0 থেকে 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | সবচেয়ে ছোট মান | `min(N, 10)` |
| `max(a, b, …)` | সবচেয়ে বড় মান | `max(1, ceil(N / 12))` |
| `abs(x)` | চিহ্ন ছাড়া মান | `abs(-3)` = 3 |

`ceil` ও `floor` কম্পিউটারের ক্ষুদ্র গোলমাল উপেক্ষা করে, তাই যে মানটি ঠিক 1 হওয়ার কথা তা কখনও 2-তে গোল হয় না।

## ত্রুটি

যে সূত্র পড়া বা হিসাব করা যায় না, সেটি ক্ষেত্রের নিচে তার ত্রুটি দেখায়, এবং উপাদানটি মোটের বাইরে থাকে ({{ui:পরিমাণ}}-এর হেডার বলে "অসম্পূর্ণ")। বার্তাসমূহ:

| বার্তা | সমাধান |
|---|---|
| সূত্র লিখুন, যেমন L বা ceil(L / 1.333) + 1। | সূত্রটি খালি। |
| "X" এখানে পরিমাপকৃত মান নয়। ব্যবহার করুন … | তালিকাভুক্ত একটি ভেরিয়েবল ব্যবহার করুন। |
| "X" এখানে ফাংশন নয়। ব্যবহার করুন ceil, floor, round, min, max, abs। | ওই ফাংশনগুলোর একটি ব্যবহার করুন। |
| "#" সূত্রে অনুমোদিত নয়। | ওই অক্ষরটি সরান (একক, `%`, `$` ও `=` অনুমোদিত নয়)। |
| ")" লেখা নেই / "(" ছাড়া ")" আছে। | বন্ধনী সমান করুন। |
| ")"-এর আগে একটি মান নেই। | যেমন `max(1, )`: মানটি পূরণ করুন। |
| সূত্রটি খুব তাড়াতাড়ি শেষ হয়ে গেছে। | যেমন `L *`: শেষ করুন। |
| অপ্রত্যাশিত "…"। কোনো অপারেটর কি বাদ পড়েছে? | পাশাপাশি দুটি মান, যেমন `2L`: `2 * L` লিখুন। |
| ceil() একটি মান নেয়। | ফাংশনকে সঠিক সংখ্যক মান দিন। |
| round(x, digits)-এর জন্য 0 থেকে 10 এর মধ্যে পূর্ণ দশমিক ঘর লাগে। | পূর্ণ সংখ্যার দশমিক ঘর ব্যবহার করুন। |
| সূত্রটি শূন্য দিয়ে ভাগ করে। | সাধারণত H শূন্য: আইটেমের উচ্চতা বা গভীরতা সেট করুন। |
| সূত্রটি কোনো সংখ্যা দেয় না। | ফলটি সংখ্যা হিসেবে থাকার জন্য খুব বড়। |
| সূত্রটি খুব দীর্ঘ (সর্বোচ্চ 500 অক্ষর)। | ছোট করুন। |

## নিরাপদ নকশা

একটি সূত্র শুধু উপরের ভেরিয়েবল ও ফাংশন দিয়ে গাণিতিক হিসাব করতে পারে। এটি কোড চালাতে বা অন্য কিছু পড়তে পারে না, তাই কেউ আপনাকে পাঠানো প্রকল্প ফাইলের সূত্র ক্ষতিকর নয়।

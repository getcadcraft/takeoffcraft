## اټکل (XLSX کارپاڼه او CSV)

هر توکي لپاره یوه کرښه، وروسته د هغه د جوړښت هره برخه د یوې کرښې په توګه (ننوتې). بیا یوه تشه کرښه او د دندې ټولټال.

| کالم | منځپانګه | په XLSX کې |
|---|---|---|
| A توکی | د توکي نوم (تور) یا د برخې نوم (ننوتی) | متن |
| B ډول | Linear, Area, Count یا Component | متن |
| C واحد | LF, m, SF, SY, m², EA، یا د برخې واحد | متن |
| D مقدار | ټول اندازه شوی، یا د فورمول پایله | شمېره |
| E ضایعات % | ضایعات | سلنه (0.10 = 10%) |
| F د ضایعاتو سره مقدار | مقدار × (1 + ضایعات) | فورمول `D*(1+E)` |
| G د واحد مواد | د موادو نرخ | شمېره |
| H د واحد کار | د کار نرخ | شمېره |
| I مواد | ځانګړي مواد | فورمول `ROUND(F*G,2)` |
| J کار | ځانګړی کار | فورمول `ROUND(F*H,2)` |
| K ټول | مواد + کار | فورمول `I+J` |
| L یادښتونه | کارول شوی فورمول، د فورمول تېروتنه، نښې په شیټونو کې چې پیمانه نلري، د دېوال ساحه، محیط | متن |

د دندې ټولټال کرښه: د I، J او K کالمونو `SUM` د پورتنیو ټولو کرښو په اړه، او په یادښتونو کې "نابشپړ: پورتني یادښتونه وګورئ" کله چې څه پاتې شوي وي.

هغه کرښه چې د فورمول تېروتنه لري مقدار یا پیسې نه لري؛ یادښت یې تېروتنه ښيي. د سرلیک کرښه ثابته ده.

په CSV کې، ورته کالمونه ساده ارزښتونه لري، د ضایعاتو سلنه شمېره ده (10 د 10% لپاره)، او پیسې په ډالرو سره د دوو لسیزو سره دي. متن چې سپریډشیټ یې د فورمول په توګه اخیستلی شي (له `=`، `+`، `-` یا `@` سره پیلېږي) د `'` سره مخته کېږي ترڅو متن پاتې شي.

## د شیټ له مخې (یوازې XLSX)

| کالم | منځپانګه |
|---|---|
| شیټ | د شیټ نوم (د PDF نوم کله چې پرانیستل شوی نه وي) |
| توکی | د توکي نوم |
| مقدار | د هغه توکي مقدار په دې شیټ کې، په خپل واحد |
| واحد | د توکي واحد |
| نښې | د نښو شمېر |

## نښې (یوازې XLSX)

هره نښه یوه کرښه.

| کالم | منځپانګه |
|---|---|
| شیټ | د شیټ نوم |
| توکی | د توکي نوم |
| ډول | Linear، Area یا Count |
| مقدار | اوږدوالی، خالصه ساحه، یا 1 |
| واحد | LF یا m؛ SF، SY یا m²؛ EA |
| تفصیل | Linear: د برخو اوږدوالي، کم شوي برخې د "(deduct)" په نښه، او "deducts (length) of (length) drawn". Area: ټولې او پرې شوې ساحې کله چې پرې شوي وي، او محیط. د بې پیمانې نښو لپاره "Sheet has no scale". |
| د داوطلبۍ ساحه | یوازې کله چې مقدار محاسبه د داوطلبۍ ساحې ولري: د نښې ساحه، یا "No bid area" |

## د داوطلبۍ ساحې له مخې (یوازې XLSX، کله چې مقدار محاسبه د داوطلبۍ ساحې ولري)

| کالم | څه |
|---|---|
| د داوطلبۍ ساحه | د ساحې نوم، یا "No bid area" |
| توکی | توکی، یا د هغه لاندې ننوتې برخه |
| واحد | د توکي یا برخې واحد |
| مقدار | په دې ساحه کې اندازه شوی (برخې: فورمول د ساحې په ټولټالونو) |
| د ضایعاتو سره مقدار | مقدار × (1 + ضایعات) |
| مواد، کار، ټول | تر سنټ پورې حسابېږي، لکه په اټکل کې |
| یادښتونه | فورمول، تېروتنې او بې پیمانې نښې، لکه په اټکل کې |

هره ساحه د "(نوم) فرعي ټولټال" کرښې سره پای ته رسېږي چې لګښتونه یې د هغې کرښو د `SUM` فورمولونه دي؛ وروستۍ کرښه، **ټولې داوطلبۍ ساحې**، فرعي ټولټالونه جمع کوي. د **نښو** کارپاڼه بیا اوومه کالم، **د داوطلبۍ ساحه**، لري.

## پیمانې (یوازې XLSX)

هر شیټ لپاره یوه کرښه چې پیمانه یا نښې لري.

| کالم | منځپانګه |
|---|---|
| شیټ | د شیټ نوم |
| پیمانه | د مخکې ټاکل شوې پیمانې نوم، یا کیلیبره شوې پیمانه، یا "پیمانه نشته" |
| څنګه | "مخکې ټاکل شوی"، یا "د (تاسو ولیکل شوی واټن) پر بنسټ کیلیبره شوی" |
| فوټه په هر PDF واحد | دقیقه پیمانې فکتور چې TakeoffCraft یې کاروي |

## د فایلونو نومونه

- `(name).xlsx` او `(name).csv`، چېرې چې نوم د لومړي PDF څخه اخیستل کېږي چې په مقدار محاسبه کې پرانیستل شوی.
- CSV د UTF-8 سره دی د بایټ ترتیب نښې (BOM) او د Windows د کرښو پای سره، کوم چې د ټولو پلیټ فارمونو سپریډشیټ پروګرامونه لولي.

جوړښتي برخې خپل مقدار د فورمول څخه ترلاسه کوي. فورمول یو لنډ حسابي څرګندونه دی د توکي د اندازه شوو ارزښتونو پر بنسټ. د کار شوو مثالونو لپاره وګورئ [جوړښتونه او فورمولونه](topic:assemblies).

## متغیرات

| د توکي ډول | متغیر | معنی |
|---|---|---|
| کرښوي | `L` | ټوله اوږدوالی |
| کرښوي | `H` | د توکي لوړوالی |
| کرښوي | `A` | د دېوال ساحه، L × H، د هغو سوریو لپاره کم شوې چې لري (د BimCraft څخه مقدار محاسبه). کله چې دا مقدار محاسبه د اندازه کولو میتود نومي، `A` د هغه له مخې اندازه کېږي: هغه سوري چې د میتود له کوچني اندازې کوچني دي پاتې کېږي، او هغه څه چې میتود د دیوالونو په یوځای کېدو کې نیسي پرېښودل کېږي. د توکي لاندې یادښت د میتود نوم ښيي |
| کرښوي | `N` | د کرښو شمېر |
| ساحه | `A` | ټوله خالصه ساحه (بهرني کرښې منفي پرې شوې برخې) |
| ساحه | `P` | ټول محیط، د پرې شوو برخو کنډې په کې |
| ساحه | `H` | د توکي ژورتیا یا ضخامت |
| ساحه | `N` | د ساحو شمېر |
| شمېرنه | `N` | شمېره |

- متغیرات د توکي په واحدونو کې دي: وګورئ [واحدونه](topic:units).
- لوی او کوچني توري یو شان دي: `l` همان `L` دی.
- یوازې د توکي خپل ډول متغیرات کار کوي. د کرښوي توکي لپاره `P` ورکول دا ښیي: `"P" دلته اندازه شوی ارزښت نه دی. وکاروئ L, H, A, N.`
- خالي لوړوالی یا ژورتیا 0 ده.

## عملګرې

| ولیکئ | معنی |
|---|---|
| `+` | جمع |
| `-` یا `−` | تفریق، یا منفي ارزښت |
| `*` یا `×` | ضرب |
| `/` یا `÷` | ویشل |
| `( )` | ګروپول |

ضرب او ویشل د جمع او تفریق څخه مخکې کېږي: `L * 2 + 4` د (L × 2) + 4 دی. کله چې شک وي، قوسونه وکاروئ.

شمېرې کېدای شي لسیزې ولري (`1.333`، `.5`) او توانونه (`1e3` = 1000). ځایونه له پامه غورځول کېږي.

## دندې

| دنده | پایله | بېلګه |
|---|---|---|
| `ceil(x)` | تر بشپړ عدد پورې پورته ګرډول | `ceil(67.5)` = 68 |
| `floor(x)` | تر بشپړ عدد پورې ښکته ګرډول | `floor(67.5)` = 67 |
| `round(x)` | نږدې بشپړ عدد ته ګرډول، نیمایي له صفر څخه لرې | `round(2.5)` = 3 |
| `round(x, d)` | د d لسیزو ته ګرډول (0 تر 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | کوچنی ارزښت | `min(N, 10)` |
| `max(a, b, …)` | لوی ارزښت | `max(1, ceil(N / 12))` |
| `abs(x)` | ارزښت پرته له نښې | `abs(-3)` = 3 |

`ceil` او `floor` د کمپیوټر د ګرډولو کوچني شور له پامه غورځوي، نو هغه ارزښت چې باید 1 وي هېڅکله 2 ته نه ګرډول کېږي.

## تېروتنې

فورمول چې نشي لوستل یا حل کېدای، د ساحې لاندې خپله تېروتنه ښيي، او برخه له ټولو څخه پاتې کېږي (د {{ui:مقدارونه}} سرلیک وايي "نابشپړ"). پیغامونه:

| پیغام | حل |
|---|---|
| فورمول ولیکئ، لکه L یا ceil(L / 1.333) + 1. | فورمول خالي دی. |
| "X" دلته اندازه شوی ارزښت نه دی. وکاروئ … | یو له ښودل شوو متغیرونو وکاروئ. |
| "X" دلته دنده نه ده. وکاروئ ceil, floor, round, min, max, abs. | یو له دې دندو وکاروئ. |
| "#" په فورمول کې اجازه نه لري. | دا نښه لرې کړئ (واحدونه، `%`، `$` او `=` اجازه نه لري). |
| د ")" نشته. / د ")" بې له "(" دی. | قوسونه متوازن کړئ. |
| د ")" مخکې ارزښت نشته. | لکه `max(1, )`: ارزښت ډک کړئ. |
| فورمول ډېر ژر پای ته رسېږي. | لکه `L *`: بشپړ یې کړئ. |
| ناڅاپي "…". ایا عملګر نه دی؟ | دوه ارزښتونه یو په بل پسې، لکه `2L`: `2 * L` ولیکئ. |
| ceil() یو ارزښت اخلي. | دندې ته سم شمېر ارزښتونه ورکړئ. |
| round(x, digits) د 0 څخه تر 10 پورې بشپړ لسیزې غواړي. | بشپړ شمېر لسیزې وکاروئ. |
| فورمول په صفر ویشي. | معمولاً H صفر دی: د توکي لوړوالی یا ژورتیا وټاکئ. |
| فورمول شمېره نه ورکوي. | پایله ډېره لویه ده چې شمېره وي. |
| دا فورمول ډېر اوږد دی (تر 500 تورونو). | لنډ یې کړئ. |

## د ډیزاین له مخې خوندي

فورمول یوازې د پورتنیو متغیرونو او دندو سره حسابي کار کولی شي. دا نشي کولی کوډ چلوي یا بل څه ولولي، نو هغه فورمول چې یو څوک په پروژه فایل کې درولیږي بې ضرره دی.

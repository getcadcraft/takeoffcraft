| کیلي یا عمل | څه کوي |
|---|---|
| کلیک | یو ټکی ږدي (یوه نقطه، د شمیرلو سره). |
| {{key:P}} | لاره: د PDF د یوې کرښې ټوله وصل لاره، یا د کلیک شاوخوا بهرنۍ کرښه ([د PDF کرښې وټاکئ](topic:pick-the-lines)). |
| {{key:F3}} | فعاله یا غیرفعاله د نقشې کرښو ته نښلول ([د نقشې کرښو ته نښلول](topic:snap-to-the-drawing)). |
| {{key:Shift}} د کلیک پر مهال نیولی | برخه د وروستي ټکي څخه 0°، 45°، 90° یا 135° ته ونیسئ. د قوس ټکو یا دایرو لپاره نه. |
| دوه ځله کلیک | یوه لړۍ پای ته ورسوئ، یا یوه ساحه یا کټ وتړئ. |

| {{key:Backspace}} یا {{key:Delete}} | وروستی ټکی لرې کړئ (لومړی د پاتې قوس ټکی). |
| {{key:Esc}} | پاتې قوس ټکی لرې کړئ؛ بیا نا بشپړه نښه لغوه کړئ؛ بیا {{ui:Select}} ته راستون شئ. |

## ټاکل او سمول

| کیلي یا عمل | څه کوي |
|---|---|
| د نښې کلیک ({{ui:Select}} وسیله) | هغه وټاکئ او خپل توکی اوسنی کړئ. |
| {{key:Shift}} + د نښې کلیک | هغه ټاکنې ته اضافه کړئ، یا لرې یې کړئ. |
| {{key:Mod+A}} | په پرانیستې پاڼه کې ټولې نښې وټاکئ. |
| کونج دستګیره کش کړئ | هغه ټکی وخوځوئ ({{key:Shift}} یې 45° ته نیسي). کار کوي کله چې یوه نښه وټاکل شي. |
| {{key:Delete}} یا {{key:Backspace}} | ټاکلې نښې ړنګول (کله چې ترسمول نه کوئ). |
| {{key:Esc}} | هیڅ ونه ټاکئ: ټاکنه او د ازموینې کرښه پاکه کړئ. |
| {{key:Mod+Z}} | بېرته کول. |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | بیا کول. |

## کاپي او سرېښول

| کیلي | څه کوي |
|---|---|
| {{key:Mod+C}} | ټاکلې نښې د خپلو توکو سره کاپي کړئ. |
| {{key:Mod+X}} | پرې کول: ټاکلې نښې کاپي کړئ، بیا یې ړنګ کړئ. |
| {{key:Mod+V}} | سرېښول: کاپي د پوینټر تعقیبوي؛ هغه ځای کلیک کړئ چیرې چې ځي. |
| {{key:Mod+Shift+V}} | په ځای کې سرېښول: په پرانیستې پاڼه کې ورته ځای. |
| {{key:Mod+D}} | ټاکلې نښې ورته جوړول: کاپي د پوینټر تعقیبوي؛ هغه ځای کلیک کړئ چیرې چې ځي. |
| {{key:Esc}} | هیڅ مه ږدئ: هغه سرېښول یا ورته جوړول لغوه کړئ چې په پوینټر کې دی. |

یوازې حروف لا هم وسیلې ټاکي ({{key:C}} دی {{ui:Count}}، {{key:D}} دی {{ui:Check}}، {{key:X}} دی {{ui:Cut-out}}، {{key:V}} دی {{ui:Select}}، {{key:A}} دی {{ui:Area}})؛ یوازې {{key:Mod}} د دې سره کاپي او سرېښول کوي. په متني ساحه کې دا کیلي په عادي ډول متن کاپي او سرېښي. وګورئ [نښې کاپي، سرېښول او ورته جوړول](topic:copy-paste).

:::warning
کله چې نه ترسموئ، {{key:Backspace}} ټاکلې نښه ړنګوي. که دا په ناڅاپي ډول وشي، {{key:Mod+Z}} یې بیرته راولي.
:::

| {{key:F}} | {{ui:Fit page}} |

| {{key:Plus}} یا {{key:=}} | په لید کې په منځ کې زوم ننه. |

| {{key:Ctrl+Shift+F}} | د بشپړې کتګورې ډولونه بدل کړئ (په هر پلیټفورم کې Control، د Mac په شمول). |

## مرسته

| کیلي | څه کوي |
|---|---|
| {{key:F1}} | د مرستې پینل پرانیزئ یا وتړئ (هم د اپ بار {{ui:Help}} تڼۍ). په هره وسیله کې کار کوي، حتی کله چې په ساحه کې لیکئ. |
| {{key:Esc}} | د مرستې پینل وتړئ. په خپل لټون بکس کې، لومړی Esc لټون پاکوي. پداسې حال کې چې پینل پرانیستل شوی، هغه Esc چې د پاڼې کلیک وروسته وهل کیږي لومړی پینل وتړي؛ بیا یې وهئ ترڅو په TakeoffCraft کې لغوه شي. |

:::mac
په ډیری Mac کیبورډونو کې پورتنۍ قطار رڼا او غږ کنټرولوي. fn سره F1 وکاروئ، یا "Use F1, F2, etc. keys as standard function keys" فعال کړئ، په سیسټم سیټینګ کې، "Keyboard" لاندې.
:::

## د پلیټفورم یادښتونه

:::mac
- {{key:Mod}} د Command کیلي ده: {{key:Mod+Z}}، {{key:Mod+S}}، {{key:Mod+O}}. بشپړ کتګور استثنا دی: Control+Shift+F.
- ښی کلیک د ټچپډ پر دوه ګوتو کلیک دی، کله چې د سیسټم سیټینګ کې Trackpad لاندې secondary click فعال وي. TakeoffCraft یوازې ثانوي تڼۍ لولي؛ Control-کلیک ممکن عادي کلیک وګڼل شي او ټکی زیات کړي.
- د ټچپډ پر دوه ګوتو سکرول پاڼه زوم کوي (نه سکرولوي). د لید خوځولو لپاره کش کړئ، یا Space ونیسئ او کش کړئ.
- Page Up او Page Down هغه کیبورډونو کې fn سره د پورته او ښکته غشو سره دي چې دا نلري.
- Backspace هغه کیلي ده چې delete نښه لري.
:::

:::windows
- {{key:Mod}} د Ctrl دی: {{key:Mod+Z}}، {{key:Mod+S}}، {{key:Mod+O}}.
- د لپټاپ ټچپډ پر دوه ګوتو سکرول پاڼه زوم کوي. د لید خوځولو لپاره کش کړئ.
:::

:::linux
- {{key:Mod}} د Ctrl دی. ځینې ډیسک ټاپونه خپل Ctrl+Alt یا Super شارټکټونه لري؛ TakeoffCraft هیڅ یې نه کاروي.
- په ټچپډ کې، دوه ګوتو سکرول پاڼه زوم کوي. د لید خوځولو لپاره کش کړئ.
:::

:::touch
TakeoffCraft ټچ د یوه پوینټر په توګه لولي:

- ټپ ټکی ږدي، نښه ټاکي یا د شمیرلو ټکی اضافه کوي.
- په یوه ګوته کش پاڼه خوځوي (په {{ui:Auto count}} کې د لټون بکس ترسموي).
- پینچ-زوم تر اوسه نه ملاتړ کیږي. {{ui:Fit page}} او {{ui:Fit width}} وکاروئ، یا په کیبورډ کې {{key:Plus}} او {{key:Minus}}.
- د ساحې د تړلو لپاره لومړی ټکی ټپ کړئ. د لړۍ د پای ته رسولو لپاره، دوه ځله ټپ کړئ چیرې چې ستاسو براوزر دوه ټپ دوه ځله کلیک ګرځوي، یا په کیبورډ کې {{key:Enter}} وهئ.
- تر هغې ژوندی اوږدوالی نه ښودل کیږي تر څو ټپ ونه کړئ، ځکه هوور نشته.

کیبورډ او موږک یا ټچپډ نن ورځ د مقدار محاسبې غوره لاره ده.
:::

## هغه کیلي چې براوزر یې ساتي

براوزرونه ځینې شارټکټونه د ځان لپاره ساتي، او پاڼه نشي کارولی: ټب تړل ({{key:Mod+W}})، نوی ټب یا کړکۍ ({{key:Mod+T}}، {{key:Mod+N}})، او د براوزر زوم ({{key:Mod+Plus}}، {{key:Mod+Minus}}). له همدې امله TakeoffCraft پاڼه د ویل او یوازې {{key:Plus}} او {{key:Minus}} کیلیو سره زوم کوي. که په تېروتنه {{key:Mod+Plus}} وفشارئ، ټوله پاڼه لویږي؛ {{key:Mod+0}} بیرته یې راولي. وګورئ [کیلي، موږک او ټچپډ](common:keys).

## د لېږدول چیرې دي

د لېږدولو امر نشته: د شمیرلو ټکی وټاکئ او کش یې کړئ، یا یوه ساحه یا کرښه وټاکئ او د کونجونو دستګیرې کش کړئ.

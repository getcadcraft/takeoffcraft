د یو توکي **اسمبلي** د برخو یوه لیست دی، چې هره برخه یې خپل د مقدار فورمول او خپل ضایعات او نرخونه لري. فورمول د توکي د اندازه شوو ټولو ارزښتونو څخه کار اخلي، نو د یو دېوال یوه اندازه کول ستونچې، پلېټونه او تختې یوځل درکوي، او دوی د اندازه کولو سره تازه کېږي.

## هغه متغیرات چې کارولی شئ

| د توکي ډول | متغیرونه |
|---|---|
| خطي | `L` اوږدوالی، `H` لوړوالی، `A` د دېوال ساحه (L × H)، `N` د کرښو شمېر |
| مساحت | `A` مساحت، `P` محیط (بهرنی کرښه + پرې شوي برخې)، `H` ژورتیا یا ضخامت، `N` د مساحتونو شمېر |
| شمېرل | `N` شمېر |

ارزښتونه د توکي د خپلو واحدونو په اساس دي: د LF او SF توکو لپاره feet او square feet، د m او m² توکو لپاره meters او square meters. د SY توکي لپاره `A` په square yards کې دی، پداسې حال کې چې `P` او `H` په feet کې پاتې کېږي.

فورمولونه `+ - * /` (یا × ÷)، قوسونه، شمېرې، او دندې `ceil`، `floor`، `round`، `min`، `max` او `abs` کاروي. بشپړ قواعد په [د فورمول ژبه](topic:formulas) کې دي.

## کار شوې بېلګه: د کور دننه دېوال

فرض وکړئ چې **Interior wall type A** د خطي توکي په توګه اندازه کړی: 4 کرښې چې ټولې 120 LF دي، او {{ui:لوړوالی}} ته `9'-0"` ټاکل شوی. د هغې **اندازه شوي** ارزښتونه L = 120، N = 4، A = 1,080 (SF د دېوال، یو مخ) ښيي.

1. د {{ui:توکي}} لاندې توکی وټاکئ.
2. په {{ui:اسمبلي}} کې، {{ui:برخه اضافه کول}} وټاکئ.
   یوه برخه چې نوم یې "Component" دی ښکاري، د فورمول `L` سره او پایله یې لاندې.
3. په {{ui:نوم}} کې `Studs 16 in o.c.` او په {{ui:واحد}} کې `EA` ولیکئ.
4. په {{ui:د مقدار فورمول}} کې `ceil(L * 12 / 16) + N` ولیکئ.
   پایله ستاسو د ټایپ کولو سره تازه کېږي: "= 94 EA". دا د 120 فوټو په اوږدو کې هر 16 انچه یوه ستونچه ده (90)، سربیره پر یوه اضافي ستونچې چې د 4 کرښو هر یوه تړي.
5. د پلېټونو لپاره بیا {{ui:برخه اضافه کول}} وټاکئ: نوم `Plates, top and bottom`، واحد `LF`، فورمول `L * 2`. پایله: 240 LF.
6. تختې اضافه کړئ: نوم `Gypsum board 4x8, both sides`، واحد `sheets`، فورمول `ceil(A * 2 / 32)`. پایله: 68 شیټونه (2,160 SF تختې ÷ 32 SF په هر شیټ = 67.5، پورته ګرد شوی).
7. د هرې برخې {{ui:ضایعات %}}، {{ui:مواد $}} او {{ui:کار $}} ډک کړئ.
   هره برخه د {{ui:مقدارونه}} لاندې د توکي په شان خپله کرښه لري، نرخ شوې، او {{ui:د کار ټوله مجموعه}} یې شامل کوي.

که د دېوال ټول لګښت په برخو کې وي، د توکي خپل د موادو او کار نرخونه 0 پرېږدئ، که نه دوه ځله شمېرل کېږي.

:::tip
ضایعات د فورمول وروسته پلي کېږي او نه ګرډېږي: 68 شیټونه د 10% ضایعاتو سره 74.8 شیټونه دي. د بشپړو شیټونو د امر لپاره، ضایعات په فورمول کې واچوئ، لکه `ceil(A * 2 / 32 * 1.1)`، او د برخې ضایعات 0 پرېږدئ.
:::

## نور فورمولونه

| شی | د توکي ډول | فورمول |
|---|---|---|
| ستونچې په 24 انچه مرکز کې | خطي | `ceil(L / 2) + N` |
| عایق بټونه، SF | خطي د لوړوالي سره | `A` |
| رنګ، دواړه خواوې، ګالنونه په 350 SF | خطي د لوړوالي سره | `ceil(A * 2 / 350)` |
| د ټایلو کارټنونه په 15 SF، 10% اضافي | مساحت | `ceil(A * 1.1 / 15)` |
| بیس یا کنارې تزیین، LF | مساحت | `P` |
| کانکرېټ، cubic yards | مساحت د ژورتیا سره | `A * H / 27` |
| کانکرېټ پورته ګرد شوی تر ربع cubic yard | مساحت د ژورتیا سره | `ceil(A * H / 27 * 4) / 4` |
| لولۍ، په هره دروازه درې | شمېرل | `N * 3` |
| لږ تر لږه یو بکس، په هر 12 کې یو | شمېرل | `max(1, ceil(N / 12))` |

## کله چې فورمول غلط وي

د فورمول لاندې کرښه د تېروتنې پیغام ته بدلېږي، د بېلګې په توګه `"X" is not a measured value here. Use L, H, A, N.` یا `A ")" is missing.` بیا برخه هېڅ اندازه نه لري، د {{ui:مقدارونه}} کې د هغې کرښه "Formula error: …" ښيي، او سرلیک وایي "Incomplete: 1 formula error (not in the totals)". فورمول سم کړئ او ټوټلونه تازه کېږي.

هغه فورمول چې په صفر ویشي هم تېروتنه ده ("The formula divides by zero.")، د بېلګې په توګه `A / H` په هغه توکي کې چې ژورتیا نلري.

## حدونه

- فورمولونه د توکي په **ټولو** ارزښتونو چلېږي، نه کرښه په کرښه. `ceil(L * 12 / 16) + N` په هره کرښه یوه ستونچه اضافه کوي؛ تر اوسه د هرې کرښې لپاره ګرډ کول نشته.
- یو فورمول یوازې د خپل توکي متغیرونه کارولی شي، نه د بل توکي.
- په هر توکي کې تر 50 برخو پورې، په هر فورمول کې تر 500 نښو پورې.

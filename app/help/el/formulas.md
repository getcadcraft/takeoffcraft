Τα συστατικά των σύνθετων ειδών παίρνουν την ποσότητά τους από έναν τύπο. Ένας τύπος είναι μια μικρή αριθμητική έκφραση πάνω στις μετρημένες τιμές του είδους. Βλ. [Σύνθετα είδη και τύποι](topic:assemblies) για παραδείγματα.

## Μεταβλητές

| Τύπος είδους | Μεταβλητή | Σημασία |
|---|---|---|
| Γραμμικό | `L` | Συνολικό μήκος |
| Γραμμικό | `H` | Το ύψος του είδους |
| Γραμμικό | `A` | Εμβαδόν τοίχου, L × H, μείον τα ανοίγματα των διαδρομών που τα φέρουν (προμέτρηση από το BimCraft). Όταν αυτή η προμέτρηση ονομάζει μέθοδο μέτρησης, το `A` μετράται με αυτήν: τα ανοίγματα όχι μεγαλύτερα από το μικρότερο μέγεθος της μεθόδου μένουν μέσα, και ό,τι αφαιρεί η μέθοδος στα σημεία συνάντησης των τοίχων δεν λαμβάνεται υπόψη. Η σημείωση κάτω από το είδος ονομάζει τη μέθοδο |
| Γραμμικό | `N` | Πλήθος διαδρομών |
| Εμβαδόν | `A` | Συνολικό καθαρό εμβαδόν (περιγράμματα μείον εγκοπές) |
| Εμβαδόν | `P` | Συνολική περίμετρος, συμπεριλαμβανομένων των ακμών των εγκοπών |
| Εμβαδόν | `H` | Το βάθος ή το πάχος του είδους |
| Εμβαδόν | `N` | Πλήθος εμβαδών |
| Καταμέτρηση | `N` | Η καταμέτρηση |

- Οι μεταβλητές είναι στις μονάδες του είδους: βλ. [Μονάδες](topic:units).
- Κεφαλαία και πεζά είναι το ίδιο: το `l` είναι `L`.
- Λειτουργούν μόνο οι μεταβλητές του τύπου του ίδιου του είδους. Το `P` σε γραμμικό είδος δίνει «"P" δεν είναι μετρημένη τιμή εδώ. Χρησιμοποιήστε L, H, A, N.»
- Ένα κενό ύψος ή βάθος είναι 0.

## Τελεστές

| Γράφετε | Σημασία |
|---|---|
| `+` | Πρόσθεση |
| `-` ή `−` | Αφαίρεση, ή αρνητική τιμή |
| `*` ή `×` | Πολλαπλασιασμός |
| `/` ή `÷` | Διαίρεση |
| `( )` | Ομαδοποίηση |

Ο πολλαπλασιασμός και η διαίρεση προηγούνται της πρόσθεσης και της αφαίρεσης: το `L * 2 + 4` είναι (L × 2) + 4. Χρησιμοποιήστε παρενθέσεις όταν έχετε αμφιβολία.

Οι αριθμοί μπορεί να έχουν δεκαδικά (`1.333`, `.5`) και εκθέτες (`1e3` = 1000). Τα κενά αγνοούνται.

## Συναρτήσεις

| Συνάρτηση | Αποτέλεσμα | Παράδειγμα |
|---|---|---|
| `ceil(x)` | Στρογγυλοποίηση προς τα πάνω σε ακέραιο | `ceil(67.5)` = 68 |
| `floor(x)` | Στρογγυλοποίηση προς τα κάτω σε ακέραιο | `floor(67.5)` = 67 |
| `round(x)` | Στρογγυλοποίηση στον πλησιέστερο ακέραιο, τα μισά μακριά από το μηδέν | `round(2.5)` = 3 |
| `round(x, d)` | Στρογγυλοποίηση σε d δεκαδικά (0 έως 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Η μικρότερη τιμή | `min(N, 10)` |
| `max(a, b, …)` | Η μεγαλύτερη τιμή | `max(1, ceil(N / 12))` |
| `abs(x)` | Η τιμή χωρίς πρόσημο | `abs(-3)` = 3 |

Τα `ceil` και `floor` αγνοούν τον μικροσκοπικό θόρυβο στρογγυλοποίησης του υπολογιστή, οπότε μια τιμή που πρέπει να είναι ακριβώς 1 δεν στρογγυλοποιείται ποτέ στο 2.

## Σφάλματα

Ένας τύπος που δεν μπορεί να διαβαστεί ή να υπολογιστεί εμφανίζει το σφάλμα του κάτω από το πεδίο, και το συστατικό μένει έξω από τα σύνολα (η κεφαλίδα {{ui:Ποσότητες}} γράφει «Ελλιπής»). Μηνύματα:

| Μήνυμα | Διόρθωση |
|---|---|
| «Πληκτρολογήστε έναν τύπο, όπως L ή ceil(L / 1.333) + 1.» | Ο τύπος είναι κενός. |
| «"X" δεν είναι μετρημένη τιμή εδώ. Χρησιμοποιήστε …» | Χρησιμοποιήστε μία από τις μεταβλητές που αναφέρονται. |
| «"X" δεν είναι συνάρτηση εδώ. Χρησιμοποιήστε ceil, floor, round, min, max, abs.» | Χρησιμοποιήστε μία από αυτές τις συναρτήσεις. |
| «Το "#" δεν επιτρέπεται σε τύπο.» | Αφαιρέστε αυτόν τον χαρακτήρα (μονάδες, `%`, `$` και `=` δεν επιτρέπονται). |
| «Λείπει ένα ")".» / «Υπάρχει ένα ")" χωρίς το "(" του.» | Εξισορροπήστε τις παρενθέσεις. |
| «Λείπει μια τιμή πριν από το ")".» | Κάτι όπως `max(1, )`: συμπληρώστε την τιμή. |
| «Ο τύπος τελειώνει πολύ νωρίς.» | Κάτι όπως `L *`: ολοκληρώστε τον. |
| «Απροσδόκητο "…". Λείπει ένας τελεστής;» | Δύο τιμές δίπλα δίπλα, όπως `2L`: γράψτε `2 * L`. |
| «Το ceil() παίρνει 1 τιμή.» | Δώστε στη συνάρτηση τον σωστό αριθμό τιμών. |
| «Το round(x, digits) χρειάζεται ακέραια ψηφία από 0 έως 10.» | Χρησιμοποιήστε ακέραιο αριθμό δεκαδικών. |
| «Ο τύπος διαιρεί με το μηδέν.» | Συνήθως το H είναι 0: ορίστε το ύψος ή το βάθος του είδους. |
| «Ο τύπος δεν δίνει αριθμό.» | Το αποτέλεσμα είναι πολύ μεγάλο για να είναι αριθμός. |
| «Ο τύπος είναι πολύ μεγάλος (έως 500 χαρακτήρες).» | Συντομεύστε τον. |

## Ασφαλής εκ σχεδιασμού

Ένας τύπος μπορεί να κάνει μόνο αριθμητική με τις μεταβλητές και τις συναρτήσεις που αναφέρονται παραπάνω. Δεν μπορεί να εκτελέσει κώδικα ούτε να διαβάσει οτιδήποτε άλλο, οπότε ένας τύπος σε αρχείο έργου που σας στέλνει κάποιος είναι ακίνδυνος.

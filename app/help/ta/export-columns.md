## மதிப்பீடு (XLSX பணித்தாள் மற்றும் CSV)

ஒரு வரி ஒரு உருப்படிக்கு, அதைத் தொடர்ந்து அதன் தொகுப்பின் ஒவ்வொரு கூறுக்கும் ஒரு வரி (உள்தள்ளப்பட்டு). பின்னர் ஒரு வெற்று வரி மற்றும் வேலையின் மொத்தம்.

| நெடுவரிசை | உள்ளடக்கம் | XLSX இல் |
|---|---|---|
| A உருப்படி | உருப்படியின் பெயர் (தடித்து) அல்லது கூறின் பெயர் (உள்தள்ளப்பட்டு) | உரை |
| B வகை | நேரியல், பரப்பளவு, எண்ணிக்கை அல்லது கூறு | உரை |
| C அலகு | LF, m, SF, SY, m², EA, அல்லது கூறின் அலகு | உரை |
| D அளவு | அளந்த மொத்தம், அல்லது சூத்திர முடிவு | எண் |
| E கழிவு % | கழிவு | சதவீதம் (0.10 = 10%) |
| F கழிவுடன் அளவு | அளவு × (1 + கழிவு) | சூத்திரம் `D*(1+E)` |
| G ஓர் அலகுக்குப் பொருள் | பொருள் விகிதம் | எண் |
| H ஓர் அலகுக்கு உழைப்பு | உழைப்பு விகிதம் | எண் |
| I பொருள் | நீட்டிக்கப்பட்ட பொருள் | சூத்திரம் `ROUND(F*G,2)` |
| J உழைப்பு | நீட்டிக்கப்பட்ட உழைப்பு | சூத்திரம் `ROUND(F*H,2)` |
| K மொத்தம் | பொருள் + உழைப்பு | சூத்திரம் `I+J` |
| L குறிப்புகள் | பயன்படுத்திய சூத்திரம், சூத்திரப் பிழை, அளவுகோல் இல்லாத தாள்களில் குறிகள், சுவர் பரப்பு, சுற்றளவு | உரை |

வேலையின் மொத்த வரி: மேலே உள்ள எல்லா வரிகளின் மீதும் I, J மற்றும் K நெடுவரிசைகளுக்கான `SUM`, மேலும் ஏதேனும் விடுபட்டிருந்தால் குறிப்புகளில் "முழுமையற்றது: மேலே உள்ள குறிப்புகளைக் காண்க".

சூத்திரப் பிழை உள்ள வரிக்கு அளவோ தொகைகளோ இல்லை; அதன் குறிப்பு பிழையைக் கூறும். தலைப்பு வரி உறைந்திருக்கும்.

CSV இல், அதே நெடுவரிசைகள் எளிய மதிப்புகளைக் கொண்டிருக்கும்; கழிவு % என்பது சதவீத எண் (10% க்கு 10), பணம் டாலரில் இரண்டு தசமங்களுடன். விரிதாள் நிரல் சூத்திரமாக எடுத்துக்கொள்ளக்கூடிய உரை (`=`, `+`, `-` அல்லது `@` இல் தொடங்கும்) உரையாகவே இருக்க முன்னால் ஒரு `'` பெறும்.

## தாள் வாரியாக (XLSX மட்டும்)

| நெடுவரிசை | உள்ளடக்கம் |
|---|---|
| Sheet (தாள்) | தாளின் பெயர் (PDF பெயருடன், அது திறக்கப்படாதபோது) |
| Item (உருப்படி) | உருப்படியின் பெயர் |
| Quantity (அளவு) | அந்தத் தாளில் அந்த உருப்படியின் அளவு, அதன் அலகில் |
| Unit (அலகு) | உருப்படியின் அலகு |
| Marks (குறிகள்) | குறிகளின் எண்ணிக்கை |

## குறிகள் (XLSX மட்டும்)

ஒரு குறிக்கு ஒரு வரி.

| நெடுவரிசை | உள்ளடக்கம் |
|---|---|
| Sheet (தாள்) | தாளின் பெயர் |
| Item (உருப்படி) | உருப்படியின் பெயர் |
| Type (வகை) | நேரியல், பரப்பளவு அல்லது எண்ணிக்கை |
| Quantity (அளவு) | நீளம், நிகரப் பரப்பளவு, அல்லது 1 |
| Unit (அலகு) | LF அல்லது m; SF, SY அல்லது m²; EA |
| Detail (விவரம்) | நேரியல்: பிரிவு நீளங்கள், கழிக்கப்பட்டவை "(கழிவு)" எனக் குறிக்கப்பட்டு, மற்றும் "வரையப்பட்ட (நீளம்) இல் (நீளம்) கழிவு". பரப்பளவு: வெட்டுகள் இருக்கும்போது மொத்த மற்றும் வெட்டுப் பரப்பளவுகள், மற்றும் சுற்றளவு. அளவுகோல் இல்லாத குறிகளுக்கு "தாளுக்கு அளவுகோல் இல்லை". |
| Bid area (ஒப்பந்தப்புள்ளிப் பகுதி) | ஒப்பந்தப்புள்ளிப் பகுதிகள் இருக்கும்போது மட்டும்: குறியின் பகுதி, அல்லது "ஒப்பந்தப்புள்ளிப் பகுதி இல்லை" |

## ஒப்பந்தப்புள்ளிப் பகுதி வாரியாக (XLSX மட்டும், அளவு கணக்கீட்டில் ஒப்பந்தப்புள்ளிப் பகுதிகள் இருக்கும்போது)

| நெடுவரிசை | என்ன |
|---|---|
| Bid area (ஒப்பந்தப்புள்ளிப் பகுதி) | பகுதியின் பெயர், அல்லது "ஒப்பந்தப்புள்ளிப் பகுதி இல்லை" |
| Item (உருப்படி) | உருப்படி, அல்லது அதன் கீழ் உள்தள்ளப்பட்ட ஒரு கூறு |
| Unit (அலகு) | உருப்படியின் அல்லது கூறின் அலகு |
| Quantity (அளவு) | அந்தப் பகுதியில் அளக்கப்பட்டது (கூறுகள்: பகுதியின் மொத்தங்களின் மீதான சூத்திரம்) |
| Qty with waste (கழிவுடன் அளவு) | அளவு × (1 + கழிவு) |
| Material, Labor, Total (பொருள், உழைப்பு, மொத்தம்) | மதிப்பீட்டில் உள்ளது போல, சென்ட் வரை நீட்டிக்கப்பட்டது |
| Notes (குறிப்புகள்) | மதிப்பீட்டில் உள்ளது போல சூத்திரம், பிழைகள் மற்றும் அளவுகோல் இல்லாத குறிகள் |

ஒவ்வொரு பகுதியும் "(பெயர்) துணைத்தொகை" வரியுடன் முடியும்; அதன் செலவுகள் அதன் வரிகளின் `SUM` சூத்திரங்கள். கடைசி வரி, **எல்லா ஒப்பந்தப்புள்ளிப் பகுதிகளும்**, துணைத்தொகைகளைச் சேர்க்கும். **குறிகள்** பணித்தாளில் ஏழாவது நெடுவரிசையாக **ஒப்பந்தப்புள்ளிப் பகுதி** இருக்கும்.

## அளவுகோல்கள் (XLSX மட்டும்)

ஸ்கேல் அல்லது குறிகள் உள்ள ஒவ்வொரு தாளுக்கும் ஒரு வரி.

| நெடுவரிசை | உள்ளடக்கம் |
|---|---|
| Sheet (தாள்) | தாளின் பெயர் |
| Scale (அளவுகோல்) | முன்னமைவின் பெயர், அல்லது அளவுத்திருத்தம் செய்யப்பட்ட அளவுகோல், அல்லது "அளவுகோல் இல்லை" |
| How (எப்படி) | "முன்னமைவு", அல்லது "நீங்கள் தட்டச்சு செய்த தூரத்தில் அளவுத்திருத்தம் செய்யப்பட்டது" |
| Feet per PDF unit (PDF அலகுக்கு அடி) | TakeoffCraft பயன்படுத்தும் சரியான அளவுகோல் காரணி |

## கோப்புப் பெயர்கள்

- `(பெயர்).xlsx` மற்றும் `(பெயர்).csv`, பெயர் அளவு கணக்கீட்டில் திறக்கப்பட்ட முதல் PDF இலிருந்து வருகிறது.
- CSV என்பது பைட் வரிசைக் குறியுடன் கூடிய UTF-8, விண்டோஸ் வரி முடிவுகளுடன்; எல்லா தளங்களிலும் உள்ள விரிதாள் நிரல்கள் அதைப் படிக்கும்.

நீங்கள் ஒரு புலத்தில் தட்டச்சு செய்யாதபோது, சுட்டி பக்கத்தில் எங்கிருந்தாலும் எழுத்து விசைகள் வேலை செய்யும். ஓர் உரையாடல் திறந்திருக்கும்போது, அதன் சொந்த விசைகள் பொருந்தும். எழுத்துகள் {{key:Shift}} உடன் அல்லது இல்லாமலும் வேலை செய்யும்.

## வரையும்போது

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| கிளிக் | ஒரு புள்ளியை வை (எண்ணுடன், ஒரு புள்ளி). |
| {{key:P}} | பாதை: ஒரு PDF கோட்டின் முழு இணைக்கப்பட்ட பாதையையோ அல்லது ஒரு கிளிக்கைச் சுற்றியுள்ள வெளிவரையையோ தேர்ந்தெடு ([PDF இன் கோடுகளைத் தேர்ந்தெடு](topic:pick-the-lines)). |
| {{key:F3}} | வரைபடத்தின் கோடுகளில் ஒட்டுவதை இயக்கு அல்லது அணை ([வரைபடத்தின் கோடுகளில் ஒட்டு](topic:snap-to-the-drawing)). |
| கிளிக் செய்யும்போது {{key:Shift}} அழுத்திப் பிடித்து | பிரிவை கடைசிப் புள்ளியிலிருந்து 0°, 45°, 90° அல்லது 135° இல் ஒட்டு. வில் புள்ளிகள் அல்லது வட்டங்களுக்கு இல்லை. |
| இருமுறை கிளிக் | ஓட்டத்தை முடி, அல்லது ஒரு பரப்பளவு அல்லது வெட்டுத்துளையை மூடு. |
| {{key:Enter}} | ஓட்டத்தை முடி, அல்லது ஒரு பரப்பளவு அல்லது வெட்டுத்துளையை மூடு. |
| வலது கிளிக் (நகராமல்) | ஓட்டத்தை முடி, அல்லது ஒரு பரப்பளவு அல்லது வெட்டுத்துளையை மூடு. |
| முதல் புள்ளியைக் கிளிக் | ஒரு பரப்பளவு அல்லது வெட்டுத்துளையை மூடு (மூன்றாம் புள்ளியிலிருந்து). |
| {{key:Backspace}} அல்லது {{key:Delete}} | கடைசிப் புள்ளியை நீக்கு (முதலில் நிலுவையிலுள்ள வில் புள்ளி). |
| {{key:Esc}} | நிலுவையிலுள்ள வில் புள்ளியைக் கைவிடு; பின்னர் முடிக்கப்படாத குறியை ரத்துசெய்; பின்னர் {{ui:தேர்ந்தெடு}} க்குத் திரும்பு. |

## தேர்ந்தெடுத்தல் மற்றும் திருத்துதல்

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| ஒரு குறியைக் கிளிக் ({{ui:தேர்ந்தெடு}} கருவி) | அதைத் தேர்ந்தெடு, அதன் உருப்படியைத் தற்போதையதாக்கு. |
| {{key:Shift}} + ஒரு குறியைக் கிளிக் | தேர்வில் சேர், அல்லது தேர்விலிருந்து நீக்கு. |
| {{key:Mod+A}} | திறந்த தாளிலுள்ள ஒவ்வொரு குறியையும் தேர்ந்தெடு. |
| ஒரு மூலைப் பிடியை இழு | அந்தப் புள்ளியை நகர்த்து ({{key:Shift}} 45° இல் ஒட்டும்). ஒரு குறி தேர்ந்தெடுக்கப்படும்போது வேலை செய்யும். |
| {{key:Delete}} அல்லது {{key:Backspace}} | தேர்ந்தெடுத்த குறிகளை நீக்கு (நீங்கள் வரையாதபோது). |
| {{key:Esc}} | தேர்வை நீக்கு: தேர்வையும் சரிபார்ப்புக் கோட்டையும் அழி. |
| {{key:Mod+Z}} | {{ui:செயல்தவிர்}}. |
| {{key:Mod+Y}} அல்லது {{key:Mod+Shift+Z}} | மீண்டும்செய். |

## நகலெடு மற்றும் ஒட்டு

| விசை | என்ன செய்யும் |
|---|---|
| {{key:Mod+C}} | தேர்ந்தெடுத்த குறிகளை அவற்றின் உருப்படிகளுடன் நகலெடு. |
| {{key:Mod+X}} | வெட்டு: தேர்ந்தெடுத்த குறிகளை நகலெடு, பின்னர் அவற்றை நீக்கு. |
| {{key:Mod+V}} | ஒட்டு: நகல் சுட்டியைப் பின்தொடரும்; அது போக வேண்டிய இடத்தில் கிளிக் செய். |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: திறந்த தாளில் அதே இடம். |
| {{key:Mod+D}} | தேர்ந்தெடுத்த குறிகளை நகலாக்கு: நகல் சுட்டியைப் பின்தொடரும்; அது போக வேண்டிய இடத்தில் கிளிக் செய். |
| {{key:Esc}} | எதையும் வைக்காதே: சுட்டியில் உள்ள ஒட்டுதல் அல்லது நகலாக்கலை ரத்துசெய். |

தனியான எழுத்துகளும் இன்னும் கருவிகளைத் தேர்ந்தெடுக்கும் ({{key:C}} என்பது {{ui:எண்ணு}}, {{key:D}} என்பது {{ui:சரிபார்}}, {{key:X}} என்பது {{ui:வெட்டுத்துளை}}, {{key:V}} என்பது {{ui:தேர்ந்தெடு}}, {{key:A}} என்பது {{ui:பரப்பளவு}}); {{key:Mod}} உடன் சேர்ந்தால் மட்டுமே அவை நகலெடுக்கும் மற்றும் ஒட்டும். ஒரு உரைப் புலத்தில் இந்த விசைகள் வழக்கம்போல் உரையை நகலெடுத்து ஒட்டும். பார்க்க: [குறிகளை நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste).

:::warning
வரையாதபோது {{key:Backspace}} தேர்ந்தெடுத்த குறியை நீக்கும். தவறுதலாக நடந்தால், {{key:Mod+Z}} அதைத் திரும்பக் கொண்டுவரும்.
:::

| {{key:Space}} அழுத்திப் பிடித்து + இழு | எந்தக் கருவியிலும் நகர்த்து. |
| {{key:F}} | {{ui:பக்கம் பொருத்து}} |
| {{key:W}} | {{ui:அகலம் பொருத்து}} |

| {{key:Minus}} | பார்வையின் நடுவில் சிறிதாக்கு. |

| {{key:Ctrl+Shift+F}} | முழுத்திரை முறைகளை மாற்று (எல்லா தளங்களிலும் Control, Mac இலும் கூட). |
| {{key:F1}} | இந்த உதவியைத் திற அல்லது மூடு, பக்கத்தின் ஓர் ஒரு பலகம். |
| {{key:3}} | தாளின் 3D சரிபார்ப்புக் காட்சி, இயக்கு அல்லது அணை. |

## தானாக எண்ணு

| விசை அல்லது செயல் | என்ன செய்யும் |
|---|---|
| ஒரு பெட்டியை இழு | தேட வேண்டிய சின்னத்தைப் பெட்டியில் அடை (தேடலைத் தொடங்கும்). |
| ஒரு பொருத்தப் பெட்டியைக் கிளிக் | அதை நிராகரி, அல்லது மீட்டெடு. |
| {{key:Esc}} | நடந்துகொண்டிருக்கும் தேடலை ரத்துசெய், அல்லது மதிப்பாய்வை நிராகரி. |

## உதவி

| விசை | என்ன செய்யும் |
|---|---|
| {{key:F1}} | உதவிப் பலகத்தைத் திற அல்லது மூடு (பயன்பாட்டுப் பட்டியின் {{ui:உதவி}} பொத்தானும் கூட). எல்லாக் கருவிகளிலும் வேலை செய்யும், புலத்தில் தட்டச்சு செய்துகொண்டிருந்தாலும் கூட. |
| {{key:Esc}} | உதவிப் பலகத்தை மூடு. அதன் தேடல் பெட்டியில், முதல் Esc தேடலை அழிக்கும். பலகம் திறந்திருக்கும்போது, தாளைக் கிளிக் செய்த பின் அழுத்தும் Esc முதலில் பலகத்தை மூடும்; TakeoffCraft இல் ரத்துசெய்ய மீண்டும் அழுத்து. |

:::touch
TakeoffCraft தொடுதலை ஒரே சுட்டியாகப் படிக்கும்:

- தட்டு ஒரு புள்ளியை வைக்கும், ஒரு குறியைத் தேர்ந்தெடுக்கும் அல்லது ஓர் எண்ணிக்கைப் புள்ளியைச் சேர்க்கும்.
- ஒரு விரலால் இழுத்தால் தாள் நகரும் ({{ui:தானாக எண்ணு}}வில் அது தேடல் பெட்டியை வரையும்).
- கிள்ளி-பெரிதாக்குதல் இன்னும் ஆதரிக்கப்படவில்லை. {{ui:பக்கம் பொருத்து}} மற்றும் {{ui:அகலம் பொருத்து}} ஐப் பயன்படுத்து, அல்லது விசைப்பலகையில் {{key:Plus}} மற்றும் {{key:Minus}}.
- ஒரு பரப்பளவை மூட, அதன் முதல் புள்ளியைத் தட்டு. ஓட்டத்தை முடிக்க, உங்கள் உலாவி இருமுறை தட்டலை இரட்டைக் கிளிக்காக மாற்றும் இடத்தில் இருமுறை தட்டு, அல்லது விசைப்பலகையில் {{key:Enter}} அழுத்து.
- சுட்டி மேலே வட்டமிடுதல் இல்லாததால், நீங்கள் தட்டும் வரை நேரடி நீள அளவு காட்டப்படாது.

இன்று அளவு கணக்கீட்டுக்குச் சிறந்த வழி விசைப்பலகை மற்றும் சுட்டி அல்லது டிராக்பேடு.
:::

## உலாவி வைத்துக்கொள்ளும் விசைகள்

உலாவிகள் சில குறுக்குவழிகளைத் தங்களுக்கென வைத்துக்கொள்ளும், பக்கம் அவற்றைப் பயன்படுத்த முடியாது: தாவலை மூடுவது ({{key:Mod+W}}), புதிய தாவல் அல்லது சாளரம் ({{key:Mod+T}}, {{key:Mod+N}}), மற்றும் உலாவி பெரிதாக்கம் ({{key:Mod+Plus}}, {{key:Mod+Minus}}). அதனால்தான் TakeoffCraft சக்கரத்தாலும் வெற்று {{key:Plus}} மற்றும் {{key:Minus}} விசைகளாலும் தாளைப் பெரிதாக்குகிறது. {{key:Mod+Plus}} ஐத் தவறுதலாக அழுத்தினால், முழுப் பக்கமும் பெரிதாகும்; {{key:Mod+0}} அதை மீட்டெடுக்கும். பார்க்க: [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys).

## நகர்த்து எங்கே இருக்கிறது

நகர்த்து கட்டளை இல்லை: ஓர் எண்ணிக்கைப் புள்ளியைத் தேர்ந்தெடுத்து இழு, அல்லது ஒரு பரப்பளவு அல்லது கோட்டைத் தேர்ந்தெடுத்து அதன் மூலைப் பிடிகளை இழு.

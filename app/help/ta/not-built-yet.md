TakeoffCraft வளர்ச்சியில் உள்ளது. இந்தப் பட்டியல் தற்போதைய உருவாக்கம் செய்யாதவற்றையும், வேலையை எப்படியும் முடிக்கும் வழியையும் காட்டுகிறது.

| லத்தீன் அல்லாத ஸ்கிரிப்ட்களில் உள்ள வரைபட உரை, குறிக்கப்பட்ட PDF இல் | Helvetica க்கு குறியீடு இல்லாத எழுத்துகள் குறிக்கப்பட்ட PDF இல் "?" ஆக அச்சாகும்; திரையில் உள்ள வரைபடம் பாதிக்கப்படாது. |
| தாளின் பட்டியிலிருந்து வரைபடத்தை மற்றொரு செயலிக்கு ஒப்படைத்தல் | அதே கோப்பை அந்தச் செயலியில் திறக்கவும். |

| ஏற்கனவே அனுப்பப்பட்ட தொகுப்புக்கான திருத்த இணைப்புகள், ஒப்பந்த வழங்கல் கடிதங்கள், ஒவ்வொரு ஏலதாரரும் ஒப்புதல் அளிக்கும் பணி வரம்புத் தாள் | புதிய தொகுப்பை அனுப்பி, ஒப்பந்தத்தை நீங்களே எழுதவும். [ஏலங்களுக்குத் தொகுப்பை அனுப்புதல்](topic:bid-invitations) கட்டமைக்கப்பட்டவற்றை விளக்குகிறது. |
| எந்தக் கணக்கிலிருந்தும் ஏல அழைப்புகளை அனுப்புதல்: சோதனையில் இருக்கும்போது, வெளி ஏலதாரர்களுக்கான மின்னஞ்சல் CadCraft குழு இயக்கிய கணக்குகளைத் தவிர முடக்கப்பட்டுள்ளது | {{ui:Scope CSV}} ஐப் பதிவிறக்கவும், அதை நீங்களே மின்னஞ்சல் அனுப்பி, ஏலங்களை உள்ளிடவும். |
| Studio சாளரத்திலிருந்து ஏலத் தொகுப்புகளை அனுப்புதல் | உலாவியில் TakeoffCraft இலிருந்து அனுப்பவும். |
| தேர்ந்தெடுத்த ஏலத்துடன் ஒரு மாற்றீட்டின் ஏலப் பகுதியை மீண்டும் விலையிடுதல் | மாற்றுகளும் ஏலப் பகுதி துணைமொத்தங்களும் உங்கள் சொந்த விலைகளைப் பயன்படுத்தும்; மாற்றீட்டை கையால் சரிசெய்யவும். |
| துணை ஒப்பந்ததாரரின் காப்பீடு அல்லது உரிமத் தேதி முடிவதற்கு முன் தானியங்கி நினைவூட்டல்கள் | தேதி கடந்ததும் அல்லது 30 நாட்களுக்குள் இருக்கும்போது, துணை ஒப்பந்ததாரர்கள் பக்கத்தில் தேதி கொடியிடப்படும்; அழைக்கும்போது அதைச் சரிபார்க்கவும். |

## விரிதாள்கள்

XLSX பணிப்புத்தகம் LibreOffice Calc இல் சரிபார்க்கப்பட்டது; அது ஒவ்வொரு மொத்தத்தையும் TakeoffCraft உடன் ஒரே சென்ட் வரை மீண்டும் கணக்கிட்டது. Excel இல் அது இன்னும் திறக்கப்படவில்லை. விரிதாள் நிரல் எதிர்பாராததைக் காட்டினால், CSV ஏற்றுமதியில் அதே மதிப்பீடு வெற்று மதிப்புகளாக உள்ளது.

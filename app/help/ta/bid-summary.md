மதிப்பீடு நீங்கள் அளவிட்டதை விலையிடுகிறது. **ஒப்பந்தப்புள்ளிச் சுருக்கம்** அதை ஒரு விலையாக மாற்றுகிறது: அதில் விற்பனை வரி, மேல்நிலைச் செலவு, இலாபம் மற்றும் பிணைப்பத்திரம் சேர்க்கப்படும், மேலும் உங்கள் சேர்த்தவை மற்றும் விலக்கியவற்றுடன் ஒரு **முன்மொழிவு PDF** உருவாக்கப்படும்.

## கூட்டல்கள்

ஐந்தில் எதிலும் ஒரு சதவீதத்தைத் தட்டச்சு செய்யவும் (மற்றவற்றை 0 ஆக விடவும்). அவை பின்வரும் வரிசையில் கணக்கிடப்படும், ஒவ்வொன்றும் அதற்கு மேலுள்ளவற்றின் மீது:

| வரி | இவ்வாறு கணக்கிடப்படுகிறது |
|---|---|
| பொருள், தொழிலாளர் | மதிப்பீட்டின் மொத்தங்கள் (அளவு கணக்கீட்டில் [மாற்றுகள்](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts) இருந்தால் அடிப்படை ஒப்பந்தப்புள்ளி). |
| தொழிலாளர் சுமை | சுமை % × தொழிலாளர்: உங்கள் குழுக்களின் ஊதியத்தின் மீதான ஊதிய வரிகள், காப்பீடு மற்றும் நலன்கள். |
| **செலவு** | பொருள் + தொழிலாளர் + தொழிலாளர் சுமை. |
| பொருளின் மீதான விற்பனை வரி | வரி % × பொருள். |
| மேல்நிலைச் செலவு | மேல்நிலைச் செலவு % × (செலவு + வரி). |
| இலாபம் | இலாபம் % × (செலவு + வரி + மேல்நிலைச் செலவு). |
| பிணைப்பத்திரம் | பிணைப்பத்திரம் % × மேலே உள்ள எல்லாம். |
| **ஒப்பந்தப்புள்ளி** | வரிகளின் கூட்டுத்தொகை. |

ஒவ்வொரு வரியும் சென்ட் வரை முழுமையாக்கப்படும். பணிப்புத்தகம் மதிப்பீட்டுப் பணித்தாளின் மொத்தத்தின் கீழ் அதே வரிகளை நேரடி சூத்திரங்களுடன் காட்டும். நீங்கள் தட்டச்சு செய்யும்போதே சுருக்கம் புதுப்பிக்கப்படும்: {{key:Enter}} ஒரு சதவீதத்தை ஏற்கும். ஒவ்வொரு மாற்றும் அதன் சொந்தச் செலவின் மீது அதே கூட்டல்களுடன் காட்டப்படும், எனவே உரிமையாளர் அதை எடுத்துக்கொண்டால் உண்மையில் என்ன மாறும் என்று பார்ப்பார்.

## முன்மொழிவு

முன்மொழிவு என்ன சொல்ல வேண்டும் என்பதை நிரப்பவும்:

- **திட்டம்** (காலியாக இருந்தால் அளவு கணக்கீட்டின் பெயர்), **இவருக்கு** (வாடிக்கையாளர்) மற்றும் **இவரிடமிருந்து** (உங்கள் நிறுவனம்).
- **சேர்த்தவை** மற்றும் **விலக்கியவை**: ஒரு வரிக்கு ஒன்று; முன்னணியில் கோடு அல்லது புள்ளி இருப்பது சரியே.
- **விதிமுறைகள்**: இலவச உரை, எடுத்துக்காட்டாக "30 நாட்களுக்கு செல்லுபடியாகும்."
- **உருப்படிகளையும் அளவுகளையும் பட்டியலிடு**: பணி வரம்பு, உருப்படி வாரியாக, அளவுகளுடன் விலைகள் இல்லாமல். மொத்தத் தொகை முன்மொழிவுக்கு இதைத் தேர்வு நீக்கவும்.

PDF (`<takeoff> - proposal.pdf`) இல் தேதி, ஒவ்வொரு கூட்டலுடனும் ஒப்பந்தப்புள்ளியுடனும் கூடிய விலைத் தொகுதி, மாற்றுகள், பணி வரம்பு, சேர்த்தவை மற்றும் விலக்கியவை, விதிமுறைகள், கையொப்பமிடவும் தேதியிடவும் வரிகள் இருக்கும். சில அளவுகளை அளக்க முடியாவிட்டால் (அளவுகோல் இல்லாத தாள்), அது விலைக்குக் கீழே அதைக் கூறும்.

## ஏற்றுமதிகளில்

அளவு கணக்கீட்டில் ஒப்பந்தப்புள்ளிச் சுருக்கம் வந்ததும், CSV அதனுடன் முடியும்; பணிப்புத்தகத்தில் **ஒப்பந்தப்புள்ளிச் சுருக்கம்** தாள் கிடைக்கும், ஒவ்வொரு வரி, அதன் சதவீதம் மற்றும் தொகையுடன். பார்க்க [மதிப்பீட்டை ஏற்றுமதி செய்](topic:export-estimate).

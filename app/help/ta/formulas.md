தொகுப்பு கூறுகள் தங்கள் அளவை ஒரு சூத்திரத்திலிருந்து பெறுகின்றன. சூத்திரம் என்பது உருப்படியின் அளந்த மதிப்புகளின் மேல் ஒரு சிறிய எண்கணித வெளிப்பாடு. எடுத்துக்காட்டுகளுக்கு [தொகுப்புகளும் சூத்திரங்களும்](topic:assemblies) பார்க்கவும்.

## மாறிகள்

| உருப்படி வகை | மாறி | பொருள் |
|---|---|---|
| நேரியல் | `L` | மொத்த நீளம் |
| நேரியல் | `H` | உருப்படியின் உயரம் |
| நேரியல் | `A` | சுவர் பரப்பு, L × H, அவற்றைக் கொண்டிருக்கும் ஓட்டங்களின் திறப்புகள் கழித்து (BimCraft இலிருந்து ஓர் அளவு கணக்கீடு). அந்த அளவு கணக்கீடு ஓர் அளவீட்டு முறையைக் குறிக்கும்போது, `A` அதன் மூலம் அளக்கப்படும்: முறையின் மிகச் சிறிய அளவை விடப் பெரிதல்லாத திறப்புகள் உள்ளே இருக்கும், மேலும் சுவர்கள் சந்திக்கும் இடத்தில் அந்த முறை அளவிடுவது விடப்படும். உருப்படிக்குக் கீழுள்ள குறிப்பு முறையின் பெயரைக் கூறும் |
| நேரியல் | `N` | ஓட்டங்களின் எண்ணிக்கை |
| பரப்பளவு | `A` | மொத்த நிகரப் பரப்பளவு (வெளிப்புறங்கள் கழித்தல் வெட்டுகள்) |
| பரப்பளவு | `P` | மொத்தச் சுற்றளவு, வெட்டு விளிம்புகள் உட்பட |
| பரப்பளவு | `H` | உருப்படியின் ஆழம் அல்லது தடிமன் |
| பரப்பளவு | `N` | பரப்புகளின் எண்ணிக்கை |
| எண்ணிக்கை | `N` | எண்ணிக்கை |

- மாறிகள் உருப்படியின் அலகுகளில் உள்ளன: [அலகுகள்](topic:units) பார்க்கவும்.
- பெரிய மற்றும் சிறிய எழுத்துகள் ஒன்றே: `l` என்பது `L`.
- உருப்படியின் சொந்த வகையின் மாறிகள் மட்டுமே வேலை செய்யும். நேரியல் உருப்படியில் `P` கொடுத்தால் `"P" இங்கே அளந்த மதிப்பு அல்ல. L, H, A, N ஐப் பயன்படுத்தவும்.` என வரும்.
- வெற்று உயரம் அல்லது ஆழம் 0 ஆகக் கருதப்படும்.

## செயலிகள்

| எழுது | பொருள் |
|---|---|
| `+` | கூட்டு |
| `-` அல்லது `−` | கழி, அல்லது எதிர்மறை மதிப்பு |
| `*` அல்லது `×` | பெருக்கு |
| `/` அல்லது `÷` | வகு |
| `( )` | குழுவாக்கு |

பெருக்கலும் வகுத்தலும் கூட்டலுக்கும் கழித்தலுக்கும் முன் செய்யப்படும்: `L * 2 + 4` என்பது (L × 2) + 4. சந்தேகம் இருந்தால் அடைப்புக்குறிகளைப் பயன்படுத்தவும்.

எண்களில் தசமங்கள் (`1.333`, `.5`) மற்றும் அடுக்குகள் (`1e3` = 1000) இருக்கலாம். இடைவெளிகள் புறக்கணிக்கப்படும்.

## செயல்பாடுகள்

| செயல்பாடு | முடிவு | எடுத்துக்காட்டு |
|---|---|---|
| `ceil(x)` | அடுத்த முழு எண்ணுக்கு மேலே சுற்று | `ceil(67.5)` = 68 |
| `floor(x)` | கீழே சுற்று | `floor(67.5)` = 67 |
| `round(x)` | அருகிலுள்ள முழு எண்ணுக்குச் சுற்று, பாதிகள் பூஜ்யத்திலிருந்து விலக்கப்படும் | `round(2.5)` = 3 |
| `round(x, d)` | d தசமங்களுக்குச் சுற்று (0 முதல் 10 வரை) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | மிகச் சிறிய மதிப்பு | `min(N, 10)` |
| `max(a, b, …)` | மிகப் பெரிய மதிப்பு | `max(1, ceil(N / 12))` |
| `abs(x)` | குறி இல்லாத மதிப்பு | `abs(-3)` = 3 |

`ceil` மற்றும் `floor` சிறிய கணினிச் சுற்றல் இரைச்சலைப் புறக்கணிக்கும், எனவே சரியாக 1 ஆக இருக்க வேண்டிய மதிப்பு ஒருபோதும் 2 ஆகச் சுற்றப்படாது.

## பிழைகள்

படிக்க அல்லது கணக்கிட முடியாத சூத்திரம் அதன் பிழையை புலத்தின் கீழ் காட்டும், மேலும் அந்தக் கூறு மொத்தங்களிலிருந்து விடப்படும் (அளவுகள் தலைப்பு "முழுமையற்றது" என்று சொல்லும்). செய்திகள்:

| செய்தி | திருத்தம் |
|---|---|
| L அல்லது ceil(L / 1.333) + 1 போன்ற ஒரு சூத்திரத்தைத் தட்டச்சு செய்யவும். | சூத்திரம் காலியாக உள்ளது. |
| "X" இங்கே அளந்த மதிப்பு அல்ல. … ஐப் பயன்படுத்தவும் | பட்டியலிடப்பட்ட மாறிகளில் ஒன்றைப் பயன்படுத்தவும். |
| "X" இங்கே ஒரு செயல்பாடு அல்ல. ceil, floor, round, min, max, abs ஐப் பயன்படுத்தவும். | அவற்றில் ஒன்றைப் பயன்படுத்தவும். |
| "#" சூத்திரத்தில் அனுமதிக்கப்படவில்லை. | அந்த எழுத்தை நீக்கவும் (அலகுகள், `%`, `$` மற்றும் `=` அனுமதிக்கப்படாது). |
| ")" விடுபட்டுள்ளது. / "(" இல்லாத ")" உள்ளது. | அடைப்புக்குறிகளைச் சமப்படுத்தவும். |
| ")" க்கு முன் ஒரு மதிப்பு விடுபட்டுள்ளது. | `max(1, )` போன்றது: மதிப்பை நிரப்பவும். |
| சூத்திரம் மிக விரைவில் முடிகிறது. | `L *` போன்றது: அதை முடிக்கவும். |
| எதிர்பாராத "…". ஓர் செயலி விடுபட்டதா? | அருகருகே இரண்டு மதிப்புகள், எடுத்துக்காட்டாக `2L`: `2 * L` என எழுதவும். |
| ceil() ஒரு மதிப்பை எடுக்கும். | செயல்பாட்டுக்குச் சரியான எண்ணிக்கையிலான மதிப்புகளைக் கொடுக்கவும். |
| round(x, digits) க்கு 0 முதல் 10 வரையிலான முழு இலக்கங்கள் தேவை. | முழு எண் தசமங்களைப் பயன்படுத்தவும். |
| சூத்திரம் பூஜ்யத்தால் வகுக்கிறது. | பொதுவாக H பூஜ்யம்: உருப்படியின் உயரம் அல்லது ஆழத்தை அமைக்கவும். |
| சூத்திரம் ஓர் எண்ணைத் தரவில்லை. | முடிவு ஓர் எண்ணாக இருக்க மிகப் பெரியது. |
| அந்தச் சூத்திரம் மிக நீளமானது (அதிகபட்சம் 500 எழுத்துகள்). | அதைச் சுருக்கவும். |

## பாதுகாப்பான வடிவமைப்பு

ஒரு சூத்திரம் மேலே உள்ள மாறிகள் மற்றும் செயல்பாடுகளுடன் எண்கணிதத்தை மட்டுமே செய்ய முடியும். அது குறியீட்டை இயக்கவோ வேறெதையும் படிக்கவோ முடியாது, எனவே யாரோ உங்களுக்கு அனுப்பும் திட்டக் கோப்பில் உள்ள சூத்திரம் தீங்கற்றது.

**விலை நூலகம்** நீங்கள் வேலைக்கு வேலை பயன்படுத்தும் உருப்படிகளை வைத்திருக்கும்: அவற்றின் வகை, அலகு, உயரம், வீணாதல், பொருள் மற்றும் தொழிலாளர் விகிதங்கள், மற்றும் அவற்றின் அசெம்பிளி. அது எந்த அளவு கணக்கீட்டிலிருந்தும் தனியாக இந்த உலாவியில் வைக்கப்படுகிறது, எனவே நீங்கள் இங்கு திறக்கும் ஒவ்வொரு அளவு கணக்கீடும் அதைப் பயன்படுத்தலாம்.

{{ui:Items}} பலகத்தின் மேலுள்ள {{ui:Library}} உடன் அதைத் திறக்கவும்.

## நூலகத்தை நிரப்பு

- {{ui:Import CSV…}} நீங்கள் CSV ஆகச் சேமித்த விரிதாளைப் படிக்கும் (கீழே நெடுவரிசைகளைப் பார்க்கவும்). பெயரும் வகையும் ஏற்கனவே நூலகத்தில் உள்ள உருப்படிகள் மாற்றப்படும்; மற்றவை சேர்க்கப்படும். படிக்க முடியாத வரிசைகள் தவிர்க்கப்படும், எவை, ஏன் என்று அது சொல்லும்.
- இந்த அளவு கணக்கீட்டின் உருப்படிகளைச் சேர் திறந்த அளவு கணக்கீட்டின் ஒவ்வொரு உருப்படியையும், அதன் விகிதங்கள் மற்றும் அசெம்பிளியுடன் நூலகத்தில் நகலெடுக்கும் (அதன் குறிகள் அல்ல).
- TakeoffCraft ஏற்றுமதி செய்யும் மதிப்பீட்டு CSV ([மதிப்பீட்டை ஏற்றுமதி செய்](topic:export-estimate)) அப்படியே இறக்குமதியாகும்: கடைசி வேலையின் விலைகள் அடுத்ததற்கு விதையாகும்.

- {{ui:Trade packs…}} ஒரு வர்த்தகத்துக்கான இலவச அசெம்பிளிகளைச் சேர்க்கும், எடுத்துக்காட்டாக உலர் சுவர், மின்சாரம் அல்லது கான்கிரீட், விலைகள் இல்லாமல். பார்க்க: [தொழில் தொகுப்புகள்](topic:trade-packs).

{{ui:Export CSV}} நூலகத்தை CSV ஆகச் சேமிக்கும், ஒரு நகலை வைத்திருக்க, விரிதாளில் திருத்த அல்லது சக ஊழியருக்குக் கொடுக்க. {{ui:Clear}} அதைக் காலி செய்யும் (இருமுறை கிளிக் செய்யவும்).

:::note
நூலகம் இந்த உலாவியின் சேமிப்பகத்தில் உள்ளது. வேறு உலாவி, வேறு கணினி அல்லது தனிப்பட்ட சாளரத்துக்கு அதன் சொந்தமானது (அல்லது எதுவும் இல்லை). நகர்த்த அதை ஏற்றுமதி செய்யவும்.
:::

## ஓர் அளவு கணக்கீட்டில் பயன்படுத்து

- உருப்படிகளைத் தேர்வு செய்யவும் ({{ui:Find in the library}} இல் தட்டச்சு செய்து பட்டியலைச் சுருக்கவும்), பின்னர் {{ui:Add to takeoff}} ஐத் தேர்ந்தெடுக்கவும். அவை அவற்றின் அசெம்பிளிகளுடன் ஒரே படியில் சேர்க்கப்படும்; அதை {{key:Mod+Z}} திரும்பப் பெறும். அளவு கணக்கீட்டில் ஏற்கனவே உள்ள பெயருக்கு `Carpet (2)` போல ஓர் எண் கிடைக்கும்.
- {{ui:Update prices}} அளவு கணக்கீட்டின் உருப்படிகளுக்கு நூலகத்தின் வீணாதல் மற்றும் விகிதங்களைக் கொடுக்கும், பெயரும் வகையும் பொருந்தும் ஒவ்வொரு நூலக உருப்படிக்கும், அதே பெயரின் அசெம்பிளி கூறுகளுக்கும். உயரங்கள், அலகுகள் மற்றும் சூத்திரங்கள் அப்படியே இருக்கும். ஒரு {{key:Mod+Z}} பழைய விலைகள் அனைத்தையும் மீட்டெடுக்கும்.

## CSV நெடுவரிசைகள்

முதல் வரிசை நெடுவரிசைகளின் பெயர்களைக் கொண்டிருக்கும், எந்த வரிசையிலும்; மற்ற நெடுவரிசைகள் புறக்கணிக்கப்படும்.

| நெடுவரிசை | அதில் என்ன செல்கிறது |
|---|---|
| Item (அல்லது Name) | உருப்படியின் பெயர். கட்டாயம். |
| Type | Linear, Area அல்லது Count (LF, SF மற்றும் EA வும் வேலை செய்யும்). காலியாக விட்டால், அலகு முடிவு செய்யும். |
| Unit | LF அல்லது m; SF, SY அல்லது m²; EA. காலியாக: வகையின் வழக்கமான அலகு. |
| Waste % | `10` அல்லது `10%`. |
| Material per unit, Labor per unit | `2.10` அல்லது `$1,250` போன்ற விகிதங்கள். |
| Height (அல்லது Depth) | `9'-0"`, `9`, அல்லது மெட்ரிக் அலகுகளுக்கு `2.7`. |
| Component, Formula | Component பெயர் (அல்லது Type `Component`) கொண்ட வரிசை, மேலுள்ள உருப்படியின் அசெம்பிளியின் பகுதி. அதன் அலகு, வீணாதல் மற்றும் விகிதங்கள் அதனுடையவை; அதன் சூத்திரம் உருப்படியின் எழுத்துகளைப் பயன்படுத்தும். பார்க்க: [அசெம்பிளிகளும் சூத்திரங்களும்](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

காற்புள்ளிகள், அரைப்புள்ளிகள் அல்லது தாவல் இடைவெளிகள் நெடுவரிசைகளுக்கிடையே எல்லாம் வேலை செய்யும்.

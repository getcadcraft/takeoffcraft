ஓர் உருப்படியின் **தொகுப்பு** என்பது கூறுகளின் பட்டியல்; ஒவ்வொரு கூறுக்கும் அதற்கான அளவுச் சூத்திரமும், அதன் சொந்த வீணாதல் மற்றும் விலைகளும் உண்டு. சூத்திரம் உருப்படியின் அளவிடப்பட்ட மொத்தங்களைப் பயன்படுத்துவதால், ஒரு சுவரின் அளவு கணக்கீட்டிலிருந்தே கம்பிகள், தகடுகள், பலகை ஆகியவை ஒரே நேரத்தில் கிடைக்கும்; நீங்கள் அளவிடும்போதே அவை புதுப்பிக்கப்படும்.

## நீங்கள் பயன்படுத்தக்கூடிய மாறிகள்

| உருப்படி வகை | மாறிகள் |
|---|---|
| நேரியல் | `L` நீளம், `H` உயரம், `A` சுவர்ப் பரப்பளவு (L × H), `N` ஓட்டங்களின் எண்ணிக்கை |
| பரப்பளவு | `A` பரப்பளவு, `P` சுற்றளவு (வெளிக்கோடு + வெட்டுகள்), `H` ஆழம் அல்லது தடிமன், `N` பரப்பளவுகளின் எண்ணிக்கை |
| எண்ணிக்கை | `N` எண்ணிக்கை |

மதிப்புகள் உருப்படியின் சொந்த அலகுகளில் இருக்கும்: LF மற்றும் SF உருப்படிகளுக்கு அடி மற்றும் சதுர அடி; m மற்றும் m² உருப்படிகளுக்கு மீட்டர் மற்றும் சதுர மீட்டர். SY உருப்படிக்கு `A` சதுர கெஜத்தில் இருக்கும்; `P` மற்றும் `H` அடியிலேயே இருக்கும்.

சூத்திரங்களில் `+ - * /` (அல்லது × ÷), அடைப்புக்குறிகள், எண்கள், மற்றும் `ceil`, `floor`, `round`, `min`, `max`, `abs` செயல்பாடுகள் பயன்படுத்தலாம். முழு விதிகளும் [சூத்திர மொழி](topic:formulas) பகுதியில் உள்ளன.

## எடுத்துக்காட்டு: உட்புறச் சுவர்

உட்புறச் சுவர் வகை A என்ற பெயரிலான நேரியல் உருப்படியை அளந்துள்ளீர்கள் என்று வைத்துக்கொள்ளுங்கள்: மொத்தம் 120 LF கொண்ட 4 ஓட்டங்கள், {{ui:உயரம்}} `9'-0"` என அமைக்கப்பட்டுள்ளது. அதன் **அளவிடப்பட்ட** மதிப்புகள்: L = 120, N = 4, A = 1,080 (சுவரின் SF, ஒரு பக்கம்).

1. {{ui:உருப்படிகள்}} கீழ் உருப்படியைத் தேர்ந்தெடுக்கவும்.
2. {{ui:தொகுப்பு}} பிரிவில் {{ui:கூறைச் சேர்}} என்பதைத் தேர்ந்தெடுக்கவும்.
   "கூறு" என்ற பெயரிலான கூறு தோன்றும்; அதில் `L` சூத்திரமும் அதன் முடிவும் கீழே காட்டப்படும்.
3. {{ui:பெயர்}} புலத்தில் `Studs 16 in o.c.` என்றும், {{ui:அலகு}} புலத்தில் `EA` என்றும் தட்டச்சு செய்யவும்.
4. {{ui:அளவுச் சூத்திரம்}} புலத்தில் `ceil(L * 12 / 16) + N` எனத் தட்டச்சு செய்யவும்.
   நீங்கள் தட்டச்சு செய்யும்போதே முடிவு புதுப்பிக்கப்படும்: "= 94 EA". இது 120 அடி நீளத்தில் ஒவ்வொரு 16 அங்குலத்துக்கும் ஒரு கம்பி (90), மேலும் 4 ஓட்டங்களில் ஒவ்வொன்றையும் மூடுவதற்காகக் கூடுதலாக ஒன்று (4) ஆகியவற்றின் கணக்கு.
5. தகடுகளுக்காக மீண்டும் {{ui:கூறைச் சேர்}} என்பதைத் தேர்ந்தெடுக்கவும்: பெயர் `Plates, top and bottom`, அலகு `LF`, சூத்திரம் `L * 2`. முடிவு: 240 LF.
6. பலகையைச் சேர்க்கவும்: பெயர் `Gypsum board 4x8, both sides`, அலகு `sheets`, சூத்திரம் `ceil(A * 2 / 32)`. முடிவு: 68 தாள்கள் (பலகையின் 2,160 SF ÷ ஒரு தாளுக்கு 32 SF = 67.5, மேல்நோக்கி முழுமையாக்கப்பட்டது).
7. ஒவ்வொரு கூறுக்கும் {{ui:வீணாதல் %}}, {{ui:பொருள் $}} மற்றும் {{ui:தொழிலாளர் $}} ஆகியவற்றை நிரப்பவும்.
   ஒவ்வொரு கூறுக்கும் {{ui:அளவுகள்}} பட்டியலில் உருப்படிக்குக் கீழ் தனி வரிசை கிடைக்கும்; அது ஓர் உருப்படியைப் போலவே விலையிடப்படும், மேலும் {{ui:பணியின் மொத்தம்}} அதையும் உள்ளடக்கும்.

சுவரின் முழுச் செலவும் கூறுகளில் இருந்தால், உருப்படியின் சொந்தப் பொருள் மற்றும் தொழிலாளர் விலைகளை 0 ஆக வைத்திருங்கள்; இல்லையெனில் அது இரு முறை கணக்கிடப்படும்.

:::tip
வீணாதல் சூத்திரத்துக்குப் பின் பயன்படுத்தப்படும், முழுமையாக்கப்படாது: 10% வீணாதலுடன் 68 தாள்கள் 74.8 தாள்கள் ஆகும். முழுத் தாள்களை ஆர்டர் செய்ய, வீணாதலைச் சூத்திரத்துக்குள் வைக்கவும், எடுத்துக்காட்டாக `ceil(A * 2 / 32 * 1.1)`, மேலும் கூறின் வீணாதலை 0 ஆக வைக்கவும்.
:::

## மேலும் சூத்திரங்கள்

| என்ன | உருப்படி | சூத்திரம் |
|---|---|---|
| 24 அங்குல மைய இடைவெளியில் கம்பிகள் | நேரியல் | `ceil(L / 2) + N` |
| காப்புப் பாய்கள், SF | உயரத்துடன் நேரியல் | `A` |
| இருபக்கமும் பெயிண்ட், 350 SF இல் கேலன்கள் | உயரத்துடன் நேரியல் | `ceil(A * 2 / 350)` |
| 15 SF இல் டைல் அட்டைப்பெட்டிகள், 10% கூடுதல் | பரப்பளவு | `ceil(A * 1.1 / 15)` |
| அடிப்பலகை அல்லது ஓர அலங்காரம், LF | பரப்பளவு | `P` |
| கான்கிரீட், கனக் கெஜம் | ஆழத்துடன் பரப்பளவு | `A * H / 27` |
| கால் கெஜமாக மேல்நோக்கி முழுமையாக்கப்பட்ட கான்கிரீட் | ஆழத்துடன் பரப்பளவு | `ceil(A * H / 27 * 4) / 4` |
| கதவுக்கு மூன்று வீதம் கீல்கள் | எண்ணிக்கை | `N * 3` |
| குறைந்தபட்சம் ஒரு பெட்டி, ஒவ்வொரு 12 க்கும் ஒன்று | எண்ணிக்கை | `max(1, ceil(N / 12))` |

## சூத்திரம் தவறாக இருக்கும்போது

சூத்திரத்துக்குக் கீழுள்ள வரி பிழைச் செய்தியாக மாறும், எடுத்துக்காட்டாக `"X" is not a measured value here. Use L, H, A, N.` அல்லது `A ")" is missing.` அப்போது கூறுக்கு எந்தத் தொகையும் இருக்காது; {{ui:அளவுகள்}} இல் அதன் வரிசை "Formula error: …" எனக் காட்டும்; தலைப்பில் "Incomplete: 1 formula error (not in the totals)" எனத் தோன்றும். சூத்திரத்தைச் சரிசெய்தால் மொத்தங்களும் புதுப்பிக்கப்படும்.

பூச்சியத்தால் வகுக்கும் சூத்திரமும் பிழையே ("The formula divides by zero."), எடுத்துக்காட்டாக ஆழம் இல்லாத உருப்படியில் `A / H`.

## வரம்புகள்

- சூத்திரங்கள் உருப்படியின் **மொத்தங்களில்** இயங்கும், ஓட்டத்துக்கு ஓட்டம் அல்ல. `ceil(L * 12 / 16) + N` ஒரு ஓட்டத்துக்கு ஒரு கம்பி சேர்க்கும்; ஓட்டம்-ஓட்டமாக முழுமையாக்கல் இன்னும் இல்லை.
- ஒரு சூத்திரம் தன் உருப்படியின் மாறிகளை மட்டுமே பயன்படுத்த முடியும், மற்ற உருப்படியின் மாறிகளை அல்ல.
- ஓர் உருப்படிக்கு அதிகபட்சம் 50 கூறுகள்; ஒரு சூத்திரத்துக்கு 500 எழுத்துகள் வரை.

## ஒரு கூறை நீக்கு

அதன் கீழுள்ள {{ui:கூறை நீக்கு}} என்பதைத் தேர்ந்தெடுக்கவும். {{key:Mod+Z}} மூலம் அதைச் செயல்தவிர்க்கலாம்.

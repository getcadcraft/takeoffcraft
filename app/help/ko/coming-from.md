PlanSwift나 Bluebeam Revu의 측정 도구로 물량 산출을 해 본 적이 있다면, TakeoffCraft의 대부분이 익숙하게 느껴질 것입니다. 도면 세트, 시트별 축척, 측정하는 항목, 그리고 가격이 매겨진 합계가 있습니다. 다만 구성 요소들이 서로 맞물리는 방식은 일부 다르며, 그 차이는 아래에 정리했습니다.

PlanSwift나 On-Screen Takeoff를 써 봤다면, {{ui:Settings}} › {{ui:TakeoffCraft}} › {{ui:Menus, keys and mouse}}에서 {{ui:Takeoff desk}} 메뉴 스타일을 고르십시오. 파일, 편집, 보기, 축척, 물량 산출, 항목, 마크업, 내보내기 메뉴가 있는 메뉴 모음과 물량 산출 도구 줄이 나타나며, 시트 막대에는 축척 사전 설정이 있습니다. [메뉴, 키, 마우스](topic:menus-keys-and-mouse)를 참고하십시오.

## 익숙한 방식과 대응

| 익숙한 방식 | TakeoffCraft에서는 |
|---|---|
| 도면을 저장하는 작업 또는 프로젝트 열기 (PlanSwift) | PDF와 `.takeoff.json` 프로젝트를 나란히 엽니다. 프로젝트에는 물량 산출만 저장되며, PDF는 사용자의 원본 파일로 그대로 남습니다. |
| 메모, 구름, 강조 표시가 있는 마크업 목록 (Bluebeam) | 시트 막대의 {{ui:Markup}}: 상태(Open, Answered, Closed)가 있는 메모, 구름, 강조 표시를 **마크업** 아래에 목록으로 보여 주며, 표시된 PDF에 그려집니다. [메모, 구름, 강조 표시](topic:markups)를 참고하십시오. |
| PDF 안에 마크업으로 저장된 측정값 (Bluebeam) | 물량 산출은 `.takeoff.json` 파일에 들어 있습니다. {{ui:Marked PDF}}: 공유할 때 쓰는 사본으로, 물량 산출이 그려져 있습니다. {{ui:PDF with the takeoff inside}}: TakeoffCraft에서 다시 열 수 있도록 물량 산출을 담은 사본입니다. |
| 물량 산출 항목 (PlanSwift), 도구 상자에 저장한 사용자 측정 도구 (Bluebeam) | {{ui:Items}} 아래의 **항목**: 이름, 유형, 색상, 단위, 높이 또는 깊이, 할증, 단가. |
| 수식이 있는 부품과 복합 단가 (PlanSwift) | 항목의 {{ui:Assembly}}: `L H A N P` 변수를 사용하는 수식이 있는 구성 요소. |
| 페이지 축척 설정 또는 보정 (둘 다) | 시트마다 {{ui:Scale}} 그룹의 {{ui:Preset}} 목록에서 고르거나 {{ui:Calibrate}} 기능을 사용합니다. {{ui:Check}} 기능은 알고 있는 치수를 측정합니다. |
| 여러 페이지 범위에 축척 하나 적용 | 아직 지원하지 않음: 시트마다 설정하십시오. |
| 한 시트에 축척이 다른 뷰포트 (Bluebeam) | 아직 지원하지 않음: 시트당 축척 하나. |
| 폴리선 길이와 면적 도구 (Bluebeam), 선형 및 면적 물량 산출 (PlanSwift) | {{ui:Linear}} ({{key:L}}) · {{ui:Area}} ({{key:A}}). |
| 직선을 그리려고 Shift 누르기 | {{key:Shift}} 키: 45° 단위로 맞춥니다. 같은 원리입니다. |
| 도면 선에 스냅 | 기본으로 켜져 있으며 끝점, 중간점, 교차점, 선 위에서 가장 가까운 점에 맞춥니다. CAD 프로그램과 같이 {{key:F3}}으로 끌 수 있습니다. |
| 수량 도구 (둘 다) | {{ui:Count}} ({{key:C}}). |
| 기호를 시각적으로 찾기 (Bluebeam) | {{ui:Auto count}} ({{key:S}}): 기호 하나를 상자로 지정하고, 검토한 뒤 추가합니다. |
| 면적에서 개구부나 공제 | 선택한 면적에서 {{ui:Cut-out}} ({{key:X}}) 및 원형 개구부. |
| 선형 연속 선의 공제 | 선을 끝까지 곧게 그린 뒤 {{key:E}} ({{ui:Deduct}}) 키를 누르면 개구부를 공제합니다. [연속 선 측정](topic:measure-linear)을 참고하십시오. |
| 폴리선의 호 구간 | {{ui:Arc}} ({{key:R}}): 곡선 위의 점을 클릭한 다음 끝점을 클릭합니다. |
| 수량 열이 있는 마크업 목록 (Bluebeam) | {{ui:Quantities}} 표: {{ui:By item}} 또는 {{ui:By sheet}}. |
| 가격이 있는 견적 그리드 (PlanSwift) | 같은 표: 할증, 재료비 · 노무비 (단위당), 합계, {{ui:Job total}}. |
| Excel 내보내기 | {{ui:XLSX}} (라이브 수식 포함) 또는 {{ui:CSV}}. |
| Esc로 도구 중지 | {{key:Esc}} 키는 취소하고 {{ui:Select}} 도구로 돌아갑니다. |
| 오른쪽 클릭으로 마침 | 여기서도 오른쪽 클릭으로 연속 선을 끝내거나 면적을 닫습니다. 오른쪽 클릭 메뉴는 없습니다. |

## 헷갈리기 쉬운 차이점

**물량 산출은 PDF 안에 들어 있지 않습니다.** 어떤 작업을 해도 PDF는 바뀌지 않습니다. `.takeoff.json` 파일을 저장해 도면과 함께 보관하십시오. 표시된 PDF를 보내도 편집 가능한 물량 산출은 전달되지 않습니다. 프로젝트 파일 및 원본 PDF 파일을 함께 보내거나, [물량 산출이 들어 있는 PDF 파일](topic:save-and-reopen#keep-the-takeoff-inside-the-pdf)을 보내십시오.

**PDF 파일은 이름이 아니라 내용으로 대조합니다.** 개정된 시트를 예전 파일 이름 그대로 덮어쓰면 TakeoffCraft에는 축척도 표식도 없는 새 파일로 인식됩니다. 예전 표식은 예전 버전에 남아 계속 집계됩니다. [물량 산출 저장 및 다시 열기](topic:save-and-reopen#when-a-pdf-has-changed)를 참고하십시오.

**축척이 없는 표식은 0으로 세지 않고 제외합니다.** 시트에 축척이 없으면 그 시트의 연속 선과 면적은 집계되지 않으며, 표에는 "미완성"이라고 표시됩니다. 많은 프로그램에서는 그냥 0으로 보게 됩니다. [축척 설정](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero)을 참고하십시오.

**용지 크기를 추측하지 않습니다.** 사전 설정은 PDF 파일이 실제 크기로 인쇄되었다고 가정합니다. 절반 크기나 "페이지에 맞춤"으로 출력된 PDF에는 {{ui:Calibrate}} 기능이 필요합니다. 항상 {{ui:Check}} 기능을 사용하십시오.

**항목 하나에는 기본 유형 하나, 필요하면 더 많은 종류.** 항목은 선형, 면적 또는 개수이며, 표식이 생기면 유형이 고정됩니다. 면적과 둘레를 함께 얻는 조건은 면적 항목입니다. 둘레는 `P` 변수입니다. 길이와 면적을 모두 갖는 벽은 높이가 있는 선형 항목입니다. 바닥, 걸레받이, 문이 있는 방처럼 여러 조건을 가진 항목은 **추가 측정**에서 다른 종류를 체크하십시오. 각각 자기 행에 가격이 매겨집니다. [항목 하나, 여러 종류의 표식](topic:create-items#one-item-several-kinds-of-marks)을 참고하십시오.

**수식은 합계로 계산됩니다.** 복합 단가의 수식은 연속 선마다가 아니라 모든 시트에 걸친 항목의 합계를 사용합니다. `N`(연속 선 또는 면적의 수)은 벽마다 스터드 하나를 더하는 것처럼 연속 선마다 추가되는 항목에 쓰입니다.

**둘레에는 개구부가 포함됩니다.** 면적의 `P`는 구멍의 가장자리를 더합니다. [개구부가 있는 면적 측정](topic:measure-areas#read-the-area)을 참고하십시오.

**드래그하면 초점이 이동합니다.** {{ui:Auto count}} 기능을 제외한 모든 도구에서 시트를 왼쪽 버튼으로 드래그하면 초점이 이동합니다. 초점 이동 도구로 바꿀 필요는 없습니다. 휠은 줌 기능을 하며 스크롤하지 않습니다.

**복구용 사본이지 클라우드가 아닙니다.** TakeoffCraft는 작업의 사본을 이 브라우저에 보관하고, 비정상 종료 뒤 복구를 제안합니다([탭이나 브라우저가 멈추면](topic:save-and-reopen#if-the-tab-or-the-browser-stops)). 그러나 물량 산출은 직접 저장해야 합니다: {{key:Mod+S}}. 클라우드 저장은 아직 제공되지 않습니다.

**모든 것이 브라우저에서 동작합니다.** 설치할 것이 없으며, 도면은 절대 업로드되지 않습니다. 데스크톱 앱은 CadCraft Studio에서 다른 일곱 개 앱과 함께 제공되며, TakeoffCraft도 그중 하나입니다.

## 아직 없는 기능

시트별 축척 영역은 아직 만들지 않았습니다. 전체 목록과 대안은 [아직 만들지 않은 기능](topic:not-built-yet)을 참고하십시오.

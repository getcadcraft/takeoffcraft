**단가 라이브러리**에는 작업마다 쓰는 항목을 보관합니다. 항목의 유형, 단위, 높이, 할증, 재료비와 노무비 단가, 그리고 복합 단가가 여기에 들어갑니다. 물량 산출과는 별도로 이 브라우저에 보관되므로, 여기서 여는 모든 물량 산출이 이를 사용할 수 있습니다.

{{ui:항목}} 패널 위쪽의 {{ui:라이브러리}}를 여십시오.

## 라이브러리 채우기

- {{ui:CSV 가져오기…}}는 CSV로 저장한 스프레드시트를 읽습니다(아래 열을 참조하십시오). 이름과 유형이 이미 라이브러리에 있는 항목은 대체되며, 나머지는 추가됩니다. 읽을 수 없는 행은 건너뛰고, 어느 행인지와 그 이유를 알려 줍니다.
- {{ui:이 물량 산출의 항목 추가}}는 열린 물량 산출의 모든 항목을 단가와 복합 단가와 함께 라이브러리에 복사합니다(표시는 제외).
- TakeoffCraft에서 내보낸 견적 CSV([견적 내보내기](topic:export-estimate))는 그대로 가져와집니다. 지난 작업의 단가가 다음 작업의 출발점이 됩니다.

- {{ui:공종 묶음…}}은 드라이월, 전기, 콘크리트 같은 공종의 무료 복합 단가를 단가 없이 추가합니다. [공종 묶음](topic:trade-packs)을 참조하십시오.

{{ui:CSV 내보내기}}는 라이브러리를 CSV로 저장합니다. 사본을 보관하거나, 스프레드시트에서 편집하거나, 동료에게 주려는 경우에 사용합니다. {{ui:지우기}}는 라이브러리를 비웁니다(두 번 클릭).

:::note
라이브러리는 이 브라우저의 저장소에 있습니다. 다른 브라우저, 다른 컴퓨터, 비공개 창에는 자체 라이브러리가 따로 있거나 아무것도 없습니다. 옮기려면 내보내십시오.
:::

## 물량 산출에서 사용하기

- 항목에 체크하고({{ui:라이브러리에서 찾기}}에 입력하면 목록을 좁힐 수 있습니다) {{ui:물량 산출에 추가}}를 선택하십시오. 항목은 복합 단가와 함께 한 단계로 추가되며, {{key:Mod+Z}}로 되돌릴 수 있습니다. 물량 산출에 이미 있는 이름에는 `Carpet (2)`처럼 번호가 붙습니다.
- {{ui:단가 갱신}}은 이름과 유형이 라이브러리 항목과 일치하는 모든 물량 산출 항목에 라이브러리의 할증과 단가를 적용합니다. 같은 이름의 복합 단가 구성 요소에도 같은 방식으로 적용합니다. 높이, 단위, 수식은 그대로 유지됩니다. {{key:Mod+Z}} 한 번이면 이전 단가가 모두 복원됩니다.

## CSV 열

첫 행에 열 이름이 어떤 순서로든 있으면 됩니다. 다른 열은 무시됩니다.

| 열 | 입력 내용 |
|---|---|
| Item (또는 Name) | 항목 이름. 필수입니다. |
| Type | Linear, Area 또는 Count(LF, SF, EA도 가능). 비워 두면 단위로 유형이 정해집니다. |
| Unit | LF 또는 m; SF, SY 또는 m²; EA. 비워 두면 해당 유형의 기본 단위입니다. |
| Waste % | `10` 또는 `10%`. |
| Material per unit, Labor per unit | `2.10` 또는 `$1,250` 같은 단가. |
| Height (or Depth) | `9'-0"`, `9`, 또는 미터 단위의 경우 `2.7`. |
| Component, Formula | Component 이름(또는 유형 `Component`)이 있는 행은 위 항목의 복합 단가에 속합니다. 단위, 할증, 단가는 그 행만의 값이며, 수식은 항목의 문자를 사용합니다. [복합 단가와 수식](topic:assemblies)을 참조하십시오. |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

열 사이에 쉼표, 세미콜론 또는 탭을 사용해도 모두 작동합니다.

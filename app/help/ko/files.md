## 열 수 있는 파일

| 파일 | 방법 | 참고 |
|---|---|---|
| PDF (`.pdf`) | {{ui:도면 열기}}, {{key:Mod+O}} 또는 페이지에 끌어다 놓기 | 여러 개를 한 번에 열 수 있습니다. 각 페이지가 시트가 됩니다. |
| 물량 산출 프로젝트 (`.takeoff.json`) | {{ui:물량 산출 열기}} 또는 페이지에 끌어다 놓기 | 항목, 축척, 표식이 들어 있습니다. 해당 PDF와 함께 끌어다 놓을 수 있습니다. |

페이지에 끌어다 놓은 그 밖의 파일은 건너뛰며, 상태 표시줄에 해당 파일 이름이 표시됩니다.

- **암호로 보호된 PDF**는 열리지 않습니다. "암호로 보호된 파일: (이름). 보호되지 않은 사본을 여십시오."
- **같은 PDF를 두 번** 열면 한 번만 열립니다. "이미 열려 있음: (이름)." TakeoffCraft는 파일을 이름이 아니라 내용으로 구분합니다.
- **스캔한 PDF**도 다른 PDF와 똑같이 열고 측정할 수 있습니다. TakeoffCraft에는 PDF 안의 텍스트가 필요하지 않습니다.
- **큰 도면 세트**: 모든 PDF는 열 때 전체를 읽으므로(지문을 만들기 위해) 매우 큰 파일은 시간이 조금 걸립니다. 썸네일은 스크롤할 때 하나씩 그려집니다.

## 저장되는 파일

모든 저장은 다운로드입니다. PDF에는 아무것도 다시 기록되지 않습니다.

| 선택 | 결과 | 담기는 내용 |
|---|---|---|
| {{ui:물량 산출 저장}} | `(이름).takeoff.json` | 항목, 복합 단가, 단가, 시트 축척, 모든 표식이 들어 있으며 각 PDF의 내용을 기준으로 연결됩니다. PDF 페이지는 들어 있지 않습니다. |
| {{ui:XLSX}} | `(이름).xlsx` | 워크시트 네 개: 견적(실시간 수식 포함), 시트별, 표식, 축척. |
| {{ui:CSV}} | `(이름).csv` | 견적을 단순 값으로 담으며, 항목과 구성 요소마다 한 행입니다. |
| {{ui:표시된 PDF}} | `(PDF 이름) (takeoff).pdf` | 표식이 있는 각 열린 PDF의 사본이며, 페이지에 물량 산출이 그려지고 범례가 붙습니다. PDF마다 파일 하나입니다. |

이름은 이 물량 산출에서 처음 연 PDF에서 가져옵니다. 이름 변경 입력란은 아직 없으므로 다른 이름을 원하면 다운로드한 파일의 이름을 바꾸십시오.

[견적 및 표시된 PDF 내보내기](topic:export-estimate)와 [내보내기 열](topic:export-columns)을 참고하십시오.

## 다운로드가 저장되는 곳

브라우저가 모든 다운로드를 저장하는 곳, 보통 다운로드 폴더에 저장됩니다. {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 찾을 수 있습니다. 브라우저가 파일마다 저장 위치를 묻도록 설정되어 있으면 그때마다 묻습니다.

:::chromium
표시된 PDF가 여러 개인 상태에서 {{ui:표시된 PDF}}를 선택하면 파일이 여러 개 한꺼번에 다운로드됩니다. Chrome과 Edge는 이 사이트의 여러 파일 다운로드를 허용할지 한 번 물을 수 있습니다. 허용을 선택하십시오.
:::

:::safari
Safari는 Safari 설정의 일반에서 다운로드 위치를 바꾸지 않았다면 다운로드 폴더에 저장합니다.
:::

## 프로젝트 파일과 PDF가 따로 있는 이유

`.takeoff.json` 파일에는 물량 산출만 들어 있습니다. 이 파일은 각 PDF의 내용(파일의 지문)으로 해당 PDF를 다시 찾으므로 다음과 같습니다.

- PDF의 이름을 바꾸거나 옮겨도 상관없습니다.
- 다른 프로그램에서 수정하거나 다시 저장한 PDF는 이름이 같아도 다른 파일로 취급됩니다.
- 열려 있지 않은 PDF의 표식도 합계에 포함됩니다.

[물량 산출 저장 및 다시 열기](topic:save-and-reopen)를 참고하십시오.

## 온라인과 오프라인

PDF와 물량 산출은 온라인이든 오프라인이든 컴퓨터 밖으로 나가지 않습니다. 연결은 TakeoffCraft 자체를 불러올 때만 필요합니다.

연결 없이 작업하려면 온라인일 때 먼저 앱을 저장하십시오.

1. 맨 위 앱 표시줄에서 {{ui:오프라인용 저장}}을 선택합니다.
   저장하는 동안 버튼에 "12 / 40 저장 중"처럼 진행 상황이 표시됩니다.
2. {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다립니다.

TakeoffCraft를 저장하면 앱, 이 도움말, PDF 리더, {{ui:표시된 PDF}}에 쓰는 PDF 작성기, 자동 개수 작업기가 브라우저에 보관되며 용량은 약 6 MB입니다. {{ui:오프라인 사용 준비됨}}이 표시되면 PDF 열기, 측정, {{ui:자동 개수}}, {{ui:물량 산출 저장}}, {{ui:XLSX}}, {{ui:CSV}}, {{ui:표시된 PDF}}까지 모두 오프라인에서 동작합니다.

| 버튼 표시 | 의미 |
|---|---|
| {{ui:오프라인용 저장}} | 이 브라우저에 아직 저장되지 않았습니다. 선택하면 저장합니다. |
| (m)개 중 (n)개 저장 중 | 지금 저장하는 중입니다. |
| {{ui:오프라인 사용 준비됨}} | 저장되었습니다. 선택하면 {{ui:다시 저장 (최신 버전 받기)}} 또는 {{ui:오프라인 사본 제거}}를 할 수 있습니다. |
| {{ui:저장하지 못했습니다}} | 일부 파일을 내려받지 못했습니다. 연결을 확인한 후 다시 선택하십시오. |
| {{ui:오프라인 사용 불가}} | 이 브라우저 창에서는 오프라인 사본을 보관할 수 없습니다(시크릿 창과 일부 관리형 컴퓨터는 이를 막습니다). |

저장된 사본이 브라우저별로 얼마나 오래 유지되는지 등 자세한 내용은 [오프라인으로 작업하기](common:offline)를 참고하십시오.

:::offline
오프라인 상태입니다. 앱 표시줄에 {{ui:오프라인 사용 준비됨}}이 표시되어 있으면 모든 기능이 동작합니다. 표시되어 있지 않으면 이 탭에서 TakeoffCraft가 아직 불러오지 않은 부분(예: {{ui:표시된 PDF}}용 PDF 작성기, 자동 개수 작업기)은 지금 불러올 수 없으며, {{ui:표시된 PDF}}는 "표시된 PDF를 쓸 수 없습니다"라는 메시지와 함께 중단됩니다. 어느 쪽이든 물량 산출은 안전합니다. {{ui:물량 산출 저장}}, {{ui:XLSX}}, {{ui:CSV}}에는 연결이 필요하지 않습니다. 다시 온라인이 될 때까지 탭을 새로 고치지 마십시오.
:::

:::online
온라인 상태입니다. 현장 방문이나 비행 전에 {{ui:오프라인용 저장}}을 선택하고 {{ui:오프라인 사용 준비됨}}이 표시될 때까지 기다리십시오.
:::

## 스프레드시트

XLSX에는 실시간 수식이 유지되므로, 스프레드시트 프로그램이 파일을 열 때 견적을 다시 계산하고 그곳에서 단가나 할증을 바꾸어도 결과가 맞게 유지됩니다. 이 통합 문서는 LibreOffice Calc에서 확인했으며, 모든 합계가 1센트까지 같게 다시 계산되었습니다. 아직 Excel에서는 열어 보지 않았습니다.

CSV는 바이트 순서 표시(BOM)가 있는 단순 값 파일이므로, 스프레드시트 프로그램이 m² 같은 문자를 올바르게 읽습니다.

## 데스크톱과 클라우드

:::desktop
0.5부터 데스크톱 앱은 CadCraft Studio입니다. TakeoffCraft와 나머지 일곱 개 앱이 한 번의 설치로 함께 제공됩니다. 별도의 TakeoffCraft 설치 프로그램은 없습니다.
:::

클라우드 저장은 아직 사용할 수 없습니다. `.takeoff.json` 파일은 작업의 PDF와 함께 보관하고, 다른 파일과 마찬가지로 백업하십시오. [파일이 저장되는 곳](common:your-files)을 참고하십시오.

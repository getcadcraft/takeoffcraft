## 견적 (XLSX 워크시트 및 CSV)

항목마다 한 행을 두고, 그 뒤에 해당 복합 단가의 구성요소마다 들여쓰기된 행을 둡니다. 그다음에 빈 행과 작업 총계가 나옵니다.

| 열 | 내용 | XLSX에서 |
|---|---|---|
| A 항목 | 항목 이름(굵게) 또는 구성요소 이름(들여쓰기) | 텍스트 |
| B 유형 | 선형, 면적, 개수 또는 구성요소 | 텍스트 |
| C 단위 | LF, m, SF, SY, m², EA 또는 구성요소의 단위 | 텍스트 |
| D 수량 | 측정 합계 또는 수식 결과 | 숫자 |
| E 할증 % | 할증 | 백분율 (0.10 = 10%) |
| F 할증 포함 수량 | 수량 × (1 + 할증) | 수식 `D*(1+E)` |
| G 단위당 재료비 | 재료 단가 | 숫자 |
| H 단위당 노무비 | 노무 단가 | 숫자 |
| I 재료비 | 합계 재료비 | 수식 `ROUND(F*G,2)` |
| J 노무비 | 합계 노무비 | 수식 `ROUND(F*H,2)` |
| K 합계 | 재료비 + 노무비 | 수식 `I+J` |
| L 비고 | 사용한 수식, 수식 오류, 축척이 없는 시트의 표시, 벽 면적, 둘레 | 텍스트 |

작업 총계 행: 위의 모든 행에 대해 I, J, K 열의 `SUM`이며, 제외된 항목이 있으면 비고에 "미완료: 위 비고를 참조하십시오."가 표시됩니다.

수식 오류가 있는 행에는 수량이나 금액이 없으며, 비고에 오류가 표시됩니다. 머리글 행은 고정됩니다.

CSV에서는 같은 열에 단순 값이 들어갑니다. 할증 %는 백분율 숫자(10%이면 10)이고, 금액은 소수 둘째 자리까지의 달러입니다. 스프레드시트가 수식으로 오인할 수 있는 텍스트(`=`, `+`, `-`, `@` 중 하나로 시작하는 텍스트)에는 텍스트로 남도록 앞에 `'`를 붙입니다.

## 시트별 (XLSX 전용)

| 열 | 내용 |
|---|---|
| 시트 | 시트 이름(열려 있지 않으면 PDF 이름 포함) |
| 항목 | 항목 이름 |
| 수량 | 해당 시트에서 그 항목의 수량, 항목의 단위로 표시 |
| 단위 | 항목의 단위 |
| 표시 | 표시 개수 |

## 표시 (XLSX 전용)

표시마다 한 행입니다.

| 열 | 내용 |
|---|---|
| 시트 | 시트 이름 |
| 항목 | 항목 이름 |
| 유형 | 선형, 면적 또는 개수 |
| 수량 | 길이, 순면적 또는 1 |
| 단위 | LF 또는 m; SF, SY 또는 m²; EA |
| 세부 정보 | 선형: 구간 길이(공제된 구간은 "(공제)"로 표시), 그리고 "그려진 (길이) 중 (길이) 공제". 면적: 개구부가 있을 때 총면적과 개구부 면적, 그리고 둘레. 축척이 없는 표시에는 "시트에 축척 없음". |
| 입찰 범위 | 물량 산출에 입찰 범위가 있을 때만: 표시의 범위 또는 "입찰 범위 없음" |

## 입찰 범위별 (XLSX 전용, 물량 산출에 입찰 범위가 있을 때)

| 열 | 내용 |
|---|---|
| 입찰 범위 | 범위 이름 또는 "입찰 범위 없음" |
| 항목 | 항목, 또는 그 아래 들여쓰기된 구성요소 |
| 단위 | 항목 또는 구성요소의 단위 |
| 수량 | 해당 범위에서 측정한 값(구성요소: 범위 합계에 대한 수식) |
| 할증 포함 수량 | 수량 × (1 + 할증) |
| 재료비, 노무비, 합계 | 견적과 같이 센트 단위까지 계산 |
| 비고 | 견적과 같이 수식, 오류 및 축척 없는 표시 |

각 범위는 "(이름) 소계" 행으로 끝나며, 이 행의 비용은 그 행들에 대한 `SUM` 수식입니다. 마지막 행인 **모든 입찰 범위**는 소계를 합산합니다. 그러면 **표시** 워크시트에 일곱 번째 열인 **입찰 범위**가 추가됩니다.

## 축척 (XLSX 전용)

축척이나 표시가 있는 시트마다 한 행입니다.

| 열 | 내용 |
|---|---|
| 시트 | 시트 이름 |
| 축척 | 프리셋 이름, 보정된 축척, 또는 "축척 없음" |
| 방법 | "프리셋" 또는 "보정(입력한 거리 기준)" |
| PDF 단위당 피트 | TakeoffCraft에서 사용하는 정확한 축척 계수 |

## 파일 이름

- `(name).xlsx` 및 `(name).csv`. 이름은 물량 산출에서 처음 연 PDF에서 가져옵니다.
- CSV는 바이트 순서 표시(BOM)가 포함된 UTF-8이며 Windows 줄바꿈을 사용하므로, 모든 플랫폼의 스프레드시트 프로그램에서 읽을 수 있습니다.

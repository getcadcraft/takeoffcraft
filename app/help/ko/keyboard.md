글자 키는 포인터가 페이지 어디에 있든, 입력란에 입력 중이 아닐 때 작동합니다. 대화상자가 열려 있으면 그 대화상자의 키가 적용됩니다. 글자 키는 {{key:Shift}} 키와 함께 또는 없이 작동합니다.

| 키 | 도구 |
|---|---|
| {{key:V}} | {{ui:Select}} |
| {{key:L}} | {{ui:Linear}} |
| {{key:A}} | {{ui:Area}} |
| {{key:O}} | {{ui:Circle}} |
| {{key:B}} | {{ui:Room}} (클릭 한 번으로 실 채우기) |
| {{key:R}} | {{ui:Arc}} 켜기 또는 끄기 (선형, 면적, 개구부에서) |

## 그리는 중

| 키 또는 동작 | 기능 |
|---|---|
| 클릭 | 점을 놓습니다 (개수 모드에서는 점 하나). |
| {{key:P}} | 경로: PDF 선의 연결된 경로 전체, 또는 클릭 주변의 윤곽선을 고릅니다 ([PDF의 선 고르기](topic:pick-the-lines)). |
| {{key:F3}} | 도면의 선에 맞추기 켜기 또는 끄기 ([도면의 선에 맞추기](topic:snap-to-the-drawing)). |
| 클릭하는 동안 {{key:Shift}} 누르기 | 마지막 점에서 선분을 0°, 45°, 90° 또는 135°에 맞춥니다. 호의 점이나 원에는 적용되지 않습니다. |
| 더블 클릭 | 구간을 끝내거나, 면적 또는 개구부를 닫습니다. |
| {{key:Enter}} | 구간을 끝내거나, 면적 또는 개구부를 닫습니다. |
| 우클릭 (움직이지 않고) | 구간을 끝내거나, 면적 또는 개구부를 닫습니다. |
| 첫 점 클릭 | 면적 또는 개구부를 닫습니다 (세 번째 점부터). |
| {{key:Backspace}} 또는 {{key:Delete}} | 마지막 점을 제거합니다 (먼저 대기 중인 호의 점). |
| {{key:Esc}} | 대기 중인 호의 점을 버립니다. 그다음 미완성 표식을 취소합니다. 그다음 {{ui:Select}} 도구로 돌아갑니다. |

## 선택 및 편집

| 키 또는 동작 | 기능 |
|---|---|
| 표식 클릭 ({{ui:Select}} 도구) | 선택하고 해당 항목을 현재 항목으로 만듭니다. |
| {{key:Shift}} + 표식 클릭 | 선택에 추가하거나, 선택에서 뺍니다. |
| {{key:Mod+A}} | 열린 시트의 모든 표식을 선택합니다. |
| 모서리 핸들 끌기 | 그 점을 이동합니다 ({{key:Shift}} 키는 45°에 맞춥니다). 표식 하나가 선택되었을 때 작동합니다. |
| {{key:Delete}} 또는 {{key:Backspace}} | 선택한 표식을 삭제합니다 (그리는 중이 아닐 때). |
| {{key:Esc}} | 아무것도 선택하지 않습니다: 선택과 확인선을 지웁니다. |
| {{key:Mod+Z}} | 실행 취소. |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 다시 실행. |

## 복사 및 붙여넣기

| 키 | 기능 |
|---|---|
| {{key:Mod+C}} | 선택한 표식을 항목과 함께 복사합니다. |
| {{key:Mod+X}} | 잘라내기: 선택한 표식을 복사한 뒤 삭제합니다. |
| {{key:Mod+V}} | 붙여넣기: 복사본이 포인터를 따라갑니다. 놓을 위치를 클릭합니다. |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 열린 시트의 같은 위치에 놓습니다. |
| {{key:Mod+D}} | 선택한 표식 복제: 복사본이 포인터를 따라갑니다. 놓을 위치를 클릭합니다. |
| {{key:Esc}} | 아무것도 놓지 않습니다: 포인터에 붙어 있는 붙여넣기 또는 복제를 취소합니다. |

글자 키만 눌러도 도구가 선택됩니다 ({{key:C}}는 {{ui:Count}}, {{key:D}}는 {{ui:Check}}, {{key:X}}는 {{ui:Cut-out}}, {{key:V}}는 {{ui:Select}}, {{key:A}}는 {{ui:Area}}). 복사와 붙여넣기는 {{key:Mod}} 키와 함께 눌러야 합니다. 텍스트 입력란에서는 이 키들이 평소처럼 텍스트를 복사하고 붙여넣습니다. [표식 복사, 붙여넣기 및 복제](topic:copy-paste)를 참고하십시오.

:::warning
그리는 중이 아닐 때 {{key:Backspace}} 키는 선택한 표식을 삭제합니다. 실수로 삭제했다면 {{key:Mod+Z}}로 되돌릴 수 있습니다.
:::

## 도움말

| 키 | 기능 |
|---|---|
| {{key:F1}} | 도움말 패널을 열거나 닫습니다 (앱 막대의 {{ui:Help}} 버튼과 같습니다). 모든 도구에서 작동하며, 입력란에 입력 중일 때도 작동합니다. |
| {{key:Esc}} | 도움말 패널을 닫습니다. 패널의 검색 상자에서는 첫 번째 Esc가 검색을 지웁니다. 패널이 열린 상태에서 시트를 클릭한 뒤 누른 Esc는 먼저 패널을 닫습니다. TakeoffCraft에서 취소하려면 한 번 더 누르십시오. |

많은 Mac 키보드에서 맨 윗줄 키는 밝기와 소리를 조절합니다. F1 키는 fn 키와 함께 누르거나, 시스템 설정의 키보드 항목에서 "F1, F2 등의 키를 표준 기능 키로 사용"을 켜십시오.
:::

## 플랫폼별 참고

:::mac
- {{key:Mod}} 키는 Command 키입니다: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}. 전체 화면은 예외로 Control+Shift+F입니다.
- 트랙패드에서 우클릭은 두 손가락 클릭입니다. 시스템 설정의 트랙패드 항목에서 보조 클릭을 켜야 합니다. TakeoffCraft는 보조 버튼만 읽으므로, Control 클릭은 일반 클릭으로 취급되어 점을 추가할 수 있습니다.
- 트랙패드에서 두 손가락으로 스크롤하면 시트가 확대 및 축소됩니다 (스크롤되지는 않습니다). 이동하려면 누른 채 끌거나, Space 키를 누른 채 끄십시오.
- Page Up과 Page Down이 없는 키보드에서는 fn 키와 위쪽 및 아래쪽 화살표 키를 함께 누릅니다.
- Backspace 키는 delete라고 표시된 키입니다.
:::

:::windows
- {{key:Mod}} 키는 Ctrl 키입니다: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}.
- 노트북 터치패드에서 두 손가락 스크롤은 시트를 확대 및 축소합니다. 이동하려면 누른 채 끄십시오.
:::

:::linux
- {{key:Mod}} 키는 Ctrl 키입니다. 일부 데스크톱은 자체 Ctrl+Alt 또는 Super 단축키를 사용하지만, TakeoffCraft는 그런 단축키를 쓰지 않습니다.
- 터치패드에서 두 손가락 스크롤은 시트를 확대 및 축소합니다. 이동하려면 누른 채 끄십시오.
:::

:::touch
TakeoffCraft는 터치를 하나의 포인터로 인식합니다:

- 탭하면 점을 놓거나, 표식을 선택하거나, 개수 점을 추가합니다.
- 한 손가락으로 끌면 시트가 이동합니다 ({{ui:Auto count}}에서는 검색 상자를 그립니다).
- 핀치 확대는 아직 지원되지 않습니다. {{ui:Fit page}}와 {{ui:Fit width}}를 쓰거나, 키보드의 {{key:Plus}} 키와 {{key:Minus}} 키를 사용하십시오.
- 면적을 닫으려면 첫 점을 탭하십시오. 구간을 끝내려면 브라우저가 두 번 탭을 더블 클릭으로 처리하는 곳에서 두 번 탭하거나, 키보드에서 {{key:Enter}} 키를 누르십시오.
- 호버가 없으므로, 탭하기 전까지는 실시간 길이 표시가 없습니다.

현재로서는 키보드와 마우스 또는 트랙패드를 쓰는 것이 물량 산출에 더 좋은 방법입니다.
:::

## 브라우저가 사용하는 키

브라우저는 일부 단축키를 직접 사용하므로 페이지가 쓸 수 없습니다: 탭 닫기 ({{key:Mod+W}}), 새 탭 또는 창 ({{key:Mod+T}}, {{key:Mod+N}}), 브라우저 확대 및 축소 ({{key:Mod+Plus}}, {{key:Mod+Minus}}). 그래서 TakeoffCraft는 휠과 단독 {{key:Plus}} 및 {{key:Minus}} 키로 시트를 확대 및 축소합니다. 실수로 {{key:Mod+Plus}}를 누르면 페이지 전체가 커지며, {{key:Mod+0}}으로 되돌릴 수 있습니다. [키, 마우스 및 트랙패드](common:keys)를 참고하십시오.

## 이동 명령의 위치

이동 명령은 없습니다: 개수 점을 선택하고 끌거나, 면적이나 선을 선택하고 모서리 핸들을 끄십시오.

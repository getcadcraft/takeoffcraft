복합 단가의 구성요소는 수량을 수식에서 얻습니다. 수식은 항목의 측정값에 대한 간단한 산술 식입니다. 예시는 [복합 단가와 수식](topic:assemblies)을 참조하십시오.

## 변수

| 항목 유형 | 변수 | 의미 |
|---|---|---|
| 선형 | `L` | 총 길이 |
| 선형 | `H` | 항목의 높이 |
| 선형 | `A` | 벽 면적, L × H, 개구부가 있는 구간의 개구부를 뺀 값(BimCraft에서 가져온 물량 산출). 해당 물량 산출에 측정 방식이 지정되어 있으면 `A`는 그 방식으로 측정됩니다. 방식의 최소 크기보다 작은 개구부는 포함되고, 벽이 만나는 곳에서 방식이 제외하는 부분은 빠집니다. 항목 아래 비고에 방식 이름이 표시됩니다. |
| 선형 | `N` | 구간 수 |
| 면적 | `A` | 총 순면적(윤곽선에서 개구부를 뺀 값) |
| 면적 | `P` | 개구부 가장자리를 포함한 총 둘레 |
| 면적 | `H` | 항목의 깊이 또는 두께 |
| 면적 | `N` | 면적 수 |
| 개수 | `N` | 개수 |

- 변수 값은 항목의 단위를 따릅니다. 참조: [단위](topic:units).
- 대문자와 소문자는 같습니다: `l`은 `L`과 같습니다.
- 항목 자체 유형의 변수만 작동합니다. 선형 항목에서 `P`를 쓰면 `"P"는 여기서 측정값이 아닙니다. L, H, A, N을 사용하십시오.` 오류가 나옵니다.
- 높이나 깊이를 비워 두면 0입니다.

## 연산자

| 입력 | 의미 |
|---|---|
| `+` | 더하기 |
| `-` 또는 `−` | 빼기 또는 음수 값 |
| `*` 또는 `×` | 곱하기 |
| `/` 또는 `÷` | 나누기 |
| `( )` | 묶기 |

곱셈과 나눗셈이 덧셈과 뺄셈보다 먼저 계산됩니다: `L * 2 + 4`는 (L × 2) + 4입니다. 헷갈리면 괄호를 사용하십시오.

숫자에는 소수(`1.333`, `.5`)와 지수(`1e3` = 1000)를 쓸 수 있습니다. 공백은 무시됩니다.

## 함수

| 함수 | 결과 | 예시 |
|---|---|---|
| `ceil(x)` | 올림하여 정수로 | `ceil(67.5)` = 68 |
| `floor(x)` | 내림하여 정수로 | `floor(67.5)` = 67 |
| `round(x)` | 가장 가까운 정수로 반올림, 0.5는 0에서 먼 쪽으로 | `round(2.5)` = 3 |
| `round(x, d)` | 소수 d자리로 반올림(0~10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | 가장 작은 값 | `min(N, 10)` |
| `max(a, b, …)` | 가장 큰 값 | `max(1, ceil(N / 12))` |
| `abs(x)` | 부호를 뺀 값 | `abs(-3)` = 3 |

`ceil`과 `floor`는 컴퓨터의 미세한 반올림 오차를 무시하므로, 정확히 1이어야 하는 값이 2로 올림되는 일은 없습니다.

## 오류

읽거나 계산할 수 없는 수식은 입력란 아래에 오류를 표시하고, 해당 구성요소는 합계에서 제외됩니다({{ui:Quantities}} 머리글에 "미완료"라고 표시됩니다). 메시지:

| 메시지 | 해결 방법 |
|---|---|
| L 또는 ceil(L / 1.333) + 1 같은 수식을 입력하십시오. | 수식이 비어 있습니다. |
| `"X"는 여기서 측정값이 아닙니다. 사용: …` | 나열된 변수 중 하나를 사용하십시오. |
| `"X"는 여기서 함수가 아닙니다. ceil, floor, round, min, max, abs 중 하나를 사용하십시오.` | 그 함수 중 하나를 사용하십시오. |
| `"#"는 수식에 사용할 수 없습니다.` | 해당 문자를 지우십시오(단위, `%`, `$` 및 `=`는 사용할 수 없습니다). |
| `")"가 빠져 있습니다.` / `"("가 없는 ")"가 있습니다.` | 괄호를 맞추십시오. |
| `")" 앞에 값이 없습니다.` | 예: `max(1, )`처럼 빈 값을 채우십시오. |
| `수식이 너무 일찍 끝납니다.` | 예: `L *`처럼 끝까지 완성하십시오. |
| `예상하지 않은 "…". 연산자가 빠졌습니까?` | 값 두 개를 나란히 쓴 경우(예: `2L`)에는 `2 * L`처럼 쓰십시오. |
| `ceil()의 인수는 1개입니다.` | 함수에 맞는 개수의 값을 주십시오. |
| `round(x, digits)에는 0부터 10까지의 정수 자릿수가 필요합니다.` | 정수 소수 자릿수를 사용하십시오. |
| `수식에서 0으로 나누고 있습니다.` | 보통 H가 0입니다. 항목의 높이 또는 깊이를 설정하십시오. |
| `결과가 숫자로 나타내기에 너무 큽니다.` | 수식이 숫자를 반환하지 않습니다. 값을 줄이십시오. |
| `수식이 너무 깁니다(최대 500자).` | 줄이십시오. |

## 설계에 따른 안전성

수식은 위의 변수와 함수로 산술 계산만 할 수 있습니다. 코드를 실행하거나 다른 것을 읽을 수 없으므로, 누군가 보내 준 프로젝트 파일 안의 수식도 해롭지 않습니다.

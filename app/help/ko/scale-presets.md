{{ui:Scale}} 그룹의 {{ui:Preset}} 목록에는 세 그룹에 걸쳐 32개의 축척이 있습니다. 사전 설정은 열린 시트의 축척을 정확히 설정합니다.

모든 사전 설정은 PDF 페이지가 도면의 실제 용지 크기라고 가정합니다. 즉 PDF 페이지의 1인치가 용지의 1인치입니다(PDF 페이지는 인치당 72포인트입니다). PDF 크기가 조정되었다면 {{ui:Calibrate}}를 사용하십시오. 축척을 설정한 뒤에는 {{ui:Check}}를 사용하십시오. [축척 설정](topic:set-the-scale)을 참조하십시오.

## 건축

| 사전 설정 | 용지 1인치 = |
|---|---|
| `1/16" = 1'-0"` | 16 ft |
| `3/32" = 1'-0"` | 10 ft 8 in |
| `1/8" = 1'-0"` | 8 ft |
| `3/16" = 1'-0"` | 5 ft 4 in |
| `1/4" = 1'-0"` | 4 ft |
| `3/8" = 1'-0"` | 2 ft 8 in |
| `1/2" = 1'-0"` | 2 ft |
| `3/4" = 1'-0"` | 1 ft 4 in |
| `1" = 1'-0"` | 1 ft |
| `1 1/2" = 1'-0"` | 8 in |
| `3" = 1'-0"` | 4 in |

## 공학

| 사전 설정 | 용지 1인치 = |
|---|---|
| `1" = 10'` | 10 ft |
| `1" = 20'` | 20 ft |
| `1" = 30'` | 30 ft |
| `1" = 40'` | 40 ft |
| `1" = 50'` | 50 ft |
| `1" = 60'` | 60 ft |
| `1" = 100'` | 100 ft |

## 미터법

`1:1`, `1:2`, `1:5`, `1:10`, `1:20`, `1:25`, `1:50`, `1:75`, `1:100`, `1:150`, `1:200`, `1:250`, `1:500`, `1:1000`.

미터법 비율은 용지의 한 단위가 실제로 그만큼의 단위에 해당한다는 뜻입니다. `1:100`에서는 페이지의 10 mm가 실제 1 m입니다.

## 보정 축척

보정 축척은 시트 아래 막대에 "보정 1" = 4.002' (24'-6"에서)처럼 표시됩니다. 이는 용지 인치당 실제 피트 수와 입력한 거리입니다. 사전 설정과 0.5% 이내로 일치하면 막대에 "(1/4" = 1'-0"과 일치)"가 추가되고, 시트 목록에는 사전 설정의 이름이 나타납니다.

## 특수한 PDF

일부 PDF는 더 큰 페이지 단위("사용자 단위")를 선언합니다. TakeoffCraft는 사전 설정과 표시되는 축척에 이를 반영합니다. PDF에서 회전된 페이지는 똑바로 세운 페이지와 같은 방식으로 측정합니다.

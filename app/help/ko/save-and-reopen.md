물량 산출은 작은 프로젝트 파일 `(이름).takeoff.json`으로 저장됩니다. 항목, 복합 단가, 단가, 모든 시트의 축척, 모든 표시를 담고 있습니다. PDF는 **포함되지 않으며**, 내용을 기준으로 PDF를 다시 찾습니다.

## 저장

1. {{ui:File}} 그룹에서 {{ui:Save takeoff}}를 선택하거나 {{key:Mod+S}}를 누르십시오.
   브라우저가 `(이름).takeoff.json`을 다운로드합니다. 상태 표시줄에 "(이름).takeoff.json 저장됨. 같은 PDF 위에서 다시 열립니다(내용으로 대조합니다)."가 표시됩니다.
2. 파일을 작업의 PDF 옆으로 옮겨 두 파일을 함께 보관하십시오.

저장할 때마다 새 파일이 다운로드됩니다. 브라우저가 두 번째 파일을 `(이름) (1).takeoff.json`처럼 이름 붙일 수 있으니, 가장 최근 파일을 보관하십시오.

이름은 이 물량 산출에서 처음 연 PDF에서 가져옵니다.

:::note
{{ui:Save takeoff}}는 물량 산출을 파일로 보관하는 유일한 방법입니다. 작업하는 동안 TakeoffCraft는 이 브라우저에 복구 사본도 보관합니다(아래 참조). 클라우드 저장은 아직 사용할 수 없습니다. 저장되지 않은 변경 사항이 있는 상태에서 탭을 닫으려 하면 브라우저가 떠날지 묻습니다.
:::

## PDF 안에 물량 산출 보관

{{ui:Export}} › {{ui:PDF with the takeoff inside}}를 선택하면 열려 있는 각 PDF의 사본이 `Plans (with takeoff).pdf`와 같은 이름으로 다운로드됩니다. 이 사본에는 전체 물량 산출(항목, 표시, 축척, 입찰 범위 등 `.takeoff.json`에 담기는 모든 것)이 첨부 파일로 들어 있습니다. 페이지는 바뀌지 않으므로 원본과 같이 보이고 인쇄되며, 다른 PDF 리더에서는 첨부 파일로 물량 산출이 나타납니다.

TakeoffCraft에서 이 PDF를 열면(PDF를 여는 어떤 방법이든) **이 PDF에 물량 산출이 들어 있습니다**라고 묻습니다. 물량 산출을 가져오려면 {{ui:Open the takeoff}}를, 도면만 열려면 {{ui:Just the PDF}}를 선택하십시오. 사본은 원본 PDF를 대신하므로, 어느 쪽에서 저장한 `.takeoff.json`이든 두 파일 모두에서 열립니다.

PDF가 여러 개이면 각 사본에 전체 물량 산출이 들어 있으므로 함께 여십시오. 사본에서 다시 저장하면 안의 물량 산출이 교체되며, 두 번째 물량 산출이 추가되지는 않습니다. `.takeoff.json`은 여전히 보관해야 할 파일입니다. 크기가 작고, 자동 저장과 데스크톱 앱이 기록하는 파일이기 때문입니다.

## 탭이나 브라우저가 멈춘 경우

변경 후 몇 초 뒤 TakeoffCraft는 이 브라우저의 저장 공간에 물량 산출 사본을 보관합니다. PDF의 합계가 64 MB 이하이면 PDF도 함께 보관합니다. 아무것도 업로드되지 않습니다. 물량 산출을 저장하거나, 새 물량 산출을 시작하거나, 다른 프로젝트를 열면 이 사본은 삭제됩니다.

탭이 충돌하거나, 브라우저나 컴퓨터가 멈추거나, 저장되지 않은 변경 사항이 있는 채로 나간 경우, 다음에 TakeoffCraft를 열면 **작업을 복구할까요?**라고 묻고 물량 산출을 이름으로 나열합니다. **복구**를 선택하면 되돌아옵니다. 항목, 표시, 축척이 복원되며, 보관된 경우 PDF도 다시 열립니다. 상태 표시줄에는 "복구됨: (이름). 아직 파일로 저장되지 않았습니다. 물량 산출 저장으로 보존하십시오."가 표시됩니다. PDF가 너무 커서 보관하지 못한 경우에는 PDF를 다시 여십시오. 표시가 해당 시트에 나타납니다. 자세한 내용은 [작업 복구](common:recover)를 참조하십시오.

## 다시 열기

1. TakeoffCraft를 여십시오.
2. `.takeoff.json` 파일과 PDF를 함께 페이지에 끌어다 놓으십시오. 또는 PDF는 {{ui:Open plans}}로, 프로젝트는 {{ui:Open takeoff}}로 여십시오. 순서는 상관없습니다.
   상태 표시줄에 "(이름) 열림: 항목 12개, 표시 340개."가 나타납니다. 모든 시트가 축척을 되찾고 표시가 해당 시트에 나타납니다.

PDF의 순서나 파일 이름, 폴더는 상관없습니다. TakeoffCraft는 내용의 지문으로 각 PDF를 알아봅니다.

현재 물량 산출에 저장되지 않은 변경 사항이 있는 상태에서 프로젝트를 열면, TakeoffCraft가 먼저 묻습니다: **취소**, **변경 사항 버리기**, **먼저 물량 산출 저장**. 프로젝트를 열면 현재 항목과 표시가 교체됩니다. 이미 열려 있는 PDF는 계속 열려 있습니다.

## PDF가 없는 경우

프로젝트의 PDF를 모두 열지 않고 프로젝트를 열면, 상태 표시줄에 "표시를 보려면 PDF를 여십시오(시트 목록에 나열됨)."가 추가됩니다. 시트 목록 아래에 다음 안내가 나옵니다.

"이 물량 산출은 열리지 않은 PDF도 포함합니다. 이 PDF의 수량은 계산되며, 표시를 보고 편집하려면 열어 주십시오:"

그 뒤에 파일 이름과 크기가 이어집니다. 이 PDF의 표시도 모든 합계와 내보내기에 계산되며, 측정했을 때의 축척을 사용합니다. 표시를 보고 편집하려면 해당 PDF를 여십시오.

## PDF가 변경된 경우

수정되었거나 다른 프로그램에서 다시 저장된 PDF는 내용이 달라지므로, 이름이 같더라도 TakeoffCraft에게는 **다른 파일**입니다. 시트 목록 아래 안내에서 이런 파일은 "같은 이름의 파일이 열려 있지만 내용이 다릅니다"라고 표시됩니다.

- 표시는 이전 버전에 계속 붙어 있습니다. 이전 위치와 축척으로 계속 계산됩니다.
- 수정된 PDF는 축척과 표시가 없는 새 시트로 열립니다.

물량 산출을 수정본으로 옮기려면 두 PDF를 모두 열고, 새 시트에서 {{ui:Compare}}를 사용하십시오: [수정된 시트 비교와 물량 산출 옮기기](topic:compare-revisions).

## 손상되었거나 다른 파일

TakeoffCraft는 사용하기 전에 모든 프로젝트 파일을 확인합니다. 다음과 같은 메시지가 나타날 수 있습니다.

- "(파일): TakeoffCraft 프로젝트가 아닙니다(올바른 JSON이 아닙니다)."
- "이것은 TakeoffCraft 프로젝트 파일이 아닙니다."
- "이 프로젝트는 최신 TakeoffCraft에서 저장되었습니다. 그 프로그램에서 여십시오."
- "표시 3개가 손상되어 제외되었습니다." (나머지는 열립니다)

## 실행 취소 기록

실행 취소 기록은 프로젝트를 열 때 새로 시작됩니다. 저장해도 지워지지 않습니다.

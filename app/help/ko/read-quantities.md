창 아래쪽의 {{ui:Quantities}} 표는 실시간 견적입니다. 표시를 그리거나, 삭제하거나, 축척을 바꾸거나, 단가를 수정하면 즉시 바뀝니다. 수량은 저장하지 않습니다. 표시에서 매번 다시 측정하므로 오래된 값이 남지 않습니다.

## 항목별

{{ui:By item}}(기본값)을 선택합니다. 각 항목은 한 행을 차지하며, 복합 단가의 구성 요소는 그 아래 행에 표시됩니다.

| 열 | 의미 |
|---|---|
| 항목 | 이름과 항목 색상입니다. "+(n) 축척 없음"은 축척이 없는 시트에 표시가 있다는 뜻입니다. |
| 수량 | 항목 단위로 측정한 합계입니다(구성 요소는 수식 결과). |
| 단위 | LF, m, SF, SY, m², EA 또는 구성 요소의 단위입니다. |
| 할증 % | 여기 또는 항목 편집기에 입력합니다. |
| 할증 적용 수량 | 수량 × (1 + 할증)입니다. |
| 재료비/단위, 노무비/단위 | 단가입니다. 여기에 직접 입력할 수 있습니다. |
| 재료비, 노무비 | 할증 적용 수량 × 단가이며, 센트 단위로 반올림합니다. |
| 합계 | 재료비 + 노무비입니다. |

마지막 행인 **공사 합계**는 재료비, 노무비, 합계 열을 더합니다. 같은 합계가 표 머리글 오른쪽에도 표시됩니다.

할증이나 단가 칸에 입력한 뒤 {{key:Enter}}를 누르거나 다른 곳을 클릭하면 적용됩니다. TakeoffCraft가 읽을 수 없는 값은 빨간색 테두리로 표시되며, 상태 표시줄에 이유가 나옵니다(예: "12.50처럼 금액을 입력하십시오.").

{{ui:Items}} 아래 또는 표에서 항목 행을 클릭하면, 모든 시트에서 그 항목의 표시가 강조되고 표시가 있는 시트로 이동합니다({{ui:Items}} 아래에서 클릭하는 것과 같습니다).

## 시트별

{{ui:By sheet}}를 선택하면 시트마다 각 항목의 수량과 표시 개수를 볼 수 있습니다. 행을 클릭하면 해당 항목이 강조된 상태로 그 시트가 열립니다. 모든 시트를 집계했는지 확인하거나, 층이나 작업 구역별로 수량을 나눌 때 사용합니다.

## 입찰 범위별

물량 산출에 입찰 범위가 있으면 {{ui:By area}}에 각 범위의 항목과 소계가 표시됩니다. [입찰 범위](topic:bid-areas)를 참조하십시오.

## 미완료 경고

합계에서 빠진 항목이 있으면 머리글에 경고가 표시됩니다. 예:

"미완료: 수식 오류 1건, 축척이 없는 시트의 표시 6개(합계에서 제외됨)"

- **수식 오류**: 복합 단가 구성 요소의 수식을 계산할 수 없습니다. 해당 행에 "수식 오류: …"가 표시됩니다. [복합 단가와 수식](topic:assemblies#when-a-formula-is-wrong)을 참조하십시오.
- **축척이 없는 시트의 표시**: 해당 시트에 축척을 지정하십시오. [축척 설정](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero)을 참조하십시오.

같은 안내가 내보낸 스프레드시트에도 들어가므로, 미완료 견적이 완료된 것처럼 보이지 않습니다.

## 항목 강조

{{ui:Items}} 아래 또는 표에서 항목을 클릭합니다. 그 항목의 표시는 모든 시트에서 진하게 유지되고 나머지는 흐려집니다. 시트 목록에는 표시가 있는 각 시트마다 "(n)개 강조"가 나타납니다. 같은 항목을 다시 클릭하면 강조가 해제됩니다.

## 측면 패널의 항목 합계

{{ui:Items}} 목록의 각 항목에도 수량이 표시됩니다. 항목 편집기의 **측정값** 블록에는 수식에서 사용하는 값이 나옵니다. 길이, 구간 수와 벽 면적, 면적, 둘레와 면적 수, 또는 개수입니다.

## 열려 있지 않은 PDF의 표시

물량 산출에는 이번에 열지 않은 PDF의 표시가 포함될 수 있습니다. 이 표시도 모든 합계에 계산되며, 시트 목록에 해당 PDF 이름이 나옵니다. [물량 산출 저장과 다시 열기](topic:save-and-reopen)를 참조하십시오.

## 더 넓은 작업 공간

{{ui:Quantities}} 머리글 오른쪽의 화살표 버튼을 누르면 표가 숨겨져 시트 작업 공간이 넓어집니다. 다시 누르면 표가 나타납니다.

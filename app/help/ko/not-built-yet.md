TakeoffCraft는 개발 중입니다. 이 목록은 현재 빌드가 하지 않는 기능과, 그런 경우에도 작업을 마치는 방법을 보여 줍니다.

## 측정

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 구간이나 윤곽의 중간에 점 삽입 | 표시를 삭제하고 다시 그리십시오. |
| 상자(윈도우) 선택 | {{key:Shift}} + 각 표시 클릭, 또는 시트의 모든 표시를 {{key:Mod+A}}로 선택하십시오. [표시 복사, 붙여넣기, 복제](topic:copy-paste)를 참조하십시오. |
| 붙여넣은 복사본의 회전, 대칭 또는 축척 변경 | 같은 축척과 같은 방향으로 시트에 붙여넣고, 나머지는 손으로 그리십시오. |
| 스캔한 시트나 그래픽 축척 막대에서 축척 읽기 | 사전 설정을 고르거나, 막대의 길이로 보정하십시오. |
| 시트마다 축척이 둘 이상인 경우(상세 영역, 확대 평면) | 시트의 축척으로 부분을 측정하고, 세트에 상세 시트가 있다면 그 확대 시트에서 상세 부분을 물량 산출하십시오. |

## 항목과 단가

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 항목의 다른 종류 표시를 사용하는 복합 단가 수식(방 항목의 문, 해당 층의 수식에서) | 수식은 주 유형의 합계를 사용합니다. 다른 종류는 자체 행에서 단가를 매기십시오. |
| 구간별로 계산하는 복합 단가 수식 | 수식은 항목의 합계를 사용합니다. 구간별 추가분은 `N`을 사용하십시오. |
| 다른 항목의 수량을 사용하는 수식 | 그 항목에서 측정을 반복하거나, 스프레드시트 내보내기에서 계산하십시오. |
| 복합 단가 구성 요소의 작업조, 또는 8시간이 아닌 작업 일 | 작업조를 항목에 지정하십시오. 다른 근무 시간의 작업조 일수는 작업조 시간 ÷ 본인의 하루 근무 시간으로 읽으십시오. |
| 메모, 구름, 강조 표시 외의 마크업(화살표, 치수, 스탬프), 또는 메모에 대한 답글 | 메모 본문에 적고, 해결되면 상태를 바꾸십시오. |
| 팀이 공유하거나 계정에 보관하는 단가 라이브러리 | 라이브러리는 이 브라우저에 보관됩니다. CSV로 내보낸 뒤 다른 컴퓨터에서 가져오십시오. |
| 실무 견적자가 검토한 공종 묶음 | 모든 묶음은 시작용입니다. 단가를 매기기 전에 가정을 작업과 제품에 맞게 확인하십시오. [공종 묶음](topic:trade-packs)을 참조하십시오. |
| 공종 묶음의 단가 | 묶음은 복합 단가만 제공합니다. 단가는 직접 설정하거나, 단가표를 CSV로 가져오십시오. |
| 물량 산출 이름 바꾸기 | 이름은 첫 PDF에서 가져옵니다. 내려받은 파일의 이름을 바꾸십시오. |
| 시트를 직접 이름 짓기 | 시트 이름은 PDF의 페이지 레이블에서 정해집니다. 파일 이름과 페이지로 검색하십시오. |

## 도면 (DWG 및 DXF)

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 도면 시트의 플롯 스타일 표, 펜 지정, CTB 파일 | 도면은 검은색으로 그려지며, 종이용으로 색을 어둡게 한 색으로 표시됩니다. 선 두께는 도면에서 가져옵니다. |
| 이진 DXF 또는 AutoCAD 2000 이전 DWG 열기 | ASCII DXF 또는 최신 DWG로 저장하십시오. |
| 폴더 위치로 연결된 도면(xref) 찾기 | 연결된 도면 파일도 호스트 도면과 함께 여십시오. 열린 파일 가운데 파일 이름으로 찾습니다. |
| 3D 폴리선, 메시, 솔리드, 영역 측정 | 도면층과 유형별로 개수를 세거나, 평면도에서 선형 및 면적 도구로 측정하십시오. |
| 라틴 문자가 아닌 스크립트의 도면 텍스트를 표시된 PDF에 넣기 | Helvetica에 글리프가 없는 문자는 표시된 PDF에서 "?"로 인쇄됩니다. 화면의 도면에는 영향이 없습니다. |
| 시트 막대에서 다른 앱으로 도면 넘기기 | 같은 파일을 그 앱에서 여십시오. |
| PDF용 {{ui:물량 산출이 들어 있는 PDF}} 같은 방식으로 물량 산출을 내부에 담은 도면 | {{ui:물량 산출 저장}}: `.takeoff.json`은 같은 도면에 다시 열리며, 내용으로 찾습니다. |
| 도면에 넣은 PDF 밑그림, 이미지, OLE 객체의 그리기 또는 개수 세기 | 이미지는 틀로만 표시됩니다. 밑그림 PDF 자체를 시트로 여십시오. |

## 자동 개수

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 다른 크기로 축척이 그려진 시트에서 기호 찾기 | 시트에 축척을 지정하거나, 그곳에 그린 상자로 검색하십시오. |
| 대칭된 기호 찾기 | 손으로 세거나, 대칭된 기호 둘레에 상자를 그려 다시 검색하십시오. |

## 파일과 공유

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 표시와 물량 산출을 함께 담은 PDF 하나 | 사람들에게 표시를 보여 줄 때는 {{ui:표시된 PDF}}, TakeoffCraft에서 다시 열 때는 {{ui:물량 산출이 들어 있는 PDF}}를 사용하십시오. |
| 시트별 또는 표시별 수량 CSV | {{ui:XLSX}}를 사용하십시오. '시트별'과 '표시' 워크시트에 있습니다. |
| 클라우드 저장 | 아직 사용할 수 없습니다. 프로젝트 파일을 컴퓨터에 저장하고 백업하십시오. |
| 별도의 TakeoffCraft 데스크톱 앱 | 0.5 버전부터 데스크톱 앱은 CadCraft Studio이며, 8개 앱이 한 설치 파일에 모두 들어 있습니다. TakeoffCraft는 브라우저에서도 실행됩니다. |

## 화면과 입력

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 마우스 오른쪽 클릭(또는 길게 누르기) 메뉴 | 도구 모음, 패널, 키를 사용하십시오. 길게 누르면 구간이나 윤곽을 마칩니다. |
| 보기 회전 | PDF에서 이미 회전된 페이지는 똑바로 표시됩니다. |

## 3D 뷰

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|
| 3D에서 표시 그리기 또는 편집 | 그리려면 시트({{key:3}})로 돌아가십시오. 선택과 삭제는 3D에서 됩니다. |
| 페이지마다 다르게 그려진 겹친 층 맞추기 | 같은 방식으로 그려진 층을 쌓으십시오. 나머지는 시트 한 장씩 확인하십시오. |
| 세는 대상과 같은 크기의 기둥 세기 | 시트의 모든 기둥은 크기가 같습니다. 기둥은 개수가 있는 위치를 표시할 뿐, 무엇인지는 표시하지 않습니다. |

## 입찰

| 아직 만들지 않은 기능 | 대신 지금 할 일 |
|---|---|

| 하도급업체의 보험 또는 면허 만료일 전 자동 알림 | 만료일이 지나거나 30일 이내이면 하도급업체 페이지에 표시됩니다. 초대할 때 확인하십시오. |

## 스프레드시트

XLSX 통합 문서는 LibreOffice Calc에서 확인했으며, 모든 합계가 TakeoffCraft와 같은 센트 단위까지 다시 계산되었습니다. Excel에서는 아직 열어 보지 않았습니다. 스프레드시트 프로그램에서 예상과 다르게 보이면, CSV 내보내기에는 같은 견적이 단순 값으로 들어 있습니다.

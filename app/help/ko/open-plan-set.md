도면 세트는 흔히 여러 PDF(건축, 구조, 기계)로 이루어집니다. TakeoffCraft는 이것들을 나란히 하나의 시트 목록으로 엽니다. 하나의 물량 산출로 모두 다룰 수 있습니다.

## PDF 열기

1. {{ui:파일}} 그룹에서 {{ui:도면 열기}}를 선택하거나 {{key:Mod+O}}를 누르십시오. (다른 메뉴 스타일에서는 이를 {{ui:PDF 열기…}}라고 합니다.)
2. 파일 대화 상자에서 세트의 PDF를 모두 선택하십시오. 여러 개를 고르려면 {{pick:mac=Command|windows=Ctrl|linux=Ctrl}} 키를 누른 채 선택하고, 범위를 고르려면 {{key:Shift}} 키를 누르십시오.
3. 열기를 선택하십시오.
   각 파일을 읽는 동안 "(name) 여는 중…" 메시지가 표시됩니다. 그러면 모든 페이지가 {{ui:시트}} 아래 나타나며, 새로 추가된 PDF 가운데 첫 번째의 첫 페이지가 열립니다.

PDF 파일을 {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 끌어 TakeoffCraft의 아무 곳에나 놓을 수도 있습니다. 끄는 동안 "PDF, DWG 또는 DXF 도면, 또는 .takeoff.json 파일을 놓으십시오" 틀이 나타납니다.

나중에 PDF 파일을 더 추가하려면 같은 방법을 다시 사용하십시오. 이미 열린 PDF 파일은 건너뜁니다.

시작 화면에는 최근에 연 PDF와 물량 산출도 나열됩니다. 페이지가 파일을 다시 열 수 있도록 허용하는 브라우저(Chrome 및 Edge)에서 가능합니다. 항목을 클릭해 여십시오. 브라우저가 먼저 권한을 요청할 수 있습니다. [내 파일](common:your-files)을 참조하십시오.

:::note
아무것도 업로드되지 않습니다. 브라우저가 컴퓨터의 PDF를 읽으며, 탭을 닫거나 {{ui:새로 만들기}}를 선택하면 TakeoffCraft에서 사라집니다.
:::

## PDF 옆의 도면

{{ui:도면 열기}}는 DWG 및 DXF 도면을 단독으로 또는 PDF 파일 옆에 함께 받습니다. 각 도면의 모델 공간과 배치는 같은 목록의 시트가 됩니다. [DWG 또는 DXF 도면 열기](topic:open-a-drawing)를 보고, 이어서 [도면에서 세기](topic:count-from-a-drawing)를 참조하십시오.

## 다른 앱에서 넘겨받은 PDF

제품군의 다른 앱은 열린 PDF 파일을 넘겨줄 수 있습니다. 그러면 새 탭에서 TakeoffCraft가 열리고, PDF 파일을 놓은 것처럼 그곳에서 열립니다. 상태 표시줄에 "(name) 열림, (app)에서 넘겨받음. 원본 파일은 변경되지 않았습니다."라고 표시됩니다. 아무것도 업로드되지 않습니다. 파일은 이 브라우저의 자체 저장소를 거치며, 열리면 그 저장소에서 사라집니다.

상태 표시줄에 PDF 파일이 "도착하지 않았습니다"라고 나오면, 탭이 너무 오래 기다렸거나 PDF 파일이 이미 다른 탭에서 열린 것입니다. {{ui:도면 열기}}로 여십시오.

반대 방향도 가능합니다. MarkupCraft가 사용자가 있는 곳에서 실행되고 파일을 받을 수 있으면, 도면 아래의 시트 막대에 {{ui:MarkupCraft}} 버튼이 있습니다. 이 버튼은 화면에 있는 시트의 PDF를 MarkupCraft에서 새 탭으로 열어 검토하고 마크업할 수 있게 합니다.

## 시트 찾기

- 왼쪽의 {{ui:시트}} 목록을 스크롤해 시트를 클릭하십시오.
- 목록 위의 **시트 검색**에 입력하면 시트 번호, 파일 이름 또는 페이지 레이블로 필터링합니다. {{ui:시트}} 옆의 개수는 필터가 켜져 있는 동안 "40개 중 3"처럼 표시됩니다.
- {{key:PageDown}}을 누르면 다음 시트, {{key:PageUp}}을 누르면 이전 시트로 이동합니다. 필터된 목록을 따릅니다.

:::mac
Page Up 및 Page Down 키가 없는 Mac 키보드에서는 fn 키와 위쪽 또는 아래쪽 화살표를 함께 누르십시오.
:::

## 시트 이름 짓기

- PDF 파일이 레이블을 지정한 페이지(예: `A-101`)는 그 레이블로 이름이 지정됩니다.
- 레이블이 없거나 페이지 번호와 같은 레이블만 있는 페이지는 "(파일 이름), 페이지 (n)"으로 이름이 지정됩니다.
- PDF 파일이 여러 개 열려 있으면, 레이블이 있는 시트에는 파일 이름도 붙습니다: "A-101 — Architectural".

시트 이름은 아직 직접 입력할 수 없습니다.

## 시트 주변 둘러보기

- 마우스 휠을 돌리면 포인터 위치를 기준으로 확대/축소됩니다.
- 왼쪽 또는 가운데 버튼으로 드래그하면 초점이 이동합니다. {{ui:자동 개수}}를 사용할 때, 또는 표시의 모서리에서 시작할 때는 드래그하는 동안 {{key:Space}}를 누르거나 가운데 버튼으로 드래그하십시오.
- {{key:F}} 키를 누르거나 {{ui:페이지 맞춤}}을 선택하면 시트 전체가 보입니다. {{key:W}} 키 또는 {{ui:너비 맞춤}}은 시트 너비에 맞춥니다.
- {{key:Plus}} 또는 {{key:=}} 키로 확대하고, {{key:Minus}} 키로 축소합니다. 보기의 가운데를 기준으로 합니다.

각 시트는 열려 있는 동안 자신의 확대/축소와 위치를 기억합니다.

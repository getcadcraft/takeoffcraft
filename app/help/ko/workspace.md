TakeoffCraft는 CadCraft 앱 표시줄 아래의 브라우저 창을 가득 채웁니다. 위에서 아래로, 왼쪽에서 오른쪽으로 구성은 다음과 같습니다.

| 부분 | 위치 | 용도 |
|---|---|---|
| 앱 표시줄 | 맨 위 | 앱 이름, 버전, {{ui:TakeoffCraft 정보}}, {{ui:도움말}}({{key:F1}}), {{ui:오프라인용 저장}}, {{ui:설정}}({{key:Mod+,}}), {{ui:전체 화면}} 버튼, {{ui:종이}} / {{ui:모델}} 테마 전환. |
| 도구 모음 | 앱 표시줄 아래 | 모든 명령이 그룹별로 있습니다: {{ui:파일}}, {{ui:내보내기}}, {{ui:축척}}, {{ui:물량 산출}}, {{ui:편집}}, {{ui:보기}}. |
| 시트 | 왼쪽 | 열린 모든 PDF의 모든 페이지이며 썸네일, 축척, 표식 개수가 표시됩니다. |
| 시트 화면 | 가운데 | 열린 페이지입니다. 여기에서 측정합니다. |
| 항목 | 오른쪽 | 물량 산출 항목, 선택한 항목의 설정, 선택한 표식. |
| 수량 | 아래쪽 | 항목별 또는 시트별 수량과 비용, 공사 총액. |
| 상태 표시줄 | 맨 아래 | 실시간 측정값, 메시지, 45° 안내, 확대/축소 비율. |

## 시트(왼쪽)

- **시트 검색**은 시트 이름, 파일 이름, 페이지 레이블로 목록을 걸러 냅니다.
- 각 시트에는 썸네일(스크롤할 때 그려집니다), 이름, 그리고 축척 또는 **축척 없음**이 표시됩니다.
- 각 행의 오른쪽에는 시트에 있는 표식 개수가 표시됩니다. 항목을 강조 표시하는 동안에는 그 항목의 표식 중 이 시트에 있는 개수가 대신 표시됩니다.
- 시트를 클릭하면 열립니다. {{key:PageDown}}과 {{key:PageUp}}은 목록의 다음 시트와 이전 시트로 이동합니다.
- 물량 산출이 열려 있지 않은 PDF를 포함하는 경우, 목록 아래의 안내에 해당 PDF 이름이 표시됩니다. [물량 산출 저장 및 다시 열기](topic:save-and-reopen)를 참고하십시오.

시트 이름은 PDF에서 가져옵니다. `A-101` 같은 페이지 레이블이 시트 이름이 됩니다. 레이블이 없는 페이지는 "Plans, 3쪽"처럼 파일 이름과 페이지 번호로 이름이 붙습니다. PDF를 여러 개 열면 레이블이 있는 시트에도 파일 이름이 함께 표시됩니다.

## 시트 화면(가운데)

- 시트 아래 막대에는 시트 이름과 축척, 또는 "아직 축척이 없습니다: 사전 설정을 고르거나 보정하십시오"가 표시됩니다. 막대의 버튼: {{ui:MarkupCraft}}(해당 앱이 PDF를 받을 수 있을 때. [물량 산출 시작 및 도면 세트 열기](topic:open-plan-set) 참고), {{ui:비교}}(시트의 이전 버전을 현재 시트 위에 겹침: [수정된 시트 비교](topic:compare-revisions)), "확인할 (n)개"(표시된 표식이 있을 때), {{ui:3D}}([3D 확인 보기](topic:check-in-3d)).
- PDF를 열기 전에는 가운데에 짧은 5단계 안내가 표시됩니다.
- 휠은 포인터 위치를 기준으로 확대/축소합니다. 끌면 화면이 이동합니다. [키보드와 마우스](topic:keyboard)를 참고하십시오.
- {{ui:자동 개수}}를 사용하는 동안에는 해당 컨트롤이 있는 막대가 시트 위쪽에 나타납니다.

## 항목(오른쪽)

맨 위에는 {{ui:입찰 범위}} 목록이 있으며, 새 표식이 들어갈 건물, 층 또는 단계를 고릅니다([입찰 범위](topic:bid-areas)).

- {{ui:새 항목}}은 작은 양식을 엽니다. 이름, 종류({{ui:선형 (길이)}}, {{ui:면적}} 또는 {{ui:수량}}), {{ui:추가}}가 있습니다.
- 목록에는 각 항목의 색, 종류 아이콘, 이름, 수량이 표시됩니다. 항목을 클릭하면 그 항목으로 그릴 수 있고 모든 시트에서 해당 표식이 강조 표시됩니다. 다시 클릭하면 강조 표시가 해제됩니다.
- 목록 아래의 **항목: (이름)**은 항목 편집기이며 이름, 종류, 색, 단위, 높이 또는 깊이, 할증, 재료비와 노무비 단가, 측정값, {{ui:복합 단가}}가 있습니다. [물량 산출 항목 만들기](topic:create-items)를 참고하십시오.
- **선택한 표식**은 표식을 선택하면 나타납니다. 속한 항목, 시트, 측정값, 그리고 {{ui:구멍 추가}}, {{ui:표식 삭제}} 같은 버튼이 표시됩니다. 표식을 여러 개 선택하면 **선택한 표식**으로 바뀌어 항목별 개수와 {{ui:복사}}, {{ui:복제}}, {{ui:잘라내기}}, {{ui:표식 삭제}}가 표시됩니다.
- 항목 편집기의 맨 아래에는 {{ui:항목 복사}}와 {{ui:항목 복제}}가 있습니다. 복합 단가와 비용은 포함하고 표식은 포함하지 않는 항목입니다. [표식 복사, 붙여넣기, 복제](topic:copy-paste)를 참고하십시오.

## 수량(아래쪽)

- {{ui:항목별}}은 모든 항목과 그 복합 단가 구성 요소를 수량, 할증, 단가, 확장 비용과 함께 나열합니다. 할증과 단가는 표에 바로 입력할 수 있습니다.
- {{ui:시트별}}은 각 항목의 시트별 수량을 나열합니다.
- 무언가가 합계에서 빠졌을 때는 **미완료:**로 시작하는 경고가 나타납니다.
- {{ui:공사 총액}}은 머리글의 오른쪽에 있습니다.
- 맨 오른쪽의 화살표 버튼은 표를 숨기거나 표시하여 시트 공간을 넓혀 줍니다.

[수량과 견적 읽기](topic:read-quantities)를 참고하십시오.

## 상태 표시줄(아래쪽)

왼쪽부터 순서대로, 그리는 동안의 실시간 측정값(길이, 면적, 반지름 또는 검사 결과), 길이를 입력하는 동안의 {{ui:입력}} 상자, TakeoffCraft의 메시지, "Shift는 45°에 스냅"이라는 안내([설정](topic:settings)에서 켜 두면 "45°에 스냅됩니다; Shift를 누르면 각도가 자유롭습니다"), {{ui:스냅}} 버튼(도면의 선에 스냅. 강조 표시되면 켜짐, {{key:F3}}), 확대/축소 비율이 있습니다.

:::tip
무언가 동작하지 않을 때는 상태 표시줄을 읽어 보십시오. 클릭을 거부한 이유가 그곳에 표시됩니다. 예: "이 시트에는 아직 축척이 없습니다."
:::

## 다른 레이아웃

위에서 설명한 것은 처음 시작할 때의 {{ui:CadCraft 클래식}} 레이아웃입니다. {{ui:설정}}({{key:Mod+,}}) › {{ui:전역}} › {{ui:배치}}에서 두 가지를 더 고를 수 있습니다. 세 레이아웃 모두 같은 도구와 키가 동작하며, {{ui:CadCraft 클래식}}을 다시 고르면 모든 컨트롤이 원래 자리로 돌아갑니다.

| 레이아웃 | TakeoffCraft에서 |
|---|---|
| {{ui:리본 및 프로젝트 탐색기}} | 위쪽 전체에 걸친 {{ui:물량 산출 리본}}([메뉴, 키, 마우스](topic:menus-keys-and-mouse)), 실행 중인 도구용 막대, 연 시트마다 하나씩 있는 탭(도면의 모델과 배치도 시트입니다), 시트 아래의 축척 사전 설정과 {{ui:페이지 맞춤}}. 왼쪽 패널에는 {{ui:물량 산출 탐색기}} 위에 {{ui:속성}}(선택한 항목, 메모 또는 표식)이 있습니다. 탐색기는 {{ui:시트}}(클릭하면 탭에서 열림), {{ui:조건}}(클릭하면 그 조건으로 그림), {{ui:견적}}(항목별 합계와 공사 총액)으로 구성되며, 썸네일은 두 번째 탭입니다. |
| {{ui:도구 상자 및 정보 상자}} | 시트 위의 도구 모음, {{ui:입찰 범위}}·실행 중인 도구 또는 선택 항목·시트 막대가 있는 정보 상자, 왼쪽의 물량 산출 도구 열, 모든 시트의 탭, 시트 아래의 {{ui:스냅}}과 확대/축소. |

[3D 확인 보기](topic:check-in-3d)가 열려 있는 동안에는 시트 탭과 시트 아래 막대가 비켜 있으며, 다시 측정하려면 3D 보기를 닫으십시오. 휴대폰에서는 항상 휴대폰 레이아웃이 실행됩니다.

## 전체 화면과 테마

앱 표시줄의 {{ui:전체 화면}} 버튼 또는 {{key:Ctrl+Shift+F}}(Mac에서도 Control)를 누르면 일반, 전체 화면, 막대를 숨긴 전체 화면 순으로 전환됩니다. 막대를 숨긴 상태에서는 포인터를 위쪽 가장자리로 옮기면 다시 표시됩니다.

{{ui:종이}}는 밝은 테마이고 {{ui:모델}}은 어두운 테마입니다. {{ui:모델}}에서는 화면에서만 도면이 반전되어(어두운 바탕에 밝은 선) 표시되며, 내보내기 결과는 절대 바뀌지 않습니다.

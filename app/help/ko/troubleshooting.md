TakeoffCraft는 대부분의 거부 사유를 창 하단의 상태 표시줄에 설명합니다. 아래에서 메시지를 찾으십시오.

## 파일 열기

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| PDF 리더를 불러오지 못했습니다. 페이지를 새로 고쳐 다시 시도하십시오. | 앱의 PDF 리더가 로드되지 않았습니다. 대개 오프라인 상태이고 오프라인 사용을 위해 앱을 저장하지 않은 경우입니다. | 다시 연결한 다음 새로 고치십시오. 그다음 {{ui:오프라인용 저장}}을 선택하고 {{ui:오프라인 사용 준비됨}}이 나타날 때까지 기다리십시오. [오프라인 작업](common:offline)을 참조하십시오. |
| (name) 파일은 암호로 보호되어 있습니다. 보호되지 않은 사본을 여십시오. | PDF를 열려면 암호가 필요합니다. | 보호되지 않은 사본을 요청하거나, 신뢰하는 PDF 프로그램에서 암호를 제거하십시오. |
| (name) 파일을 PDF로 읽을 수 없습니다 (…) | 파일이 손상되었거나 실제 PDF가 아닙니다. | 다시 다운로드하거나, 해당 파일을 만든 프로그램에서 다시 저장하십시오. |
| (name) 파일은 이미 열려 있습니다. | 같은 PDF(내용이 같음)가 열려 있습니다. | 할 일 없음. |
| TakeoffCraft는 PDF와 .takeoff.json 프로젝트를 엽니다. 건너뜀: … | 다른 파일 형식은 제외되었습니다. | 도면을 먼저 PDF로 변환하십시오. |
| 파일을 놓아도 아무 일도 없음 | 파일을 브라우저 창 밖에 놓았거나, 브라우저가 PDF를 새 탭에서 열었습니다. | TakeoffCraft 페이지 자체에 놓으십시오. "PDF 또는 .takeoff.json을 여기에 놓으십시오" 영역에 작동 여부가 표시됩니다. |
| 큰 세트를 여는 데 시간이 걸림 | 모든 PDF를 식별하기 위해 전체를 읽습니다. | "(name) 여는 중…" 메시지가 사라질 때까지 기다리십시오. 축소판은 스크롤하면서 채워집니다. |

## 측정

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 먼저 PDF를 여십시오. | 열린 시트가 없습니다. | PDF를 여십시오. |
| 이 시트에는 아직 축척이 없어 측정할 수 없습니다. 사전 설정 축척을 고르거나 먼저 보정하십시오(수량은 축척 없이도 작동합니다). | {{ui:선형}}, {{ui:면적}}, {{ui:원}}, {{ui:개구부}} 도구는 축척이 필요합니다. | [축척 설정](topic:set-the-scale) |
| 먼저 선형 항목을 만드십시오({{ui:항목}} 아래에 이름 입력), 그런 다음 시트를 클릭하십시오. | 해당 유형의 항목이 없습니다. | 열린 {{ui:새 항목}} 양식을 채우고 {{ui:추가}}를 선택하십시오. |
| 먼저 물량을 산출할 항목을 고르십시오({{ui:항목}} 패널). | 현재 항목이 삭제되었습니다. | {{ui:항목}} 아래의 항목을 클릭하십시오. |
| 구간에는 최소 두 점이 필요합니다. | 한 번 클릭한 뒤 완료했습니다. | 최소 두 점을 클릭하십시오. |
| 면적에는 최소 세 점이 필요합니다. | 꼭짓점이 너무 적습니다. | 최소 세 꼭짓점을 클릭하십시오. |
| 외곽선이 스스로 교차하므로 면적이 틀립니다. 교차하지 않도록 다시 그리십시오. | 8자 모양입니다. | 두 개의 면적으로 나누어 그리거나, 가장자리를 순서대로 따라 그리십시오. |
| 그 점들은 면적을 둘러싸지 않습니다. | 모든 점이 한 직선 위에 있습니다. | 공간을 둘러싸는 꼭짓점을 클릭하십시오. |
| 먼저 면적 마크를 선택({{ui:선택}} 도구)하고, {{ui:개구부}}를 선택한 다음 그 안에 구멍을 그리십시오. | {{ui:개구부}} 도구는 선택된 면적이 필요합니다. | {{key:V}}를 누르고, 면적을 클릭한 다음 {{key:X}}를 누르십시오. |
| 개구부는 면적 안에 완전히 들어가야 합니다. | 구멍이 외곽선과 교차하거나 밖으로 벗어납니다. | 면적 안에 구멍을 그리십시오. |
| 개구부끼리는 겹칠 수 없습니다. | 두 구멍이 겹칩니다. | 두 구멍을 함께 감싸는 하나의 구멍을 그리거나, 서로 떨어뜨리십시오. |
| … 점이 원래 위치로 돌아갔습니다. | 끌어 놓은 꼭짓점 때문에 외곽선이 스스로 교차하거나 구멍이 밖으로 밀려날 수 있었습니다. | 도형이 유효하게 유지되는 위치로 끌어 놓으십시오. |
| 원의 가장자리에서 중심에서 떨어진 점을 클릭하십시오. | 두 번째 클릭이 중심에 너무 가까웠습니다. | 더 바깥쪽을 클릭하십시오. |
| 클릭하면 점이 추가되지 않고 시트가 이동함 | 버튼을 누른 상태에서 포인터가 몇 픽셀 이상 움직였습니다. 이는 드래그로 간주됩니다. | 움직이지 않고 클릭하십시오. 특히 트랙패드를 사용할 때 그렇습니다. |
| Shift 키로 스냅되지 않음 | 호 위에 점을 찍거나 원을 그리고 있습니다. | 45° 스냅은 직선 구간에만 적용됩니다. |
| 가까운 선에 점이 달라붙음 | 도면 선에 스냅이 켜져 있습니다. | 확대하여 선 사이를 클릭하거나, {{key:F3}}를 눌러 스냅을 끄십시오. |
| 스냅 표시기가 나타나지 않음 | 스냅이 꺼져 있거나, 시트가 스캔본이거나, 도구가 스냅하지 않습니다({{ui:수량}}, {{ui:자동 개수}}, 붙여넣기). | {{key:F3}}를 누르십시오. 스캔본에는 스냅할 선이 없습니다. |
| 길이가 틀림 | 축척이 틀렸습니다(크기가 조정된 PDF에 사전 설정을 쓴 경우가 많습니다). | 알려진 치수에 {{ui:검사}}를 사용한 다음 {{ui:보정}}을 선택하십시오. |

## 축척

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 더 멀리 떨어진 두 점을 고르십시오. | 보정 점이 거의 겹쳐 있습니다. | 더 긴 치수에서 보정하십시오. |
| 보정 대화상자의 메시지, 예: "해당 거리를 읽을 수 없습니다" | 거리가 TakeoffCraft가 읽을 수 없는 형식입니다. | [길이, 단가 및 백분율 입력](topic:entry-formats)을 참조하십시오. |
| 이 시트에는 아직 축척이 없어 검사할 것이 없습니다. 보정하거나 사전 설정을 고르십시오. | 축척이 없는 시트에서 {{ui:검사}}를 실행했습니다. | 먼저 축척을 설정하십시오. |
| {{ui:사전 설정}} 목록이 흐리게 표시됩니다. | 열린 시트가 없습니다. | PDF를 여십시오. |

## 수량과 수식

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 불완전: … (합계에 포함되지 않음) | 수식 오류, 또는 축척이 없는 시트에 마크가 있습니다. | [수량과 견적 읽기](topic:read-quantities#the-incomplete-warning)를 참조하십시오. |
| 항목 옆의 +(n) 축척 없음 | 일부 마크가 축척이 없는 시트에 있습니다. | 해당 시트에 축척을 설정하십시오. |
| 수식 오류: … | 수식을 계산할 수 없습니다. | [수식 언어](topic:formulas#errors)를 참조하십시오. |
| 이 항목에는 마크가 있으므로 유형을 바꿀 수 없습니다. | 마크가 생기면 유형이 고정됩니다. | 다른 유형의 새 항목을 만들고, 마크를 그 항목으로 다시 그리십시오. |
| 항목에는 이름이 필요합니다. | 이름 칸이 비었습니다. | 이름을 입력하십시오. |
| 12.50와 같은 금액을 입력하십시오. / 10 또는 7.5와 같은 백분율을 입력하십시오. | 단가 또는 할증을 읽을 수 없습니다. | [길이, 단가 및 백분율 입력](topic:entry-formats)을 참조하십시오. |
| 합계가 두 배로 보임 | 항목에 자체 단가가 있고, 구성 요소도 같은 비용을 가집니다. | 구성 요소가 비용을 가지면 항목 자체의 단가를 0으로 설정하십시오. |
| 이 항목의 마크는 열려 있지 않은 PDF에 있습니다. | 모든 마크가 아직 열지 않은 PDF에 있는 항목을 클릭했습니다. | 해당 PDF를 여십시오. 이름은 {{ui:시트}} 아래에 나열됩니다. |

## 자동 개수

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 상자가 너무 작습니다. 기호 전체를 둘러싸도록 그리십시오. | 상자가 매우 작습니다. | 확대한 다음 기호 전체를 상자로 감싸십시오. |
| 상자가 거의 비어 있습니다. 기호를 둘러싸도록 그리십시오. | 상자에는 종이만 있습니다. | 기호 자체를 상자로 감싸십시오. |
| 일치 없음. {{ui:일치}} 슬라이더를 낮추거나 기호를 더 촘촘히 상자로 감싸십시오. | 충분히 높은 점수를 받은 것이 없습니다. | 기호를 촘촘히 상자로 감싸거나, {{ui:일치}} 슬라이더를 낮추십시오. |
| 잘못된 기호를 포함하여 일치가 너무 많음 | 비슷한 기호가 실제 기호와 점수가 가깝습니다. | {{ui:일치}} 슬라이더를 올리고, 잘못된 상자를 클릭해 거부하십시오. |
| 다른 시트에서 일치 항목이 누락됨 | 해당 시트는 기호를 다른 크기로 그리거나, 90° 단계가 아닌 각도로 그립니다. | 해당 시트에 상자를 그려 검색하거나, 직접 세십시오. |
| (n)개 시트는 이 기호 크기로 검색하기에 너무 컸습니다. | 작업 크기에서 시트가 너무 큽니다. | 더 큰 기호를 상자로 감싸거나, 해당 시트는 직접 세십시오. |
| 검색 실패: … | 백그라운드 검색이 중단되었습니다. | 다시 시도하십시오. 반복되면 페이지를 새로 고치십시오(먼저 저장하십시오). 오프라인에서는 앱 표시줄에 {{ui:오프라인 사용 준비됨}}이 표시된 후에만 작동합니다. |
| 끌기가 이동 대신 상자를 그림 | 이것이 {{ui:자동 개수}}의 동작 방식입니다. | {{key:Space}}를 누른 채 끌거나, 가운데 버튼으로 끌기를 하십시오. |

## 저장 및 내보내기

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 아직 내보낼 것이 없습니다: 항목을 만들고 물량을 산출하십시오. | 항목이 없습니다. | 먼저 항목을 만드십시오. |
| 열린 PDF에 마크가 아직 없습니다. | {{ui:표시된 PDF}}가 열린 PDF에 그릴 것이 없습니다. | 마크가 있는 PDF를 여십시오. |
| 이 PDF는 암호로 보호되었거나 암호화되어 있어 표시된 사본을 쓸 수 없습니다. … | PDF가 암호화되어 있습니다. | 대신 {{ui:XLSX}}를 내보내거나, 암호화되지 않은 PDF 사본을 사용하십시오(다른 파일이므로 자체 물량 산출이 필요합니다). |
| 표시된 PDF를 쓸 수 없습니다: … | 대개 오프라인 상태이고, 앱을 오프라인 사용을 위해 저장하지 않아 PDF 작성기가 없습니다. | 온라인으로 전환한 다음 {{ui:표시된 PDF}}를 다시 선택하십시오. 이를 피하려면 {{ui:오프라인용 저장}}을 선택하고 {{ui:오프라인 사용 준비됨}}이 나타날 때까지 기다리십시오. |
| 표시된 PDF가 하나만 다운로드됨 | 브라우저가 여러 다운로드를 한꺼번에 차단했습니다. | 이 사이트의 여러 다운로드를 허용한 다음 다시 내보내십시오. |
| (file) 파일은 TakeoffCraft 프로젝트가 아닙니다(올바른 JSON이 아님). / 이것은 TakeoffCraft 프로젝트 파일이 아닙니다. | 잘못된 파일이거나 손상된 파일입니다. | `.takeoff.json` 파일을 고르십시오. |
| 이 프로젝트는 더 새로운 TakeoffCraft에서 저장되었습니다. 그곳에서 여십시오. | 파일이 더 새로운 빌드에서 만들어졌습니다. | 더 새로운 빌드에서 여십시오. |
| (n)개 마크가 손상되어 제외되었습니다. | 파일 일부가 손상되었거나 직접 편집되었습니다. | 나머지는 열렸습니다. 빠진 마크를 다시 그리거나 이전 사본을 여십시오. |
| 다시 열고 나서 마크가 없음 | PDF가 열려 있지 않거나, 그중 하나가 변경되었습니다. | [물량 산출 저장 및 다시 열기](topic:save-and-reopen#when-a-pdf-has-changed)를 참조하십시오. |
| 브라우저가 "사이트를 떠나시겠습니까?"라고 묻습니다. | 저장되지 않은 변경 사항이 있습니다. | 머무른 다음 {{key:Mod+S}}로 저장하십시오. |

## 키와 마우스

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 문자 키가 작동하지 않음 | 커서가 입력란(검색, 항목 편집기, 표)에 있습니다. | 시트를 클릭하거나, {{key:Tab}}으로 입력란 밖으로 나가십시오. |
| 휠이 스크롤 대신 확대/축소함 | 휠은 항상 시트를 확대/축소합니다. | 드래그하여 이동하십시오. |
| 페이지 전체가 커지거나 작아짐 | 브라우저 확대/축소({{key:Mod+Plus}} 또는 {{key:Mod+Minus}}). | {{key:Mod+0}}을 누르십시오. 휠 또는 단독 {{key:Plus}} 및 {{key:Minus}} 키로 시트를 확대/축소하십시오. |
| Backspace를 누르자 마크가 사라짐 | Backspace는 그리는 중이 아닐 때 선택된 마크를 삭제합니다. | {{key:Mod+Z}}로 되돌리십시오. |
| Mac에서 우클릭으로 완료되지 않음 | Control 클릭은 일반 클릭으로 전달됩니다. | 보조 클릭을 켠 상태에서 두 손가락 클릭을 사용하거나, {{key:Enter}}를 누르십시오. |

## 터치 스크린

터치 스크린에서:

- **탭**은 점을 놓습니다(또는 {{ui:선택}}으로 마크를 선택합니다). 한 손가락으로 끌면 이동합니다.
- **두 손가락**으로 꼬집으면 두 손가락 사이 지점을 기준으로 확대/축소되며, 함께 움직이면 이동합니다. 두 번째 손가락을 대면 첫 번째 손가락이 시작한 동작이 취소되므로, 꼬집기 동작이 점을 남기지 않습니다.
- 구간이나 외곽선은 **길게 누르기**(우클릭), **두 번 탭**, 또는 시트 하단 표시줄의 {{ui:끝내기}}로 완료합니다. 같은 표시줄에는 {{ui:뒤}}(마지막 점을 되돌림)와 {{ui:취소}}가 있습니다. 면적은 첫 점을 탭해도 닫힙니다.
- 손가락용 대상은 더 큽니다: 점은 더 멀리서도 스냅, 닫기, 선택되며 꼭짓점 핸들도 더 큽니다.

길이를 입력하려면 키보드가 필요합니다. 화면 키보드는 {{ui:입력}} 상자에 초점이 있을 때 작동합니다.

태블릿에서는 키보드와 마우스 또는 트랙패드가 있으면 물량 산출이 훨씬 쉬워집니다.

## 오프라인 작업

| 버튼 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| {{ui:저장하지 못했습니다}} | 오프라인 사용을 위해 저장하는 중 앱 파일 일부가 다운로드되지 않았습니다. | 연결을 확인하고 버튼을 다시 선택하십시오. |
| {{ui:오프라인 사용 불가}} | 비공개 창과 일부 관리 컴퓨터는 오프라인 사본을 차단합니다. | 일반 창이나 다른 브라우저를 사용하십시오. |
| "저장 중…"이 시작되지 않음 | 오프라인 상태입니다. 저장하려면 연결이 필요합니다. | 온라인 상태에서 저장하십시오. |
| 업데이트 후 앱이 오래됨 | 오프라인 사본은 며칠 전의 것입니다. | 온라인 상태에서 {{ui:오프라인 사용 준비됨}}을 선택한 다음 {{ui:다시 저장 (최신 버전 받기)}} 버튼을 선택하십시오. |
| 여유 공간을 되찾고 싶음 | 오프라인 사본은 약 6 MB입니다. | {{ui:오프라인 사용 준비됨}}을 선택한 다음 {{ui:오프라인 사본 제거}}를 선택하십시오. |

[오프라인 작업](common:offline)을 참조하십시오.

## 여전히 해결되지 않음

앱이 응답하지 않으면 페이지를 새로 고치십시오. 저장하지 않은 물량 산출은 새로 고침할 때 사라지므로, 가능하다면 먼저 {{key:Mod+S}}로 저장하십시오. 브라우저 관련 질문은 [브라우저와 컴퓨터](common:browsers)를 참조하십시오.

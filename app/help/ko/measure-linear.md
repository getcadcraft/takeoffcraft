선형 항목은 길이를 측정합니다. 각 구간은 점들이 이어진 것입니다: 직선 선분, 그리고 호 모드를 켜면 호. 항목은 여러 시트에 걸쳐 원하는 만큼 구간을 가질 수 있습니다.

시작하기 전에: 시트에 축척이 필요하고 ([축척 설정](topic:set-the-scale)), 선형 항목이 있어야 합니다 ([물량 항목 만들기](topic:create-items)).

벡터 PDF에서는 클릭이 도면 자체의 선에 맞춰집니다: 끝점, 중간점, 교차점 ([도면의 선에 맞추기](topic:snap-to-the-drawing); {{key:F3}} 키로 끕니다).

## 구간 그리기

1. {{ui:Items}} 아래의 선형 항목을 클릭합니다.
2. 도구 모음의 {{ui:Linear}} 도구를 선택하거나 {{key:L}} 키를 누릅니다.
3. 구간의 시작점을 클릭합니다.
4. 따라가며 각 모서리를 클릭합니다.
   상태 막대에 "길이" (지금까지의 구간, 포인터까지)와 "선분" (그리고 있는 선분)이 피트와 인치로 표시됩니다.
5. 구간을 끝냅니다: 마지막 점을 더블 클릭하거나, {{key:Enter}} 키를 누르거나, 우클릭합니다.
   구간은 항목 색으로 그려지고 선택된 표식이 됩니다. {{ui:Items}} 목록과 {{ui:Quantities}} 표의 항목 길이가 늘어납니다.

도구는 {{ui:Linear}}에 머물러 있으므로 바로 다음 구간을 시작할 수 있습니다. {{key:Esc}} 키를 누르면 {{ui:Select}} 도구로 돌아갑니다.

그리는 중에는 다음과 같습니다:

- {{key:Backspace}} 키 (또는 {{key:Delete}} 키)는 마지막 점을 제거합니다.
- {{key:Esc}} 키는 미완성 구간을 버립니다.
- 드래그하면 시트가 이동하고, 휠로 확대 및 축소하며, 점은 추가되지 않습니다.

:::mac
Mac 트랙패드에서 우클릭은 두 손가락 클릭입니다 (시스템 설정의 트랙패드 항목에서 보조 클릭을 켜십시오). TakeoffCraft는 보조 버튼만 읽으므로, Control 클릭은 일반 클릭으로 취급되어 점이 추가될 수 있습니다. 더블 클릭이나 {{key:Enter}} 키는 항상 구간을 끝냅니다.
:::

:::touch
터치 화면에서는 탭으로 점을 놓고, 한 손가락으로 끌어 이동하며, 두 손가락으로 핀치하여 확대합니다. 길게 누르기, 두 번 탭하기, 또는 시트 아래 막대의 {{ui:Finish}} 항목으로 끝냅니다 ({{ui:Back}}은 마지막 점을 되돌립니다). [문제 해결](topic:troubleshooting#touch-screens)을 참고하십시오.
:::

## 45° 단위의 직선

점을 놓는 동안 {{key:Shift}} 키를 누르십시오. 마지막 점에서 나오는 선분은 가장 가까운 0°, 45°, 90° 또는 135° 방향으로 맞춰지며, 드래그한 길이는 그대로 유지됩니다. 상태 막대에 "Shift 키: 45° 맞춤"이라고 표시됩니다.

호 모드에서는 호가 끝나는 지점에 적용됩니다: 호의 현은 시작점에서 45° 단위로 놓입니다. 곡선 위에서 클릭한 점은 맞춰지지 않습니다.

## 호와 곡선 벽

1. 구간을 그리는 중에 곡선이 시작되는 점을 놓습니다.
2. 호 모드를 켭니다: 도구 모음에서 {{ui:Arc}} 도구를 선택하거나 {{key:R}} 키를 누릅니다. 버튼이 눌린 상태로 유지됩니다.
3. 곡선 위 아무 점이나, 중간쯤을 클릭합니다.
   상태 막대에 "(호: 끝나는 곳을 클릭)"이 추가되고, 미리 보기가 클릭한 점을 지나도록 휘어집니다.
4. 곡선이 끝나는 곳을 클릭합니다.
   호가 추가됩니다. 길이는 여러 개의 짧은 현이 아니라 정확한 호의 길이입니다.
5. 다음 곡선에서도 중간 점과 끝을 클릭해 호를 계속 그리거나, {{key:R}} 키를 다시 눌러 직선 선분으로 돌아갑니다.

{{key:Backspace}} 키 또는 {{key:Esc}} 키는 먼저 곡선 위의 대기 중인 점을 버립니다. 다시 누르면 평소처럼 점을 제거합니다.

## 길이와 좌표 입력

첫 점 뒤에는 클릭 대신 다음 점이 갈 위치를 입력할 수 있습니다. 숫자, `@` 또는 `#`을 입력하면 상태 막대에 {{ui:Type}} 상자가 열리고 입력한 내용이 표시됩니다. {{key:Enter}} 키를 누르면 점이 놓이며, 상자는 다음 점을 위해 열린 채로 남습니다.

| 입력 | 다음 점이 가는 곳 |
|---|---|
| `12'6"` | 마지막 점에서 12'-6" 떨어진 곳, 포인터 방향 (방향을 가리킨 뒤 길이를 입력) |
| `12'6"<45` | 화면의 오른쪽에서 반시계 방향으로 45°, 12'-6" (`<90`은 위, `<-90`은 아래) |
| `@6',-4'` | 마지막 점에서 오른쪽 6', 아래 4' |
| `6',4'` (또는 `#6',4'`) | 이 구간의 첫 점에서 오른쪽 6', 위 4' |

길이는 TakeoffCraft의 모든 곳에서와 같은 방식으로 입력합니다 ([입력 형식](topic:entry-formats)): `12'-6 1/2"`, `12.5` (피트), `30"`, `3.2 m`. "오른쪽"과 "위"는 시트를 보는 기준입니다. PDF 페이지를 돌려도 마찬가지입니다.

빈 상자에서 {{key:Enter}} 키를 누르면 시트에서 {{key:Enter}} 키를 누른 것처럼 구간이 끝납니다. {{key:Esc}} 키는 상자를 닫고 구간은 계속 유지합니다. 입력한 점도 클릭과 같은 규칙을 따르므로, 공제, 호, 면적 닫기가 모두 작동합니다. 같은 상자가 {{ui:Area}}와 {{ui:Cut-out}}에서도 작동하며, 원의 중심을 정한 뒤에는 반지름을 입력받습니다.

## 구간의 일부 공제

출입구나 상점 전면을 지나는 벽 구간은 곧게 그려도 벽만 계산되도록 할 수 있습니다: 개구부를 가로지르는 선분은 **공제**입니다. 이 선분은 얇은 점선으로 그려지며, 계산되지 않습니다.

그리는 중에는:

1. 개구부가 시작되는 곳에 점을 놓습니다.
2. 도구 모음의 {{ui:Deduct}} 도구를 선택하거나 {{key:E}} 키를 누릅니다. 버튼이 눌린 상태로 유지되고, 상태 막대에 다음 선분이 공제라고 표시됩니다.
3. 개구부가 끝나는 곳을 클릭합니다. 선분은 점선으로 그려지고, 상태 막대의 "길이"에서 빠집니다.
4. {{key:E}} 키를 다시 누르고 벽을 따라 계속 그립니다.

그린 뒤에는: 구간을 선택합니다. **선택된 표식** 아래 각 선분에 {{ui:Deduct}} 상자가 있습니다. 체크하면 그 선분을 공제하고, 체크를 해제하면 다시 계산합니다. 각 변경은 실행 취소 한 단계입니다.

구간은 항상 계산되는 선분을 최소 하나 유지합니다. 패널에는 **공제** (공제된 길이)와 **그린 길이** (구간 전체)가 표시되며, **길이**, 항목의 수량, 벽 면적, 비용은 모두 공제를 뺀 길이를 사용합니다. 3D 확인 보기에서는 벽에 틈이 생기고, 표시된 PDF에서는 공제가 점선으로 그려지며, 내보낸 **표식** 시트에 공제 목록이 나옵니다.

구간의 모서리를 옮기면 공제가 유지됩니다. 점을 추가하거나 제거하면 (구간을 다시 그리면) 공제 없이 시작합니다.

## 구간 세부 정보 보기

{{ui:Select}} ({{key:V}}) 도구를 선택하고 구간을 클릭합니다. 오른쪽의 **선택된 표식**에 다음이 표시됩니다:

- 구간이 속한 항목 (목록에서 다른 선형 항목을 골라 구간을 옮길 수 있습니다),
- 시트,
- 피트와 인치 및 LF로 된 **길이**,
- **선분** 개수, 그리고 항목에 높이가 있을 때는 **벽 면적**,
- 각 선분의 길이 (호 뒤에는 "(호)"가 붙습니다)와 그 {{ui:Deduct}} 상자.

시트에서는 선택한 구간의 각 선분에 길이가 표시됩니다.

## 구간 고치기

- **점 이동**: 구간을 선택한 다음 사각 모서리 핸들 하나를 끕니다. {{key:Shift}} 키를 누르면 이동한 선분이 45° 단위로 맞춰집니다. 호는 휨을 유지합니다.
- **호 휘기**: 선택된 구간의 각 호 가운데에는 둥근 핸들이 있습니다. 끌면 손을 놓은 곳을 지나도록 호가 휘어지므로, 더 휘거나, 덜 휘거나, 반대로 휠 수 있습니다. 끝점 사이의 직선 위로 끌어 놓으면 직선 선분이 됩니다. {{key:Mod+Z}}로 되돌립니다 ("호 휘기").
- **구간 삭제**: 구간을 선택하고 {{key:Delete}} 키를 누르거나, 도구 모음의 {{ui:More}} 메뉴에서 {{ui:Delete}} 항목을 선택하거나, 패널의 {{ui:Delete mark}} 항목을 선택합니다.
- **실행 취소**: {{key:Mod+Z}}. 다시 실행은 {{key:Mod+Y}}.

구간 중간에 점을 넣는 기능은 아직 없습니다. 구간을 삭제하고 다시 그리십시오.

## 벽 면적

선형 항목에 {{ui:Height}} 값 (예: `9'-0"`)을 지정하십시오. 그러면 **벽 면적 (A)** = 길이 × 높이를 SF (미터법 항목은 m²)로 보고하며, 이 벽 면적은 스프레드시트 내보내기의 메모 열에 들어갑니다. 보드, 페인트, 단열재를 위한 복합 단가에서 사용하십시오: [복합 단가와 공식](topic:assemblies)을 참고하십시오.

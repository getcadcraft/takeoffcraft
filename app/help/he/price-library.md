**ספריית המחירים** מחזיקה פריטים שאתם משתמשים בהם עבודה אחר עבודה: הסוג, היחידה, הגובה, הפחת, תעריפי החומר והעבודה, והמכלול שלהם. היא נשמרת בדפדפן זה, בנפרד מכל הוצאת כמויות, כך שכל הוצאת כמויות שתפתחו כאן יכולה להשתמש בה.

פותחים אותה בעזרת {{ui:Library}} שבראש חלונית {{ui:Items}}.

## מילוי הספרייה

- {{ui:Import CSV…}} קורא גיליון אלקטרוני שנשמר כ-CSV (ראו את העמודות למטה). פריטים ששמם וסוגם כבר בספרייה מוחלפים; השאר נוספים. שורות שאי אפשר לקרוא מדולגות, והתוכנה מציינת אילו ולמה.
- **הוספת פריטי הוצאת הכמויות הזו** מעתיקה לספרייה כל פריט של הוצאת הכמויות הפתוחה, עם תעריפיו והמכלול שלו (לא את הסימונים שלו).
- ייצוא האומדן ל-CSV שמייצא TakeoffCraft ([ייצוא האומדן](topic:export-estimate)) מיובא כמות שהוא: מחירי העבודה הקודמת מזינים את הבאה.

- {{ui:Trade packs…}} מוסיף מכלולים חינמיים למקצוע, כמו גבס, חשמל או בטון, ללא מחירים. ראו [חבילות מקצוע](topic:trade-packs).

{{ui:Export CSV}} שומר את הספרייה כ-CSV: לשמירת עותק, לעריכה בגיליון אלקטרוני או למסירה לעמית. {{ui:Clear}} מרוקן אותה (לחצו פעמיים).

:::note
ספריית המחירים נמצאת באחסון של הדפדפן הזה. דפדפן אחר, מחשב אחר או חלון פרטי יש להם ספרייה משלהם (או שאין להם כלל). ייצאו אותה כדי להעביר אותה.
:::

## שימוש בהוצאת כמויות

- סמנו פריטים (הקלידו ב-{{ui:Find in the library}} כדי לצמצם את הרשימה), ובחרו {{ui:Add to takeoff}}. הם נוספים עם מכלוליהם בצעד אחד, שאפשר לבטל ב-{{key:Mod+Z}}. שם שכבר קיים בהוצאת הכמויות מקבל מספר, כמו `Carpet (2)`.
- {{ui:Update prices}} נותן לפריטים של הוצאת הכמויות את הפחת והתעריפים של הספרייה, לכל פריט ששמו וסוגו תואמים לפריט בספרייה, וכך גם לרכיבי מכלול בעלי אותו שם. גבהים, יחידות ונוסחאות נשארים כמו שהם. צעד {{key:Mod+Z}} אחד מחזיר את כל המחירים הישנים.

## עמודות ה-CSV

השורה הראשונה מציינת את העמודות, בכל סדר; עמודות אחרות מושמטות.

| עמודה | מה נכנס בה |
|---|---|
| Item (or Name) | שם הפריט. שדה חובה. |
| Type | Linear, Area או Count (LF, SF ו-EA עובדים גם הם). אם ריק, היחידה מכריעה. |
| Unit | LF או m; SF, SY או m²; EA. ריק: היחידה הרגילה של הסוג. |
| Waste % | `10` או `10%`. |
| Material per unit, Labor per unit | תעריפים כמו `2.10` או `$1,250`. |
| Height (or Depth) | `9'-0"`, `9`, או `2.7` ליחידות מטריות. |
| Component, Formula | שורה עם שם Component (או הסוג `Component`) היא חלק מהמכלול של הפריט שמעליה. היחידה, הפחת והתעריפים שלה משלה; הנוסחה שלה משתמשת באותיות של הפריט, ראו [מכלולים ונוסחאות](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

בין העמודות עובדים פסיקים, נקודה-פסיק או טאב.

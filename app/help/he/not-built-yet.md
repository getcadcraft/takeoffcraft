TakeoffCraft נמצאת בפיתוח. רשימה זו מפרטת מה הגרסה הנוכחית אינה עושה, וכיצד לבצע את העבודה בכל זאת.

## מדידה

| טרם נבנה | כיום, במקום |
|---|---|
| הוספת נקודה באמצע קו או מתאר | מחקו את הסימון וציירו אותו מחדש. |
| בחירה בתיבה (חלון) | לחיצה עם {{key:Shift}} על כל סימון, או {{key:Mod+A}} לכל הסימונים בגיליון. ראו [העתקה, הדבקה ושכפול של סימונים](topic:copy-paste). |
| סיבוב, היפוך או שינוי קנה מידה של עותק מודבק | הדביקו בגיליון באותו קנה מידה ובאותו כיוון; שרטטו את השאר ביד. |
| קריאת קנה מידה מגיליון סרוק, או משורת קנה מידה גרפית | בחרו את ההגדרה המוקדמת, או כיילו לפי אורך השורה. |
| יותר מקנה מידה אחד בגיליון (אזורי פירוט, תוכניות מוגדלות) | מדדו את החלק בקנה המידה של הגיליון, וכמתו את הפירוט בגיליון המוגדל שלו, אם יש לסט כזה גיליון משלו. |

## פריטים ותמחור

| טרם נבנה | כיום, במקום |
|---|---|
| נוסחאות הרכבה שמשתמשות בסוגי סימונים אחרים של פריט (הדלתות של פריט חדר בנוסחאות הקומה שלו) | הנוסחאות משתמשות בסיכומי הסוג הראשי; תמחרו את הסוגים האחרים בשורות משלהם. |
| נוסחאות הרכבה שמחושבות הרצה אחר הרצה | הנוסחאות משתמשות בסיכומי הפריט; השתמשו ב-`N` לתוספות לכל הרצה. |
| נוסחאות שמשתמשות בכמויות של פריט אחר | חזרו על המדידה בפריט ההוא, או חשבו זאת בייצוא לגיליון האלקטרוני. |
| צוותים על רכיבי מכלול, או יום עבודה שאינו 8 שעות | שייכו את הצוות לפריט; קראו ימי צוות לאורך יום אחר כשעות צוות ÷ היום שלכם. |
| תוספות (markups) שאינן הערות, ענני סימון והדגשות (חיצים, מידות, חותמות), או תשובות להערה | כתבו זאת בטקסט ההערה; שנו את מצבה כשהנושא מוסדר. |
| ספריית מחירים משותפת לצוות, או ספרייה השמורה בחשבון שלכם | הספרייה נשמרת בדפדפן זה: ייצאו אותה ל-CSV וייבאו אותה במחשב האחר. |
| חבילות מקצוע שנבדקו על ידי מעריכי כמויות במקצוע | כל חבילה היא נקודת פתיחה: בדקו את הנחותיה מול העבודה והמוצרים שלכם לפני תמחור. ראו [חבילות מקצוע](topic:trade-packs). |
| מחירים בחבילות מקצוע | חבילות מביאות מכלולים בלבד: קבעו את התעריפים שלכם, או ייבאו את מחירון שלכם כ-CSV. |
| שינוי שם הוצאת הכמויות | השם נלקח מה-PDF הראשון; שנו את שם הקבצים שהורדתם. |
| מתן שמות לגיליונות ביד | הגיליונות נקראים לפי תוויות העמודים של ה-PDF; חפשו לפי שם הקובץ ומספר העמוד. |

## שרטוטים (DWG ו-DXF)

| טרם נבנה | כיום, במקום |
|---|---|
| טבלאות סגנון הדפסה (plot style), הקצאות עטים וקבצי CTB בגיליונות של שרטוט | שרטוט מצויר בשחור, או בצבעיו מוכהים להדפסה על נייר; עובי הקווים נלקח מהשרטוט. |
| פתיחת DXF בינארי, או DWG ישן מ-AutoCAD 2000 | שמרו כ-DXF מסוג ASCII או כ-DWG חדש יותר. |
| איתור שרטוט מקושר (xref) לפי התיקייה שבה הוא נמצא | פתחו גם את הקובץ של השרטוט המקושר, יחד עם המארח: הוא נמצא לפי שם הקובץ בין הקבצים הפתוחים. |
| מדידת פוליליינים תלת-ממדיים, רשתות, מוצקים ואזורים | ספרו אותם לפי שכבה וסוג, או מדדו את מבט התוכנית עם הכלים Linear ו-Area. |
| טקסט בסימון PDF מתוך שרטוט בכתב שאינו לטיני | תווים של Helvetica שאין להם גליף ידפסו כ-"?" ב-PDF המסומן; השרטוט על המסך אינו מושפע. |
| העברת שרטוט ליישום אחר מסרגל הגיליונות | פתחו את אותו הקובץ באותו יישום. |
| שרטוט שנושא את הוצאת הכמויות בתוכו, כפי שעושה {{ui:PDF with the takeoff inside}} עבור PDF | {{ui:Save takeoff}}: ה-`.takeoff.json` נפתח שוב על אותו שרטוט, ומזוהה לפי תוכנו. |
| שרטוט או ספירה של תשתיות PDF, תמונות ואובייקטי OLE שהוטמעו בשרטוט | תמונות מוצגות כמסגרת בלבד. פתחו את קובץ ה-PDF של התשתית עצמו כגיליון. |

## הצעות מחיר

| טרם נבנה | כיום, במקום |
|---|---|
| תוספות לחבילה שכבר נשלחה, מכתבי זכייה, וגיליון היקף שכל מציע חותם עליו | שלחו חבילה חדשה וכתבו את מכתב הזכייה בעצמכם. [שליחת חבילה להצעות](topic:bid-invitations) מכסה את מה שנבנה. |
| שליחת הזמנות להצעה מכל חשבון: בזמן הבדיקה, דואר למציעים חיצוניים כבוי, פרט לחשבונות שצוות CadCraft הפעיל | הורידו את {{ui:Scope CSV}}, שלחו אותו בדוא"ל בעצמכם, והקלידו את ההצעות. |

| תזכורות אוטומטיות לפני תום תוקף ביטוח או רישיון של קבלן משנה | התאריך מסומן בדף קבלני המשנה לאחר שחלף או כשנותרו עד 30 ימים; בדקו אותו בעת ההזמנה. |

## גיליונות אלקטרוניים

חוברת העבודה XLSX נבדקה ב-LibreOffice Calc, שחישב מחדש כל סכום עד לאגורה זהה ל-TakeoffCraft. היא עדיין לא נפתחה ב-Excel. אם תוכנת גיליונות מציגה משהו בלתי צפוי, ייצוא ה-CSV מכיל את אותה אומדן כערכים פשוטים.

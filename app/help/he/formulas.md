רכיבי הרכבה מקבלים את הכמות שלהם מנוסחה. נוסחה היא ביטוי חשבוני קצר על הערכים שנמדדו בפריט. ראו [הרכבות ונוסחאות](topic:assemblies) לדוגמאות מלאות.

## משתנים

| סוג הפריט | משתנה | משמעות |
|---|---|---|
| אורך | `L` | אורך כולל |
| אורך | `H` | גובה הפריט |
| אורך | `A` | שטח קיר, L × H, בניכוי הפתחים של מקטעים שנושאים אותם (כתב כמויות מ-BimCraft). כאשר כתב הכמויות מציין שיטת מדידה, `A` נמדד לפיה: פתחים שאינם גדולים מהגודל המינימלי של השיטה נשארים בחישוב, ומה ששיטת הכמות מוציאה במפגש קירות נשאר בחוץ. ההערה מתחת לפריט מציינת את השיטה |
| אורך | `N` | מספר המקטעים |
| שטח | `A` | שטח נטו כולל (קווי מתאר בניכוי חתכים) |
| שטח | `P` | היקף כולל, כולל קצוות החורים |
| שטח | `H` | עומק או עובי הפריט |
| שטח | `N` | מספר השטחים |
| ספירה | `N` | הספירה |

- המשתנים הם ביחידות הפריט: ראו [יחידות](topic:units).
- אותיות גדולות וקטנות זהות: `l` הוא `L`.
- רק המשתנים של סוג הפריט פועלים. `P` על פריט אורך נותן `"P" is not a measured value here. Use L, H, A, N.` (הודעה: `"P" אינו ערך נמדד כאן. השתמשו ב-L, H, A, N.`)
- גובה או עומק ריקים הם 0.

## אופרטורים

| כותבים | משמעות |
|---|---|
| `+` | חיבור |
| `-` או `−` | חיסור, או ערך שלילי |
| `*` או `×` | כפל |
| `/` או `÷` | חילוק |
| `( )` | קיבוץ |

כפל וחילוק קודמים לחיבור וחיסור: `L * 2 + 4` הוא (L × 2) + 4. השתמשו בסוגריים כשאתם לא בטוחים.

למספרים יכולות להיות ספרות אחרי הנקודה (`1.333`, `.5`) וחזקות (`1e3` = 1000). רווחים מתעלמים.

## פונקציות

| פונקציה | תוצאה | דוגמה |
|---|---|---|
| `ceil(x)` | עיגול כלפי מעלה למספר שלם | `ceil(67.5)` = 68 |
| `floor(x)` | עיגול כלפי מטה למספר שלם | `floor(67.5)` = 67 |
| `round(x)` | עיגול למספר השלם הקרוב, חצאים מתרחקים מאפס | `round(2.5)` = 3 |
| `round(x, d)` | עיגול ל-d ספרות אחרי הנקודה (0 עד 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | הערך הקטן ביותר | `min(N, 10)` |
| `max(a, b, …)` | הערך הגדול ביותר | `max(1, ceil(N / 12))` |
| `abs(x)` | הערך ללא סימנו | `abs(-3)` = 3 |

`ceil` ו-`floor` מתעלמים מרעש עיגול קטן של המחשב, כך שערך שאמור להיות בדיוק 1 לעולם לא יעוגל ל-2.

## שגיאות

נוסחה שאי אפשר לקרוא או לחשב מציגה את השגיאה שלה מתחת לשדה, והרכיב נשאר מחוץ לסכומים (הכותרת **כמויות** מציינת "לא שלם"). הודעות:

| הודעה | תיקון |
|---|---|
| הקלידו נוסחה, כמו L או ceil(L / 1.333) + 1. | הנוסחה ריקה. |
| "X" אינו ערך נמדד כאן. השתמשו ב-… | השתמשו באחד המשתנים המפורטים. |
| "X" אינו פונקציה כאן. השתמשו ב-ceil, floor, round, min, max, abs. | השתמשו באחת מהפונקציות האלה. |
| "#" אינו מותר בנוסחה. | הסירו את התו (יחידות, `%`, `$` ו-`=` אינם מותרים). |
| חסר ")". / יש ")" בלי "(" שלו. | איזנו את הסוגריים. |
| חסר ערך לפני ")". | משהו כמו `max(1, )`: מלאו את הערך. |
| הנוסחה מסתיימת מוקדם מדי. | משהו כמו `L *`: השלימו אותה. |
| "…" לא צפוי. האם חסר אופרטור? | שני ערכים זה לצד זה, כמו `2L`: כתבו `2 * L`. |
| ceil() מקבלת ערך אחד בלבד. | תנו לפונקציה את מספר הערכים הנכון. |
| round(x, digits) דורשת מספר שלם של ספרות מ-0 עד 10. | השתמשו במספר שלם של ספרות אחרי הנקודה. |
| הנוסחה מחלקת באפס. | בדרך כלל H הוא 0: קבעו גובה או עומק לפריט. |
| הנוסחה אינה נותנת מספר. | התוצאה גדולה מכדי להיות מספר. |
| הנוסחה ארוכה מדי (500 תווים לכל היותר). | קצרו אותה. |

## בטוחה בתכנון

נוסחה יכולה לבצע חישוב רק עם המשתנים והפונקציות שלמעלה. היא אינה יכולה להריץ קוד או לקרוא דבר אחר, ולכן נוסחה בקובץ פרויקט ששלח לכם מישהו אינה מזיקה.

## הערכה (גיליון XLSX ו-CSV)

שורה לכל פריט, ואחריה שורה לכל רכיב בהרכבה שלו (בהזחה). לאחר מכן שורה ריקה וסך הכול העבודה.

| עמודה | תוכן | ב-XLSX |
|---|---|---|
| A פריט | שם הפריט (מודגש) או שם הרכיב (בהזחה) | טקסט |
| B סוג | אורך, שטח, ספירה או רכיב | טקסט |
| C יחידה | LF, m, SF, SY, m², EA, או היחידה של הרכיב | טקסט |
| D כמות | הכמות הכוללת שנמדדה, או תוצאת הנוסחה | מספר |
| E פחת % | פחת | אחוז (0.10 = 10%) |
| F כמות עם פחת | כמות × (1 + פחת) | נוסחה `D*(1+E)` |
| G חומר ליחידה | תעריף החומר | מספר |
| H עבודה ליחידה | תעריף העבודה | מספר |
| I חומר | חומר מורחב | נוסחה `ROUND(F*G,2)` |
| J עבודה | עבודה מורחבת | נוסחה `ROUND(F*H,2)` |
| K סה"כ | חומר + עבודה | נוסחה `I+J` |
| L הערות | הנוסחה שבשימוש, שגיאת נוסחה, סימונים בגיליונות ללא קנה מידה, שטח קיר, היקף | טקסט |

שורת סך הכול העבודה: `SUM` של עמודות I, J ו-K על פני כל השורות שלמעלה, והכיתוב "לא שלם: ראו את ההערות למעלה" בעמודת ההערות כאשר משהו הושמט.

שורה עם שגיאת נוסחה אינה מכילה כמות או סכומים; ההערה שלה מציינת את השגיאה. שורת הכותרות מקובעת.

ב-CSV, אותן עמודות מכילות ערכים פשוטים. העמודה פחת % היא מספר אחוזים (10 עבור 10%), והכסף הוא בדולרים עם שתי ספרות אחרי הנקודה. טקסט שגיליון חישוב עלול לקרוא כנוסחה (מתחיל ב-`=`, `+`, `-` או `@`) מקבל `'` מוביל, כדי שיישאר טקסט.

## לפי גיליון (XLSX בלבד)

| עמודה | תוכן |
|---|---|
| גיליון | שם הגיליון (עם שם ה-PDF כאשר הוא אינו פתוח) |
| פריט | שם הפריט |
| כמות | הכמות של אותו פריט בגיליון זה, ביחידתו |
| יחידה | היחידה של הפריט |
| סימונים | מספר הסימונים |

## סימונים (XLSX בלבד)

שורה לכל סימון.

| עמודה | תוכן |
|---|---|
| גיליון | שם הגיליון |
| פריט | שם הפריט |
| סוג | אורך, שטח או ספירה |
| כמות | אורך, שטח נטו, או 1 |
| יחידה | LF או m; SF, SY או m²; EA |
| פירוט | באורך: אורכי הקטעים, הקטעים שנוכו מסומנים "(deduct)", ו-"deducts (length) of (length) drawn". בשטח: השטחים הגולמיים ושטחי החיתוך כאשר יש חיתוכים, וההיקף. "לגיליון אין קנה מידה" עבור סימונים ללא קנה מידה. |
| שטח הצעה | רק כאשר לכתב הכמויות יש שטחי הצעה: שטח הסימון, או "אין שטח הצעה" |

## לפי שטח הצעה (XLSX בלבד, כאשר לכתב הכמויות יש שטחי הצעה)

| עמודה | מה |
|---|---|
| שטח הצעה | שם השטח, או "אין שטח הצעה" |
| פריט | הפריט, או רכיב בהזחה מתחתיו |
| יחידה | היחידה של הפריט או הרכיב |
| כמות | נמדדה בשטח הזה (רכיבים: הנוסחה על סכומי השטח) |
| כמות עם פחת | כמות × (1 + פחת) |
| חומר, עבודה, סה"כ | מורחבים עד לסנט, כמו בגיליון הערכה |
| הערות | נוסחה, שגיאות וסימונים ללא קנה מידה, כמו בגיליון הערכה |

כל שטח מסתיים בשורה "סיכום ביניים של (שם)" שהעלויות בה הן נוסחאות `SUM` על שורותיו. השורה האחרונה, **כל שטחי ההצעה**, מסכמת את הסיכומים הביניים. גיליון **סימונים** מקבל אז עמודה שביעית, **שטח הצעה**.

## קנה מידה (XLSX בלבד)

שורה לכל גיליון שיש לו קנה מידה או סימונים.

| עמודה | תוכן |
|---|---|
| גיליון | שם הגיליון |
| קנה מידה | שם ההגדרה המוכנה, או קנה המידה שכויל, או "אין קנה מידה" |
| אופן | "הגדרה מוכנה", או "כויל לפי המרחק שהקלדתם" |
| רגל ליחידת PDF | מקדם קנה המידה המדויק ש-TakeoffCraft משתמש בו |

## שמות קבצים

- `(name).xlsx` ו-`(name).csv`, כאשר השם נלקח מקובץ ה-PDF הראשון שנפתח בכתב הכמויות.
- קובץ ה-CSV בקידוד UTF-8 עם סימן סדר בתים (BOM) וסיומות שורה של Windows, שתוכנות גיליון בכל הפלטפורמות קוראות.

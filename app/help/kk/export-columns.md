## Estimate (XLSX жұмыс парағы және CSV)

Әр нысанға бір жол, содан кейін оның жинағындағы әр компонентке бір жол (шегініспен). Одан кейін бос жол және жалпы сома.

| Баған | Мазмұны | XLSX-те |
|---|---|---|
| A Item | Нысан атауы (қалың) немесе компонент атауы (шегініспен) | Мәтін |
| B Type | Linear, Area, Count немесе Component (Сызықтық, Аудан, Санау немесе Компонент) | Мәтін |
| C Unit | LF, m, SF, SY, m², EA немесе компоненттің бірлігі | Мәтін |
| D Quantity | Өлшенген жалпы мән немесе формула нәтижесі | Сан |
| E Waste % | Қалдық | Пайыз (0.10 = 10%) |
| F Qty with waste | Саны × (1 + қалдық) | Формула `D*(1+E)` |
| G Material per unit | Материалдың бірлік бағасы | Сан |
| H Labor per unit | Жұмыстың бірлік бағасы | Сан |
| I Material | Есептелген материал | Формула `ROUND(F*G,2)` |
| J Labor | Есептелген жұмыс | Формула `ROUND(F*H,2)` |
| K Total | Материал + жұмыс | Формула `I+J` |
| L Notes | Қолданылған формула, формула қатесі, масштабсыз парақтардағы белгілер, қабырға ауданы, периметр | Мәтін |

Жалпы сома жолы: жоғарыдағы барлық жолдардағы I, J және K бағандарының `SUM` мәні. Бір нәрсе өткізіліп жіберілсе, Notes бағанында "Incomplete: see the notes above" жазылады.

Формула қатесі бар жолда саны немесе сомасы болмайды; оның ескертпесі қатені көрсетеді. Тақырып жолы бекітілген.

CSV-да дәл осы бағандар жай мәндерді қамтиды: Waste % — пайыз саны (10 — 10%), ал ақша доллармен, екі ондық таңбамен. Электрондық кесте формула деп қабылдауы мүмкін мәтін (`=`, `+`, `-` немесе `@` басталатын) алдына `'` қойылады, сондықтан ол мәтін болып қалады.

## Парақ бойынша (тек XLSX)

| Баған | Мазмұны |
|---|---|
| Sheet | Парақ атауы (ашық емес болса, PDF атауымен) |
| Item | Нысан атауы |
| Quantity | Сол парақтағы нысанның саны, оның бірлігімен |
| Unit | Нысанның бірлігі |
| Marks | Белгілер саны |

## Белгілер (тек XLSX)

Әр белгіге бір жол.

| Баған | Мазмұны |
|---|---|
| Sheet | Парақ атауы |
| Item | Нысан атауы |
| Type | Linear, Area немесе Count (Сызықтық, Аудан немесе Санау) |
| Quantity | Ұзындық, таза аудан немесе 1 |
| Unit | LF немесе m; SF, SY немесе m²; EA |
| Detail | Сызықтық: кесінді ұзындықтары, алынған кесінділер "(deduct)" деп белгіленеді, және "deducts (length) of (length) drawn". Аудан: ойықтар болса, жалпы және ойылған аудандар, және периметр. Масштабсыз белгілер үшін "Sheet has no scale". |
| Bid area | Тек көлемдеуде тендерлік аудандар болғанда: белгінің ауданы немесе "No bid area" |

## Тендерлік аудан бойынша (тек XLSX, көлемдеуде тендерлік аудандар болғанда)

| Баған | Мазмұны |
|---|---|
| Bid area | Ауданның атауы немесе "No bid area" |
| Item | Нысан, немесе оның астындағы шегінген компонент |
| Unit | Нысанның немесе компоненттің бірлігі |
| Quantity | Сол аудандағы өлшем (компоненттер үшін: аудан жиындары бойынша формула) |
| Qty with waste | Саны × (1 + қалдық) |
| Material, Labor, Total | Estimate парағындағыдай центке дейін есептелген |
| Notes | Estimate парағындағыдай формула, қателер және масштабсыз белгілер |

Әр аудан "(name) subtotal" жолымен аяқталады, оның шығындары сол жолдар бойынша `SUM` формулалары болып табылады. Соңғы жол, **All bid areas**, аудандардың жиынтықтарын қосады. **Marks** жұмыс парағында енді жетінші баған бар: **Bid area**.

## Масштабтар (тек XLSX)

Масштабы немесе белгілері бар әр параққа бір жол.

| Баған | Мазмұны |
|---|---|
| Sheet | Парақ атауы |
| Scale | Пресеттің атауы, калибрленген масштаб немесе "No scale" |
| How | "Preset", немесе "Calibrated on (the distance you typed)" |
| Feet per PDF unit | TakeoffCraft қолданатын дәл масштаб коэффициенті |

## Файл атаулары

- `(name).xlsx` және `(name).csv`, мұндағы атау көлемдеуде ашылған бірінші PDF-тен алынады.
- CSV — UTF-8, байт белгісі (BOM) және Windows жол соңдары бар; оны барлық платформадағы электрондық кесте бағдарламалары оқиды.

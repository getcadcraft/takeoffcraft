Жинақтың компоненттері санын формуладан алады. Формула — өлшенген мәндер бойынша қарапайым арифметикалық өрнек. Жұмыс мысалдары үшін [Жинақтар және формулалар](topic:assemblies) бөлімін қараңыз.

## Айнымалылар

| Нысан түрі | Айнымалы | Мағынасы |
|---|---|---|
| Сызықтық | `L` | Жалпы ұзындық |
| Сызықтық | `H` | Нысанның биіктігі |
| Сызықтық | `A` | Қабырға ауданы, L × H, оны тасымалдайтын жолдардың тесіктерін алып тастағанда (BimCraft-тан көлемдеу). Көлемдеу өлшеу әдісін атаған кезде `A` сол әдіспен өлшенеді: әдістің ең кіші өлшемінен үлкен емес тесіктер қалады, ал қабырғалар түйіскен жерде әдіс алып тастайтын бөлік шығарылады. Нысанның астындағы ескерту әдістің атауын көрсетеді |
| Сызықтық | `N` | Жолдар саны |
| Аудан | `A` | Жалпы таза аудан (контурлар минус ойықтар) |
| Аудан | `P` | Жалпы периметр, ойық жиектерін қоса |
| Аудан | `H` | Нысанның тереңдігі немесе қалыңдығы |
| Аудан | `N` | Аудандар саны |
| Санау | `N` | Саны |

- Айнымалылар нысанның бірліктерінде: қараңыз [Бірліктер](topic:units).
- Бас және кіші әріптер бірдей: `l` — `L`.
- Тек нысанның өз түріне сәйкес айнымалылар жұмыс істейді. Сызықтық нысандағы `P` мынаны береді: «P» мұнда өлшенген мән емес. L, H, A, N пайдаланыңыз.
- Биіктігі немесе тереңдігі бос нысанның мәні 0 болады.

## Амалдар

| Жазу | Мағынасы |
|---|---|
| `+` | Қосу |
| `-` немесе `−` | Азайту, немесе теріс мән |
| `*` немесе `×` | Көбейту |
| `/` немесе `÷` | Бөлу |
| `( )` | Топтау |

Көбейту мен бөлу қосу мен азайтудан бұрын орындалады: `L * 2 + 4` — (L × 2) + 4. Күмәндансаңыз, жақша пайдаланыңыз.

Сандарда ондық бөлшектер (`1.333`, `.5`) және дәрежелер (`1e3` = 1000) болуы мүмкін. Бос орындар елемейді.

## Функциялар

| Функция | Нәтиже | Мысал |
|---|---|---|
| `ceil(x)` | Бүтін санға дейін жоғары дөңгелектеу | `ceil(67.5)` = 68 |
| `floor(x)` | Бүтін санға дейін төмен дөңгелектеу | `floor(67.5)` = 67 |
| `round(x)` | Ең жақын бүтін санға дейін дөңгелектеу, жартылары нөлден алыс | `round(2.5)` = 3 |
| `round(x, d)` | d ондық таңбаға дейін дөңгелектеу (0-ден 10-ға дейін) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Ең кіші мән | `min(N, 10)` |
| `max(a, b, …)` | Ең үлкен мән | `max(1, ceil(N / 12))` |
| `abs(x)` | Таңбасыз мән | `abs(-3)` = 3 |

`ceil` мен `floor` компьютердің ұсақ дөңгелектеу шуын елемейді, сондықтан дәл 1 болатын мән ешқашан 2-ге дейін дөңгелектенбейді.

## Қателер

Оқуға немесе есептеуге болмайтын формула өзінің қатесін өрістің астында көрсетеді, ал компонент жалпы сандардан шығарылады ({{ui:Саны}} тақырыбы "Incomplete" деп жазады). Хабарламалар:

| Хабарлама | Түзету |
|---|---|
| Формуланы теріңіз, мысалы L немесе ceil(L / 1.333) + 1. | Формула бос. |
| «X» мұнда өлшенген мән емес. Қолданыңыз … | Тізімдегі айнымалылардың бірін пайдаланыңыз. |
| «X» мұнда функция емес. Қолданыңыз: ceil, floor, round, min, max, abs. | Осы функциялардың бірін пайдаланыңыз. |
| «#» формулада рұқсат етілмейді. | Сол таңбаны алып тастаңыз (бірліктер, `%`, `$` және `=` рұқсат етілмейді). |
| «)» жетіспейді. / «)» таңбасына сәйкес «(» жоқ. | Жақшаларды теңестіріңіз. |
| «)» алдында мән жетіспейді. | Мысалы `max(1, )`: мәнді толтырыңыз. |
| Формула тым ерте аяқталды. | Мысалы `L *`: аяқтаңыз. |
| Күтпеген «…». Амал жетіспей ме? | Қатар тұрған екі мән, мысалы `2L`: `2 * L` деп жазыңыз. |
| ceil() 1 мән қабылдайды. | Функцияға мәндердің дұрыс санын беріңіз. |
| round(x, digits) 0-ден 10-ға дейінгі бүтін цифрларды қажет етеді. | Ондық таңбалардың бүтін санын пайдаланыңыз. |
| Формула нөлге бөледі. | Әдетте H 0: нысанның биіктігін немесе тереңдігін беріңіз. |
| Формула сан бермейді. | Нәтиже сан болуға тым үлкен. |
| Бұл формула тым ұзын (ең көбі 500 таңба). | Қысқартыңыз. |

## Дизайны бойынша қауіпсіз

Формула тек жоғарыдағы айнымалылар мен функциялармен арифметика орындай алады. Ол код іске қоса алмайды және басқа ешнәрсені оқи алмайды, сондықтан біреу жіберген жоба файлындағы формула зиянсыз.

## Смета (рабочий лист XLSX и CSV)

Одна строка на позицию, за ней строка на каждый компонент ее комплекта (с отступом). Затем пустая строка и общий итог.

| Столбец | Содержимое | В XLSX |
|---|---|---|
| A Позиция | Название позиции (жирным) или компонента (с отступом) | Текст |
| B Тип | Linear, Area, Count или Component | Текст |
| C Ед. изм. | LF, m, SF, SY, m², EA или единица компонента | Текст |
| D Количество | Измеренный итог или результат формулы | Число |
| E Отходы % | Отходы | Процент (0.10 = 10%) |
| F Количество с отходами | Количество × (1 + отходы) | Формула `D*(1+E)` |
| G Материалы за единицу | Расценка на материалы | Число |
| H Труд за единицу | Расценка на труд | Число |
| I Материалы | Сумма по материалам | Формула `ROUND(F*G,2)` |
| J Труд | Сумма по труду | Формула `ROUND(F*H,2)` |
| K Итого | Материалы + труд | Формула `I+J` |
| L Примечания | Использованная формула, ошибка формулы, пометки на листах без масштаба, площадь стен, периметр | Текст |

Строка общего итога: `SUM` по столбцам I, J и K для всех строк выше; в примечаниях пишется «Неполно: см. примечания выше», если что-то не учтено.

У строки с ошибкой формулы нет количества и сумм; в примечании указана сама ошибка. Строка заголовка закреплена.

В CSV те же столбцы содержат простые значения: Waste % — число процентов (10 для 10%), а суммы — в долларах с двумя знаками после запятой. Текст, который таблица может принять за формулу (начинается с `=`, `+`, `-` или `@`), получает ведущий `'`, чтобы остаться текстом.

## По листам (только XLSX)

| Столбец | Содержимое |
|---|---|
| Лист | Название листа (с именем PDF, если он не открыт) |
| Позиция | Название позиции |
| Количество | Количество этой позиции на этом листе в ее единице |
| Ед. изм. | Единица позиции |
| Пометки | Число пометок |

## Пометки (только XLSX)

Одна строка на пометку.

| Столбец | Содержимое |
|---|---|
| Лист | Название листа |
| Позиция | Название позиции |
| Тип | Linear, Area или Count |
| Количество | Длина, чистая площадь или 1 |
| Ед. изм. | LF или m; SF, SY или m²; EA |
| Подробности | Linear: длины участков, вычитаемые отмечены «(вычет)», и «вычеты (длина) из (длина) нарисовано». Area: общая и вырезанные площади, если есть вырезы, и периметр. «Лист без масштаба» — для пометок без масштаба. |
| Зона предложения | Только если в подсчете есть зоны предложения: площадь пометки или «Без зоны предложения» |

## По зонам предложения (только XLSX, если в подсчете есть зоны предложения)

| Столбец | Что здесь |
|---|---|
| Зона предложения | Название зоны или «Без зоны предложения» |
| Позиция | Позиция или компонент с отступом под ней |
| Ед. изм. | Единица позиции или компонента |
| Количество | Измерено в этой зоне (компоненты: формула по итогам зоны) |
| Количество с отходами | Количество × (1 + отходы) |
| Материалы, Труд, Итого | Суммы до цента, как на листе сметы |
| Примечания | Формула, ошибки и пометки без масштаба, как на листе сметы |

Каждая зона заканчивается строкой «(название) подытог», где затраты — формулы `SUM` по ее строкам; последняя строка, **All bid areas**, складывает подытоги. Рабочий лист **Пометки** тогда получает седьмой столбец — **Зона предложения**.

## Масштабы (только XLSX)

Одна строка на каждый лист, у которого есть масштаб или пометки.

| Столбец | Содержимое |
|---|---|
| Лист | Название листа |
| Масштаб | Название шаблона, откалиброванный масштаб или «Нет масштаба» |
| Как задан | «Шаблон» или «Откалибровано по (расстояние, которое вы ввели)» |
| Футов на единицу PDF | Точный коэффициент масштаба, который использует TakeoffCraft |

## Имена файлов

- `(название).xlsx` и `(название).csv`, где название берется из первого PDF, открытого в подсчете.
- CSV в кодировке UTF-8 с меткой порядка байтов и окончаниями строк Windows, которые читают таблицы на любой платформе.

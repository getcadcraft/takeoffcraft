Состав позиции — это список компонентов, у каждого из которых есть формула количества, собственные отходы и расценки. Формула использует измеренные итоги позиции, поэтому один подсчёт стены даёт вам стойки, обвязки и листы сразу, и они обновляются по мере измерения.

## Переменные, которые можно использовать

| Тип позиции | Переменные |
|---|---|
| Линейная | `L` длина, `H` высота, `A` площадь стены (L × H), `N` количество участков |
| Площадь | `A` площадь, `P` периметр (контур + вырезы), `H` глубина или толщина, `N` количество площадей |
| Подсчёт | `N` количество |

Значения даны в единицах самой позиции: футы и квадратные футы для позиций в LF и SF, метры и квадратные метры для позиций в m и m². Для позиции в SY `A` дано в квадратных ярдах, а `P` и `H` остаются в футах.

В формулах используются `+ - * /` (или × ÷), скобки, числа и функции `ceil`, `floor`, `round`, `min`, `max` и `abs`. Полные правила — в разделе [Язык формул](topic:formulas).

## Пример: внутренняя стена

Допустим, вы подсчитали **Внутренняя стена, тип A** как линейную позицию: 4 участка общей длиной 120 LF, с {{ui:Высота}}, равной `9'-0"`. Её **измеренные** значения: L = 120, N = 4, A = 1,080 (SF стены, одна сторона).

1. Выберите позицию в {{ui:Позиции}}.
2. В {{ui:Состав}} выберите {{ui:Добавить компонент}}.
   Появится компонент с именем «Компонент», с формулой `L` и её результатом ниже.
3. Введите `Studs 16 in o.c.` в {{ui:Название}} и `EA` в {{ui:Ед. изм.}}.
4. В {{ui:Формула количества}} введите `ceil(L * 12 / 16) + N`.
   Результат обновляется по мере ввода: «= 94 EA». Это одна стойка каждые 16 дюймов вдоль 120 футов (90) плюс одна дополнительная, чтобы закрыть каждый из 4 участков.
5. Снова выберите {{ui:Добавить компонент}} для обвязок: название `Plates, top and bottom`, ед. изм. `LF`, формула `L * 2`. Результат: 240 LF.
6. Добавьте листы гипсокартона: название `Gypsum board 4x8, both sides`, ед. изм. `sheets`, формула `ceil(A * 2 / 32)`. Результат: 68 листов (2,160 SF гипсокартона ÷ 32 SF на лист = 67.5, округлено вверх).
7. Заполните для каждого компонента {{ui:Отходы, %}}, {{ui:Материалы, $}} и {{ui:Трудозатраты, $}}.
   Каждый компонент получает свою строку под позицией в {{ui:Количества}}, оценивается как позиция, и {{ui:Итого по работе}} его включает.

Если стоимость стены полностью в компонентах, оставьте собственные расценки материалов и трудозатрат позиции равными 0, иначе они будут учтены дважды.

:::tip
Отходы применяются после формулы и не округляются: 68 листов с 10% отходов — это 74.8 листа. Чтобы заказывать целые листы, включите отходы в формулу, например `ceil(A * 2 / 32 * 1.1)`, и оставьте отходы компонента равными 0.
:::

## Другие формулы

| Что | Позиция | Формула |
|---|---|---|
| Стойки с шагом 24 in o.c. | Линейная | `ceil(L / 2) + N` |
| Утеплитель, маты, SF | Линейная с высотой | `A` |
| Краска, с двух сторон, галлоны на 350 SF | Линейная с высотой | `ceil(A * 2 / 350)` |
| Плитка, упаковки по 15 SF, с запасом 10% | Площадь | `ceil(A * 1.1 / 15)` |
| Плинтус или кромка, LF | Площадь | `P` |
| Бетон, кубические ярды | Площадь с глубиной | `A * H / 27` |
| Бетон, округлённый вверх до четверти ярда | Площадь с глубиной | `ceil(A * H / 27 * 4) / 4` |
| Петли, по три на дверь | Подсчёт | `N * 3` |
| Минимум одна коробка, по одной на 12 | Подсчёт | `max(1, ceil(N / 12))` |

## Когда формула неверна

Строка под формулой превращается в сообщение об ошибке, например `"X" is not a measured value here. Use L, H, A, N.` или `A ")" is missing.` Компонент тогда не имеет сумм, его строка в {{ui:Количества}} показывает «Ошибка формулы: …», а в заголовке написано «Неполно: 1 ошибка формулы (не учтена в итогах)». Исправьте формулу, и итоги обновятся.

Формула, которая делит на ноль, тоже даёт ошибку («Формула делит на ноль.»), например `A / H` у позиции без глубины.

## Ограничения

- Формулы считаются по **итогам** позиции, а не по участкам. `ceil(L * 12 / 16) + N` добавляет одну стойку на участок; округления по участкам пока нет.
- Формула может использовать только переменные своей позиции, но не чужих позиций.
- До 50 компонентов на позицию, 500 символов в формуле.

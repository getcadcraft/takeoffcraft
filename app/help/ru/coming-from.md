Если вы считали объемы в PlanSwift или с инструментами измерения в Bluebeam Revu, большая часть TakeoffCraft будет знакомой: набор чертежей, масштаб на каждом листе, измеряемые объекты и итоговая сумма со стоимостью. Связь между частями устроена в чем-то иначе, и эти места описаны ниже.

Если вы знакомы с PlanSwift или On-Screen Takeoff, выберите стиль меню {{ui:Takeoff desk}} в {{ui:Settings}} › {{ui:TakeoffCraft}} › {{ui:Menus, keys and mouse}}: строка меню с пунктами Файл, {{ui:Edit}}, Вид, {{ui:Scale}}, Подсчет, {{ui:Items}}, {{ui:Markup}} и {{ui:Export}} над рядом инструментов подсчета, а шаблоны масштаба находятся на панели листа. См. [Меню, клавиши и мышь](topic:menus-keys-and-mouse).

## Привычки и их аналоги

| Вы привыкли к | В TakeoffCraft |
|---|---|
| Открытие задания или проекта, в котором хранятся чертежи (PlanSwift) | Откройте PDF и файл проекта `.takeoff.json` рядом. Проект хранит только подсчет; PDF остаются вашими файлами. |
| Список пометок с заметками, облаками и выделениями (Bluebeam) | {{ui:Markup}} на панели листа: заметки, облака и выделения со статусом (открыто, отвечено, закрыто), перечисленные в разделе **Разметка**, нарисованы в {{ui:Marked PDF}}. См. [Заметки, облака и выделения](topic:markups). |
| Измерения, сохраненные как пометки внутри PDF (Bluebeam) | Подсчет хранится в файле `.takeoff.json`. {{ui:Marked PDF}} записывает копию с нарисованным подсчетом для отправки; {{ui:PDF with the takeoff inside}} записывает копию с подсчетом внутри, которую можно снова открыть в TakeoffCraft. |
| Позиции подсчета (PlanSwift), пользовательские инструменты измерения, сохраненные в Tool Chest (Bluebeam) | **Позиции** под {{ui:Items}}: название, тип, цвет, единица измерения, высота или глубина, отходы, расценки. |
| Детали и сборки с формулами (PlanSwift) | {{ui:Assembly}} позиции: составляющие с формулой, которая использует `L H A N P`. |
| Задание масштаба страницы или калибровка (оба) | Список {{ui:Preset}} или {{ui:Calibrate}} в группе {{ui:Scale}}, для каждого листа. {{ui:Check}} измеряет известный размер. |
| Применение одного масштаба к диапазону страниц | Пока нет: задавайте каждый лист. |
| Видовые экраны с разными масштабами на одном листе (Bluebeam) | Пока нет: один масштаб на лист. |
| Инструменты длины полилинии и площади (Bluebeam), линейный и площадной подсчет (PlanSwift) | {{ui:Linear}} ({{key:L}}) и {{ui:Area}} ({{key:A}}). |
| Удержание {{key:Shift}} для прямых линий | {{key:Shift}} привязывает к шагам 45°, та же идея. |
| Привязка к линиям чертежа | Включена по умолчанию: концы, середины, пересечения и ближайшая точка на линии. {{key:F3}} отключает ее, как в CAD-программах. |
| Инструмент подсчета (оба) | {{ui:Count}} ({{key:C}}). |
| Визуальный поиск символов (Bluebeam) | {{ui:Auto count}} ({{key:S}}): обведите один символ, проверьте найденное, добавьте. |
| Вырезы или вычеты в площадях | {{ui:Cut-out}} ({{key:X}}) на выбранной площади и круглые вырезы. |
| Вычеты на линейных участках | Проведите участок насквозь и нажмите {{key:E}} ({{ui:Deduct}}) для проема. См. [Измерение линейных участков](topic:measure-linear). |
| Дуговые участки в полилинии | {{ui:Arc}} ({{key:R}}): укажите точку на кривой, затем ее конец. |
| Список пометок с колонками количества (Bluebeam) | Таблица {{ui:Quantities}}, {{ui:By item}} или {{ui:By sheet}}. |
| Смета с расценками (PlanSwift) | Та же таблица: отходы, материалы и трудозатраты за единицу, итоговые суммы и {{ui:Job total}}. |
| Экспорт в Excel | {{ui:XLSX}} с живыми формулами или {{ui:CSV}}. |
| Escape для остановки инструмента | {{key:Esc}} отменяет и возвращает {{ui:Select}}. |
| Щелчок правой кнопкой для завершения | Правый щелчок здесь тоже завершает участок или замыкает площадь. Контекстного меню нет. |

## Различия, которые сбивают с толку

**Подсчет не находится внутри вашего PDF.** Ничто из сделанного не меняет ваши PDF. Сохраните файл `.takeoff.json` и храните его вместе с чертежами. Если отправить кому-то PDF с пометками, он не получит редактируемый подсчет: отправьте файл проекта и исходные PDF или [PDF с подсчетом внутри](topic:save-and-reopen#keep-the-takeoff-inside-the-pdf).

**PDF сопоставляются по содержимому, а не по имени.** Переработанный лист, сохраненный поверх старого имени файла, для TakeoffCraft является новым файлом, без масштаба и без пометок. Старые пометки остаются на старой версии и продолжают учитываться. См. [Сохранение и открытие подсчета](topic:save-and-reopen#when-a-pdf-has-changed).

**Пометки без масштаба не учитываются, а не считаются нулем.** Если у листа нет масштаба, его участки и площади не учитываются, а в таблице стоит «Неполно». Во многих программах вы бы просто увидели 0. См. [Задание масштаба](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero).

**Угадывания размера страницы нет.** Шаблоны считают, что PDF напечатан в полный размер. PDF в половину размера или «по размеру страницы» требуют {{ui:Calibrate}}. Всегда используйте {{ui:Check}}.

**Одна позиция, один основной тип, и больше, если вы попросите.** Позиция бывает линейной, площадной или счетной, и ее тип фиксируется, когда у нее появились пометки. Условие, которое дает и площадь, и ее периметр, — это площадная позиция: ее периметр — переменная `P`. Стена с длиной и площадью — линейная позиция с высотой. Для позиции с несколькими условиями, например комнаты с полом, плинтусом и дверями, отметьте остальные виды под **Также измерять**: каждый учитывается в своей строке. См. [Одна позиция, несколько видов пометок](topic:create-items#one-item-several-kinds-of-marks).

**Формулы считаются по итогам.** Формулы сборки используют итоги позиции по всем листам, а не каждый участок отдельно. `N` (число участков или площадей) нужно для дополнительных элементов на каждый участок, например одна дополнительная стойка на стену.

**Периметр включает вырезы.** `P` площади добавляет края ее отверстий. См. [Измерение площадей с вырезами](topic:measure-areas#read-the-area).

**Перетаскивание сдвигает.** Перетаскивание левой кнопкой по листу сдвигает его во всех инструментах, кроме {{ui:Auto count}}. Переключаться на инструмент панорамы никогда не нужно. Колесо масштабирует; оно не прокручивает.

**Копия для восстановления, а не облако.** TakeoffCraft хранит копию вашей работы в этом браузере и предлагает ее вернуть после сбоя ([Если вкладка или браузер зависли](topic:save-and-reopen#if-the-tab-or-the-browser-stops)), но подсчет сохраняете вы: {{key:Mod+S}}. Сохранение в облаке пока недоступно.

**Все работает в браузере.** Ничего устанавливать не нужно, и планы никогда не загружаются. Для настольного приложения TakeoffCraft входит в CadCraft Studio вместе с остальными семью приложениями.

Компоненты комплектов получают количество из формулы. Формула — это небольшое арифметическое выражение над измеренными значениями позиции. См. [Комплекты и формулы](topic:assemblies) с разобранными примерами.

## Переменные

| Тип позиции | Переменная | Значение |
|---|---|---|
| Линейная | `L` | Общая длина |
| Линейная | `H` | Высота позиции |
| Линейная | `A` | Площадь стены, L × H, за вычетом проемов участков, где они есть (подсчет из BimCraft). Если в этом подсчете указан метод измерения, `A` измеряется по нему: проемы не больше наименьшего размера метода остаются, а то, что метод отбрасывает в местах примыкания стен, не учитывается. Примечание под позицией называет метод |
| Линейная | `N` | Число участков |
| Площадь | `A` | Общая чистая площадь (контуры минус вырезы) |
| Площадь | `P` | Общий периметр, включая кромки вырезов |
| Площадь | `H` | Глубина или толщина позиции |
| Площадь | `N` | Число площадей |
| Подсчет | `N` | Количество |

- Переменные — в единицах позиции: см. [Единицы](topic:units).
- Заглавные и строчные буквы одинаковы: `l` — это `L`.
- Работают только переменные собственного типа позиции. `P` у линейной позиции даст `"P" здесь не измеряемая величина. Используйте L, H, A, N.`
- Пустые высота или глубина считаются нулем.

## Операторы

| Пишется | Значение |
|---|---|
| `+` | Сложение |
| `-` или `−` | Вычитание или отрицательное значение |
| `*` или `×` | Умножение |
| `/` или `÷` | Деление |
| `( )` | Группировка |

Умножение и деление выполняются раньше сложения и вычитания: `L * 2 + 4` — это (L × 2) + 4. Если сомневаетесь, ставьте скобки.

Числа могут иметь десятичные знаки (`1.333`, `.5`) и степени (`1e3` = 1000). Пробелы игнорируются.

## Функции

| Функция | Результат | Пример |
|---|---|---|
| `ceil(x)` | Округление вверх до целого | `ceil(67.5)` = 68 |
| `floor(x)` | Округление вниз до целого | `floor(67.5)` = 67 |
| `round(x)` | Округление до ближайшего целого, половины от нуля | `round(2.5)` = 3 |
| `round(x, d)` | Округление до d знаков после запятой (от 0 до 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Наименьшее значение | `min(N, 10)` |
| `max(a, b, …)` | Наибольшее значение | `max(1, ceil(N / 12))` |
| `abs(x)` | Значение без знака | `abs(-3)` = 3 |

`ceil` и `floor` игнорируют мельчайший машинный шум округления, поэтому значение, которое должно быть ровно 1, никогда не округляется вверх до 2.

## Ошибки

Формула, которую нельзя прочитать или вычислить, показывает свою ошибку под полем, а компонент не входит в итоги (в заголовке {{ui:Количества}} написано «Неполно»). Сообщения:

| Сообщение | Как исправить |
|---|---|
| «Введите формулу, например L или ceil(L / 1.333) + 1.» | Формула пуста. |
| `"X" здесь не измеряемая величина. Используйте …` | Используйте одну из перечисленных переменных. |
| `"X" здесь не функция. Используйте ceil, floor, round, min, max, abs.` | Используйте одну из этих функций. |
| `Символ "#" не допускается в формуле.` | Уберите этот символ (единицы, `%`, `$` и `=` не допускаются). |
| Не хватает ")". / Есть ")" без парного "(". | Уравняйте скобки. |
| Перед ")" не хватает значения. | Например, `max(1, )`: введите значение. |
| Формула обрывается слишком рано. | Например, `L *`: допишите ее. |
| Неожиданное «…». Не хватает оператора? | Два значения рядом, например `2L`: напишите `2 * L`. |
| ceil() принимает 1 значение. | Передайте функции нужное число значений. |
| round(x, digits) требует целое число знаков от 0 до 10. | Используйте целое число знаков после запятой. |
| Формула делит на ноль. | Обычно H равно 0: задайте высоту или глубину позиции. |
| Формула не дает число. | Результат слишком велик для числа. |
| Эта формула слишком длинная (не более 500 знаков). | Сократите ее. |

## Безопасно по замыслу

Формула может только выполнять арифметику с перечисленными выше переменными и функциями. Она не может запускать код или читать что-либо еще, поэтому формула в файле проекта, который вам прислали, безопасна.

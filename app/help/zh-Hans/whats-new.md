本次更新是 TakeoffCraft 0.9 相对 0.8.1 的变化。这是该应用的一个小版本：长度现在可以用米、厘米或毫米读取，面积和比例能正确适应公制工作，圆弧有十种画法。实时协作会话中也会显示每个人所在的位置。

## 新增

### 以米、厘米或毫米读取长度

- **长度显示方式。** {{ui:Settings}} › {{ui:TakeoffCraft}} 中有 {{ui:Show lengths as}}，可选 {{ui:Follow Global}}、{{ui:Feet-inches}}、m、cm 和 mm。{{ui:Follow Global}} 使用你在 {{ui:Settings}} › {{ui:Global}} › {{ui:Units}} 中标星的公制长度单位；若未标星任何公制单位，则使用英尺-英寸。它会改变长度在图纸、状态栏和面板中的显示方式，包括高度、深度、厚度和楼层。在高度字段中只输入数字时，按当前显示的单位读取。
- **仅影响显示。** 数量、费用和导出均根据精确长度计算。1/16、1/8 和 1/4 英寸的选项仅在英尺-英寸下出现。参见 [以米显示长度](topic:show-lengths-in-meters)。
- **重量单位。** {{ui:Typed quantity (no drawing)}} 项目现在可以使用 lb、TON、kg 或 t，并可按单位定价。
- **温度。** 每个项目的项目编辑器中都有可选的 {{ui:Temperature}} 字段，可以 °C 或 °F 输入。{{ui:Settings}} › {{ui:TakeoffCraft}} 中的 {{ui:Show temperatures as}} 提供 {{ui:Follow Global}}、°C 或 °F。

### 公制工作的面积和比例

- **图纸上以 m2 显示面积。** 使用公制项目测量的面积，现在在图纸标签、标记面板和表格中都显示 m2，而不再显示 SF。规则是：当项目按公制定价，或长度以 m、cm 或 mm 显示时使用 m2；否则使用 SF。
- **墙面积。** 带高度的线性项目，现在会在项目列表中显示其墙面积（长度乘以高度），并在按项目的数量表下方以注释行显示。
- **比例预设 1:75 和 1:150。** 它们位于 {{ui:Scale}} 组的 {{ui:Preset}} 列表中，该组现在共有 32 种比例。参见 [比例预设](topic:scale-presets)。

### 十种方法画圆弧

- 在 {{ui:Arc}} 开启时（工具栏按钮或 {{key:R}}），图纸栏中会出现 {{ui:Arc method}} 框，可选：3-Point, Start, Center, End, Start, Center, Angle, Start, Center, Length, Start, End, Angle, Start, End, Direction, Start, End, Radius, Center, Start, End, Center, Start, Angle 和 Center, Start, Length。角度、长度、半径和方向可以点击或输入。它可用于线段、面积和洞口。0.9 之前保存的文件打开后效果相同。参见 [用十种方法画圆弧](topic:draw-arcs-ten-methods)。

### 协同工作

- **查看彼此的指针。** 在实时协作会话中，每个人的指针会连同其姓名和颜色显示在图纸上，所选标记周围有虚线框。位于其他图纸上的人会列出该图纸的名称。参见 [与他人实时协作](topic:work-live)。
- **跟随他人与人员列表。** 实时协作会话中的 {{ui:People}} 按钮会列出每个人，显示其正在使用的工具、所在图纸以及最后一次编辑的时间。{{ui:Follow}} 会让你的视图与对方同步；主持人可以使用 {{ui:Ask everyone to follow me}}。参见 [在实时协作会话中跟随队友](topic:follow-a-teammate)。

## 所有应用通用

- **工具提示和入门提示。** 悬停文字为 Bootstrap 工具提示，入门提示可以关闭。
- **可滚动的选项卡栏。** 面板的选项卡栏放不下时会滚动，而不是被截断。
- **选项卡标题。** 浏览器标签页显示 `<document> - TakeoffCraft | CadCraft`。
- **布局。** {{ui:Settings}} 中的布局列表是下拉列表，会显示所选布局。
- **语言。** 你选择的语言现在也用于页面自身显示的文字，例如新建、打开和保存。除英语外的其他语言在母语人士审阅前均为机器草稿。

## 已知局限

- 长度显示、重量和温度单位以及新预设已通过测试并在页面中检查。并未逐一手动检查每个面板在每种单位下的显示。
- 人员列表尚未与真实的教师和学生班级进行人工检查。
- 除英语外的其他语言均为机器草稿。
- Windows 安装程序未经代码签名（点击“更多信息”，然后点击“仍要运行”）。macOS 磁盘映像未经公证（右键单击，然后选择“打开”）。

## 更早版本：0.8和0.8.1

本次更新是 TakeoffCraft 0.8（2026-11-01 发布）和 0.8.1（2026-11-02）相对 0.7 的变化。现在可以在整套图纸中一次性对图例符号进行计数，新的算量可以从过往项目的价格开始，并且可以用供应商的库存核对算量。0.8.1 是一个修复版本。

### 新增

**在整套图纸中计数**

- **框选图例一次。** 工具栏中的 {{ui:Count everything}} 会读取符号图例：拖动框选符号以及旁边印刷的名称。每个符号会连同其图片和名称列出，名称会成为项目名称。取消勾选不需要的项目，然后选择 {{ui:在 N 张图纸上计数}}。进度条会显示正在搜索的图纸，{{ui:Cancel}} 可停止运行，页面在运行期间仍可使用。
- **所有图纸一次运行。** 每个符号都会在每张已打开的图纸上计数。以其他比例绘制的图纸会按该比例搜索，符号可在任何直角方向上找到。图例自身的符号不会在其所在图纸上计数。
- **添加前先审阅。** 每个总数都有一个按图纸的链接（"E-103: 4"），可跳转到该图纸。点击某个找到项上的框可将其排除，再次点击可恢复。匹配度（50%至100%）只筛选已找到的结果，不会重新搜索。
- **一次撤销。** {{ui:添加 N 个标记}} 会为每个符号创建一个计数项目，并在每个找到处放置一个标记。如果某个名称已是你的计数项目，则会复用。{{key:Ctrl+Z}} 会撤回所有项目和标记。你接受的结果也会加入 {{ui:Learned}}。
- **任意角度的符号。** 在计数前勾选 {{ui:Symbols at any angle}}，还可找到以非直角旋转的符号。搜索会每15度旋转一次每个符号，且非圆形符号可能需要多达6倍的时间。
- **功能说明。** 仅在你自己的图纸上进行普通的符号匹配，不使用经过训练的模型，任何内容都不会离开你的计算机。在一个虚构的200张图纸的图纸集上，于一台快速的台式机上使用 Chrome 从头到尾用时9.4秒；真实的图纸集会更慢。参见 [计数整套图纸中的所有内容](topic:count-everything)。

**记住你自己项目中的价格**

- **TakeoffCraft 会记住你的单价。** 保存算量时，每个使用过且已定价的项目都会按名称和类型记住：材料单价、人工单价、损耗和单位。每个名称保留最近12个项目。该数据保存在本计算机上，与价格库放在一起，绝不会保存在算量文件中，也不会发送到任何地方。
- **从它开始新算量。** 工具栏上的 {{ui:Prices}} 会为每个项目显示上次项目的单价、典型单价和价格范围。{{ui:Use last}} 或 {{ui:Use typical}} 为一个项目定价，{{ui:用记忆中的价格为 N 个未定价项目定价}} 会为所有尚无价格的项目定价。每次使用都是一个撤销步骤。
- **过往工作。** {{ui:Learn from a past takeoff…}} 会记住已保存算量（.json）中已定价的项目。
- **查看、更改、遗忘。** {{ui:Everything remembered}} 列出所有名称；垃圾桶按钮可遗忘某一个，{{ui:Clear all prices}} 则遗忘全部。关闭 {{ui:Remember my prices when I save a takeoff}} 即可停止记忆。按“个”计价的单价绝不会套用到按英尺计价的项目上。参见 [过往项目的价格记忆](topic:price-memory)。

**供应商库存和交货周期**

- **与供应商清单核对。** 工具栏上的 {{ui:Supply}} 会读取供应商的库存清单（{{ui:添加供应商文件……}}），即 CSV 或电子表格，并结合损耗，将算量所需内容与之核对。最多保留五个文件。不会发送任何内容，也不会向供应商询问：由你提供文件。
- **结果说明。** 短缺项目排在最前，显示如“缺 120 EA”、“交货周期 21 天”、“缺货待补”、“单位不同”、“无库存数据”或“有库存”等文字。{{ui:可接受的最长等待（天）}} 默认为14。
- **订货清单。** {{ui:Order list (CSV)}} 会下载短缺项目，包括缺少的数量、供应商和交货周期。
- **写入价格库。** 如果文件中有价格，{{ui:Prices into the Library}} 会为每个同名且同单位的价格库条目设置材料价格。从价格库重新定价，即可将其带入算量。
- **在问题面板中。** 短缺为警告，长时间等待为注释，归在“供应商库存”下。你可以附上原因接受某一项，原因会保存在算量中。参见 [核对供应商库存和交货周期](topic:supplier-stock)。

**AI 助手**

- **供三个功能使用的工具。** 在 {{ui:Settings}} 中允许使用助手后，助手可以读取图例（`legend_open`），运行计数（`legend_count_start`，然后是 `legend_count_status` 和 `legend_count_result`），并添加结果（`legend_count_add`，可先预览）。它可以读取记住的价格（`prices_list`），并据此为项目定价（`prices_apply`，可先预览），还可以读取供应商核对结果（`supply_check`）。添加供应商文件仍由你自己完成。参见 [在 TakeoffCraft 中使用 AI 助手](topic:use-with-ai-assistants)。

**所有应用通用**

- **语言。** 共54种语言；其中10种为新增（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语）。除英语外的其他语言在母语人士审阅前均为机器草稿。
- **输入设备。** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} 设定触控板、鼠标侧键、手写笔、3D 鼠标、游戏手柄或 MIDI 控制器的功能，可对所有应用生效，也可仅对某一应用生效。参见 [使用触控板、3D 鼠标或控制器](common:input-devices)。
- **工具栏行数。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} 提供 {{ui:Wrap}}（默认）、{{ui:2 rows}} 和 {{ui:1 row}}；放不下的分组会左右滚动。参见 [排列面板](common:arrange-panels)。
- **问题面板。** 共用的警告和注释面板现在也包含上述供应商库存核对，与其他检查并列。
- **插件。** 插件跟随你的账户列表。参见 [插件和你的账户列表](common:addons-basics)。
- **连接你的 AI。** CadCraft Studio 是中心：只需连接一次助手，即可用于全部八个应用。Studio 本身不包含 AI。

### 0.8.1 中已修复

- **DWG 类别部分。** DWG 文件的类别部分曾被读取为错误的类型。该问题已在 TakeoffCraft 以及其他四个应用中修复。
- **Studio 运行时可以更改语言。** 之前，Studio 及其打包版本仅支持英语。此项尚未在每个平台的桌面版本上测试；如果语言未能更改，请告知我们。

### 本版本尚未实现

- **未经代码签名。** Windows 可能会发出警告；在 Mac 上，首次需右键单击并选择 {{ui:未处理}}。商店版本（Microsoft Store、Google Play、App Store）暂停发布，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- **Studio 更新。** Windows 安装程序和 Linux 软件包每天检查一次，并会先询问。便携式 zip 仅提示你，macOS 和 APK 不会自动更新。0.8 版的 macOS .dmg 将随正式版本发布。
- **连接你的 AI。** Studio 内的一键连接、浏览器中 AI 的托管连接器、Studio 内自带的 API 密钥以及已发布的 MCP 软件包，均不在本版本承诺之列。
- **全部计数。** 它需要以与图例相同的方式绘制的符号；穿过墙或长线的符号可能会被漏掉。镜像符号无法找到；没有比例、以其他尺寸绘制的图纸，会以图例的尺寸进行搜索。在信任其余结果之前，请先检查第一张图纸上的找到项。
- **供应商库存。** 库存数字的时效仅取决于你添加的文件。该核对从不向供应商询问。
- **语言。** 泰米尔语的应用栏会溢出。

其他内容见 [尚未实现](topic:not-built-yet)。上一版本见 [0.7 新增功能](topic:whats-new-0-7)。

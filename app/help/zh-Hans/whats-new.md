本文介绍 TakeoffCraft 0.8（2026-11-01 发布）和 0.8.1（2026-11-02）相对 0.7 的变化。现在可以一次对整套图纸统计符号图例，新算量可以从过往算量的价格开始，并且可以对照供应商的库存检查算量。0.8.1 为修复版本。

## 新增

### 在整套图纸中全部计数

- **框选一次图例。** 工具栏中的{{ui:Count everything}}会读取符号图例：用框选住符号及其旁边印刷的名称。每个符号连同图片和名称一起列出，名称会成为该项目的名称。取消勾选不需要的项，然后选择{{ui:在N张图纸上计数}}。进度条会显示正在搜索的图纸，{{ui:Cancel}}可停止运行，运行期间页面仍可使用。
- **一次运行覆盖所有图纸。** 每个符号都会在每张打开的图纸上计数。按其他比例绘制的图纸会以该比例进行搜索，符号可按任意直角旋转后查找。图例自身的符号不会在其所在图纸上计数。
- **添加前先检查。** 每个总数都带有各图纸的链接（如“E-103: 4”），点击即可跳转到该图纸。点击某个查找结果的方框可将其排除，再次点击即可恢复。匹配度（50%至100%）只用于筛选已找到的结果，不会重新搜索。
- **一个撤销步骤。** {{ui:添加N个标记}}会为每个符号创建一个计数项目，并在每个查找结果处添加一个标记。与已有计数项目同名的名称会直接复用。{{key:Ctrl+Z}}可撤销所有项目和标记。所接受的结果也会记入{{ui:Learned}}。
- **任意角度的符号。** 在统计前勾选{{ui:Symbols at any angle}}，还可以查找按非直角旋转的符号。搜索会每隔15度旋转一次每个符号，非圆形符号的耗时最多可能增加到六倍。
- **功能说明。** 这是基于本地图纸的普通符号匹配，不使用训练模型，所有内容都保留在本机，不会离开计算机。在一套模拟的200张图纸上，于一台高性能台式机的 Chrome 中全过程耗时9.4秒；实际图纸集会更慢。参见[在整套图纸中全部计数](topic:count-everything)。

### 过往算量的价格记忆

- **TakeoffCraft 记住各项单价。** 保存算量时，每个被使用的已定价项目都会按名称和类型记录下来：材料单价、人工单价、损耗和单位。每个名称保留最近12次算量。记录保存在本机的价格库旁边，不会写入算量文件，也不会发送到任何地方。
- **用它开始新算量。** 工具栏上的{{ui:Prices}}会为每个项目显示上次算量的单价、典型单价及其范围。{{ui:Use last}}或{{ui:Use typical}}可为单个项目定价，{{ui:根据记忆价格为N个未定价项目定价}}会为所有尚未定价的项目填入价格。每次使用都是一个撤销步骤。
- **旧的工作成果。** {{ui:Learn from a past takeoff…}}会记住已保存算量文件（.json）中已定价的项目。
- **查看、修改、遗忘。** {{ui:Everything remembered}}列出所有名称；删除按钮可删除某一条记录，{{ui:Clear all prices}}则删除全部。关闭{{ui:Remember my prices when I save a takeoff}}即可停止记录。按“每个”计价的单价绝不会用于按英尺计价的项目。参见[过往算量的价格记忆](topic:price-memory)。

### 供应商库存与交货周期

- **对照供应商清单检查。** 工具栏上的{{ui:Supply}}会读取供应商的库存清单（通过{{ui:Add a supplier file…}}添加），即 CSV 或电子表格，并据此检查算量所需的数量（含损耗）。最多保留五个文件。不会发送任何内容，也不会向供应商发出询问：文件需要自行提供。
- **检查结果。** 短缺项目排在最前，显示为“缺 120 EA”“交货周期21天”“待补货”“单位不同”“无库存数量”或“有库存”。{{ui:Longest wait wanted (days)}}默认从14天开始。
- **订货清单。** {{ui:Order list (CSV)}}会下载短缺项目，包含缺货数量、供应商和交货周期。
- **价格写入库。** 若文件中含有价格，{{ui:Prices into the Library}}会为名称和单位相同的每个库项目设置材料价格。从库中重新定价即可将其带入算量。
- **在问题面板中。** 缺货为警告，长时间等待为注释，二者都位于“供应商库存”下。可以附带理由接受某项，理由会保存在算量文件中。参见[检查供应商库存与交货周期](topic:supplier-stock)。

### AI 助手

- **三项功能均可使用工具。** 在{{ui:Settings}}中允许助手后，助手可以读取图例（`legend_open`），运行统计（`legend_count_start`，随后`legend_count_status`和`legend_count_result`），并将其添加（`legend_count_add`，可先预览）。它可以读取记住的价格（`prices_list`），并据此为项目定价（`prices_apply`，可先预览），还可以读取供应商检查结果（`supply_check`）。添加供应商文件仍由用户自行完成。参见[在 AI 助手中使用 TakeoffCraft](topic:use-with-ai-assistants)。

### 所有应用通用

- **语言。** 共54种语言；新增十种（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语）。英语以外的语言在母语人士审阅前均为机器翻译草稿。
- **输入设备。** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}}用于设置触控板、鼠标侧键、手写笔、3D鼠标、游戏手柄或 MIDI控制器的功能，可对所有应用生效，也可仅对某一应用生效。参见[使用触控板、3D鼠标或控制器](common:input-devices)。
- **工具栏行数。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}}提供{{ui:Wrap}}（默认）、{{ui:2 rows}}和{{ui:1 row}}；放不下的分组会左右滚动。参见[排列面板](common:arrange-panels)。
- **问题面板。** 共享的警告与注释面板现在也包含上述供应商库存检查，与其他检查并列。
- **插件。** 插件跟随账户列表。参见[插件与账户列表](common:addons-basics)。
- **连接 AI。** CadCraft Studio 是中心：只需连接一次 AI 助手，即可用于全部八个应用。Studio 自身不提供 AI。

## 0.8.1 中修复

- **DWG 的 classes 部分。** DWG 文件的 classes 部分曾被误读为错误的类型。此问题已在 TakeoffCraft 以及其他四个应用中修复。
- **Studio 可在运行时切换语言。** 此前 Studio 及其打包版本仅支持英语。此功能尚未在所有平台的桌面版本上测试；如果语言没有切换，请告知我们。

## 本版本尚未实现

- **未进行代码签名。** Windows 可能会发出警告；在 Mac 上，首次运行需右键点击并选择{{ui:未处理}}。应用商店版本（Microsoft Store、Google Play、App Store）暂停发布，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- **Studio 更新。** Windows 安装程序和 Linux 软件包每天检查一次更新，并会先询问。便携式 zip 仅提示更新，macOS 和 APK 不会自动更新。0.8 版 macOS 的 .dmg 文件将随正式发布提供。
- **连接 AI。** 本版本不承诺提供：Studio 内的一键连接、适用于浏览器中 AI 的托管连接器、Studio 内使用用户自己的 API 密钥，以及已发布的 MCP 软件包。
- **全部计数。** 需要以与图例相同的方式绘制的符号；符号上若穿过墙体或长线，可能会被漏掉。镜像符号无法找到；没有比例且以其他尺寸绘制的图纸，将按图例的尺寸搜索。在信任其余结果之前，请先检查第一张图纸上的查找结果。
- **供应商库存。** 库存数量的时效取决于所添加文件的时效。检查不会向供应商询问。
- **语言。** 泰米尔语的应用栏会溢出。

其他内容见[尚未实现](topic:not-built-yet)。上一版本的内容见[0.7 新增功能](topic:whats-new-0-7)。

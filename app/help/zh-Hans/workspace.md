TakeoffCraft占满CadCraft应用栏下方的浏览器窗口。自上而下、从左到右依次为：

| 部分 | 位置 | 用途 |
|---|---|---|
| 应用栏 | 最顶部 | 应用名称、版本、{{ui:关于TakeoffCraft}}、{{ui:帮助}}（{{key:F1}}）、{{ui:保存以供离线使用}}、{{ui:设置}}（{{key:Mod+,}}）、{{ui:全屏}}按钮和{{ui:图纸}} / {{ui:模型}}主题切换。 |
| 工具栏 | 应用栏下方 | 所有命令，分组排列：{{ui:文件}}、{{ui:导出}}、{{ui:比例}}、{{ui:算量}}、{{ui:编辑}}、{{ui:视图}}。 |
| 图纸 | 左侧 | 每个已打开PDF的每一页，带缩略图、比例和标记数量。 |
| 图纸页面 | 中间 | 已打开的页面。你在这里测量。 |
| 分项 | 右侧 | 你的算量分项、所选分项的设置，以及所选标记。 |
| 工程量 | 底部 | 按分项或按图纸的工程量和成本，以及工程总计。 |
| 状态栏 | 最底部 | 实时测量值、消息、45°提示和缩放比例。 |

## 工具栏

将指针悬停在任意按钮上可以看到它的作用和快捷键。

| 组 | 按钮 |
|---|---|
| {{ui:文件}} | {{ui:新建}}（空白算量）、{{ui:打开平面图}}（{{key:Mod+O}}）、{{ui:打开算量}}（`.takeoff.json`项目）、{{ui:保存算量}}（{{key:Mod+S}}） |
| {{ui:导出}} | 一个菜单：{{ui:XLSX}}、{{ui:CSV}}、{{ui:标记PDF}} |
| {{ui:比例}} | {{ui:校准}}（{{key:K}}）、{{ui:核对}}（{{key:D}}）和{{ui:预设}}列表 |
| {{ui:算量}} | {{ui:选择}}（{{key:V}}）、{{ui:线性}}（{{key:L}}）、{{ui:面积}}（{{key:A}}）、{{ui:圆}}（{{key:O}}）、{{ui:圆弧}}（{{key:R}}，开关）、{{ui:扣减}}（{{key:E}}，开关）、{{ui:洞口}}（{{key:X}}）、{{ui:计数}}（{{key:C}}）、{{ui:自动计数}}（{{key:S}}） |
| {{ui:编辑}} | {{ui:撤销}}（{{key:Mod+Z}}）、{{ui:重做}}（{{key:Mod+Y}}）、{{ui:复制}}（{{key:Mod+C}}）、{{ui:粘贴}}（{{key:Mod+V}}），以及{{ui:更多}}：{{ui:剪切}}、{{ui:复制}}、{{ui:粘贴}}、{{ui:原位粘贴}}、{{ui:创建副本}}、{{ui:删除}}、{{ui:全选}}、{{ui:取消选择}} |

正在使用的工具呈按下状态。{{ui:圆弧}}和{{ui:扣减}}按钮在开启期间保持按下。

## 图纸（左侧）

- **搜索图纸**按图纸名称、文件名或页面标签筛选列表。
- 每张图纸显示缩略图（在你滚动时绘制）、名称，以及它的比例或**无比例**。
- 每行右侧显示该图纸有多少个标记。当某个分项处于高亮状态时，则改为显示该分项在这张图纸上有多少个标记。
- 点击图纸即可打开它。{{key:PageDown}}和{{key:PageUp}}移到列表中的下一张和上一张图纸。
- 当某个算量涉及未打开的PDF时，列表下方会有一条备注列出它们。参见[保存并重新打开算量](topic:save-and-reopen)。

图纸名称取自PDF：像`A-101`这样的页面标签会成为图纸名称。没有标签的页面以其文件名和页码命名，例如“Plans，第3页”。打开多个PDF时，有标签的图纸也会显示文件名。

## 图纸页面（中间）

- 图纸下方的栏显示图纸名称及其比例，或“还没有比例：请选择预设或校准”。它的按钮有：{{ui:MarkupCraft}}（当该应用能接收此PDF时；参见[开始算量并打开图纸集](topic:open-plan-set)）、{{ui:比较}}（把此图纸的较早版本叠加在其上：[比较修订后的图纸](topic:compare-revisions)）、“(n)个待核对”（已标记的标记，有时才显示）和{{ui:3D}}（[3D核对视图](topic:check-in-3d)）。
- 在没有打开任何PDF之前，中间显示一份简短的五步指南。
- 滚轮以指针位置为中心缩放。拖动可平移。参见[键盘和鼠标](topic:keyboard)。
- 使用{{ui:自动计数}}时，图纸顶部会出现带有其控件的栏。

## 分项（右侧）

最上方是{{ui:报价区域}}列表：新标记所归入的建筑、楼层或阶段（[报价区域](topic:bid-areas)）。

- {{ui:新建分项}}会打开一个小表单：名称、类型（{{ui:线性（长度）}}、{{ui:面积}}或{{ui:计数}}）和{{ui:添加}}。
- 列表显示每个分项的颜色、类型图标、名称和工程量。点击一个分项可用它绘制，并在所有图纸上高亮它的标记。再次点击则停止高亮。
- 列表下方的**分项：(名称)**是分项编辑器：名称、类型、颜色、单位、高度或深度、损耗、材料和人工费率、测量值，以及{{ui:组合}}。参见[创建算量分项](topic:create-items)。
- 选择标记时会出现**所选标记**：它属于哪个分项、所在图纸、测量值，以及{{ui:添加洞口}}和{{ui:删除标记}}等按钮。选择多个标记时变为**所选标记**（复数）：每个分项各有多少个，以及{{ui:复制}}、{{ui:创建副本}}、{{ui:剪切}}和{{ui:删除标记}}。
- 分项编辑器的末尾是{{ui:复制分项}}和{{ui:创建分项副本}}：带有组合和成本但不含标记的分项。参见[复制、粘贴和创建标记副本](topic:copy-paste)。

## 工程量（底部）

- {{ui:按分项}}列出每个分项及其组合的组成部分，含工程量、损耗、费率和合价。你可以直接在表中输入损耗和费率。
- {{ui:按图纸}}列出每个分项在每张图纸上的工程量。
- 当有内容未计入合计时，会出现以**不完整：**开头的警告。
- {{ui:工程总计}}位于标题行的右侧。
- 最右端的箭头按钮可隐藏或显示该表，为图纸腾出更多空间。

参见[查看工程量和估算](topic:read-quantities)。

## 状态栏（底部）

自左向右依次为：绘制时的实时测量值（长度、面积、半径或核对结果）、输入长度时的{{ui:输入}}框、来自TakeoffCraft的消息、提示“按住Shift可捕捉45°”（或在[设置](topic:settings)中开启后显示“捕捉45°；按Shift可取消角度限制”）、{{ui:捕捉}}按钮（捕捉到图形的线条，高亮时为开启；{{key:F3}}），以及缩放百分比。

:::tip
有操作没有生效时，请看状态栏。TakeoffCraft会在那里说明为何拒绝了某次点击，例如“此图纸还没有比例。”
:::

## 其他布局

以上都是{{ui:CadCraft 经典}}布局，即初始布局。{{ui:设置}}（{{key:Mod+,}}） › {{ui:全局}} › {{ui:布局}}还提供另外两种；三种布局中的工具和按键相同，再次选择{{ui:CadCraft 经典}}会让所有控件回到原来的位置。

| 布局 | 在 TakeoffCraft 中 |
|---|---|
| {{ui:功能区和项目浏览器}} | 顶部的{{ui:算量功能区}}（[菜单、按键和鼠标](topic:menus-keys-and-mouse)）、当前工具的栏、你打开的每张图纸各占一个选项卡（图形的“模型”和各布局也是图纸），图纸下方是比例预设和{{ui:适合页面}}。左侧面板在{{ui:算量浏览器}}之上放置{{ui:属性}}（所选的分项、注释或标记）：{{ui:图纸}}（点击一张即在选项卡中打开）、{{ui:条件}}（点击一项即用它绘制）和{{ui:估算}}（每个分项的合计和工程总计）；缩略图是它的第二个选项卡。 |
| {{ui:工具箱和信息框}} | 图纸上方的工具栏、带有{{ui:报价区域}}的信息框、当前工具或所选内容以及图纸栏，左侧是一列算量工具，每张图纸一个选项卡，图纸下方是{{ui:捕捉}}和缩放。 |

打开[3D核对视图](topic:check-in-3d)时，图纸选项卡和图纸下方的栏会退到一边；关闭3D视图后才能继续测量。在手机上始终使用手机布局。

## 全屏和主题

应用栏中的{{ui:全屏}}按钮，或{{key:Ctrl+Shift+F}}（在所有平台上都是Control，Mac也一样），依次切换普通、全屏，以及隐藏各栏的全屏。隐藏各栏后，将指针移到顶端即可再次显示它们。

{{ui:图纸}}是浅色主题，{{ui:模型}}是深色主题。在{{ui:模型}}下，图形在屏幕上反色显示（深底浅线）；导出的内容绝不会改变。

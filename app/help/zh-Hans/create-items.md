**分项**是需要测量并计价的一类对象：墙体类型、地面饰面、天花板、门、灯具等。每个标记都属于一个分项。其他程序称之为条件。

每个分项都有一种类型（还可以接受其他种类的标记，参见[一个分项，多种标记](topic:create-items#one-item-several-kinds-of-marks)）：

| 类型 | 绘制方式 | 报告内容 | 单位 |
|---|---|---|---|
| 线性 | 相连点组成的线段 | 长度、线段数量，设有高度时还报告墙面面积 | LF 或 m |
| 面积 | 带切除部分的封闭轮廓 | 面积、周长、区域数量 | SF、SY、SQ、ac、ha 或 m² |
| 计数 | 每个对象单击一次 | 数量 | EA |
| 输入的数量 | 无需绘制：直接输入数量 | 输入的数字（或从 CivilCraft 导入的数字） | LS、EA、CY、m³、lb、TON、kg、t、LF、m、SF、SY、SQ、ac、ha 或 m² |

## 输入的数量（无需图纸）

估算中有些项目从不绘制：动员费、许可费、应急费、总价分包，以及 CivilCraft 计算出的挖填方量。将它们设为**输入的数量**：

1. 选择 {{ui:新建分项}}，输入名称，选择 {{ui:输入的数量（无需图纸）}}，然后选择 {{ui:添加}}。
2. 在分项编辑器中选择 {{ui:单位}}（总价用 LS），并输入 {{ui:数量}}：`1`、`2.5` 或 `1,250`。
3. 损耗和单价的设置与其他分项相同。组合的公式使用 `Q`（即数量）进行计算，例如 `ceil(Q / 12)` 车次。

输入的数量不占用任何标记，也永远不会使估算不完整。当算量包含报价区域时，编辑器还有 {{ui:报价区域}}：此时数量会计入该区域、其备选项及合计，与该区域中的标记相同。从其他应用导入的数量会注明来源，参见[土方与标高点](topic:earthwork#cut-and-fill-from-civilcraft)。

## 新建分项

1. 在右侧的 {{ui:分项}} 面板中选择 {{ui:新建分项}}。
2. 输入名称，例如 `Interior wall type A` 或 `Carpet tile`。
3. 选择类型：{{ui:线性（长度）}}、{{ui:面积}} 或 {{ui:计数}}。
4. 选择 {{ui:添加}}（或按 {{key:Enter}}）。
   分项会出现在列表中，拥有自己的颜色，成为绘制时使用的分项，其编辑器在列表下方打开。状态栏会提示接下来选择哪个工具。

在表单中按 {{key:Esc}} 可关闭表单而不添加分项。

:::tip
如果先选择测量工具，TakeoffCraft 会使用该类型最后一个分项；或打开 {{ui:新建分项}} 表单，并已预先选定该类型。
:::

## 选择用于绘制的分项

点击列表中的一个分项。它会成为新标记所属的分项，其标记在每张图纸上高亮显示，其他分项则淡化。若当前图纸没有它的标记，TakeoffCraft 会跳转到有标记的图纸。再次点击该分项可停止高亮；它仍是绘制时使用的分项。

使用 {{ui:选择}} 工具点击某个标记，也会将其所属分项设为当前分项。

## 设置分项

分项编辑器（**分项：（名称）**）包含以下字段。每个字段在离开该字段或按 {{key:Enter}} 时保存，每次更改都可以撤销。

| 字段 | 作用 |
|---|---|
| {{ui:名称}} | 显示在列表、表格和导出文件中。 |
| {{ui:输入}} | 线性、面积或计数。分项已有标记后即锁定（“带有标记的分项会保留其类型”）。 |
| {{ui:颜色}} | 其标记在屏幕上及带标记的 PDF 中的颜色。 |
| {{ui:单位}} | 数量的报告单位：线性用 LF 或 m；面积用 SF、SY、SQ、ac、ha 或 m²；计数用 EA。 |
| {{ui:同时测量}} | 该分项可接受的其他种类标记，各自有独立单位。见下文。 |
| {{ui:高度}}（线性） | 墙高。分项随后还会报告墙面面积（长度 × 高度）。来自 BimCraft 模型的线段会带有其门窗：这些门窗只扣除一次，分项会显示毛面积、洞口和净面积。若来自 BimCraft 项目的算量选择了计量方法，则此处也按该方法计量（备注会注明方法及其来源，并说明未经工料测量师核实）；该方法无法在 TakeoffCraft 中更改。墙体类型中的砖或砌块及砂浆会以两个部件呈现：需订购的数量和砂浆体积。 |
| {{ui:深度}}（面积） | 深度或厚度，用于组合公式（例如混凝土体积）。 |
| {{ui:损耗 %}} | 在计价前加到数量上：10 表示数量 × 1.10。 |
| {{ui:材料 $/LF}} | 每单位材料成本。标签随单位变化：$/SF、$/EA 等。 |
| {{ui:人工 $/LF}} | 每单位人工成本。 |
| {{ui:CSI编号}} | 其 CSI MasterFormat 编号，例如 `09 21 16`（或仅分部，`09`）。工作簿的“按分部”工作表据此对成本分组。来自[专业包](topic:trade-packs)的分项已带有该编号。 |

对于英制单位，高度和深度可输入英尺和英寸（`9'-0"`、`8' 6"`）或十进制英尺（`9`）；对于公制单位，可输入米（`2.7`、`2700 mm`）。单价可输入如 `12.50` 或 `$1,250` 的金额，最多四位小数。参见[长度、单价与百分比输入](topic:entry-formats)。

在字段下方，**已测量**显示分项公式可用的合计及其字母：线性的长度（L）、线段数（N）、墙面面积（A）；面积的面积（A）、周长（P）、区域数（N）；计数的数量（N）。

## 一个分项，多种标记

有些对象可以用多种方式测量：房间有地面（面积）、沿墙的踢脚线（长度）和门（计数）。与其创建三个分项，不如只创建一个：

1. 用其主要类型创建分项，例如面积分项 `Room 101`。
2. 在其编辑器的 {{ui:同时测量}} 下，勾选 {{ui:线性}}、{{ui:计数}}或两者。每个选项旁都会出现一个单位。
3. 使用分项可接受该种类的任意工具绘制：当 `Room 101` 为当前分项时，{{ui:面积}} 绘制其地面，{{ui:线性}} 绘制其踢脚线，{{ui:计数}} 标记其门。TakeoffCraft 不会要求另选分项。

分项列表会显示每项数量（`50.00 SF + 2 EA`）。在工程量表中，该分项的行显示主要数量，每种其他种类在其下方各占一行，例如 **Room 101（计数）**，并有各自的损耗、材料和人工单价。导出文件、每张图纸的表格以及带标记 PDF 的图例也以同样方式列出它们。

主类型的字段仍归主类型所有：高度或深度、**坡度**、**扣减面积**以及三维形状仅适用于其标记。为面积分项绘制的踢脚线线段会沿平面图直接测量，并在三维中平铺显示。组合公式使用主类型的合计。

只有在分项没有某种标记时，才能取消勾选该种类；需先删除这些标记，或在 **选定标记** 下将其移至其他分项。标记可以移至任何接受其种类的分项。

再往下是{{ui:组合}}：如龙骨或板材等部件，每个部件都有自己的公式和单价。参见[组合与公式](topic:assemblies)。

在底部，{{ui:上移}} 和 {{ui:下移}} 可更改分项在列表和导出文件中的位置，{{ui:删除分项}} 会连同其所有标记一并删除（删除前会询问，且可以撤销）。

面积分项还有 **坡度**（在斜面上测量的屋面平面：[屋顶与坡面](topic:roofs-and-slopes)）和 **扣减面积**（其标记会从其他分项的面积中扣除：[测量面积](topic:measure-areas#back-outs-columns-shafts-and-openings-taken-out-of-several-items)）。线性分项有 **坡度**（水平、斜边、斜脊或天沟），对于斜边和斜脊还有 **坡度**（角度）。

## 表格中的单价

也可直接在 {{ui:工程量}} 表格底部（{{ui:按分项}}）输入 {{ui:损耗 %}}、材料和人工单价。这与编辑器中的设置相同。

## 计价方法

对每个分项及每个组合部件：

1. **含损耗** = 数量 ×（1 + 损耗 %）。
2. **材料** = 含损耗 × 每单位材料价格，精确到分。
3. **人工** = 含损耗 × 每单位人工价格，精确到分。
4. **合计** = 材料 + 人工。

{{ui:工程总计}} 会累加每个分项和每个部件。一个分项可以同时带有自身单价和组合；两者都会计入，因此当部件已包含成本时，应将分项单价设为 0。

## 按班组计算人工

分项的人工可以不按每单位单价计算，而是按班组计算：班组每小时完成多少、有多少人、每人工资多少。在分项编辑器中的 {{ui:按班组计算人工}} 下，勾选 {{ui:按班组计算人工价格}} 并填写：

| 字段 | 示例 |
|---|---|
| {{ui:产量}} | 整个班组每小时完成 `20` LF（以分项单位计） |
| {{ui:班组人数}} | `2` 人 |
| {{ui:每人工资 $/小时}} | `45` |

TakeoffCraft 根据含损耗的数量计算：

- **班组工时** = 数量 ÷ 产量（110 LF ÷ 20 = 5.5），
- **工人工时** = 班组工时 × 班组人数（11），
- **班组工日** = 班组工时 ÷ 8（0.69），
- **人工** = 工人工时 × 工资（$495.00）。

编辑器显示结果及其换算的单价（$4.50/LF）。此后，分项自身的人工单价在编辑器和表格中均为只读。{{ui:工程量}} 表格的标题会增加整个工程的工人工时和班组工日。导出文件会注明每个班组的工时；在工作簿中，人工单元格是基于班组的公式（`ROUND(F2/20*2*45,2)`）。取消勾选即可恢复为按每单位计算的单价。

## 公制分项

选择 m（线性）或 m²（面积）作为单位。此时数量、高度和公式值均以米计。图纸比例可以是任一预设或校准；单位与比例相互独立。

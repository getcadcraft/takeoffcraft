3D 视图是一种检查手段，而非第二份图纸：它将图纸上的计量立起来显示在屏幕上，因此缺失的墙、重复的楼板或误加的计数一眼即可发现。

开始前：图纸需要比例（[设置比例](topic:set-the-scale)）。高度和深度需要真实的英尺数值，因此在没有比例的图纸上，{{ui:3D}} 会给出提示，并保持在平面图纸上。

## 打开 3D 视图

1. 显示你想要检查的图纸。
2. 在显示图纸名称和比例的栏上选择 {{ui:3D}}，或按 {{key:3}}。
   首次打开时，3D 视图需要片刻加载。图纸平放于地面上，计量则以各分项的颜色立于其上。
3. 要返回，请再次选择 {{ui:3D}}、{{ui:返回图纸}}，或按 {{key:3}}。选择绘图工具（线性、面积、计数等）也会返回，因为标记是绘制在平面图纸上的。

它在屏幕上显示图纸；可在图纸列表中切换图纸，或使用 {{key:PageDown}} 和 {{key:PageUp}}，3D 视图会随之变化。若要同时查看多层，请将它们叠放（见下文）。

## 你所看到的

| 标记 | 在 3D 中 |
|---|---|
| 线性段，分项带高度 | 沿该段立起的一面墙，高度为该分项的高度。曲线段沿曲线延伸。 |
| 线性段，分项无高度 | 图纸上的一条线。请在 **分项** 下为该分项设置高度，以将其立起。 |
| 面积，分项带深度 | 深度为该值的楼板，其洞口保持开放。 |
| 面积，分项无深度 | 一块薄的 2" 板，以便仍能显示。 |
| 计数 | 每个计数点上的一根小柱子。 |

高度即线性分项的 {{ui:高度}} 字段，深度即面积分项的 {{ui:深度}} 字段，位于 **分项** 下（参见 [创建计量分项](topic:create-items)）。修改后，3D 视图会立即更新。图纸名称下方的说明会列出图纸所含内容，例如“本图纸的 3D 视图：2 面墙、1 块楼板、3 个计数”，以及有多少段或面积没有高度或深度。点击会穿透该说明，直达视图。

3D 中的数字不会改变：墙的面积是其精确长度乘以高度，楼板的体积是其净面积（轮廓减去洞口，曲线精确计算）乘以深度。曲线仅在屏幕上以短直线段绘制。

## 环顾四周

| 操作 | 作用 |
|---|---|
| 拖动，或用中键拖动 | 围绕计量环绕。 |
| {{key:Shift}} + 拖动，或用右键拖动 | 平移。 |
| 鼠标滚轮 | 以指针位置为中心缩放。 |
| 触控板双指滑动 | 环绕（{{key:Shift}} 为平移）。双指捏合缩放。 |
| {{ui:等轴测}}、{{ui:顶}}、{{ui:前}}、{{ui:后}}、{{ui:左}}、{{ui:右}}、{{ui:底}} | 标准视图，以计量为取景范围。3D 视图默认以 {{ui:等轴测}} 打开。 |
| {{ui:透视}} | 开启或关闭透视（关闭时为平行投影）。 |
| {{ui:范围缩放}} 或 {{key:F}} | 整张图纸。 |
| {{ui:图纸}} | 显示或隐藏地面上的图纸。 |
| 右上角的视图立方体 | 点击某个面、边或角即可从该方向观察；拖动可环绕；拖动其罗盘环可旋转；房子按钮返回 {{ui:等轴测}}。 |

角落会显示视图立方体、一个小的 X、Y、Z 坐标轴图标，或不显示任何内容：请在 {{ui:设置}} 的 TakeoffCraft 选项卡下的 **角落指示器** 中选择（[TakeoffCraft 设置](topic:settings)）。平面图纸没有角落指示器。

:::touch
单指环绕；双指捏合缩放，移动则平移。轻点即可选择。
:::

## 带厚度、底高和洞口的墙

带高度的线性分项会以细条的形式立起。要将其视为真实的墙，请在其设置的 **3D 中** 下为该分项设定形状：

- **墙厚**（8"、0.2 m）：墙变为实体，以你绘制的线为中心，转角为斜接。
- **底高**：墙从距地面该高度处开始（如吊顶、上柜）。面积分项也有此项：例如天花板位于 9'-0"。
- **开口顶高**：被扣除的段（如门，[扣除线段的一部分](topic:measure-linear#deduct-a-part-of-a-run)）会使墙保持在该高度以上，因此门会显示为门。若未设置，被扣除的段会在顶部留下一个缺口。

这些设置仅影响 3D 视图的形状：工程量（长度、墙面面积、成本）保持不变。

## 叠放楼层

1. 打开每一层的 PDF。
2. 在 3D 视图中，选择 {{ui:标高…}}，并输入每层的标高，例如首层输入 `0`，下一层输入 `12'`。留空则不包含该图纸。
3. 选择 {{ui:叠放}}。每张有标高的图纸都会在其高度上显示其计量；屏幕上的图纸位于其自身楼层之下，其余楼层则以轮廓显示。说明会注明已叠放的楼层数。

图纸按其在页面上的位置对齐，因此适用于以相同方式绘制的平面图（相同的图纸尺寸和位置）。有标高但没有比例的图纸会被排除，说明中会提示。再次选择 {{ui:叠放}} 可一次只显示一张图纸。标高与计量一同保存。

## 将 3D 视图保存为图像

在 3D 栏上选择 {{ui:PNG}}，可保存屏幕上当前视图的图片（`… 3D.png`）；按住 {{key:Shift}} 点击 {{ui:PNG}} 则生成两倍大小的图片（`… 3D@2x.png`），便于打印。

## 将 3D 视图保存为模型

在 3D 栏上选择 {{ui:GLB}}。你将得到一个 `.glb` 文件（二进制 glTF），内容为视图所示之物：屏幕上的楼层，或所有叠放的楼层。其他 3D 程序可以打开它：每个标记为一个对象，以其分项命名，使用该分项的颜色，单位为米，Y 轴向上。图纸本身和轮廓不包含在内。

## 从 3D 中选择标记

点击墙、楼板、压板或柱子。其标记即成为所选标记，与在图纸上点击完全相同：它显示在 **所选标记** 下，其分项成为当前分项，状态栏显示其长度和高度，或其面积、深度和立方码。{{key:Shift}} + 点击可将标记加入选择集或将其移出。{{key:Delete}} 删除所选标记，{{key:Mod+Z}} 可将其恢复；{{key:Esc}} 取消全部选择。返回图纸后，相同的标记仍保持选中。

:::tip
图纸跟随主题：在“模型”中，地面上的图纸会变暗，与平面视图一致。
:::

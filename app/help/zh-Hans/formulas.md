组合组件的工程量由公式得出。公式是基于项目测量值的一个简单算术表达式。示例参见[组合与公式](topic:assemblies)。

## 变量

| 项目类型 | 变量 | 含义 |
|---|---|---|
| 线性 | `L` | 总长度 |
| 线性 | `H` | 项目的高度 |
| 线性 | `A` | 墙面积，L × H，减去所在线段上的洞口（来自 BimCraft 的算量）。若该算量指定了测量方法，则 `A` 按该方法测量：不大于该方法最小尺寸的洞口保留在计算中，该方法在墙体交接处扣除的部分不计入。项目下方的备注会注明所用方法 |
| 线性 | `N` | 线段数量 |
| 面积 | `A` | 总净面积（轮廓减去洞口） |
| 面积 | `P` | 总周长，包括洞口边缘 |
| 面积 | `H` | 项目的深度或厚度 |
| 面积 | `N` | 面积数量 |
| 计数 | `N` | 计数值 |

- 变量使用项目的单位：参见[单位](topic:units)。
- 大小写相同：`l` 等同于 `L`。
- 只有项目自身类型的变量可用。线性项目上的 `P` 会得到 `"P" 在此不是测量值。请使用 L、H、A、N。`
- 空的高度或深度视为 0。

## 运算符

| 写法 | 含义 |
|---|---|
| `+` | 加 |
| `-` 或 `−` | 减，或负值 |
| `*` 或 `×` | 乘 |
| `/` 或 `÷` | 除 |
| `( )` | 分组 |

乘除优先于加减：`L * 2 + 4` 即 (L × 2) + 4。不确定时请使用括号。

数字可以带小数（`1.333`、`.5`）和指数（`1e3` = 1000）。空格会被忽略。

## 函数

| 函数 | 结果 | 示例 |
|---|---|---|
| `ceil(x)` | 向上取整为整数 | `ceil(67.5)` = 68 |
| `floor(x)` | 向下取整为整数 | `floor(67.5)` = 67 |
| `round(x)` | 四舍五入为最接近的整数（半数远离零） | `round(2.5)` = 3 |
| `round(x, d)` | 四舍五入到 d 位小数（0 至 10） | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | 最小值 | `min(N, 10)` |
| `max(a, b, …)` | 最大值 | `max(1, ceil(N / 12))` |
| `abs(x)` | 去掉符号后的值 | `abs(-3)` = 3 |

`ceil` 和 `floor` 会忽略计算机产生的微小舍入误差，因此本应恰好为 1 的值不会被向上取整为 2。

## 错误

无法读取或计算的公式会在输入框下方显示错误，该组件不计入总计（{{ui:工程量}}表头显示“不完整”）。错误信息：

| 信息 | 修正方法 |
|---|---|
| 请输入公式，例如 L 或 ceil(L / 1.333) + 1。 | 公式为空。 |
| "X" 在此不是测量值。请使用… | 使用上述变量之一。 |
| "X" 在此不是函数。请使用 ceil、floor、round、min、max、abs。 | 使用其中一个函数。 |
| 公式中不允许使用 "#"。 | 删除该字符（不允许使用单位、`%`、`$` 和 `=`）。 |
| 缺少 ")"。/ 存在没有对应 "(" 的 ")"。 | 使括号配对。 |
| ")" 前缺少数值。 | 类似 `max(1, )`：补充数值。 |
| 公式提前结束。 | 类似 `L *`：补全公式。 |
| 出现意外的 "…"。是否缺少运算符？ | 两个数值并列，例如 `2L`：应写作 `2 * L`。 |
| ceil() 只接受 1 个值。 | 为函数提供正确数量的值。 |
| round(x, digits) 需要 0 至 10 之间的整数位数。 | 使用整数位小数。 |
| 公式除以零。 | 通常是 H 为 0：请设置项目的高度或深度。 |
| 公式结果不是数字。 | 结果过大，无法表示为数字。 |
| 公式过长（最多 500 个字符）。 | 缩短公式。 |

## 设计上的安全性

公式只能使用上述变量和函数进行算术运算，无法运行代码或读取其他任何内容，因此他人发送的项目文件中的公式是无害的。

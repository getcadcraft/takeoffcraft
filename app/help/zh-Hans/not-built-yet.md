TakeoffCraft 仍在开发中。本列表说明当前版本未实现的功能，以及如何仍然完成工作。

## 测量

| 尚未实现 | 目前的替代做法 |
|---|---|
| 在线段或轮廓的中间插入一个点 | 删除该标记，然后重新绘制。 |
| 框选（窗口）选择 | 按住{{key:Shift}}逐个单击每个标记，或按{{key:Mod+A}}选择图纸上的所有标记。参见[复制、粘贴与创建副本标记](topic:copy-paste)。 |
| 旋转、镜像或缩放已粘贴的副本 | 在图纸上以相同比例和相同方向粘贴；其余部分手动绘制。 |
| 从扫描图纸或图形比例尺读取比例 | 选择预设，或以比例尺的长度进行校准。 |
| 每张图纸有多个比例（详图区、放大平面图） | 以图纸的比例测量该部分；如果图纸集中有该详图的放大图纸，则在其自己的放大图纸上进行算量。 |

## 分项与定价

| 尚未实现 | 目前的替代做法 |
|---|---|
| 使用分项中其他类型标记的组合公式（例如房间分项中的门，用于其所在楼层的公式） | 公式使用主要类型的合计；其他类型请在各自的行中单独定价。 |
| 逐段计算的组合公式 | 公式使用分项的合计；每段的额外量请使用 `N`。 |
| 使用另一分项工程量的公式 | 在该分项中重复测量，或在电子表格导出中计算。 |
| 组合构件上的班组，或工作日不是8小时 | 将班组分配给分项；对于其他工作日长度，按班组工时 ÷ 你的每日工时 计算班组日。 |
| 除备注、云线和高亮之外的批注（箭头、标注、图章），或对备注的回复 | 将内容写入备注文字；解决后更改其状态。 |
| 由团队共享或与你的账户绑定的价格库 | 价格库保存在本浏览器中：将其导出为CSV，然后在另一台电脑上导入。 |
| 由资深估价人员审核的专业包 | 每个专业包都只是入门模板：在用它定价之前，请对照你的项目和产品核对其假设。参见[专业包](topic:trade-packs)。 |
| 专业包中的价格 | 专业包仅提供组合：请自行设置单价，或将价目表作为CSV导入。 |
| 重命名算量 | 名称取自第一个PDF；请重命名下载的文件。 |
| 手动命名图纸 | 图纸根据PDF的页码标签命名；可按文件名和页码搜索。 |

## 图形（DWG与DXF）

| 尚未实现 | 目前的替代做法 |
|---|---|
| 图形图纸上的打印样式表、笔指定和CTB文件 | 图形以黑色绘制，或为纸张将其颜色加深；线宽取自图形本身。 |
| 打开二进制DXF，或早于AutoCAD 2000的DWG | 另存为ASCII DXF或较新的DWG。 |
| 按外部参照（xref）所在的文件夹查找该图形 | 将外部参照图形文件与主图形一同打开：它会在已打开的文件中按文件名被找到。 |
| 测量三维多段线、网格、实体和面域 | 按图层和类型计数，或使用线性和面积工具测量平面视图。 |
| 非拉丁文字图形的带标记PDF中的文字 | Helvetica没有字形的字符会在带标记的PDF中打印为“?”；屏幕上的图形不受影响。 |
| 从图纸栏将图形交给其他应用 | 在该应用中打开同一文件。 |
| 图形本身包含算量（与{{ui:内含算量的PDF}}对PDF的做法相同） | {{ui:保存算量}}：`.takeoff.json` 可重新打开同一图形，并通过其内容找到该图形。 |
| 在图形中放置的PDF底图、图像和OLE对象的绘制或计数 | 图像仅显示为边框。请将底图PDF本身作为图纸打开。 |

## 自动计数

| 尚未实现 | 目前的替代做法 |
|---|---|
| 在比例未按另一尺寸绘制的图纸上查找符号 | 为图纸设置比例，或在其上绘制框选后进行搜索。 |
| 查找镜像符号 | 手动计数这些符号，或在某个镜像符号周围绘制框选后再次搜索。 |

## 文件与共享

| 尚未实现 | 目前的替代做法 |
|---|---|
| 同时显示标记并包含算量的一个PDF | {{ui:标记PDF}}供他人查看标记；{{ui:内含算量的PDF}}用于在TakeoffCraft中重新打开。 |
| 按图纸或按标记列出工程量的CSV | 使用{{ui:XLSX}}：其“按图纸”和“标记”工作表即包含这些内容。 |
| 云端保存 | 暂不可用。请将项目文件保存到你的计算机并进行备份。 |
| 独立的TakeoffCraft桌面应用 | 从0.5版起，桌面应用为CadCraft Studio，八个应用一次安装即可。TakeoffCraft也可以在浏览器中运行。 |

## 屏幕与输入

| 尚未实现 | 目前的替代做法 |
|---|---|
| 右键（或长按）菜单 | 使用工具栏、面板和按键。长按可完成一段线段或一个轮廓。 |
| 旋转视图 | 在PDF中已旋转的页面会正向显示。 |

## 三维视图

| 尚未实现 | 目前的替代做法 |
|---|---|
| 在三维中绘制或编辑标记 | 返回图纸（{{key:3}}）进行绘制；在三维中可以选择和删除。 |
| 对齐以不同位置绘制在页面上的堆叠楼层 | 堆叠绘制方式相同的楼层；其他楼层逐张图纸检查。 |
| 计数尺寸与被计数对象相同的柱 | 图纸上的每根柱大小都相同；它标记的是计数位置，而不是计数对象本身。 |

## 投标

| 尚未实现 | 目前的替代做法 |
|---|---|
| 已发送的投标包的补充文件、中标函，以及每位投标人签字确认的范围表 | 发送新的投标包，并自行编写中标函。[发送投标包](topic:bid-invitations)说明了已实现的功能。 |
| 从任意账户发送投标邀请：测试期间，除CadCraft团队已启用的账户外，发送给外部投标人的邮件已关闭 | 下载{{ui:范围CSV}}，自行发送邮件并录入投标价。 |
| 从Studio窗口发送投标包 | 在浏览器中的TakeoffCraft中发送。 |
| 使用所选投标价重新定价备选项的投标范围 | 备选项和投标范围小计使用你自己的价格；请手动调整备选项。 |
| 分包商保险或执照到期前的自动提醒 | 日期一旦过期或在30天之内，会在“分包商”页面上标记；邀请时请检查。 |

## 面板

| 尚未实现 | 目前的替代做法 |
|---|---|
| 移动{{ui:工程量}}表格 | 只能移动{{ui:图纸}}和{{ui:分项}}面板。参见[排列面板](common:arrange-panels)。 |

## 电子表格

XLSX工作簿已在LibreOffice Calc中检查，其重新计算的每个合计都与TakeoffCraft精确到分一致。尚未在Excel中打开。如果电子表格程序显示异常，CSV导出以纯数值保存了同样的估算。

## 绘制时

| 按键或操作 | 作用 |
|---|---|
| 单击 | 放置一个点（使用计数时为一个计数点）。 |
| {{key:P}} | 路径：选取PDF线条的整条连通路径，或点击处周围的轮廓（[拾取PDF的线条](topic:pick-the-lines)）。 |
| {{key:F3}} | 开启或关闭捕捉到图纸线条（[捕捉到图纸线条](topic:snap-to-the-drawing)）。 |
| 单击时按住{{key:Shift}} | 将线段捕捉到距上一点0°、45°、90°或135°的方向。不适用于圆弧点或圆。 |
| 双击 | 结束一段线，或闭合一个面积或洞口。 |
| {{key:Enter}} | 结束一段线，或闭合一个面积或洞口。 |
| 右键单击（不移动） | 结束一段线，或闭合一个面积或洞口。 |
| 单击第一个点 | 闭合一个面积或洞口（从第三个点起）。 |
| {{key:Backspace}}或{{key:Delete}} | 删除最后一个点（先删除待定的圆弧点）。 |
| {{key:Esc}} | 放弃待定的圆弧点；然后取消未完成的标记；然后返回{{ui:选择}}。 |

## 选择和编辑

| 按键或操作 | 作用 |
|---|---|
| 单击标记（选择工具） | 选中它，并将其所属分项设为当前。 |
| {{key:Shift}}+单击标记 | 将其加入选择，或从选择中移除。 |
| {{key:Mod+A}} | 选中当前打开图纸上的所有标记。 |
| 拖动角控点 | 移动该点（按住{{key:Shift}}可捕捉到45°）。选中一个标记时可用。 |
| {{key:Delete}}或{{key:Backspace}} | 删除选中的标记（非绘制状态时）。 |
| {{key:Esc}} | 取消全部选择：清除选择和检查线。 |
| {{key:Mod+Z}} | 撤销。 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 重做。 |

## 复制和粘贴

| 按键 | 作用 |
|---|---|
| {{key:Mod+C}} | 复制选中的标记及其分项。 |
| {{key:Mod+X}} | 剪切：复制选中的标记，然后将其删除。 |
| {{key:Mod+V}} | 粘贴：副本跟随指针移动；单击放置位置。 |
| {{key:Mod+Shift+V}} | 原位粘贴：放置在当前打开图纸的相同位置。 |
| {{key:Mod+D}} | 创建副本：副本跟随指针移动；单击放置位置。 |
| {{key:Esc}} | 不放下任何内容：取消仍在指针上的粘贴或创建副本操作。 |

字母键单独使用时仍会切换工具（{{key:C}}为{{ui:计数}}，{{key:D}}为{{ui:核对}}，{{key:X}}为{{ui:洞口}}，{{key:V}}为{{ui:选择}}，{{key:A}}为{{ui:面积}}）；只有{{key:Mod}}加上这些字母才会复制和粘贴。在文本输入框中，这些按键照常复制和粘贴文本。参见[复制、粘贴和创建标记副本](topic:copy-paste)。

:::warning
非绘制状态下，{{key:Backspace}}会删除选中的标记。若误操作，按{{key:Mod+Z}}即可将其恢复。
:::

## 视图和图纸

| 按键或操作 | 作用 |
|---|---|
| 鼠标滚轮 | 以指针位置为中心放大和缩小。 |
| 拖动（左键、中键或右键） | 平移。在{{ui:自动计数}}中，左键拖动会改为绘制搜索框。 |
| 按住{{key:Space}}并拖动 | 在任何工具下平移。 |
| {{key:F}} | {{ui:适合页面}} |
| {{key:W}} | {{ui:适合宽度}} |
| {{key:Plus}}或{{key:=}} | 以视图中心为基准放大。 |
| {{key:Minus}} | 以视图中心为基准缩小。 |
| {{key:PageDown}}/{{key:PageUp}} | 图纸列表中的下一张或上一张图纸。 |
| {{key:Ctrl+Shift+F}} | 循环切换全屏模式（在所有平台上均为Control键，Mac上也是如此）。 |
| {{key:F1}} | 在侧边打开或关闭本帮助面板。 |
| {{key:3}} | 开启或关闭图纸的3D检查视图。 |

## 3D视图

| 按键或操作 | 作用 |
|---|---|
| 拖动，或用中键拖动 | 旋转。 |
| {{key:Shift}}+拖动，或用右键拖动 | 平移。 |
| 鼠标滚轮 | 以指针位置为中心缩放。在触控板上，双指滑动为旋转，捏合为缩放。 |
| 单击 | 选中指针下的标记（按住{{key:Shift}}并单击可加入或移出选择）。 |
| {{key:F}}或{{key:W}} | 范围缩放。 |
| {{key:3}} | 返回平面图纸。 |

参见[在3D中检查算量](topic:check-in-3d)。

## 自动计数

| 按键或操作 | 作用 |
|---|---|
| 拖动出一个框 | 框选要搜索的符号（开始搜索）。 |
| 单击匹配框 | 排除该匹配，或将其恢复。 |
| {{key:Esc}} | 取消正在进行的搜索，或放弃审阅。 |

## 帮助

| 按键 | 作用 |
|---|---|
| {{key:F1}} | 打开或关闭帮助面板（也可通过应用栏中的{{ui:帮助}}按钮）。在所有工具下均可使用，即使正在输入框中输入。 |
| {{key:Esc}} | 关闭帮助面板。在其搜索框中，第一次按{{key:Esc}}会清除搜索。面板打开时，若在单击图纸后按{{key:Esc}}，会先关闭面板；再按一次则在TakeoffCraft中取消操作。 |

:::mac
许多Mac键盘的顶行用于控制亮度和声音。按fn加F1，或在“系统设置”的“键盘”下开启“将F1、F2等键用作标准功能键”。
:::

| 按键 | 作用 |

## 平台说明

:::mac
- {{key:Mod}}即Command键：{{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。全屏例外：Control+Shift+F。
- 在触控板上，只要在“系统设置”的“触控板”下开启了辅助点按，双指点按即为右键单击。TakeoffCraft只识别辅助按键；Control+单击可能被当作普通单击而添加一个点。
- 在触控板上双指滚动会缩放图纸（而不是滚动）。若要平移，请按住并拖动，或按住空格键并拖动。
- 在没有Page Up和Page Down键的键盘上，它们分别是fn加上、下方向键。
- Backspace即标有delete的键。
:::

:::windows
- {{key:Mod}}即Ctrl：{{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。
- 在笔记本触控板上，双指滚动会缩放图纸。若要平移，请按住并拖动。
:::

:::linux
- {{key:Mod}}即Ctrl。某些桌面环境有其自身的Ctrl+Alt或Super快捷键；TakeoffCraft不使用这些快捷键。
- 在触控板上，双指滚动会缩放图纸。若要平移，请按住并拖动。
:::

:::touch
TakeoffCraft将触摸识别为单一指针：

- 轻触可放置一个点、选中一个标记或添加一个计数点。
- 单指拖动可平移图纸（在{{ui:自动计数}}中则会绘制搜索框）。
- 尚不支持双指捏合缩放。请使用{{ui:适合页面}}和{{ui:适合宽度}}，或在键盘上使用{{key:Plus}}和{{key:Minus}}。
- 要闭合一个面积，请轻触其第一个点。要结束一段线，请在浏览器将双击识别为双击事件的位置双击，或在键盘上按{{key:Enter}}。
- 由于没有悬停，在你轻触之前不会显示实时长度。

目前，键盘加鼠标或触控板是进行算量更好的方式。
:::

## 浏览器保留的按键

浏览器会自行保留一些快捷键，页面无法使用它们：关闭标签页（{{key:Mod+W}}）、新建标签页或窗口（{{key:Mod+T}}、{{key:Mod+N}}）以及浏览器缩放（{{key:Mod+Plus}}、{{key:Mod+Minus}}）。因此，TakeoffCraft用滚轮以及单独的{{key:Plus}}和{{key:Minus}}键来缩放图纸。若你误按了{{key:Mod+Plus}}，整个页面会变大；按{{key:Mod+0}}即可恢复。参见[按键、鼠标和触控板](common:keys)。

## 移动命令的位置

没有“移动”命令：选中一个计数点并拖动即可，或选中一个面积或线并拖动其角控点。

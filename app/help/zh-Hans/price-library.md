**价格库**保存你在一个又一个项目中反复使用的项目：它们的类型、单位、高度、损耗、材料和人工单价，以及它们的组合。它保存在本浏览器中，独立于任何算量，因此你在这里打开的每个算量都可以使用它。

在{{ui:分项}}面板顶部使用{{ui:价格库}}将其打开。

## 填充价格库

- {{ui:导入CSV…}}会读取保存为CSV的电子表格（参见下方的列）。名称和类型都已在库中的项目会被替换；其余的会被添加。无法读取的行会被跳过，并会说明是哪些行以及原因。
- {{ui:添加本算量的分项}}会将打开的算量中的每个分项，连同其单价和组合（不含其标记），复制到库中。
- TakeoffCraft导出的估算CSV（[导出估算](topic:export-estimate)）可以原样导入：上一个工程的价格会用于下一个工程。

- {{ui:专业包…}}会添加某一专业的免费组合，例如干墙、电气或混凝土，但不含价格。参见[专业包](topic:trade-packs)。

{{ui:导出CSV}}会将库保存为CSV，用于备份、在电子表格中编辑，或分发给同事。{{ui:清空}}会清空库（需点击两次）。

:::note
价格库保存在本浏览器的存储中。其他浏览器、其他计算机或隐私窗口都有各自的库（或者没有库）。请导出后再迁移。
:::

## 在算量中使用

- 勾选项目（可在{{ui:在价格库中查找}}中输入内容以缩小列表），然后选择{{ui:添加到算量}}。它们会连同其组合一起，在一个步骤中添加，可用{{key:Mod+Z}}一次撤销。若算量中已有同名项目，则会加上编号，例如`Carpet (2)`。
- {{ui:更新价格}}会为算量中的项目赋予库中的损耗和单价，适用于名称和类型都与库项目匹配的每个项目，同名的组合组件也同样适用。高度、单位和公式保持不变。一次{{key:Mod+Z}}即可将所有旧价格恢复。

## CSV的列

第一行为列名，顺序不限；其他列会被忽略。

| 列 | 填写内容 |
|---|---|
| Item (or Name) | 项目名称。必填。 |
| Type | Linear、Area或Count（LF、SF和EA也可以）。留空时由单位决定。 |
| Unit | LF或m；SF、SY或m²；EA。留空：该类型的常用单位。 |
| Waste % | `10`或`10%`。 |
| Material per unit, Labor per unit | 单价，例如`2.10`或`$1,250`。 |
| Height (or Depth) | `9'-0"`、`9`，或公制单位下的`2.7`。 |
| Component, Formula | 带有Component名称（或类型为`Component`）的行，属于其上方项目的组合的一部分。其单位、损耗和单价各自独立；其公式使用项目的字母代号，参见[组合与公式](topic:assemblies)。 |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

列之间使用逗号、分号或制表符均可。

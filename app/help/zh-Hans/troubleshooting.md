TakeoffCraft 会在窗口底部的状态栏中说明大多数被拒绝的操作。请在下面找到对应的消息。

## 打开文件

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 无法加载 PDF 阅读器。请重新加载页面后再试。 | 应用的 PDF 阅读器未能加载，通常是因为你处于离线状态，而且从未将应用保存以供离线使用。 | 重新连接并重新加载。然后选择{{ui:Save for offline}}，等待{{ui:Offline ready}}出现；参见[离线使用](common:offline)。 |
| （文件名）受密码保护。请打开未加密的副本。 | 打开该 PDF 需要密码。 | 请对方提供未加密的副本，或在你信任的 PDF 程序中移除密码。 |
| （文件名）无法作为 PDF 读取（…） | 文件已损坏，或者它实际上不是 PDF。 | 重新下载，或从生成它的程序中重新保存。 |
| （文件名）已打开。 | 相同内容的 PDF 已打开。 | 无需操作。 |
| TakeoffCraft 可打开 PDF 和 .takeoff.json 项目。已跳过：… | 其他文件类型已被丢弃。 | 请先将图纸转换为 PDF。 |
| 拖放文件后没有反应 | 文件被拖放到浏览器窗口之外，或浏览器在新标签页中打开了 PDF。 | 请拖放到 TakeoffCraft 页面本身；当可以拖放时，“拖放 PDF 或 .takeoff.json”框会显示出来。 |
| 打开大套图纸需要一些时间 | 为了生成指纹，每个 PDF 都会被完整读取。 | 等待“正在打开（文件名）…”消息消失。滚动时缩略图会逐渐显示。 |

## 测量

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 请先打开 PDF。 | 没有打开任何图纸。 | 打开 PDF。 |
| 此图纸尚未设置比例，因此无法测量。请先选择预设比例或进行校准（计数无需比例）。 | 线性、面积、圆和洞口工具需要比例。 | [设置比例](topic:set-the-scale)。 |
| 请先创建一个线性分项（在分项下命名），然后在图纸上点击。 | 没有该类型的分项。 | 填写打开的{{ui:New item}}表单，然后选择{{ui:Add}}。 |
| 请先选择要算量的分项（分项面板）。 | 当前分项已被删除。 | 点击{{ui:Items}}下的一个分项。 |
| 一条线段至少需要两个点。 | 你只点击了一次就结束了。 | 至少点击两个点。 |
| 面积至少需要三个点。 | 角点太少。 | 至少点击三个角点。 |
| 轮廓自相交，因此其面积会出错。请重新绘制，避免交叉。 | 8 字形。 | 将其绘制为两个面积，或按顺序沿边缘绘制。 |
| 这些点没有围成任何面积。 | 所有点都在同一条直线上。 | 点击能围成一个区域的角点。 |
| 请先选择一个面积标记（选择工具），然后选择洞口并在其中绘制孔洞。 | {{ui:Cut-out}}需要先选中一个面积。 | 按{{key:V}}，点击该面积，然后按{{key:X}}。 |
| 洞口必须完全位于面积之内。 | 孔洞与轮廓相交或超出轮廓。 | 在面积内绘制孔洞。 |
| 洞口之间不能重叠。 | 两个孔洞重叠。 | 绘制一个包围两者的孔洞，或将它们分开。 |
| … 该点已被放回原位。 | 拖动的角点会使轮廓自相交，或将孔洞推到外部。 | 拖动到能保持图形有效的位置。 |
| 请在圆的边缘（远离圆心处）点击一个点。 | 第二次点击离圆心太近。 | 点击得更远一些。 |
| 点击时平移图纸，而不是添加点 | 按住按钮时指针移动超过了几个像素；这会被视为拖动。 | 点击时保持不动，尤其是在触控板上。 |
| Shift 不起吸附作用 | 你正在圆弧上放置点，或正在绘制圆。 | 45° 吸附仅适用于直线段。 |
| 点跳到附近的线上 | 已开启捕捉到图纸线条。 | 放大视图以在线条之间点击，或按{{key:F3}}关闭捕捉。 |
| 没有出现捕捉标记 | 捕捉已关闭、图纸是扫描件，或该工具不使用捕捉（计数、自动计数、粘贴）。 | 按{{key:F3}}；扫描件上没有可吸附的线条。 |
| 长度不正确 | 比例不正确（通常是 PDF 被缩放后又使用了预设）。 | 对已知尺寸使用{{ui:Check}}，然后使用{{ui:Calibrate}}。 |

## 比例

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 请选择距离更远的两个点。 | 校准点几乎重叠在一起。 | 使用更长的尺寸进行校准。 |
| 校准对话框中的消息，例如“无法读取该距离” | 距离的格式 TakeoffCraft 无法读取。 | 参见[长度、单价和百分比输入](topic:entry-formats)。 |
| 此图纸尚未设置比例，因此无可核对的内容。请对其进行校准，或选择预设。 | 在未设置比例的图纸上使用{{ui:Check}}。 | 请先设置比例。 |
| {{ui:Preset}}列表呈灰色 | 没有打开任何图纸。 | 打开 PDF。 |

## 工程量和公式

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 不完整：…（未计入合计） | 公式错误，或标记位于未设置比例的图纸上。 | 参见[阅读工程量和估算](topic:read-quantities#the-incomplete-warning)。 |
| 分项旁显示 +(n) 未设比例 | 其部分标记位于未设置比例的图纸上。 | 为这些图纸设置比例。 |
| 公式错误：… | 无法计算该公式。 | 参见[公式语言](topic:formulas#errors)。 |
| 该分项已有标记，因此其类型无法更改。 | 有标记后，类型即被锁定。 | 创建另一种类型的新分项，并用它重新绘制标记。 |
| 分项需要名称。 | 名称字段被清空。 | 输入名称。 |
| 请输入类似12.50的金额。/ 请输入类似10或7.5的百分比。 | 无法读取单价或损耗。 | 参见[长度、单价和百分比输入](topic:entry-formats)。 |
| 合计似乎翻倍 | 该分项自身的单价和组件承载了相同的成本。 | 当组件已承载成本时，将分项自身的单价设为0。 |
| 该分项的标记位于未打开的 PDF 上。 | 你点击的分项，其所有标记都位于你未打开的 PDF 上。 | 打开这些 PDF；它们的名称列在{{ui:Sheets}}下。 |

## 自动计数

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 该框太小。请围绕整个符号绘制。 | 框非常小。 | 放大视图，并用框选整个符号。 |
| 该框几乎是空的。请围绕一个符号绘制。 | 框内只有图纸空白。 | 框选符号本身。 |
| 没有匹配项。请降低匹配度滑块，或更紧地框选符号。 | 没有任何结果得分足够高。 | 紧密框选符号，或将{{ui:Match}}滑块向下拖动。 |
| 匹配项过多，包括错误的符号 | 相似的符号得分接近真实符号。 | 提高{{ui:Match}}滑块，并点击错误的框以将其剔除。 |
| 其他图纸上缺少匹配项 | 这些图纸上的符号尺寸不同，或角度不是90°的倍数。 | 在这些图纸上绘制框进行搜索，或手动计数。 |
| （n）张图纸对于此符号尺寸而言太大，无法搜索。 | 按工作尺寸计算，该图纸会过大。 | 框选更大的符号，或手动计数该图纸。 |
| 搜索失败：… | 后台搜索已停止。 | 请重试；如果再次出现，请重新加载页面（先保存）。离线时，只有当应用栏显示{{ui:Offline ready}}后才能使用。 |
| 拖动时绘制框而不是平移 | 这就是{{ui:Auto count}}的工作方式。 | 按住{{key:Space}}并拖动，或用鼠标中键拖动。 |

## 保存和导出

| 消息或症状 | 原因 | 解决方法 |
|---|---|---|
| 尚无可导出的内容：请创建一个分项并进行算量。 | 没有任何分项。 | 请先创建一个分项。 |
| 已打开的 PDF 上尚无标记。 | {{ui:Marked PDF}}无法在已打开的 PDF 上绘制任何内容。 | 打开带有标记的 PDF。 |
| 此 PDF 受密码保护或已加密，因此无法写入带标记的副本。… | 该 PDF 已加密。 | 改为导出{{ui:XLSX}}，或使用未加密的 PDF 副本（由于它是不同的文件，因此需要单独的算量）。 |
| 无法写入带标记的 PDF：… | 通常是因为：处于离线状态，且应用未保存以供离线使用，因此缺少 PDF 写入组件。 | 联网后再次选择{{ui:Marked PDF}}。为避免此情况，请选择{{ui:Save for offline}}，并等待{{ui:Offline ready}}出现。 |
| 只下载了一个带标记的 PDF | 浏览器阻止了同时进行的多个下载。 | 允许此网站进行多次下载，然后重新导出。 |
| （文件）不是 TakeoffCraft 项目（不是有效的 JSON）。/ 这不是 TakeoffCraft 项目文件。 | 文件错误，或文件已损坏。 | 选择 `.takeoff.json` 文件。 |
| 此项目由较新版本的 TakeoffCraft 保存。请在该版本中打开。 | 该文件来自较新的版本。 | 在较新的版本中打开它。 |
| （n）个标记已损坏并被排除。 | 文件的一部分已损坏或被手动编辑。 | 其余部分已打开。请重新绘制缺失的标记，或打开较旧的副本。 |
| 重新打开后标记缺失 | PDF 未打开，或其中一个已更改。 | 参见[保存并重新打开算量](topic:save-and-reopen#when-a-pdf-has-changed)。 |
| 浏览器询问“离开网站？” | 有未保存的更改。 | 留在页面，并使用{{key:Mod+S}}保存。 |

## 键盘和鼠标

| 症状 | 原因 | 解决方法 |
|---|---|---|
| 字母键无反应 | 光标位于某个输入框中（搜索、分项编辑器、表格）。 | 点击图纸，或按{{key:Tab}}离开该输入框。 |
| 滚轮是缩放而不是滚动 | 滚轮始终用于缩放图纸。 | 拖动以平移。 |
| 整个页面变大或变小了 | 浏览器缩放（{{key:Mod+Plus}}或{{key:Mod+Minus}}）。 | 按{{key:Mod+0}}。使用滚轮或单独的{{key:Plus}}和{{key:Minus}}缩放图纸。 |
| 按下 Backspace 后标记消失了 | 在非绘制状态下，Backspace 会删除所选标记。 | {{key:Mod+Z}}可将其恢复。 |
| 在 Mac 上右键单击无法结束 | Control 点击被当作普通点击。 | 开启辅助点击后使用双指点击，或按{{key:Enter}}。 |

## 触摸屏

在触摸屏上：

- **轻触**放置一个点（或使用{{ui:Select}}选择标记）。单指拖动可平移。
- **双指**捏合以围绕两指之间的点缩放，并在两指一起移动时平移。放下第二根手指会取消第一根手指已开始的操作，因此捏合操作不会留下一个点。
- 使用**长按**（相当于右键单击）、**双击**，或图纸底部栏中的{{ui:Finish}}来**完成**一条线段或一个轮廓。同一栏中还有{{ui:Back}}（撤回最后一个点）和{{ui:Cancel}}。面积也可以通过点击第一个点来闭合。
- 手指操作的目标更大：点会从更远的距离吸附、闭合和选取，角点手柄也更大。

输入长度需要键盘；当{{ui:Type}}输入框获得焦点时，屏幕键盘即可使用。

在平板电脑上，键盘加鼠标或触控板会使算量容易得多。

## 离线使用

| 按钮或症状 | 原因 | 解决方法 |
|---|---|---|
| {{ui:Could not save}} | 在保存以供离线使用时，部分应用文件未能下载。 | 检查网络连接，然后再次选择该按钮。 |
| {{ui:Offline not available}} | 隐私窗口和部分受管理的计算机会阻止离线副本。 | 使用普通窗口，或使用其他浏览器。 |
| “正在保存…”从未开始 | 你处于离线状态；保存需要网络连接。 | 在联网时保存。 |
| 更新后应用仍是旧版本 | 离线副本来自较早的日期。 | 联网后，选择{{ui:Offline ready}}，然后选择{{ui:Save again (get the newest version)}}。 |
| 你想收回空间 | 离线副本约为6 MB。 | 选择{{ui:Offline ready}}，然后选择{{ui:Remove the offline copy}}。 |

参见[离线使用](common:offline)。

## 仍未解决

如果应用停止响应，请重新加载页面。除非你已保存，否则重新加载后算量将丢失，因此如果可以，请先使用{{key:Mod+S}}保存。有关浏览器问题，请参见[浏览器和计算机](common:browsers)。

每张图纸都有自己的比例。你可以自行设置，也可以让 TakeoffCraft 从图纸文字中读取（见下文），然后进行核对。在图纸设置比例之前，{{ui:线性}}、{{ui:面积}}、{{ui:圆}}和{{ui:洞口}}都会拒绝对其进行测量。{{ui:计数}}和{{ui:自动计数}}无需比例即可使用。

图纸列表显示每张图纸的比例，或**未设比例**。打开图纸下方的栏显示相同信息。

## 使用预设（当 PDF 按实际尺寸打印时）

1. 打开图纸。
2. 打开{{ui:比例}}组中的{{ui:预设}}列表。
3. 选择图纸上标注的比例，例如建筑下的 `1/8" = 1'-0"`。
   状态栏显示：“此图纸的比例：1/8" = 1'-0"。”
4. 进行核对（见下文）。

预设假定 PDF 为绘图时所用的实际纸张尺寸。如果 PDF 是通过“适应页面”生成的，或是半尺寸图纸集，则该预设是错误的。请改为校准。

完整列表见[比例预设](topic:scale-presets)。

## 从图纸文字中读取比例

大多数图纸都会标注比例：标题栏中的 `SCALE: 1/4" = 1'-0"`，或视图下方的 `1:100`。TakeoffCraft 可以读取这些内容，并一次性设置所有图纸的比例。

1. 打开{{ui:预设}}列表，选择顶部的{{ui:从图纸文字…}}。
2. 列表显示每张图纸：其当前比例，以及其文字所述内容——**文字标注 1/4" = 1'-0"**、**文字中无比例**或**文字标明不按比例**（NTS）。
3. 未设比例但文字中标注了比例的图纸会被勾选。可以勾选或取消勾选任意图纸，然后选择{{ui:设置已勾选的比例}}。按{{key:Mod+Z}}可一次性全部撤销。
4. 使用下文的{{ui:核对}}检查每张图纸上的一个尺寸：只有当 PDF 按实际尺寸打印时，预设才是正确的。

它可以识别与[预设](topic:scale-presets)相匹配的建筑（`3/16" = 1'-0"`、`1 1/2" = 1'-0"`）、工程（`1" = 20'`）和公制（`1:50`）标注方式。当一张图纸标注了多个比例（例如带有放大详图的平面图）时，它会采用出现次数最多的比例，紧跟在 SCALE 一词后的比例计为两次；其他比例则以红色显示，以便你核对。扫描图纸没有文字，需手动设置其比例。

## 根据已知尺寸校准

当你不信任图纸上的任何印刷比例、图纸集经过缩放，或图纸标注“不按比例”但带有尺寸时，请使用此方法。

1. 打开图纸，放大你已知的长尺寸，例如轴线间距或建筑总尺寸。尺寸越长，结果越精确。
2. 在{{ui:比例}}组中选择{{ui:校准}}，或按{{key:K}}。
3. 点击尺寸的一端。在每一端放大以提高精度；在两次点击之间可以缩放和平移。
4. 点击另一端。按住{{key:Shift}}可使线条保持在 0°、45° 或 90°。
   随即打开**校准此图纸**对话框。
5. 在**实际距离**中输入真实距离，例如 `24'-6 1/2"`、`24.5`（十进制英尺）、`30"` 或 `7.5 m`。参阅[长度、单价与百分比输入](topic:entry-formats)。
6. 选择{{ui:设置比例}}。
   状态栏将比例显示为“1" = (n)'”；当其与某个预设的差值在 0.5% 以内时，它会说明是哪个预设，例如“与 1/4" = 1'-0" 匹配（如需精确比例，请选择该预设）”。
   TakeoffCraft 将返回{{ui:选择}}工具。

当校准结果与某个预设匹配时，选择该预设可获得精确比例，而不是取决于你点击位置的比例。

## 核对比例

始终使用第二个尺寸核对新比例。

1. 在{{ui:比例}}组中选择{{ui:核对}}，或按{{key:D}}。
2. 点击图纸上标注的某个尺寸的两端。
   状态栏显示“核对：12'-6"”，并以十进制英尺和米显示相同长度；核对线会保留在图纸上并标注其长度。
3. 与标注的尺寸进行比较。如果偏差较大，请在更长的尺寸上重新校准。

按{{key:Esc}}可清除核对线。

## 更改比例

选择另一个预设或重新校准。如果图纸已有测量结果，TakeoffCraft 会询问**更改此图纸的比例？**并说明将重新测量多少个测量值。选择{{ui:更改比例}}。图纸上的每个线段和区域都会以新比例重新测量。可以用{{key:Mod+Z}}撤销。

## 为何未设比例的图纸不计为零

未设比例的图纸上的标记没有实际长度或面积。TakeoffCraft 绝不会将其计为零，否则会悄无声息地使估算偏低。因此它会：

- 将这些标记排除在合计之外，
- 在{{ui:工程量}}中的分项旁显示“+(n) 个未设比例”，
- 在表格标题中显示“未完成：(n) 个标记位于未设比例的图纸上（未计入合计）”，
- 将数量写入导出电子表格的备注列。

当你打开一个从未设置比例的项目时，可能会出现这种情况。为图纸设置比例后，标记会立即计入。计数标记始终计入；它们不需要比例。

## 提示

- 在开始测量前，为你将要测量的每张图纸设置比例。在图纸列表中查找**未设比例**，即可找到尚未设置的图纸（搜索框搜索的是图纸名称，而非比例）。
- 同一张图纸上的详图和放大平面图通常使用另一种比例。TakeoffCraft 每张图纸只有一个比例；请参阅[尚未实现](topic:not-built-yet)。
- 公制图纸：选择公制预设，例如 `1:100`，或使用公制距离进行校准，例如 `6000 mm`。

## 造价估算（XLSX 工作表和 CSV）

每个项目占一行，其后为其组合中每个组件各占一行（缩进显示）。然后是一个空行和总计行。

| 列 | 内容 | 在 XLSX 中 |
|---|---|---|
| A 项目 | 项目名称（粗体）或组件名称（缩进） | 文本 |
| B 类型 | 线性、面积、计数或组件 | 文本 |
| C 单位 | LF、m、SF、SY、m²、EA，或组件的单位 | 文本 |
| D 工程量 | 测量总量，或公式结果 | 数字 |
| E 损耗% | 损耗 | 百分比（0.10 = 10%） |
| F 含损耗工程量 | 工程量 ×（1 + 损耗） | 公式 `D*(1+E)` |
| G 每单位材料 | 材料单价 | 数字 |
| H 每单位人工 | 人工单价 | 数字 |
| I 材料 | 材料金额 | 公式 `ROUND(F*G,2)` |
| J 人工 | 人工金额 | 公式 `ROUND(F*H,2)` |
| K 合计 | 材料 + 人工 | 公式 `I+J` |
| L 备注 | 所用公式、公式错误、无比例图纸上的标记、墙面积、周长 | 文本 |

总计行：对上方所有行的 I、J 和 K 列使用 `SUM` 求和；若有遗漏内容，则在备注中显示“不完整：请参见上方备注”。

公式出错的行没有工程量和金额；其备注会给出错误信息。表头行已冻结。

在 CSV 中，各列均为纯数值；损耗% 为百分比数字（10 表示 10%），金额以美元计，保留两位小数。电子表格可能误认为公式的文本（以 `=`、`+`、`-` 或 `@` 开头）前会加上 `'`，使其保持为文本。

## 按图纸（仅 XLSX）

| 列 | 内容 |
|---|---|
| 图纸 | 图纸名称（未打开时附带 PDF 名称） |
| 项目 | 项目名称 |
| 工程量 | 该项目在该图纸上的工程量，以其单位计 |
| 单位 | 项目的单位 |
| 标记 | 标记数量 |

## 标记（仅 XLSX）

每个标记占一行。

| 列 | 内容 |
|---|---|
| 图纸 | 图纸名称 |
| 项目 | 项目名称 |
| 类型 | 线性、面积或计数 |
| 工程量 | 长度、净面积，或 1 |
| 单位 | LF 或 m；SF、SY 或 m²；EA |
| 细节 | 线性：各段长度，被扣减的段标注“(deduct)”，以及“已绘制 (length) 中扣减 (length)”。面积：存在洞口时的毛面积和洞口面积，以及周长。无比例的标记显示“图纸没有比例”。 |
| 投标范围 | 仅当算量包含投标范围时：标记所在的范围，或“无投标范围” |

## 按投标范围（仅 XLSX，当算量包含投标范围时）

| 列 | 内容 |
|---|---|
| 投标范围 | 范围名称，或“无投标范围” |
| 项目 | 项目，或其下缩进的组件 |
| 单位 | 项目或组件的单位 |
| 工程量 | 该范围内的测量值（组件：基于该范围合计的公式） |
| 含损耗工程量 | 工程量 ×（1 + 损耗） |
| 材料、人工、合计 | 精确到分计算，与造价估算相同 |
| 备注 | 公式、错误和无比例标记，与造价估算相同 |

每个范围以“(name) 小计”行结束，其金额为对其各行求和的 `SUM` 公式；最后一行 **全部投标范围** 汇总各小计。**标记**工作表随后会有第七列 **投标范围**。

## 比例（仅 XLSX）

每个具有比例或标记的图纸占一行。

| 列 | 内容 |
|---|---|
| 图纸 | 图纸名称 |
| 比例 | 预设名称，或校准后的比例，或“无比例” |
| 方式 | “预设”，或“按（输入的距离）校准” |
| 每个 PDF 单位的英尺数 | TakeoffCraft 使用的精确比例系数 |

## 文件名

- `(name).xlsx` 和 `(name).csv`，其中名称取自算量中打开的第一个 PDF。
- CSV 为带字节顺序标记的 UTF-8 编码，并使用 Windows 换行符，各平台的电子表格程序均可读取。

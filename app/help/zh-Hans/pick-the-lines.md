在矢量PDF中，墙体和边线都是真实的线条。{{ui:路径}}({{key:P}})会按线条的绘制方式获取它们：单击一条线，即可测量与之相连的所有线条，从头到尾，因此你无需通过单击墙角来描摹墙体。图纸需要有比例。扫描页面没有可拾取的线条；这种情况下请使用[线性](topic:measure-linear)或[面积](topic:measure-areas)。

## 拾取路径或轮廓

1. 选择{{ui:路径}}。指针下方的线条会被勾勒出来，其他可能与之相连的路径会以细线显示。
2. 单击一条线：整个相连路径即被拾取。工具栏下方的栏会显示其段数、长度、间隙容差以及被桥接的间隙数。回到起点的路径为闭合路径，并会同时报告其周长。
3. 或者在远离任何线条的闭合轮廓内部单击：该点周围的轮廓会被拾取为一个面积。最小的轮廓优先；按{{key:Tab}}可切换到下一个较大的轮廓。
4. 按{{key:Enter}}（或右键单击，或双击）添加标记。拾取的路径会成为**线性**分项的一个标记，轮廓则会成为**面积**分项的一个标记：优先使用当前分项（若其类型相符），否则使用同类型中最新的分项。若没有分项，则会打开新建分项表单，在你再次按{{key:Enter}}之前不会添加任何内容。所有拾取的内容会在一个撤销步骤中添加。

## 间隙容差

绘图员常会在线条应当相交处留下小缝隙。当两条线的端点距离小于**间隙容差**时，它们会被连接。容差初始值为图纸上的1.5点（按图纸比例以英尺和英寸显示），并且一个同样宽的虚线圆环会跟随指针，位于其下路径的每个端点上。每个被桥接的缝隙在拾取的路径上都会以橙色圈出，栏中也会统计其数量。

{{key:]}}使容差变宽，{{key:[}}使其变窄。拾取的路径会立即按新的容差重新连接。在交汇处，路径会沿弯曲最小的方向继续前进，并离开分支。

## 按键

| 按键或操作 | 作用 |
|---|---|
| 单击 | 拾取指针下方的路径，或其周围的轮廓。 |
| {{key:Shift}}+单击 | 将另一条路径或轮廓添加到已拾取的内容中。 |
| {{key:Tab}} | 尝试指针下方的下一条路径，或下一个较大的轮廓。 |
| {{key:Backspace}}或{{key:Mod+Z}} | 从最后拾取的路径上去掉最后一段，每次一段。没有段的路径会被移除。若未拾取任何内容，{{key:Mod+Z}}即为普通撤销。 |
| {{key:[}}和{{key:]}} | 更窄和更宽的间隙容差。 |
| {{key:Enter}} | 添加标记。 |
| {{key:Esc}} | 清除已拾取的内容。 |

## 注意事项

- 图形中的曲线由多段短直线组成，因此其长度略小于真实弧长。若需要精确的圆弧，请测量图形自身的文件（[从图形测量](topic:measure-from-a-drawing)）。
- 被桥接的缝隙会按跨越它的一条直线计算，因此闭合轮廓的周长会包含它。
- 只有页面自身路径中的笔画和填充才算作线条。以字母绘制的文字和图片都不算。

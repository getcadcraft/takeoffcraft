线性分项用于测量长度。每条线段都是一串点：由直线段组成，并在开启圆弧模式的位置包含圆弧。一个分项可以在任意数量的图纸上包含任意数量的线段。

开始之前：图纸需要设置比例（[设置比例](topic:set-the-scale)），并且你需要一个线性分项（[创建算量分项](topic:create-items)）。

在矢量PDF上，你的单击会捕捉到图纸自身的线条：端点、中点和交点（[捕捉到图纸线条](topic:snap-to-the-drawing)；{{key:F3}}可将其关闭）。

## 绘制一段线

1. 单击{{ui:分项}}下的线性分项。
2. 在工具栏中选择{{ui:线性}}，或按{{key:L}}。
3. 单击线段的起点。
4. 沿线段依次单击每个角。
   状态栏以英尺和英寸显示“长度”（到指针为止的已绘制部分）和“线段”（你正在绘制的线段）。
5. 结束该线段：双击最后一个点、按{{key:Enter}}或右键单击。
   该线段会以分项的颜色绘制，并成为选中的标记。{{ui:分项}}列表和{{ui:工程量}}表中该分项的长度随之增加。

该工具保持在{{ui:线性}}状态，因此你可以立即开始下一段。按{{key:Esc}}返回{{ui:选择}}。

绘制时：

- {{key:Backspace}}（或{{key:Delete}}）会删除最后一个点。
- {{key:Esc}}会放弃未完成的线段。
- 拖动会平移图纸，滚轮会缩放，但都不会添加点。

:::mac
在Mac触控板上，右键单击为双指点按（需在“系统设置”的“触控板”下开启辅助点按）。TakeoffCraft只识别辅助按键，因此Control+单击可能被当作普通单击而添加一个点。双击或按{{key:Enter}}始终会结束绘制。
:::

:::touch
在触摸屏上，轻触可放置点，单指拖动可平移，双指捏合可缩放。可通过长按、双击，或图纸下方栏中的{{ui:完成}}来结束绘制（{{ui:后}}会撤回最后一个点）。参见[故障排除](topic:troubleshooting#touch-screens)。
:::

## 以45°为步进绘制直线

在放置点时按住{{key:Shift}}。从上一点出发的线段会捕捉到最接近的0°、45°、90°或135°方向，并保持你沿该方向拖动的长度。状态栏会提示：“Shift捕捉到45°”。

在圆弧模式下，它作用于圆弧的终点：圆弧的弦会以45°为步进，从其起点开始。你在曲线上单击的点永远不会被捕捉。

## 圆弧和弧形墙

1. 在绘制线段时，在曲线的起点放置一个点。
2. 开启圆弧模式：在工具栏中选择{{ui:圆弧}}，或按{{key:R}}。该按钮保持按下状态。
3. 在曲线上的任意一点（大致位于其中部）单击。
   状态栏会添加“（圆弧：单击终点）”，预览线会弯曲经过你所单击的点。
4. 单击曲线的终点。
   圆弧即被添加。其长度为精确的圆弧长度，而不是多段短弦的和。
5. 在下一段曲线上单击一点及其终点，即可继续绘制圆弧；或再次按{{key:R}}，返回直线段。

{{key:Backspace}}或{{key:Esc}}会先放弃曲线上待定的点；再次按下则如常删除点。

## 输入长度和坐标

在第一个点之后，你可以输入下一个点的位置，而无需单击。输入数字、`@`或`#`：状态栏中会打开{{ui:输入}}框，显示你已输入的内容。按{{key:Enter}}放置该点；该框保持打开，用于下一个点。

| 输入 | 下一个点位于 |
|---|---|
| `12'6"` | 距上一点12'-6"，朝向指针方向（先指明方向，再输入长度） |
| `12'6"<45` | 距上一点12'-6"，角度为45°，从屏幕右侧起逆时针计算（`<90`为向上，`<-90`为向下） |
| `@6',-4'` | 距上一点向右6'、向下4' |
| `6',4'`（或`#6',4'`） | 距本段第一个点向右6'、向上4' |

长度的输入方式与TakeoffCraft中的其他地方相同（[输入格式](topic:entry-formats)）：`12'-6 1/2"`、`12.5`（英尺）、`30"`、`3.2 m`。“向右”和“向上”均以你在图纸上看到的为准，即使PDF页面已旋转。

在空白框中按{{key:Enter}}会结束该线段，与在图纸上按{{key:Enter}}相同；{{key:Esc}}会关闭该框并保留线段。输入的点与单击的点遵循相同的规则：扣减、圆弧以及闭合面积均可使用。同样的输入框也可用于{{ui:面积}}和{{ui:洞口}}；在圆心之后，它会接受半径。

## 扣减线段的一部分

穿过门或店面的墙体线段，可以一直绘制通过，但只计算墙体：开口处的线段为**扣减**。它们以细虚线绘制，且不计入。

绘制时：

1. 在开口起点放置一个点。
2. 在工具栏中选择{{ui:扣减}}，或按{{key:E}}。该按钮保持按下状态，状态栏会说明后续线段为扣减。
3. 单击开口的终点。该线段以虚线绘制；状态栏中的“长度”不包括它。
4. 再次按{{key:E}}，然后沿墙体继续绘制。

绘制完成后：选中该线段。在**选中的标记**下，每个线段都有一个{{ui:扣减}}框：勾选即扣减该线段，取消勾选则重新计入。每次更改均为一步撤销。

一段线始终至少保留一个计入的线段。面板会显示**扣减**（被扣减的长度）和**绘制**（整段线的长度）；**长度**、分项的数量、墙面面积和成本均使用不含扣减的长度。3D检查视图会在墙体中留出空隙，标记PDF会以虚线绘制扣减，导出的**标记**工作表会列出它们。

移动角点会保留扣减。添加或删除点（通过重新绘制该线段）则从无扣减状态开始。

## 查看线段详情

选择{{ui:选择}}（{{key:V}}），然后单击该线段。右侧的**选中的标记**显示：

- 其所属分项（在列表中选择另一个线性分项即可将线段移至该分项），
- 图纸，
- 以英尺和英寸以及LF显示的**长度**，
- **线段**数量，以及当分项设有高度时的**墙面面积**，
- 每个线段的长度（圆弧后标注“（圆弧）”）及其{{ui:扣减}}框。

在图纸上，选中线段的每一段都会标注其长度。

## 修正线段

- **移动点**：选中线段，然后拖动其中一个方形角控点。按住{{key:Shift}}可将被移动的线段捕捉到45°步进。圆弧会保留其凸度。
- **弯曲圆弧**：选中的线段会在每段圆弧中部显示一个圆形控点。拖动它：圆弧会经过你松开鼠标的位置，因此可以更凸、更平，或向另一侧弯曲。若将其拖到两端之间的直线上，它会变为直线段。{{key:Mod+Z}}可撤销该操作（“弯曲圆弧”）。
- **删除线段**：选中后按{{key:Delete}}，在工具栏的{{ui:更多}}菜单中选择{{ui:删除}}，或在面板中选择{{ui:删除标记}}。
- **撤销**：{{key:Mod+Z}}；重做使用{{key:Mod+Y}}。

目前无法在线段中间插入点。请删除该线段并重新绘制。

## 墙面面积

为线性分项设置{{ui:高度}}（例如`9'-0"`）。随后它会报告**墙面面积（A）**=长度×高度，以SF为单位（公制分项则为m²），墙面面积也会进入电子表格导出的备注列。在构件中可将其用于木板、涂料或保温材料：参见[构件和公式](topic:assemblies)。

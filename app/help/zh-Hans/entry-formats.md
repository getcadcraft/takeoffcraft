## 长度

用于{{ui:校准}}中的**实际距离**，以及项目编辑器中的{{ui:高度}}和{{ui:深度}}。

| 输入内容 | 含义 |
|---|---|
| `24'-0"` | 24英尺 |
| `24'-6 1/2"` | 24英尺6½英寸 |
| `12' 6 1/2"` | 12英尺6½英寸（用空格代替短横线） |
| `12'-6-1/2"` | 12英尺6½英寸（各部分之间用短横线） |
| `24'` | 24英尺 |
| `30"` | 30英寸 |
| `6 1/2"` | 6½英寸 |
| `3/4"` | ¾英寸 |
| `24 ft 6 in` | 24英尺6英寸（也可用 `foot`、`feet`、`inch`、`inches`） |
| `24.5` | 24.5，采用默认单位（见下文） |
| `24.5'` | 24.5英尺 |
| `7.5 m` | 7.5米 |
| `750 cm` | 750厘米 |
| `7500 mm` | 7,500毫米 |

- 纯数字在校准以及 LF、SF 或 SY 单位的项目中表示**英尺**，在 m 或 m² 单位的项目中表示**米**。
- 来自文字处理软件的弯引号和撇号（′ ″ ’ ”）与 `'` 和 `"` 效果相同。两个单引号 `''` 视为 `"`。
- 逗号会被忽略：`1,200 mm` 即 1200 mm。
- 分数两侧都需要整数：`6 1/2"` 可以，`6.5 1/2"` 不行。
- 零和负数距离不被接受。

提示信息：

- “请输入距离，例如 24'-0" 或 7.5 m。”（输入框为空）
- “请输入大于零的距离。”
- “请使用英尺和英寸（24'-6 1/2"）、十进制英尺、m、cm 或 mm。”（单位无法识别）
- “无法识别该距离。请尝试 24'-6 1/2" 或 24.5。”

要清除项目的高度或深度，清空输入框即可。

### 计算

每个长度输入框，以及绘制时的键入框，还支持使用 `+`、`-`、`*`、`/` 和括号进行计算：
`4+7/16`（默认单位下为 4.4375 英寸）、`12'6" + 3/4"`、`(24'-0")/3`（8 英尺）、`2*450mm`。

- 写在长度中的短横线仍属于长度的一部分：`24'-6"` 为 24英尺6英寸，`6-1/2` 为 6½。要做减法，请在短横线两侧加空格：`24' - 6"` 为 23'-6"。
- 纯数字与长度相乘或相除时按数值计算；与长度相加时，则采用默认单位。
- `abs`、`round`、`ceil` 和 `floor` 同样可用。无法识别的计算会被拒绝，并指出出错的位置。

## 长度的显示方式

长度以英尺、英寸和十六分之一英寸显示：`12'-6 1/2"`、`0'-0 3/4"`。显示时数值会四舍五入到最接近的 1/16 英寸；工程量本身不做舍入。十进制数值显示两位小数，并带千位分隔符，例如 `1,234.50 LF`。

## 单价（每单位的材料和人工）

| 输入内容 | 含义 |
|---|---|
| `12.5` | $12.50 |
| `$12.50` | $12.50 |
| `1,250` | $1,250.00 |
| `0.385` | $0.385（最多四位小数，超出部分会被舍入） |
| （留空） | $0 |

提示信息：“请输入金额，例如 12.50。”或“金额过大。”不接受负数单价。

金额（材料、人工、合计）精确到分计算：含损耗的工程量 × 单价，按四舍五入（半数远离零）取整，与电子表格的 `ROUND(x, 2)` 完全一致。

## 损耗百分比

| 输入内容 | 含义 |
|---|---|
| `10` | 10% |
| `7.5%` | 7.5% |
| （留空） | 0% |

最多两位小数，范围为 0% 至 1000%。提示信息：“请输入百分比，例如 10 或 7.5。”或“不允许超过 1000% 的损耗。”

## 名称和单位

- 项目和组件名称：最多 200 个字符。
- 组件的{{ui:单位}}：最多 20 个字符的任意文字，例如 `EA`、`sheets`、`CY`、`gal`。它仅作标签使用；TakeoffCraft 不会进行换算。

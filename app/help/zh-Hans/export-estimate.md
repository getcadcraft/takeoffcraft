导出内容为下载文件。文件在本机根据算量和已打开的 PDF 生成，不会发送到任何地方。

## 造价估算表（XLSX）

1. 在工具栏中打开{{ui:导出}}菜单，选择{{ui:XLSX}}。
   浏览器会下载 `(name).xlsx`。状态栏显示“已导出 (name).xlsx（带实时公式的造价估算，按图纸、标记、比例）。”，若造价估算不完整，还会显示警告。
2. 用电子表格程序打开。

工作簿包含四个工作表，并在适用时包含以下报告：

| 工作表 | 内容 |
|---|---|
| 造价估算 | 每个项目和每个组件各占一行：工程量、损耗、含损耗工程量、单价、材料、人工、合计、备注。底部为总计。 |
| 按图纸 | 每个项目在各图纸上的工程量，以及标记数量。 |
| 标记 | 每个标记：图纸、项目、类型、工程量，以及细节（段长、毛面积和洞口面积、周长）。 |
| 比例 | 每个具有比例或标记的图纸：其比例、设置方式（预设，或按哪个距离校准），以及每个 PDF 单位的英尺数。 |
| 算量汇总 | 每个项目的工程量、CSI编号、标记和图纸，不含价格。 |
| 材料清单 | 算量中所有组合部件的汇总（被多个项目使用的同一部件合并为一行），包括损耗、材料成本以及使用它的项目。 |
| 报价请求 | 发送给供应商的材料清单：含损耗工程量、空白的单价列，以及随价格输入自动填充的合价和总计。 |
| 按分部 | 当项目具有{{ui:CSI编号}}时，按 CSI MasterFormat 分部列出材料、人工和合计。 |

若使用[投标汇总](topic:bid-summary)，造价估算工作表末尾还会列出其加价项（人工附加费、销售税、管理费、利润、保函和投标报价），并以实时公式表示。

造价估算工作表保留**实时公式**：含损耗工程量、取整后的材料和人工金额、每行合计以及总计。电子表格程序会重新计算这些公式，因此可在表格中修改单价或损耗，合计随之更新。TakeoffCraft 计算出的数值也同时保存在单元格中，并精确到分一致。

备注列列出每个组件的公式、公式错误、无比例图纸上的标记、墙面积和周长。若有遗漏内容，总计行会显示“不完整：请参见上方备注”。

该工作簿已在 LibreOffice Calc 中检查，其重新计算的总计与原结果一致。尚未在 Excel 中打开过。逐列详细说明见[导出列](topic:export-columns)。

## 造价估算（CSV）

打开{{ui:导出}}菜单，选择{{ui:CSV}}。得到 `(name).csv`：与造价估算工作表相同的行和列，为纯数值（无公式），并包含总计行。可粘贴到其他造价或会计系统中使用。

CSV 仅包含造价估算；如需按图纸的工程量和标记列表，请使用 XLSX。同一菜单中的{{ui:材料清单}}会将材料清单单独保存为 CSV，用于订货。

## Google Sheets 中的造价估算

在工程量表格上方，**复制到Google Sheets**会将造价估算以制表符分隔的文本放入剪贴板，内容与 CSV 行相同。在 Google Sheets 中点击单元格 A1 并粘贴即可。TakeoffCraft 不会登录 Google，也不会向其发送任何内容。

## 缺失单价与审核确认

有工程量但没有单价的行，在备注中会显示**无单价**，导出时会在总计下方统计这些行。造价估算经过审核确认后，导出内容会注明确认人、确认时间以及对应的总计金额。参见[缺失单价与造价估算审核确认](topic:sign-off-the-estimate)。

## 标记PDF

1. 打开需要绘制标记的 PDF。
2. 打开{{ui:导出}}菜单，选择{{ui:标记PDF}}。
   显示“正在写入标记PDF……”，随后浏览器会为每个标记的 PDF 下载一个文件，文件名为 `(PDF name) (takeoff).pdf`。

副本中：

- 线段以其项目颜色绘制为线条，
- 面积以浅色填充并带实线轮廓，洞口保持开放，
- 计数以圆点表示，
- 每个有标记的页面在左下角添加一个小图例：列出每个项目的颜色、名称以及该页面上的工程量。

原始 PDF 不会被修改。

注意：

- 仅写入已打开的 PDF。未打开的 PDF 上的标记仍计入总计，但不会绘制；请先打开这些 PDF。
- 图例中的名称使用标准 PDF 字体。无法显示的字符将显示为“?”。
- 加密的 PDF 无法生成带标记的副本：“此 PDF 受密码保护或已加密，因此无法写入标记副本。算量本身没有问题；请改为导出电子表格。”
- 在同一标签页中首次使用{{ui:标记PDF}}时会加载 PDF 写入器。离线时，只有应用栏显示{{ui:离线可用}}，写入器才可用；参见[离线工作](common:offline)。

:::chromium
导出多个标记PDF时，Chrome 和 Edge 可能会询问一次是否允许本站下载多个文件。请选择“允许”，否则只会获得第一个文件。
:::

## 没有可导出的内容？

- {{ui:XLSX}}和{{ui:CSV}}需要至少一个项目：“尚无可导出的内容：请新建一个项目并进行算量。”
- {{ui:标记PDF}}需要已打开的 PDF 上有标记：“已打开的 PDF 上尚无标记。”

## 也请保存算量

导出是报告。若要稍后继续处理算量，还需选择{{ui:保存算量}}：参见[保存与重新打开算量](topic:save-and-reopen)。

若要添加管理费、利润、税费和保函并发送报价，参见[投标汇总和报价](topic:bid-summary)。

不必等待下一套图纸。建筑师发送建筑模型时，可直接在此打开，并从模型中取得工程量。模型在本机读取，不会发送到任何地方。

## 步骤

1. 在工具栏上选择{{ui:Model}}，然后选取模型的 `.ifc` 文件；或像打开其他文件一样，使用{{ui:Open plans}}打开。
2. {{ui:Model takeoff}}随即打开，每个类别和类型各占一行：墙按墙类型，楼板按楼板类型，门按门类型，依此类推。每行显示其数量以及该类别的计量单位。
3. 将{{ui:Group by}}设为{{ui:Category}}可快速得到总计，或设为{{ui:Category, type and level}}，以按楼层拆分每种类型。
4. 取消勾选不需要的行。{{ui:Find}}可缩小列表范围。取消勾选某行也会在三维图中隐藏其构件。
5. 为模型设置一个{{ui:Model name}}，并在整个项目中保持使用，例如项目名称。
6. 选择{{ui:Add to the takeoff}}。每项工程量都会成为项目列表中的一个输入工程量。像其他项目一样为其命名、定价并关联组合。

## 在三维中查看模型

{{ui:Show the model in 3D}}会在表格上方绘制模型，每行使用一种颜色（行名称旁的色块）。拖动可旋转，按住{{key:Shift}}并拖动可移动，使用滚轮缩放，选择{{ui:Fit}}或{{ui:Reset}}可恢复视图。

- **点击构件**：在图中点击某个构件，表格中会选中其所在行，该行的所有构件高亮，其余构件变淡。再次点击同一构件，如果它属于多行（例如墙的某一图层），则会选中下一行。
- **点击行**：点击表格中的某行，可高亮其构件。再次点击该行，或点击图中空白处，即可取消高亮。
- 房间不会被绘制，因为房间的体积会遮挡建筑。
- 非常大的模型会为部分构件只保留一个包围盒，以便装入内存；面板会显示数量。这不会改变数值。

如果此计算机无法绘制三维图形，表格将照常工作。

## 按材料、图层或尺寸分组

{{ui:Group by}}另有三个选项：

- {{ui:Category and material}}：由多层构成的墙、楼板或屋顶，每层材料各占一行，因此石膏板、龙骨和保温层可以分别定价。只使用一种材料的建筑构件归入该材料的行；没有材料的构件归入名为“未指定材料”的行。
- {{ui:Category and layer}}：与上述相同，但行中会显示图层厚度（例如“保温层，100 mm”）。
- {{ui:Category, type and door or window size}}：门和窗按宽度和高度拆分（例如 3'-0" × 6'-8" 或 914 × 2,032 mm）。

对于图层，面积为墙自身的一个立面（或楼板、屋顶的平面或表面积），体积为该面积乘以图层厚度。行的备注会说明有多少数值来自图层。同一面墙各图层的体积之和，等于模型为其给出的体积。

## 将行或门窗保存为 CSV

{{ui:Save rows as CSV}}会将已勾选的行保存为电子表格，每个标题中均注明单位。{{ui:Save openings schedule as CSV}}（仅当模型含门或窗时可用）会按类型、楼层和尺寸保存每个门和窗及其数量。

## 测量内容

| 类别 | 工程量 |
|---|---|
| 墙 | 数量、长度、墙面积（单面，已扣除洞口）、体积 |
| 楼板、板、吊顶及其他覆面 | 数量、平面面积、体积 |
| 屋顶 | 数量、平面面积、屋面面积、体积 |
| 基础 | 数量、平面面积、体积 |
| 柱、梁及其他构件 | 数量、沿构件的长度、体积 |
| 栏杆、管道、风管和线缆 | 数量、长度 |
| 楼梯 | 数量、体积 |
| 房间 | 数量、楼面面积、体积 |
| 门、窗及其他所有项目 | 数量 |

如果模型作者在文件中给出了某个工程量，则使用该数值；否则根据构件的形状测量。每个工程量都带有备注，说明数值的来源以及有多少个构件提供了数值。

:::note
按形状测量的墙长从一端量到另一端，因此在转角处相交的两面墙都会包含该转角。计算体积需要闭合的形状：形状不闭合的构件会被计数，但不给出体积。弯曲或带转角的墙构件按其全部竖向面积的一半测量，备注中会注明。
:::

## 新版模型到达时

打开较新的文件，并输入相同的{{ui:Model name}}。在添加任何内容之前，面板会显示有多少工程量是新增的、有多少已更改以及从何值变为何值，并列出早期版本中已不在模型里的工程量。选择{{ui:Add to the takeoff}}：已更改的工程量采用新数值，而名称、单价、损耗和组合保持不变。已从模型中删除的工程量保留旧数值；如果设计已取消它们，请自行删除。

类型和楼层名称用于识别工程量。如果建筑师重命名了墙类型，它会作为新工程量出现，而旧的工程量则列为已删除。

## 可读取的文件

IFC 文件（IFC2x3、IFC4 和 IFC4.3）。包含道路、铁路或桥梁的 IFC 文件仍会像以前一样直接导入其基础设施工程量。

TakeoffCraft 在本版本中不读取 `.rvt` 文件。如果建筑师使用 Revit，请要求其导出模型的 IFC 文件（文件、导出、IFC），然后打开该文件。

一个模型一次最多可导入 500 项工程量。超过时，请取消勾选部分行，或按类别分组。

这是 TakeoffCraft 0.9 相对于 0.8.1 的变更。这是本应用的一个小版本：长度现在可以按米、厘米或毫米读取，面积和比例能正确适用于公制工作，圆弧提供十种画法。实时协作会话中，还会显示每个人所在的位置。

## 新增

### 按米、厘米或毫米读取长度

- **长度显示方式。**{{ui:Settings}} › {{ui:TakeoffCraft}}中有{{ui:Show lengths as}}，选项包括{{ui:Follow Global}}、{{ui:Feet-inches}}、m、cm 和 mm。{{ui:Follow Global}}使用在{{ui:Settings}} › {{ui:Global}} › {{ui:Units}}中选定的公制长度单位；若未选定，则使用英尺-英寸。它会改变图纸上、状态栏中以及面板中长度的显示方式，包括高度、深度、厚度和楼层。在高度字段中输入的不带单位的数字，按当前显示的单位读取。
- **仅用于显示。**工程量、成本和导出均按精确长度计算。1/16、1/8 和 1/4 英寸的选项仅在英尺-英寸下出现。参见[以米显示长度](topic:show-lengths-in-meters)。
- **重量单位。**{{ui:Typed quantity (no drawing)}}项目现在可以使用 lb、TON、kg 或 t，并按单位定价。
- **温度。**每个项目在项目编辑器中都有可选的{{ui:Temperature}}字段，以 °C 或 °F 输入。{{ui:Settings}} › TakeoffCraft 中的{{ui:Show temperatures as}}提供{{ui:Follow Global}}、°C 或 °F。

### 公制工作的面积与比例

- **图纸上以 m2 显示面积。**使用公制项目测得的面积，现在在图纸标签、标记面板和表格中均显示为 m2，不再显示 SF。规则为：当项目以公制定价，或长度以 m、cm 或 mm 显示时使用 m2，否则使用 SF。
- **墙面积。**带高度的线性项目还会在项目列表中显示其墙面积（长度乘以高度），并在按项目列出的工程量表下方的备注行中显示。
- **比例预设 1:75 和 1:150。**它们位于{{ui:Scale}}组的{{ui:Preset}}列表中，该组现有 32 个比例。参见[比例预设](topic:scale-presets)。

### 圆弧十种画法

- 当{{ui:Arc}}开启时（工具栏按钮或{{key:R}}），图纸栏中会出现{{ui:Arc method}}框。可选画法依次为：三点；起点、圆心、终点；起点、圆心、角度；起点、圆心、长度；起点、终点、角度；起点、终点、方向；起点、终点、半径；圆心、起点、终点；圆心、起点、角度；圆心、起点、长度。角度、长度、半径和方向可以点击，也可以输入。它适用于线性段、区域和开洞。0.9 之前保存的文件打开时效果相同。参见[用十种方法画圆弧](topic:draw-arcs-ten-methods)。

### 协作

- **查看彼此的光标。**在实时协作会话中，每个人的指针会连同其名称和颜色显示在图纸上，其选中的标记外有虚线框。位于其他图纸上的人员会列出该图纸的名称。参见[与他人实时协作](topic:work-live)。
- **跟随他人与人员列表。**实时协作会话中的{{ui:People}}按钮会列出每个人，显示其使用的工具、所在图纸以及最后编辑时间。{{ui:Follow}}可使你的视图随其移动，主持人可使用{{ui:Ask everyone to follow me}}。参见[在实时协作会话中跟随队友](topic:follow-a-teammate)。

## 所有应用通用

- **工具提示与开始提示。**悬停文字为 Bootstrap 工具提示，开始提示可以关闭。
- **可滚动的选项卡栏。**面板的选项卡栏如果放不下，会滚动显示，而不是被截断。
- **选项卡标题。**浏览器标签页显示为 `<document> - TakeoffCraft | CadCraft`。
- **布局。**{{ui:Settings}}中的布局列表为下拉菜单，显示所选布局。
- **语言。**所选语言现在会应用于页面自身显示的文字，例如“新建”“打开”和“保存”。英文以外的语言在母语者审阅之前均为机器草稿。

## 已知局限

- 长度显示、重量和温度单位以及新预设已通过测试并在页面中核对。并未逐一手动检查每个单位下的每个面板。
- 人员列表尚未与真实的教师和学生班级进行手动测试。
- 英文以外的语言为机器草稿。
- Windows 安装程序未经代码签名（点击“更多信息”，然后选择“仍要运行”）。macOS 磁盘映像未经公证（右键单击，然后选择“打开”）。

## 较早版本：0.8 和 0.8.1

这是 TakeoffCraft 0.8（2026-11-01 发布）和 0.8.1（2026-11-02 发布）相对于 0.7 的变更。现在可以在整套图纸中一次性计数符号图例，新算量可以从过往工作的价格开始，并且可以对照供应商的库存检查算量。0.8.1 为修复版本。

### 新增

**整套图纸中全部计数**

- **一次框选图例。**工具栏中的{{ui:Count everything}}会读取符号图例：拖动框选符号以及旁边印出的名称。每个符号连同其图片和名称列出，名称会成为项目名称。取消勾选不需要的符号，然后选择{{ui:Count on N sheets}}（在 N 张图纸上计数）。进度条会显示正在搜索的图纸，{{ui:Cancel}}可停止运行，且页面仍可使用。
- **在一次运行中处理每张图纸。**每个符号都会在每张打开的图纸上计数。比例不同的图纸会按其比例进行搜索，符号可以旋转任意直角。图例自身的符号不会在其所在图纸上计数。
- **添加前先审阅。**每个总数都有一个指向各图纸的链接（“E-103：4”），点击即可跳转到该图纸。点击某个框可将其排除，再次点击即可恢复。匹配程度（50% 至 100%）仅用于筛选已找到的结果，不会重新搜索。
- **一个撤销步骤。**{{ui:添加 N 个标记}}会为每个符号创建一个计数项目，并在每个找到处添加标记。与已有计数项目同名的名称会被复用。{{key:Ctrl+Z}}可撤销所有项目和标记。接受的结果也会用于{{ui:Learned}}。
- **任意角度的符号。**计数前勾选{{ui:Symbols at any angle}}，还可以找到以非直角旋转的符号。搜索会每隔 15 度旋转一次每个符号，而非圆形的符号可能需要多达六倍的时间。
- **工作原理。**仅在打开的图纸上进行普通的符号匹配，不使用训练模型，所有内容都不会离开计算机。在一套虚构的 200 张图纸上，于快速的台式机上使用 Chrome 从头到尾耗时 9.4 秒；真实图纸集会更慢。参见[整套图纸中全部计数](topic:count-everything)。

**根据过往工作记忆价格**

- **TakeoffCraft 记住单价。**保存算量时，每个已使用的已定价项目都会按名称和类型记住：材料单价、人工单价、损耗和单位。每个名称保留最近 12 次工作。这些数据保存在本计算机上，与价格库放在一起，不会保存在算量文件中，也不会发送到任何地方。
- **用它开始新算量。**工具栏中的{{ui:Prices}}会为每个项目显示上次工作的单价、典型单价以及价格范围。{{ui:Use last}}或{{ui:Use typical}}可为单个项目定价，{{ui:从记忆中为 N 个未定价项目定价}}会为所有尚未定价的项目定价。每次使用都是一个撤销步骤。
- **较早的工作。**{{ui:从过往算量中学习……}}会记住已保存算量（.json）中已定价项目的价格。
- **查看、更改、遗忘。**{{ui:Everything remembered}}列出所有名称；删除按钮可忘记某一个名称，{{ui:Clear all prices}}可清除全部。关闭{{ui:Remember my prices when I save a takeoff}}即可停止记忆。按件计的单价绝不会应用于按英尺计的项目。参见[过往工作的价格记忆](topic:price-memory)。

**供应商库存与交货期**

- **对照供应商清单检查。**工具栏中的{{ui:Supply}}读取供应商的库存清单（{{ui:Add a supplier file…}}，即 CSV 或电子表格），并将算量所需的材料（含损耗）与之对照。最多保留五个文件。不会发送任何内容，也不会向供应商询问：文件需自行提供。
- **显示内容。**缺货项目排在最前，显示如“缺 120 EA”“交货期 21 天”“已缺货待补”“单位不同”“无库存数据”或“有库存”。{{ui:Longest wait wanted (days)}}默认为 14。
- **订货清单。**{{ui:Order list (CSV)}}会下载缺货项目，包括缺货数量、供应商和交货期。
- **价格写入价格库。**如果文件含有价格，{{ui:Prices into the Library}}会为名称和单位相同的每个价格库条目设置材料价格。从价格库重新定价即可将其带入算量。
- **在问题面板中。**缺货为警告，等待过长为注释，归于“供应商库存”下。可附上原因接受某一项，该原因会保存在算量中。参见[检查供应商库存和交货期](topic:supplier-stock)。

**AI 助手**

- **三者通用的工具。**在{{ui:Settings}}中允许助手后，助手可以读取图例（`legend_open`），运行计数（`legend_count_start`，然后是 `legend_count_status` 和 `legend_count_result`），并将其添加（`legend_count_add`，可先预览）。它可以读取记住的价格（`prices_list`），并据此为项目定价（`prices_apply`，可先预览），还可以读取供应商检查结果（`supply_check`）。添加供应商文件仍需由用户自行完成。参见[在 AI 助手中使用 TakeoffCraft](topic:use-with-ai-assistants)。

**所有应用通用**

- **语言。**共 54 种语言；其中 10 种为新增（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语和乌兹别克语）。英文以外的语言在母语者审阅之前均为机器草稿。
- **输入设备。**{{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}}可设置触控板、鼠标侧键、手写笔、3D 鼠标、游戏手柄或 MIDI 控制器的功能，既可用于所有应用，也可仅用于某一个应用。参见[使用触控板、3D 鼠标或控制器](common:input-devices)。
- **工具栏行数。**{{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}}提供{{ui:Wrap}}（默认）、{{ui:2 rows}}和{{ui:1 row}}；放不下的组会左右滚动。参见[排列面板](common:arrange-panels)。
- **问题面板。**共享的警告和注释面板现在包含上述供应商库存检查，与其他检查并列。
- **插件。**插件跟随你的账户列表。参见[插件和账户列表](common:addons-basics)。
- **连接你的 AI。**CadCraft Studio 是中心：只需为八个应用连接一次助手。Studio 本身没有 AI。

### 0.8.1 修复

- **DWG 类部分。**DWG 文件的类部分曾被读取为错误的类型。此问题已在 TakeoffCraft 及其他四个应用中修复。
- **Studio 运行时可更改语言。**此前 Studio 及其打包版本仅支持英文。此功能尚未在每个平台的桌面版本上测试；如果语言未能更改，请告诉我们。

### 本版本尚未提供

- **未经代码签名。**Windows 可能会发出警告；在 Mac 上，首次需右键单击并选择{{ui:Open}}。商店版本（Microsoft Store、Google Play、App Store）暂缓发布，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- **Studio 更新。**Windows 安装程序和 Linux 软件包每天检查一次更新，并会先询问。便携式 zip 仅提示更新；macOS 和 APK 不会自动更新。0.8 版的 macOS .dmg 随发布提供。
- **连接 AI。**Studio 内的一键连接、浏览器中的托管式 AI 连接器、Studio 内自备的 API 密钥，以及已发布的 MCP 软件包，均未承诺在本版本中提供。
- **全部计数。**它需要以与图例相同的方式绘制的符号；符号上穿过墙或长线时可能被漏掉。镜像符号不会被找到；未标注比例、以另一尺寸绘制的图纸将按图例的尺寸搜索。在信任其余结果之前，请检查第一张图纸上找到的项目。
- **供应商库存。**库存数字的时效性仅取决于你添加的文件。检查从不询问供应商。
- **语言。**泰米尔语的应用栏会溢出。

其他内容见[尚未实现](topic:not-built-yet)。上一版本见[0.7 版新增功能](topic:whats-new-0-7)。

## 可以打开什么

| 文件 | 方式 | 说明 |
|---|---|---|
| PDF（`.pdf`） | {{ui:打开平面图}}、{{key:Mod+O}}，或拖放到页面上 | 可以一次打开多个。每一页成为一张图纸。 |
| 算量项目（`.takeoff.json`） | {{ui:打开算量}}，或拖放到页面上 | 你的分项、比例和标记。可以连同其PDF一起拖放。 |

拖放到页面上的其他文件会被跳过，状态栏会列出它们的名称。

- **受密码保护的PDF**无法打开：“(name)受密码保护。请打开一份未加密的副本。”
- **同一个PDF打开两次**时只会打开一次：“(name)已经打开。”TakeoffCraft按文件内容而不是文件名来识别文件。
- **扫描版PDF**与其他PDF一样可以打开和测量；TakeoffCraft不需要PDF中的文字。
- **大型图纸集**：每个PDF在打开时都会被完整读取（以生成指纹），因此非常大的文件需要一点时间。缩略图在你滚动时逐个绘制。

## 保存什么

每次保存都是一次下载。不会向你的PDF回写任何内容。

| 你的操作 | 得到的文件 | 内容 |
|---|---|---|
| {{ui:保存算量}} | `(name).takeoff.json` | 分项、组合、费率、图纸比例和每个标记，按内容与各个PDF关联。不含PDF页面。 |
| {{ui:XLSX}} | `(name).xlsx` | 四个工作表：估算（含实时公式）、按图纸、标记、比例。 |
| {{ui:CSV}} | `(name).csv` | 以纯数值表示的估算，每个分项和每个组成部分各一行。 |
| {{ui:标记PDF}} | `(PDF name) (takeoff).pdf` | 每个含有标记的已打开PDF的副本，算量绘制在其页面上并附有图例。每个PDF一个文件。 |

名称取自你在此算量中打开的第一个PDF。目前还没有重命名框：如果想用其他名称，请重命名下载的文件。

参见[导出估算和标记PDF](topic:export-estimate)和[导出列](topic:export-columns)。

## 下载的文件保存在哪里

浏览器会把它们保存在保存所有下载内容的地方，通常是“下载”文件夹。可在{{pick:mac=访达|windows=文件资源管理器|linux=你的文件管理器}}中找到。如果你的浏览器设置为每次询问保存位置，它就会询问。

:::chromium
有多个带标记的PDF时，{{ui:标记PDF}}会一次下载多个文件。Chrome和Edge可能会询问一次此网站是否可以下载多个文件。请选择允许。
:::

:::safari
除非你在Safari设置的“通用”中更改了下载位置，否则Safari会保存到“下载”。
:::

## 为什么项目文件和PDF是分开的

`.takeoff.json`文件只保存你的算量。它通过内容（每个文件的指纹）重新找到自己的PDF，因此：

- 重命名或移动PDF没有影响。
- 被其他程序更改或重新保存过的PDF，即使名称相同，也会被视为另一个文件。
- 未打开的PDF上的标记仍然计入合计。

参见[保存并重新打开算量](topic:save-and-reopen)。

## 在线和离线

你的PDF和算量绝不会离开你的计算机，无论在线还是离线。网络连接只对加载TakeoffCraft本身有关。

要在没有网络连接时工作，请先在在线时保存此应用：

1. 选择顶部应用栏中的{{ui:保存以供离线使用}}。
   保存期间，按钮会计数：“正在保存12/40”。
2. 等待显示{{ui:离线可用}}。

保存TakeoffCraft会在你的浏览器中保留应用、本帮助、PDF阅读器、{{ui:标记PDF}}所用的PDF写入器和自动计数的工作程序，约6 MB。显示{{ui:离线可用}}后，一切功能都可离线使用：打开PDF、测量、{{ui:自动计数}}、{{ui:保存算量}}、{{ui:XLSX}}、{{ui:CSV}}和{{ui:标记PDF}}。

| 按钮显示 | 含义 |
|---|---|
| {{ui:保存以供离线使用}} | 尚未保存在此浏览器中。选择它即可保存。 |
| 正在保存(n)/(m) | 正在保存。 |
| {{ui:离线可用}} | 已保存。选择它可进行{{ui:重新保存（获取最新版本）}}或{{ui:移除离线副本}}。 |
| {{ui:无法保存}} | 有些文件没有下载成功。请检查网络连接后再次选择它。 |
| {{ui:无法离线使用}} | 此浏览器窗口无法保留离线副本（隐私窗口和某些受管理的计算机会阻止）。 |

更多内容，包括已保存的副本在各浏览器中能保留多久：[离线工作](common:offline)。

:::offline
当前处于离线状态。如果应用栏显示{{ui:离线可用}}，一切功能都可使用。如果没有，TakeoffCraft在此标签页中尚未加载的部分（{{ui:标记PDF}}所用的PDF写入器、自动计数的工作程序）现在无法加载，{{ui:标记PDF}}会以“无法写入标记PDF”中止。无论哪种情况，你的算量都是安全的：{{ui:保存算量}}、{{ui:XLSX}}和{{ui:CSV}}不需要网络连接。在恢复在线之前不要重新加载此标签页。
:::

:::online
当前处于在线状态。在现场踏勘或乘飞机之前，请选择{{ui:保存以供离线使用}}并等待显示{{ui:离线可用}}。
:::

## 电子表格

XLSX保留实时公式，因此电子表格程序在打开文件时会重新计算估算，当你在其中更改费率或损耗时仍能保持正确。该工作簿已在LibreOffice Calc中检查过，每个合计重新计算后都精确到分一致。尚未在Excel中打开过。

CSV是带字节顺序标记的纯数值，因此电子表格程序能正确读取m²之类的字符。

## 桌面版和云

:::desktop
从0.5起，桌面应用是CadCraft Studio：一次安装即包含TakeoffCraft和其他七个应用。没有单独的TakeoffCraft安装程序。
:::

云保存尚不可用。请把`.takeoff.json`文件与项目的PDF放在一起，并像对待其他文件一样备份。参见[文件保存到哪里](common:your-files)。

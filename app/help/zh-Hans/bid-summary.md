估算为你所计量的内容定价。**报价汇总**将其转换为价格：它增加销售税、管理费、利润和保函，并生成包含你的包含项与不包含项的**报价单 PDF**。

从 {{ui:导出}} › {{ui:报价汇总与报价单…}} 打开。其中的所有内容都随计量一同保存，且每项更改均可撤销。

## 加价

在五项中任一项输入百分比（其余保持为 0）。它们按以下顺序计算，每项基于其上方的合计：

| 行 | 计算方式 |
|---|---|
| 材料、人工 | 估算的合计（当计量包含[备选项](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts)时，为基本报价）。 |
| 人工附加费 | 附加费 % × 人工：你的工人工资所涉及的工资税、保险和福利。 |
| **成本** | 材料 + 人工 + 人工附加费。 |
| 材料销售税 | 税 % × 材料。 |
| 管理费 | 管理费 % ×（成本 + 税）。 |
| 利润 | 利润 % ×（成本 + 税 + 管理费）。 |
| 保函 | 保函 % × 以上所有内容。 |
| **报价** | 各行之和。 |

每行四舍五入到分。工作簿在估算工作表的合计下方以实时公式显示相同的各行。汇总会随你的输入即时更新：按 {{key:Enter}} 确认百分比。每个备选项都按其自身成本采用相同的加价显示，以便业主看清选择它会真正改变多少。

## 报价单

填写报价单应说明的内容：

- **项目**（为空时使用计量名称）、**致**（客户）和 **来自**（你的公司）。
- **包含项**与**不包含项**：每行一项；行首的破折号或项目符号均可。
- **条款**：自由文本，例如“报价有效期为 30 天。”
- **列出分项及数量**：工作范围，逐项列出数量，不含价格。若要进行总价报价，请取消勾选。

选择 {{ui:报价单PDF}}。该 PDF（`<takeoff> - proposal.pdf`）包含日期、价格块（含每项加价和报价）、备选项、工作范围、包含项和不包含项、条款，以及签字和日期的线条。若有部分数量无法测量（图纸没有比例），报告会在价格下方注明。

## 导出

计量一旦有了报价汇总，CSV 将以其结尾，工作簿会增加一个 **报价汇总** 工作表，包含每行、其百分比和金额。参见 [导出估算](topic:export-estimate)。

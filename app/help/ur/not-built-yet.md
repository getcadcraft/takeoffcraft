TakeoffCraft ابھی ڈویلپمنٹ میں ہے۔ یہ فہرست بتاتی ہے کہ موجودہ ورژن کیا نہیں کرتا، اور پھر بھی کام کیسے مکمل کیا جائے۔

## پیمائش

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| کسی رن یا آؤٹ لائن کے درمیان ایک پوائنٹ داخل کرنا | نشان حذف کریں اور اسے دوبارہ بنائیں۔ |
| باکس (ونڈو) سلیکشن | ہر نشان پر {{key:Shift}} + کلک کریں، یا شیٹ کے تمام نشانات کے لیے {{key:Mod+A}}۔ دیکھیں [نشانات کاپی، چسپاں اور ڈپلیکیٹ کریں](topic:copy-paste)۔ |
| چسپاں کی گئی نقل کو گھمانا، مرر کرنا یا دوبارہ اسکیل کرنا | ایک ہی اسکیل اور ایک ہی رخ پر شیٹ پر چسپاں کریں؛ باقی ہاتھ سے بنائیں۔ |
| اسکین شدہ شیٹ یا گرافک اسکیل بار سے اسکیل پڑھنا | پری سیٹ منتخب کریں، یا بار کی لمبائی پر کیلیبریٹ کریں۔ |
| ایک شیٹ پر ایک سے زیادہ اسکیل (ڈیٹیل ایریاز، بڑے کیے گئے پلان) | حصے کو شیٹ کے اسکیل پر ناپیں، اور اگر سیٹ میں اس کی الگ بڑی شیٹ ہو تو ڈیٹیل کی مقدار اسی الگ شیٹ سے نکالیں۔ |

| ابھی تیار نہیں | اس کے بجائے، آج |
|---|---|
| مرکب فارمولے جو کسی آئٹم کے نشانات کی دوسری اقسام استعمال کریں (منزل کے فارمولوں میں کمرے کے آئٹم کے دروازے) | فارمولے مرکزی قسم کے ٹوٹلز استعمال کرتے ہیں؛ دوسری اقسام کی قیمت ان کی اپنی قطاروں میں لگائیں۔ |
| رن کے حساب سے نکالے جانے والے مرکب فارمولے | فارمولے آئٹم کے ٹوٹلز استعمال کرتے ہیں؛ رن کے اضافی حصوں کے لیے `N` استعمال کریں۔ |
| کسی دوسرے آئٹم کی مقداریں استعمال کرنے والے فارمولے | اس آئٹم میں پیمائش دہرائیں، یا اسپریڈ شیٹ ایکسپورٹ میں حساب کریں۔ |
| مرکب اجزا پر عملہ، یا 8 گھنٹے کے علاوہ کوئی کام کا دن | عملہ آئٹم کو دیں؛ کسی اور دن کی لمبائی کے لیے عملہ-دن کو عملہ-گھنٹے ÷ آپ کا دن کے طور پر پڑھیں۔ |
| نوٹس، کلاؤڈز اور ہائی لائٹس کے علاوہ مارک اپس (تیر، ڈائمینشنز، اسٹیمپس)، یا نوٹ پر جوابات | نوٹ کے متن میں لکھیں؛ طے ہونے پر اس کی حیثیت بدلیں۔ |
| ٹیم کے ساتھ مشترکہ قیمتوں کی لائبریری، یا آپ کے اکاؤنٹ کے ساتھ محفوظ لائبریری | لائبریری اس براؤزر میں رہتی ہے: اسے CSV کے طور پر ایکسپورٹ کریں اور دوسرے کمپیوٹر پر امپورٹ کریں۔ |
| کام کرنے والے تخمینہ کاروں کی جانچ شدہ ٹریڈ پیکس | ہر پیک ایک ابتدائی سیٹ ہے: قیمت لگانے سے پہلے اس کے مفروضات اپنے کام اور اپنی مصنوعات سے ملائیں۔ دیکھیں [ٹریڈ پیکس](topic:trade-packs)۔ |
| ٹریڈ پیکس میں قیمتیں | پیکس صرف مرکب آئٹمز دیتے ہیں: اپنی شرحیں خود طے کریں، یا اپنی قیمتوں کی فہرست CSV کے طور پر امپورٹ کریں۔ |
| ٹیک آف کا نام بدلنا | نام پہلی PDF سے آتا ہے؛ ڈاؤن لوڈ ہونے والی فائلوں کا نام بدلیں۔ |
| شیٹس کو ہاتھ سے نام دینا | شیٹس کے نام PDF کے صفحے کے لیبلز سے بنتے ہیں؛ فائل کے نام اور صفحے سے تلاش کریں۔ |

| شیٹ بار سے ڈرائنگ کو کسی دوسری ایپ کو منتقل کرنا | وہی فائل اس ایپ میں کھولیں۔ |

مرکب اجزا اپنی مقدار ایک فارمولے سے لیتے ہیں۔ فارمولا آئٹم کی ناپی گئی قدروں پر ایک چھوٹا سا حسابی اظہار ہے۔ مثالوں کے لیے دیکھیں [مرکب اور فارمولے](topic:assemblies)۔

## متغیرات

| آئٹم کی قسم | متغیر | مطلب |
|---|---|---|
| Linear | `L` | کل لمبائی |
| Linear | `H` | آئٹم کی اونچائی |
| Linear | `A` | دیوار کا رقبہ، L × H، ان رنز کے کھلے حصے منہا کر کے جو انہیں رکھتے ہیں (BimCraft سے ٹیک آف)۔ جب وہ ٹیک آف پیمائش کا طریقہ بتائے تو `A` اسی سے ناپا جاتا ہے: اس طریقے کے سب سے چھوٹے سائز سے چھوٹے کھلے حصے شامل رہتے ہیں، اور جہاں دیواریں ملتی ہیں وہاں کا وہ حصہ چھوڑ دیا جاتا ہے جو طریقہ نکالتا ہے۔ آئٹم کے نیچے کا نوٹ طریقے کا نام بتاتا ہے |
| Linear | `N` | رنز کی تعداد |
| Area | `A` | کل خالص رقبہ (بیرونی خاکے منہا کٹ آؤٹ) |
| Area | `P` | کل احاطہ، کٹ آؤٹ کے کناروں سمیت |
| Area | `H` | آئٹم کی گہرائی یا موٹائی |
| Area | `N` | رقبوں کی تعداد |
| Count | `N` | گنتی |

- متغیرات آئٹم کی اکائیوں میں ہوتے ہیں: دیکھیں [اکائیاں](topic:units)۔
- بڑے اور چھوٹے حروف ایک جیسے ہیں: `l` یعنی `L`۔
- صرف آئٹم کی اپنی قسم کے متغیرات کام کرتے ہیں۔ linear آئٹم پر `P` لکھنے سے یہ پیغام آتا ہے: "P" یہاں ناپی گئی قدر نہیں ہے۔ L, H, A, N استعمال کریں۔
- خالی اونچائی یا گہرائی 0 ہوتی ہے۔

## آپریٹرز

| لکھیں | مطلب |
|---|---|
| `+` | جمع |
| `-` یا `−` | تفریق، یا منفی قدر |
| `*` یا `×` | ضرب |
| `/` یا `÷` | تقسیم |
| `( )` | گروپ |

ضرب اور تقسیم جمع اور تفریق سے پہلے ہوتے ہیں: `L * 2 + 4` یعنی (L × 2) + 4۔ شک ہو تو قوسین استعمال کریں۔

اعداد میں اعشار ہو سکتے ہیں (`1.333`، `.5`) اور قوت نما بھی (`1e3` = 1000)۔ خالی جگہیں نظرانداز ہوتی ہیں۔

## فنکشنز

| فنکشن | نتیجہ | مثال |
|---|---|---|
| `ceil(x)` | اوپر کی طرف پورے عدد تک گول | `ceil(67.5)` = 68 |
| `floor(x)` | نیچے کی طرف پورے عدد تک گول | `floor(67.5)` = 67 |
| `round(x)` | قریب ترین پورے عدد تک، نصف صفر سے دور کی طرف | `round(2.5)` = 3 |
| `round(x, d)` | d اعشاری ہندسوں تک گول (0 سے 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | سب سے چھوٹی قدر | `min(N, 10)` |
| `max(a, b, …)` | سب سے بڑی قدر | `max(1, ceil(N / 12))` |
| `abs(x)` | علامت کے بغیر قدر | `abs(-3)` = 3 |

`ceil` اور `floor` کمپیوٹر کی چھوٹی گول کاری کی غلطیوں کو نظرانداز کرتے ہیں، اس لیے جو قدر بالکل 1 ہونی چاہیے وہ کبھی 2 تک گول نہیں ہوتی۔

## خرابیاں

جو فارمولا پڑھا یا حل نہ ہو سکے وہ اپنی خرابی فیلڈ کے نیچے دکھاتا ہے، اور جزو کل میں شامل نہیں ہوتا ({{ui:Quantities}} ہیڈر "Incomplete" کہتا ہے)۔ پیغامات:

| پیغام | درستی |
|---|---|
| فارمولا لکھیں، جیسے L یا ceil(L / 1.333) + 1۔ | فارمولا خالی ہے۔ |
| "X" یہاں ناپی گئی قدر نہیں ہے۔ … استعمال کریں | درج متغیرات میں سے ایک استعمال کریں۔ |
| "X" یہاں فنکشن نہیں ہے۔ ceil، floor، round، min، max، abs استعمال کریں۔ | ان میں سے ایک فنکشن استعمال کریں۔ |
| "#" فارمولے میں اجازت نہیں ہے۔ | یہ حرف ہٹائیں (اکائیاں، `%`، `$` اور `=` اجازت شدہ نہیں)۔ |
| ")" غائب ہے۔ / "(" کے بغیر ")" موجود ہے۔ | قوسین برابر کریں۔ |
| ")" سے پہلے قدر غائب ہے۔ | جیسے `max(1, )`: قدر ڈالیں۔ |
| فارمولا بہت جلد ختم ہو گیا۔ | جیسے `L *`: مکمل کریں۔ |
| غیر متوقع "…"۔ کیا آپریٹر غائب ہے؟ | دو قدریں ساتھ ساتھ، جیسے `2L`: `2 * L` لکھیں۔ |
| ceil() ایک قدر لیتا ہے۔ | فنکشن کو درست تعداد میں قدریں دیں۔ |
| round(x, digits) کو 0 سے 10 تک پورے ہندسے چاہئیں۔ | اعشاری ہندسوں کی پوری تعداد استعمال کریں۔ |
| فارمولا صفر سے تقسیم کرتا ہے۔ | عام طور پر H صفر ہوتا ہے: آئٹم کی اونچائی یا گہرائی مقرر کریں۔ |
| فارمولا کوئی عدد نہیں دیتا۔ | نتیجہ عدد کے لیے بہت بڑا ہے۔ |
| یہ فارمولا بہت لمبا ہے (زیادہ سے زیادہ 500 حروف)۔ | مختصر کریں۔ |

## محفوظ ڈیزائن

فارمولا صرف اوپر کے متغیرات اور فنکشنز کے ساتھ حساب کر سکتا ہے۔ یہ کوڈ نہیں چلا سکتا اور نہ کچھ اور پڑھ سکتا ہے، اس لیے کسی کی بھیجی ہوئی پروجیکٹ فائل میں موجود فارمولا نقصان دہ نہیں۔

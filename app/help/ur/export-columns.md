## Estimate (XLSX ورک شیٹ اور CSV)

ہر آئٹم کے لیے ایک قطار، اور اس کے مرکب آئٹم کے ہر جزو کے لیے ایک قطار (اندر کی طرف)۔ پھر ایک خالی قطار اور جاب کا کل۔

| Column | مواد | XLSX میں |
|---|---|---|
| A Item | آئٹم کا نام (بولڈ) یا جزو کا نام (اندر کی طرف) | متن |
| B Type | Linear، Area، Count یا Component | متن |
| C Unit | LF، m، SF، SY، m²، EA، یا جزو کی اکائی | متن |
| D Quantity | ناپا گیا کل، یا فارمولے کا نتیجہ | عدد |
| E Waste % | ضیاع | فیصد (0.10 = 10%) |
| F Qty with waste | مقدار × (1 + ضیاع) | فارمولا `D*(1+E)` |
| G Material per unit | مواد کا نرخ | عدد |
| H Labor per unit | مزدوری کا نرخ | عدد |
| I Material | بڑھائی گئی مواد کی رقم | فارمولا `ROUND(F*G,2)` |
| J Labor | بڑھائی گئی مزدوری کی رقم | فارمولا `ROUND(F*H,2)` |
| K Total | مواد + مزدوری | فارمولا `I+J` |
| L Notes | استعمال شدہ فارمولا، فارمولے کی غلطی، بغیر اسکیل والی شیٹس پر نشانات، دیوار کا رقبہ، احاطہ | متن |

جاب کے کل کی قطار: کالم I، J اور K پر اوپر کی ہر قطار کے لیے `SUM`، اور جب کچھ چھوڑا گیا ہو تو Notes میں "Incomplete: see the notes above"۔

فارمولے کی غلطی والی قطار میں کوئی مقدار یا رقم نہیں ہوتی؛ اس کا نوٹ غلطی بتاتا ہے۔ ہیڈر قطار منجمد ہوتی ہے۔

CSV میں یہی کالم سادہ قدریں رکھتے ہیں، Waste % فیصد کا عدد ہوتا ہے (10% کے لیے 10)، اور رقم ڈالر میں دو اعشاری ہندسوں کے ساتھ ہوتی ہے۔ وہ متن جسے اسپریڈشیٹ فارمولا سمجھ سکتی ہے (`=`، `+`، `-` یا `@` سے شروع ہونے والا) اس سے پہلے `'` لگا کر متن ہی رکھا جاتا ہے۔

## By sheet (صرف XLSX)

| Column | مواد |
|---|---|
| Sheet | شیٹ کا نام (جب PDF کھلی نہ ہو تو PDF کا نام بھی) |
| Item | آئٹم کا نام |
| Quantity | اس شیٹ پر اس آئٹم کی مقدار، اس کی اکائی میں |
| Unit | آئٹم کی اکائی |
| Marks | نشانات کی تعداد |

## Marks (صرف XLSX)

ہر نشان کے لیے ایک قطار۔

| Column | مواد |
|---|---|
| Sheet | شیٹ کا نام |
| Item | آئٹم کا نام |
| Type | Linear، Area یا Count |
| Quantity | لمبائی، خالص رقبہ، یا 1 |
| Unit | LF یا m؛ SF، SY یا m²؛ EA |
| Detail | Linear: حصوں کی لمبائیاں، منہا شدہ حصے "(deduct)" کے نشان کے ساتھ، اور "deducts (length) of (length) drawn"۔ Area: کٹ آؤٹ ہوں تو مجموعی اور کٹ آؤٹ رقبے، اور احاطہ۔ بغیر اسکیل کے نشانات کے لیے "Sheet has no scale"۔ |
| Bid area | صرف جب ٹیک آف میں بولی کے علاقے ہوں: نشان کا رقبہ، یا "No bid area" |

## By bid area (صرف XLSX، جب ٹیک آف میں بولی کے علاقے ہوں)

| Column | کیا ہے |
|---|---|
| Bid area | علاقے کا نام، یا "No bid area" |
| Item | آئٹم، یا اس کے نیچے اندر کی طرف جزو |
| Unit | آئٹم یا جزو کی اکائی |
| Quantity | اس علاقے میں ناپی گئی مقدار (اجزاء: علاقے کے کل پر فارمولا) |
| Qty with waste | مقدار × (1 + ضیاع) |
| Material, Labor, Total | تخمینے کی طرح سینٹ تک بڑھائی گئی |
| Notes | فارمولا، غلطیاں اور بغیر اسکیل کے نشانات، تخمینے کی طرح |

ہر علاقہ ایک قطار "(نام) subtotal" پر ختم ہوتا ہے جس کی لاگت اس کی قطاروں پر `SUM` فارمولے ہیں؛ آخری قطار، **All bid areas**، ذیلی کل جمع کرتی ہے۔ پھر **Marks** ورک شیٹ میں ساتواں کالم **Bid area** ہوتا ہے۔

## Scales (صرف XLSX)

ہر شیٹ کے لیے ایک قطار جس کا اسکیل یا نشانات ہوں۔

| Column | مواد |
|---|---|
| Sheet | شیٹ کا نام |
| Scale | پری سیٹ کا نام، یا کیلیبریٹ شدہ اسکیل، یا "No scale" |
| How | "Preset"، یا "Calibrated on (the distance you typed)" |
| Feet per PDF unit | وہ درست اسکیل فیکٹر جو TakeoffCraft استعمال کرتا ہے |

## فائل کے نام

- `(name).xlsx` اور `(name).csv`، جہاں نام ٹیک آف میں کھولی گئی پہلی PDF سے آتا ہے۔
- CSV UTF-8 میں ہے، بائٹ آرڈر مارک اور ونڈوز لائن اینڈنگز کے ساتھ، جو ہر پلیٹ فارم پر اسپریڈشیٹ پروگرام پڑھتے ہیں۔

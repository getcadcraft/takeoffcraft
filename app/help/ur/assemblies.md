کسی آئٹم کی **اسمبلی** ایسے جزوں کی فہرست ہے جن میں سے ہر ایک کا اپنا مقدار فارمولا، اپنا ضیاع اور اپنے نرخ ہوتے ہیں۔ فارمولا آئٹم کے ناپے ہوئے کل مجموعے استعمال کرتا ہے، اس لیے دیوار کی ایک مقدار نکالنے سے ہی اسٹڈز، پلیٹس اور بورڈ ایک ساتھ مل جاتے ہیں، اور جیسے جیسے آپ ناپتے ہیں یہ خود بخود اپ ڈیٹ ہوتے ہیں۔

## استعمال کیے جا سکنے والے متغیرات

| آئٹم کی قسم | متغیرات |
|---|---|
| لکیری | `L` لمبائی، `H` اونچائی، `A` دیوار کا رقبہ (L × H)، `N` رنز کی تعداد |
| رقبہ | `A` رقبہ، `P` احاطہ (خاکہ + کٹ آؤٹس)، `H` گہرائی یا موٹائی، `N` رقبوں کی تعداد |
| گنتی | `N` گنتی |

قدریں آئٹم کی اپنی اکائیوں میں ہوتی ہیں: LF اور SF آئٹمز کے لیے فٹ اور مربع فٹ، m اور m² آئٹمز کے لیے میٹر اور مربع میٹر۔ SY آئٹم کے لیے `A` مربع گز میں ہوتا ہے، جبکہ `P` اور `H` فٹ میں ہی رہتے ہیں۔

فارمولوں میں `+ - * /` (یا × ÷)، قوسین، اعداد، اور فنکشنز `ceil`، `floor`، `round`، `min`، `max` اور `abs` استعمال ہوتے ہیں۔ مکمل اصول [فارمولا کی زبان](topic:formulas) میں دیے گئے ہیں۔

## مثال: اندرونی دیوار

فرض کریں آپ نے **Interior wall type A** کو لکیری آئٹم کے طور پر ناپا ہے: 4 رنز، کل 120 LF، اور {{ui:Height}} `9'-0"` پر سیٹ ہے۔ اس کی **ناپی گئی** قدریں یوں ہیں: L = 120، N = 4، A = 1,080 (دیوار کا SF، ایک طرف)۔

1. {{ui:Items}} کے تحت آئٹم منتخب کریں۔
2. {{ui:Assembly}} میں {{ui:Add component}} منتخب کریں۔
   «جزو» نام کا ایک جزو ظاہر ہوگا، جس میں فارمولا `L` ہوگا اور نیچے اس کا نتیجہ۔
3. {{ui:Name}} میں `Studs 16 in o.c.` اور {{ui:Unit}} میں `EA` لکھیں۔
4. {{ui:Quantity formula}} میں `ceil(L * 12 / 16) + N` لکھیں۔ نتیجہ لکھتے ہی اپ ڈیٹ ہو جاتا ہے: "= 94 EA"۔ یہ 120 فٹ پر ہر 16 انچ پر ایک اسٹڈ (90) ہے، اور 4 رنز میں سے ہر ایک کو بند کرنے کے لیے ایک اضافی۔
5. پلیٹس کے لیے {{ui:Add component}} دوبارہ منتخب کریں: نام `Plates, top and bottom`، اکائی `LF`، فارمولا `L * 2`۔ نتیجہ: 240 LF۔
6. بورڈ شامل کریں: نام `Gypsum board 4x8, both sides`، اکائی `sheets`، فارمولا `ceil(A * 2 / 32)`۔ نتیجہ: 68 sheets (2,160 SF بورڈ ÷ 32 SF فی شیٹ = 67.5، اوپر کی طرف گول کیا گیا)۔
7. ہر جزو کا {{ui:Waste %}}، {{ui:Material $}} اور {{ui:Labor $}} بھریں۔ ہر جزو {{ui:Quantities}} میں آئٹم کے نیچے اپنی الگ قطار میں آتا ہے، آئٹم کی طرح قیمت کے ساتھ، اور {{ui:Job total}} میں شامل ہوتا ہے۔

اگر دیوار کی پوری لاگت اجزا میں ہے، تو آئٹم کے اپنے مواد اور مزدوری کے نرخ 0 رہنے دیں، ورنہ یہ دو بار شمار ہوگی۔

:::tip
ضیاع فارمولے کے بعد لاگو ہوتا ہے اور اسے گول نہیں کیا جاتا: 10% ضیاع کے ساتھ 68 sheets، 74.8 sheets ہیں۔ پوری شیٹس منگوانے کے لیے، ضیاع کو فارمولے کے اندر رکھیں، جیسے `ceil(A * 2 / 32 * 1.1)`، اور جزو کا ضیاع 0 رکھیں۔
:::

## مزید فارمولے

| کیا | آئٹم | فارمولا |
|---|---|---|
| 24 انچ سینٹر پر اسٹڈز | لکیری | `ceil(L / 2) + N` |
| انسولیشن بیٹس، SF | اونچائی کے ساتھ لکیری | `A` |
| دونوں طرف پینٹ، 350 SF فی گیلن | اونچائی کے ساتھ لکیری | `ceil(A * 2 / 350)` |
| 15 SF کے ٹائل کارٹن، 10% اضافی | رقبہ | `ceil(A * 1.1 / 15)` |
| بیس یا کنارے کی ٹرم، LF | رقبہ | `P` |
| کنکریٹ، cubic yards | گہرائی کے ساتھ رقبہ | `A * H / 27` |
| کنکریٹ، پاؤ گز تک اوپر گول | گہرائی کے ساتھ رقبہ | `ceil(A * H / 27 * 4) / 4` |
| ہنگز، فی دروازہ تین | گنتی | `N * 3` |
| کم از کم ایک ڈبہ، ہر 12 پر ایک | گنتی | `max(1, ceil(N / 12))` |

## جب فارمولا غلط ہو

فارمولے کے نیچے کی لائن ایک خرابی کے پیغام میں بدل جاتی ہے، مثلاً `"X" is not a measured value here. Use L, H, A, N.` یا `A ")" is missing.`۔ پھر جزو کی کوئی رقم نہیں ہوتی، {{ui:Quantities}} میں اس کی قطار «فارمولے کی خرابی: …» دکھاتی ہے، اور ہیڈر کہتا ہے «نامکمل: 1 فارمولے کی خرابی (کل مجموعوں میں شامل نہیں)»۔ فارمولا درست کریں تو کل مجموعے اپ ڈیٹ ہو جاتے ہیں۔

جو فارمولا صفر سے تقسیم کرے وہ بھی خرابی ہے («فارمولا صفر سے تقسیم کرتا ہے۔»)، مثلاً `A / H` ایسے آئٹم پر جس کی کوئی گہرائی نہ ہو۔

## حدود

- فارمولے آئٹم کے **کل مجموعوں** پر چلتے ہیں، رن رن پر نہیں۔ `ceil(L * 12 / 16) + N` ہر رن کے لیے ایک اسٹڈ شامل کرتا ہے؛ ابھی فی رن گول کرنے کی سہولت نہیں ہے۔
- فارمولا صرف اپنے آئٹم کے متغیرات استعمال کر سکتا ہے، کسی دوسرے آئٹم کے نہیں۔
- فی آئٹم زیادہ سے زیادہ 50 اجزا، اور فی فارمولا 500 حروف۔

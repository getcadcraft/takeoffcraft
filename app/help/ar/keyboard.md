تعمل مفاتيح الحروف عندما يكون المؤشر في أي مكان من الصفحة، وأنت لا تكتب في حقل. وأثناء فتح مربع حوار، تسري مفاتيحه الخاصة. وتعمل الحروف مع {{key:Shift}} أو دونه.

## أثناء الرسم

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| نقرة | تضع نقطة (نقطة مع {{ui:Count}}). |
| {{key:P}} | المسار: التقاط المسار المتصل كاملاً لخط PDF، أو المخطط المحيط بالنقرة ([التقاط خطوط PDF](topic:pick-the-lines)). |
| {{key:F3}} | الانجذاب إلى خطوط الرسم تشغيل أو إيقاف ([الانجذاب إلى خطوط الرسم](topic:snap-to-the-drawing)). |
| النقر مع الضغط على {{key:Shift}} | ينجذب الجزء إلى 0° أو 45° أو 90° أو 135° من النقطة الأخيرة. ليس لنقاط القوس أو الدوائر. |
| النقر المزدوج | ينهي المسار، أو يغلق مساحة أو فتحة. |
| {{key:Enter}} | ينهي المسار، أو يغلق مساحة أو فتحة. |
| النقر بالزر الأيمن (دون تحريك) | ينهي المسار، أو يغلق مساحة أو فتحة. |
| النقر على النقطة الأولى | يغلق المساحة أو الفتحة (من النقطة الثالثة). |
| {{key:Backspace}} أو {{key:Delete}} | يحذف النقطة الأخيرة (أولاً نقطة القوس المعلّقة). |
| {{key:Esc}} | يلغي نقطة القوس المعلّقة؛ ثم يلغي العلامة غير المكتملة؛ ثم يعود إلى {{ui:Select}}. |

## التحديد والتحرير

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| النقر على علامة (أداة التحديد) | يحدّدها ويجعل بندها الحالي. |
| النقر مع الضغط على {{key:Shift}} | يضيفها إلى التحديد، أو يُخرجها منه. |
| {{key:Mod+A}} | يحدّد كل علامات الورقة المفتوحة. |
| السحب من مقبض الزاوية | ينقل تلك النقطة ({{key:Shift}} يلتقط بزاوية 45°). يعمل عندما تكون علامة واحدة محدّدة. |
| {{key:Delete}} أو {{key:Backspace}} | يحذف العلامات المحددة (عندما لا تكون في وضع الرسم). |
| {{key:Esc}} | يلغي التحديد كله: يمسح التحديد وخط الفحص. |
| {{key:Mod+Z}} | تراجع. |
| {{key:Mod+Y}} أو {{key:Mod+Shift+Z}} | إعادة. |

## النسخ واللصق

| المفتاح | ما يفعله |
|---|---|
| {{key:Mod+C}} | نسخ العلامات المحددة مع بنودها. |
| {{key:Mod+X}} | قص: ينسخ العلامات المحددة ثم يحذفها. |
| {{key:Mod+V}} | لصق: تتبع النسخة المؤشر؛ انقر حيث تريد أن تذهب. |
| {{key:Mod+Shift+V}} | لصق في المكان: الموضع نفسه على الورقة المفتوحة. |
| {{key:Mod+D}} | تكرار العلامات المحددة: تتبع النسخة المؤشر؛ انقر حيث تريد أن تذهب. |
| {{key:Esc}} | لا يُوضع شيء: يلغي اللصق أو التكرار الذي على المؤشر. |

الحروف وحدها ما زالت تختار الأدوات ({{key:C}} هو {{ui:Count}}، {{key:D}} هو {{ui:Check}}، {{key:X}} هو {{ui:Cut-out}}، {{key:V}} هو {{ui:Select}}، {{key:A}} هو {{ui:Area}})؛ ولا ينسخ ويلصق إلا {{key:Mod}} معها. وفي حقل النص، تنسخ هذه المفاتيح النص وتلصقه كالمعتاد. انظر [نسخ العلامات ولصقها وتكرارها](topic:copy-paste).

:::warning
يحذف {{key:Backspace}} العلامة المحددة عندما لا تكون في وضع الرسم. إن حدث ذلك بالخطأ، اضغط {{key:Mod+Z}} لاستعادتها.
:::

## العرض والأوراق

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| عجلة الفأرة | تكبير وتصغير عند المؤشر. |
| السحب (بالزر الأيسر أو الأوسط أو الأيمن) | تحريك. وفي {{ui:Auto count}} يرسم السحب بالزر الأيسر مربع البحث بدلاً من ذلك. |
| السحب مع الضغط على {{key:Space}} | تحريك، في أي أداة. |
| {{key:F}} | {{ui:Fit page}} |
| {{key:W}} | {{ui:Fit width}} |
| {{key:Plus}} أو {{key:=}} | تكبير من منتصف المنظر. |
| {{key:Minus}} | تصغير من منتصف المنظر. |
| {{key:PageDown}} / {{key:PageUp}} | الورقة التالية أو السابقة في قائمة الأوراق. |
| {{key:Ctrl+Shift+F}} | التنقل بين أوضاع ملء الشاشة (Control على كل المنصات، وكذلك على Mac). |
| {{key:F1}} | يفتح هذه المساعدة أو يغلقها، وهي لوحة جانبية. |
| {{key:3}} | منظر الفحص ثلاثي الأبعاد للورقة، تشغيل أو إيقاف. |

## المنظر ثلاثي الأبعاد

| المفتاح أو الإجراء | ما يفعله |
|---|---|
| السحب، أو السحب بالزر الأوسط | مدار. |
| السحب مع الضغط على {{key:Shift}}، أو السحب بالزر الأيمن | تحريك. |
| عجلة الفأرة | تكبير عند المؤشر. على لوحة التتبع، يُدير المرورُ بإصبعين المدار، ويكبّر القرص. |
| النقر | يحدّد العلامة تحت المؤشر (النقر مع {{key:Shift}} يضيف أو يُخرج). |
| {{key:F}} أو {{key:W}} | تكبير إلى الامتدادات. |
| {{key:3}} | العودة إلى الورقة المسطحة. |

## المساعدة

| المفتاح | ما يفعله |
|---|---|
| {{key:F1}} | يفتح لوحة المساعدة أو يغلقها (وكذلك زر {{ui:Help}} في شريط التطبيق). يعمل في كل أداة، حتى أثناء الكتابة في حقل. |
| {{key:Esc}} | يغلق لوحة المساعدة. وفي مربع بحثها يمسح أول {{key:Esc}} البحث. وإذا نقرت على الورقة أثناء فتح اللوحة، يغلق {{key:Esc}} اللوحة أولاً؛ اضغطه مرة أخرى للإلغاء في TakeoffCraft. |

:::mac
في كثير من لوحات Mac، يتحكم الصف العلوي في السطوع والصوت. اضغط fn مع {{key:F1}}، أو فعّل "Use F1, F2, etc. keys as standard function keys" في إعدادات النظام، تحت لوحة المفاتيح.
:::

## ملاحظات المنصات

:::mac
- {{key:Mod}} هو مفتاح Command: {{key:Mod+Z}}، {{key:Mod+S}}، {{key:Mod+O}}. ملء الشاشة هو الاستثناء: Control+Shift+F.
- النقر بالزر الأيمن على لوحة التتبع هو نقرة بإصبعين، بعد تفعيل النقر الثانوي في إعدادات النظام، تحت لوحة التتبع. تقرأ TakeoffCraft الزر الثانوي فقط؛ وقد يُحسب النقر مع Control نقرة عادية ويضيف نقطة.
- التمرير بإصبعين على لوحة التتبع يكبّر الورقة (ولا يمررها). للتحريك، اضغط واسحب، أو اضغط على {{key:Space}} مع السحب.
- في اللوحات التي لا تحتوي على Page Up أو Page Down، يُضغط fn مع السهم لأعلى أو لأسفل.
- Backspace هو المفتاح المكتوب عليه delete.
:::

:::windows
- {{key:Mod}} هو Ctrl: {{key:Mod+Z}}، {{key:Mod+S}}، {{key:Mod+O}}.
- على لوحة اللمس في الحاسوب المحمول، يكبّر التمرير بإصبعين الورقة. للتحريك، اضغط واسحب.
:::

:::linux
- {{key:Mod}} هو Ctrl. بعض أسطح المكتب تستعمل اختصارات Ctrl+Alt أو Super الخاصة بها؛ ولا تستعمل TakeoffCraft أيّاً منها.
- على لوحة التتبع، يكبّر التمرير بإصبعين الورقة. للتحريك، اضغط واسحب.
:::

:::touch
تقرأ TakeoffCraft اللمس كمؤشر واحد:

- النقرة تضع نقطة، أو تحدّد علامة، أو تضيف نقطة عدّ.
- السحب بإصبع واحد يحرّك الورقة (وفي {{ui:Auto count}} يرسم مربع البحث).
- التكبير بالقرص غير مدعوم بعد. استعمل {{ui:Fit page}} أو {{ui:Fit width}}، أو {{key:Plus}} و{{key:Minus}} على لوحة المفاتيح.
- لإغلاق مساحة، المس نقطتها الأولى. لإنهاء مسار، انقر نقرتين سريعتين في المكان الذي يحوّل فيه متصفحك النقرتين إلى نقرة مزدوجة، أو اضغط {{key:Enter}} على لوحة المفاتيح.
- لا يظهر قياس الطول الحي حتى تلمس، لأنه لا يوجد تحويم بالمؤشر.

لحصر الكميات اليوم، لوحة المفاتيح مع الفأرة أو لوحة التتبع هي الطريقة الأفضل.
:::

## المفاتيح التي يحتفظ بها المتصفح

تحتفظ المتصفحات ببعض الاختصارات لنفسها، ولا تستطيع الصفحة استعمالها: إغلاق اللسان ({{key:Mod+W}})، أو لسان أو نافذة جديدة ({{key:Mod+T}}، {{key:Mod+N}})، وتكبير المتصفح ({{key:Mod+Plus}}، {{key:Mod+Minus}}). لذلك تُكبّر TakeoffCraft الورقة بعجلة الفأرة وبالمفتاحين {{key:Plus}} و{{key:Minus}} وحدهما. وإذا ضغطت {{key:Mod+Plus}} بالخطأ، تكبر الصفحة كلها؛ و{{key:Mod+0}} يعيدها. انظر [المفاتيح والفأرة ولوحات اللمس](common:keys).

## أين يوجد النقل

لا يوجد أمر نقل: حدّد نقطة عدّ واسحبها، أو حدّد مساحة أو خطاً واسحب مقابض زواياه.

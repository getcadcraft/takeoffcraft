## تقدير التكلفة (ورقة XLSX وملف CSV)

صف لكل بند، يليه صف لكل مكوّن من تجميعته (مُزاح للداخل). ثم صف فارغ والإجمالي الكلي للعمل.

| العمود | المحتوى | في XLSX |
|---|---|---|
| البند (A) | اسم البند (بخط عريض) أو اسم المكوّن (مُزاح) | نص |
| النوع (B) | خطي، مساحة، عدد أو مكوّن | نص |
| الوحدة (C) | LF وm وSF وSY وm² وEA، أو وحدة المكوّن | نص |
| الكمية (D) | الإجمالي المقاس، أو نتيجة المعادلة | رقم |
| نسبة الهدر (E) | الهدر | نسبة مئوية (0.10 = 10%) |
| الكمية مع الهدر (F) | الكمية × (1 + الهدر) | معادلة `D*(1+E)` |
| المواد لكل وحدة (G) | سعر المواد | رقم |
| العمالة لكل وحدة (H) | سعر العمالة | رقم |
| المواد (I) | المواد الممتدة | معادلة `ROUND(F*G,2)` |
| العمالة (J) | العمالة الممتدة | معادلة `ROUND(F*H,2)` |
| الإجمالي (K) | المواد + العمالة | معادلة `I+J` |
| الملاحظات (L) | المعادلة المستخدمة، وخطأ المعادلة، والعلامات على أوراق بلا مقياس، ومساحة الجدار، والمحيط | نص |

صف الإجمالي الكلي: `SUM` للأعمدة I وJ وK عبر كل الصفوف أعلاه، والعبارة "Incomplete: see the notes above" في الملاحظات عند إغفال شيء ما. (الترجمة في الواجهة: "غير مكتمل: انظر الملاحظات أعلاه".)

الصف الذي فيه خطأ معادلة لا كمية له ولا مبالغ؛ وتذكر ملاحظته الخطأ. صف العناوين مثبَّت.

في CSV تحمل الأعمدة نفسها قيماً عادية، ونسبة الهدر رقم بالمئة (10 لـ 10%)، والمبالغ بالدولار بخانتين عشريتين. النص الذي قد يأخذه جدول البيانات كمعادلة (يبدأ بـ `=` أو `+` أو `-` أو `@`) يُسبق بالحرف `'` ليبقى نصاً.

## حسب الورقة (XLSX فقط)

| العمود | المحتوى |
|---|---|
| الورقة | اسم الورقة (مع اسم PDF عندما لا يكون مفتوحاً) |
| البند | اسم البند |
| الكمية | كمية ذلك البند على تلك الورقة، بوحدته |
| الوحدة | وحدة البند |
| العلامات | عدد العلامات |

## العلامات (XLSX فقط)

صف لكل علامة.

| العمود | المحتوى |
|---|---|
| الورقة | اسم الورقة |
| البند | اسم البند |
| النوع | خطي أو مساحة أو عدد |
| الكمية | الطول أو صافي المساحة، أو 1 |
| الوحدة | LF أو m؛ SF أو SY أو m²؛ EA |
| التفاصيل | خطي: أطوال المقاطع، والمقاطع المخصومة مُعلَّمة "(خصم)"، و"يُخصم (الطول) من (الطول) المرسوم". مساحة: المساحة الإجمالية ومساحات الفتحات عند وجود فتحات، والمحيط. "الورقة بلا مقياس" للعلامات غير المقيسة. |
| منطقة الحصر | فقط عندما يحوي الحصر مناطق حصر: مساحة العلامة، أو "بلا منطقة حصر" |

## حسب منطقة الحصر (XLSX فقط، عندما يحوي الحصر مناطق حصر)

| العمود | المحتوى |
|---|---|
| منطقة الحصر | اسم المنطقة، أو "بلا منطقة حصر" |
| البند | البند، أو مكوّن مُزاح تحته |
| الوحدة | وحدة البند أو المكوّن |
| الكمية | المقاس في تلك المنطقة (للمكوّنات: المعادلة على إجماليات المنطقة) |
| الكمية مع الهدر | الكمية × (1 + الهدر) |
| المواد، العمالة، الإجمالي | ممتدة حتى السنت، كما في تقدير التكلفة |
| الملاحظات | المعادلة والأخطاء والعلامات غير المقيسة، كما في تقدير التكلفة |

تنتهي كل منطقة بصف "المجموع الفرعي (الاسم)" تكون تكاليفه معادلات `SUM` على صفوفه؛ والصف الأخير، **كل مناطق الحصر**، يجمع المجاميع الفرعية. وتحوي ورقة **العلامات** عندها عموداً سابعاً هو **منطقة الحصر**.

## المقاييس (XLSX فقط)

صف لكل ورقة لها مقياس أو علامات.

| العمود | المحتوى |
|---|---|
| الورقة | اسم الورقة |
| المقياس | اسم الإعداد المسبق، أو المقياس المعايَر، أو "بلا مقياس" |
| الطريقة | "إعداد مسبق"، أو "معايَرة على (المسافة التي كتبتها)" |
| أقدام لكل وحدة PDF | معامل المقياس الدقيق الذي يستخدمه TakeoffCraft |

## أسماء الملفات

- `(name).xlsx` و`(name).csv`، حيث يُؤخذ الاسم من أول PDF فُتح في الحصر.
- ملف CSV بترميز UTF-8 مع علامة ترتيب البايت ونهايات أسطر Windows، وهو ما تقرؤه برامج جداول البيانات على كل منصة.

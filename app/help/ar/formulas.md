تحصل مكوّنات التجميعة على كميتها من معادلة. المعادلة تعبير حسابي صغير على القيم المقاسة للبند. انظر [التجميعات والمعادلات](topic:assemblies) للأمثلة المحلولة.

## المتغيرات

| نوع البند | المتغير | المعنى |
|---|---|---|
| خطي | `L` | الطول الكلي |
| خطي | `H` | ارتفاع البند |
| خطي | `A` | مساحة الجدار، L × H، مطروحاً منها فتحات المسارات التي تحملها (حصر من BimCraft). عندما يسمّي ذلك الحصر طريقة قياس، تُقاس `A` بها: الفتحات التي لا تتجاوز أصغر حجم في الطريقة تبقى داخلاً، ويُستبعد ما تحسبه الطريقة عند التقاء الجدران. الملاحظة تحت البند تذكر الطريقة |
| خطي | `N` | عدد المسارات |
| مساحة | `A` | صافي المساحة الكلية (المحيطات مطروحاً منها الفتحات) |
| مساحة | `P` | المحيط الكلي، بما فيه حواف الفتحات |
| مساحة | `H` | عمق البند أو سماكته |
| مساحة | `N` | عدد المساحات |
| عدد | `N` | العدد |

- المتغيرات بوحدات البند: انظر [الوحدات](topic:units).
- الحروف الكبيرة والصغيرة سواء: `l` تعني `L`.
- لا تعمل إلا متغيرات نوع البند نفسه. مثلاً `P` في بند خطي تعطي: `"P" is not a measured value here. Use L, H, A, N.`
- الارتفاع أو العمق الفارغ يساوي 0.

## العمليات

| تكتب | المعنى |
|---|---|
| `+` | جمع |
| `-` أو `−` | طرح، أو قيمة سالبة |
| `*` أو `×` | ضرب |
| `/` أو `÷` | قسمة |
| `( )` | تجميع |

تأتي عمليات الضرب والقسمة قبل الجمع والطرح: `L * 2 + 4` تعني (L × 2) + 4. استخدم الأقواس عند الشك.

يمكن أن تحوي الأرقام كسوراً عشرية (`1.333`، `.5`) وأسساً (`1e3` = 1000). المسافات مُهمَلة.

## الدوال

| الدالة | النتيجة | مثال |
|---|---|---|
| `ceil(x)` | التقريب إلى أعلى عدد صحيح | `ceil(67.5)` = 68 |
| `floor(x)` | التقريب إلى أدنى عدد صحيح | `floor(67.5)` = 67 |
| `round(x)` | التقريب إلى أقرب عدد صحيح، والمنتصف بعيداً عن الصفر | `round(2.5)` = 3 |
| `round(x, d)` | التقريب إلى d خانات عشرية (من 0 إلى 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | أصغر قيمة | `min(N, 10)` |
| `max(a, b, …)` | أكبر قيمة | `max(1, ceil(N / 12))` |
| `abs(x)` | القيمة بلا إشارتها | `abs(-3)` = 3 |

تتجاهل `ceil` و`floor` ضجيج التقريب الصغير في الحاسوب، فلا تُقرَّب قيمة يجب أن تكون 1 إلى 2 أبداً.

## الأخطاء

المعادلة التي لا تُقرأ أو لا يمكن حسابها تُظهر خطأها تحت الحقل، ويُستبعد المكوّن من الإجماليات (يقول عنوان {{ui:الكميات}} "غير مكتمل"). الرسائل:

| الرسالة | الإصلاح |
|---|---|
| اكتب معادلة، مثل L أو ceil(L / 1.333) + 1. | المعادلة فارغة. |
| "X" ليست قيمة مقاسة هنا. استخدم … | استخدم أحد المتغيرات المذكورة. |
| "X" ليست دالة هنا. استخدم ceil أو floor أو round أو min أو max أو abs. | استخدم إحدى هذه الدوال. |
| "#" غير مسموح بها في معادلة. | احذف هذا الحرف (الوحدات و`%` و`$` و`=` غير مسموحة). |
| ينقص ")". / يوجد ")" بلا "(" مقابل. | وازن الأقواس. |
| ينقص قيمة قبل ")". | مثل `max(1, )`: أدخل القيمة. |
| المعادلة تنتهي مبكراً. | مثل `L *`: أكملها. |
| غير متوقع "…". هل ينقص عامل؟ | قيمتان متجاورتان، مثل `2L`: اكتب `2 * L`. |
| تأخذ ceil() قيمة واحدة. | أعطِ الدالة عدد القيم الصحيح. |
| تحتاج round(x, digits) إلى أرقام عشرية صحيحة من 0 إلى 10. | استخدم عدداً صحيحاً من الخانات العشرية. |
| المعادلة تقسم على صفر. | عادةً يكون H صفراً: حدّد ارتفاع البند أو عمقه. |
| المعادلة لا تعطي عدداً. | النتيجة أكبر من أن تكون عدداً. |
| المعادلة طويلة جداً (500 حرف كحدّ أقصى). | اختصرها. |

## آمنة بالتصميم

لا تستطيع المعادلة إلا إجراء عمليات حسابية بالمتغيرات والدوال المذكورة أعلاه. لا تستطيع تشغيل شيفرة أو قراءة أي شيء آخر، لذلك فالمعادلة في ملف مشروع يرسله إليك أحدهم غير ضارة.

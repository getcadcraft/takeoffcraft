تحتوي **مكتبة الأسعار** على البنود التي تستخدمها في مشروع تلو آخر: نوعها ووحدتها وارتفاعها وهدرها، وأسعار المواد والعمالة، وتجميعها. وتُحفظ في هذا المتصفح منفصلةً عن أي حصر، فيمكن لكل حصر تفتحه هنا أن يستخدمها.

افتحها بـ{{ui:المكتبة}} أعلى لوحة {{ui:البنود}}.

## تعبئة المكتبة

- يقرأ {{ui:استيراد CSV…}} جدول بيانات محفوظاً بصيغة CSV (راجع الأعمدة أدناه). تُستبدل البنود التي يتطابق اسمها ونوعها مع بند في المكتبة، وتُضاف الباقي. وتُتجاوز الصفوف التي لا يستطيع قراءتها، ويذكر أيها وسبب ذلك.
- يَنسخ {{ui:إضافة بنود هذا الحصر}} كل بند في الحصر المفتوح إلى المكتبة، مع أسعاره وتجميعته (دون علاماته).
- يُستورد ملف CSV لتقدير التكلفة الذي يصدّره TakeoffCraft ([تصدير التقدير](topic:export-estimate)) كما هو: أسعار المشروع الأخير تكون أساساً للمشروع التالي.

- يضيف {{ui:حزم الأعمال…}} تجميعات مجانية لحرفة، مثل الجبس والكهرباء والخرسانة، دون أسعار. راجع [حزم الأعمال](topic:trade-packs).

يحفظ {{ui:تصدير CSV}} المكتبة كملف CSV، للاحتفاظ بنسخة، أو لتحريرها في جدول بيانات، أو لإعطائها لزميل. ويُفرغها {{ui:مسح}} (انقر مرتين).

:::note
تعيش المكتبة في تخزين هذا المتصفح. ولكل متصفح آخر أو حاسوب آخر أو نافذة خاصة مكتبته (أو لا مكتبة لها). صدّرها لنقلها.
:::

## استخدامها في حصر

- حدّد البنود (واكتب في {{ui:ابحث في المكتبة}} لتضييق القائمة)، واختر {{ui:إضافة إلى الحصر}}. تُضاف مع تجميعاتها في خطوة واحدة يتراجع عنها {{key:Mod+Z}}. ويحصل الاسم الموجود في الحصر بالفعل على رقم، مثل `Carpet (2)`.
- يمنح {{ui:تحديث الأسعار}} بنود الحصر هدر المكتبة وأسعارها، لكل بند يتطابق اسمه ونوعه مع بند في المكتبة، والأمر نفسه لمكوّنات التجميعة التي لها الاسم نفسه. وتبقى الارتفاعات والوحدات والمعادلات كما هي. ويعيد {{key:Mod+Z}} مرة واحدة كل الأسعار القديمة.

## أعمدة CSV

يسمّي الصف الأول الأعمدة، بأي ترتيب؛ وتُتجاهل الأعمدة الأخرى.

| العمود | ما يُكتب فيه |
|---|---|
| Item (or Name) | اسم البند. مطلوب. |
| Type | Linear أو Area أو Count (وتعمل LF وSF وEA أيضاً). إن تُرك فارغاً، تحدد الوحدة النوع. |
| Unit | LF أو m؛ وSF وSY أو m²؛ وEA. إن كان فارغاً فوحدة النوع المعتادة. |
| Waste % | `10` أو `10%`. |
| Material per unit, Labor per unit | أسعار مثل `2.10` أو `$1,250`. |
| Height (or Depth) | `9'-0"` أو `9` أو `2.7` للوحدات المترية. |
| Component, Formula | صف فيه اسم مكوّن (أو النوع `Component`) هو جزء من تجميعة البند الذي فوقه. وله وحدته وهدره وأسعاره الخاصة؛ ومعادلته تستخدم أحرف البند، راجع [التجميعات والمعادلات](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

الفواصل، أو الفواصل المنقوطة، أو علامات الجدولة بين الأعمدة كلها تعمل.

Isilinganiso sezindleko silinganisa lokho okukalile. **Isifinyezo sethenda** siyishintsha ibe yintengo: sengeza intela yokuthengisa, izindleko zokuphatha, inzuzo nebhondi, futhi senza **i-PDF yesiphakamiso** nokufakiwe kwakho nokungafakiwe.

Vula kusuka ku-{{ui:Export}} › {{ui:Bid summary & proposal…}}. Konke okukuso kugcinwa kanye nokubala, futhi ushintsho ngalunye lungahlehliswa.

## Ukumaka

Bhala iphesenti kunoma iyiphi kwezinhlanu (shiya ezinye ku-0). Ziqoqwa ngale ndlela, ngayinye phezu kwalokho okungaphezulu kwayo:

| Umugqa | Kubalwa njenge |
|---|---|
| Izinto, Umsebenzi | Amanani esilinganiso sezindleko (ithenda elisisekelo uma ukubala sekunokukhetha [okukhethwayo](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts)). |
| Umthwalo womsebenzi | % womthwalo × umsebenzi: intela yomholo, ukuvikelwa nezinzuzo ezinholweni zezisebenzi zakho. |
| **Izindleko** | Izinto + umsebenzi + umthwalo womsebenzi. |
| Intela yokuthengisa ezintweni | % yentela × izinto. |
| Izindleko zokuphatha | % wokuphatha × (izindleko + intela). |
| Inzuzo | % wenzuzo × (izindleko + intela + izindleko zokuphatha). |
| Ibhondi | % webhondi × konke okungenhla. |
| **Ithenda** | Isamba semigqa. |

Umugqa ngamunye uzungezwa ukuya kusenti. Incwadi yokusebenza ikhombisa imigqa efanayo ngaphansi kwesamba sethebula le-Estimate, ngamafomula aphilayo. Isifinyezo siyavuselelwa njengoba uthayipha: {{key:Enter}} ithatha iphesenti. Ukukhetha ngakunye kukhonjiswa ngezinkulungwane ezifanayo ngezindleko zakho, ukuze umnikazi abone ukuthi ukususa kwakho kushintsha kanjani ngempela.

## Isiphakamiso

Gcwalisa okufanele isiphakamiso sikutshele:

- **Iphrojekthi** (igama lebalo uma lingenalutho), **Ku** (ikliyenti) no-**Ukusuka** (inkampani yakho).
- **Okufakiwe** no-**Okungafakiwe**: eyodwa ngomugqa; udashi noma ibhulethi ngaphambili kuyalungile.
- **Imigomo**: umbhalo ongakhethiwe, njengo "Kusebenza izinsuku ezingama-30."
- **Dweba izinto nezinani**: umsebenzi, into ngayinye, namanani, kungekho mitengo. Susa ukuthikwa ukuze ube isiphakamiso sesamba esisodwa.

Khetha {{ui:Proposal PDF}}. I-PDF (`<takeoff> - proposal.pdf`) inedethi, ibhlogo yentengo enakho konke ukumaka nethenda, okukhethwayo, umsebenzi, okufakiwe nokungafakiwe, imigomo, nemigqa yokusayina nedethi. Uma amanye amanani engakwazi ukulinganiswa (ishidi elingenasikali), lokho kubhalwa ngaphansi kwentengo.

## Ku-exports

Uma ukubala sekunesifinyezo sethenda, i-CSV iphela ngaso futhi incwadi yokusebenza ithola ishidi le-**Bid summary**, ngomugqa ngamunye, iphesenti lawo nesamba lawo. Bona [Thumela isilinganiso sezindleko](topic:export-estimate).

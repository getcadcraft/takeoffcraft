TakeoffCraft isathuthukiswa. Lolu luhlu lubonisa okungenziwa yile bhilidi yamanje, nokuthi umsebenzi ungenziwa kanjani namuhla.

## Ukukala

| Akukakhiwa | Esikhundleni, namuhla |
|---|---|
| Ukufaka iphoyinti phakathi komugqa noma umbandela | Susa uphawu bese uludweba futhi. |
| Ukukhetha ngebhokisi (iwindi) | {{key:Shift}} + ukuchofoza ngayinye yamamaki, noma {{key:Mod+A}} kuwo wonke amamaki eshidi. Bona [Kopisha, namathisela futhi phinda amamaki](topic:copy-paste). |
| Ukujikeleza, ukubuyisela phansi noma ukushintsha isikali sekhophi enamathisiwe | Namathisela eshidini ngesikali nangokuqondiswa okufanayo; dweba okunye ngesandla. |
| Ukufunda isikali eshidini elisiwe noma kubha yesikali esiyisithombe | Khetha isethi ekhona, noma linganisa ngobude bebha. |
| Isikali esingaphezu kwesisodwa eshidini (izindawo zemininingwane, amapulani akhulisiwe) | Linganisa ingxenye ngesikali seshidi, bese ubala imininingwane eshidini layo elikhulisiwe uma isethi inalo. |

## Izinto nentengo

| Akukakhiwa | Esikhundleni, namuhla |
|---|---|
| Izifomula zenhlanganisela ezisebenzisa ezinye izinhlobo zamamakiento (izimnyango zegumbi kwizifomula zesitezi salo) | Izifomula zisebenzisa izipheluzi zohlobo oluyinhloko; nika ezinye izinhlobo intengo emigqeni yazo. |
| Izifomula zenhlanganisela ezibalwa umugqa ngomugqa | Izifomula zisebenzisa izipheluzi zento; sebenzisa `N` ngezengeziwe zomugqa ngamunye. |
| Izifomula ezisebenzisa amanani enye into | Phinda ukulinganisa kuleyo nto, noma uyibale kusiphephelo se-spreadsheet esithunyelwe. |
| Amaqembu ezingxenyeni zenhlanganisela, noma usuku lokusebenza olungelona amahora angu-8 | Nikeza iqembu into; funda izinsuku zeqembu kusuku olunobude obehlukile njengamahora eqembu ÷ usuku lwakho. |
| Ukumaka okungelona amanothi, amafu nokukhanyisa (imicibisho, izilinganiso, izitembu), noma izimpendulo kunothi | Yibhale kumbhalo wenothi; shintsha isimo sawo njengoba kuxazululwa. |
| Umtapo wezintengo oqhelelene yiqembu, noma ogcinwe ne-akhawunti yakho | Umtapo ugcinwa kule bhrawuza: uwuthumele njenge-CSV bese uwungenisa kenye ikhompyutha. |
| Amaphakhi wokuhweba ahlolwe ngabalinganisi besikhathi esigcwele | Yonke iphakhi iyisiqalo: hlola izimo zayo ngomsebenzi wakho nangemikhiqizo yakho ngaphambi kokubala intengo ngayo. Bona [Amaphakhi wokuhweba](topic:trade-packs). |
| Izintengo emaphakhini wokuhweba | Amaphakhi anikeza izinhlanganisela kuphela: setha amazinga akho, noma ungenise uhlu lwakho lwentengo njenge-CSV. |
| Ukuqamba kabusha ukubala | Igama lithathwa kuPDF yokuqala; qamba kabusha amafayela alayishiwe. |
| Ukuqamba amashidi ngesandla | Amashidi aqanjwa ngamalebula amakhasi e-PDF; sesha ngegama lefayela nekhasi. |

## Imidwebo (DWG ne-DXF)

| Akukakhiwa | Esikhundleni, namuhla |
|---|---|
| Amathebula wesitayela sokuprinta, izabelo zepeni namafayela e-CTB emashidini omdwebo | Umdwebo udwetshwa mnyama, noma ngemibala yawo emnyama ukuze ufaneleke iphepha; ubukhulu bemigqa buvela kumdwebo. |
| Ukuvula i-DXF yebinary, noma i-DWG edlula i-AutoCAD 2000 | Yigcine njenge-DXF ye-ASCII noma njenge-DWG entsha. |
| Ukuthola umdwebo oxhunyiwe (xref) ngesikhwama esiwuphethe | Vula nofayela lomdwebo oxhunyiwe, kanye nomdwebo owubambe: utholakala ngegama lefayela phakathi kwamafayela avulekile. |
| Ukulinganisa imigqa ye-3D, ama-mesh, izinto eziqinile nezindawo | Zibale ngengqimba nangohlobo, noma linganisa ukubukwa kwepulani ngamathuluzi i-Linear ne-Area. |
| Umbhalo ku-PDF emakiwe ovela komdwebo ngezinhlelo zokubhala ezingeziso zaseLatin | Izinhlamvu ezingenagilifu ku-Helvetica zikhishwa njenge-"?" ku-PDF emakiwe; umdwebo esikrinini awuthintekile. |
| Ukudluliselwa komdwebo kolunye uhlelo kusuka ebha yeshidi | Vula leli fayela kulolo hlelo. |
| Umdwebo oqukethe ukubala ngaphakathi kwawo, njengoba {{ui:I-PDF enomsebenzi ongaphakathi}} kwenza ama-PDF | {{ui:Londoloza ukubala amanani}}: i-`.takeoff.json` ivuleka kabusha kumdwebo ofanayo, ithole ngokuqukethwe kwawo. |
| Izingaphansi ze-PDF, izithombe nezinto ze-OLE ezibekwe emdwebeni | Izithombe zibonakala njengohlaka kuphela. Vula i-PDF yengaphansi njengeshidi. |

## Amashidi ezibalo

Incwadi ye-XLSX ihlolwe ku-LibreOffice Calc, eyabala kabusha zonke izinhlobo zobuningi ngesenti efanayo ne-TakeoffCraft. Ayikavulwa ku-Excel. Uma uhlelo lwamashidi lukhombisa okungalindelekile, uhlu lwe-CSV lugcina isilinganiso esifanayo njengamanani avamile.

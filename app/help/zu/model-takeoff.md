Akudingeki ulinde isethi elandelayo yemidwebo. Uma umklami ethumela imodeli yesakhiwo, yivule lapha bese uthatha amanani ngqo kuyo. Imodeli ifundwa kukhompyutha yakho; akukho okuthunyelwa noma kanjani.

## Izinyathelo

1. Khetha {{ui:Model}} kwibha yamathuluzi bese ukhetha ifayela `.ifc` lemodeli, noma usebenzise {{ui:Open plans}} njengakunoma yiliphi elinye ifayela.
2. {{ui:Model takeoff}} ivula ngomugqa owodwa ngesigaba nangohlobo: izindonga ngohlobo lwezindonga, amaphansi ngohlobo lwamaphansi, izimnyango ngohlobo lwezimnyango, njalo njalo. Umugqa ngamunye ubonisa inani lawo nokuthi lesi sigaba silinganiswa ngani.
3. Setha {{ui:Group by}} ibe {{ui:Category}} ukuze uthole isamba esisheshayo, noma ibe {{ui:Category, type and level}} ukuze uhlukanise zonke izinhlobo ngokwamazinga.
4. Susa utiki emigqeni ongayifuni. {{ui:Find}} inciphisa uhlu. Ukususa utiki komugqa kufiha nezingxenye zawo esithombeni se-3D.
5. Nika imodeli {{ui:Model name}} ozoyigcina kuyo yonke le misebenzi, isibonelo igama lephrojekthi.
6. Khetha {{ui:Add to the takeoff}}. Inani ngalinye liba yinani elinohlobo kuhlu lwezinto. Liqambe, linike amanani bese uxhuma izinhlanganisela njengakunoma yiyiphi enye into.

## Bona imodeli nge-3D

{{ui:Show the model in 3D}} idweba imodeli phezu kwethebula, umbala owodwa ngomugqa ngamunye (ichibi lombala eduze kwegama lomugqa). Hudula ukuze uyiphendule, bamba {{key:Shift}} uhudule ukuze uyinyakazise, sebenzisa inkeke ukuze usondeze, bese ukhetha {{ui:Fit}} noma {{ui:Reset}} ukuze ubuyele.

- **Chofoza ingxenye** esithombeni bese umugqa wayo ukhethwa ethebulini, zonke izingxenye zalo umugqa zikhanye nezinye zibe mpunga. Chofoza ingxenye efanayo futhi uma ikhona kumigqa eminingi (udonga ngezendlalelo zalo), umugqa olandelayo uyakhethwa.
- **Chofoza umugqa** ethebulini ukuze ukhanyise izingxenye zawo. Chofoza futhi, noma chofoza indawo engenalutho esithombeni, ukuze uwususe.
- Amagumbi awadwetshwa, ngoba ivolumu yegumbi ingafihla isakhiwo.
- Imodeli enkulu kakhulu igcina ibhokisi kuphela kwezinye izingxenye ukuze ifake enkumbulweni; ipaneli ikhomba ukuthi zingaki. Amanani awashintshi.

Uma le khompyutha ingenakudweba i-3D, ethebula lisebenza njengakuqala.

## Qoqa ngempahla yokwakha, ungqimba noma usayizi

{{ui:Group by}} inezinketho ezintathu ezengeziwe:

- {{ui:Category and material}}: udonga, iphansi noma uphahla oyakhiwe ngezendlalelo kunika impahla yokwakha yendlalelo ngayinye umugqa wayo, ukuze i-drywall, ama-studs nokufakwa kokushisa kunikezwe amanani ahlukene. Ingxenye yesakhiwo enempahla eyodwa ithola umugqa walowo mpahla, kanti engenayo igcinwa emgqeni othi "Akukho mpahla egamiwe".
- {{ui:Category and layer}}: okufanayo, kodwa umugqa ubonisa ukuqina kwendlalelo kuwo ("Insulation, 100 mm").
- {{ui:Category, type and door or window size}}: izimnyango namawindi ahlukaniswa ngobubanzi nobude bawo (isibonelo 3'-0" × 6'-8" noma 914 × 2,032 mm).

Ngendlalelo, indawo iba ubuso bodonga (noma indawo yephansi noma yophahla ngokuhlelwa noma ngobuso), ivolumu ibe yile ndawo iphindwe ngokuqina kwendlalelo. Inothi lomugqa likhomba ukuthi amanani angaki avela endlalelweni. Izendlalelo zodonga oyedwa zingeza ndawonye zifike evolumini imodeli eyibhala ngalo.

## Londoloza imigqa noma izimbobo njenge-CSV

{{ui:Save rows as CSV}} igcina imigqa oyikhethile, namayunithi ekhanda ngalinye, ukuze kusetshenziswe ishidi lezibalo. {{ui:Save openings schedule as CSV}} (kuphela uma imodeli inezimnyango noma amawindi) igcina zonke izimnyango namawindi ngohlobo, izinga, usayizi kanye nenani lawo.

## Okulinganiswayo

| Isigaba | Amanani |
|---|---|
| Izindonga | inani, ubude, indawo yodonga (ubuso obubodwa, izimbobo zisusiwe), ivolumu |
| Amaphansi, amaslebhu, amasilingi nezinye izembozo | inani, indawo yepulani, ivolumu |
| Uphahla | inani, indawo yepulani, ubuso bophahla, ivolumu |
| Izisekelo | inani, indawo yepulani, ivolumu |
| Insika, amabhimu nezinye izingxenye | inani, ubude ngasemgqeni wengxenye, ivolumu |
| Izibambelelo, amapayipi, amapayipi omoya nemigqa yezintambo zikagesi | inani, ubude |
| Izitebhisi | inani, ivolumu |
| Amagumbi | inani, indawo yephansi, ivolumu |
| Izimnyango, amawindi nokunye konke | inani |

Uma umklami wemodeli eshe inani efayeleni, leyo nombolo iyasetshenziswa. Uma kungenjalo, inombolo ilinganiswa kusuka ekwakhekeni kwesakhiwo. Inani ngalinye ligcina inothi elisho ukuthi yiyiphi, nokuthi izinto ezingaki zinike inombolo.

:::note
Ubude bodonga olulinganiswe ekwakheni kwalo luhamba kusuka esiphelweni kuya esiphelweni, ngakho izindonga ezimbili ezihlangana ekhoneni zombili zifaka leli khona. Ivolumu idinga ukwakheka okuvaliwe: into engavali ukwakheka kwayo iyabalwa kodwa ayinikezi ivolumu. Into yodonga egobile noma enekhona ilinganiswa njengohhafu wazo zonke izinhlangothi zayo ezimile, nothi lwayo luyasho lokho.
:::

## Uma imodeli entsha ifika

Vula ifayela elisha bese uthayipha {{ui:Model name}} efanayo. Ngaphambi kokuthi wengeze noma yini, ipaneli itshela ukuthi zingaki izinani ezintsha, zingaki ezishintshile nokuthi zishintshe kusuka kwini kuya kwini, nokuthi yiziphi izinani ekhophini langaphambili ezingasekho emodelini. Khetha {{ui:Add to the takeoff}}: izinani ezishintshile zithatha izinombolo zazo ezintsha, kanti amagama akho, amazinga, ukuchitheka kanye nezinhlanganisela zihlala kanjalo. Izinani ezinyamalele emodelini zigcina izinombolo zazo ezindala; zisuse wena uqobo uma idizayini izilahlile.

Amagama ohlobo nezinga yindlela inani elibonakala ngayo. Uma umklami eqamba kabusha uhlobo lodonga, lifika njengenani elisha, bese elidala lidweshwa njengelinyamalele.

## Amafayela afundwa lapha

Amafayela e-IFC (IFC2x3, IFC4 and IFC4.3). Ifayela le-IFC elinemigwaqo, imigqa yesitimela noma amabhuloho liyaqhubeka lilethe amanani ezakhiwo zalo ngqo, njengakuqala.

I-TakeoffCraft ayifundi amafayela `.rvt` kulokhu kukhishwa. Uma umklami esebenza ku-Revit, cela ukuthunyelwa kwe-IFC kwemodeli (File, Export, IFC) bese uyivula leyo.

Imodeli eyodwa ingaletha kuze kube amanani angu-500 ngesikhathi esisodwa. Uma kukhona amaningi, susa utiki imigqa noma qoqa ngesigaba.

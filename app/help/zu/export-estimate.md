Ukuthumela kuyizinkomba zokulanda. Zenziwa ekhompyutheni yakho kusukela ekubaleni namaPDF avuliwe; akukho okuthunyelwa noma yikuphi.

## Isilinganiso njenge-spreadsheet (XLSX)

1. Vula imenyu ethi {{ui:Thumela}} ethuleni bese ukhetha {{ui:XLSX}}.
   Isiphequluli sakho silanda `(name).xlsx`. Ibha yesimo ithi "Kuthunyelwe (name).xlsx (isilinganiso nezifomula eziphilayo, ngeshidi, ngemaki, izikali)." bese ingeza isexwayiso uma isilinganiso singaphelele.
2. Vula kuhlelo lwakho lwe-spreadsheet.

I-workbook inamashidi amane, namanye ama-report alandelayo uma ehambisana:

| Ishidi | Okuqukethwe |
|---|---|
| Estimate | Umugqa ngento nangekhomponenti ngayinye: inani, udoti, inani nodoti, amarethi, impahla, umsebenzi, isamba, amanothi. Isamba sephrojekthi ngaphansi. |
| By sheet | Inani lento ngayinye kushidi ngalinye, nenani lemaki. |
| Marks | Imaki ngayinye: ishidi, into, uhlobo, inani, nemininingwane (ubude bezingxenye, izindawo ezigcwele nezikhishiwe, umjikelo). |
| Scales | Ishidi ngalinye elinesikali noma amaemaki: isikali salo, ukuthi sasethwa kanjani (ipreset, noma silinganiswe ngebanga elifakiwe), namafidi ngeyunithi ye-PDF. |
| Takeoff summary | Inani lento ngayinye, inombolo ye-CSI, amaemaki namashidi, ngaphandle kwamanani. |
| Material list | Yonke ingxenye yokuhlanganiswa ifakwe ndawonye ekubaleni (ingxenye efanayo esetshenziswa izinto eziningi ingumugqa owodwa), nodoti nezindleko zempahla, nezinto eziyisebenzisayo. |
| Quote request | Uhlu lwempahla lokuthumela kumnikezi: izinani nodoti, ikholomu yamarethi amayunithi engenalutho, nezengeziwe nesamba ezigcwalisa uma amanani efakwa. |
| By division | Impahla, umsebenzi nesamba ngesigaba se-CSI MasterFormat, uma izinto zinenombolo ye-{{ui:Inombolo ye-CSI}}. |

Nge[isifinyezo sethenda](topic:bid-summary), ishidi le-Estimate liphela nemarkup yalo (inzuzo yabasebenzi, intela yokuthengisa, izindleko zokuphatha, inzuzo, ibhondi nethenda), njengezifomula eziphilayo.

Ishidi le-Estimate ligcina **izifomula eziphilayo**: inani nodoti, izinani zempahla nomsebenzi ezizungeziwe, isamba sawo wonke umugqa nesamba sephrojekthi. Izinhlelo ze-spreadsheet ziyabala kabusha, ngakho ungashintsha irethi noma udoti kuspredishithi bese amasamba ayalandela. Izinombolo ezibalwe yi-TakeoffCraft nazo zigcinwe emaseli, futhi ziyafana kuze kube yisenti.

Ikholomu yamanothi ibala ifomula yekhomponenti ngayinye, amaphutha ezifomula, amaemaki emashidini angenasikali, indawo yodonga nomjikelo. Uma kukhona okushiyiwe, umugqa wesamba sephrojekthi uthi "Incomplete: see the notes above".

I-workbook ihlolwe ku-LibreOffice Calc, yabalwa kabusha yanikeza amasamba afanayo. Ayikavulwa ku-Excel. Imininingwane ngekholomu ngayinye itholakala ku-[Amakholomu okuthumela](topic:export-columns).

## Isilinganiso njenge-CSV

Vula imenyu ethi {{ui:Thumela}} bese ukhetha {{ui:CSV}}. Uthola `(name).csv`: imigqa namakholomu afanayo nalawo weshidi le-Estimate, njengamanani avamile (akukho zifomula), kanye nesamba sephrojekthi. Sebenzisa ukunamathisela kwenye inhlelo yezilinganiso noma yezezimali.

I-CSV inesilinganiso kuphela; ngamanani ngeshidi nohlu lwemaki, sebenzisa i-XLSX. {{ui:Uhlu lwezinto zokwakha}} kumenyu efanayo ilondoloza uhlu lwempahla lodwa njenge-CSV, lokuyala.

## Isilinganiso ku-Google Sheets

Ngaphezulu kwethebhula lamanani, **Kopisha ye-Google Sheets** ufaka isilinganiso ekhliphodini njengombhalo ohlukaniswe ngamathebhu, ngemigqa efanayo ne-CSV. Ku-Google Sheet, chofoza iseli A1 bese unamathisela. I-TakeoffCraft ayingeni ngemvume ku-Google futhi ayithumeli lutho lapho.

## Amarethi angekho nokusayina

Umugqa onamanani kodwa ongenarethi uthi **No rate** kumanothi wawo, futhi ukuthumela kuwabala ngaphansi kwamasamba. Uma isilinganiso sasayinwa, ukuthumela kukhomba ukuthi ubani asayina, nini nangani isamba. Bheka [Amarethi angekho nokusayina isilinganiso](topic:sign-off-the-estimate).

## PDF emakwe

1. Vula ama-PDF ofuna ukuwadweba amaemaki awo.
2. Vula imenyu ethi {{ui:Thumela}} bese ukhetha {{ui:Marked PDF}}. Kuvela "Ibhala i-PDF emakwe…", bese isiphequluli sakho silanda ifayela elilodwa nge-PDF emakwe ngayinye, igama layo ngu `(PDF name) (takeoff).pdf`.

Kwikhophi:

- imigqa idwetshwe njengemigqa ngombala wento yayo,
- izindawo zigcwaliswe kancane ngomugqa oqinile, nezikhishiwe zishiywe zivulekile,
- amanani ngamachashazi,
- ikhasi ngalinye elinemaki lithola ilejendi encane ekhoneni laso eliphansi kwesobunxele: umbala wento ngayinye, igama nenani kulelo khasi.

Ama-PDF akho ayinhloko awashintshiwe.

Amanothi:

- Kubhalwa ama-PDF avuliwe kuphela. Amaemaki kuma-PDF angavulekile ahlala emagameni ahlanganisiwe kodwa awadwetshwanga; vula lawo ama-PDF kuqala.
- Amagama asendabeni yelejendi asebenzisa ifonti evamile ye-PDF. Izinhlamvu ezingakwazi ukuboniswa ziphrintwa njenge-"?".
- I-PDF ebethelwe ingeke ikopishwe nemaki: "Le PDF ivikelwe ngephasiwedi noma ifihliwe, ngakho ikhophi enemaki ayikwazi ukubhalwa. Ukubala ngokwakho kulungile; thumela i-spreadsheet esikhundleni salokho."
- Okokuqala {{ui:Marked PDF}} ethebhu ilayisha umbhali we-PDF. Ngaphandle kwe-inthanethi, ikhona kuphela uma ibha ye-app ibonisa {{ui:Ilungele ukusetshenziswa ngaphandle kwe-inthanethi}}; bheka [Ukusebenza ngaphandle kwe-inthanethi](common:offline).

:::chromium
Uma kunama-PDF amaningi amakwe, i-Chrome ne-Edge zingabuza kanye ukuthi lesi sayithi singavumela yini ukulanda amafayela amaningi. Khetha Vumela, noma uzothola ifayela lokuqala kuphela.
:::

## Akukho okuthunyelwayo?

- {{ui:XLSX}} ne-{{ui:CSV}} zidinga okungenani into eyodwa: "Akukho okuthunyelwayo okwamanje: yenza into bese uyibala."
- {{ui:Marked PDF}} idinga amaemaki kuPDF evuliwe: "Akukho maemaki kuma-PDF avuliwe okwamanje."

## Londoloza ukubala futhi

Ukuthumela kuyombiko. Ukuze uqhubeke nokusebenza ngokubala kamuva, khetha futhi {{ui:Londoloza ukubala amanani}}: bheka [Londoloza nevule futhi ukubala](topic:save-and-reopen).

Ukuze wengeze izindleko zokuphatha, inzuzo, intela nebhondi bese uthumela isiphakamiso, bheka [Isifinyezo sethenda nesiphakamiso](topic:bid-summary).

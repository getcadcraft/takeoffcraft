असेम्बली घटकहरूले तिनीहरूको परिमाण सूत्रबाट लिन्छन्। सूत्र आइटमका मापन गरिएका मानहरूमाथिको सानो अंकगणित अभिव्यक्ति हो। उदाहरणका लागि [असेम्बली र सूत्रहरू](topic:assemblies) हेर्नुहोस्।

## चरहरू

| आइटमको प्रकार | चर | अर्थ |
|---|---|---|
| रेखीय | `L` | कुल लम्बाइ |
| रेखीय | `H` | आइटमको उचाइ |
| रेखीय | `A` | भित्ताको क्षेत्रफल, L × H, खुला भागहरू घटाएर (BimCraft बाट परिमाण गणना)। जब त्यो परिमाण गणनाले मापन विधि नाम दिन्छ, `A` त्यसबाट नापिन्छ: विधिको सबैभन्दा सानो आकारभन्दा नबढ्ने खुला भागहरू भित्र रहन्छन्, र भित्ताहरू जोडिने ठाउँमा विधिले लिने भाग छोडिन्छ। आइटमअन्तर्गतको टिप्पणीले विधिको नाम दिन्छ |
| रेखीय | `N` | रनहरूको संख्या |
| क्षेत्रफल | `A` | कुल खुद क्षेत्रफल (रूपरेखा घटाउने कटाइएका भाग) |
| क्षेत्रफल | `P` | कुल परिधि, कटाइएका भागका किनारासहित |
| क्षेत्रफल | `H` | आइटमको गहिराइ वा मोटाई |
| क्षेत्रफल | `N` | क्षेत्रहरूको संख्या |
| गणना | `N` | गणना |

- चरहरू आइटमका एकाइमा हुन्छन्: [एकाइहरू](topic:units) हेर्नुहोस्।
- ठूलो र सानो अक्षर उस्तै हो: `l` `L` हो।
- आइटमको आफ्नै प्रकारका चरहरू मात्र काम गर्छन्। रेखीय आइटममा `P` ले `"P" is not a measured value here. Use L, H, A, N.` को सट्टा `"P" यहाँ मापन गरिएको मान होइन। L, H, A, N प्रयोग गर्नुहोस्।` दिन्छ।
- खाली उचाइ वा गहिराइ 0 हो।

## अपरेटरहरू

| लेख्नुहोस् | अर्थ |
|---|---|
| `+` | जोड्नु |
| `-` वा `−` | घटाउनु, वा ऋणात्मक मान |
| `*` वा `×` | गुणन |
| `/` वा `÷` | भाग |
| `( )` | समूह बनाउनु |

गुणन र भाग जोड र घटाउभन्दा पहिले हुन्छन्: `L * 2 + 4` (L × 2) + 4 हो। शंका लाग्दा कोष्ठक प्रयोग गर्नुहोस्।

संख्यामा दशमलव (`1.333`, `.5`) र घातांक (`1e3` = 1000) हुन सक्छन्। खाली ठाउँहरू बेवास्ता गरिन्छन्।

## फङ्सनहरू

| फङ्सन | नतिजा | उदाहरण |
|---|---|---|
| `ceil(x)` | पूर्ण संख्यामा माथि गोलो | `ceil(67.5)` = 68 |
| `floor(x)` | पूर्ण संख्यामा तल गोलो | `floor(67.5)` = 67 |
| `round(x)` | नजिकको पूर्ण संख्यामा गोलो, आधा शून्यबाट टाढा | `round(2.5)` = 3 |
| `round(x, d)` | d दशमलवमा गोलो (0 देखि 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | सबैभन्दा सानो मान | `min(N, 10)` |
| `max(a, b, …)` | सबैभन्दा ठूलो मान | `max(1, ceil(N / 12))` |
| `abs(x)` | चिन्हबिनाको मान | `abs(-3)` = 3 |

`ceil` र `floor` ले कम्प्युटरको सानो गोलो गर्ने आवाज बेवास्ता गर्छन्, त्यसैले ठ्याक्कै 1 हुनुपर्ने मान कहिल्यै 2 मा गोलो हुँदैन।

## त्रुटिहरू

पढ्न वा गणना गर्न नसकिने सूत्रले फिल्डमुनि आफ्नो त्रुटि देखाउँछ, र घटक कुल जोडबाट छोडिन्छ ({{ui:Quantities}} शीर्षकमा "अपूर्ण" लेखिन्छ)। सन्देशहरू:

| सन्देश | उपाय |
|---|---|
| सूत्र टाइप गर्नुहोस्, जस्तै L वा ceil(L / 1.333) + 1। | सूत्र खाली छ। |
| "X" यहाँ मापन गरिएको मान होइन। … मध्ये एउटा प्रयोग गर्नुहोस्। | सूचीबद्ध चरहरूमध्ये एउटा प्रयोग गर्नुहोस्। |
| "X" यहाँ फङ्सन होइन। ceil, floor, round, min, max, abs प्रयोग गर्नुहोस्। | ती फङ्सनहरूमध्ये एउटा प्रयोग गर्नुहोस्। |
| सूत्रमा "#" अनुमति छैन। | त्यो अक्षर हटाउनुहोस् (एकाइ, `%`, `$` र `=` अनुमति छैन)। |
| ")" छुटेको छ। / ")" त्यसको "(" बिना छ। | कोष्ठकहरू बराबर गर्नुहोस्। |
| ")" अघि मान छुटेको छ। | जस्तै `max(1, )`: मान भर्नुहोस्। |
| सूत्र चाँडै सकियो। | जस्तै `L *`: पूरा गर्नुहोस्। |
| अपेक्षित नभएको "…"। अपरेटर छुटेको हो? | दुई मान छेउछेउमा, जस्तै `2L`: `2 * L` लेख्नुहोस्। |
| ceil() ले 1 मान लिन्छ। | फङ्सनलाई सही संख्याका मान दिनुहोस्। |
| round(x, digits) लाई 0 देखि 10 सम्मका पूर्ण अंक चाहिन्छ। | पूर्ण संख्यामा दशमलव प्रयोग गर्नुहोस्। |
| सूत्रले शून्यले भाग गर्छ। | प्रायः H 0 हो: आइटमको उचाइ वा गहिराइ सेट गर्नुहोस्। |
| सूत्रले संख्या दिँदैन। | नतिजा संख्याका लागि धेरै ठूलो छ। |
| त्यो सूत्र धेरै लामो छ (अधिकतम 500 अक्षर)। | छोटो बनाउनुहोस्। |

## सुरक्षित डिजाइनद्वारा

सूत्रले माथि सूचीबद्ध चरहरू र फङ्सनहरूसँग मात्र अंकगणित गर्न सक्छ। यसले कोड चलाउन वा अरू केही पढ्न सक्दैन, त्यसैले कसैले तपाईंलाई पठाएको परियोजना फाइलमा रहेको सूत्र हानिरहित हुन्छ।

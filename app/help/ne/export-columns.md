## अनुमान (XLSX कार्यपत्र र CSV)

प्रति आइटम एउटा पङ्क्ति, त्यसपछि उसको असेम्बलीको प्रति घटक एउटा पङ्क्ति (इन्डेन्ट गरिएको)। त्यसपछि एउटा खाली पङ्क्ति र कामको कुल जोड।

| स्तम्भ | सामग्री | XLSX मा |
|---|---|---|
| A आइटम | आइटमको नाम (बोल्ड) वा घटकको नाम (इन्डेन्ट) | पाठ |
| B प्रकार | Linear, Area, Count वा Component | पाठ |
| C एकाइ | LF, m, SF, SY, m², EA, वा घटकको एकाइ | पाठ |
| D परिमाण | मापन गरिएको कुल, वा सूत्रको नतिजा | संख्या |
| E फोहोर % | फोहोर | प्रतिशत (0.10 = 10%) |
| F फोहोरसहितको परिमाण | परिमाण × (1 + फोहोर) | सूत्र `D*(1+E)` |
| G सामग्री प्रति एकाइ | सामग्री दर | संख्या |
| H श्रम प्रति एकाइ | श्रम दर | संख्या |
| I सामग्री | विस्तारित सामग्री | सूत्र `ROUND(F*G,2)` |
| J श्रम | विस्तारित श्रम | सूत्र `ROUND(F*H,2)` |
| K जोड | सामग्री + श्रम | सूत्र `I+J` |
| L टिप्पणीहरू | प्रयोग गरिएको सूत्र, सूत्र त्रुटि, स्केल नभएका शीटका चिह्नहरू, भित्ता क्षेत्रफल, परिधि | पाठ |

कामको कुल जोड पङ्क्ति: माथिका सबै पङ्क्तिहरूमा स्तम्भ I, J र K को `SUM`, र केही छुटेमा टिप्पणीमा "अपूर्ण: माथिका टिप्पणी हेर्नुहोस्"।

सूत्र त्रुटि भएको पङ्क्तिमा परिमाण वा रकम हुँदैन; त्यसको टिप्पणीले त्रुटि बताउँछ। शीर्षक पङ्क्ति स्थिर गरिएको हुन्छ।

CSV मा उही स्तम्भहरूमा सादा मानहरू हुन्छन्, फोहोर % प्रतिशतको संख्या हो (10 = 10%), र रकम डलरमा दुई दशमलवसहित हुन्छ। स्प्रेडसिटले सूत्र ठान्न सक्ने पाठ (`=`, `+`, `-` वा `@` बाट सुरु हुने) को अगाडि `'` राखिन्छ, ताकि त्यो पाठ नै रहोस्।

## शीटअनुसार (केवल XLSX)

| स्तम्भ | सामग्री |
|---|---|
| शीट | शीटको नाम (PDF नाम पनि, खुला नभएमा) |
| आइटम | आइटमको नाम |
| परिमाण | त्यो शीटमा त्यो आइटमको परिमाण, त्यसको एकाइमा |
| एकाइ | आइटमको एकाइ |
| चिह्नहरू | चिह्नहरूको संख्या |

## चिह्नहरू (केवल XLSX)

प्रति चिह्न एउटा पङ्क्ति।

| स्तम्भ | सामग्री |
|---|---|
| शीट | शीटको नाम |
| आइटम | आइटमको नाम |
| प्रकार | Linear, Area वा Count |
| परिमाण | लम्बाइ, खुद क्षेत्रफल, वा 1 |
| एकाइ | LF वा m; SF, SY वा m²; EA |
| विवरण | Linear: खण्डका लम्बाइहरू, घटाइएका खण्डहरू "(deduct)" चिह्नित, र "कोरिएको (लम्बाइ) मध्ये (लम्बाइ) घटाइएको"। Area: कटाइएका भाग भएमा कुल र कटाइएका क्षेत्रफल, र परिधि। स्केल नभएका चिह्नका लागि "शीटमा स्केल छैन"। |
| बोलपत्र क्षेत्र | केवल जब परियोजनामा बोलपत्र क्षेत्र हुन्छन्: चिह्नको क्षेत्रफल, वा "बोलपत्र क्षेत्र छैन" |

## बोलपत्र क्षेत्र अनुसार (केवल XLSX, जब परियोजनामा बोलपत्र क्षेत्र हुन्छन्)

| स्तम्भ | के हो |
|---|---|
| बोलपत्र क्षेत्र | क्षेत्रको नाम, वा "बोलपत्र क्षेत्र छैन" |
| आइटम | आइटम, वा त्यसमुनि इन्डेन्ट गरिएको घटक |
| एकाइ | आइटम वा घटकको एकाइ |
| परिमाण | त्यो क्षेत्रमा मापन गरिएको (घटकहरू: क्षेत्रको कुल योगमा सूत्र) |
| फोहोरसहितको परिमाण | परिमाण × (1 + फोहोर) |
| सामग्री, श्रम, जोड | अनुमानमा जस्तै, सेन्टसम्म विस्तारित |
| टिप्पणीहरू | सूत्र, त्रुटि र स्केल नभएका चिह्नहरू, अनुमानमा जस्तै |

प्रत्येक क्षेत्र "(नाम) उप-जोड" पङ्क्तिमा समाप्त हुन्छ, जसको लागत यसका पङ्क्तिहरूमाथिका `SUM` सूत्र हुन्; अन्तिम पङ्क्ति, **सबै बोलपत्र क्षेत्रहरू**, उप-जोडहरू जोड्छ। त्यसपछि **चिह्नहरू** कार्यपत्रमा सातौँ स्तम्भ, **बोलपत्र क्षेत्र** हुन्छ।

## स्केलहरू (केवल XLSX)

स्केल वा चिह्न भएको प्रत्येक शीटका लागि एउटा पङ्क्ति।

| स्तम्भ | सामग्री |
|---|---|
| शीट | शीटको नाम |
| स्केल | प्रिसेटको नाम, वा क्यालिब्रेट गरिएको स्केल, वा "स्केल छैन" |
| कसरी | "Preset" भए "प्रिसेट", वा "क्यालिब्रेट गरिएको (तपाईंले टाइप गरेको दूरीमा)" |
| PDF एकाइप्रति फिट | TakeoffCraft ले प्रयोग गर्ने सटीक स्केल कारक |

## फाइल नामहरू

- `(name).xlsx` र `(name).csv`, जहाँ नाम परिमाण गणनामा खोलिएको पहिलो PDF बाट आउँछ।
- CSV UTF-8 हो, byte order mark र Windows लाइन-अन्तसहित, जुन सबै प्लेटफर्ममा स्प्रेडसिट कार्यक्रमहरूले पढ्छन्।

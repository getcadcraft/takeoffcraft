**ფასების ბიბლიოთეკა** ინახავს ერთეულებს, რომლებსაც სამუშაოდან სამუშაოზე იყენებთ: მათ ტიპს, ერთეულს, სიმაღლეს, დანაკარგს, მასალისა და შრომის განაკვეთებსა და მათ აწყობას. ის ინახება ამ ბრაუზერში, მოცულობისგან განცალკევებით, ასე რომ ყოველი მოცულობა, რომელსაც აქ გახსნით, მას იყენებს.

გახსენით {{ui:ბიბლიოთეკა}} {{ui:ერთეულები}} პანელის ზედა ნაწილში.

## ბიბლიოთეკის შევსება

- {{ui:CSV-ის შემოტანა…}} კითხულობს ცხრილურ ფაილს, შენახულს CSV-ად (იხილეთ სვეტები ქვემოთ). ერთეულები, რომელთა სახელი და ტიპი უკვე ბიბლიოთეკაშია, იცვლება; დანარჩენი ემატება. ვერ წაკითხული სტრიქონები გამოტოვდება, და ის ამბობს, რომელი და რატომ.
- {{ui:ამ მოცულობის ერთეულების დამატება}} აკოპირებს ღია მოცულობის ყველა ერთეულს ბიბლიოთეკაში, თავისი განაკვეთებითა და აწყობით (არა მისი ნიშნებით).
- ხარჯთაღრიცხვის CSV, რომელსაც TakeoffCraft ექსპორტს უკეთებს ([ხარჯთაღრიცხვის ექსპორტი](topic:export-estimate)), იმპორტდება როგორც არის: წინა სამუშაოს ფასები იწყებს შემდეგს.

- {{ui:დარგობრივი პაკეტები…}} ამატებს უფასო აწყობებს ერთი დარგისთვის, მაგალითად თაბაშირის, ელექტროობისა თუ ბეტონისთვის, ფასების გარეშე. იხილეთ [დარგობრივი პაკეტები](topic:trade-packs).

{{ui:CSV-ის ექსპორტი}} ინახავს ბიბლიოთეკას CSV-ად: ასლის შესანახად, ელექტრონულ ცხრილში რედაქტირებისთვის ან კოლეგისთვის გადასაცემად. {{ui:გასუფთავება}} ცარიელს ხდის მას (დააწკაპუნეთ ორჯერ).

:::note
ბიბლიოთეკა ცხოვრობს ამ ბრაუზერის საცავში. სხვა ბრაუზერს, სხვა კომპიუტერს ან პირად ფანჯარას თავისი აქვს (ან არ აქვს). გადასატანად ექსპორტი გააკეთეთ.
:::

## გამოყენება მოცულობაში

- მონიშნეთ ერთეულები ({{ui:ძებნა ბიბლიოთეკაში}}-თი შეავიწროვეთ სია) და აირჩიეთ {{ui:მოცულობების დათვლაში დამატება}}. ისინი ემატება თავიანთი აწყობებით ერთ ნაბიჯად, რომელიც {{key:Mod+Z}}-ით უკან ბრუნდება. სახელი, რომელიც მოცულობაში უკვე არის, იღებს ნომერს, მაგალითად `Carpet (2)`.
- {{ui:ფასების განახლება}} აძლევს მოცულობის ერთეულებს ბიბლიოთეკის დანაკარგსა და განაკვეთებს, ყოველი ერთეულისთვის, რომლის სახელი და ტიპი ემთხვევა ბიბლიოთეკის ერთეულს, და იგივეს აწყობის იმავე სახელის კომპონენტებისთვის. სიმაღლეები, ერთეულები და ფორმულები უცვლელი რჩება. ერთი {{key:Mod+Z}} აბრუნებს ყველა ძველ ფასს.

## CSV-ის სვეტები

პირველი სტრიქონი ასახელებს სვეტებს ნებისმიერი თანმიმდევრობით; სხვა სვეტები უგულებელყოფილია.

| სვეტი | რა ჩაიწერება მასში |
|---|---|
| Item (or Name) | ერთეულის სახელი. სავალდებულოა. |
| Type | Linear, Area ან Count (LF, SF და EA ასევე მუშაობს). ცარიელის შემთხვევაში ერთეული წყვეტს. |
| Unit | LF ან m; SF, SY ან m²; EA. ცარიელი: ტიპის ჩვეულებრივი ერთეული. |
| Waste % | `10` ან `10%`. |
| Material per unit, Labor per unit | განაკვეთები, მაგალითად `2.10` ან `$1,250`. |
| Height (or Depth) | `9'-0"`, `9`, ან `2.7` მეტრული ერთეულებისთვის. |
| Component, Formula | სტრიქონი Component სახელით (ან ტიპით `Component`) არის იმ ერთეულის აწყობის ნაწილი, რომელიც მის ზემოთაა. მისი Unit, Waste და განაკვეთები საკუთარია; მისი Formula იყენებს ერთეულის ასოებს, იხილეთ [აწყობები და ფორმულები](topic:assemblies). |

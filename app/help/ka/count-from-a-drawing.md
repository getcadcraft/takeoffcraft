{{ui:CAD count}} ფურცლის ზოლზე (ბრძანება **Count from the drawing** სხვა მენიუს სტილებში) ითვლის იმას, რაც DWG ან DXF ამბობს, რომ არსებობს. სადაც {{ui:Auto count}} ეძებს სიმბოლოს სურათს და შეიძლება ერთი გამოტოვოს ან ცრუ იპოვოს, ეს ითვლის ობიექტებს: `DOOR-36` სახელის ბლოკის ყოველი ჩასმა არის ერთი კარი. ჯერ გახსენით ნახაზი: [DWG ან DXF ნახაზის გახსნა](topic:open-a-drawing).

## ბლოკის დათვლა

1. გახსენით ნახაზის ფურცელი. {{ui:CAD count}} ფურცლის ზოლზეა.
2. აირჩიეთ ის. ფანჯარა ჩამოთვლის ბლოკებს და იმას, თუ რამდენი თითოეულია. მოძებნეთ სახელით, შემდეგ აირჩიეთ ერთი.
3. შეამოწმეთ სიის ქვემოთ მდებარე ხაზი: „22 ნაპოვნია, 22 დასამატებელია.“
4. {{ui:Add to}}-ს ქვეშ აირჩიეთ დათვლის ერთეული, ან დატოვეთ {{ui:A new count item}} და მიეცით სახელი.
5. აირჩიეთ დამატების ღილაკი, რომელიც ასახელებს რიცხვს: {{ui:Add 22 marks}}. ნიშნები გამოჩნდება ბლოკის ჩასმის წერტილებში, და ერთეულის რაოდენობა იქნება დათვლა.

ეს ერთი გაუქმების ნაბიჯია: {{key:Mod+Z}} ერთად აშორებს ნიშნებს და ახალ ერთეულს. შეფასება, ცხრილი და მონიშნული PDF ერთეულს ისე ეპყრობა, როგორც სხვა დათვლის ერთეულს.

### რა ითვლება

- **ბლოკის სახელის ყოველი ჩასმა**, მისი მასშტაბისა და კუთხის მიუხედავად, მოდელის სივრცეში ან ქაღალდის სივრცეში. ბლოკის სახელები რეგისტრის მიმართ არ არის მგრძნობიარე.
- **ბლოკების მასივები** (MINSERT): მასივის ყოველი ასლი ერთად ითვლება.
- **ჩადგმული ბლოკები.** ბლოკი, რომელიც სხვა ბლოკის შიგნითაა, ითვლება ყოველ სიღრმეზე. სია ამბობს „6 სხვა ბლოკების შიგნით“; მოხსენით {{ui:Count blocks inside other blocks too}}, რომ დაითვალოთ მხოლოდ ის ჩასმები, რომლებიც პირდაპირ ნახაზშია.
- **დინამიკური ბლოკები.** დინამიკური ბლოკი ითვლება თავისი სახელით, არა ანონიმურ ასლებში (`*U12`), რომლებსაც ფაილი ინახავს. მისი მდგომარეობები ცალკე ჩანს („Single 12, Double 4“): აირჩიეთ მდგომარეობა, რომ დაითვალოთ მხოლოდ ისინი, ან {{ui:Every variant}}. როცა ფაილი არ ამბობს, რომელ მდგომარეობას აჩვენებს ასლი, ისინი ჩანს როგორც „(მდგომარეობა უცნობია)“.
- **ფენის ფილტრი.** ბლოკი რამდენიმე ფენაზე: აირჩიეთ ერთი {{ui:On layer}}-ის ქვეშ.

### რა არ ითვლება

- **დამალული ფენები.** ობიექტი ფენაზე, რომელიც ფაილში გამორთულია ან გაყინულია (ან დამალული გაქვთ {{ui:Layers}}-ში), გამოტოვებულია და ხაზი ამბობს რამდენი: „3 დამალულ ფენაზე გამოტოვებული“. მონიშნეთ {{ui:Count them too}}, რომ ისინიც შევიდეს.
- **მიბმული ნახაზები, რომლებიც არ არის ღია**, არ ითვლება; ფანჯარა ამას ამბობს.
- **ობიექტები, რომლებიც ზუსტად სხვა იმავე სახის ობიექტზეა დადებული**, ითვლება ორად (ისინი ორი ობიექტია) და ფანჯარა ამას ამბობს: ეს ჩვეულებრივ ხაზვის შეცდომაა, ღირს შემოწმება.

## ფურცელზე ნაჩვენები ან მთელი ნახაზი

- **რასაც ფურცელი აჩვენებს** ითვლის ობიექტებს, რომლებსაც ფურცელი აჩვენებს: განლაგებაზე, მოდელის ობიექტებს მის ხედებში (ფენა, რომელიც ხედში გაყინულია, იქ არ ითვლება), პლუს განლაგების საკუთარს.
- **მთელი ნახაზი, ყოველი ობიექტი ერთხელ** ითვლის მოდელის სივრცეს ერთხელ, ნიშნებით Model ფურცელზე, და არ ითვლის იმას, რასაც რამდენიმე განლაგება კიდევ აჩვენებს.

განლაგებით ნაჩვენები და Model-ით ნაჩვენები ერთი და იგივე ობიექტები ერთ რიცხვს იძლევა; ერთ ერთეულს ორივე ნუ დაუმატებთ.

## დათვლის ხელახლა დათვლა

იმავე ბლოკის ხელახლა დათვლა იმავე ერთეულით ამატებს მხოლოდ ახალს: „22 უკვე დათვლილია.“ ყოველი ნიშანი ერთ ობიექტს ნიშნავს.

## ფენისა და ტიპის მიხედვით

{{ui:By layer and type}}-ზე აირჩიეთ ფენა და ობიექტის ტიპი (წრეწირები, პოლიხაზები, შტრიხები…): „ყველა წრეწირი E-LITE-ზე“. მონიშნეთ {{ui:Also count objects inside blocks}}, რომ ისინიც შევიდეს, რომლებიც ბლოკის განსაზღვრებებშია, ყოველ ადგილას, სადაც ბლოკია ჩასმული.

## ტექსტით

{{ui:By text}}-ზე ჩაწერეთ ტექსტი, როგორიცაა `A3`, და მიუთითეთ, არის თუ არა ზუსტად ეს, შეიცავს თუ არა, ან მთლიანი სიტყვაა. ტექსტის ობიექტები, მულტილიდერის ტექსტი და ბლოკის **ატრიბუტის მნიშვნელობები** ყველა ითვლება (ტეგის ატრიბუტი `ITEM = A3` ნაპოვნია); აირჩიეთ {{ui:In attribute}}, რომ დაითვალოთ მხოლოდ ერთი ატრიბუტი. ყველაზე გავრცელებული ტექსტები ჩამოთვლილია დასაწკაპუნებლად.

## როდის გამოვიყენოთ Auto count

გამოიყენეთ {{ui:Auto count}} PDF-ებისთვის და იმ სიმბოლოებისთვის ნახაზში, რომლებიც ბლოკები არ არის (დახატული თავისუფლად ან დაშლილი). ბლოკებად დახატული დაითვალეთ აქ.

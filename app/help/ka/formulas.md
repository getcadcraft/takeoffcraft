აწყობის კომპონენტები რაოდენობას იღებენ ფორმულიდან. ფორმულა არის მცირე არითმეტიკული გამოსახულება ელემენტის გაზომილ მნიშვნელობებზე. სამუშაო მაგალითებისთვის იხილეთ [აწყობები და ფორმულები](topic:assemblies).

## ცვლადები

| ელემენტის ტიპი | ცვლადი | მნიშვნელობა |
|---|---|---|
| წრფივი | `L` | სრული სიგრძე |
| წრფივი | `H` | ელემენტის სიმაღლე |
| წრფივი | `A` | კედლის ფართობი, L × H, გამოკლებული იმ მონაკვეთების ღიობები, რომლებსაც ისინი აქვთ (დათვლა BimCraft-დან). როცა ეს დათვლა ასახელებს გაზომვის მეთოდს, `A` იზომება მისით: ღიობები, რომლებიც არ აღემატება მეთოდის უმცირეს ზომას, რჩება, ხოლო ის, რასაც მეთოდი კედლების შეხვედრისას აკლებს, გამოტოვებულია. ელემენტის ქვეშ შენიშვნა ასახელებს მეთოდს |
| წრფივი | `N` | მონაკვეთების რაოდენობა |
| ფართობი | `A` | წმინდა ფართობი სულ (კონტურები მინუს ამოჭრილობები) |
| ფართობი | `P` | სრული პერიმეტრი, ამოჭრილობის კიდეების ჩათვლით |
| ფართობი | `H` | ელემენტის სიღრმე ან სისქე |
| ფართობი | `N` | ფართობების რაოდენობა |
| დათვლა | `N` | რაოდენობა |

- ცვლადები არის ელემენტის ერთეულებში: იხილეთ [ერთეულები](topic:units).
- დიდი და პატარა ასოები ერთნაირია: `l` არის `L`.
- მუშაობს მხოლოდ ელემენტის საკუთარი ტიპის ცვლადები. `P` წრფივ ელემენტზე იძლევა: `"P" აქ გაზომილი მნიშვნელობა არ არის. გამოიყენეთ L, H, A, N.`
- ცარიელი სიმაღლე ან სიღრმე არის 0.

## ოპერატორები

| ჩაწერეთ | ნიშნავს |
|---|---|
| `+` | შეკრება |
| `-` ან `−` | გამოკლება, ან უარყოფითი მნიშვნელობა |
| `*` ან `×` | გამრავლება |
| `/` ან `÷` | გაყოფა |
| `( )` | დაჯგუფება |

გამრავლება და გაყოფა წინ უსწრებს შეკრებასა და გამოკლებას: `L * 2 + 4` არის (L × 2) + 4. ეჭვის შემთხვევაში გამოიყენეთ ფრჩხილები.

რიცხვებს შეიძლება ჰქონდეს ათობითი ნაწილი (`1.333`, `.5`) და ექსპონენტი (`1e3` = 1000). ინტერვალები უგულებელყოფილია.

## ფუნქციები

| ფუნქცია | შედეგი | მაგალითი |
|---|---|---|
| `ceil(x)` | დამრგვალება მთელამდე ზემოთ | `ceil(67.5)` = 68 |
| `floor(x)` | დამრგვალება მთელამდე ქვემოთ | `floor(67.5)` = 67 |
| `round(x)` | დამრგვალება უახლოეს მთელამდე, ნახევრები ნულიდან მოშორებით | `round(2.5)` = 3 |
| `round(x, d)` | დამრგვალება d ათობით ნიშნამდე (0-დან 10-მდე) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | უმცირესი მნიშვნელობა | `min(N, 10)` |
| `max(a, b, …)` | უდიდესი მნიშვნელობა | `max(1, ceil(N / 12))` |
| `abs(x)` | მნიშვნელობა ნიშნის გარეშე | `abs(-3)` = 3 |

`ceil` და `floor` უგულებელყოფენ კომპიუტერის დამრგვალების მცირე გადახრებს, ასე რომ მნიშვნელობა, რომელიც ზუსტად 1 უნდა იყოს, არასდროს მრგვალდება 2-მდე.

## შეცდომები

ფორმულა, რომელიც ვერ იკითხება ან ვერ გამოითვლება, ველის ქვეშ აჩვენებს თავის შეცდომას, და კომპონენტი გამოტოვებულია ჯამებიდან ({{ui:Quantities}}-ის სათაური წერს „არასრულია“). შეტყობინებები:

| შეტყობინება | გამოსწორება |
|---|---|
| ჩაწერეთ ფორმულა, მაგალითად L ან ceil(L / 1.333) + 1. | ფორმულა ცარიელია. |
| `"X"` აქ გაზომილი მნიშვნელობა არ არის. გამოიყენეთ … | გამოიყენეთ ერთ-ერთი ჩამოთვლილი ცვლადი. |
| `"X"` აქ ფუნქცია არ არის. გამოიყენეთ ceil, floor, round, min, max, abs. | გამოიყენეთ ერთ-ერთი ეს ფუნქცია. |
| `"#"` ფორმულაში არ არის დაშვებული. | წაშალეთ ეს სიმბოლო (ერთეულები, `%`, `$` და `=` არ არის დაშვებული). |
| `")"` აკლია. / არის `")"` მისი `"("`-ის გარეშე. | დააბალანსეთ ფრჩხილები. |
| `")"`-მდე მნიშვნელობა აკლია. | მაგალითად `max(1, )`: შეავსეთ მნიშვნელობა. |
| ფორმულა ზედმეტად ადრე მთავრდება. | მაგალითად `L *`: დაასრულეთ. |
| მოულოდნელი `"…"`. ხომ არ აკლია ოპერატორი? | ორი მნიშვნელობა გვერდიგვერდ, მაგალითად `2L`: ჩაწერეთ `2 * L`. |
| `ceil()` იღებს 1 მნიშვნელობას. | მიეცით ფუნქციას მნიშვნელობების სწორი რაოდენობა. |
| `round(x, digits)`-ს სჭირდება მთელი ციფრები 0-დან 10-მდე. | გამოიყენეთ მთელი რიცხვი ათობითი ნიშნებისთვის. |
| ფორმულა ნულზე ყოფს. | როგორც წესი, H არის 0: დააყენეთ ელემენტის სიმაღლე ან სიღრმე. |
| ფორმულა არ იძლევა რიცხვს. | შედეგი ძალიან დიდია რიცხვად. |
| ეს ფორმულა ძალიან გრძელია (მაქსიმუმ 500 სიმბოლო). | შეამოკლეთ. |

## დიზაინით უსაფრთხო

ფორმულას შეუძლია მხოლოდ არითმეტიკა ზემოთ ჩამოთვლილი ცვლადებითა და ფუნქციებით. მას არ შეუძლია კოდის გაშვება ან სხვა რაიმეს წაკითხვა, ამიტომ ფორმულა პროექტის ფაილში, რომელსაც ვინმე გამოგიგზავნით, უვნებელია.

## ხარჯთაღრიცხვა (XLSX სამუშაო ფურცელი და CSV)

თითო ელემენტზე ერთი მწკრივი, შემდეგ თითო კომპონენტზე მწკრივი მისი აწყობიდან (შეწეული). შემდეგ ცარიელი მწკრივი და სამუშაოს ჯამი.

| სვეტი | შინაარსი | XLSX-ში |
|---|---|---|
| A ელემენტი | ელემენტის სახელი (მუქად) ან კომპონენტის სახელი (შეწეული) | ტექსტი |
| B ტიპი | წრფივი, ფართობი, დათვლა ან კომპონენტი | ტექსტი |
| C ერთეული | LF, m, SF, SY, m², EA, ან კომპონენტის ერთეული | ტექსტი |
| D რაოდენობა | გაზომილი ჯამი ან ფორმულის შედეგი | რიცხვი |
| E ნარჩენი % | ნარჩენი | პროცენტი (0.10 = 10%) |
| F რაოდენობა ნარჩენით | რაოდენობა × (1 + ნარჩენი) | ფორმულა `D*(1+E)` |
| G მასალა ერთეულზე | მასალის განაკვეთი | რიცხვი |
| H შრომა ერთეულზე | შრომის განაკვეთი | რიცხვი |
| I მასალა | გაშლილი მასალა | ფორმულა `ROUND(F*G,2)` |
| J შრომა | გაშლილი შრომა | ფორმულა `ROUND(F*H,2)` |
| K ჯამი | მასალა + შრომა | ფორმულა `I+J` |
| L შენიშვნები | გამოყენებული ფორმულა, ფორმულის შეცდომა, მონიშვნები ფურცლებზე მასშტაბის გარეშე, კედლის ფართობი, პერიმეტრი | ტექსტი |

სამუშაოს ჯამის მწკრივი: `SUM` სვეტებისთვის I, J და K ზემოთ ყველა მწკრივზე და შენიშვნებში „არასრულია: იხილეთ ზემოთ შენიშვნები“, როცა რაღაც გამოტოვებულია.

ფორმულის შეცდომის მქონე მწკრივს არ აქვს რაოდენობა ან თანხები; მისი შენიშვნა ასახელებს შეცდომას. სათაურის მწკრივი დაფიქსირებულია.

CSV-ში იგივე სვეტები შეიცავს უბრალო მნიშვნელობებს, ნარჩენი % არის პროცენტის რიცხვი (10 არის 10%-ისთვის), ხოლო თანხები არის დოლარებში ორი ათობითი ნიშნით. ტექსტი, რომელსაც სპრედშიტმა შეიძლება ფორმულად მიიჩნიოს (იწყება `=`, `+`, `-` ან `@`-ით), იღებს წამყვან `'`-ს, რათა დარჩეს ტექსტად.

| სვეტი | შინაარსი |
|---|---|
| ფურცელი | ფურცლის სახელი |
| ელემენტი | ელემენტის სახელი |
| ტიპი | წრფივი, ფართობი ან დათვლა |

## სატენდერო ფართობების მიხედვით (მხოლოდ XLSX, როცა დათვლას აქვს სატენდერო ფართობები)

| სვეტი | რა არის |
|---|---|
| სატენდერო ფართობი | ფართობის სახელი, ან „სატენდერო ფართობი არ არის“ |
| ელემენტი | ელემენტი, ან მის ქვეშ შეწეული კომპონენტი |
| ერთეული | ელემენტის ან კომპონენტის ერთეული |
| რაოდენობა | გაზომილი ამ ფართობში (კომპონენტები: ფორმულა ფართობის ჯამებზე) |
| რაოდენობა ნარჩენით | რაოდენობა × (1 + ნარჩენი) |
| მასალა, შრომა, ჯამი | გაშლილი ცენტამდე, როგორც ხარჯთაღრიცხვაზე |
| შენიშვნები | ფორმულა, შეცდომები და უმასშტაბო მონიშვნები, როგორც ხარჯთაღრიცხვაზე |

ყოველი ფართობი მთავრდება მწკრივით „(სახელი) ქვეჯამი“, რომლის ღირებულებები არის `SUM` ფორმულები მის მწკრივებზე. ბოლო მწკრივი, **ყველა სატენდერო ფართობი**, ამატებს ქვეჯამებს. **მონიშვნები** სამუშაო ფურცელს მაშინ აქვს მეშვიდე სვეტი, **სატენდერო ფართობი**.

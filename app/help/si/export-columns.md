## ඇස්තමේන්තුව (XLSX වැඩ පත්‍රය සහ CSV)

අයිතමයකට එක් පේළියක්, ඉන්පසු එහි එකලස් වල සෑම සංරචකයකටම පේළියක් (ඉඩ තබා). ඉන්පසු හිස් පේළියක් සහ ව්‍යාපෘති එකතුව.

| තීරුව | අන්තර්ගතය | XLSX හි |
|---|---|---|
| A Item | අයිතම නම (තද) හෝ සංරචක නම (ඉඩ තබා) | පෙළ |
| B Type | Linear, Area, Count හෝ Component | පෙළ |
| C Unit | LF, m, SF, SY, m², EA, හෝ සංරචකයේ ඒකකය | පෙළ |
| D Quantity | මනින ලද එකතුව, හෝ සූත්‍රයේ ප්‍රතිඵලය | සංඛ්‍යාව |
| E Waste % | අපද්‍රව්‍ය | ප්‍රතිශතය (0.10 = 10%) |
| F Qty with waste | ප්‍රමාණය × (1 + අපද්‍රව්‍ය) | සූත්‍රය `D*(1+E)` |
| G Material per unit | ද්‍රව්‍ය අනුපාතය | සංඛ්‍යාව |
| H Labor per unit | ශ්‍රම අනුපාතය | සංඛ්‍යාව |
| I Material | දිගු ද්‍රව්‍ය මුදල | සූත්‍රය `ROUND(F*G,2)` |
| J Labor | දිගු ශ්‍රම මුදල | සූත්‍රය `ROUND(F*H,2)` |
| K Total | ද්‍රව්‍ය + ශ්‍රමය | සූත්‍රය `I+J` |
| L Notes | භාවිත කළ සූත්‍රය, සූත්‍ර දෝෂය, පරිමාණ නැති පත්‍රවල ලකුණු, බිත්ති ප්‍රදේශය, පරිධිය | පෙළ |

ව්‍යාපෘති එකතු පේළිය: ඉහත සෑම පේළියක්ම පුරා I, J සහ K තීරුවල `SUM`, සහ යමක් ඉවත් වූ විට සටහන් වල "අසම්පූර්ණයි: ඉහත සටහන් බලන්න".

සූත්‍ර දෝෂයක් ඇති පේළියකට ප්‍රමාණයක් හෝ මුදල් නැත; එහි සටහන දෝෂය දක්වයි. ශීර්ෂ පේළිය සවි කර ඇත.

CSV හි, එම තීරුවල සරල අගයන් ඇත, Waste % යනු ප්‍රතිශත සංඛ්‍යාවකි (10% සඳහා 10), සහ මුදල් ඩොලර් වලින් දශම දෙකකින්. පැතුරුම්පත් වැඩසටහනක් සූත්‍රයක් ලෙස ගත හැකි පෙළ (`=`, `+`, `-` හෝ `@` වලින් ආරම්භ වන) ඉදිරියෙන් `'` ලබයි, එය පෙළ ලෙස තබා ගැනීමට.

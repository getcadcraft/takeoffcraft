එකලස් සංරචකයන්ට ඒවායේ ප්‍රමාණය සූත්‍රයකින් ලැබේ. සූත්‍රය අයිතමයේ මනින ලද අගයන් මත කුඩා අංක ගණිත ප්‍රකාශනයකි. උදාහරණ සඳහා [එකලස් සහ සූත්‍ර](topic:assemblies) බලන්න.

## විචල්‍ය

| අයිතම වර්ගය | විචල්‍යය | අර්ථය |
|---|---|---|
| Linear | `L` | මුළු දිග |
| Linear | `H` | අයිතමයේ උස |
| Linear | `A` | බිත්ති ප්‍රදේශය, L × H, ඒවායේ විවර ඇති ධාවන වල විවර අඩු කළ (BimCraft takeoff එකකින්). එම takeoff එක මිනුම් ක්‍රමයක් නම් කළ විට, `A` එම ක්‍රමයෙන් මනී: එම ක්‍රමයේ කුඩාම ප්‍රමාණයට වඩා විශාල නොවන විවර ඇතුළත් වේ, සහ බිත්ති හමුවන තැනදී ක්‍රමය ගන්නා දෙය ඉවත් වේ. අයිතමය යටතේ ඇති සටහන ක්‍රමයේ නම කියයි |
| Linear | `N` | ධාවන ගණන |
| Area | `A` | මුළු ශුද්ධ ප්‍රදේශය (දාර අඩු කප්පාදු) |
| Area | `P` | මුළු පරිධිය, කප්පාදු දාර ඇතුළුව |
| Area | `H` | අයිතමයේ ගැඹුර හෝ ඝනකම |
| Area | `N` | ප්‍රදේශ ගණන |
| Count | `N` | ගණන |

- විචල්‍ය අයිතමයේ ඒකකවලයි: බලන්න [ඒකක](topic:units).
- විශාල සහ කුඩා අකුරු සමානයි: `l` යනු `L` වේ.
- අයිතමයේ තමන්ගේම වර්ගයේ විචල්‍ය පමණක් ක්‍රියා කරයි. Linear අයිතමයක `P` ලබා දෙන්නේ `"P" මෙහි මනින ලද අගයක් නොවේ. L, H, A, N භාවිත කරන්න.` යන පණිවිඩයයි.
- හිස් උසක් හෝ ගැඹුරක් 0 වේ.

## ක්‍රියාකරුවන්

| ලියන්න | අර්ථය |
|---|---|
| `+` | එකතු කරන්න |
| `-` හෝ `−` | අඩු කරන්න, හෝ සෘණ අගයක් |
| `*` හෝ `×` | ගුණ කරන්න |
| `/` හෝ `÷` | බෙදන්න |
| `( )` | කණ්ඩායම් කරන්න |

ගුණ කිරීම සහ බෙදීම එකතු කිරීම සහ අඩු කිරීමට පෙර යයි: `L * 2 + 4` යනු (L × 2) + 4 වේ. සැකයක් ඇති විට වරහන් භාවිත කරන්න.

සංඛ්‍යාවලට දශම (`1.333`, `.5`) සහ ඝාතාංක (`1e3` = 1000) තිබිය හැක. හිස්තැන් නොසලකා හරින ලදී.

## ශ්‍රිත

| ශ්‍රිතය | ප්‍රතිඵලය | උදාහරණය |
|---|---|---|
| `ceil(x)` | ඉහළට පූර්ණ සංඛ්‍යාවට වටයි | `ceil(67.5)` = 68 |
| `floor(x)` | පහළට පූර්ණ සංඛ්‍යාවට වටයි | `floor(67.5)` = 67 |
| `round(x)` | ආසන්නතම පූර්ණ සංඛ්‍යාවට, අර්ධ ශුන්‍යයෙන් ඈත දිශාවට | `round(2.5)` = 3 |
| `round(x, d)` | d දශම ස්ථානවලට වටයි (0 සිට 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | කුඩාම අගය | `min(N, 10)` |
| `max(a, b, …)` | විශාලතම අගය | `max(1, ceil(N / 12))` |
| `abs(x)` | ලකුණ නැති අගය | `abs(-3)` = 3 |

`ceil` සහ `floor` කුඩා පරිගණක වටයන ශබ්දය නොසලකා හරියි, එබැවින් හරියටම 1 විය යුතු අගයක් කිසිවිට 2 දක්වා ඉහළට වටයන්නේ නැත.

## දෝෂ

කියවිය නොහැකි හෝ ගණනය කළ නොහැකි සූත්‍රයක් ක්ෂේත්‍රය යටතේ එහි දෝෂය පෙන්වන අතර, සංරචකය එකතු වලින් ඉවත් වේ ({{ui:Quantities}} ශීර්ෂය "අසම්පූර්ණයි" කියයි). පණිවිඩ:

| පණිවිඩය | ගැලපුම |
|---|---|
| සූත්‍රයක් ටයිප් කරන්න, උදාහරණයක් ලෙස L හෝ ceil(L / 1.333) + 1. | සූත්‍රය හිස් ය. |
| `"X"` මෙහි මනින ලද අගයක් නොවේ. … භාවිත කරන්න | ලැයිස්තුගත විචල්‍ය වලින් එකක් භාවිත කරන්න. |
| `"X"` මෙහි ශ්‍රිතයක් නොවේ. ceil, floor, round, min, max, abs භාවිත කරන්න. | ඒවායින් එකක් භාවිත කරන්න. |
| සූත්‍රයේ `"#"` අවසර නැත. | එම අක්ෂරය ඉවත් කරන්න (ඒකක, `%`, `$` සහ `=` අවසර නැත). |
| `")"` නැත. / `"("` නැති `")"` ඇත. | වරහන් සමතුලිත කරන්න. |
| `")"` ට පෙර අගයක් නැත. `max(1, )` වැනි. | අගය පුරවන්න. |
| සූත්‍රය ඉතා ඉක්මනින් අවසන් වේ. `L *` වැනි. | අවසන් කරන්න. |
| අනපේක්ෂිත `"…"`. ක්‍රියාකරුවෙක් නැතිද? `2L` වැනි අගයන් දෙකක් යන්තම් පිහිටා. | `2 * L` ලෙස ලියන්න. |
| ceil() එක් අගයක් ගනී. | ශ්‍රිතයට නිවැරදි අගය ගණන දෙන්න. |
| round(x, digits) ට 0 සිට 10 දක්වා පූර්ණ ඉලක්කම් අවශ්‍යයි. | පූර්ණ දශම ගණනක් භාවිත කරන්න. |
| සූත්‍රය ශුන්‍යයෙන් බෙදයි. සාමාන්‍යයෙන් H ශුන්‍යයි. | අයිතමයේ උස හෝ ගැඹුර සකසන්න. |
| සූත්‍රය සංඛ්‍යාවක් ලබා නොදේ. | ප්‍රතිඵලය සංඛ්‍යාවක් වීමට ඉතා විශාලයි. |
| එම සූත්‍රය ඉතා දිගුයි (උපරිම අක්ෂර 500). | කෙටි කරන්න. |

## ආරක්ෂිත නිර්මාණය

සූත්‍රයට ඉහත විචල්‍ය සහ ශ්‍රිත සමඟ පමණක් ගණිතය කළ හැක. එයට කේතය ක්‍රියාත්මක කිරීමට හෝ වෙනත් කිසිවක් කියවීමට නොහැක, එබැවින් යමෙක් ඔබට යවන ව්‍යාපෘති ගොනුවක සූත්‍රයක් හානිකර නොවේ.

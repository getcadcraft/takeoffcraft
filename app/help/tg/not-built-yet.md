TakeoffCraft дар ҷараёни таҳия аст. Ин рӯйхат чизҳоеро нишон медиҳад, ки нашри ҷорӣ намекунад ва чӣ гуна бо вуҷуди ин корро анҷом додан мумкин аст.

## Чен кардан

| Ҳанӯз сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Нуқтаро дар миёнаи хат ё контур ворид кардан | Нишонаро нест карда, аз нав кашед. |
| Интихоби бо қуттича (тиреза) | {{key:Shift}} + ҳар нишонаро клик кунед, ё {{key:Mod+A}} барои ҳамаи нишонаҳои варақ. Нигаред ба [Нусха бардоштан, гузоштан ва дубораҳо кардани нишонаҳо](topic:copy-paste). |
| Гардондан, инъикос ё тағйири миқёси нусхаи гузошташуда | Дар варақ бо ҳамон миқёс ва ҳамон самт гузоред; қисми боқимондаро бо даст кашед. |
| Хондани миқёс аз варақи скансуда ё аз хатчаи миқёси графикӣ | Пешфарзро интихоб кунед, ё бо дарозии хатчаи миқёс калибровка кунед. |
| Зиёда аз як миқёс дар як варақ (минтақаҳои тафсилот, нақшаҳои калоншуда) | Қисмро бо миқёси варақ чен кунед ва агар маҷмӯа варақи калоншудаи алоҳида дошта бошад, тафсилотро аз он ҳисоб кунед. |

## Ҷузъҳо ва нархгузорӣ

| Ҳанӯз сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| Формулаҳои маҷмӯа, ки навъҳои дигари нишонаҳои ҷузъро истифода мебаранд (дарҳои ҳуҷра дар формулаҳои фарши ошёна) | Формулаҳо ҷамъи навъи асосиро истифода мебаранд; навъҳои дигарро дар сатрҳои худашон нархгузорӣ кунед. |
| Формулаҳои маҷмӯа, ки барои ҳар хат ҳисоб мешаванд | Формулаҳо ҷамъи ҷузъро истифода мебаранд; барои иловаҳои ҳар хат `N`-ро истифода баред. |
| Формулаҳое, ки миқдорҳои ҷузъи дигарро истифода мебаранд | Ченкуниро дар он ҷузъ такрор кунед, ё онро дар содироти ҷадвали электронӣ ҳисоб кунед. |
| Бригадаҳо дар ҷузъҳои маҷмӯа, ё рӯзи корӣ ғайр аз 8 соат | Бригадаро ба ҷузъ диҳед; рӯзҳои бригада барои дарозии дигари рӯз чун соатҳои бригада ÷ рӯзи шумо хонда шаванд. |
| Қайдгузориҳо ба ғайр аз ёддоштҳо, абрҳо ва нишонаҳои рангӣ (тирҳо, андозаҳо, муҳрҳо) ё посухҳо ба ёддошт | Онро дар матни ёддошт нависед; ҳолати онро ҳангоми ҳал шуданаш иваз кунед. |
| Китобхонаи нархҳо, ки дар даста мубодила мешавад ё бо ҳисоби шумо нигоҳ дошта мешавад | Китобхона дар ин браузер нигоҳ дошта мешавад: онро ҳамчун CSV содир кунед ва дар компютери дигар ворид кунед. |
| Бастаҳои касбӣ, ки аз ҷониби сметачиёни корӣ санҷида шудаанд | Ҳар баста стартовӣ аст: пеш аз нархгузорӣ бо он, фарзияҳои онро ба корӣ ва маҳсулоти худ санҷед. Нигаред ба [Бастаҳои касбӣ](topic:trade-packs). |
| Нархҳо дар бастаҳои касбӣ | Бастаҳо танҳо маҷмӯаҳоро меоранд: нархҳои худро муқаррар кунед, ё рӯйхати нархи худро ҳамчун CSV ворид кунед. |
| Номи ҳисоби ҳаҷми корҳоро иваз кардан | Ном аз PDF-и аввал гирифта мешавад; файлҳои зеризадашударо номашон иваз кунед. |
| Номгузории варақҳо бо дасти худ | Варақҳо аз нишонаҳои саҳифаи PDF ном мегиранд; бо номи файл ва саҳифа ҷустуҷӯ кунед. |

| Ҳанӯз сохта нашудааст | Ба ҷои он, имрӯз |

| Кушодани DXF-и дуӣ ё DWG-и кӯҳнатар аз AutoCAD 2000 | Онро ҳамчун ASCII DXF ё DWG-и навтар захира кунед. |
| Ёфтани нақшаи пайвастшуда (xref) аз рӯи ҷузвдоне, ки дар он аст | Нақшаи пайвастшударо низ бо файли мизбон кушоед: он бо номи файл дар байни файлҳои кушодашуда ёфта мешавад. |

| Матн дар PDF-и бо нишонаҳо аз нақша бо хатҳои ғайр аз лотинӣ | Аломатҳое, ки Helvetica глиф надорад, дар PDF-и бо нишонаҳо ҳамчун "?" чоп мешаванд; нақша дар экран тағйир намеёбад. |

| Замина-PDF-ҳо, тасвирҳо ва объектҳои OLE, ки дар нақша ҷойгиранд: чен кардан ё шумурдан | Тасвирҳо танҳо ҳамчун чаҳорчӯба нишон дода мешаванд. PDF-и заминаро худаш ҳамчун варақ кушоед. |

## Ҷадвалҳои электронӣ

Китоби XLSX дар LibreOffice Calc санҷида шудааст; он ҳар ҷамъро то ҳамон як тин ба TakeoffCraft ҳисоб кард. Он то ҳол дар Excel кушода нашудааст. Агар барномаи ҷадвалӣ чизи ғайричашмдошт нишон диҳад, содироти CSV ҳамон сметаро ҳамчун арзишҳои оддӣ дорад.

## Нусхабардорӣ ва гузоштан

| Тугмача | Чӣ мекунад |
|---|---|
| {{key:Mod+C}} | Нишонҳои интихобшударо бо ҷузъҳояшон нусха мегирад. |
| {{key:Mod+X}} | Буриш: нишонҳоро нусха мегирад, сипас нест мекунад. |
| {{key:Mod+V}} | Гузоштан: нусха ба нишондиҳанда пайравӣ мекунад; ба ҷое, ки мехоҳед, пахш кунед. |
| {{key:Mod+Shift+V}} | Гузоштан дар ҷои худ: ҳамон ҷо дар варақи кушода. |
| {{key:Mod+D}} | Нусхаи нишонҳои интихобшуда: нусха ба нишондиҳанда пайравӣ мекунад; ҷоеро пахш кунед. |
| {{key:Esc}} | Ҳеҷ чизро нагузоред: гузоштан ё нусхаи дар нишондиҳанда бударо бекор мекунад. |

Ҳарфҳои танҳо абзорҳоро интихоб мекунанд: {{key:C}} ин {{ui:Count}} аст, {{key:D}} ин {{ui:Check}} аст, {{key:X}} ин {{ui:Cut-out}} аст, {{key:V}} ин {{ui:Select}} аст, {{key:A}} ин {{ui:Area}} аст; танҳо {{key:Mod}} бо онҳо нусха мегирад ва мегузорад. Дар майдони матн ин тугмачаҳо мисли одатӣ матнро нусха мекунанд ва мегузоранд. Нигаред: [Нусхабардорӣ, гузоштан ва нусхабардории нишонҳо](topic:copy-paste).

:::warning
{{key:Backspace}} вақте ки шумо намекашед, нишони интихобшударо нест мекунад. Агар ин тасодуфан шавад, {{key:Mod+Z}} онро бармегардонад.
:::

## Ёддоштҳои платформа

:::mac
- {{key:Mod}} калиди Command аст: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}. Истисно экрани пурра: Control+Shift+F.
- Пахши рост ин пахши ду ангушт дар трекпад аст, вақте ки пахши дуюмдараҷа дар Танзимоти система, дар бахши Trackpad фаъол аст. TakeoffCraft танҳо тугмачаи дуюмро мехонад; Control-клик метавонад ҳамчун клики оддӣ ҳисоб шуда, нуқта илова кунад.
- Ду ангушт дар трекпад варақро калон мекунад (гардонида намешавад). Барои ҷойивазкунӣ пахш карда кашед, ё {{key:Space}}-ро нигоҳ дошта кашед.
- Page Up ва Page Down ин fn бо тирҳои боло ва поён дар клавиатураҳое, ки онҳоро надоранд.
- Backspace калиди бо «delete» навишташуда аст.
:::

:::windows
- {{key:Mod}} Ctrl аст: {{key:Mod+Z}}, {{key:Mod+S}}, {{key:Mod+O}}.
- Дар трекпади лаптоп, гардондани ду ангушт варақро калон мекунад. Барои ҷойивазкунӣ пахш карда кашед.
:::

:::linux
- {{key:Mod}} Ctrl аст. Баъзе мизҳо Ctrl+Alt ё Super-и худро доранд; TakeoffCraft ҳеҷ яке аз онҳоро истифода намебарад.
- Дар тачпад, гардондани ду ангушт варақро калон мекунад. Барои ҷойивазкунӣ пахш карда кашед.
:::

:::touch
TakeoffCraft сенсорро ҳамчун як нишондиҳанда мехонад:

- Тап нуқта мегузорад, нишонро интихоб мекунад ё нуқтаи шуморишро илова мекунад.
- Кашидан бо як ангушт варақро ҷойивазкунӣ мекунад (дар {{ui:Auto count}} қуттии ҷустуҷӯро мекашад).
- Ҷамъкунии ангуштон барои калонкунӣ ҳоло дастгирӣ намешавад. {{ui:Fit page}} ва {{ui:Fit width}}-ро истифода баред, ё {{key:Plus}} ва {{key:Minus}} дар клавиатура.
- Барои пӯшидани масоҳат, ба нуқтаи аввалаш тап кунед. Барои анҷом додани хат, дабл-тап кунед, он ҷое ки браузер онро пахши дукарата мешуморад, ё {{key:Enter}}-ро дар клавиатура пахш кунед.
- То тап кардан, хонди дарозии зинда нест, зеро ҳаво (hover) вуҷуд надорад.

То имрӯз беҳтарин роҳи тарҳбандӣ клавиатура ва мушук ё трекпад аст.
:::

## Тугмачаҳое, ки браузер нигоҳ медорад

Браузерҳо баъзе миёнбурҳоро барои худ нигоҳ медоранд ва саҳифа онҳоро истифода карда наметавонад: баста кардани варақа ({{key:Mod+W}}), варақаи нав ё тиреза ({{key:Mod+T}}, {{key:Mod+N}}) ва калонкунии браузер ({{key:Mod+Plus}}, {{key:Mod+Minus}}). Аз ин рӯ TakeoffCraft варақро бо чарх ва бо тугмачаҳои соф {{key:Plus}} ва {{key:Minus}} калон мекунад. Агар {{key:Mod+Plus}}-ро тасодуфан пахш кунед, тамоми саҳифа калон мешавад; {{key:Mod+0}} онро барқарор мекунад. Нигаред: [Тугмачаҳо, мушукҳо ва трекпадҳо](common:keys).

## Ҷои Move

Фармони Move нест: нуқтаи шуморишро интихоб кунед ва кашед, ё масоҳат ё хатро интихоб кунед ва дастакҳои кунҷашро кашед.

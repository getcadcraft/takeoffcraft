**Китобхонаи нархҳо** ашёҳоеро нигоҳ медорад, ки шумо дар ҳар кор истифода мебаред: навъ, воҳид, баландӣ, талафот, тарифҳои мавод ва меҳнат, ва маҷмӯаи онҳо. Он дар ин браузер, ҷудо аз ҳар ҳисоби ҳаҷми корҳо нигоҳ дошта мешавад, аз ин рӯ ҳар ҳисобе, ки шумо дар ин ҷо мекушоед, метавонад онро истифода барад.

Онро бо {{ui:Китобхона}} дар боло панели {{ui:Ҷузъҳо}} кушоед.

## Китобхонаро пур кунед

- {{ui:Ворид кардани CSV…}} ҷадвали электронии дар CSV захирашударо мехонад (ба сутунҳо дар поён нигаред). Ашёҳое, ки номашон ва навъашон аллакай дар китобхона ҳастанд, иваз мешаванд; боқимондаро илова мекунад. Сатрҳое, ки хонда наметавонад, гузаронида мешаванд ва мегӯяд, кадомҳо ва чаро.
- {{ui:Иловаи ашёҳои ин ҳисоб}} ҳар ашёи ҳисоби кушодашударо бо тарифҳо ва маҷмӯаи он ба китобхона нусха мебардорад (нишонаҳояшро не).
- CSV-и смета, ки TakeoffCraft содир мекунад ([Содироти смета](topic:export-estimate)), ҳамон тавре ки ҳаст ворид мешавад: нархҳои корҳои охирин барои корҳои навбатӣ асос мешаванд.

- {{ui:Бастаҳои касбӣ…}} маҷмӯаҳои ройгонро барои як касб илова мекунад, мисли гипсокартон, барқӣ ё бетон, бе нарх. Нигаред ба [Бастаҳои касбӣ](topic:trade-packs).

{{ui:Содироти CSV}} китобхонаро ҳамчун CSV захира мекунад, то нусха нигоҳ дорад, онро дар ҷадвали электронӣ таҳрир кунад ё ба ҳамкор диҳад. {{ui:Тоза кардан}} онро холӣ мекунад (ду маротиба клик кунед).

:::note
Китобхона дар захираи ин браузер ҷой дорад. Браузери дигар, компютери дигар ё тирезаи махфӣ захираи худро доранд (ё надоранд). Барои кӯчонидан онро содир кунед.
:::

## Онро дар ҳисоб истифода баред

- Ашёҳоро тик гузоред (барои маҳдуд кардани рӯйхат дар {{ui:Ёфтан дар китобхона}} нависед) ва {{ui:Илова ба ҳисоб}}-ро интихоб кунед. Онҳо бо маҷмӯаҳои худ дар як қадам илова мешаванд, ки онро {{key:Mod+Z}} бекор мекунад. Номе, ки аллакай дар ҳисоб аст, рақам мегирад, мисли `Қолин (2)`.
- {{ui:Навсозии нархҳо}} ба ашёҳои ҳисоб талафот ва тарифҳои китобхонаро медиҳад, барои ҳар ашёе, ки номаш ва навъаш бо ашёи китобхона мувофиқ аст, ва ҳамин тавр барои ҷузъҳои маҷмӯа бо ҳамон ном. Баландӣ, воҳидҳо ва формулаҳо ҳамон хел мемонанд. Як {{key:Mod+Z}} ҳамаи нархҳои кӯҳнаро бармегардонад.

## Сутунҳои CSV

Сатри аввал номи сутунҳоро дар ҳар тартиб медиҳад; сутунҳои дигар нодида гирифта мешаванд.

| Сутун | Чӣ дар он меравад |
|---|---|
| Item (ё Name) | Номи ашё. Лозим аст. |
| Type | Linear, Area ё Count (LF, SF ва EA низ кор мекунанд). Агар холӣ монад, воҳид қарор медиҳад. |
| Unit | LF ё m; SF, SY ё m²; EA. Холӣ: воҳиди маъмули навъ. |
| Waste % | `10` ё `10%`. |
| Material per unit, Labor per unit | Тарифҳо мисли `2.10` ё `$1,250`. |
| Height (ё Depth) | `9'-0"`, `9`, ё `2.7` барои воҳидҳои метрӣ. |
| Component, Formula | Сатре, ки номи Component дорад (ё навъи `Component`), қисми маҷмӯаи ашёи болоии худ аст. Воҳид, талафот ва тарифҳои он худашон; формулаи он ҳарфҳои ашёро истифода мебарад, нигаред ба [Маҷмӯаҳо ва формулаҳо](topic:assemblies). |

```
Item,Type,Unit,Waste %,Material per unit,Labor per unit,Height,Component,Formula
Partition type A,Linear,LF,10,2.10,3.33,9'-0",,
,Component,EA,,4.25,,,Studs 16 in. o.c.,ceil(L / 1.333) + N
VCT flooring,Area,SF,5,1.85,1.10,,,
Duplex outlets,Count,EA,,3.50,45,,,
```

Вергулҳо, нуқтавергулҳо ё табуляторҳо байни сутунҳо ҳама кор мекунанд.

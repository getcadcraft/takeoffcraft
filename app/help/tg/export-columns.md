## Смета (варақи XLSX ва CSV)

Як сатр барои ҳар ашё, ва пас як сатр барои ҳар ҷузъи маҷмӯаи он (бо фосила). Сипас сатри холӣ ва ҷамъи умумии лоиҳа.

| Сутун | Мундариҷа | Дар XLSX |
|---|---|---|
| A Ашё | Номи ашё (сиёҳ) ё номи ҷузъ (бо фосила) | Матн |
| B Навъ | Linear, Area, Count ё Component | Матн |
| C Воҳид | LF, m, SF, SY, m², EA ё воҳиди ҷузъ | Матн |
| D Миқдор | Ҷамъи ченшуда ё натиҷаи формула | Адад |
| E Исроф % | Исроф | Фоиз (0.10 = 10%) |
| F Миқдор бо исроф | Миқдор × (1 + исроф) | Формула `D*(1+E)` |
| G Маводи ҳар воҳид | Нархи маводи | Адад |
| H Меҳнати ҳар воҳид | Нархи меҳнат | Адад |
| I Маводи | Маблағи маводи ҳисобшуда | Формула `ROUND(F*G,2)` |
| J Меҳнат | Маблағи меҳнати ҳисобшуда | Формула `ROUND(F*H,2)` |
| K Ҷамъ | Маводи + меҳнат | Формула `I+J` |
| L Қайдҳо | Формулаи истифодашуда, хатои формула, нишонаҳо дар варақҳо бе миқёс, майдони девор, периметр | Матн |

Сатри ҷамъи умумии лоиҳа: `SUM` аз сутунҳои I, J ва K дар ҳамаи сатрҳои боло, ва «Нопурра: ба қайдҳои боло нигаред» дар Қайдҳо, вақте ки чизе дохил нашудааст.

Сатре, ки хатои формула дорад, миқдор ё маблағ надорад; қайдаш хатоиро нишон медиҳад. Сатри сарлавҳа мустаҳкам аст.

Дар CSV, ҳамон сутунҳо арзишҳои оддӣ доранд, Исроф % адади фоиз аст (10 барои 10%), ва пул бо доллар ва ду рақам баъд аз нуқта аст. Матне, ки барномаи ҷадвал онро формула ҳисоб мекунад (бо `=`, `+`, `-` ё `@` оғоз мешавад), бо `'` дар аввал навишта мешавад, то матн боқӣ монад.

## Аз рӯи варақ (танҳо XLSX)

| Сутун | Мундариҷа |
|---|---|
| Варақ | Номи варақ (бо номи PDF, агар кушода набошад) |
| Ашё | Номи ашё |
| Миқдор | Миқдори ашё дар он варақ, дар воҳиди худаш |
| Воҳид | Воҳиди ашё |
| Нишонаҳо | Шумораи нишонаҳо |

## Нишонаҳо (танҳо XLSX)

Як сатр барои ҳар нишона.

| Сутун | Мундариҷа |
|---|---|
| Варақ | Номи варақ |
| Ашё | Номи ашё |
| Навъ | Linear, Area ё Count |
| Миқдор | Дарозӣ, масоҳати соф ё 1 |
| Воҳид | LF ё m; SF, SY ё m²; EA |
| Тафсилот | Хатӣ: дарозии қисмҳо, қисмҳои тарҳшуда бо «(тарҳ)», ва «тарҳ (дарозӣ) аз (дарозӣ) кашида шуд». Масоҳат: масоҳати умумӣ ва буридашуда вақте ки буриш ҳаст, ва периметр. «Варақ миқёс надорад» барои нишонаҳои бе миқёс. |
| Масоҳати пешниҳод | Танҳо вақте ки ҷадвали пешниҳод ҳаст: масоҳати нишона ё «Масоҳати пешниҳод нест» |

## Аз рӯи масоҳати пешниҳод (танҳо XLSX, вақте ки ҷадвал масоҳати пешниҳод дорад)

| Сутун | Чӣ |
|---|---|
| Масоҳати пешниҳод | Номи масоҳат, ё «Масоҳати пешниҳод нест» |
| Ашё | Ашё, ё ҷузъи бо фосила зери он |
| Воҳид | Воҳиди ашё ё ҷузъ |
| Миқдор | Ченшуда дар он масоҳат (ҷузъҳо: формула аз ҷамъҳои масоҳат) |
| Миқдор бо исроф | Миқдор × (1 + исроф) |
| Маводи, Меҳнат, Ҷамъ | Ҳисобшуда то сент, мисли Смета |
| Қайдҳо | Формула, хатоҳо ва нишонаҳои бе миқёс, мисли Смета |

Ҳар масоҳат бо сатри «(ном) ҷамъи қисман» ба охир мерасад, ки хароҷоташ формулаҳои `SUM` аз сатрҳои он аст; сатри охирин, **Ҳамаи масоҳатҳои пешниҳод**, ҷамъҳои қисмро илова мекунад. Варақи **Нишонаҳо** пас ҳафтумин сутун, **Масоҳати пешниҳод**, дорад.

## Миқёсҳо (танҳо XLSX)

Як сатр барои ҳар варақ, ки миқёс ё нишона дорад.

| Сутун | Мундариҷа |
|---|---|
| Варақ | Номи варақ |
| Миқёс | Номи пешфарз, ё миқёси калибровкашуда, ё «Миқёс нест» |
| Чӣ тавр | «Пешфарз» ё «Калибровка дар асоси масофаи воридшуда» |
| Футҳо барои воҳиди PDF | Коэффисиенти дақиқи миқёс, ки TakeoffCraft истифода мебарад |

## Номҳои файлҳо

- `(ном).xlsx` ва `(ном).csv`, ки ном аз аввалин PDF-и кушодашуда дар ҳисоб гирифта мешавад.
- CSV бо кодировкаи UTF-8, нишонаи тартиби байт ва хатҳои Windows аст, ки барномаҳои ҷадвал дар ҳар платформа хонда метавонанд.

Ҷузъҳои маҷмӯа миқдори худро аз формула мегиранд. Формула ифодаи хурди арифметикӣ аз арзишҳои ченшудаи ашё аст. Ниг. [Маҷмӯаҳо ва формулаҳо](topic:assemblies) барои мисолҳои амалӣ.

## Тағйирёбандаҳо

| Навъи ашё | Тағйирёбанда | Маънӣ |
|---|---|---|
| Linear | `L` | Дарозии умумӣ |
| Linear | `H` | Баландии ашё |
| Linear | `A` | Масоҳати девор, L × H, бе кушодаҳои хатҳое, ки онҳоро доранд (ҷадвале аз BimCraft). Вақте ки ҷадвал усули ченкуниро номбар мекунад, `A` бо он чен мешавад: кушодаҳое, ки аз андозаи хурдтарини усул калон нестанд, мемонанд, ва чизе, ки усул дар ҷои пайвасти деворҳо мегирад, берун мешавад. Ёддошт зери ашё усулро номбар мекунад |
| Linear | `N` | Шумораи хатҳо |
| Area | `A` | Масоҳати соф умумӣ (контурҳо минус буриҳо) |
| Area | `P` | Периметри умумӣ, аз ҷумла канорҳои буриш |
| Area | `H` | Чуқурӣ ё ғафсии ашё |
| Area | `N` | Шумораи масоҳатҳо |
| Count | `N` | Шумора |

- Тағйирёбандаҳо дар воҳидҳои ашё ҳастанд: ниг. [Воҳидҳо](topic:units).
- Ҳарфҳои калон ва хурд якхеланд: `l` ин `L` аст.
- Танҳо тағйирёбандаҳои навъи ашёи худ кор мекунанд. `P` барои ашёи Linear натиҷаи `"P" дар ин ҷо чен карда нашудааст. Истифода баред L, H, A, N.` медиҳад.
- Баландии ё чуқурии холӣ 0 ҳисоб мешавад.

## Амалҳо

| Менависед | Маънӣ |
|---|---|
| `+` | Илова |
| `-` ё `−` | Тарҳ, ё арзиши манфӣ |
| `*` ё `×` | Зарб |
| `/` ё `÷` | Тақсим |
| `( )` | Гурӯҳбандӣ |

Зарб ва тақсим пеш аз илова ва тарҳ иҷро мешаванд: `L * 2 + 4` ин (L × 2) + 4 аст. Агар шубҳа бошад, қавс истифода баред.

Ададҳо метавонанд касрӣ (`1.333`, `.5`) ва дараҷагӣ (`1e3` = 1000) бошанд. Фосилаҳо нодида гирифта мешаванд.

## Функсияҳо

| Функсия | Натиҷа | Мисол |
|---|---|---|
| `ceil(x)` | Ба боло то адади бутун | `ceil(67.5)` = 68 |
| `floor(x)` | Ба поён то адади бутун | `floor(67.5)` = 67 |
| `round(x)` | Ба наздиктарин адади бутун, нимаҳо аз сифр дур | `round(2.5)` = 3 |
| `round(x, d)` | Ба d рақами баъд аз нуқта (0 то 10) | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | Хурдтарин арзиш | `min(N, 10)` |
| `max(a, b, …)` | Калонтарин арзиш | `max(1, ceil(N / 12))` |
| `abs(x)` | Арзиш бе аломати он | `abs(-3)` = 3 |

`ceil` ва `floor` хатогии хурди ҳисобкунаки компютерро нодида мегиранд, аз ин рӯ арзише, ки бояд дақиқан 1 бошад, ҳеҷ гоҳ ба 2 гирд карда намешавад.

## Хатоҳо

Формуле, ки хонда ё ҳисоб карда наметавонад, хатояшро зери майдон нишон медиҳад ва ҷузъ аз ҷамъҳо берун монда мешавад (сарлавҳаи {{ui:Quantities}} менависад «Нопурра»). Паёмҳо:

| Паём | Ислоҳ |
|---|---|
| Формуларо ворид кунед, мисли L ё ceil(L / 1.333) + 1. | Формула холӣ аст. |
| «X» дар ин ҷо чен карда нашудааст. Истифода баред … | Яке аз тағйирёбандаҳои зикршударо истифода баред. |
| «X» дар ин ҷо функсия нест. Истифода баред ceil, floor, round, min, max, abs. | Яке аз он функсияҳоро истифода баред. |
| «#» дар формула роҳ дода намешавад. | Он аломатро хориҷ кунед (воҳидҳо, `%`, `$` ва `=` роҳ дода намешаванд). |
| Қавси «)» нест. / Қавси «)» бе «(» ҳаст. | Қавсҳоро баробар кунед. |
| Пеш аз «)» арзиш нест. | Мисли `max(1, )`: арзишро пур кунед. |
| Формула хеле зуд тамом мешавад. | Мисли `L *`: онро пурра кунед. |
| Ногаҳонии «…». Амал нест? | Ду арзиш паҳлӯ ба паҳлӯ, мисли `2L`: `2 * L` нависед. |
| ceil() 1 арзиш мегирад. | Ба функсия шумораи дурусти арзишҳоро диҳед. |
| round(x, digits) ба адади бутуни рақамҳо аз 0 то 10 ниёз дорад. | Адади бутуни рақамҳои баъд аз нуқтаро истифода баред. |
| Формула ба сифр тақсим мешавад. | Одатан H нол аст: баландӣ ё чуқурии ашёро таъин кунед. |
| Формула адад намедиҳад. | Натиҷа барои адад шудан хеле калон аст. |
| Ин формула хеле дароз аст (ҳадди ниҳоӣ 500 аломат). | Онро кӯтоҳ кунед. |

## Бехатар аз рӯи тарҳ

Формула фақат арифметика бо тағйирёбандаҳо ва функсияҳои боло карда метавонад. Он код иҷро карда ё чизи дигареро хонда наметавонад, аз ин рӯ формула дар файли лоиҳае, ки касе барои шумо мефиристад, зарарнок нест.

**項目**是你要量測並定價的一樣東西：一種牆體類型、一種地板飾面、一個天花板、一扇門、一個燈具。你繪製的每個標記都屬於某個項目。其他程式稱之為條件。

每個項目都有一種類型（也可以加入其他種類的標記，見[一個項目，多種類型的標記](topic:create-items#one-item-several-kinds-of-marks)）：

| 類型 | 你繪製的內容 | 報告內容 | 單位 |
|---|---|---|---|
| 線性 | 相連點組成的段 | 長度、段數，以及有高度時的牆面積 | LF 或 m |
| 面積 | 含開孔的封閉輪廓 | 面積、周長、面積數 | SF、SY、SQ、ac、ha 或 m² |
| 計數 | 每個物件按一下 | 數量 | EA |
| 輸入的數量 | 無，直接輸入數量 | 你輸入的數字（或從 CivilCraft 帶入的數字） | LS、EA、CY、m³、lb、TON、kg、t、LF、m、SF、SY、SQ、ac、ha 或 m² |

## 輸入的數量（無圖紙）

估價中有些東西從來不會被繪製：進場費、許可證、應變預備金、整筆分包，以及 CivilCraft 算出的挖方與填方。把它們設為**輸入的數量**：

1. 選擇{{ui:新增項目}}，輸入名稱，選取{{ui:輸入的數量（無圖紙）}}，然後選擇{{ui:新增}}。
2. 在項目編輯器中選擇{{ui:單位}}（整筆金額用 LS），並輸入{{ui:數量}}：`1`、`2.5` 或 `1,250`。
3. 損耗與單價的設定方式與其他項目相同。組合件的公式使用 `Q`（即數量），例如 `ceil(Q / 12)` 車次。

輸入的數量不會佔用任何標記，也永遠不會使估價變成不完整。當數量計算有投標區域時，編輯器也會有{{ui:投標區域}}：此時數量會計入該區域、其替代項與合計，就像該處的標記一樣。從其他應用程式帶入的數量會註明來源，見[土方與高程點](topic:earthwork#cut-and-fill-from-civilcraft)。

## 建立項目

1. 在右側的{{ui:項目}}面板中，選擇{{ui:新增項目}}。
2. 輸入名稱，例如 `Interior wall type A` 或 `Carpet tile`。
3. 選取類型：{{ui:線性（長度）}}、{{ui:面積}}或{{ui:計數}}。
4. 選擇{{ui:新增}}（或按{{key:Enter}}）。
   項目會以其自身的顏色出現在清單中，成為你繪製時使用的項目，其編輯器會在清單下方開啟。狀態列會告訴你下一步應選擇哪個工具。

在表單中按{{key:Esc}}即可關閉表單，不新增項目。

:::tip
若你先選擇量測工具，數量計算會使用最後一個相同類型的項目，或開啟已選好該類型的{{ui:新增項目}}表單。
:::

## 選取你要繪製的項目

在清單中按一下某個項目。它會成為新標記的歸屬項目，其標記會在每張圖紙上以高亮顯示，其他項目則會淡化。若開啟的圖紙上沒有該項目的標記，數量計算會跳到有標記的圖紙。再按一次該項目即可停止高亮；它仍然是你繪製時使用的項目。

使用{{ui:選取}}工具按一下標記，也會將其所屬項目設為目前項目。

## 設定項目

項目編輯器（**項目：（名稱）**）有以下欄位。離開欄位或按{{key:Enter}}時會儲存每個欄位，且每項變更都可以復原。

| 欄位 | 用途 |
|---|---|
| {{ui:名稱}} | 顯示於清單、表格與匯出檔案中。 |
| {{ui:輸入}} | 線性、面積或計數。項目一旦有標記即鎖定（「有標記的項目會保留其類型」）。 |
| {{ui:顏色}} | 其標記在螢幕上及標示過的 PDF 中的顏色。 |
| {{ui:單位}} | 數量的報告單位：線性為 LF 或 m；面積為 SF、SY、SQ、ac、ha 或 m²；計數為 EA。 |
| {{ui:同時量測}} | 此項目可接受的其他種類標記，各有其單位。見下文。 |
| {{ui:高度}}（線性） | 牆高。項目因此也會報告牆面積（長度 × 高度）。來自 BimCraft 模型的段會帶有其門與窗：這些會被扣除一次，項目會列出毛面積、開口與淨面積。來自 BimCraft 專案且已選擇量測方法的數量計算，在此也會依該方法量測（備註會註明方法與來源，並說明未經工料測量師核對）；此方法無法在 TakeoffCraft 中變更。牆體類型中的磚塊或砌塊與砂漿會以兩個組件進入：要訂購的數量與砂漿體積。 |
| {{ui:深度}}（面積） | 深度或厚度，用於組合件公式（例如混凝土體積）。 |
| {{ui:損耗 %}} | 在計價前加入數量：10 即數量 × 1.10。 |
| {{ui:材料 $/LF}} | 每單位材料成本。標籤會依單位顯示，例如 $/SF、$/EA 等。 |
| {{ui:人工 $/LF}} | 每單位人工成本。 |
| {{ui:CSI編號}} | 其 CSI MasterFormat 編號，例如 `09 21 16`（或只填分部 `09`）。工作簿的「依分部」工作表會依此分組成本。來自[工種套件](topic:trade-packs)的項目已具備此編號。 |

英制單位的高度與深度可輸入英尺與英寸（`9'-0"`、`8' 6"`）或十進位英尺（`9`）；公制單位則可輸入公尺（`2.7`）或毫米（`2700 mm`）。單價可輸入如 `12.50` 或 `$1,250` 的金額，最多四位小數。見[長度、單價與百分比輸入](topic:entry-formats)。

在欄位下方，**已量測**會顯示項目公式可使用的合計及其字母：線性為長度 (L)、段數 (N)、牆面積 (A)；面積為面積 (A)、周長 (P)、面積數 (N)；計數為計數 (N)。

## 一個項目，多種類型的標記

有些東西可以用多種方式量測：房間有地板（面積）、沿牆的踢腳線（長度）以及門（計數）。與其建立三個項目，不如只建立一個：

1. 以其主要類型建立項目，例如面積項目 `Room 101`。
2. 在其編輯器的{{ui:同時量測}}下，勾選{{ui:線性}}、{{ui:計數}}或兩者。每一項旁邊會出現一個單位。
3. 以該項目接受的任一種類工具繪製：當 `Room 101` 為目前項目時，{{ui:面積}}繪製其地板，{{ui:線性}}繪製其踢腳線，{{ui:計數}}計算其門。TakeoffCraft 不會要求另選項目。

項目清單會顯示每個數量（`50.00 SF + 2 EA`）。在數量表中，項目的列會顯示其主要數量，而每種其他類型會在其下方有自己的一列，例如**Room 101（計數）**，並有自己的損耗、材料與人工單價。匯出檔、每張圖紙的表格與標示過的 PDF 圖例，都以相同方式列出它們。

主要類型的欄位仍屬於該主要類型：高度或深度、坡度、扣除面積與 3D 形狀，僅適用於其自身的標記。為面積項目繪製的踢腳線會沿平面以一般方式量測，並在 3D 中以平面顯示。組合件公式使用主要類型的合計。

只有在項目沒有該類型的標記時，才能取消勾選該類型；請先刪除這些標記，或先在**所選標記**下將其移至其他項目。標記可以移到任何接受其類型的項目。

再往下是{{ui:組合件}}：如立柱或木板等組件，各有其公式與單價。見[組合件與公式](topic:assemblies)。

最後，{{ui:上移}}與{{ui:下移}}會變更項目在清單與匯出檔中的位置，而{{ui:刪除項目}}會移除項目及其所有標記（會先詢問；可以復原）。

面積項目另有**坡度**（在斜面上量測的屋面平面：[屋頂與斜面](topic:roofs-and-slopes)）與**扣除面積**（其標記會從其他項目的面積中扣除：[量測面積](topic:measure-areas#back-outs-columns-shafts-and-openings-taken-out-of-several-items)）。線性項目有**斜面**（平、山牆、四坡或天溝），以及在山牆與四坡時的**坡度**。

## 表格中的單價

也可以直接在底部的{{ui:數量}}表格（{{ui:依項目}}）中輸入{{ui:損耗 %}}、材料與人工單價。這與編輯器中的設定相同。

## 計價方式

對每個項目與每個組合件組件：

1. **含損耗** = 數量 × (1 + 損耗 %)。
2. **材料** = 含損耗 × 每單位材料，四捨五入至分。
3. **人工** = 含損耗 × 每單位人工，四捨五入至分。
4. **合計** = 材料 + 人工。

{{ui:工程總額}}會加總每個項目與每個組件。一個項目可同時帶有自己的單價與組合件；兩者都會計入，因此當組件已包含成本時，將項目單價保持為 0。

## 依班組計算人工

項目的人工不一定以每單位單價計，也可由班組計算：班組每小時完成多少、有多少人，以及每人工資。在項目編輯器的{{ui:依班組計算人工}}下，勾選{{ui:依班組計算人工}}方塊，並填入：

| 欄位 | 範例 |
|---|---|
| {{ui:產量}} | `20`，即整個班組每小時 20 LF（以項目單位計） |
| {{ui:班組人數}} | `2` 人 |
| {{ui:每人每小時工資（$）}} | `45` |

TakeoffCraft 會根據含損耗的數量計算：

- **班組工時** = 數量 ÷ 產量（110 LF ÷ 20 = 5.5），
- **人工工時** = 班組工時 × 班組人數（11），
- **班組日** = 班組工時 ÷ 8（0.69），
- **人工** = 人工工時 × 工資（$495.00）。

編輯器會顯示結果，以及換算後的單價（$4.50/LF）。此時項目本身的人工單價會變成唯讀，在編輯器與表格中皆然。{{ui:數量}}表格的標題列會加上整體的人工工時與班組日。匯出檔會註明各班組的工時；在工作簿中，人工儲存格是依班組的公式（`ROUND(F2/20*2*45,2)`）。取消勾選方塊即可恢復為每單位單價。

## 公制項目

選擇 m（線性）或 m²（面積）作為單位。此時數量、高度與公式值都以公尺計。圖紙比例可為任一預設值或校正值；單位與比例彼此獨立。

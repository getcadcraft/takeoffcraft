每張圖紙都有自己的比例。你可以手動設定，或讓 TakeoffCraft 從圖紙文字中讀取（見下文），並加以檢查。在圖紙設定比例之前，{{ui:線性}}、{{ui:面積}}、{{ui:圓形}}與{{ui:切除區}}都會拒絕在其上量測。{{ui:計數}}與{{ui:自動計數}}則無須比例即可使用。

圖紙清單會顯示每張圖紙的比例，或**無比例**。開啟圖紙下方的列也會顯示相同資訊。

## 使用預設（當 PDF 以實際大小列印時）

1. 開啟圖紙。
2. 開啟{{ui:比例}}群組中的{{ui:預設}}清單。
3. 選取圖紙上印的比例，例如建築類下的 `1/8" = 1'-0"`。
   狀態列會顯示「此圖紙的比例：1/8" = 1'-0"」。
4. 依下文加以檢查。

預設值假設 PDF 為圖紙設計時的實際紙張大小。若 PDF 是以「符合頁面」製作，或為半尺寸圖組，則預設值是錯誤的。請改用校正。

完整清單請見[比例預設](topic:scale-presets)。

## 從圖紙文字讀取比例

多數圖紙會標示其比例：標題欄中為 `SCALE: 1/4" = 1'-0"`，視圖下方為 `1:100`。TakeoffCraft 可以讀取這些比例，並一次設定每張圖紙。

1. 開啟{{ui:預設}}清單，並選擇{{ui:從圖紙文字…}}（位於最上方）。
2. 清單會顯示每張圖紙：其目前的比例，以及其文字所述的內容 — **文字為 1/4" = 1'-0"**、**文字中無比例**，或**文字註明非依比例**（NTS）。
3. 未設定比例且文字有標示比例的圖紙會被勾選。可勾選或取消勾選任何圖紙，然後選擇{{ui:設定已勾選的比例}}。一次{{key:Mod+Z}}即可全部還原。
4. 使用{{ui:檢查}}（見下文）在每張圖紙上檢查一個尺寸：只有 PDF 以實際大小列印時，預設值才正確。

它可讀取建築（`3/16" = 1'-0"`、`1 1/2" = 1'-0"`）、工程（`1" = 20'`）與公制（`1:50`）的標示法，只要符合某個[預設值](topic:scale-presets)。當圖紙標示多於一種比例（例如含放大細部的平面圖）時，會採用其中出現次數最多的比例，而寫在 SCALE 一字之後的比例計為兩次；其他比例會以紅色顯示，供你檢查。掃描的圖紙沒有文字，須手動設定其比例。

## 依已知尺寸校正

當沒有可信的印刷比例、圖組經過縮放，或圖紙註明「非依比例」但仍有尺寸時，請使用此方式。

1. 開啟圖紙，並放大一個已知的長尺寸，例如格線間距或建築物整體尺寸。尺寸越長，準確度越高。
2. 在{{ui:比例}}群組中選擇{{ui:校正}}，或按{{key:K}}。
3. 點選尺寸的一端。為求精確，可在每端放大；兩次點選之間可縮放與平移。
4. 點選另一端。按住{{key:Shift}}可使線保持在 0°、45° 或 90°。
   開啟**校正此圖紙**對話方塊。
5. 在**實際距離**中輸入真實距離，例如 `24'-6 1/2"`、`24.5`（十進位英呎）、`30"` 或 `7.5 m`。請參閱[長度、單價與百分比輸入](topic:entry-formats)。
6. 選擇{{ui:設定比例}}。
   狀態列會以 "1" = (n)' 的形式顯示比例；若其與某個預設值相差在 0.5% 以內，則會指出是哪一個，例如「符合 1/4" = 1'-0"（如需精確比例，請選擇該預設值）」。
   TakeoffCraft 會回到{{ui:選取}}工具。

當校正結果符合某個預設值時，選擇該預設值即可取得精確比例，而不會依點選位置而定。

## 檢查比例

每個新比例都應以第二個尺寸檢查。

1. 在{{ui:比例}}群組中選擇{{ui:檢查}}，或按{{key:D}}。
2. 點選圖紙上印出的尺寸的兩端。
   狀態列會顯示「檢查：12'-6"」，並以十進位英呎與公尺顯示相同長度；檢查線會保留在圖紙上並顯示其長度。
3. 與印出的尺寸比較。若有偏差，請以較長的尺寸重新校正。

按{{key:Esc}}可清除檢查線。

## 變更比例

改選其他預設值或重新校正。若圖紙已有量測，TakeoffCraft 會詢問**變更此圖紙的比例？**，並說明將重新量測多少個量測值。選擇{{ui:變更比例}}。圖紙上的每個段與面積都會以新比例重新量測。可以按{{key:Mod+Z}}復原。

## 為何未設定比例的圖紙不以零計算

未設定比例之圖紙上的標記沒有實際長度或面積。TakeoffCraft 絕不會將其計為零，那樣會悄悄使估價過低。取而代之的是：

- 將這些標記排除於合計之外，
- 在{{ui:數量}}中於項目旁顯示「+(n) 未設比例」，
- 在表格標題中顯示「不完整：(n) 個標記位於未設定比例的圖紙上（未計入合計）」，
- 將數量寫入試算表匯出的附註欄。

當開啟的專案從未設定比例時，可能會發生這種情況。為圖紙設定比例後，標記會立即計入。計數標記一律會計入；它們不需要比例。

## 提示

- 開始量測前，請先為所有要量測的圖紙設定比例。在圖紙清單中搜尋**無比例**，即可找到尚未設定的圖紙（搜尋方塊搜尋的是圖紙名稱，而非比例）。
- 同一張圖紙上的細部與放大平面圖通常使用另一種比例。TakeoffCraft 每張圖紙只有一個比例；請參閱[尚未實作的功能](topic:not-built-yet)。
- 公制圖面：選擇公制預設值，例如 `1:100`，或以公制距離（如 `6000 mm`）校正。

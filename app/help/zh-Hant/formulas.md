組合中的組件透過公式取得數量。公式是對項目量測值進行的簡單算術運算式。範例請見[組合與公式](topic:assemblies)。

## 變數

| 項目類型 | 變數 | 意義 |
|---|---|---|
| 線性 | `L` | 總長度 |
| 線性 | `H` | 項目的高度 |
| 線性 | `A` | 牆面面積，L × H，扣除有開孔之段的開口面積（來自 BimCraft 的數量計算）。當該數量計算指定量測方法時，`A` 依該方法量測：不大於該方法最小尺寸的開口不予扣除，而該方法在牆體交接處計算扣除的部分則不計入。項目下方的附註會說明所用的方法。 |
| 線性 | `N` | 段數 |
| 面積 | `A` | 淨面積總計（外框減去開孔） |
| 面積 | `P` | 周長總計，包含開孔邊緣 |
| 面積 | `H` | 項目的深度或厚度 |
| 面積 | `N` | 面積的數量 |
| 計數 | `N` | 計數值 |

- 變數以項目的單位計：請見[單位](topic:units)。
- 大小寫相同：`l` 與 `L` 相同。
- 只有項目本身類型的變數有效。在線性項目上使用 `P` 會顯示「"P" 在此不是量測值。請使用 L、H、A、N。」
- 空白的高度或深度視為 0。

## 運算子

| 寫法 | 意義 |
|---|---|
| `+` | 加 |
| `-` 或 `−` | 減，或負值 |
| `*` 或 `×` | 乘 |
| `/` 或 `÷` | 除 |
| `( )` | 分組 |

乘除優先於加減：`L * 2 + 4` 即 (L × 2) + 4。不確定時請使用括號。

數字可以含小數（`1.333`、`.5`）與指數（`1e3` = 1000）。空格會被忽略。

## 函式

| 函式 | 結果 | 範例 |
|---|---|---|
| `ceil(x)` | 進位到整數 | `ceil(67.5)` = 68 |
| `floor(x)` | 捨去到整數 | `floor(67.5)` = 67 |
| `round(x)` | 四捨五入到最接近的整數，中間值遠離零 | `round(2.5)` = 3 |
| `round(x, d)` | 四捨五入到 d 位小數（0 至 10） | `round(3.14159, 2)` = 3.14 |
| `min(a, b, …)` | 最小值 | `min(N, 10)` |
| `max(a, b, …)` | 最大值 | `max(1, ceil(N / 12))` |
| `abs(x)` | 去除正負號後的值 | `abs(-3)` = 3 |

`ceil` 與 `floor` 會忽略電腦計算產生的微小誤差，因此理應正好為 1 的數值不會被進位成 2。

## 錯誤

無法讀取或計算的公式會在欄位下方顯示錯誤，該組件會被排除在合計之外（{{ui:Quantities}}標題會顯示「不完整」）。訊息如下：

| 訊息 | 修正方式 |
|---|---|
| 「請輸入公式，例如 L 或 ceil(L / 1.333) + 1。」 | 公式為空白。 |
| 「"X" 在此不是量測值。請使用…」 | 使用上列的變數之一。 |
| 「"X" 在此不是函式。請使用 ceil、floor、round、min、max、abs。」 | 使用其中一個函式。 |
| 「公式中不允許使用 "#"。」 | 移除該字元（不允許單位、`%`、`$` 與 `=`）。 |
| 「缺少 ")"。」或「")" 前沒有對應的 "("。」 | 使括號配對。 |
| 「")" 前缺少數值。」 | 例如 `max(1, )`：補上數值。 |
| 「公式過早結束。」 | 例如 `L *`：補完公式。 |
| 「非預期的 "…"。是否缺少運算子？」 | 兩個數值並列，例如 `2L`：請寫成 `2 * L`。 |
| 「ceil() 只接受 1 個值。」 | 給函式正確數量的值。 |
| 「round(x, digits) 需要 0 至 10 之間的整數位數。」 | 使用整數的小數位數。 |
| 「公式除以零。」 | 通常是 H 為 0：請設定項目的高度或深度。 |
| 「公式的結果不是數字。」 | 結果太大，無法表示為數字。 |
| 「公式過長（最多 500 個字元）。」 | 縮短公式。 |

## 設計上的安全性

公式只能對上述變數與函式進行算術運算，無法執行程式碼或讀取其他內容，因此他人傳送的專案檔中的公式無害。

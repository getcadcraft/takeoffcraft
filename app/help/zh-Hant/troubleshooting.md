TakeoffCraft 大多會在視窗底部的狀態列中說明無法執行的原因。請在下方找到該訊息。

## 開啟檔案

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| PDF 讀取器無法載入。重新載入頁面後再試。 | 應用程式的 PDF 讀取器未能載入，通常是因為你處於離線狀態，且此應用程式從未儲存供離線使用。 | 重新連線並重新載入。然後選擇{{ui:Save for offline}}，並等待{{ui:Offline ready}}；見[離線使用](common:offline)。 |
| （名稱）受密碼保護。請開啟未受保護的副本。 | 開啟此 PDF 需要密碼。 | 向對方索取未受保護的副本，或在你信任的 PDF 程式中移除密碼。 |
| （名稱）無法被讀取為 PDF（…） | 檔案已損壞，或並非真正的 PDF。 | 重新下載，或由製作該檔案的程式重新儲存。 |
| （名稱）已開啟。 | 同一份 PDF（內容相同）已開啟。 | 無需處理。 |
| TakeoffCraft 可開啟 PDF 與 .takeoff.json 專案。已略過：… | 其他檔案類型已被捨棄。 | 先將圖面轉換為 PDF。 |
| 拖放檔案後沒有反應 | 檔案拖放在瀏覽器視窗之外，或瀏覽器在新分頁中開啟了 PDF。 | 拖放到 TakeoffCraft 頁面本身；「拖放 PDF 或 .takeoff.json」框會顯示何時可以運作。 |
| 開啟大型圖組需要一些時間 | 每個 PDF 都會完整讀取以產生指紋辨識。 | 等待「正在開啟（名稱）…」訊息消失。縮圖會在你捲動時逐漸載入。 |

## 測量

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| 先開啟 PDF。 | 未開啟任何圖面。 | 開啟 PDF。 |
| 此圖面尚未設定比例，因此無法量測。請先選取預設比例或進行校正（計數無需比例即可運作）。 | 線性、面積、圓形與切除區工具需要比例。 | [設定比例](topic:set-the-scale)。 |
| 請先建立線性項目（在{{ui:Items}}下命名），然後點擊圖面。 | 沒有該類型的項目。 | 填寫開啟的{{ui:New item}}表單，然後選擇{{ui:Add}}。 |
| 請先選取要計算的項目（項目面板）。 | 目前的項目已被刪除。 | 點擊{{ui:Items}}下的項目。 |
| 一段量測至少需要兩個點。 | 你在點擊一次後即結束。 | 至少點擊兩個點。 |
| 面積至少需要三個點。 | 角點太少。 | 至少點擊三個角點。 |
| 輪廓自身交叉，因此其面積會有誤。請重新繪製，不要交叉。 | 8 字形。 | 將其繪製為兩個面積，或依順序沿邊緣繪製。 |
| 這些點未圍成任何面積。 | 所有點都在同一直線上。 | 點擊能圍出空間的角點。 |
| 請先選取面積標記（選取工具），再選擇切除區並在其中繪製孔洞。 | {{ui:Cut-out}}需要先選取面積。 | 按{{key:V}}，點擊面積，然後按{{key:X}}。 |
| 切除區必須完全位於面積之內。 | 孔洞與輪廓交叉或超出輪廓。 | 在面積內繪製孔洞。 |
| 切除區不能彼此重疊。 | 兩個孔洞重疊。 | 繪製一個圍住兩者的孔洞，或將兩者分開。 |
| …該點已放回原位。 | 拖曳的角點會使輪廓自身交叉，或使孔洞超出邊界。 | 拖曳到能讓形狀維持有效的位置。 |
| 點擊圓周上遠離圓心的一點。 | 第二次點擊太靠近圓心。 | 點擊更遠的位置。 |
| 點擊時圖面會平移，而不是新增點 | 按鈕按下時指標移動超過數像素；這會被視為拖曳。 | 點擊時不要移動，尤其是使用觸控板時。 |
| {{key:Shift}}不會鎖角 | 你正在圓弧上放置點，或正在繪製圓。 | 45° 鎖角只適用於直線段。 |
| 點會跳到附近的線上 | 「鎖點到圖面的線條」已開啟。 | 放大檢視以便在線條之間點擊，或按{{key:F3}}關閉鎖點。 |
| 沒有出現鎖點標記 | 鎖點已關閉、圖面為掃描，或該工具不鎖點（計數、自動計數、貼上）。 | 按{{key:F3}}；若為掃描圖面，則沒有可鎖定的線條。 |
| 長度不正確 | 比例錯誤（通常是以預設值調整大小的 PDF）。 | 對已知尺寸使用{{ui:Check}}，然後使用{{ui:Calibrate}}。 |

## 比例

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| 請選取距離較遠的兩點。 | 校正點幾乎重疊。 | 在較長的尺寸上進行校正。 |
| 校正對話方塊中的訊息，例如「無法讀取該距離」 | 距離的格式是 TakeoffCraft 無法讀取的。 | 見[長度、單價與百分比輸入](topic:entry-formats)。 |
| 此圖面尚未設定比例，因此沒有可檢查的內容。請進行校正，或選取預設比例。 | 在未設定比例的圖面上使用{{ui:Check}}。 | 先設定比例。 |
| {{ui:Preset}}清單呈灰色 | 未開啟任何圖面。 | 開啟 PDF。 |

## 數量與公式

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| 未完成：…（未計入合計） | 公式錯誤，或標記位於未設定比例的圖面上。 | 見[讀取數量與估價](topic:read-quantities#the-incomplete-warning)。 |
| 項目旁顯示 +(n)，未設比例 | 部分標記位於未設定比例的圖面上。 | 為這些圖面設定比例。 |
| 公式錯誤：… | 無法計算該公式。 | 見[公式語言](topic:formulas#errors)。 |
| 此項目已有標記，因此無法變更其類型。 | 一旦有標記，類型即被鎖定。 | 建立另一類型的新項目，並以該項目重新繪製標記。 |
| 項目需要名稱。 | 名稱欄位被清空。 | 輸入名稱。 |
| 輸入如 12.50 的金額。/ 輸入如 10 或 7.5 的百分比。 | 無法讀取單價或損耗。 | 見[長度、單價與百分比輸入](topic:entry-formats)。 |
| 合計看起來重複計算了 | 項目本身的單價與組件承載相同的成本。 | 當組件已承載成本時，將項目本身的單價設為 0。 |
| 此項目的標記位於未開啟的 PDF 上。 | 你點擊了一個所有標記都位於未開啟 PDF 上的項目。 | 開啟那些 PDF；其名稱列於{{ui:Sheets}}下。 |

## 自動計數

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| 方框太小。請將其繪製在整個符號周圍。 | 方框非常小。 | 放大檢視，並以方框圍住整個符號。 |
| 該方框幾乎是空的。請繪製在符號周圍。 | 方框內只有紙張。 | 以方框圍住符號本身。 |
| 沒有相符項目。請降低相符度滑桿，或更緊密地框選符號。 | 沒有任何項目達到足夠高的分數。 | 緊密框選符號，或將{{ui:Match}}滑桿向下拖曳。 |
| 相符項目過多，包括錯誤的符號 | 相似的符號得分接近真正的符號。 | 提高{{ui:Match}}滑桿，並點擊錯誤的方框以排除它們。 |
| 其他圖面上缺少相符項目 | 這些圖面以不同的尺寸，或非 90° 步進的角度繪製符號。 | 在那些圖面上繪製方框後進行搜尋，或手動計數。 |
| （n）張圖紙過大，無法以此符號尺寸搜尋。 | 以工作尺寸計算時，圖紙會過大。 | 框選較大的符號，或手動計數該圖紙。 |
| 搜尋失敗：… | 背景搜尋已停止。 | 再試一次；若重複發生，請重新載入頁面（先儲存）。離線時，只有在應用程式列顯示{{ui:Offline ready}}後才能運作。 |
| 拖曳會繪製方框而非平移 | 這是{{ui:Auto count}}的運作方式。 | 按住{{key:Space}}後拖曳，或以中鍵拖曳。 |

## 儲存與匯出

| 訊息或現象 | 原因 | 解決方法 |
|---|---|---|
| 尚無可匯出的內容：請建立一個項目並加以計算。 | 沒有任何項目。 | 先建立一個項目。 |
| 已開啟的 PDF 上尚無標記。 | {{ui:Marked PDF}}無法在已開啟的 PDF 上繪製任何內容。 | 開啟有標記的 PDF。 |
| 此 PDF 受密碼保護或加密，因此無法寫出標記副本。… | 該 PDF 已加密。 | 改為匯出{{ui:XLSX}}，或使用未加密的 PDF 副本（由於是不同的檔案，它需要有自己的數量計算）。 |
| 無法寫入標記 PDF：… | 常見原因：離線，且應用程式未儲存供離線使用，因此缺少 PDF 寫入器。 | 連線後再次選擇{{ui:Marked PDF}}。若要避免此情況，請選擇{{ui:Save for offline}}，並等待{{ui:Offline ready}}。 |
| 只下載了一份標記 PDF | 瀏覽器一次阻擋了多個下載。 | 允許此網站的多重下載，然後再次匯出。 |
| （檔案）不是 TakeoffCraft 專案（不是有效的 JSON）。/ 這不是 TakeoffCraft 專案檔。 | 檔案錯誤，或檔案已損壞。 | 選取 `.takeoff.json` 檔案。 |
| 此專案由較新版本的 TakeoffCraft 儲存。請在該版本中開啟。 | 檔案來自較新的版本。 | 在較新版本中開啟。 |
| （n）個標記已損壞並已略過。 | 檔案的一部分已損壞，或被手動編輯。 | 其餘部分已開啟。請重新繪製遺失的標記，或開啟較舊的副本。 |
| 重新開啟後標記遺失 | PDF 未開啟，或其中一個已變更。 | 見[儲存與重新開啟數量計算](topic:save-and-reopen#when-a-pdf-has-changed)。 |
| 瀏覽器詢問「要離開網站嗎？」 | 有尚未儲存的變更。 | 留在頁面，並以{{key:Mod+S}}儲存。 |

## 鍵盤與滑鼠

| 現象 | 原因 | 解決方法 |
|---|---|---|
| 字母鍵沒有反應 | 游標位於欄位中（搜尋、項目編輯器、表格）。 | 點擊圖面，或按{{key:Tab}}離開欄位。 |
| 滾輪是縮放而非捲動 | 滾輪一律縮放圖面。 | 拖曳以平移。 |
| 整個頁面變大或變小 | 瀏覽器縮放（{{key:Mod+Plus}}或{{key:Mod+Minus}}）。 | 按{{key:Mod+0}}。以滾輪或單獨的{{key:Plus}}與{{key:Minus}}縮放圖面。 |
| 按 Backspace 後標記消失 | 未在繪製時，Backspace 會刪除所選的標記。 | 按{{key:Mod+Z}}可將其復原。 |
| 在 Mac 上按右鍵無法結束 | Control 點按會被視為一般點按。 | 開啟次要按鍵點按後，使用雙指點按，或按{{key:Enter}}。 |

## 觸控螢幕

在觸控螢幕上：

- **輕觸**會放置一個點（或以{{ui:Select}}選取標記）。單指拖曳即可平移。
- **雙指**捏合可以兩指之間的點為中心縮放，兩指一起移動時則平移。第二根手指放下會取消第一根手指所開始的操作，因此捏合不會留下一個點。
- 以**長按**（相當於右鍵）、**連按兩下**，或圖面底部列中的{{ui:Finish}}，即可結束一段量測或一個輪廓。同一列上有{{ui:Back}}（撤回最後一點）與{{ui:Cancel}}。面積也可以點擊第一點來封閉。
- 手指的目標範圍較大：點會鎖定、封閉與選取的距離更遠，角點控點也更大。

輸入長度需要鍵盤；當{{ui:Type}}方塊取得焦點時，螢幕鍵盤即可使用。

在平板上，搭配鍵盤與滑鼠或觸控板會讓數量計算容易得多。

## 離線使用

| 按鈕或現象 | 原因 | 解決方法 |
|---|---|---|
| {{ui:Could not save}} | 儲存供離線使用時，部分應用程式檔案未能下載。 | 檢查網路連線，然後再次選擇該按鈕。 |
| {{ui:Offline not available}} | 私密瀏覽視窗與部分受管理的電腦會阻擋離線副本。 | 使用一般視窗，或其他瀏覽器。 |
| 「正在儲存…」一直沒有開始 | 你處於離線狀態；儲存需要連線。 | 在連線時儲存。 |
| 更新後應用程式仍是舊版 | 離線副本來自較早的日子。 | 連線後，選擇{{ui:Offline ready}}，然後選擇{{ui:Save again (get the newest version)}}。 |
| 想要收回空間 | 離線副本約 6 MB。 | 選擇{{ui:Offline ready}}，然後選擇{{ui:Remove the offline copy}}。 |

見[離線使用](common:offline)。

## 仍未解決

若應用程式停止回應，請重新載入頁面。除非已儲存，否則重新載入會遺失你的數量計算，因此若可以，請先以{{key:Mod+S}}儲存。瀏覽器相關問題請見[瀏覽器與電腦](common:browsers)。

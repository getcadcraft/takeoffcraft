估價會計算你所量取的數量。**投標摘要**會將其轉換為價格：加入銷售稅、管理費、利潤與保證金，並製作包含你的包含與不包含範圍的**報價書PDF**。

從{{ui:匯出}} › {{ui:投標摘要與報價書…}}開啟。其中的所有內容都會與數量計算一併儲存，且每項變更都可以復原。

## 附加費

在五個欄位中任一輸入百分比（其餘保持 0）。它們會依此順序計算，每一項都以其上方的結果為基礎：

| 列 | 計算方式 |
|---|---|
| 材料、人工 | 估價的總計（若數量計算有[替代項](topic:bid-areas#alternates-base-bid-plus-adds-and-deducts)，則為基本標價）。 |
| 人工附加費用 | 附加費 % × 人工：工班薪資所需的薪資稅、保險與福利。 |
| **成本** | 材料 + 人工 + 人工附加費用。 |
| 材料銷售稅 | 稅 % × 材料。 |
| 管理費 | 管理費 % ×（成本 + 稅）。 |
| 利潤 | 利潤 % ×（成本 + 稅 + 管理費）。 |
| 保證金 | 保證金 % × 以上所有項目。 |
| **投標價** | 各列的總和。 |

每一列都會四捨五入到分。活頁簿會在估價工作表的總計下方顯示相同的列，並以即時公式呈現。摘要會在你輸入時即時更新：按{{key:Enter}}即可確定百分比。每個替代項都會以其自身的成本套用相同的附加費，讓業主看到取消它實際上會改變多少。

## 報價書

填寫報價書應包含的內容：

- **專案**（若留空，則為數量計算的名稱）、**致**（客戶）與**從**（你的公司）。
- **包含**與**不包含**：每行一項；行首加上破折號或項目符號皆可。
- **條款**：自由文字，例如「有效期 30 天。」
- **列出項目與數量**：逐項列出工作範圍與數量，不含價格。若為總價報價，請取消勾選。

選擇{{ui:報價書PDF}}。PDF（`<takeoff> - proposal.pdf`）會包含日期、附有各項附加費與投標價的價格區塊、替代項、工作範圍、包含與不包含範圍、條款，以及供簽名與填寫日期的欄位。若有些數量無法量測（例如沒有比例的圖紙），它會在價格下方註明。

## 匯出內容

一旦數量計算有投標摘要，CSV會以它結尾，活頁簿會新增**投標摘要**工作表，列出每一行、其百分比與金額。請參閱[匯出估價](topic:export-estimate)。

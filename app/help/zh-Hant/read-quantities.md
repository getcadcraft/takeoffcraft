底部的{{ui:數量}}表格就是即時的估價。繪製、刪除、變更比例或編輯單價時，它都會立即更新。數量不會被儲存；每次都會依標記重新量測，因此不會過時。

## 依項目

選擇{{ui:依項目}}（預設）。每個項目一列，其組合元件則各占一列於其下。

| 欄位 | 說明 |
|---|---|
| 項目 | 名稱，以項目的顏色標示。「+(n) unscaled」表示部分標記位於未設定比例的圖紙上。 |
| 數量 | 以項目單位計的量測合計（組合元件則為公式結果）。 |
| 單位 | LF、m、SF、SY、m²、EA，或元件的單位。 |
| 損耗 % | 可在此輸入，或在項目編輯器中輸入。 |
| 含損耗 | 數量 ×（1 + 損耗）。 |
| 材料/單位、人工/單位 | 單價；可在此直接輸入。 |
| 材料、人工 | 含損耗的數量 × 單價，四捨五入至分。 |
| 合計 | 材料 + 人工。 |

最後一列**工程合計**會加總材料、人工與合計欄。同一總額也會顯示在表格標題列的右側。

在損耗或單價儲存格中輸入後，按{{key:Enter}}或點選其他處即可套用。TakeoffCraft 無法讀取的數值會以紅色外框標示，狀態列會說明原因，例如「請輸入如 12.50 這樣的金額。」

點選項目的列即可在每張圖紙上反白其標記，並跳至有標記的圖紙（與點選{{ui:項目}}下的項目相同）。

## 依圖紙

選擇{{ui:依圖紙}}，即可查看每張圖紙上各項目的數量及標記數。點選某一列即可開啟該圖紙並反白該項目。可用來確認每張圖紙都已計算，或依樓層或工作範圍拆分數量。

## 依區域

當數量計算包含投標範圍時，{{ui:依區域}}會列出每個區域的項目與小計。請參閱[投標範圍](topic:bid-areas)。

## 不完整警告

當有項目未計入合計時，表格標題會顯示警告，例如：

「不完整：1 個公式錯誤，6 個標記位於未設定比例的圖紙上（未計入合計）」

- **公式錯誤**：組合元件的公式無法計算。其列會顯示「公式錯誤：…」。請參閱[組合與公式](topic:assemblies#when-a-formula-is-wrong)。
- **未設定比例之圖紙上的標記**：請為這些圖紙設定比例。請參閱[設定比例](topic:set-the-scale#why-unscaled-sheets-are-not-counted-as-zero)。

相同的說明也會寫入匯出的試算表，因此不完整的估價不會看起來是完整的。

## 反白顯示項目

點選{{ui:項目}}下的項目或表格中的項目。其標記會在每張圖紙上維持全色，其餘則淡出。圖紙清單會在含有標記的圖紙上顯示「(n) 已反白」。再次點選該項目即可停止反白。

## 側邊面板中的項目合計

{{ui:項目}}清單中的每個項目也會顯示其數量。項目編輯器中的**實測**區塊會顯示其公式所用的數值：長度、段數與牆面積；面積、周長與區域數；或計數。

## 不在開啟狀態的 PDF 上的標記

數量計算可以包含本次未開啟之 PDF 上的標記。這些標記仍會計入每個合計；圖紙清單會列出這些 PDF 的名稱。請參閱[儲存與重新開啟數量計算](topic:save-and-reopen)。

## 擴大繪圖區

數量標題列右側的箭頭按鈕可隱藏{{ui:數量}}表格，讓圖紙有更多空間。再按一次即可重新顯示表格。

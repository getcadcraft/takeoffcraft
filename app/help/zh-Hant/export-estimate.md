匯出為下載檔案。匯出內容由數量計算與已開啟的 PDF 在本機產生，不會傳送到任何地方。

## 試算表形式的估價（XLSX）

1. 在工具列開啟{{ui:Export}}功能表，選擇{{ui:XLSX}}。
   瀏覽器會下載 `(name).xlsx`。狀態列會顯示「已匯出 (name).xlsx（含即時公式的估價、依圖紙、標記、比例尺）。」，若估價不完整則會加上警告。
2. 以試算表程式開啟。

活頁簿包含四個工作表，並在適用時另加下列報表：

| 工作表 | 內容 |
|---|---|
| 估價 | 每個項目與組件一列：數量、損耗、含損耗數量、單價、材料、人工、合計與附註。底部為工作總計。 |
| 依圖紙 | 每個項目在各圖紙上的數量，以及標記數。 |
| 標記 | 每個標記：圖紙、項目、類型、數量，以及明細（各段長度、總面積與開孔面積、周長）。 |
| 比例尺 | 每張有比例尺或標記的圖紙：其比例尺、設定方式（預設，或依哪一段距離校正），以及每 PDF 單位的英尺數。 |
| 數量摘要 | 每個項目的數量、CSI編號、標記與圖紙，不含價格。 |
| 材料清單 | 數量計算中所有組合零件的加總（同一零件被多個項目使用時只佔一列），含損耗與材料成本，以及使用該零件的項目。 |
| 報價請求 | 寄給供應商的材料清單：含損耗的數量、空白的單價欄，以及隨輸入單價而填入的延伸金額與合計。 |
| 依分部 | 當項目具有{{ui:CSI number}}時，依 CSI MasterFormat 分部列出材料、人工與合計。 |

若有[投標摘要](topic:bid-summary)，估價工作表末尾還會以即時公式列出其加價項目（人工負擔、營業稅、管理費、利潤、保證金與投標價）。

估價工作表保留**即時公式**：含損耗的數量、四捨五入後的材料與人工金額、每列的合計與工作總計。試算表程式會重新計算，因此可在試算表中變更單價或損耗，合計會隨之更新。TakeoffCraft 計算出的數字也會存入儲存格，並精確到分。

附註欄列出每個組件的公式、公式錯誤、無比例尺圖紙上的標記、牆面面積與周長。若有任何遺漏，工作總計列會顯示「不完整：請見上方附註」。

此活頁簿已在 LibreOffice Calc 中檢查，重新計算的合計相同。尚未在 Excel 中測試。逐欄的詳細說明請見[匯出欄位](topic:export-columns)。

## CSV 形式的估價

開啟{{ui:Export}}功能表，選擇{{ui:CSV}}。會得到 `(name).csv`：與估價工作表相同的列與欄，為純數值（無公式），並包含工作總計。可貼入其他估價或會計系統。

CSV 只包含估價；若要依圖紙的數量與標記清單，請使用 XLSX。同一功能表中的{{ui:Material list}}會將材料清單單獨存為 CSV，供採購使用。

## Google 試算表中的估價

在數量表格上方，**複製到 Google 試算表**會將估價以定位字元分隔的文字放到剪貼簿，列與 CSV 相同。在 Google 試算表中點選儲存格 A1 後貼上。TakeoffCraft 不會登入 Google，也不會傳送任何內容到該處。

## 缺少單價與簽核

有數量但沒有單價的列，其附註會顯示**無單價**，匯出時會在合計下方統計這些列。若估價已完成簽核，匯出會列出簽核人、簽核時間與對應的總額。請見[缺少單價與估價簽核](topic:sign-off-the-estimate)。

## 已標記的 PDF

1. 開啟要繪製標記的 PDF。
2. 開啟{{ui:Export}}功能表，選擇{{ui:Marked PDF}}。
   顯示「Writing the marked PDF…」，之後瀏覽器會為每個已標記的 PDF 下載一個檔案，檔名為 `(PDF name) (takeoff).pdf`。

在副本中：

- 段以其項目的顏色繪製為線條，
- 面積以淺色填滿並帶實線外框，開孔保持空白，
- 計數以圓點表示，
- 每個有標記的頁面左下角會有一個小型圖例：每個項目的顏色、名稱以及該頁上的數量。

原始 PDF 不會被更動。

注意事項：

- 只會寫入已開啟的 PDF。未開啟之 PDF 上的標記仍計入合計，但不會繪製；請先開啟那些 PDF。
- 圖例中的名稱使用標準 PDF 字型。無法顯示的字母會以「?」顯示。
- 加密的 PDF 無法複製並附上標記，訊息為：「This PDF is password-protected or encrypted, so a marked copy cannot be written. The takeoff itself is fine; export the spreadsheet instead.」
- 在同一索引標籤中第一次使用{{ui:Marked PDF}}時會載入 PDF 寫入元件。離線時，只有應用程式列顯示{{ui:Offline ready}}時才可用；請見[離線工作](common:offline)。

:::chromium
下載多個已標記的 PDF 時，Chrome 與 Edge 可能會詢問一次是否允許此網站下載多個檔案。請選擇「允許」，否則只會取得第一個檔案。
:::

## 沒有可匯出的內容？

- {{ui:XLSX}}與{{ui:CSV}}至少需要一個項目：「尚無可匯出的內容：請建立一個項目並進行量測。」
- {{ui:Marked PDF}}需要已開啟的 PDF 上有標記：「已開啟的 PDF 上尚無標記。」

## 也要儲存數量計算

匯出是一份報表。若要之後繼續處理數量計算，也請選擇{{ui:Save takeoff}}：請見[儲存與重新開啟數量計算](topic:save-and-reopen)。

若要加入管理費、利潤、稅金與保證金並傳送報價單，請見[投標摘要與報價單](topic:bid-summary)。

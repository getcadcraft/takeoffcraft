以下是TakeoffCraft 0.9相較於0.8.1的變更。這是針對本應用程式的小型版本：現在可以用公尺、公分或毫米讀取長度，面積與比例能正確套用公制作業，圓弧也有十種繪製方式。即時協作工作階段中也會顯示每位成員的位置。

## 新增功能

### 以公尺、公分或毫米讀取長度

- **長度顯示方式。** {{ui:設定}} › {{ui:TakeoffCraft}} 內有{{ui:長度顯示方式}}，選項為{{ui:跟隨全域}}、{{ui:英呎英吋}}、m、cm 與 mm。{{ui:跟隨全域}}會使用在{{ui:設定}} › {{ui:全域}} › {{ui:單位}}中加上星號的公制長度單位；若未加星號，則採用英呎英吋。此設定會改變圖紙上、狀態列與各面板中長度的顯示方式，包括高度、深度、厚度與標高。在高度欄位中輸入的純數字，會以所顯示的單位讀取。
- **僅影響顯示。** 數量、成本與匯出皆依精確長度計算。1/16、1/8 與 1/4 英吋的選項只會在英呎英吋時出現。請參閱[以公尺顯示長度](topic:show-lengths-in-meters)。
- **重量單位。** {{ui:輸入的數量（無圖紙）}}項目現在可以使用 lb、TON、kg 或 t，並可依單位計價。
- **溫度。** 每個項目在項目編輯器中都有選填的{{ui:溫度}}欄位，可以攝氏或華氏度輸入（C 或 F）。{{ui:設定}} › {{ui:TakeoffCraft}} 中的{{ui:溫度顯示方式}}提供{{ui:跟隨全域}}、°C 或 °F。

### 公制作業的面積與比例

- **圖面上以 m2 顯示面積。** 以公制項目量測的面積，現在會在圖面標籤與標記面板中顯示 m2，表格中也一樣，不再顯示 SF。規則為：項目以公制計價，或長度以 m、cm 或 mm 顯示時使用 m2；否則使用 SF。
- **牆面積。** 具有高度的線性項目，會在項目清單中顯示其牆面積（長度乘以高度），並於依項目列出的數量表下方以附註列顯示。
- **比例預設值 1:75 與 1:150。** 這兩項位於{{ui:比例}}群組的{{ui:預設}}清單中，該群組現在共有 32 種比例。請參閱[比例預設值](topic:scale-presets)。

### 十種方法的圓弧

- 啟用{{ui:圓弧}}時（工具列按鈕或{{key:R}}），圖紙列中會出現{{ui:圓弧方法}}方塊，選項為：三點；起點、圓心、終點；起點、圓心、角度；起點、圓心、長度；起點、終點、角度；起點、終點、方向；起點、終點、半徑；圓心、起點、終點；圓心、起點、角度；以及圓心、起點、長度。角度、長度、半徑與方向皆可點選或輸入。此功能適用於線段、面積與開孔。0.9 之前儲存的檔案開啟後結果相同。請參閱[以十種方法繪製圓弧](topic:draw-arcs-ten-methods)。

### 協同作業

- **檢視彼此的游標。** 在即時協作工作階段中，每位成員的指標會以其名稱與顏色顯示在圖紙上，並以虛線框標示其所選取的標記。位於其他圖紙的成員，會列出該圖紙的名稱。請參閱[與他人即時協作](topic:work-live)。
- **跟隨成員與人員清單。** 即時協作工作階段中的{{ui:人員}}按鈕，會列出每位成員、其正在使用的工具、所在圖紙，以及最後編輯的時間。{{ui:跟隨}}會讓檢視與對方同步，主持人則可使用{{ui:要求所有人跟隨我}}。請參閱[在即時協作工作階段中跟隨隊友](topic:follow-a-teammate)。

## 所有應用程式

- **工具提示與啟動提示。** 滑鼠停留時顯示的文字為 Bootstrap 工具提示，啟動提示可以關閉。
- **可捲動的索引標籤列。** 面板中放不下的索引標籤列會改為捲動，不再被截斷。
- **索引標籤標題。** 瀏覽器索引標籤顯示為 `<document> - TakeoffCraft | CadCraft`。
- **版面配置。** {{ui:設定}}中的版面配置清單為下拉式選單，會顯示所選的版面配置。
- **語言。** 現在所選的語言也會套用到頁面本身顯示的文字，例如「新增」、「開啟」與「儲存」。英文以外的語言在母語人士審閱前均為機器草稿。

## 已知限制

- 長度顯示、重量與溫度單位，以及新的預設值已透過測試與頁面檢查。並非每個面板在每種單位下都已人工檢查。
- 人員清單尚未以實際的教師與學生班級進行人工測試。
- 英文以外的語言為機器草稿。
- Windows 安裝程式未經程式碼簽署（點選「其他資訊」，再選擇「仍要執行」）。macOS 磁碟映像檔未經公證（以右鍵點選，然後選擇「開啟」）。

## 較早版本：0.8 與 0.8.1

以下是TakeoffCraft 0.8（2026-11-01 發佈）與 0.8.1（2026-11-02）相較於 0.7 的變更。現在可以一次對整套圖紙計算符號圖例的數量，新的數量計算可以從過去工作的價格開始，並可依供應商的庫存檢查所需數量。0.8.1 為修正版本。

### 新增功能

**整套圖紙全部計數**

- **只需框選一次圖例。** 工具列中的{{ui:全部計數}}會讀取符號圖例：拖曳框選符號及其旁印製的名稱。每個符號會連同其圖片與名稱列出，名稱會成為該項目的名稱。取消勾選不需要的項目，然後選擇{{ui:在N張圖紙上計數}}。進度列會顯示正在搜尋的圖紙，按{{ui:取消}}即可停止執行，頁面仍可使用。
- **一次執行涵蓋所有圖紙。** 每個符號都會在所有已開啟的圖紙上計數。以其他比例繪製的圖紙，會以該比例進行搜尋，且符號可在任何直角方向找到。圖例本身所含的符號，不會計入其所在圖紙。
- **加入前先檢視。** 每個總數都有各圖紙的連結（例如「E-103：4」），可跳至該圖紙。點選搜尋結果中的方框即可排除，再點選一次即可恢復。比對程度（50%至100%）僅篩選已找到的結果，不會重新搜尋。
- **單一復原步驟。** {{ui:加入N個標記}}會為每個符號建立一個計數項目，並在每個搜尋結果上加上標記。若名稱已是現有的計數項目，則會重複使用。{{key:Ctrl+Z}}會一併復原所有項目與標記。已接受的結果也會計入{{ui:已學習}}。
- **任意角度的符號。** 計數前勾選{{ui:任意角度的符號}}，即可另外找到以非直角旋轉的符號。搜尋會以每 15 度旋轉一次符號，而非圓形的符號可能需要多達六倍的時間。
- **功能說明。** 在自有圖紙上進行一般符號比對，不使用訓練過的模型，資料也不會離開本機電腦。在一套虛構的 200 張圖紙上，於高速桌上型電腦的 Chrome 中從頭到尾共耗時 9.4 秒；實際的圖紙集會較慢。請參閱[整套圖紙全部計數](topic:count-everything)。

**依過去工作記憶價格**

- **TakeoffCraft 記住單價。** 儲存數量計算時，每個已使用且已定價的項目，都會依名稱與類型記住：材料單價、人工單價、損耗與單位。每個名稱會保留最近 12 次的工作紀錄。這些資料保存在此電腦的價格程式庫旁，絕不會存在數量計算檔案中，也不會傳送到任何地方。
- **從記憶的價格開始新的數量計算。** 工具列上的{{ui:價格}}會為每個項目顯示上次工作的單價、典型單價與範圍。{{ui:採用上次}}或{{ui:採用典型值}}可為一個項目定價，而{{ui:從記憶中為N個未定價項目定價}}會填入所有尚未定價的項目。每次使用皆為一個復原步驟。
- **較早的工作。** {{ui:從過去的數量計算學習…}}會記住已儲存數量計算（.json）中已定價的項目。
- **檢視、變更與清除。** {{ui:所有已記住的內容}}會列出每個名稱；垃圾桶按鈕可清除單一名稱，{{ui:清除所有價格}}則會清除全部。關閉{{ui:儲存數量計算時記住我的價格}}即可停止記憶。以每件計價的單價，絕不會套用到以每英呎計價的項目。請參閱[依過去工作記憶價格](topic:price-memory)。

**供應商庫存與交期**

- **與供應商清單比對。** 工具列上的{{ui:供貨}}會讀取供應商的庫存清單（{{ui:加入供應商檔案…}}），可為 CSV 或試算表，並依損耗比對數量計算所需的數量。最多保留五個檔案。不會傳送任何資料，也不會向供應商查詢，檔案須由使用者自行提供。
- **結果說明。** 缺貨項目會排在最前面，並以下列文字標示：「缺 120 EA」、「交期 21 天」、「已延後交貨」、「單位不同」、「無庫存數量」或「有庫存」。{{ui:可接受的最長等待時間（天）}}預設為 14。
- **訂購清單。** {{ui:訂購清單（CSV）}}會下載缺貨項目，內含缺少數量、供應商與交期。
- **價格匯入程式庫。** 若檔案含有價格，{{ui:價格匯入程式庫}}會依相同名稱與單位，設定每個程式庫項目的材料價格。再從程式庫重新定價，即可將其帶入數量計算。
- **在問題面板中。** 缺貨屬於警告，等待過久則為附註，皆列於「供應商庫存」之下。可附上理由接受某項結果，且該理由會儲存於數量計算中。請參閱[檢查供應商庫存與交期](topic:supplier-stock)。

**AI 助理**

- **三者皆提供工具。** 在{{ui:設定}}中允許助理後，助理即可讀取圖例（`legend_open`）、執行計數（`legend_count_start`，接著為`legend_count_status`與`legend_count_result`），並加入結果（`legend_count_add`，可先預覽）。助理可讀取已記住的價格（`prices_list`），並依其為項目定價（`prices_apply`，可先預覽），也可讀取供應商比對結果（`supply_check`）。加入供應商檔案仍須由使用者自行操作。請參閱[在TakeoffCraft中使用AI助理](topic:use-with-ai-assistants)。

**所有應用程式**

- **語言。** 共支援五十四種語言；其中十種為新增（立陶宛語、拉脫維亞語、波士尼亞語、馬拉地語、泰盧固語、阿爾巴尼亞語、南非荷蘭語、菲律賓語、史瓦希里語與烏茲別克語）。英文以外的語言在母語人士審閱前均為機器草稿。
- **輸入裝置。** {{ui:設定}} › {{ui:全域}} › {{ui:輸入裝置}}可設定觸控板、滑鼠側邊按鍵、觸控筆、3D 滑鼠、遊戲控制器或 MIDI 控制器的功能，可套用於所有應用程式，或僅套用於單一應用程式。請參閱[使用觸控板、3D 滑鼠或控制器](common:input-devices)。
- **工具列列數。** {{ui:設定}} › {{ui:一般}} › {{ui:工具列列數}}提供{{ui:自動換行}}（預設）、{{ui:2列}}與{{ui:1列}}；無法放入的群組會橫向捲動。請參閱[安排面板](common:arrange-panels)。
- **問題面板。** 共用的警告與附註面板，現在也會顯示上述供應商庫存檢查，與其他檢查並列。
- **外掛。** 外掛會依帳戶清單而定。請參閱[外掛與帳戶清單](common:addons-basics)。
- **連接 AI。** CadCraft Studio 是中心：只需連接一次助理，即可用於全部八個應用程式。Studio 本身沒有 AI。

### 0.8.1 中的修正

- **DWG 類別區段。** DWG 檔案的類別區段曾被讀取為錯誤的類型。此問題已在TakeoffCraft以及其他四個應用程式中修正。
- **Studio 可在執行時變更語言。** 先前 Studio 及其封裝版本僅提供英文。此功能尚未在各平台的桌面版本上完整測試；若語言未能變更，請告知我們。

### 本版尚未提供

- **未經程式碼簽署。** Windows 可能會顯示警告；在 Mac 上，首次開啟時需以右鍵點選並選擇{{ui:待處理}}。應用程式商店版本（Microsoft Store、Google Play、App Store）目前暫停，iPad 與 iPhone 版本未針對 0.8.1 重新建置。
- **Studio 更新。** Windows 安裝程式與 Linux 套件每天檢查一次，並會先詢問。可攜式 zip 僅提供通知，macOS 與 APK 不會自動更新。0.8 的 macOS .dmg 將隨正式版發佈。
- **連接 AI。** 本版不保證提供：Studio 內的一鍵連接、瀏覽器中 AI 的託管連接器、在 Studio 內使用自有 API 金鑰，以及已發佈的 MCP 套件。
- **全部計數。** 需要符號以與圖例相同的方式繪製；若符號上穿過牆體或長線，可能會被漏掉。鏡像符號無法找到；未標示比例且以其他尺寸繪製的圖紙，會以圖例的尺寸進行搜尋。在信賴其餘結果之前，請先檢查第一張圖紙的搜尋結果。
- **供應商庫存。** 庫存數字的新舊程度，取決於所加入的檔案。此檢查絕不會向供應商查詢。
- **語言。** 泰米爾語的應用程式列會溢出。

其他內容請參閱[尚未實作](topic:not-built-yet)。上一版請參閱[0.7 新功能](topic:whats-new-0-7)。

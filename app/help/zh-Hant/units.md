## 項目單位

| 項目類型 | 單位 | 名稱 |
|---|---|---|
| 線性 | LF | 線性英尺（預設） |
| 線性 | m | 公尺 |
| 面積 | SF | 平方英尺（預設） |
| 面積 | SY | 平方碼 |
| 面積 | SQ | 屋面方（100 平方英尺） |
| 面積 | ac | 英畝 |
| 面積 | m² | 平方公尺 |
| 面積 | ha | 公頃 |
| 計數 | EA | 每個 |

可隨時用項目編輯器中的{{ui:Unit}}變更，即使量測後也可以；數量會立即換算。

{{ui:Unit}}清單會顯示在{{ui:Settings}} › {{ui:General}} › {{ui:Units}}中已啟用的單位，且一律包含項目本身的單位。若該處標示星號的長度或面積單位是此項目的單位之一，新項目會以該單位開始；否則以 LF 或 SF 開始。見[單位、輸入值與單位清單](common:unit-lists)。

## 公式變數的單位

| 項目單位 | L、P、H | A |
|---|---|---|
| LF | 英尺 | 平方英尺（牆面積） |
| m | 公尺 | 平方公尺（牆面積） |
| SF | 英尺 | 平方英尺 |
| SY | 英尺 | 平方碼 |
| SQ | 英尺 | 屋面方 |
| ac | 英尺 | 英畝 |
| m² | 公尺 | 平方公尺 |
| ha | 公尺 | 公頃 |

對於 SY 項目，`A` 以平方碼計，而 `P` 與 `H` 仍以英尺計。由 SY 項目得出的體積為 `A * 9 * H / 27` 立方碼；板材使用 SF 較為簡單。

## 單位固定之處

部分讀數一律以英尺顯示：

- 繪製時狀態列的即時讀數（英尺英吋、SF）。
- **已選取的標記**（英尺英吋、LF 與 SF）。
- 檢查結果（英尺英吋，並附小數英尺與公尺）。
- 試算表「標記」工作表中的線段長度與周長（英尺英吋）。

項目總計、{{ui:Quantities}}表格、公式與估價工作表使用項目本身的單位。

## 比例與單位分開

圖面比例表示圖面的大小；項目單位則表示如何回報。比例為 `1:100` 的公制圖面可用 LF 計算，英制圖面也可用平方公尺計算。校正接受任何單位：`24'-6"`、`7.5 m`、`7500 mm`。

## 精確度

TakeoffCraft 會根據你點擊的點精確量測，包括真正的圓弧長度與面積，且不會對數量進行四捨五入。顯示時，長度會四捨五入至 1/16 英吋，小數則取兩位。金額僅在合計時才會四捨五入至分。

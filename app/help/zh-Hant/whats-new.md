這是 TakeoffCraft 0.9 相較於 0.8.1 的變更。這是針對本應用程式的小型版本：現在可以用公尺、公分或毫米讀取長度，面積與比例也能正確套用公制作業，圓弧則有十種畫法。即時協作工作階段也會顯示每位成員所在的位置。

## 新功能

### 以公尺、公分或毫米讀取長度

- **長度顯示方式。** {{ui:Settings}} › {{ui:TakeoffCraft}} 中有 {{ui:Show lengths as}}，選項包括 {{ui:Follow Global}}、{{ui:Feet-inches}}、m、cm 與 mm。{{ui:Follow Global}} 會使用你在 {{ui:Settings}} › {{ui:Global}} › {{ui:Units}} 中標示星號的公制長度單位；若未標示任何單位，則使用英呎英吋。此設定會改變圖紙上、狀態列與各面板中長度的讀取方式，包括高度、深度、厚度與樓層。在高度欄位中輸入的純數字，會以目前顯示的單位讀取。
- **僅影響顯示。** 數量、成本與匯出都依據精確長度計算。1/16、1/8 與 1/4 英吋的選項只會在英呎英吋模式下出現。請見[以公尺顯示長度](topic:show-lengths-in-meters)。
- **重量單位。** {{ui:Typed quantity (no drawing)}} 項目現在可以使用 lb、TON、kg 或 t，並可依單位定價。
- **溫度。** 每個項目在項目編輯器中都有可選的 {{ui:Temperature}} 欄位，可以攝氏 C 或華氏 F 輸入。{{ui:Settings}} › {{ui:TakeoffCraft}} 中的 {{ui:Show temperatures as}} 提供 {{ui:Follow Global}}、°C 或 °F 選項。

### 公制作業的面積與比例

- **圖紙上以 m2 顯示面積。** 使用公制項目量測的面積，現在會在圖紙標籤與標記面板中，以及表格裡都顯示 m2，不再顯示 SF。規則是：若項目以公制計價，或長度以 m、cm 或 mm 顯示，就使用 m2；否則使用 SF。
- **牆面積。** 具有高度的線性項目，會在項目清單中顯示其牆面積（長度乘以高度），並在依項目的數量表下方以附註列顯示。
- **比例預設 1:75 與 1:150。** 這兩個比例位於 {{ui:Scale}} 群組的 {{ui:Preset}} 清單中，該群組現在共有 32 種比例。請見[比例預設](topic:scale-presets)。

### 圓弧十種畫法

- 開啟 {{ui:Arc}}（工具列按鈕或 {{key:R}}）時，圖紙列中會出現 {{ui:Arc method}} 方塊，共有十種方法：三點、起點－圓心－終點、起點－圓心－角度、起點－圓心－長度、起點－終點－角度、起點－終點－方向、起點－終點－半徑、圓心－起點－終點、圓心－起點－角度，以及圓心－起點－長度。角度、長度、半徑與方向都可以點選或輸入。這適用於線性段、面積與開孔。0.9 之前儲存的檔案會以相同方式開啟。請見[以十種方法畫圓弧](topic:draw-arcs-ten-methods)。

### 共同作業

- **查看彼此的指標。** 在即時協作工作階段中，每位成員的指標會以其名稱與顏色顯示在圖紙上，其所選取的標記會以虛線框標示。位於其他圖紙的成員，會列出該圖紙的名稱。請見[與他人即時協作](topic:work-live)。
- **跟隨成員與人員清單。** 即時協作工作階段中的 {{ui:People}} 按鈕會列出每位成員、其使用的工具、所在圖紙，以及最後編輯的時間。{{ui:Follow}} 會讓你的檢視跟著對方移動，主持人也可以使用 {{ui:Ask everyone to follow me}}。請見[在即時協作中跟隨隊友](topic:follow-a-teammate)。

## 所有應用程式

- **工具提示與啟動提示。** 滑過時顯示的文字為 Bootstrap 工具提示，且啟動提示可以關閉。
- **可捲動的索引標籤列。** 面板的索引標籤列若放不下，會捲動顯示，而不會被截斷。
- **索引標籤標題。** 瀏覽器索引標籤會顯示 `<document> - TakeoffCraft | CadCraft`。
- **配置。** {{ui:Settings}} 中的配置清單改為下拉式清單，會顯示所選的配置。
- **語言。** 你選擇的語言現在也會套用到頁面自行顯示的文字，例如 New、Open 與 Save。英文以外的語言在母語人士審閱前，皆為機器翻譯草稿。

## 誠實的限制

- 長度顯示、重量與溫度單位，以及新的預設值，都已透過測試與頁面檢查。但並非每個面板在每種單位下都經過人工檢查。
- 人員清單尚未由真實的師生班級進行人工檢查。
- 英文以外的語言為機器翻譯草稿。
- Windows 安裝程式未經程式碼簽署（按「更多資訊」，再按「仍要執行」）。macOS 磁碟映像檔未經公證（按右鍵，再選擇 {{ui:Open}}）。

## 較早版本：0.8 與 0.8.1

以下是 TakeoffCraft 0.8（2026-11-01 發佈）與 0.8.1（2026-11-02）相較於 0.7 的變更。現在可以在整個圖紙集中一次計數符號圖例，新的數量計算可以從過去工作的價格開始，並且可以將數量與供應商的庫存進行核對。0.8.1 為修正版本。

### 新功能

**計數圖紙集中的全部項目**

- **一次框選圖例。** 工具列中的 {{ui:Count everything}} 會讀取符號圖例：拖曳方框框住符號與旁邊印製的名稱。每個符號會連同其圖片與名稱列出，該名稱會成為項目名稱。取消勾選不需要的項目，然後選擇 {{ui:Count on N sheets}}。進度列會顯示正在搜尋的圖紙，{{ui:Cancel}} 會停止執行，且頁面在執行期間仍可使用。
- **一次執行涵蓋所有圖紙。** 每個符號都會在每張已開啟的圖紙上計數。以其他比例繪製的圖紙會以該比例搜尋，符號則可以旋轉任何直角方向。圖例本身的符號不會在其所在圖紙上計數。
- **加入前先檢視。** 每個總數都有一個連結到各圖紙的項目（例如「E-103: 4」），點選即可前往該圖紙。點選搜尋結果中的方框可將其排除，再點選一次即可恢復。匹配程度（50% 至 100%）只會過濾已找到的結果，不會重新搜尋。
- **單一復原步驟。** {{ui:Add N marks}} 會為每個符號建立一個計數項目，並在每個找到的位置加上標記。若名稱已是你既有的計數項目，則會重複使用。{{key:Ctrl+Z}} 會將所有項目與標記一併復原。你接受的結果也會加入 {{ui:Learned}}。
- **任意角度的符號。** 計數前勾選 {{ui:Symbols at any angle}}，還能找到以非直角旋轉的符號。搜尋會每 15 度旋轉一次符號，且非圓形的符號可能需要六倍的時間。
- **功能說明。** 這是在你自己的圖紙上進行的一般符號比對，沒有使用訓練過的模型，資料也不會離開你的電腦。在一個虛構的 200 張圖紙圖組上，於速度快的桌上型電腦上以 Chrome 執行，總計耗時 9.4 秒；實際的圖說集會較慢。請見[在圖紙集中全部計數](topic:count-everything)。

**來自你自己工作的價格記憶**

- **TakeoffCraft 會記住你的單價。** 儲存數量計算時，每個已定價且有使用的項目會依名稱與類型被記住：材料單價、人工單價、損耗與單位。每個名稱保留最近 12 次工作。這些資料保存在本機電腦上、價格程式庫旁，不會存入數量計算檔案，也不會傳送到任何地方。
- **以記憶價格開始新的數量計算。** 工具列上的 {{ui:Prices}} 會為每個項目顯示上次工作的單價、典型單價與範圍。{{ui:Use last}} 或 {{ui:Use typical}} 可為單一項目定價，{{ui:Price N unpriced items from memory}} 則會為所有尚未定價的項目填入價格。每次使用都是一個復原步驟。
- **較早的工作。** {{ui:Learn from a past takeoff…}} 會記住已儲存數量計算檔（.json）中已定價的項目。
- **檢視、修改與忘記。** {{ui:Everything remembered}} 會列出所有名稱；垃圾桶按鈕可忘記單一名稱，{{ui:Clear all prices}} 則會忘記全部。若要停止記憶，請關閉 {{ui:Remember my prices when I save a takeoff}}。每個單價的價格絕不會套用到以每英呎計價的項目上。請見[過去工作的價格記憶](topic:price-memory)。

**供應商庫存與交期**

- **與供應商清單核對。** 工具列上的 {{ui:Supply}} 會讀取供應商的庫存清單（{{ui:Add a supplier file…}}），可為 CSV 檔或試算表，並依數量計算所需的項目（含損耗）進行核對。最多保留五個檔案。不會傳送任何資料，也不會向供應商發出查詢：由你提供檔案。
- **結果說明。** 短缺項目會優先顯示，例如「短缺120 EA」、「交期21天」、「缺貨待補」、「單位不同」、「無庫存數量」或「有庫存」。{{ui:Longest wait wanted (days)}} 預設為 14。
- **訂購清單。** {{ui:Order list (CSV)}} 會下載短缺項目，內容包括短缺數量、供應商與交期。
- **價格匯入程式庫。** 若檔案含有價格，{{ui:Prices into the Library}} 會為名稱與單位相同的每個程式庫項目設定材料價格。之後可從程式庫重新定價，將其帶入數量計算。
- **在問題面板中。** 短缺為警告，長時間等待則為附註，列於「供應商庫存」之下。你可以附上理由接受某項結果，該理由會儲存在數量計算中。請見[核對供應商庫存與交期](topic:supplier-stock)。

**AI 助理**

- **三者皆有工具。** 在 {{ui:Settings}} 中允許使用助理後，助理可以讀取圖例（`legend_open`）、執行計數（`legend_count_start`，接著是 `legend_count_status` 與 `legend_count_result`）並加入結果（`legend_count_add`，可先預覽）。它可以讀取已記住的價格（`prices_list`），依其為項目定價（`prices_apply`，可先預覽），並讀取供應商核對結果（`supply_check`）。加入供應商檔案仍由你自行操作。請見[在 AI 助理中使用 TakeoffCraft](topic:use-with-ai-assistants)。

**所有應用程式**

- **語言。** 共有五十四種語言；其中十種為新增（立陶宛文、拉脫維亞文、波士尼亞文、馬拉地文、泰盧固文、阿爾巴尼亞文、南非荷蘭文、菲律賓文、斯瓦希里文與烏茲別克文）。英文以外的語言在母語人士審閱前，皆為機器翻譯草稿。
- **輸入裝置。** {{ui:Settings}} › {{ui:Global}} › {{ui:Input devices}} 可設定觸控板、滑鼠側邊按鈕、觸控筆、3D 滑鼠、遊戲控制器或 MIDI 控制器的功能，適用於所有應用程式或單一應用程式。請見[使用觸控板、3D 滑鼠或控制器](common:input-devices)。
- **工具列列數。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} 提供 {{ui:Wrap}}（啟動時的預設）、{{ui:2 rows}} 與 {{ui:1 row}}；放不下的群組會橫向捲動。請見[安排面板](common:arrange-panels)。
- **問題面板。** 共用的警告與附註面板，現在也包含上述供應商庫存核對結果，與其他檢查並列顯示。
- **外掛。** 外掛會依你的帳戶清單提供。請見[外掛與你的帳戶清單](common:addons-basics)。
- **連接 AI 助理。** CadCraft Studio 是中心：只要連接一次助理，即可供全部八個應用程式使用。Studio 本身沒有 AI。

### 0.8.1 已修正

- **DWG 類別區段。** DWG 檔案的類別區段曾被讀取為錯誤的類型。此問題已在 TakeoffCraft 及其他四個應用程式中修正。
- **Studio 可在執行時變更語言。** 先前 Studio 及其封裝版本僅有英文。此功能尚未在每個平台的桌面版本上測試；若語言未變更，請告訴我們。

### 本版尚未實作

- **未經程式碼簽署。** Windows 可能會出現警告；在 Mac 上，第一次請按右鍵並選擇 {{ui:Open}}。商店版本（Microsoft Store、Google Play、App Store）暫緩發佈，且 iPad 與 iPhone 版本未針對 0.8.1 重新建置。
- **Studio 更新。** Windows 安裝程式與 Linux 套件每天檢查一次更新，並會先詢問。可攜式 zip 僅會通知你，macOS 與 APK 不會自動更新。0.8 的 macOS .dmg 會隨版本發佈。
- **連接 AI 助理。** 本版不提供 Studio 內一鍵連接、瀏覽器中 AI 的託管連接器、在 Studio 內使用你自己的 API 金鑰，以及已發佈的 MCP 套件。
- **全部計數。** 符號的繪製方式必須與圖例相同，若符號上穿過牆或長線，可能會被漏掉。鏡像的符號不會被找到；未標示比例且以其他尺寸繪製的圖紙，會以圖例的尺寸搜尋。在信任其餘結果之前，請先檢查第一張圖紙的搜尋結果。
- **供應商庫存。** 庫存數字的新舊程度取決於你加入的檔案。核對過程絕不會向供應商查詢。
- **語言。** 泰米爾文的應用程式列會溢出。

其他內容請見[尚未實作](topic:not-built-yet)。上一版請見[0.7 新功能](topic:whats-new-0-7)。

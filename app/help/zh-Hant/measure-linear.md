線性項目量測長度。每段線段都是一連串的點：直線段，以及開啟圓弧模式後的弧線。一個項目可以在任意數量的圖紙上包含任意數量的線段。

開始前：圖紙需要比例（[設定比例](topic:set-the-scale)），並需要一個線性項目（[建立數量計算項目](topic:create-items)）。

在向量 PDF 上，點擊會吸附至圖紙本身的線條：端點、中點與交點（[鎖點至圖紙線條](topic:snap-to-the-drawing)；{{key:F3}}可將其關閉）。

## 繪製線段

1. 點擊{{ui:Items}}下的線性項目。
2. 在工具列中選擇{{ui:Linear}}，或按{{key:L}}。
3. 點擊線段的起點。
4. 沿線段點擊每個角點。
   狀態列會以英尺與英寸顯示「長度」（目前線段至指標處）與「分段」（正在繪製的那一段）。
5. 結束線段：連按兩下最後一點、按{{key:Enter}}，或按右鍵。
   線段會以項目的顏色繪製，並成為選取的標記。{{ui:Items}}清單與{{ui:Quantities}}表格中該項目的長度會增加。

工具會保持在{{ui:Linear}}，因此可立即開始下一段線段。按{{key:Esc}}即可返回{{ui:Select}}。

繪製時：

- {{key:Backspace}}（或{{key:Delete}}）會移除最後一點。
- {{key:Esc}}會捨棄未完成的線段。
- 拖曳會平移圖紙，滾輪會縮放，且不會新增點。

:::mac
在 Mac 觸控板上，右鍵為雙指點擊（需在「系統設定」的「觸控板」下開啟次要點按）。TakeoffCraft 只讀取次要按鈕，因此 Control 點擊可能會被視為一般點擊並新增一個點。連按兩下或{{key:Enter}}一律會結束線段。
:::

:::touch
在觸控螢幕上，輕觸可放置點，以一根手指拖曳可平移，以兩根手指捏合可縮放。可長按、連續輕觸兩下，或按圖紙下方列中的{{ui:Finish}}結束（{{ui:Back}}會將最後一點收回）。參見[疑難排解](topic:troubleshooting#touch-screens)。
:::

## 以 45 度為步進的直線

放置點時按住{{key:Shift}}。從上一點出發的線段會吸附至最接近的 0°、45°、90° 或 135° 方向，並保留沿該方向拖曳的長度。狀態列會提示：「Shift吸附至45°」。

在圓弧模式中，此功能適用於圓弧的終點：圓弧的弦線會以 45 度為步進，從其起點延伸。點擊於曲線上的點則絕不吸附。

## 圓弧與曲牆

1. 繪製線段時，於曲線起點放置點。
2. 開啟圓弧模式：在工具列中選擇{{ui:Arc}}或按{{key:R}}。按鈕會保持按下狀態。
3. 點擊曲線上的任一點，位於曲線的中段附近。
   狀態列會加上「（圓弧：點擊終點處）」，預覽會通過該點而彎曲。
4. 點擊曲線的終點。
   圓弧隨即加入。其長度為精確的弧長，而非一連串短弦線的總和。
5. 點擊下一段曲線上的另一點及其終點即可繼續繪製圓弧，或再按{{key:R}}返回直線段。

{{key:Backspace}}或{{key:Esc}}會先捨棄曲線上待定的點；再按一次即可照常移除點。

## 輸入長度與座標

放置第一點之後，可以輸入下一點的位置，而不必點擊。輸入數字、`@` 或 `#`：狀態列中會開啟{{ui:Type}}方塊，並顯示所輸入的內容。按{{key:Enter}}即可放置點；方塊會保持開啟，供下一點使用。

| 輸入 | 下一點位置 |
|---|---|
| `12'6"` | 距離上一點 12'-6"，朝向指標（先指向方向，再輸入長度） |
| `12'6"<45` | 以 45° 方向，距離 12'-6"，角度自螢幕右方逆時針計算（`<90` 為向上，`<-90` 為向下） |
| `@6',-4'` | 距離上一點向右 6'、向下 4' |
| `6',4'`（或 `#6',4'`） | 距離本段線段的第一點向右 6'、向上 4' |

長度的輸入方式與 TakeoffCraft 其他地方相同（[輸入格式](topic:entry-formats)）：`12'-6 1/2"`、`12.5`（英尺）、`30"`、`3.2 m`。「右」與「上」以圖紙上所見的方向為準，即使 PDF 頁面已旋轉亦然。

在空白方塊中按{{key:Enter}}會結束線段，與在圖紙上按{{key:Enter}}相同；{{key:Esc}}會關閉方塊並保持線段繼續。輸入的點與點擊的點適用相同規則：扣除、圓弧與封閉面積皆可使用。相同的方塊也可用於{{ui:Area}}與{{ui:Cut-out}}；在圓的圓心之後，它會接受半徑。

## 扣除線段的一部分

經過門或店面的牆面線段，可以直接畫過去，而仍只計算牆面：跨越開口的線段為**扣除段**。它們會以細虛線繪製，且不計入。

繪製時：

1. 於開口起點放置點。
2. 在工具列中選擇{{ui:Deduct}}或按{{key:E}}。按鈕會保持按下狀態，狀態列會說明接下來的分段為扣除段。
3. 點擊開口終點。該分段會以虛線繪製，狀態列的「長度」不包含此段。
4. 再按{{key:E}}，然後沿牆面繼續。

繪製完成後：選取該線段。在**選取的標記**下，每個分段都有一個{{ui:Deduct}}方塊：勾選即可扣除該分段，取消勾選則重新計入。每次變更皆為一次復原。

線段至少會保留一個計入的分段。此時面板會顯示**扣除**（被扣除的長度）與**已繪製**（整段線段）；**長度**、項目數量、牆面面積與成本皆採用不含扣除的長度。3D 檢查檢視會在牆面留下缺口，已標記 PDF 會以虛線繪製扣除段，匯出的**標記**工作表會列出這些扣除段。

移動角點會保留扣除段。新增或移除點（重新繪製線段）後，將不含扣除段。

## 檢視線段詳細資料

選擇{{ui:Select}}（{{key:V}}）並點擊線段。右側的**選取的標記**會顯示：

- 所屬的項目（在清單中選擇另一個線性項目，即可將線段移至該項目）、
- 圖紙、
- 以英尺與英寸及 LF 表示的**長度**、
- **分段**數量，以及項目設有高度時的**牆面面積**、
- 每個分段的長度（圓弧後標示「（圓弧）」），以及其{{ui:Deduct}}方塊。

在圖紙上，所選線段的每個分段都會標示其長度。

## 修正線段

- **移動點**：選取線段，然後拖曳其方形角控點。按住{{key:Shift}}可使移動的分段以 45 度為步進吸附。圓弧會保留其凸度。
- **彎曲圓弧**：被選取的線段會在每段圓弧中央顯示圓形控點。拖曳該控點：圓弧會通過放開滑鼠的位置，因此可以彎得更多、更少，或反向彎曲。若將其拖至兩端之間的直線上，它會變為直線段。{{key:Mod+Z}}可復原（「彎曲圓弧」）。
- **刪除線段**：選取後按{{key:Delete}}、在工具列的{{ui:More}}功能表中選擇{{ui:Delete}}，或在面板中選擇{{ui:Delete mark}}。
- **復原**：{{key:Mod+Z}}；取消復原為{{key:Mod+Y}}。

目前尚無法在線段中間插入點。可刪除該線段後重新繪製。

## 牆面面積

為線性項目設定{{ui:Height}}（例如`9'-0"`）。之後會報告**牆面面積 (A)** = 長度 × 高度，以 SF 表示（公制項目則為 m²），且牆面面積會列入試算表匯出的附註欄。可在組合中用於板材、油漆或隔熱材料：參見[組合與公式](topic:assemblies)。

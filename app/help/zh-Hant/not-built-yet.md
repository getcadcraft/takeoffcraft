TakeoffCraft 仍在開發中。本清單列出目前版本尚未提供的功能，以及如何仍然完成工作。

## 量測

| 尚未實作 | 現在可以改用 |
|---|---|
| 在一段或一個輪廓的中間插入一點 | 刪除該標記，重新繪製。 |
| 框選（視窗選取） | 按住{{key:Shift}}並逐一點選各標記，或按{{key:Mod+A}}選取圖紙上的所有標記。請參閱[複製、貼上與建立副本標記](topic:copy-paste)。 |
| 旋轉、鏡像或重新縮放貼上的副本 | 在圖紙上以相同比例與方向貼上；其餘以手繪補上。 |
| 從掃描圖紙或圖形比例尺讀取比例 | 選取預設比例，或依比例尺長度進行校正。 |
| 同一張圖紙上有多種比例（詳圖區、放大平面圖） | 以圖紙比例量測該部分；若圖紙集中有該詳圖的放大圖紙，則在其獨立的放大圖紙上計算數量。 |

## 項目與定價

| 尚未實作 | 現在可以改用 |
|---|---|
| 組合公式使用某項目的其他類型標記（例如房間項目在所屬樓層的公式中使用門） | 公式使用主要類型的合計；其他類型請各自列在獨立的列中計價。 |
| 組合公式逐段計算 | 公式使用項目的合計；每段的額外數量請使用 `N`。 |
| 公式使用其他項目的數量 | 在該項目中重新量測，或在試算表匯出中計算。 |
| 組合元件的班組，或非 8 小時的工作日 | 將班組指派給項目；以班組小時 ÷ 工作日長度計算班組日。 |
| 附註、修訂雲形與螢光標示以外的標記（箭頭、標註、圖章），或附註的回覆 | 將內容寫入附註文字中；處理完成時更改其狀態。 |
| 由團隊共用，或保存於帳戶中的價格程式庫 | 程式庫保存在此瀏覽器中：匯出為 CSV，再於另一台電腦匯入。 |
| 經工地估價人員審閱的工種套件 | 每個套件都只是起點：定價前，請依本案與所用產品檢查其假設。請參閱[工種套件](topic:trade-packs)。 |
| 工種套件中的價格 | 套件僅提供組合：自行設定單價，或將價目表以 CSV 匯入。 |
| 重新命名數量計算 | 名稱取自第一份 PDF；請重新命名已下載的檔案。 |
| 手動為圖紙命名 | 圖紙依 PDF 的頁面標籤命名；請依檔名與頁碼搜尋。 |

## 圖形（DWG 與 DXF）

| 尚未實作 | 現在可以改用 |
|---|---|
| 圖形配置上的列印樣式表、筆分配與 CTB 檔 | 圖形以黑色繪製，或為紙張而將其顏色加深；線寬取自圖形本身。 |
| 開啟二進位 DXF，或早於 AutoCAD 2000 的 DWG | 另存新檔為 ASCII DXF 或較新的 DWG。 |
| 依所在資料夾尋找外部參考（xref） | 與主圖一併開啟該外部參考圖形檔：會在已開啟的檔案中依檔名找到。 |
| 量測 3D 聚合線、網格、實體與面域 | 依圖層與類型計數，或以「線性」與「面積」工具量測平面視圖。 |
| 已標記 PDF 中，圖形內以非拉丁文字寫成的文字 | Helvetica 沒有字形的字元，會在{{ui:Marked PDF}}中印成「?」；螢幕上的圖形不受影響。 |
| 從圖紙列將圖形交給其他應用程式 | 在該應用程式中開啟同一檔案。 |
| 如同 PDF 的{{ui:PDF with the takeoff inside}}，將數量計算內含於圖形中 | 使用{{ui:Save takeoff}}：`.takeoff.json` 會在同一圖形上重新開啟，並依內容比對找到。 |
| 圖形中放置的 PDF 底圖、影像與 OLE 物件之繪製或計數 | 影像只以外框顯示。請將底圖 PDF 本身開啟為圖紙。 |

## 自動計數

| 尚未實作 | 現在可以改用 |
|---|---|
| 在符號尺寸與圖紙比例不符的圖紙上尋找符號 | 為圖紙設定比例，或在該處框出範圍後搜尋。 |
| 尋找鏡像符號 | 以手工計數；或在鏡像符號周圍框出範圍後重新搜尋。 |

## 檔案與共用

| 尚未實作 | 現在可以改用 |
|---|---|
| 同時顯示標記並內含數量計算的單一 PDF | {{ui:Marked PDF}}供他人查看標記；{{ui:PDF with the takeoff inside}}供在 TakeoffCraft 中重新開啟。 |
| 依圖紙或標記的數量 CSV | 使用{{ui:XLSX}}：其中的「依圖紙」與「標記」工作表有這些資料。 |
| 雲端儲存 | 尚未提供。請將專案檔儲存到電腦並備份。 |
| 獨立的 TakeoffCraft 桌面應用程式 | 自 0.5 起，桌面應用程式為 CadCraft Studio，八個應用程式共用一次安裝。TakeoffCraft 也可在瀏覽器中執行。 |

## 畫面與輸入

| 尚未實作 | 現在可以改用 |
|---|---|
| 右鍵（或長按）功能表 | 使用工具列、面板與按鍵。長按會結束一段或一個輪廓。 |
| 旋轉檢視 | 在 PDF 中已旋轉的頁面會正向顯示。 |

## 3D 檢視

| 尚未實作 | 現在可以改用 |
|---|---|
| 在 3D 中繪製或編輯標記 | 回到圖紙（{{key:3}}）進行繪製；在 3D 中可選取與刪除。 |
| 對齊在頁面上不同位置繪製的堆疊樓層 | 堆疊的樓層請以相同位置繪製；其他樓層請逐張圖紙檢查。 |
| 計數與被計數物件尺寸相同的柱 | 圖紙上的每根柱大小相同；它標示計數位置，而不表示被計數的內容。 |

## 投標

| 尚未實作 | 現在可以改用 |
|---|---|
| 已寄出套件的補遺、得標通知函，以及每位投標人簽認的工作範圍表 | 寄出新的套件，並自行撰寫得標通知。[寄送投標套件](topic:bid-invitations)說明已實作的功能。 |
| 從任何帳戶寄出投標邀請：測試期間，對外投標人的郵件已關閉，僅限 CadCraft 團隊已啟用的帳戶除外 | 下載{{ui:Scope CSV}}，自行以電子郵件寄出，並輸入投標金額。 |
| 從 Studio 視窗寄出投標套件 | 於瀏覽器中的 TakeoffCraft 寄出。 |
| 以選定的投標價重新定價替代項的投標範圍 | 替代項與投標範圍小計使用自訂單價；請手動調整替代項。 |
| 分包商保險或授權到期前的自動提醒 | 日期已過或距今 30 天內時，會在「分包商」頁面標示；邀請時請加以檢查。 |

## 面板

| 尚未實作 | 現在可以改用 |
|---|---|
| 移動{{ui:Quantities}}表格 | 只有{{ui:Sheets}}與{{ui:Items}}面板可以移動。請參閱[安排面板](common:arrange-panels)。 |

## 試算表

XLSX 活頁簿已在 LibreOffice Calc 中檢查，其重新計算的每筆合計都與 TakeoffCraft 相符到分。尚未在 Excel 中開啟。若試算表程式顯示異常，CSV 匯出以一般數值保存相同的估價。

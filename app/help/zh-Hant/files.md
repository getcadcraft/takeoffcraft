## 開啟的檔案

| 檔案 | 方式 | 附註 |
|---|---|---|
| PDF（`.pdf`） | {{ui:開啟圖紙}}、{{key:Mod+O}}，或拖放到頁面上 | 可一次開啟多個。每一頁成為一張圖紙。 |
| 數量計算專案（`.takeoff.json`） | {{ui:開啟數量計算}}，或拖放到頁面上 | 你的項目、比例與標記。可以與其 PDF 一起拖放。 |

拖放到頁面上的其他檔案會被略過，狀態列會列出它們的名稱。

- **受密碼保護的 PDF** 無法開啟：「(name) 受密碼保護。請開啟未加密的副本。」
- **同一份 PDF 開啟兩次**只會開啟一次：「(name) 已經開啟。」TakeoffCraft 以內容而非名稱來辨識檔案。
- **掃描的 PDF** 與其他 PDF 一樣可開啟與量測；TakeoffCraft 不需要 PDF 中的文字。
- **大型圖紙集：**每份 PDF 在開啟時都會完整讀取（為了取得指紋），所以非常大的檔案需要一點時間。縮圖會隨你捲動逐張繪製。

## 儲存的檔案

每次儲存都是下載。不會有任何內容寫回你的 PDF。

| 你選擇 | 你得到 | 內容 |
|---|---|---|
| {{ui:儲存數量計算}} | `(name).takeoff.json` | 項目、組合件、單價、圖紙比例與每個標記，以內容對應到各份 PDF。不含 PDF 頁面。 |
| {{ui:XLSX}} | `(name).xlsx` | 四張工作表：估價（含即時公式）、依圖紙、標記、比例。 |
| {{ui:CSV}} | `(name).csv` | 以純數值呈現的估價，每個項目與每個組成各一列。 |
| {{ui:已標記 PDF}} | `(PDF name) (takeoff).pdf` | 每份含標記的已開啟 PDF 的副本，頁面上畫有數量計算內容並附圖例。每份 PDF 一個檔案。 |

名稱取自你在這份數量計算中開啟的第一份 PDF。目前尚無重新命名的方塊：如果想用別的名稱，請為下載的檔案重新命名。

見[匯出估價與已標記的 PDF](topic:export-estimate)與[匯出欄位](topic:export-columns)。

## 下載的檔案存到哪裡

瀏覽器會把檔案存在它存放所有下載內容的地方，通常是「下載」資料夾。請在{{pick:mac=Finder|windows=檔案總管|linux=檔案管理員}}中尋找。若你的瀏覽器設定為每次詢問儲存位置，則會詢問。

:::chromium
有多份已標記 PDF 時，{{ui:已標記 PDF}}會一次下載多個檔案。Chrome 與 Edge 可能會詢問一次此網站是否可以下載多個檔案。請選擇允許。
:::

:::safari
除非你在 Safari 設定的「一般」中變更了下載位置，否則 Safari 會儲存到「下載項目」。
:::

## 為什麼專案檔與 PDF 是分開的

`.takeoff.json` 檔案只存放你的數量計算。它以內容（每個檔案的指紋）重新找到它的 PDF，所以：

- 重新命名或移動 PDF 都沒有影響。
- 被其他程式變更或重新儲存的 PDF，即使名稱相同，也視為不同的檔案。
- 未開啟的 PDF 上的標記仍然會計入合計。

見[儲存並重新開啟數量計算](topic:save-and-reopen)。

## 線上與離線

你的 PDF 與數量計算絕不會離開你的電腦，不論線上或離線。網路連線只在載入 TakeoffCraft 本身時才有關係。

要在沒有網路連線時工作，請在線上時先儲存應用程式：

1. 選擇頂端應用程式列的{{ui:儲存供離線使用}}。
   儲存期間，按鈕會持續計數：「儲存中12/40」。
2. 等待顯示{{ui:可離線使用}}。

儲存 TakeoffCraft 會把應用程式、這份說明、PDF 讀取器、{{ui:已標記 PDF}}使用的 PDF 寫入器，以及自動計數背景程式保存在你的瀏覽器中，約 6 MB。一旦顯示{{ui:可離線使用}}，一切都能離線運作：開啟 PDF、量測、{{ui:自動計數}}、{{ui:儲存數量計算}}、{{ui:XLSX}}、{{ui:CSV}}與{{ui:已標記 PDF}}。

| 按鈕顯示 | 意義 |
|---|---|
| {{ui:儲存供離線使用}} | 尚未儲存在這個瀏覽器中。選擇它即可儲存。 |
| 儲存中 n/m | 正在儲存。 |
| {{ui:可離線使用}} | 已儲存。選擇它可使用{{ui:重新儲存（取得最新版本）}}或{{ui:移除離線副本}}。 |
| {{ui:無法儲存}} | 有些檔案沒有下載成功。請檢查網路連線並再選擇一次。 |
| {{ui:無法離線使用}} | 這個瀏覽器視窗無法保留離線副本（私密視窗與部分受管理的電腦會阻擋）。 |

更多說明，包括已儲存的副本在各瀏覽器中能保存多久：[離線工作](common:offline)。

:::offline
目前離線。若應用程式列顯示{{ui:可離線使用}}，一切都能運作。若沒有，TakeoffCraft 在這個索引標籤中尚未載入的部分（供{{ui:已標記 PDF}}使用的 PDF 寫入器、自動計數背景程式）現在無法載入，{{ui:已標記 PDF}}會停止並顯示「無法寫入已標記的 PDF」。不論哪種情況，你的數量計算都是安全的：{{ui:儲存數量計算}}、{{ui:XLSX}}與{{ui:CSV}}不需要網路連線。在重新連上網路之前，請不要重新載入索引標籤。
:::

:::online
目前在線上。在到工地現場或搭飛機之前，請選擇{{ui:儲存供離線使用}}，並等到顯示{{ui:可離線使用}}。
:::

## 試算表

XLSX 保留即時公式，所以試算表程式在開啟檔案時會重新計算估價，並在你於其中變更單價或損耗時保持正確。這份活頁簿已在 LibreOffice Calc 中檢查過，每個合計重新計算後都精確到同一分。尚未在 Excel 中開啟過。

CSV 是帶有位元組順序標記的純數值，所以試算表程式能正確讀取 m² 之類的字元。

## 桌面與雲端

:::desktop
從 0.5 起，桌面應用程式是 CadCraft Studio：TakeoffCraft 與其他七個應用程式裝在同一份安裝中。沒有獨立的 TakeoffCraft 安裝程式。
:::

目前尚無雲端儲存。請把你的 `.takeoff.json` 檔案與該專案的 PDF 放在一起，並像其他檔案一樣備份。見[檔案的去向](common:your-files)。

不必等待下一套圖紙。建築師寄出建築模型時，可直接在此開啟，並從模型取得數量。模型在本機讀取，不會傳送到任何地方。

## 步驟

1. 在工具列上選擇{{ui:模型}}，然後選取模型的`.ifc`檔案；或如同其他檔案一樣，以{{ui:開啟圖紙}}開啟。
2. {{ui:模型數量計算}}會開啟，每個類別與類型各一列：牆依牆類型、樓板依樓板類型、門依門類型，依此類推。每列會顯示其數量，以及該類別的量測單位。
3. 將{{ui:分組依據}}設為{{ui:類別}}可快速取得總計，或設為{{ui:類別、類型與樓層}}，以依樓層拆分每種類型。
4. 取消勾選不需要的列。{{ui:搜尋}}可縮小清單範圍。取消勾選某列時，也會在 3D 圖中隱藏其零件。
5. 為模型設定一個在整個工作期間都會保留的{{ui:模型名稱}}，例如專案名稱。
6. 選擇{{ui:加入數量計算}}。每個數量會成為項目清單中的輸入數量。與其他項目一樣，為其命名、定價並附加組合即可。

## 以 3D 檢視模型

{{ui:以3D顯示模型}}會在表格上方繪製模型，每列各有一種顏色（列名旁的色塊）。拖曳即可旋轉，按住{{key:Shift}}再拖曳即可移動，使用滾輪縮放，並選擇{{ui:符合}}或{{ui:重設}}以回到原本的檢視。

- **在圖中點選零件**，表格中對應的列會被選取，該列的所有零件會亮起，其餘則淡化。再次點選同一零件時，若其位於多列中（例如牆的各圖層），則會選取下一列。
- **在表格中點選一列**，即可亮起其零件。再次點選該列，或點選圖中的空白處，即可清除。
- 不繪製房間，因為房間的體積會遮住建築物。
- 非常大型的模型會僅為部分零件保留方塊外框，以便符合記憶體限制；面板會顯示數量。數字不會改變。

若此電腦無法繪製 3D，表格仍會照常運作。

## 依材質、圖層或尺寸分組

{{ui:分組依據}}另有三種選項：

- {{ui:類別與材質}}：由多層構成的牆、樓板或屋頂，會為每層材質各給一列，因此石膏板、龍骨與隔熱材可分開定價。使用單一材質的建築零件會歸入該材質的列；沒有材質的零件則保留在名為「未指定材質」的列中。
- {{ui:類別與圖層}}：與上相同，但列中會顯示該圖層的厚度（例如「隔熱材，100 mm」）。
- {{ui:類別、類型與門窗尺寸}}：門與窗會依寬度與高度拆分（例如 3'-0" × 6'-8" 或 914 × 2,032 mm）。

對於圖層而言，面積為牆面本身的面積（或樓板、屋頂的平面或表面積），體積則為該面積乘以圖層厚度。列的附註會說明有多少數字來自圖層。同一面牆的各圖層加總，等於模型為該牆所載明的體積。

## 將列或開孔儲存為 CSV

{{ui:將列儲存為CSV}}會將已勾選的列儲存為試算表可用的檔案，並在每個標題中附上單位。{{ui:將門窗開孔明細表儲存為CSV}}（僅在模型含有門或窗時可用）會依類型、樓層與尺寸，連同數量儲存每一扇門與窗。

## 量測項目

| 類別 | 數量 |
|---|---|
| 牆 | 數量、長度、牆面積（單一面，扣除開孔）、體積 |
| 樓板、板、天花板與其他覆蓋層 | 數量、平面面積、體積 |
| 屋頂 | 數量、平面面積、屋頂表面、體積 |
| 基礎 | 數量、平面面積、體積 |
| 柱、樑與構件 | 數量、沿構件長度、體積 |
| 欄杆、管線、風管與電纜路線 | 數量、長度 |
| 樓梯 | 數量、體積 |
| 房間 | 數量、地板面積、體積 |
| 門、窗與其他所有項目 | 數量 |

若模型作者已在檔案中載明某項數量，則採用該數值。否則，數值會依元素的形狀量測。每個數量都會保留一則附註，說明採用的來源，以及有多少元素提供了數值。

:::note
依形狀量測的牆長度是從頭到尾計算，因此在轉角處相交的兩面牆都會包含該轉角。體積需要封閉的形狀：形狀未封閉的元素會被計數，但不會產生體積。彎曲或具轉角的牆元素，會以其所有直立面的一半計量，附註中會說明此事。
:::

## 收到較新的模型時

開啟較新的檔案，並輸入相同的{{ui:模型名稱}}。加入任何項目之前，面板會顯示有多少數量為新增、有多少數量已變更及其前後數值，以及較早版本中哪些數量已不在模型中。選擇{{ui:加入數量計算}}：已變更的數量會採用新的數字，而名稱、單價、損耗與組合則維持不變。已從模型中移除的數量會保留其舊數字；若設計已刪除這些項目，請自行移除。

類型與樓層名稱是辨識數量的依據。若建築師重新命名某牆類型，該數量會以新數量的形式出現，而舊數量則會列為已移除。

## 可讀取的檔案

IFC 檔案（IFC2x3、IFC4 與 IFC4.3）。含有道路、鐵路或橋梁的 IFC 檔案，仍會如以往一樣直接匯入其基礎設施數量。

本版 TakeoffCraft 不讀取`.rvt`檔案。若建築師使用 Revit，請要求匯出模型的 IFC 檔（檔案、匯出、IFC），並開啟該檔案。

一個模型一次最多可匯入 500 個數量。若超過此數量，請取消勾選部分列，或依類別分組。

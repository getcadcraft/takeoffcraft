在向量 PDF 中，牆與邊緣是真實的線條。{{ui:Path}}（{{key:P}}）會依其繪製的樣子取得這些線條：點選線條一下，即可量測與之相連的所有線條，從頭到尾，因此無需逐一點擊牆的角點來描繪。圖紙需要比例。掃描頁面沒有可選取的線條；該處請改用[線性](topic:measure-linear)或[面積](topic:measure-areas)。

## 選取路徑或輪廓

1. 選擇{{ui:Path}}。指標下的線條會以輪廓標示，其他可能的路徑則以細線顯示。
2. 點選一條線：整條相連的路徑會被選取。工具列下方的列會顯示其線段、長度、縫隙容許值，以及已橋接的縫隙數量。回到起點的路徑為封閉路徑，並會另外顯示其周長。
3. 或在封閉輪廓內部點選，遠離任何線條：會將該點周圍的輪廓選取為面積。最小的輪廓會先被選取；按{{key:Tab}}可嘗試下一個較大的輪廓。
4. 按{{key:Enter}}（或按右鍵，或按兩下）以新增標記。選取的路徑會成為**線性**項目的標記，輪廓則成為**面積**項目的標記：優先使用目前項目（若其類型相符），否則使用最新建立的同類型項目。若沒有任何項目，會開啟新項目表單，直到再次按{{key:Enter}}前不會新增任何內容。所有選取的內容會以一個復原步驟新增。

## 縫隙容許值

製圖者會在線條應相接之處留下小縫隙。當兩條線的端點距離小於**縫隙容許值**時，兩線會相連。其起始值為圖紙上的 1.5 pt（依圖紙比例以英尺與英吋顯示）。一個同寬度的虛線圓環會跟隨指標，並位於其下路徑的每個端點上。每個被橋接的縫隙，在選取的路徑上會以橘色圈出，且列中會計數。

{{key:]}}會加寬容許值，{{key:[}}會縮窄。已選取的路徑會立即以新容許值重新相連。在交會處，路徑會沿轉彎最小的方向直行，並離開分支。

## 按鍵

| 按鍵或動作 | 作用 |
|---|---|
| 點一下 | 選取指標下的路徑，或其周圍的輪廓。 |
| {{key:Shift}} + 點一下 | 將另一條路徑或輪廓加入已選取的內容。 |
| {{key:Tab}} | 嘗試指標下的下一條路徑，或下一個較大的輪廓。 |
| {{key:Backspace}}或{{key:Mod+Z}} | 逐段移除最後選取路徑的最後一段。沒有線段的路徑會被移除。若未選取任何內容，{{key:Mod+Z}}即為一般復原。 |
| {{key:[}}與{{key:]}} | 縮窄與加寬縫隙容許值。 |
| {{key:Enter}} | 新增標記。 |
| {{key:Esc}} | 清除已選取的內容。 |

## 注意事項

- 圖形中的曲線由多段短直線組成，因此其長度會略短於真實弧長。若要取得精確的弧長，請量測圖形本身的檔案（[從圖形量測](topic:measure-from-a-drawing)）。
- 被橋接的縫隙會視為跨越它的直線跳接，因此封閉輪廓的周長會包含該段。
- 只有頁面本身路徑中的筆畫與填色才是線條。以文字字形繪製的文字與圖片不屬於線條。

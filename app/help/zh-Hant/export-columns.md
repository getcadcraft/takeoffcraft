## 估價（XLSX 工作表與 CSV）

每個項目一列，其後為其組合中每個組件一列（縮排）。接著是一個空白列與工作總計。

| 欄 | 內容 | 在 XLSX 中 |
|---|---|---|
| A 項目 | 項目名稱（粗體）或組件名稱（縮排） | 文字 |
| B 類型 | 線性、面積、計數或組件 | 文字 |
| C 單位 | LF、m、SF、SY、m²、EA，或組件的單位 | 文字 |
| D 數量 | 量測總和，或公式結果 | 數字 |
| E 損耗 % | 損耗 | 百分比（0.10 = 10%） |
| F 含損耗數量 | 數量 ×（1 + 損耗） | 公式 `D*(1+E)` |
| G 每單位材料 | 材料單價 | 數字 |
| H 每單位人工 | 人工單價 | 數字 |
| I 材料 | 延伸材料 | 公式 `ROUND(F*G,2)` |
| J 人工 | 延伸人工 | 公式 `ROUND(F*H,2)` |
| K 合計 | 材料 + 人工 | 公式 `I+J` |
| L 附註 | 使用的公式、公式錯誤、無比例尺圖紙上的標記、牆面面積、周長 | 文字 |

工作總計列：對上方每一列的 I、J、K 欄執行 `SUM`；若有遺漏項目，附註欄會顯示「不完整：請見上方附註」。

公式錯誤的列沒有數量或金額；其附註會說明錯誤。標題列已凍結。

在 CSV 中，相同欄位存放純數值，損耗 % 為百分比數字（10 表示 10%），金額以美元計、保留兩位小數。可能被試算表當成公式的文字（以 `=`、`+`、`-` 或 `@` 開頭）會在前面加上 `'`，使其保持為文字。

## 依圖紙（僅 XLSX）

| 欄 | 內容 |
|---|---|
| 圖紙 | 圖紙名稱（未開啟時附上 PDF 名稱） |
| 項目 | 項目名稱 |
| 數量 | 該項目在該圖紙上的數量，以其單位計 |
| 單位 | 項目的單位 |
| 標記 | 標記數量 |

## 標記（僅 XLSX）

每個標記一列。

| 欄 | 內容 |
|---|---|
| 圖紙 | 圖紙名稱 |
| 項目 | 項目名稱 |
| 類型 | 線性、面積或計數 |
| 數量 | 長度、淨面積，或 1 |
| 單位 | LF 或 m；SF、SY 或 m²；EA |
| 明細 | 線性：各段長度，扣除的段標示「(扣除)」，以及「扣除 (長度)，已繪製 (長度)」。面積：有開孔時的總面積與開孔面積，以及周長。未設定比例尺的標記顯示「圖紙無比例尺」。 |
| 投標範圍 | 僅當數量計算有投標範圍時：該標記的面積，或「無投標範圍」 |

## 依投標範圍（僅 XLSX，當數量計算有投標範圍時）

| 欄 | 內容 |
|---|---|
| 投標範圍 | 範圍名稱，或「無投標範圍」 |
| 項目 | 該項目，或其下縮排的組件 |
| 單位 | 項目或組件的單位 |
| 數量 | 在該範圍內量測（組件：範圍總計上的公式） |
| 含損耗數量 | 數量 ×（1 + 損耗） |
| 材料、人工、合計 | 精確到分，與估價工作表相同 |
| 附註 | 公式、錯誤與無比例尺標記，與估價工作表相同 |

每個範圍結尾為「(名稱) 小計」列，其金額為對該範圍各列的 `SUM` 公式；最後一列 **所有投標範圍** 加總各小計。**標記**工作表則會多一欄 **投標範圍**（第七欄）。

## 比例尺（僅 XLSX）

每張有比例尺或標記的圖紙一列。

| 欄 | 內容 |
|---|---|
| 圖紙 | 圖紙名稱 |
| 比例尺 | 預設集名稱、校正後的比例尺，或「無比例尺」 |
| 設定方式 | 「預設」，或「依輸入的距離校正」 |
| 每 PDF 單位的英尺數 | TakeoffCraft 使用的精確比例係數 |

## 檔案名稱

- `(name).xlsx` 與 `(name).csv`，檔名取自數量計算中第一個開啟的 PDF。
- CSV 採 UTF-8 編碼，附帶位元組順序標記（BOM）並使用 Windows 換行，各平台的試算表程式皆可讀取。

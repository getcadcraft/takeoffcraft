項目的**組合件**是一份組件清單，每個組件都有自己的數量公式、損耗與單價。公式使用項目的實測總計，因此對牆面做一次數量計算，就能同時得到間柱、底板與板材，而且它們會隨你的量測即時更新。

## 可用的變數

| 項目類型 | 變數 |
|---|---|
| 線性 | `L` 長度、`H` 高度、`A` 牆面面積（L × H）、`N` 段數 |
| 面積 | `A` 面積、`P` 周長（外框 + 開孔）、`H` 深度或厚度、`N` 區域數 |
| 計數 | `N` 數量 |

數值使用項目本身的單位：LF 與 SF 項目為英尺與平方英尺，m 與 m² 項目為公尺與平方公尺。對 SY 項目而言，`A` 為平方碼，而 `P` 與 `H` 仍為英尺。

公式可使用 `+ - * /`（或 × ÷）、括號、數字，以及函式 `ceil`、`floor`、`round`、`min`、`max` 與 `abs`。完整規則請見[公式語言](topic:formulas)。

## 範例：室內牆

假設你已將**室內牆 A 型**以線性項目計算：共 4 段、總長 120 LF，並將{{ui:高度}}設為 `9'-0"`。其**實測**值為 L = 120、N = 4、A = 1,080（牆面 SF，單面）。

1. 在{{ui:項目}}下選取該項目。
2. 在{{ui:組合件}}中選擇{{ui:新增組件}}。
   畫面會出現一個名為「組件」的組件，其公式為 `L`，結果顯示在下方。
3. 在{{ui:名稱}}中輸入 `Studs 16 in o.c.`，在{{ui:單位}}中輸入 `EA`。
4. 在{{ui:數量公式}}中輸入 `ceil(L * 12 / 16) + N`。
   結果會隨你輸入即時更新：「= 94 EA」。這代表每 16 英吋一根，沿 120 英尺共 90 根，再加上 4 段各多一根以收尾。
5. 再次選擇{{ui:新增組件}}加入底板：名稱 `Plates, top and bottom`，單位 `LF`，公式 `L * 2`。結果：240 LF。
6. 加入板材：名稱 `Gypsum board 4x8, both sides`，單位 `sheets`，公式 `ceil(A * 2 / 32)`。結果：68 張（板材 2,160 SF ÷ 每張 32 SF = 67.5，無條件進位）。
7. 填寫每個組件的{{ui:損耗 %}}、{{ui:材料 $}}與{{ui:人工 $}}。
   每個組件會在{{ui:數量}}中項目底下各自顯示一列，計價方式與項目相同，且{{ui:工程總額}}會包含它。

若牆面成本全部計入組件，請將項目本身的材料與人工單價保持為 0，否則會重複計算。

:::tip
損耗會在公式之後套用，且不做進位：68 張加上 10% 損耗為 74.8 張。若要訂購整張板材，請將損耗放進公式，例如 `ceil(A * 2 / 32 * 1.1)`，並將組件的損耗保持為 0。
:::

## 更多公式

| 用途 | 項目 | 公式 |
|---|---|---|
| 間柱，每 24 英吋中心 | 線性 | `ceil(L / 2) + N` |
| 隔熱棉，SF | 有高度的線性 | `A` |
| 油漆，雙面，每 350 SF 一加侖 | 有高度的線性 | `ceil(A * 2 / 350)` |
| 瓷磚箱數，每箱 15 SF，多 10% | 面積 | `ceil(A * 1.1 / 15)` |
| 踢腳板或邊條，LF | 面積 | `P` |
| 混凝土，立方碼 | 有深度的面積 | `A * H / 27` |
| 混凝土，無條件進位至四分之一碼 | 有深度的面積 | `ceil(A * H / 27 * 4) / 4` |
| 鉸鏈，每門三個 | 計數 | `N * 3` |
| 至少一盒，每 12 個一盒 | 計數 | `max(1, ceil(N / 12))` |

## 公式出錯時

公式下方那一行會變成錯誤訊息，例如 `"X" is not a measured value here. Use L, H, A, N.` 或 `A ")" is missing.`。接著該組件沒有金額，它在{{ui:數量}}中的那一列會顯示「公式錯誤：…」，標題會顯示「未完成：1 個公式錯誤（未計入總計）」。修正公式後，總計會自動更新。

公式除以零也是錯誤，例如在沒有深度的項目上使用 `A / H`，會顯示「公式除以零。」

## 限制

- 公式是針對項目的**總計**計算，而非逐段計算。`ceil(L * 12 / 16) + N` 會對每段各加一根間柱；目前尚未支援逐段進位。
- 公式只能使用其所屬項目的變數，不能使用其他項目的變數。
- 每個項目最多 50 個組件，每個公式最多 500 個字元。

## 移除組件

在組件下方選擇{{ui:移除組件}}。你可以用{{key:Mod+Z}}復原。

只要指標位於頁面任何位置，且未在欄位中輸入，字母鍵即可使用。對話方塊開啟時，其自身的按鍵會生效。字母鍵可搭配或不搭配{{key:Shift}}使用。

## 繪製時

| 按鍵或動作 | 作用 |
|---|---|
| 點擊 | 放置一個點（使用{{ui:Count}}時為計數點）。 |
| {{key:P}} | 路徑：選取 PDF 線條的整段相連路徑，或點擊處周圍的輪廓（[選取 PDF 線條](topic:pick-the-lines)）。 |
| {{key:F3}} | 開啟或關閉鎖點至圖紙線條（[鎖點至圖紙線條](topic:snap-to-the-drawing)）。 |
| 點擊時按住{{key:Shift}} | 線段以上一點為基準，吸附至 0°、45°、90° 或 135°。不適用於圓弧點或圓。 |
| 連按兩下 | 結束線段，或封閉面積或切除區。 |
| {{key:Enter}} | 結束線段，或封閉面積或切除區。 |
| 按右鍵（未移動） | 結束線段，或封閉面積或切除區。 |
| 點擊第一點 | 封閉面積或切除區（自第三點起）。 |
| {{key:Backspace}}或{{key:Delete}} | 移除最後一點（若有待定的圓弧點，先移除該點）。 |
| {{key:Esc}} | 捨棄待定的圓弧點；接著取消未完成的標記；然後返回{{ui:Select}}。 |

## 選取與編輯

| 按鍵或動作 | 作用 |
|---|---|
| 點擊標記（選取工具） | 選取該標記，並將其所屬項目設為目前項目。 |
| {{key:Shift}} + 點擊標記 | 加入選取集，或將其移出。 |
| {{key:Mod+A}} | 全選開啟圖紙上的每個標記。 |
| 拖曳角控點 | 移動該點（{{key:Shift}}會吸附至 45°）。選取一個標記時可用。 |
| {{key:Delete}}或{{key:Backspace}} | 刪除選取的標記（未在繪製時）。 |
| {{key:Esc}} | 取消選取：清除選取集與檢查線。 |
| {{key:Mod+Z}} | 復原。 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 取消復原。 |

## 複製與貼上

| 按鍵 | 作用 |
|---|---|
| {{key:Mod+C}} | 複製選取的標記及其項目。 |
| {{key:Mod+X}} | 剪下：複製選取的標記，然後刪除。 |
| {{key:Mod+V}} | 貼上：副本跟隨指標；點擊要放置的位置。 |
| {{key:Mod+Shift+V}} | 原位貼上：開啟圖紙上的相同位置。 |
| {{key:Mod+D}} | 建立選取標記的副本：副本跟隨指標；點擊要放置的位置。 |
| {{key:Esc}} | 不放置任何內容：取消跟隨指標的貼上或建立副本。 |

單獨的字母鍵仍可選取工具（{{key:C}}為{{ui:Count}}，{{key:D}}為{{ui:Check}}，{{key:X}}為{{ui:Cut-out}}，{{key:V}}為{{ui:Select}}，{{key:A}}為{{ui:Area}}）；只有搭配{{key:Mod}}時才會複製與貼上。在文字欄位中，這些按鍵會照常複製與貼上文字。參見[複製、貼上與建立標記副本](topic:copy-paste)。

:::warning
未在繪製時，{{key:Backspace}}會刪除選取的標記。若誤刪，可按{{key:Mod+Z}}復原。
:::

## 3D 檢視

| 按鍵或動作 | 作用 |
|---|---|
| 拖曳，或以中鍵拖曳 | 環繞旋轉。 |
| {{key:Shift}} + 拖曳，或以右鍵拖曳 | 平移。 |
| 滾輪 | 在指標位置縮放。在觸控板上，雙指滑動為環繞旋轉，捏合為縮放。 |
| 點擊 | 選取指標下方的標記（{{key:Shift}} + 點擊可加入或移出）。 |
| {{key:F}}或{{key:W}} | 範圍縮放。 |
| {{key:3}} | 返回平面圖紙。 |

## 說明

| 按鍵 | 作用 |
|---|---|
| {{key:F1}} | 開啟或關閉說明面板（也可使用應用程式列上的{{ui:Help}}按鈕）。在任何工具中皆可使用，即使在欄位中輸入也一樣。 |
| {{key:Esc}} | 關閉說明面板。在其搜尋方塊中，第一次按Esc會清除搜尋。面板開啟時，若在點擊圖紙後按Esc，會先關閉面板；再按一次即可在 TakeoffCraft 中取消操作。 |

:::mac
在許多 Mac 鍵盤上，頂列按鍵控制亮度與音量。可按住fn並按F1，或在「系統設定」的「鍵盤」下開啟「將 F1、F2 等鍵用作標準功能鍵」。
:::

## 平台注意事項

:::mac
- {{key:Mod}}為 Command 鍵：{{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。全螢幕為例外：Control+Shift+F。
- 在觸控板上以雙指點擊即為右鍵，前提是已在「系統設定」的「觸控板」下開啟次要點按。TakeoffCraft 只讀取次要按鈕；Control 點擊可能被視為一般點擊，並新增一個點。
- 在觸控板上以雙指捲動會縮放圖紙（而非捲動）。若要平移，可按住並拖曳，或按住Space並拖曳。
- 在沒有這兩鍵的鍵盤上，Page Up與Page Down為fn加上上、下方向鍵。
- Backspace即標示為delete的按鍵。
:::

:::windows
- {{key:Mod}}為Ctrl：{{key:Mod+Z}}、{{key:Mod+S}}、{{key:Mod+O}}。
- 在筆電觸控板上，雙指捲動會縮放圖紙。若要平移，可按住並拖曳。
:::

:::linux
- {{key:Mod}}為Ctrl。部分桌面環境有自己的 Ctrl+Alt 或 Super 快速鍵；TakeoffCraft 都不使用這些快速鍵。
- 在觸控板上，雙指捲動會縮放圖紙。若要平移，可按住並拖曳。
:::

:::touch
TakeoffCraft 將觸控視為單一指標：

- 輕觸可放置點、選取標記或新增計數點。
- 以一根手指拖曳可平移圖紙（在{{ui:Auto count}}中則繪製搜尋方塊）。
- 尚未支援捏合縮放。可改用{{ui:Fit page}}與{{ui:Fit width}}，或鍵盤上的{{key:Plus}}與{{key:Minus}}。
- 若要封閉面積，輕觸其第一點。若要結束線段，可在瀏覽器會把兩次輕觸視為連按兩下的位置輕觸兩次，或在鍵盤上按{{key:Enter}}。
- 由於沒有懸停，在輕觸之前不會即時顯示長度。

目前使用鍵盤與滑鼠或觸控板進行數量計算較為理想。
:::

## 瀏覽器保留的按鍵

瀏覽器會自行保留部分快速鍵，頁面無法使用這些快速鍵：關閉分頁（{{key:Mod+W}}）、新增分頁或視窗（{{key:Mod+T}}、{{key:Mod+N}}）以及瀏覽器縮放（{{key:Mod+Plus}}、{{key:Mod+Minus}}）。因此 TakeoffCraft 以滾輪及單獨的{{key:Plus}}與{{key:Minus}}按鍵縮放圖紙。若誤按{{key:Mod+Plus}}，整個頁面會放大；{{key:Mod+0}}可將其還原。參見[按鍵、滑鼠與觸控板](common:keys)。

## 移動指令的位置

沒有移動指令：選取計數點並拖曳即可，或選取面積或線條後拖曳其角控點。
